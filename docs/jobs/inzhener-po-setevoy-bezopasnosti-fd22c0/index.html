Инженер по сетевой безопасности. Локация: #Москва. Опыт: 3+ лет. Зарплата: ₽. Обсуждается на собеседовании. Компания: Т-Банк. Обязанности: • Поддерживать и развивать средства сетевой защиты: FW/NGFW, IDS/IPS, Proxy, HBFW и другие. • Заниматься операционной работой по сетевым доступам: ревью, выдача, траблшутинг. • Улучшать операционные процессы команды. • Актуализировать документацию по сетевой безопасности — внутреннюю и пользовательскую. • Автоматизировать рутинные задачи и процессы: скрипты, API, интеграции. • Участвовать в разработке и развитии новых внутренних инструментов автоматизации. Требования: • Имеешь опыт внедрения и эксплуатации сетевых средств защиты: FW/NGFW, IDS/IPS, Web Proxy и других. • Уверенно разбираешься в сетевых технологиях и протоколах: TCP/IP, VLAN, TLS, DNS, mTLS, IPsec, QUIC, VRF, протоколы маршрутизации. • Понимаешь принципы работы механизмов защиты: SSL/TLS decryption, URL filtering, Application Control, 802.1X, ACL, MAB, Port Security и других. • Знаешь современные подходы к информационной безопасности: Zero Trust, Secure by Design, defense-in-depth. • Умеешь автоматизировать задачи на одном или нескольких языках: Python, Go, PowerShell, Bash. • Работал(а) с процессами согласования и выдачи сетевых доступов. #Гибрид
