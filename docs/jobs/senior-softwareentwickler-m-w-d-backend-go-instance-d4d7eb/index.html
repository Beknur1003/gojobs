(Senior) Softwareentwickler (m/w/d) Backend Go – Instance

Unser Hetzner Cloud Team mit ca. 80 Mitarbeiter:innen arbeitet sowohl deutschlandweit remote als auch in unserem Büro in München (Unterföhring). Das Instance Team entwickelt das Herzstück der Hetzner Cloud: die Plattform, auf der täglich tausende virtuelle Server erstellt werden. Gemeinsam baut das Team zentrale Cloud-Produkte wie Cloud-Server, Volumes und Snapshots weiter aus, bringt eigene Ideen ein und meistert spannende Skalierungsherausforderungen, damit unsere Infrastruktur zuverlässig und skalierbar bleibt. Dabei setzt das Team auf moderne Technologien wie Go, PostgreSQL, Redis, Docker und Kafka, folgt aber nicht jedem Hype, ganz nach dem Motto „the right tool for the job“. Eine ausgereifte CI/CD-Pipeline auf Basis von GitLab, Docker und Kubernetes ermöglicht effizientes Entwickeln, während automatische Tests und Code Reviews für Sicherheit und Qualität sorgen. Weil gutes Tooling für die Arbeit entscheidend ist, wird es kontinuierlich weiterentwickelt. Diese Stelle beinhaltet eine Bereitschaftsrotation zur Aufrechterhaltung der Dienste und kann remote innerhalb Deutschlands ausgeübt werden. Für diese Position ist ein Jahresgehalt zwischen 68.000 und 101.000 EUR brutto vorgesehen. Die konkrete Einstufung erfolgt in Abhängigkeit von Berufserfahrung und Verantwortungsumfang. Unser Stack in Schlagworten: Go, PostgreSQL, Docker und Kafka. Deine Aufgaben • Du entwickelst unsere Cloudprodukte Cloud-Server, Volumes und Snapshots weiter und baust sie aus • Du arbeitest mit einer Continuous Integration/Deployment Pipeline auf Basis von GitLab, Docker und Kubernetes • Du schreibst sauberen, verständlichen Code (DRY, KISS) und automatisierte Tests • Du führst gemeinsam mit deinem Team Code Reviews durch • Du aktualisierst bestehende Dokumentationen eigenständig und führst sie fort • Du nimmst an einer Bereitschaftsrotation teil und sorgst so für den zuverlässigen Betrieb unserer Dienste Requirements • Du hast sehr gute Programmierkenntnisse in Go • Du bringst Erfahrung mit Datenbanksystemen und event-basierten Systemen (Kafka) mit • Du kennst dich mit Docker, GitLab und Kubernetes aus • Du legst Wert auf sauberen, verständlichen Code (DRY, KISS) und automatisiertes Testen • Du arbeitest verlässlich, selbstständig und flexibel und dokumentierst deine Projekte strukturiert und eigenständig • Du sprichst und schreibst fließend Deutsch und Englisch Originally posted on Himalayas
