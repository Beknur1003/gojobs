Software Engineer - Product Platform Security

Rubrik Job Board Palo Alto, CA опубликовано 6 октября 2026

AWSGCPAzureLinuxPythonJavaC++BlockchainAI/LLM
About the Team & Role The Platform Security Engineering team builds the security features and frameworks that every Rubrik product runs on protecting hundreds of petabytes of data across thousands of enterprise customers globally, from encryption and certificate management to access control and platform hardening at scale. We're a small team with massive impact: the problem space covers the entire Rubrik portfolio, from performant core backend architecture to the AI-powered engineering workflows we and the rest of Rubrik now build with daily. This is a strong opportunity for new grads and early-career engineers who want real ownership on security-critical systems. You'll help solve problems like: • How do we roll out post-quantum cryptography across the backup data path before it's an industry requirement? • How do we let customers manage sessions and access against compromise, at enterprise scale? • How do we build an access control engine that holds up against dynamic, customer-defined policies unique to a data management platform? • How do we secure the AI agents and agentic developer workflows that are now embedded in how Rubrik engineers ship code? You'll work alongside experienced engineers and deeply technical managers who will mentor you as you grow, on a roadmap with genuine business impact. What You'll Do Security feature development • Design and steer AI to write clean, well-tested code in Go, Scala, or Python for scalable, secure platform services. • Collaborate with senior engineers on system design and architecture decisions. • Identify attack surfaces and build solutions to harden Rubrik products. • Triage, debug, and drive product/system issues to resolution with clear ownership. • Use AI coding assistants and agentic workflows as a core part of your daily engineering, while learning to treat AI-generated code as untrusted input that gets the same security scrutiny as any other contribution. Security code and design reviews • Review code and design docs from other teams to flag security concerns before they ship. • Help extend our review practices to cover AI-powered features and AI agents as they become part of Rubrik's product surface. • Contribute to secure coding guidelines and evangelize them across engineering. Team collaboration • Partner with Product Management, UI/UX, docs, InfoSec, and support to turn security requirements into shipped features. • Participate in planning, design reviews, and knowledge sharing. How We Build and Secure with AI AI isn't a side note for this team, it's part of the job on both sides: • As builders: you'll use AI coding assistants and agentic tools as part of your normal workflow, the same way the rest of Rubrik engineering does. • As security engineers: you'll help define what "secure" means for AI-generated code, AI-powered features, and autonomous agents acting inside Rubrik's infrastructure, an active, fast-moving part of our roadmap. What We're Looking For Required • Bachelor's degree in CS, Software Engineering, or related field, or equivalent practical experience. • 0-2 years of software development experience (internships, personal projects, and bootcamps count). • Strong fundamentals in at least one language (Go, Java, Python, C++, or similar) and in data structures, algorithms, and testing. • Genuine interest in security, curious about how systems break and motivated to build things that don't. • A proactive, self-directed learning style; comfortable asking questions and diving into ambiguity. Preferred • Coursework, personal projects, or internships in cybersecurity, cryptography, or systems security. • Comfort with Linux/Unix, Git, and basic networking (TCP/IP, HTTP/HTTPS, DNS). • Exposure to cloud platforms (AWS, Azure, GCP). • Hands-on experience with AI coding assistants or agentic dev tools (Claude Code, Copilot, or similar). • Interest in open-source security tooling or the broader security community. What Makes a Great Candidate Beyond the qualifications above, the traits that predict success on this team: • Thinks critically - can analyze problems and reason through potential security implications, not just implement what's asked. • Collaborates well - enjoys working with others and learning from teammates across disciplines. • Pays attention to detail - understands that small details matter in security. Growth & Mentorship You'll be paired with senior engineers who invest directly in your growth. Over time, expect to build real depth in: • Applied cryptography, secure protocol design, and threat modeling. • Distributed systems, API design, and system-level security testing. • Security code review — spotting vulnerability patterns in both human- and AI-written code. • Technical communication, documentation, and (as you grow) mentoring others yourself. We back this with a dedicated mentorship program, regular tech talks and learning sessions, and support for security conferences and training. Why Join Shield Platform? The best entry point into security engineering we know of: direct ownership on mission-critical production systems that safeguard Fortune 500 enterprises and critical infrastructure worldwide, mentorship from veteran security architects, and a forward-looking roadmap spanning post-quantum cryptography to AI agent security that puts you at the absolute forefront of enterprise security engineering.
