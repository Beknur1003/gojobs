About Mandolin Nearly every disease will become treatable in our lifetimes. Mandolin is laying the clinical and financial infrastructure to get groundbreaking treatments to patients faster, powered by AI agents. Mandolin partners closely with the largest healthcare institutions in the US, covering more than $10B drug spend across the country. We're backed by Greylock, SV Angel, Maverick, SignalFire, and the founders of Vercel, Decagon, and Yahoo. Why we need you Mandolin’s usage is climbing quickly and we’re preparing for a broad public launch. The platform must deliver enterprise-grade reliability, airtight security, and effortless developer productivity while processing sensitive healthcare data. We’re looking for an Infrastructure Engineer who can build and operate a rock-solid cloud foundation—then codify the best-practice guardrails that every engineer will rely on as we scale. What you’ll do • Own cloud infrastructure end-to-end: Design and operate scalable, highly available environments across development, staging, and production. Establish autoscaling policies, HA networking, cost-efficient resource management, and clear environment parity. We run on GCP today — what matters is how you think about infrastructure, not which cloud you learned on. • Drive GitOps and Kubernetes delivery: Own the GitOps delivery pipeline using ArgoCD and Kubernetes. Manage clusters, ApplicationSets, workload deployments, and promotion workflows across environments. Ensure deployments are reliable, observable, and safely reversible. • Embed security into the SDLC: Centralize secrets management, define zero-trust IAM policies, integrate continuous vulnerability scanning into CI/CD, and own incident-response playbooks. Security is a design input, not an afterthought. • Build first-class observability: Deploy and maintain metrics, tracing, and log pipelines. Define actionable SLOs and alerting so the team knows about problems before customers do. • Improve developer experience: Provide runbooks, local-environment tooling, and clear onboarding patterns that let new engineers ship safely on day one. Reduce toil through automation and golden-path tooling. • Write code that matters: Infrastructure at Mandolin isn't just configuration — you'll write Go to build internal tooling, automate operational workflows, and solve problems that can't be solved with YAML alone. • Collaborate across teams: Review architectural changes for infrastructure and security impact. Partner with backend engineers on scalability initiatives. Document decisions clearly so knowledge doesn't live only in your head. Must-have experience • 7+ years building and operating production cloud infrastructure at scale • Deep hands-on experience with Kubernetes — cluster management, workload design, networking, autoscaling, production troubleshooting • GitOps & ArgoCD: Experience with ApplicationSets, sync waves, multi-cluster delivery, promotion workflows • CI/CD experience: GitHub Actions, Cloud Build, or equivalent — pipelines, caching, artifact management, security gates • IAC: Pulumi, Terraform, or equivalent — writing infrastructure as code, not just running it • Secrets Management: centralized stores, ESO or equivalent, automated rotation, zero inline secrets • Security: IAM design, zero-trust principles, vulnerability scanning, dependency management • Experience writing production-quality code in GoLang, functional programming style, not just scripts • Cloud experience: we run on GCP.
