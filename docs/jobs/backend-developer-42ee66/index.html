About the role We are seeking a Backend Developer to design, build, and maintain high-performance server-side logic using Go (Golang). You will be responsible for managing data persistence in PostgreSQL, implementing real-time streaming with Redpanda, and orchestrating services within a Google Cloud Platform (GCP) environment. This role focuses on building efficient, concurrent microservices that handle large data volumes and real-time event processing. Key responsibilities • Develop efficient, concurrent microservices using Go (Golang) to handle high-traffic applications • Maintain and optimize PostgreSQL databases, utilizing advanced features like JSONB for semi-structured data • Utilize Redis as an in-memory data store for high-speed caching, session storage, and low-latency messaging • Implement GraphQL APIs and manage service federation via Apollo Gateway to centralize authentication and authorization • Design event-driven architectures using Redpanda (a high-performance Kafka alternative) for real-time data streaming • Execute deep integrations with healthcare partners, primarily DoseSpot for e-prescribing, as well as PointClickCare, Waystar, and PhilHealth • Package and manage applications using Docker containers to ensure consistency across different environments • Deploy and manage services on GCP Compute Engine and Cloud Functions • Enforce Data at Rest security through encryption and manage access via Identity and Access Management (IAM) using least privilege principles • Automate tasks and manage cloud provisioning using Ansible and Bash scripts About you • 0-2 years of experience, open for fresh graduates with relevant internship experience
