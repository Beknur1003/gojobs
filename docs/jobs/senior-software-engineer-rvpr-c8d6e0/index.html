SENIOR SOFTWARE ENGINEER RVPR is seeking a Senior Engineer to help build and scale the distributed systems that power personalization and data across our portfolio. In this role, you'll design and operate high-performance backend services and the message-driven pipelines that connect them, working primarily in Go alongside Python-based AI agents. You'll collaborate with teammates to build systems that are reliable, observable, and built to scale, leveraging modern AI-assisted development practices to move faster without cutting corners. At RVPR, we believe exceptional products are built by exceptional people. We foster a collaborative, agile environment that values learning, craftsmanship, and work-life balance. We offer competitive benefits, flexibility, and strong opportunities for professional growth, alongside a commitment to diversity and inclusion. Join us to make a meaningful impact by building platform infrastructure that enables personalized experiences at scale. What You’ll Do: • Build systems for scale, observability, and fault tolerance across distributed services • Own end-to-end delivery from design through deployment and on-call • Maintain CI/CD pipelines and infrastructure using GitHub Actions, Terraform, and AWS • Use agentic coding tools (Claude Code, Codex, Cursor, or whatever's next) as co-engineers, not autocomplete • Build intelligent agents and automation in Python where it accelerates the platform • Continually look for opportunities to set standards, build tools, and automate toil out of existence • Coordinate with data science, product, and other engineering teams to deliver quality solutions • Contribute to key architectural decisions and system design across the platform • Participate in code reviews to maintain high standards and share knowledge • Research and prototype next-generation solutions using modern tech stacks (TypeScript, NextJS, Python) to validate technical hypotheses and prove concepts before production • Experiment with emerging AI frameworks, tools, and architectures—building POCs that push the boundaries of what's possible • Design and implement experimental services and APIs that serve as technical foundations for future product innovations • Drive technical discovery through hands-on coding, measurement, and analysis—moving from idea to validated proof-of-concept • Work autonomously on ambiguous problems where the solution path isn't clear, using agile principles to manage uncertainty What We’re Looking For: • Technical Mastery: Proficient in React and React Native, with understanding of Python. Plus if you have Go experience • Technical Skills: Solid experience in API development and Amazon Web Services (AWS) • Passion for AI: A keen interest in OpenAI, LangChain, and Large Language Models (LLMs) • Growth Mindset: A relentless desire to learn and excel in a tech-driven environment • Hands-on experience with CI/CD pipelines and testing in a production context At Red Ventures we offer a competitive offer package.
