О проекте

Это бесплатная лента вакансий для Go-разработчиков. Она собирает вакансии из Telegram-каналов, открытых досок удалённой работы, треда «Who is hiring» на Hacker News и карьерных страниц компаний, склеивает дубли и показывает контакты рекрутеров открыто. Без регистрации, подписки и лимитов на открытие контактов.

Как это работает

  1. Сбор раз в день. Скрипт читает публичное веб-превью Telegram-каналов (то же, что видно в браузере на t.me/s/канал), открытые ленты досок удалённой работы и API карьерных систем Greenhouse, Lever, Ashby и Workday.
  2. Разбор правилами. Зарплата, формат, грейд, английский, стек и контакты извлекаются регулярными выражениями и словарями, без нейросетей. Иногда это ошибается: точный текст всегда в оригинале.
  3. Регион и «Go — основной». Регион берётся из места работы, кода страны, валюты зарплаты и начала поста. «Из любой страны» ставится, только когда источник прямо пишет Worldwide, Global или «из любой точки мира». «Go — основной» значит, что Go в названии роли или в тексте упоминается заметно чаще других языков бэкенда.
  4. Склейка дублей. Одна вакансия в пяти каналах — одна карточка с пятью ссылками. Совпадение ищется по контактам, компании с названием и похожести текста.
  5. Ссылка на оригинал у каждой вакансии. Сайт ничего не публикует от себя и всегда ведёт к первоисточнику.

Зарплата в долларах в месяц считается по фиксированному курсу и нужна только для фильтра. Пост из Telegram держится в ленте 60 дней. Вакансия с сайта компании или доски держится, пока источник её показывает, и пропадает, как только её сняли.

Remote OK, Remotive, Himalayas, Jobicy, We Work Remotely, Djinni, Arbeitnow и Working Nomads разрешают использовать свои ленты при условии ссылки на оригинальную вакансию; она есть на каждой странице. Списки компаний для проверки взяты в том числе из открытого проекта job-board-aggregator (MIT).

Ещё тысячи вакансий с сайтов компаний на ~90 карьерных системах (Oracle, iCIMS, SmartRecruiters, сайты Яндекса, Ozon, VK и других) приходят через открытый API freehire — открытого проекта с исходным кодом под MIT. У таких вакансий источник подписан «freehire», а кнопка отклика ведёт на сайт компании.
