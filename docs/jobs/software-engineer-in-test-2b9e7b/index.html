Software Engineer in Test

Recro Gurugram, Haryana, India опубликовано 19 ноября 2026

Офис Контракт / B2B
DockerPrometheusGrafanaCI/CDPythonAI/LLM
About the role: We are seeking a skilled SDET to own test automation end to end: build the framework, build the pipeline that tests and monitors our voice orchestration product, and make the same foundation reusable for every product that follows. WFO - Gurgaon, 5 days working Requirements • You will design, build and run the automation and monitoring that tells us whether each product is ready to ship and healthy once it is live. Build the automation framework. • Design a modular, reusable framework (API, UI, load and data layers, shared fixtures, reporting) that any new product can adopt with minimal setup. • Set the coding standards and structure for how tests are written at sixhats.ai. • Test the voice orchestration pipeline end to end. • Automate full call flows with simulated callers. • Cover call setup and teardown, interruptions and turn-taking, speech recognition accuracy, response latency, speech output quality, conversation flow correctness and telephony edge cases. • Handle non-deterministic AI output. • Create evaluation approaches (golden datasets, scoring rubrics, tolerance-based assertions) so that tests stay meaningful when model responses vary. Own performance and reliability testing. • Run load, stress and soak tests for concurrent calls, and inject failures (network loss, slow or failing upstream services) to confirm the platform degrades gracefully. • Wire quality into CI/CD. Run suites in parallel on every change, set release gates, keep tests fast and stable, and drive down flaky tests rather than tolerating them. Build monitoring and observability. • Set up synthetic test calls against production, dashboards and alerts for latency, error rates, call success and audio quality, and work with engineering to define the targets we hold ourselves to. Prepare for the next products. Extend the framework to the CRM (workflows, APIs, data integrity, permissions) and the photo imaging studio (image output quality, visual regression, processing performance). • Raise the quality bar across the team. Join design and code reviews, push for testable designs, triage defects, assess release readiness and mentor engineers on writing good tests. Required Qualifications and Skills: • 2 - 3 years in SDET, test automation or quality engineering roles, with at least one framework built from scratch (not only maintained). • Must be from a Tier 1 college (Top: IIT/IIIT, also NIT/DTU/REC) ONLY, with a Computer Science B.Tech only. • Strong programming skills in Python (preferred), Golang: clean code, object-oriented design, async programming and sensible design patterns. • Framework design experience: layered structure, reusable clients and fixtures, configuration and environment management, test data handling and clear reporting. • API testing depth across REST and streaming protocols such as WebSockets, plus contract testing and mocking of third-party services. • UI test automation with Playwright, Selenium or Cypress, including strategies to keep UI tests stable. • CI/CD experience with GitHub Actions, GitLab CI or Jenkins, and working knowledge of Docker for repeatable test environments. • Performance testing with k6, Locust, JMeter or similar, and the ability to read results and find bottlenecks. • Monitoring and observability basics: logs, metrics and traces, dashboards and alerting (Grafana, Prometheus, Datadog or similar). • Solid SQL and comfort debugging across several services using logs and tracing. • A sound test strategy mindset: test pyramid, risk-based prioritisation and shift-left practices. • Clear written and verbal communication, and ownership of quality outcomes without waiting to be told.
