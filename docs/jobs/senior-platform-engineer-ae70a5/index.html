The Role We are looking for a Senior Platform Engineer on behalf of our client to build, scale, and maintain an Internal Developer Platform (IDP) that empowers application software teams to ship code safely, independently, and rapidly. In this role, you will treat the developer platform as a product—building self-service infrastructure abstractions, automated CI/CD capabilities, and guardrails that eliminate operational toil for product developers. What We Are Looking For • 5+ years of hands-on experience in platform engineering, site reliability engineering (SRE), or core DevOps, with a proven track record of designing and delivering Internal Developer Platforms (IDPs). • Expert-level mastery of Kubernetes administration, custom controller/operator architectures, service meshes (Istio/Linkerd), and continuous delivery via GitOps tools (ArgoCD or Flux). • Deep proficiency using Terraform, OpenTofu, or Pulumi to construct modular, reusable infrastructure blueprints across cloud environments (AWS, GCP, or Azure). • Strong programming skills in Go or Python to build custom platform extensions, CLI tools, Kubernetes operators, and API integrations. • Practical experience building or integrating developer portals (e.g., Backstage, Port) and automated workflow engines to abstract infrastructure complexity. • Hands-on experience establishing end-to-end telemetry standards using Prometheus, Grafana, and OpenTelemetry for metric, log, and trace aggregation. Nice-to-Have • Experience with cloud-native control plane abstractions like Crossplane. • Exposure to FinOps practices, container cost monitoring (e.g., Kubecost), and automated resource optimization. • Active contributions to open-source cloud-native projects (CNCF ecosystem). • Strong background in zero-trust security controls, secrets management (HashiCorp Vault), and compliance automation. Responsibilities: • Architect, build, and maintain self-service platform tools and developer portals that enable product teams to independently provision infrastructure, manage environments, and deploy services. • Maintain robust, automated GitOps delivery pipelines using ArgoCD/Flux, establishing safe deployment practices (canary, blue-green, automated rollbacks). • Maintain cluster health, upgrade lifecycles, autoscaling policies, and security policies across multi-region Kubernetes deployments. • Write production-grade Go/Python code to build custom Kubernetes operators, CLI utilities, and API automation to streamline developer workflows. • Establish platform-wide SLI/SLO tracking, implement centralized logging and tracing infrastructure, and enforce automated security and cost-compliance policies across environments.
