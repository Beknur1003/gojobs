Key Responsibilities: - Full Stack Development: Design, develop and maintain scalable web applications across frontend and backend systems using GoLang and React. - Backend Engineering: Build efficient, secure and maintainable backend services, APIs and business logic using GoLang. - Frontend Development: Develop responsive, intuitive and high-performance user interfaces using React, ensuring a seamless user experience. - Cloud Infrastructure: Build, deploy and manage applications on Google Cloud Platform (GCP), following best practices for scalability, reliability and security. - API Development and Integration: Design and integrate RESTful APIs and services to enable seamless communication between frontend applications and backend systems. - Database and Performance Optimisation: Work with databases, optimise queries and improve application performance, reliability and response times. - System Design and Architecture: Contribute to technical design decisions and build maintainable systems that can scale with evolving business and product requirements. - Code Quality and Testing: Write clean, reusable and well-documented code; conduct code reviews; and implement appropriate testing practices to maintain software quality. - Security and Reliability: Follow secure coding practices and help ensure application data, services and infrastructure remain reliable and protected. - Cross-Functional Collaboration: Work closely with product, design and other engineering team members to understand requirements, solve technical challenges and deliver product improvements. Good to Have: - Experience working in fintech, financial services, investment platforms or other product-led technology companies. - Familiarity with microservices architecture and distributed systems. - Experience with Docker, Kubernetes and CI/CD pipelines. - Understanding of cloud security, observability and application scalability. - Experience working in agile development environments.
