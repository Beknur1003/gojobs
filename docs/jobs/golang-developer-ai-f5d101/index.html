Job Description Backend Developer – Go / Golang Role Overview We are looking for a Backend Developer with 5–10years of software development experience and strong expertise in Go (Golang) to build scalable backend services, APIs, and distributed workflows. The role involves working with cloud-native data platforms, workflow orchestration, search, caching, and real-time systems within a production SaaS environment. Key Responsibilities • Design, develop, and maintain backend services and microservices using Go, including APIs, service contracts, and inter-service communication. • Build scalable data-driven services using GCP Firestore, MongoDB Atlas, Elastic Cloud, and appropriate data-access patterns. • Develop resilient distributed workflows and background processing using Temporal. • Implement caching and high-performance data-access patterns using Redis and Valkey. • Integrate backend services with Centrifugo, APIs, and other distributed-system components where required. • Build automated unit, integration, and API tests, and contribute to reliability, observability, security, and production troubleshooting. • Use AI development tools such as Cursor, Claude, GitHub Copilot, or equivalent to accelerate development, testing, debugging, code review, and technical problem-solving. Required Qualifications • 5–8 years of software development experience, with strong hands-on expertise in Go (Golang). • Hands-on experience developing AI-enabled capabilities or integrating AI/ML models, LLMs, or AI services into production products. • Strong knowledge of Go concepts including concurrency, goroutines, channels, interfaces, context handling, and idiomatic Go development. • Experience building REST APIs, microservices, and distributed systems, including error handling, retries, idempotency, timeouts, and asynchronous processing. • Experience working with NoSQL databases and distributed data stores; exposure to technologies such as Firestore or MongoDB is preferred. • Experience with automated testing, Git-based development, CI/CD, observability, API security, and production troubleshooting. • Practical experience using AI-assisted development tools such as Cursor, Claude, GitHub Copilot, or similar tools in day-to-day engineering workflows. Good to Have • Hands-on experience with GCP Firestore, MongoDB Atlas, Elastic Cloud/Elasticsearch, Redis, or Valkey. • Experience with Temporal or similar workflow orchestration platforms. • Experience with Centrifugo, WebSockets, gRPC, Protocol Buffers, or OpenAPI/Swagger. • Experience modernizing or integrating with legacy Python services, particularly environments transitioning away from Python 2.7. • • Experience working with large-scale SaaS or cloud-native distributed systems. Success in This Role A successful developer will build reliable, scalable, and well-tested backend services, make sound decisions across databases, workflows, caching, and distributed systems, effectively use AI-assisted engineering tools, and take ownership of solutions from design through production.
