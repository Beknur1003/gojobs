Your Role and Responsibilities At HashiCorp, an IBM Company, we’re on a mission to enable organizations to provision, secure, connect, and run infrastructure for any application. Our Security Engineering team helps protect the cloud environments and services that support that mission. We are looking for a senior Cloud Security Engineer with a strong software and infrastructure engineering background to design and build scalable security capabilities across our cloud environments. This role goes beyond identifying security issues: you will engineer preventative controls, automated guardrails, and secure-by-default patterns that enable engineering teams to move quickly while managing cloud risk. Responsibilities • Lead the design and implementation of cloud security architecture and engineering solutions across AWS, Azure, GCP, and other cloud environments. • Architect and build production-quality security tooling and automation using Go/Golang and Python, integrating security directly into infrastructure and engineering workflows. • Design preventative security controls and automated guardrails using Terraform and Infrastructure as Code (IaC), enabling secure-by-default cloud deployments. • Establish scalable security patterns across IAM, cloud networking, workload identity, containers/Kubernetes, secrets management, PKI, and workload protection. • Design and integrate security controls into CI/CD pipelines, infrastructure provisioning, and developer workflows, shifting security earlier into the engineering lifecycle. • Provide technical leadership for complex cloud security initiatives, independently driving solutions from architecture and design through implementation and operationalization. • Identify systemic cloud security risks and translate them into reusable engineering patterns, automation, detections, and preventative controls rather than relying solely on manual remediation. • Partner with platform, infrastructure, product, and security engineering teams to conduct architecture reviews and influence the design of secure cloud services. • Improve CSPM/CNAPP, vulnerability management, detection, and cloud security monitoring capabilities and translate findings into engineering improvements. • Research emerging cloud attack techniques and technologies and apply those insights to evolving cloud security architecture. • Mentor engineers and provide technical direction on cloud security engineering, automation, and secure infrastructure design. Strong software engineering background, ideally in infrastructure, platform, cloud, or security engineering, with experience designing and operating production systems and building automation or tooling using Go/Golang or Python. Deep hands-on cloud security experience with AWS and/or Azure, including IAM, networking, compute/workloads, containers/Kubernetes, and cloud-native security controls. Strong Infrastructure as Code experience, preferably Terraform, designing reusable, secure infrastructure patterns and automated preventative security controls. Experience integrating security into CI/CD and engineering workflows, including Linux environments and automated security guardrails that enable secure-by-default deployments. Ability to lead complex cloud security initiatives across multiple engineering teams, effectively communicating architecture, security risks, and technical trade-offs to engineering and security stakeholders. Experience designing workload identity, OIDC federation, PKI, secrets management, and short-lived credential architectures. Experience building internal developer platforms, self-service infrastructure, paved roads, or automated security guardrails. Experience with Cloud Security Posture Management (CSPM) or CNAPP platforms, cloud vulnerability management, and security detection tooling; experience with Wiz is a plus. Experience architecting and securing infrastructure across AWS, Azure, and GCP, including developing consistent controls across multiple cloud providers. Experience with policy-as-code and preventative security controls integrated into Terraform and CI/CD workflows. Experience designing or operating security controls for Kubernetes and containerized workloads. Knowledge of Zero Trust architecture, cloud governance, and modern identity security principles. Understanding of compliance frameworks such as SOC 2, ISO 27001, and FedRAMP.
