Job Summary Managed File Transfer engineer with deep understanding of Managed File Transfer protocols and experienced with the MFT solution of the Axway suite. Key Responsibilities ou will work on a new solution for the external file transfer service, migrate the consumers and maintain the infrastructure. Infrastructure as Code: Develop and manage infrastructure as code DevOps Integration: Collaborate with DevOps teams to ensure smooth CI/CD pipelines and efficient application deployment. DevSecOps Security: Implement (automate) and maintain robust security measures to protect our platforms from vulnerabilities and cyber threats. Risk Assessment: Identify potential risks and vulnerabilities in platform architecture and work on risk mitigation strategies. Monitoring and Optimization: Continuously monitor platform performance, identify bottlenecks, and implement optimizations for improved efficiency. Alerting and Incident Response: Set up proactive alerting systems and develop incident response procedures to ensure platform reliability and availability. You have great problem-solving and troubleshooting skills. You are a strong communicator and like to collaborate with others.
