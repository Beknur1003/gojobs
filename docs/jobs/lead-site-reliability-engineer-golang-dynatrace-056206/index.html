Job Title: Lead Site Reliability Engineer (SRE, Golang, GCP & Dynatrace) Experience Required: 6+ Years in IT (Minimum 4+ Years dedicated to Systems/Software Development & Site Reliability Engineering) Location: Chennai - Hybrid Notice Period: Immediate to 15 - 30 Days Max Education Required: Bachelor's Degree in Computer Science, Information Technology, Systems Engineering, or related technical discipline Job Summary: We are seeking an execution-focused Lead Site Reliability Engineer (Engineer 3) to take technical ownership of system availability, platform reliability, and infrastructure performance across multi-tier cloud environments. In this role, you will apply a software engineering mindset to infrastructure operations - writing production-grade code to automate manual tasks, building internal SRE monitoring backends, and driving proactive issue detection across large-scale distributed systems. The ideal candidate brings 6+ years of IT experience with deep software craftsmanship in Golang and cloud-native architecture on Google Cloud Platform (GCP). You combine full-stack observability instrumentation (Dynatrace, OpenTelemetry, PostgreSQL) with Infrastructure as Code (Terraform), robust on-call incident response leadership, chaos/blameless postmortem analysis, and automated self-healing mechanisms to scale systems sustainably. Key Responsibilities: - SRE Tooling & Backend Development: Design, code, test, and maintain internal SRE platforms and monitoring service backends using Golang, PostgreSQL, and OpenTelemetry. - Observability & Performance Profiling: Instrument, configure, and administer enterprise APM and monitoring tools using Dynatrace and OpenTelemetry; define and monitor Service Level Indicators (SLIs), Objectives (SLOs), and Error Budgets to proactively detect system degradation. - GCP Cloud Infrastructure & Cost Optimization: Architect, scale, and optimize infrastructure on Google Cloud Platform (GCP); analyze compute/storage utilization, optimize resource allocation, and implement architectural cost efficiencies. - Infrastructure as Code (IaC): Provision, govern, and maintain cloud infrastructure declaratively using Terraform; build automated workflows to ensure environment consistency across development, testing, and production tiers. - Incident Leadership & Postmortems: Participate in on-call engineering rotations; lead root-cause analysis (RCA), debug distributed system bottlenecks, and facilitate blameless postmortems with preventive technical guardrails. - Engineering Standards & Code Reviews: Conduct rigorous peer code reviews for production deployments and automation scripts; set software craftsmanship standards across platform and application development teams. - Disaster Recovery & Security Hardening: Author comprehensive architectural designs, operational runbooks, and disaster recovery automation; maintain security baselines, vulnerability remediations, and audit compliance across cloud workloads. Skills & Qualifications: Required Technical DNA: - Total Experience: 6+ years of professional IT experience with at least 4 years of dedicated hands-on software development and systems reliability engineering. - Core Programming: Strong software engineering proficiency in Golang (Go) following clean code principles, concurrency models, and test-driven development. - Cloud Platform: 3+ years of hands-on architecture and operational experience on Google Cloud Platform (GCP). - Enterprise Observability: Deep practical experience with Dynatrace (agent deployment, service flow tracing, root-cause engine) and OpenTelemetry instrumentation. - Infrastructure as Code & Data Store: Proven hands-on track record using Terraform to provision cloud assets and administering/querying PostgreSQL backends. - Operations & Incident Response: Demonstrated experience leading incident triage, participating in on-call rotations, and authoring technical postmortem remediation plans. - Working familiarity with Kubernetes (GKE), Docker container internals, and service mesh technologies. - Secondary scripting or application development fluency in Python or Bash. - Experience integrating CI/CD pipelines (GitHub Actions, Cloud Build, Jenkins) with automated deployment gates. - GCP Professional Cloud DevOps Engineer or Professional Cloud Architect certification.
