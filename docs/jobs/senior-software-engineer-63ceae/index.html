About NCR VOYIX NCR Voyix Corporation (NYSE: VYX) is a global platform-powered leader in unified commerce for shopping and dining. Combining a flexible, intelligent platform with end-to-end payments capabilities and services developed through its deep industry experience, NCR Voyix empowers retailers and restaurants to accelerate new possibilities for their operations, experiences and business outcomes. NCR Voyix is headquartered in Atlanta, Georgia, and serves customers in more than 35 countries worldwide. Job Summary We are seeking a highly motivated Senior Software Engineer to design, develop, and maintain scalable, high-performance applications across modern retail and POS platforms. The ideal candidate will possess deep expertise in Go backend development, React/TypeScript frontend engineering, distributed microservices architecture, API design, and SQL Server-based data solutions. This role requires strong technical leadership, ownership of software quality and delivery, and the ability to mentor engineers while driving architectural and engineering excellence across business-critical retail systems. Job Responsibilities • Design, develop, and maintain scalable backend services and APIs using Go, following clean architecture principles, dependency injection patterns, and robust error-handling practices. • Build and enhance modern web applications using React and TypeScript, creating reusable UI components and maintainable, testable frontend architectures. • Own API design and lifecycle management, including REST and gRPC services, API versioning, backward compatibility, contract enforcement, and integration reliability. • Design and implement efficient data access solutions using SQL Server, ensuring optimal query performance, schema integrity, and secure handling of business-critical data. • Lead development efforts for distributed systems, collaborating across frontend, backend, and infrastructure teams to deliver high-quality solutions. • Own build quality and release readiness by maintaining CI/CD pipelines, resolving flaky builds and automated checks, enforcing linting and testing standards, and improving engineering productivity. • Troubleshoot and resolve complex issues across Dockerized microservices environments, tracing failures through application logs, service interactions, infrastructure configurations, and deployment pipelines. • Participate in architecture discussions and technical decision-making to improve system scalability, maintainability, performance, and operational reliability. • Conduct high-quality code reviews, promote engineering best practices, and mentor team members on software design, development standards, and problem-solving techniques. • Break down complex business and technical requirements into well-defined deliverables and guide execution across the development lifecycle. • Collaborate with Product, Quality Engineering, DevOps, and other stakeholders to deliver reliable and secure software solutions. Job Qualifications Required Qualifications • Bachelor's degree in Computer Science, Software Engineering, Information Technology, or a related field. • 7+ years of professional software development experience in enterprise-scale applications. • Strong proficiency in Go (Golang) with experience developing production-grade APIs and backend services. • Extensive experience with React and TypeScript, including component-based architecture, state management, and frontend performance optimization. • Proven experience designing and supporting REST and gRPC APIs, including versioning strategies, backward compatibility, and contract-driven development. • Advanced SQL Server expertise, including query optimization, database schema design, stored procedures, and data access best practices. • Hands-on experience with CI/CD practices and tools, including build automation, test automation, quality gates, and release management. • Experience working with Docker-based microservice architectures and troubleshooting distributed systems. • Strong debugging and problem-solving skills with the ability to analyze issues across multiple system layers. • Demonstrated experience providing technical leadership through architecture reviews, code reviews, mentoring, and engineering best practices. • Excellent communication and collaboration skills with the ability to work effectively across cross-functional teams. Preferred Qualifications • Experience within Retail, POS, Commerce, Payments, Loyalty, Inventory Management, or Order Processing domains. • Knowledge of performance tuning and optimization techniques for highly distributed service architectures. • Experience implementing secure coding practices, including authentication, authorization, secret management, PII protection, and least-privilege access patterns. • Experience modernizing legacy applications into scalable, service-oriented architectures and maintainable microservice boundaries. • Familiarity with cloud-native application development, observability, monitoring, and operational excellence practices.
