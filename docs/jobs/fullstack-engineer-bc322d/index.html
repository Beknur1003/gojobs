# Full-Stack Engineer ## Job Summary We are seeking a Full-Stack Engineer to develop comprehensive product features spanning from client-facing React applications to backend Go services and data layers. This role requires leveraging AI coding tools effectively while taking full ownership of delivered code. The position directly contributes to building a scalable, reliable, and user-friendly investing platform that supports the company’s mission of providing seamless global investment experiences. ## Responsibilities - Build end-to-end product features using **React**, **TypeScript**, and **Go**. - Develop fast, intuitive user interfaces with Tailwind CSS, real-time data handling, and WebSockets. - Design clean APIs using Protobuf and Connect-RPC/gRPC with strongly typed clients across the stack. - Model the financial domain thoughtfully and create robust **PostgreSQL** schemas, transactions, and migrations. - Integrate with broking, payments, and KYC systems, ensuring proper handling of retries, failures, and idempotency. - Build event-driven workflows and systems that maintain reliability at scale. - Write comprehensive tests across the stack and manage features from development through production deployment. - Deploy and operate services on Google Cloud and Kubernetes, actively monitoring the performance and health of shipped code. - Collaborate closely with the founding team to translate evolving product ideas into simple, reliable software solutions. - Work on a **6-day work week** schedule. ## Qualifications - 3–5 years of experience building products, preferably in broking, trading, fintech, or other transaction-heavy systems. - Strong hands-on experience with **React** and **TypeScript**, including expertise in state management, performance optimization, real-time updates, and error handling. - Proficient in **Go** programming language, with production experience in Protobuf and Connect-RPC/gRPC. - Practical understanding of domain-driven design, transactional outbox patterns, and event-driven system architectures. - Strong knowledge of **PostgreSQL**, including transactions, locking mechanisms, migrations, and data modeling. Awareness of financial data representation best practices (e.g., using decimals instead of floats). - Comfortable working across both frontend and backend layers rather than specializing in a single area. - Educational background from IIT or an equivalent institute is preferred. ## Preferred Skills - Experience with AI coding tools integrated into the development workflow. - Familiarity with Tailwind CSS and WebSockets. - Knowledge of cloud infrastructure deployment and operations, specifically Google Cloud and Kubernetes. ## Experience - 3 to 5 years of relevant experience in product development, ideally within fintech, broking, trading, or transaction-heavy environments. ## Environment - Based in Mumbai, India. - Work involves full-stack development with deployment and operations on cloud infrastructure (Google Cloud and Kubernetes). - Collaborative work environment with close interaction with the founding team. - Use of AI coding tools integrated into the development workflow. - 6-day work week schedule.
