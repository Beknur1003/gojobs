You are:   A Backend Application Engineer who enjoys turning complex business and mission needs into dependable enterprise software. You build the services, APIs, business logic, data interactions, and integrations that power federal applications. You may be developing your foundation across back-end engineering or already be ready to independently own services, integrations, and meaningful application workstreams. This capability is intentionally broader than a single programming language. As your experience grows, you may lead application modernization efforts, define service and integration patterns, mentor engineers, and influence architecture and engineering standards across teams. The work: • Design, build, test, and maintain enterprise application services, APIs, business logic, data-access layers, and integrations. • Develop solutions using languages and frameworks appropriate to the problem, including Java, C#, JavaScript/TypeScript, Python, Go, or comparable technologies. • Integrate applications with databases, messaging platforms, external services, legacy systems, cloud services, and enterprise platforms. • Modernize legacy application components and help decompose tightly coupled systems into maintainable services and reusable capabilities. • Write automated unit, integration, and API tests and participate in code reviews, CI/CD, debugging, release support, and production issue resolution. • Apply secure coding, API design, error handling, logging, observability, performance, and data-integrity practices throughout development. • Use AFS-approved AI-assisted engineering tools and workflows to accelerate coding, testing, refactoring, documentation, and analysis while validating outputs. • Partner with Product Managers, Digital Experience Engineers, Quality Engineers, Cloud Platform Engineers, architects, security teams, and client stakeholders. • As your experience grows, lead complex services or application areas, establish technical patterns, mentor engineers, and shape modernization and architecture decisions. Here's what you need: • Professional experience in back-end, application, software, API, or integration engineering, or equivalent practical experience. • Hands-on development experience in at least one modern enterprise language such as Java, C#, JavaScript/TypeScript, Python, Go, or a comparable language. • Experience building or consuming REST APIs, services, business logic, or enterprise application integrations. • Experience with relational or NoSQL databases and common data-access concepts. • Experience leveraging code assist technologies while developing applications (e.g., Gemini Code Assist, GitHub Copilot, Amazon CodeWhisperer, etc.) • Understanding of automated testing, source control, code review, debugging, CI/CD, and Agile software delivery. • For candidates with deeper experience, demonstrated ability to lead complex application work, mentor others, define engineering patterns, and make sound tradeoff decisions across teams. Bonus points if you have: • Bachelor's degree in Computer Science, Engineering, Information Systems, or equivalent practical experience. • Experience with Spring/Spring Boot, .NET, Node.js, FastAPI/Django/Flask, Go frameworks, or comparable application frameworks. • Experience with microservices, event-driven architectures, messaging technologies, API gateways, or enterprise integration patterns. • Experience with AWS, Azure, containers, Kubernetes, serverless technologies, or cloud-native application development. • Experience with application modernization, legacy integration, data migration, performance engineering, or secure software development. • Ability to learn unfamiliar systems, communicate technical issues clearly, and take increasing ownership of services or application workstreams. • Previous federal consulting, government, or mission-oriented delivery experience. Eligibility Requirements: • U.S. Citizenship required. • Ability to work with federal clients and comply with applicable AFS, client, security, and program requirements. • Ability to work in a hybrid, remote, or client-site environment as program needs require.
