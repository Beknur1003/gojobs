ML Engineer - Robotics at PhyAgents At PhyAgents, a machine learning engineer works across the full loop that makes a robot better : data, models, training, simulation, evaluation, and deployment on real hardware. You'll do research-grade work and ship it onto robots in the same quarter. Responsibilities : - Training and post-training : Train and post-train robotic foundation models, including vision-language-action models, using imitation learning and reinforcement learning. - Training infrastructure : Build and scale distributed multi-node GPU training, data loaders, and reproducible pipelines. - Simulation : Build simulation environments and train policies that transfer to real robots. - Rewards and verifiers : Design reward functions and verifiers for task success. - Evaluation : Build harnesses to evaluate model performance in simulation and on real hardware. - Data and data infrastructure : Define data needs and build pipelines to turn raw robot episodes into versioned datasets. - Models on robots : Ensure models run reliably on real hardware and debug failures. Requirements : - 5+ years of hands-on experience training and shipping ML models in production or research. - B. Tech, M. Tech or PhD in Computer Science, Electrical Engineering or a related field. - Track record of owning an ML system end to end. - Deep hands-on experience with PyTorch, including writing and debugging non-trivial training loops. - Experience training at scale : multi-GPU or multi-node training (DDP, FSDP, DeepSpeed, or equivalent). - Strong fundamentals in linear algebra, probability, optimisation, and machine learning. - Strong software engineering habits. Tech Stack : C++, Rust, Golang, TypeScript, Jetson, ONNX, TensorRT About PhyAgents : At PhyAgents, we're building the Claude Code for Physical AI : a robotic foundation model plus an agentic framework for reliable, long-horizon operations in industrial environments. We're starting with high-mix verticals where fixed automation has never worked. We build physical agents : complete robots, delivered as a workforce. Why Explore a Career at PhyAgents : You'll be among the first engineers in the India team of a Silicon Valley deep tech startup. You'll work on the same problems, with the same bar, as our team in San Jose. The India team is a core part of how we build models, data, and infrastructure.
