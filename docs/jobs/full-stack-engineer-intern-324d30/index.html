Tertarik dengan dunia software development dan mau mengembangkan skill coding? Yuk, belajar langsung dan berkembang bareng tim kami! Kualifikasi 1. Pendidikan minimal S1 di bidang Ilmu Komputer, Teknik Informatika, Sistem Informasi, atau bidang terkait. 2. Memiliki pengalaman kerja dan sertifikasi sebagai Full Stack Engineer atau Web Developer minimal 1–3 tahun. 3. Menguasai framework frontend seperti React.js, Vue.js, atau Angular. 4. Mahir di backend dengan bahasa seperti Node.js, Python, Golang, atau lainnya serta memahami pembuatan RESTful API atau GraphQL. 5. Memahami basis data relasional & non-relasional (mis. PostgreSQL, MongoDB). 6. Terbiasa menggunakan Git & workflow kolaboratif (branching, pull request). 7. Mampu menulis kode yang bersih, modular, dan teruji (unit/integration tests). 8. Memahami praktik DevOps dasar (CI/CD, containerization seperti Docker). 9. Memiliki kemampuan analisis dan pemecahan masalah teknis yang baik. 10. Komunikatif dan mampu bekerja secara mandiri maupun dalam tim. Jobdesk 1. Mengembangkan fitur aplikasi web dari sisi frontend menggunakan framework JavaScript modern. 2. Membangun dan memelihara backend service & API yang scalable dan aman. 3. Bekerja sama dengan tim desain, produk, dan QA untuk memastikan aplikasi berfungsi sesuai kebutuhan. 4. Menulis kode yang bersih, terstruktur, dan terdokumentasi baik sesuai standar pengembangan perangkat lunak. 5. Mengoptimalkan performa aplikasi, termasuk load time, responsivitas, dan efisiensi resource. 6. Melakukan integrasi dengan database, layanan pihak ketiga, dan sistem lain sesuai kebutuhan produk. 7. Berpartisipasi dalam proses code review, deployment, dan troubleshooting. 8. Menjaga keamanan aplikasi melalui praktik pengembangan yang baik. 9. Membantu menyusun dokumentasi teknis dan panduan penggunaan fitur.
