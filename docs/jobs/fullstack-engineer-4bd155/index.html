PT Abadi Sejahtera Finansindo (Singa Fintech)• Tangerang, Banten, Indonesia (On-site) We are looking for a Fullstack Engineer to join our IT team and play a key role in designing, developing, and maintaining high-quality web applications across both frontend and backend systems. You will work closely with the engineering team to build scalable solutions, optimize existing applications, solve technical challenges, and ensure applications are properly deployed and functioning. What You’ll Do • Design, develop, and maintain new and existing web applications across frontend and backend. • Write clean, high-quality, scalable, and maintainable code. • Continuously optimize existing applications to improve design, performance, and reliability. • Ensure web applications are properly deployed, implemented, and functioning. • Participate in technical design discussions and code reviews. • Identify technical challenges and propose and implement effective solutions. • Collaborate effectively with team members throughout the development lifecycle. What We’re Looking For • Bachelor’s degree or above in Computer Science, Information Technology, or a related field. • 3+ years of professional experience in the software industry. • Strong understanding of Data Structures, Algorithms, and Computer Science fundamentals. • Hands-on experience with Golang. • Experience with PHP and Laravel. • Strong frontend development experience with: JavaScript, HTML5, CSS3, JSON, React • Good understanding of HTTP, Web Services, and RESTful APIs. • Good knowledge of SQL queries and databases. • Strong communication and interpersonal skills. • Ability to work collaboratively in a team with a positive attitude. • Good command of English. Technical Skills Backend: Golang, PHP, Laravel Frontend: JavaScript, React, HTML5, CSS3, JSON API & Web: HTTP, Web Services, RESTful API Database: SQL Fundamentals: Data Structures, Algorithms, Computer Science Hiring Process 1. HR Screening Call – Background, communication skills, career aspirations, and culture fit. 2. Technical Interview – Deep dive into Data Structures, Golang/Laravel, React, API integration, and SQL. 3. Live Coding / Technical Assessment – Practical problem-solving, code quality, and algorithm assessment. 4. User Interview & Culture Fit – Team alignment, project workflow, and offer discussion. Why Join Us? Join a collaborative IT team where you can work across the full technology stack, solve meaningful technical challenges, and contribute directly to the development and optimization of web applications. Apply now and become part of our growing engineering team!
