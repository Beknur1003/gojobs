Старший Go-разработчик (1С-платформа)

Ozon опубликовано 17 ноября 2026

Go — основной язык Удалёнка Senior
CI/CDBlockchainFinTech
Привет! Это команда инфраструктуры 1С и SQL Server. Мы развиваем инфраструктуру MS SQL, на которой работают критичные для бизнеса сервисы: финансовый учёт, 1С и доставка. В нашей зоне ответственности — петабайты данных, большие OLTP-нагрузки и географически распределенные базы размером в десятки и сотни терабайт. Сейчас мы развиваем автоматизацию инфраструктуры и постепенно переносим её из скриптов и решений в коде SQL и 1С в полноценные сервисы. Ищем Go-разработчика, который будет создавать сервисы и веб-интерфейсы для управления инфраструктурой MS SQL, 1С и интеграцией с другими внутренними системами. В этой роли предстоит с нуля развивать направление разработки внутри команды и самостоятельно отвечать за технические решения. Вы будете • Разрабатывать сервисы и веб-интерфейсы для автоматизации работы с MS SQL и 1С. • Создавать интеграции между внутренними системами и инфраструктурой MS SQL, в том числе с 1С. • Переводить существующую автоматизацию в виде скриптов на полноценные программные решения. • Проектировать и развивать инструменты по управлению MS SQL-инфраструктурой в подходе «MS SQL как сервис». • Самостоятельно принимать технические решения и развивать направление разработки в команде. Примеры задач • Разработать сервис, который связывает внутренние системы с MS SQL и 1С и автоматизирует передачу данных между ними. • Перенести существующую автоматизацию создания и настройки баз данных в 1С/SQL в Go-сервис. • Создать веб-интерфейс для управления типовыми операциями с MS SQL-инфраструктурой. • Автоматизировать копирование баз данных в Staging-окружение через сервис. • Развивать инструменты, которые позволяют заказчику управлять своими базами данных без участия DBA. Нам важно • Опыт коммерческой разработки на Go от 3 лет. • Опыт разработки backend-сервисов и интеграций между системами. • Понимание принципов проектирования API и взаимодействия сервисов. • Опыт работы с реляционными базами данных и SQL. • Опыт разработки сервисов, которые взаимодействуют с инфраструктурными системами. • Умение самостоятельно проектировать решения и доводить их до production. • Понимание принципов CI/CD и опыт работы с GitLab. Будет плюсом • Опыт интеграции Go-сервисов с 1С или другими корпоративными системами. • Опыт работы с MS SQL Server. • Опыт разработки инструментов для автоматизации инфраструктуры. • Опыт работы в роли единственного разработчика в проекте или команде.
