About this role We are looking for a Senior Golang Developer to build and scale low-latency, high-availability backend platforms for our broking products. You will work in an AI-driven development lifecycle (ADLC): AI agents support every stage from spec to production, and engineers stay accountable for correctness, security and compliance. You will work with Product, Engineering, Risk and Business teams. Key responsibilities Platform engineering • Build low-latency, high-throughput Go microservices for: • Order placement and execution • OMS/RMS • Market data • Portfolio and positions • Margin • Onboarding/KYC • Build REST, gRPC, WebSocket and event-driven services on Kafka or RabbitMQ. • Integrate with NSE/BSE, CDSL/NSDL, payment gateways and third-party trading and wealth platforms. • Design schemas and tune queries for trade, order and market data. AI-driven development lifecycle • Spec-first: Write clear API contracts (OpenAPI/Protobuf) and acceptance criteria before AI-assisted implementation. • Agentic coding: Use AI agents (for example Claude Code or Copilot) for scaffolding, refactoring, tests and documentation. • Context engineering: Maintain repository context files such as CLAUDE.md or AGENTS.md, plus coding standards and domain glossaries. • Review and ownership: Check all AI-generated code for concurrency, latency, security and financial-correctness issues. You own every line that merges. • AI in CI/CD and operations: Use AI for PR review, scanning, log analysis and incident triage. Production changes still need human approval. • Governance: Follow the company AI policy, SEBI rules and the DPDP Act. Never share PII, KYC data, credentials or trading logic with unapproved tools. Reliability and collaboration • Tune performance for real-time trading loads: profiling, GC and memory, benchmarking. • Run services with full observability, alerting and automated testing. • Take part in architecture discussions, code reviews and incident handling. Key skills Must have • 6+ years of production Go: goroutines, channels, mutexes, context, memory optimisation and concurrency patterns. • Microservices; REST, gRPC and WebSockets. • PostgreSQL and MySQL, Redis, and Kafka or RabbitMQ. • Docker, Kubernetes, CI/CD, Git, Linux and shell scripting. • Daily use of AI coding assistants or agents in professional work, with measurable gains in quality and speed. • Ability to critically review AI-generated Go code, especially concurrency and performance paths. Good to have • Experience building AI developer tools, such as MCP servers or custom agent skills. • AI-assisted testing: fuzzing and mutation testing in Go. • OpenTelemetry, Prometheus and Grafana. • FIX or exchange APIs, and Indian capital markets regulation.
