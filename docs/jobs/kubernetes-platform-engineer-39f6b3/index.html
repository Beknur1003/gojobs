Kubernetes Platform Engineer

Wits Innovation Lab Hyderabad, Telangana, India опубликовано 23 ноября 2026

KubernetesDockerTerraformAWSGCPAzurePrometheusGrafanaLinuxCI/CDPython
We are looking for experienced Kubernetes (K8s) Engineers to support and manage enterprise-grade containerized platforms hosted in Data Center environments. The ideal candidate should possess strong hands-on experience in Kubernetes administration, container platforms, and automation using Python, GoLang, and Ansible. The role involves managing highly available production environments, troubleshooting platform issues, automating operational activities, and driving platform reliability. Key Responsibilities:- Kubernetes Administration • Deploy, configure, manage, and support Kubernetes clusters in production environments. • Monitor cluster health, node utilization, pod performance, and resource optimization. • Perform cluster upgrades, patching, backup, and recovery activities. • Troubleshoot issues related to pods, deployments, services, ingress, storage, and networking. • Ensure high availability, scalability, and security of Kubernetes environments. Container Platform Management • Manage containerized workloads using Docker and Kubernetes. • Support CI/CD deployment processes and container lifecycle management. • Implement and maintain Kubernetes namespaces, RBAC, quotas, and policies. • Work closely with development and DevOps teams for application onboarding and support. Automation & Development • Develop automation scripts and tools using Python and GoLang. • Create and maintain Ansible Playbooks for platform configuration and operational automation. • Automate provisioning, monitoring, deployment, patching, and compliance activities. • Contribute to Infrastructure-as-Code (IaC) and platform engineering initiatives. Linux & Infrastructure Management • Administer Linux servers (RHEL, Rocky Linux, CentOS, Ubuntu). • Troubleshoot OS-level issues impacting Kubernetes workloads. • Manage storage, networking, and system performance tuning. • Support data center infrastructure operations and production environments. Monitoring & Incident Management • Handle L2 production incidents and problem management activities. • Perform root cause analysis (RCA) and implement preventive measures. • Monitor infrastructure using tools such as Prometheus, Grafana, ELK, or equivalent. • Participate in 24x7 on-call and critical incident support. Security & Compliance • Implement Kubernetes security best practices. • Manage RBAC, Secrets, Certificates, and Network Policies. • Ensure adherence to security standards, vulnerability remediation, and audit requirements. Required Technical Skills Mandatory Skills • Kubernetes Administration (K8s) • Docker / Container Technologies • Linux Administration (RHEL/CentOS/Ubuntu) • Python Development/Scripting • GoLang Programming • Ansible Automation • Kubernetes Networking and Storage Concepts • Production Support & Troubleshooting Preferred Skills • OpenShift Administration • Helm Charts • ArgoCD / GitOps • Jenkins / CI-CD Pipelines • Prometheus, Grafana, ELK • Git & Version Control • Terraform Exposure • Cloud Platforms (OpenStack, AWS, Azure, GCP) Experience & Qualifications • Bachelor's degree in Computer Science, Information Technology, Engineering, or related field. • Minimum 5 years of experience in Infrastructure, Container Platform, or Kubernetes Administration. • Hands-on experience managing enterprise Kubernetes production environments. • Strong programming/scripting experience in Python and GoLang. • Experience developing Ansible automation solutions. • Experience supporting mission-critical and high-availability environments. Preferred Certifications • Certified Kubernetes Administrator (CKA) • Certified Kubernetes Application Developer (CKAD) • Red Hat OpenShift Certification • RHCSA / RHCE • Docker Certified Associate • Ansible Automation Certification Key Competencies • Strong troubleshooting and analytical skills. • Knowledge of SRE and DevOps practices. • Excellent communication and stakeholder management skills. • Ability to handle production-critical incidents under pressure. • Strong focus on automation, reliability, and operational excellence. Hiring Requirement Summary Data Center L2 Engineer – Kubernetes Platform Engineer Openings:- 2 Experience:- 5+ Years Location:- Hyderabad Mandatory Skills Kubernetes, Python, GoLang, Ansible, Linux Preferred Skills OpenShift, Helm, Terraform, CI/CD, Monitoring Tools Environment Enterprise Data Center / Container Platform Support Model 24x7 Production Support Ideal Candidate Profile: A Kubernetes Platform Engineer with strong production support experience, hands-on Kubernetes cluster administration skills, and automation expertise using Python, GoLang, and Ansible, capable of managing and optimizing large-scale enterprise container platforms.
