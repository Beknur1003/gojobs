Quality Assurance Automation Engineer

Job Description • Develop detailed test plans and test cases. • Identify, document, and track bugs or errors using project management tools. • Design, build, and implement automation testing frameworks from scratch for Web, Mobile, and API platforms. • Lead and foster an automation culture within the team by providing training, documentation, and standardizing QA processes. • Develop a hybrid testing strategy that combines manual testing and automation to ensure efficiency and faster product releases. • Integrate automated test scripts into CI/CD pipelines to support continuous testing. • Work closely with development teams (Golang, Nuxt.js/Vue.js, Swift, Kotlin) to identify critical areas that require automation and analyze the root causes of bugs. Job Qualifications • Bachelor’s Degree in Information Technology • 3-4 years of experience in Quality Assurance or Software Testing • Strong understanding of SDLC (Software Development Life Cycle) and STLC (Software Testing Life Cycle). • Proficiency in manual testing techniques and Agile/Scrum methodologies. • Ability to write basic database queries (SQL) for data validation. • Experience in building automation frameworks from scratch for Web platforms, preferably using JavaScript-based tools; Playwright or Cypress to align with the Nuxt/Vue ecosystem. • Experience in Mobile automation (such as Appium for testing Swift/iOS and Kotlin/Android applications) and API test automation (using Postman, RestAssured, or similar tools). • Advanced proficiency in JavaScript, along with a basic understanding of Golang, Swift, or Kotlin code to facilitate code reviews and testing processes. • Experience with CI/CD tools (such as GitHub Actions, GitLab CI, or Jenkins). • Strong understanding of source code management using Git and the implementation of design patterns in test automation (such as the Page Object Model). • Ability to take ownership of features/modules and collaborate with cross-functional teams • Good Analytical, Critical, and Problem Solving Skills
