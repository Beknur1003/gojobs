Summary: We are seeking a seasoned Sr. Developer / SRE / DevOps Engineer to join our team. The successful candidate will bring a strong foundation in backend software engineering, site reliability engineering (SRE), and modern CI/CD automation. You should be proficient in at least one modern language (such as Java, Python, or Golang), possess solid problem-solving skills, and have experience running resilient production systems. Because our project work moves dynamically, this role requires technical versatility, adaptability, and high attention to detail. Responsibilities: - Design, develop, and maintain resilient backend services and technical components aligned with business goals. - Write clean, maintainable code in at least one modern programming language (Java, Python, or Golang). - Build, optimize, and maintain CI/CD pipelines (e.g., LightSpeed, Harness, Tekton, Jenkins) and containerized deployments (Docker/Podman, Kubernetes/OpenShift). - Implement observability and monitoring solutions (e.g., Grafana, Prometheus, Splunk/Loki) to track system health, metrics, and logs. - Troubleshoot, diagnose, and resolve complex technical issues and production incidents with systematic root-cause analysis. - Apply practical knowledge of Linux/CLI, networking fundamentals, REST APIs, and database technologies. - Drive engineering quality through code reviews, technical design reviews, automated testing, and reliability best practices. - Collaborate across cross-functional teams and provide technical guidance/mentorship to junior team members. Qualifications: - Proven experience as a Senior Software Engineer, SRE, DevOps Engineer, or in a similar hybrid role. - Strong proficiency in object-oriented/functional programming and technical design using Java, Python, or Golang. - Hands-on experience with modern CI/CD tooling (e.g., Tekton, Harness, Jenkins, uDeploy) and container platforms (Kubernetes, OpenShift, Docker). - Experience with application monitoring, logging, and observability tools (e.g., Prometheus, Grafana, Splunk, OpenTelemetry). - Solid understanding of Linux environments, shell scripting, networking concepts (HTTP, TCP/IP, DNS), REST APIs, and relational/NoSQL databases. - Strong analytical and debugging skills with the ability to troubleshoot and resolve issues in production environments. - Excellent communication and collaboration skills with a proactive, problem-solving mindset. - Ability to thrive and adapt in a fast-paced agile environment with evolving project requirements.
