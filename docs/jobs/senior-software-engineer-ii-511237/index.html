Senior Software Engineer II

Axway Software SA Scottsdale, AZ, US опубликовано 19 октября 2026

Senior

Overview Axway, Inc. seeks Senior Software Engineer II in Scottsdale, AZ Job Description: Responsible for end-to-end software development lifecycle, including design, effort estimation, coding, testing, and deployment of scalable and maintainable solutions in R&D. Deliver high-quality software solutions with a focus on reusability, scalability, maintainability, and security. Develop software solutions with a strong focus on reusability, ensuring that existing code components can be efficiently leveraged across multiple projects. Design and implement systems with scalability in mind to support growing workloads and evolving business needs. Prioritize maintainability by writing clean, well-documented code that allows for easy updates and modifications over time. Uphold high standards of security, integrating best practices to protect software against unauthorized access and potential threats. Provide estimates of workload required to complete specified tasks and plans work accordingly. Carry out development tasks according to project plans and timelines outlined by various stakeholders. Participate in final qualification of deliverables, and documentation of software releases. Analyze and fix assigned software defects reported both internally and externally. Check quality of production system through systematic unit, integration and end-to-end testing, Collaborate and communicate with product owners/managers, architects, user experience designers, members of other scrum teams to meet shared objectives. Participate in all scrum activities such as grooming, planning, retrospective, and sprint reviews. Position allows for partial remote work. Must live within reasonable commuting distance. Reports to company office in Scottsdale, AZ. Job Requirements: Requires a Bachelor’s degree in Computer Science, Software Engineering, or related and 3 years of related experience, including some experience in each of the following skills: Designing and building multi-tenant SaaS products with scalability, security and reliability; Developing distributed, low-latency server-side applications using Java and Golang; Designing RESTful APIs, microservices, and service-to service communication patterns; Database schema design, query optimization, transaction management, data modeling, and Object-Relational Mapping frameworks for enterprise-scale applications; Building applications utilizing multi-threading, synchronization mechanisms, and performance optimization techniques; Deploying and managing containerized workloads, including orchestration and scaling, using Docker, Kubernetes, and Helm; and Implementing automated build, testing and deployment pipelines using Github, Gitlab, or Jenkins. EOE. To apply, email resume to Candace Kappelman, ckappelman@axway.com referencing Req. # 316.
