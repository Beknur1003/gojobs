En Horizonte nos encontramos en la búsqueda de un Cloud Engineer senior y apasionado por la innovación técnica para sumarse a proyectos de ingeniería de software a escala empresarial. El perfil seleccionado será responsable de diseñar, desarrollar y desplegar microservicios de alto rendimiento, orquestar arquitecturas distribuidas orientadas a eventos y construir soluciones de última generación que integran servicios nativos de AWS y frameworks de agentes de Inteligencia Artificial (LangGraph / AI Agents). Principales responsabilidades • Diseñar, construir y optimizar microservicios robustos utilizando (8, 11, 17) y Spring Boot. • Desarrollar componentes backend de alto rendimiento y concurrencia utilizando Golang. • Implementar arquitecturas orientadas a eventos (event-driven), APIs RESTful y sistemas distribuidos tolerantes a fallos. • Diseñar y desplegar soluciones cloud-native sobre AWS, aprovechando arquitecturas serverless y servicios gestionados AWS Lambda, DynamoDB, AWS AppSync, Amazon Lex y AWS AgentCore. • Integrar y orquestar flujos de agentes inteligentes mediante LangGraph u otros frameworks de orquestación de AI Agents. • Diseñar, consultar y optimizar bases de datos relacionales en Oracle Database, aplicando técnicas avanzadas de SQL optimization y tuning. • Gestionar contenedores y despliegues con Docker y Kubernetes / OpenShift. • Asegurar la integración y entrega continua (CI/CD) mediante repositorios y pipelines automatizados en Git. Requisitos del perfil • Experiencia: Mínimo 5 años de experiencia comprobable en desarrollo backend enterprise y soluciones en la nube. • Backend Core: Dominio sólido de Java 8 / 11 / 17 y framework Spring Boot. • Lenguaje secundario indispensable: Experiencia práctica demostrable en desarrollo con Golang. • Arquitectura de Software: Experiencia sólida en diseño de REST APIs, arquitecturas distribuidas y arquitecturas orientadas a eventos Event-Driven Architecture. • Nube AWS Hands-on Experiencia directa implementando y operando: • AWS Lambda • DynamoDB • AWS AppSync • Amazon Lex • AWS AgentCore • Inteligencia Artificial aplicada: Experiencia práctica integrando LangGraph o cualquier framework de orquestación de agentes de IA • Contenedores y DevOps: Manejo de Docker, plataformas de orquestación Kubernetes u OpenShift, pipelines de CI/CD y control de versiones con Git. • Bases de Datos: Sólidos conocimientos en Oracle Database y optimización avanzada de consultas SQL • Idiomas: Inglés conversacional. Ofrecemos • Sueldo competitivo: 100% nómina abierto a pretensiones económicas según perfil y experiencia técnica. • Prestaciones de ley superiores: • Seguro de Gastos Médicos Mayores familiar • Vales de despensa • Seguro de vida • Aguinaldo de 30 días • Pago correspondiente de PTU. • Esquema de trabajo híbrido de lunes a viernes de 9:00 am a 6:00 pm • Ubicación: cualquiera de las sedes en CDMX, Guadalajara, Monterrey o Querétaro.
