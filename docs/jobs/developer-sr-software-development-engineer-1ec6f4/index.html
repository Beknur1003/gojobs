Join our Team About this opportunity Ericsson Enterprise Wireless Solutions, Inc. seeks a Developer (Senior Software Development Engineer) in Boise, ID, or various unanticipated worksites throughout the U.S., responsible for designing and developing SaaS applications for private 5G networks; building event-driven microservices in Golang using GCP Pub/Sub; architecting highly available and scalable cloud-based backend services; developing RESTful APIs; and integrating monitoring, analytics, and messaging platforms across multi-cloud environments. What you will do: Design and develop SaaS applications using event-driven microservices architectures for private 5G networks. Build microservices and applications in Golang using GCP Pub/Sub to enable real-time communication across network components and services. Program in Python and Golang for scalable application development. Architect highly available, horizontally scalable backend services with a strong focus on security for public cloud SaaS applications. Integrate Prometheus with GCP Pub/Sub to stream metrics from private 5G network devices and applications for real-time monitoring, alerting, and performance analysis. Use PostgreSQL for event sourcing and analytics, persisting event logs, metadata, and state changes. Work with relational, NoSQL, and time-series databases, including Postgres, Cassandra, Hadoop, Elastic, and DynamoDB. Design RESTful APIs using modern frameworks. Scale backend services with Redis and Memcached. Operate in multi-cloud environments including GCP and AWS. Configure log streaming with Fluent Bit and alert and notification services using Alertmanager. Scope, estimate, and document development tasks and create JIRA tickets. Develop unit tests and integrate them into CI/CD pipelines. Diagnose and resolve complex customer issues with strong ownership and accountability. Contribute to an agile software development lifecycle and collaborate with cross-functional engineering teams to deliver end-to-end solutions. Worksite: 1100 W. Idaho Street Suite 800 Boise, ID 83702, or various unanticipated worksites across the U.S. You will bring: Master's degree or foreign equivalent in Computer Science, Data Engineering, or a related field and 7 years of experience in distributed system architecture. 7 years of experience to include: • Using Python or Go for data-intensive applications; • Building microservices and data APIs using Spring Boot or FastAPI; • Containerization and orchestration using Docker, Kubernetes, and Helm; • Version control, unit testing, and code quality practices; • CI/CD pipelines using either GitLab CI and Jenkins or ArgoCD. 5 years of experience to include: • Designing end-to-end architectures; • Defining data ingestion frameworks; • Migrating cloud-native platforms using Azure, AWS, or GCP; • Telemetry design; • Distributed data processing using Apache Spark, Flink, Kafka Streams, or Beam; • Real-time and batch data pipeline design including ingestion, transformation, storage, and analytics; • Data lakehouse or streaming architectures using Delta Lake, Hudi, Iceberg, or Kafka Connect; • NoSQL and distributed storage using Cassandra, HBase, Elasticsearch, or ClickHouse; • Infrastructure-as-code tools using Terraform or Ansible. “#LI-DNI” Why Join Ericsson?
