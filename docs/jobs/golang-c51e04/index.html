Golang 後端工程師(大安)

天晴資訊有限公司 Daan District, Taipei City, Taiwan опубликовано 19 октября 2026

Go — основной язык
MySQLRedisKafkaRabbitMQElasticsearchDockerAWSLinuxCI/CDReact
【職務內容】 使用 Golang 開發與維護後端服務與系統。 設計與實作 API 架構、資料處理流程與模組化後端框架。 規劃與實作後端系統架構，提升系統擴充性、穩定性與可維護性。 撰寫技術文件與單元測試，維持良好的程式碼品質與可讀性。 處理高併發場景與效能優化，確保系統穩定運行。 配合運維團隊，參與 CI/CD 流程與後端部署，確保服務穩定交付。 與前端、平台及其他跨部門團隊協作，完成系統整合與功能落地。 【職務要求】 具備後端服務開發經驗，且有 Golang 實務開發經驗。 熟悉關聯式資料庫（如 MySQL 等，具備基礎 SQL 撰寫與設計觀念）。 熟悉 Git 版本控制。 具備獨立開發、問題分析與解決能力，思維靈活。 具備良好的溝通能力、責任感與團隊合作精神。 【加分條件】 熟悉常見 NoSQL 或搜尋/日誌分析引擎（如 Redis、DynamoDB、OpenSearch / Elasticsearch）。 具備 AWS 雲端服務使用經驗（如 S3、Lambda、CloudWatch 等）。 具備影音串流架構（如 AWS IVS、WebRTC）或即時互動系統相關經驗。 熟悉 Linux 系統操作，具備常見指令使用能力。 熟悉 Docker 等容器化技術。 理解基本 CI/CD 流程，能與運維團隊協作部署。 熟悉 Golang 框架（如 Gin、Beego、Echo 等）。 具備實際上線專案經驗（不限產業）。 具備遊戲後端開發經驗，或曾參與遊戲相關專案。 熟悉遊戲伺服器邏輯、即時系統或狀態同步架構。 理解獎勵與數值系統設計，例如： A. 回饋機率與中獎率設計 B. 獎項資源池控管 C. 條件式觸發與活動邏輯 熟悉高併發系統架構與消息佇列（如 Kafka、RabbitMQ）。 了解前端框架（Vue.js / React.js），能與前端共同規劃 API。
