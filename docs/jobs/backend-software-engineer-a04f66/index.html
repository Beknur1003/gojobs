Department Overview The Vehicle Intelligence division is a core part of Motorola Solutions' Video & Software Enterprise, focused on delivering industry-leading solutions for Automatic License Plate Recognition (ALPR) and vehicle detection. Our platform provides mission-critical analytics and real-time intelligence to law enforcement and commercial customers globally. We are currently evolving our cloud-native ecosystem to support advanced vehicle data analytics and pattern recognition. Our team operates at a massive global scale, building resilient systems that process and store high-throughput data streams to provide actionable insights for public safety. Job Description We are seeking a mid-to-senior level Backend Software Engineer to join our Vehicle Manager Cloud team in Ho Chi Minh City. In this role, you will be a key contributor to our Modern Event Processing Platform, focusing on high-performance data ingestion, horizontal scalability, and cloud-native architecture. You will design and implement services that handle large-scale data processing pipelines and integrate AI-driven insights into our core products. Responsibilities include: • Design and implement high-performance backend microservices within a modern cloud-native architecture. • Directly collaborate with US-based engineering teams on a daily basis, contributing to global product roadmaps and architectural decisions. • Develop cloud-native event processing systems that ensure low-latency data flow and high availability. • Optimize data streaming and ingestion using technologies like Kafka or Azure Event Hubs to process high volumes of real-time events. • Architect high-performance data solutions utilizing Redis for caching and SQL Server or Postgres for relational data management. • Integrate AI-driven services to enhance raw data with advanced attributes and intelligence. • Deploy and manage containerized services using Kubernetes (K8s) and Docker to maintain a stateless and scalable environment. • Leverage AI-assisted engineering tools (such as GitHub Copilot or Cursor) to accelerate development, debugging, and code quality. • Drive engineering excellence through automated testing, high unit test coverage, and participation in technical design and code reviews. Basic Requirements • Bachelor’s Degree/ Master Degree in Computer Science, Software Engineering, or a related technical field. • Minimum of 3 years of professional experience in backend software development. • Primary Tech Stack: Strong proficiency in C# or .NET is highly preferred for immediate integration. Java or Golang experts with strong CS fundamentals who are open to mastering new languages and architectures is preferred. • Familiarity with major cloud providers (AWS, Azure, or GCP). • Experience with SQL Server, Postgres, or other major relational databases is a plus. • Hands-on experience with Docker and Kubernetes (K8s) for container orchestration is a plus • Experience with distributed messaging systems (e.g., Kafka, Event Hubs, or RabbitMQ). • Proficiency in English (written and verbal) for collaboration in a global environment.
