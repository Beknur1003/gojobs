Сейчас мы ищем Senior Golang разработчика в нашу команду. • Разработка backend-сервисов на Go; • Проектирование и развитие микросервисной архитектуры; • Разработка и поддержка REST / gRPC API; • Работа с SQL / NoSQL базами данных, кэшами и брокерами сообщений; • Участие в проектировании отказоустойчивых и масштабируемых решений; • Написание unit-, integration- и e2e-тестов; • Участие в code review, декомпозиции задач и технических обсуждениях; • Работа с контейнеризацией, CI/CD, мониторингом и логированием. • Коммерческий опыт разработки на Go от 5 лет; • Глубокое понимание Go: goroutines, channels, select, sync, race conditions; • Понимание runtime Go, GC, pprof / trace, модели памяти, escape analysis; • Опыт работы с REST и gRPC, будет плюсом опыт со streaming; • Опыт работы с SQL-базами данных, понимание миграций, индексов и оптимизации запросов; • Опыт работы с Redis и/или другими NoSQL-решениями; • Опыт работы с брокерами сообщений: Kafka, RabbitMQ, NATS или аналогами; • Опыт работы с Docker, понимание Kubernetes; • Опыт написания тестов, знание testing, testify, gomock/mockery или аналогов; • Понимание принципов микросервисной архитектуры, отказоустойчивости и масштабирования; • Опыт работы с Git, CI/CD, участие в code review; • Умение работать в команде, проактивность и внимательность к качеству кода.
