軟體暨解決方案研發中心缺額招聘 # About the team We are the Software and Solutions Center, pioneering comprehensive AI and server hardware-software integration solutions. At our center, you'll gain hands-on experience with cutting-edge AI accelerators and advanced software stacks while developing innovative external products and internal tools that drive Gigacomputing's exponential growth. Join our team at the forefront of technological innovation where your expertise will directly shape the future of computing. # About the job and responsibilities (What you’ll be doing) This position is responsible for operating, maintaining, and optimizing the company's internal CI/CD, automated deployment processes, and infrastructure environment. You will assist the team in implementing infrastructure automation with GitOps at the core, ensuring that service deployments are stable, secure, and traceable. Additionally, you will collaborate with development teams to provide consistent development environments (Vagrant / kind) and Infrastructure as Code (IaC) foundations. Key Responsibilities • Cluster Management: Maintain and optimize Kubernetes (K8s) clusters to ensure high availability and observability. • GitOps Implementation: Manage and optimize ArgoCD deployment workflows to implement the GitOps model effectively. • Infrastructure as Code (IaC): Design and maintain IaC architectures, using Ansible and Helm to manage cloud and internal resources. • Environment Consistency: Establish development and testing environments using Vagrant and kind, ensuring consistency between local setups and other environments. • Pipeline Management: Assist in building and maintaining CI/CD Pipelines (e.g., GitHub Actions, GitLab CI, Argo Workflows). • Monitoring & Observability: Monitor system resources, deployment performance, and security by implementing solutions such as Prometheus, Grafana, Loki, and ELK. • Developer Support: Support development teams in troubleshooting deployment issues and optimizing infrastructure. • Documentation:** Develop and maintain automation tools and internal technical documentation. # Minimum qualifications (What we need to see) • Strong familiarity with Kubernetes architecture and operations. • Experience with ArgoCD and a solid understanding of GitOps workflows. • Proficiency with IaC tools (e.g., Terraform, Ansible, Pulumi). • Strong Linux system administration skills and Shell Scripting capabilities. • Knowledge of Docker and container networking. • Hands-on experience implementing CI/CD (GitHub Actions, GitLab CI, Jenkins, Argo Workflows, etc.). • Ability to set up development/test environments using Vagrant, kind, or similar tools. • Proficiency in Git version control and branching strategies (GitOps / trunk-based development). # Preferred qualifications (Ways to stand out from the crowd) • Experience with public cloud platforms (AWS / GCP / Azure). • Familiarity with monitoring and logging ecosystems (Prometheus, Grafana, Loki, ELK). • Experience in SRE(Site Reliability Engineering) or concepts of availability monitoring design. • Familiarity with security automation tools (e.g., Vault, OPA, Kyverno). • Ability to develop automation using Golang, Python, or Bash.
