We are seeking a Full Stack Software Engineer (Golang) to design, develop, enhance and maintain scalable applications and microservices within an enterprise environment. You will primarily work with Golang backend development, relational databases and Kubernetes, while contributing to frontend development using Vue.js. The role involves database design, performance optimization, cloud-native deployments, frontend-backend integration and production troubleshooting while collaborating with cross-functional teams in an Agile environment. Responsibilities • Design, develop and maintain scalable backend applications and microservices using Golang • Develop and maintain frontend application components using Vue.js , ensuring seamless integration with backend services • Design and optimize database schemas, SQL queries and data integrations using PostgreSQL or equivalent relational databases • Implement database migrations and performance improvements to support new and existing application features • Build, deploy and maintain containerized applications using Kubernetes within cloud environments • Support continuous integration and continuous delivery (CI/CD) pipelines to improve software deployment and release processes • Monitor application performance, investigate production issues and perform root-cause analysis • Collaborate with developers, testers and stakeholders within an Agile Scrum environment to deliver reliable software solutions Requirements • Strong hands-on experience developing backend applications and microservices using Golang • Practical experience developing frontend applications using Vue.js or React.js, with knowledge of TypeScript and frontend-backend integration Experience working with PostgreSQL or equivalent relational databases, including SQL optimization, schema design and data migrations • Hands-on experience deploying and maintaining containerized applications using Kubernetes • Practical experience working with at least one major cloud platform, such as Amazon Web Services (AWS), Microsoft Azure or Google Cloud Platform (GCP) • Working knowledge of CI/CD pipelines, automated deployment practices and cloud-native application development • Experience monitoring application performance, troubleshooting production issues and performing root-cause analysis
