Salary: $90,000 - $130,000 Package We're looking for two software engineers, entry- to mid-level, to join an independent Australian consultancy in Canberra. You'll build bespoke software for government and private-sector clients, across both frontend and backend, with real responsibility early and a team behind you. The team works in Golang, Python, Rust and JavaScript, with React on the frontend and SQL and MongoDB for databases. They're also keen to hear from people with AI skills. How much you own depends on your experience, and you can take on more as you grow What's on offer • A salary of $90K to $130K, depending on your skills and experience • Early responsibility, with support, scaled to your experience • Wide latitude to find your own answers, and people to ask when you need a hand • Bespoke software and AI-focused tooling for government and private-sector clients • Exposure across the full stack, from application code down to hardware when things break • A team that shares what it learns and keeps knowledge in version control • Interstate applicants will be considered What you'll be doing • Build and maintain bespoke software across the stack, using Golang, Python, Rust, JavaScript and React • Design for security, maintainability and scalability from the start • Track down the root cause of failures across the stack, from application code to hardware, and fix them • Work with AI and help build AI-focused tooling • Integrate and deploy software in varied enterprise environments, and support clients through delivery • Prototype and build alongside people from other disciplines • Write clean, well-documented code and take part in code reviews • Document systems so the knowledge lives in version control • Keep learning, and share what you find with the team What you'll bring Must-have: • Programming experience in at least one backend and one frontend language (the team uses Golang, Python, Rust, JavaScript and React) • Comfortable with Git and team workflows through pull requests • Some exposure to CI/CD systems (GitLab CI, GitHub Actions, Jenkins or Buildkite) and databases (SQL or MongoDB) • Happy to work with wide latitude, willing to find answers and not afraid to ask for help • Able to explain technical concepts to non-specialists • Pragmatic about quality Desirable: • Skills or interest in AI • Networking and wireless fundamentals • Security fundamentals • Linux fundamentals • Embedded technologies Essential requirement: You must be an Australian citizen and pass pre-employment screening, including a police history check. If you graduated in the last 3 years, please include your academic transcript.
