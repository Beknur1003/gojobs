About the Role: We are looking for a high-ownership SDE-2 (Full-Stack) to build, scale, and own critical features end-to-end - from backend services to rich frontend interfaces. In this role, you will work within a cross-functional product squad alongside product managers, designers, and fellow engineers to power platforms that healthcare organizations depend on daily. You will take feature ownership from initial technical design all the way through deployment and monitoring in production. We are looking for someone who deeply cares about software craft, ships reliably, and thrives in a fast-paced environment. What You'll Do: - End-to-End Delivery: Build backend services in Go (or other strictly typed languages like Java) and frontend user interfaces in Angular, owning the complete feature lifecycle. - Technical Ownership: Take full accountability for feature design, implementation, deployment, monitoring, and debugging in production. - System Design & Architecture: Contribute to API design, data modeling, database schema optimization (MySQL), and microservices architecture. - Code & Engineering Quality: Write clean, testable, well-documented code. Conduct constructive code reviews to maintain high engineering standards. - Collaboration & Innovation: Partner closely with product and design teams to translate product requirements into resilient technical solutions. - Operational Excellence: Improve testing, CI/CD pipelines, cloud deployment workflows (AWS), and observability across systems. - Mentorship: Support junior engineers through code reviews, pairing sessions, and architectural discussions. Must-Have Requirements : - Experience: 3 - 5+ years of professional software development experience in building production systems (Product startup experience strongly preferred). - Primary Tech Stack : 1. Backend: Strong proficiency in Go (Golang preferred) or Java / strictly typed languages. 2. Frontend: Hands-on experience with Angular (or comparable modern frameworks like React/Vue). 3. Databases: Solid understanding of relational databases (MySQL) - including schema design, indexing strategies, and query optimization. 4. Cloud & DevOps: Hands-on experience deploying and operating services on cloud infrastructure (AWS preferred), along with Git and CI/CD pipelines. 5. Core Fundamentals: Strong understanding of system design, API development, unit/integration testing, and software engineering best practices. - Education: B.Tech / B.E. in Computer Science or a related technical field. Good-to-Have Qualifications : - Prior experience in HealthTech or complex, highly regulated domains where reliability and compliance matter. - Familiarity with containerization and orchestration (Docker, Kubernetes). - Experience with observability tools (logging, metrics, and tracing platforms). - Comfort with using AI-assisted coding tools (Cursor, Copilot, Claude) to streamline and accelerate development workflows. Why Join Us? : - Core Product Ownership: Direct responsibility for mission-critical workflows that directly impact healthcare operations. - High Growth Environment: Collaborative culture working with high-caliber talent in a fast-moving product setup. - Employee Benefits: Comprehensive health insurance, mandatory PF, performance incentives, and support for notice period buyouts (evaluated case-by-case).
