Lead Software Engineer - AI Studio

HIGHLEVEL INDIA PRIVATE LIMITED Remote; India опубликовано 4 ноября 2026

Go — основной язык Удалёнка Lead
PostgreSQLPrometheusGrafanaOpenTelemetryMicroservicesReactAI/LLM
About the Role : We're looking for a Lead Software Engineer to join our AI Studio Team, the group responsible for building AI Studio, an AI-based React application builder that generates production-ready websites and other React applications from natural language. As a lead engineer, you will drive the technical direction for our AI-driven application-builder architecture, lead complex system design decisions, and serve as a hands-on technical leader and mentor for the engineers building AI Studio's app generation engine, React website/app builder, design and component systems, domain publishing pipeline, and AI agents. This is a hands-on individual contributor role - you'll spend the majority of your time designing systems and writing production code, while partnering closely with product, infra, and design to shape the roadmap, raise engineering standards, and deliver intuitive, generative, high-performance user experiences at scale. Core Responsibilities : - Own architecture and scaling decisions for core AI Studio platform components. - Lead design and implementation of cross-cutting initiatives to improve system responsiveness, generation accuracy, and platform robustness. - Build scalable, fault-tolerant LLM pipelines for content generation, layout creation, experimentation, and AI-driven user guidance. - Work hands-on with technologies like Go, NestJS, Node, PostgreSQL, Firestore, Vector Databases, Cloudflare Workers, Cloudflare KV, and microservices. - Design distributed systems that handle high-throughput generative and analytical workloads while ensuring correctness and low latency. - Drive improvements in observability using Prometheus/Grafana, OpenTelemetry, and structured logging. - Implement hallucination mitigation strategies and enforce data governance, access control, and privacy boundaries. - Mentor engineers through code reviews, design discussions, and pairing. Requirements : - 6+ years of backend engineering experience, including distributed system design and high-scale platform development. - Strong proficiency in Go (Golang) alongside Node/NestJS experience. - Hands-on experience building and operating edge/serverless services with Cloudflare Workers and Cloudflare KV. - Deep expertise in event-driven architectures, asynchronous workflows, and high-throughput data pipelines. - Strong command of relational (PostgreSQL) and NoSQL data models. - Fluency in LLM integrations, vector search, embeddings, RAG patterns, and generative AI frameworks. - Familiarity with frontend architecture using Vue and a solid understanding of UI/UX principles. - Experience with monitoring, alerting, and incident response for production systems. - Exceptional communication and cross-functional leadership capabilities.
