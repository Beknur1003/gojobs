Compensation: No equity About Ortus Innovation Ortus Innovation Pvt. Ltd. is building DXINT, an indigenous AI-powered intelligence platform designed for complex, real-world data processing and analysis. We are building a high-ownership engineering team focused on production-grade systems. Role Overview We are looking for a self-driven Full-Stack Engineer Intern to work across backend services, frontend applications, multimedia processing, web data extraction, and cloud infrastructure. You will contribute to real engineering workflows using Python, Golang, React, and AWS. This role is suited to freshers and early-career developers who can demonstrate strong fundamentals, practical project experience, and the ability to solve problems independently. Key Responsibilities • Multimedia Processing: Build pipelines for audio, video, images, and PDFs using Python, FFmpeg, OpenCV, and PDF-processing libraries. • OCR and Document Parsing: Extract structured information from scanned documents, images, and other unstructured inputs. • Web Data Extraction: Develop and maintain data ingestion pipelines using Playwright, Puppeteer, Scrapy, or Selenium, respecting applicable access restrictions. • Backend Engineering: Build REST APIs, microservices, and data-processing workflows using Golang, Python, PostgreSQL, Redis, and DuckDB. • Cloud Infrastructure: Work with AWS S3, Lambda, and EC2 for storage, event-driven execution, and compute-intensive workloads. • Frontend Development: Build responsive dashboards and interfaces using React, JavaScript, TypeScript, HTML, and CSS. • Engineering Ownership: Write maintainable code, test thoroughly, debug independently, use Git/GitHub workflows, and deliver assigned features on time. Required Skills • Python and foundational software engineering • Golang fundamentals and concurrency concepts • React.js, JavaScript, HTML, and CSS • SQL and relational databases • Basic AWS knowledge, particularly S3, Lambda, and EC2 • Git and GitHub • Familiarity with OCR, PDF parsing, media processing, or browser automation Candidates need not have professional experience in every technology. Strong fundamentals, demonstrable projects, and the ability to learn independently are essential. Ideal Candidate • 0–1 years of experience; freshers are welcome. • Has built practical projects, contributed to open source, or completed relevant internships. • Takes ownership and follows tasks through to completion. • Can read documentation, debug independently, and work with limited supervision. • Pays close attention to data accuracy, edge cases, reliability, and code quality. • Is comfortable working in a fast-moving startup environment with a six-day work schedule. Work Details • Type: Internship • Duration: 3–6 months • Location: Remote • Schedule: Six days per week • Stipend: To be disclosed • Start: Immediate / rolling Growth and Recognition • Hands-on exposure to production engineering systems and real-world data pipelines. • Direct collaboration with the engineering team. • High-performing interns may be considered for full-time employment after the internship, subject to performance and business requirements. • Certificate of completion and a recommendation letter highlighting demonstrated contributions, subject to successful completion. How to Apply Please share your CV, GitHub profile, LinkedIn profile, and links to relevant projects. Shortlisted candidates may be asked to complete a practical technical assignment and demonstrate their work. We value demonstrated ability, accountability, and execution over credentials alone.
