核心後端工程師 (Core Back-End Developer)

思樞科技有限公司 Xitun District, Taichung City, Taiwan опубликовано 20 октября 2026

Go — основной язык Гибрид
PostgreSQLMySQLRedisMicroservicesCI/CD
Job Description｜工作內容 • Core System Development: Develop and maintain high-concurrency, low-latency backend systems and core service architectures using Golang (Mandatory). 核心系統開發：使用 Golang（必要條件）進行高併發、低延遲的核心後端系統與服務架構設計、開發與維護。 • Architecture Optimization: Design stable, scalable, secure, and high-performance backend solutions, and continuously perform system tuning. 架構優化與設計：設計穩定、可擴充、安全且高效能的後端解決方案，並持續進行系統效能調優。 • Cross-Team Collaboration: Collaborate closely with frontend/UI developers to define clear API specifications and ensure smooth system integration. 前後端協作：與前端/UI 開發人員密切合作，制定清晰的 API 規範，確保系統前後端整合順暢。 • Troubleshooting & Maintenance: Responsible for system troubleshooting, debugging, and performance optimization to ensure 24/7 high availability and stability. 維運與除錯：負責後端系統的問題排除、除錯與效能優化，確保系統 24/7 高可用性與穩定度。 • Deployment & Testing: Support system deployment, automated testing, CI/CD pipelines, and ongoing technical improvements. 部署與測試：支援系統部署、自動化測試、CI/CD 流程及持續的技術架構改善。 Requirements｜必備條件 • 5+ years of experience in backend development with expert proficiency in Golang in production environments. 5 年以上後端開發經驗，且熟練掌握 Golang（具備生產環境實戰經驗）。 • Familiarity with microservices architecture, RESTful APIs, WebSockets, and database performance tuning (MySQL / PostgreSQL / Redis). 熟悉微服務架構、RESTful API、WebSocket 及資料庫（MySQL / PostgreSQL / Redis）效能優化。 • Strong mindsets in OOP/Functional programming, with a high emphasis on code quality and unit testing. 具備物件導向/函數式編程思維，重視程式碼品質與單元測試。
