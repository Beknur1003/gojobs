Role Overview : We are looking for a skilled Golang Software Engineer to join the Google CSRM Automation/SRE team. The engineer will be responsible for developing scalable automation solutions, backend services, and integrations to improve security network operations, infrastructure reliability, and operational efficiency across global sites. Key Responsibilities • Design, develop, and maintain backend services and automation tools using Golang. • Build RESTful APIs and integrate with infrastructure management platforms. • Automate network and server provisioning, configuration, monitoring, and troubleshooting. • Develop integrations with Cisco NSO, NetBox, ServiceNow, and other infrastructure platforms. • Build automated health checks, diagnostics, and remediation workflows. • Support CI/CD pipelines, containerized applications, and cloud-native deployments. • Collaborate with Installation, Sustainment, and SRE teams to identify automation opportunities. • Improve system reliability, observability, and operational performance. Required Technical Skills • Strong hands-on experience with Golang (Go), concurrency, goroutines, and REST APIs. • Experience with Python or Bash scripting. • Good understanding of Linux, networking fundamentals (TCP/IP, DNS, HTTP/HTTPS), and distributed systems. • Experience with Docker, Kubernetes, Git, and CI/CD pipelines. • Familiarity with Google Cloud Platform (GCP), particularly GKE. • Experience with monitoring tools such as Prometheus and Grafana. • Strong debugging, troubleshooting, and problem-solving skills. Preferred Qualifications • Experience with Cisco NSO, NetBox, or network automation platforms. • Knowledge of NETCONF, RESTCONF, gRPC, or gNMI. • Experience developing infrastructure automation and self-healing workflows. • Familiarity with enterprise network and physical security infrastructure. • Experience working in a global SRE or infrastructure operations environment. Expected Outcomes • Reduce manual operational effort through automation. • Improve infrastructure monitoring and incident resolution. • Deliver reusable, scalable automation workflows. • Accelerate network installation, provisioning, and operational handovers. • Improve service reliability across the global CSRM environment.
