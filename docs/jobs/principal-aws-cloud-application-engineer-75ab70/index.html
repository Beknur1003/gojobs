Job Title: Principal AWS Cloud Application Engineer Location: Inner Southern Suburb, Sydney Salary: Level 4 salary + super Work Setup: Full-time | Fully on-site About the Role: This is a senior technical leadership opportunity for an experienced AWS Cloud Application Engineer who enjoys staying hands-on with technology. Qualifications: • 10-20 years of software engineering experience, with significant cloud application experience. • Strong hands-on experience with AWS cloud services and architecture. • Proven experience designing and developing production-grade cloud applications. • Strong software development and programming fundamentals. • Experience with Terraform or comparable Infrastructure-as-Code technologies. • Strong experience with Docker and Kubernetes. • Solid understanding of CI/CD and DevOps practices. • Experience with distributed systems and scalable application architectures. • Previous experience leading, mentoring or technically guiding engineers. • Strong system-design and software architecture capabilities. • Excellent problem-solving and communication skills. • Comfortable being a hands-on technical contributor, rather than moving exclusively into management.
