Software Engineer – Java & Golang Employment Type: 12 Months Contract Work Location: Changi, Singapore Experience: 5–8 years Availablity : Immediate Joiner Preferred Job Description We are looking for an experienced Software Engineer with strong hands-on development experience in both Java and Golang (Go). The successful candidate will work on mission-critical applications and will be responsible for re-architecting and rewriting existing Golang services into clean, performant and maintainable Java solutions. The role requires a strong software engineering foundation, experience working with distributed systems, and the ability to develop reliable and maintainable applications in a production environment. Key Responsibilities • Re-architect and rewrite existing Golang services into idiomatic, clean and maintainable Java. • Design, develop, test and maintain scalable backend applications and services. • Analyse existing Go code, business logic and service dependencies before migration to Java. • Develop robust solutions for distributed and mission-critical systems. • Write clean, readable, testable and well-documented code. • Participate in technical design and architectural discussions. • Troubleshoot application, integration and performance issues. • Apply appropriate design patterns and engineering practices without unnecessary complexity. • Work closely with developers and other technical stakeholders throughout the software development lifecycle. • Ensure application stability, reliability, maintainability and performance. • Use AI-assisted development tools appropriately for repetitive or boilerplate activities while maintaining engineering ownership over core logic and technical decisions. Mandatory Requirements • 4 + years of professional software development experience. • Strong hands-on development experience in Java. • Strong hands-on development experience in Golang / Go. • Experience developing backend services using Spring / Spring Boot. • Experience with microservices and distributed systems. • Good working knowledge of SQL and relational databases. • Experience developing and consuming REST APIs. • Understanding of concurrent programming / multithreading concepts. • Strong debugging, problem-solving and code-quality practices. • Experience supporting reliable, production-grade applications. Good to Have • Apache Kafka or other message-queue technologies. • AWS S3 or other object-storage technologies. • Networking and routing fundamentals. • Angular or other modern frontend technologies. • Cloud and container technologies such as AWS, Docker or Kubernetes. • Experience working on large-scale enterprise or financial-services applications. Preferred Candidate Profile • Strong analytical and problem-solving ability. • Able to understand an existing codebase and translate functionality between programming languages. • Values code readability, maintainability and long-term system stability. • Comfortable working collaboratively with technical teams. • Able to clearly document technical decisions and complex application logic. • Proactive in proposing practical technical solutions when standard approaches are insufficient.
