Golang Data Engineer - ETL/ELT Pipelines

Sedin Technologies Chennai опубликовано 11 июля 2026

We are looking for a skilled Golang Data Engineer to design, build, and maintain high-performance data processing systems and backend services. The ideal candidate should have hands-on experience in Golang, distributed systems, ETL pipelines, and modern data engineering practices. You will work closely with data scientists, analytics teams, and software engineers to build scalable data platforms capable of processing large volumes of structured and unstructured data. Key Responsibilities: - Design, develop, test, deploy, and maintain scalable data engineering applications using Golang. - Build and optimize high-performance ETL/ELT pipelines for processing large-scale datasets. - Develop and maintain RESTful APIs and backend services supporting data platforms and analytics applications. - Design distributed data processing systems with a focus on scalability, reliability, and fault tolerance. - Develop reusable, maintainable, and well-tested code following software engineering best practices. - Implement concurrent data processing solutions using Goroutines and Channels. - Integrate data from multiple internal and external sources while ensuring data quality and consistency. - Work with SQL and NoSQL databases for efficient storage, retrieval, and transformation of data. - Optimize application performance, database queries, and data processing workflows. - Participate in architecture discussions and contribute to the design of scalable data infrastructure. - Collaborate with cross-functional teams including Data Science, Analytics, Product, and Engineering. - Monitor, troubleshoot, and resolve production issues related to data pipelines and backend services. - Ensure data security, governance, and compliance across engineering workflows. - Implement logging, monitoring, and automated testing to improve system reliability. Required Skills: - Strong proficiency in Golang with hands-on backend development experience. - Experience building scalable ETL/ELT pipelines and data processing applications. - Strong knowledge of SQL and relational databases such as PostgreSQL or MySQL. - Experience with NoSQL databases like MongoDB, Cassandra, or Redis. - Understanding of distributed systems, concurrency, and asynchronous programming. - Experience developing RESTful APIs and microservices. - Familiarity with Apache Kafka or other messaging systems. - Experience with Docker and Kubernetes. - Knowledge of Git, CI/CD pipelines, and software development best practices. - Strong problem-solving, debugging, and analytical skills. Preferred Skills: - Experience with Apache Spark, Hadoop, or distributed data processing frameworks. - Exposure to cloud data platforms such as AWS, Azure, or Google Cloud. - Familiarity with data warehousing concepts and big data technologies. - Experience with workflow orchestration tools such as Apache Airflow. - Understanding of data governance, security, and observability practices.
