Job Title: Full Stack API Developer (GoLang) Experience: 6-9 Years Job Description: We are looking for a skilled Full Stack API Developer with strong expertise in GoLang, AWS, API development, and DevOps practices. The ideal candidate will have experience building scalable enterprise applications, developing and managing APIs, and contributing to cloud-native solutions in a fast-paced Agile environment. Key Responsibilities: • Design, develop, and maintain RESTful APIs and backend services using GoLang. • Develop and manage API solutions using Kong API Gateway. • Build, deploy, and support applications on AWS cloud platforms. • Implement and maintain CI/CD pipelines for automated build, test, and deployment processes. • Collaborate with cross-functional teams to deliver scalable and secure enterprise applications. • Troubleshoot production issues, optimize application performance, and ensure system reliability. • Follow DevOps best practices and contribute to improving developer experience and engineering productivity. Required Skills: • Strong hands-on experience with GoLang development. • Experience with AWS services and cloud-native application development. • Expertise in Kong API Gateway and API lifecycle management. • Experience with CI/CD tools and DevOps practices. • Good understanding of Microservices, REST APIs, Containers, and Kubernetes. • Excellent communication, stakeholder management, and analytical skills. • Experience working in Agile/Scrum environments. Nice to Have: • Experience with frontend technologies such as React or Angular. • Exposure to Infrastructure as Code (Terraform/CloudFormation). • Knowledge of monitoring and observability tools.
