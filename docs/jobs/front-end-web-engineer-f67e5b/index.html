Front End Web Engineer

PT Fita Sehat Nusantara Jakarta опубликовано 17 сентября 2026

Офис
GraphQLKubernetesGCPTypeScriptNode.js
Fita is a health-tech platform that aims to plug the preventive healthcare gap in Indonesia with localized content that has been curated by certified fitness trainers & nutritionists. We are looking for a Front End Web Engineer to ensure optimal utilization of website & web application standards best practices and efficient code for development and production. A commitment to collaborative problem solving, sophisticated design, and quality product is essential. In Fita, you possess absolute ownership over the systems in your business scope of control. As we have a very dynamic culture, a creative and analytical individual who is not afraid to speak up, take charge, and be bold would be the next rockstar candidates. Our Tech Stack: • Golang and Typescript for Backend • Kubernetes for Backend • GraphQL for API Gateway in NodeJS and Apollo • Google Cloud Platform in Indonesia region with services BigQuery, Pubsub, GKE, Cloud SQL • Flutter for Mobile Apps Job Description : • Engaged in the full agile development lifecycle; designing, developing, testing, deploying, maintaining, and monitoring fast and user-friendly website & web application • Within a cross-functional team, collaborate with other engineers specializing in backend services, mobile apps, and test automation, as well as product design and ideation • Write clean, efficient, high performance and testable code • Transforming requirement into highly scalable and robust system • Building reusable components and front-end libraries for future use • Transforming designs and wireframes (UI/UX designs) into high-quality code Requirements: • Bachelor degree in Computer Science or related fields, or equivalent professional experience in software development • Preferably 3+ years experience of frontend development, whether in-house, for an agency, or as freelancers • Knowledge and experience with advanced JavaScript libraries and frameworks, such as ReactJS, NextJS, Gatsby, etc • Experience with web accessibility, cross-browser compatibility issues, and frontend performance optimizations • Proficient understanding with unit testing, code reviews, and other quality-oriented practices • Good understanding of layout and basic user interface design principles
