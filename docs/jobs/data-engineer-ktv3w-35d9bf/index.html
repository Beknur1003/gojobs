How You’ll Make an Impact • Collaborate with business stakeholders to gather and analyze requirements for new data initiatives, translating them into actionable technical specifications as well as design data solutions. • Design, develop, and maintain a robust and scalable data lake architecture on a cloud platform. • Develop and implement data ingestion pipelines for various data sources, ensuring data quality, consistency, and reliability. • Design and implement data transformation processes (ETL/ELT) to prepare data for analysis and consumption. • Build and maintain metadata management systems for data discovery and governance. • Implement security and access controls to protect sensitive data within the data lake. • Monitor and optimize the performance of data pipelines and the data lake infrastructure. • Troubleshoot and resolve issues related to data ingestion, processing, and storage. • Stay current with the latest technologies and best practices in data engineering and cloud computing. • Participate in code reviews and ensure adherence to coding standards. What Will Set You Up for Success • Bachelor’s degree in Computer Science, Engineering, Data Science, Information Technology, or related field. • 5+ years of experience as a Data Engineer or related field, with a proven track record of building and maintaining large-scale data platforms. • Extensive experience with cloud-based data warehousing and data lake solutions (AWS, Google Cloud, Azure). • Proficiency in at least one programming language (e.g., Python, Golang, Java, or Scala). • Familiarity with SQL and database systems. • Basic understanding of data processing frameworks (e.g., Spark, Hadoop) is a plus. • Strong understanding of data modeling, data warehousing principles, and data governance. • Strong analytical and problem-solving skills. • Excellent communication and collaboration skills. • Relevant certification is a plus (e.g., Google Cloud Certified Professional Data Engineer).
