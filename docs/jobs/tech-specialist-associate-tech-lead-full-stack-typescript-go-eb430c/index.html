JOB ID:QT-SUL-07-422 Job Summary We are looking for an experienced Tech Specialist / Associate Tech Lead with strong expertise in TypeScript, Angular, Go, and AWS serverless technologies to own end-to-end solution development for SaaS integration platforms. The role involves architecture, hands-on development, event-driven integrations, cloud infrastructure, observability, security, and technical leadership. Key Responsibilities • Own end-to-end solution architecture and hands-on development using TypeScript and Go. • Design robust REST APIs, webhooks, error handling, retry mechanisms, and integration workflows. • Develop and maintain Angular-based UI components for integration configuration, connection status, and data-flow visualization. • Build serverless integration pipelines using AWS Lambda, EventBridge, SQS, and CDK. • Implement asynchronous and event-driven architectures with reliable webhook ingestion and failure recovery. • Design solutions for resiliency, scalability, fault tolerance, and graceful degradation. • Implement structured logging, distributed tracing, and monitoring using OpenTelemetry and Datadog. • Contribute to dashboards and KPIs that provide visibility into integration health and system performance. • Apply tenant isolation, GDPR data minimization, secure encryption, and SOC 2-aligned practices. • Write clean, efficient, maintainable, testable code and conduct peer code reviews. • Create and maintain technical documentation, Architecture Decision Records (ADRs), and engineering standards. • Participate in Agile ceremonies including sprint planning, backlog grooming, daily stand-ups, and retrospectives. • Collaborate with developers, DevOps, product owners, architects, and business stakeholders. • Drive technical excellence through performance optimization, secure coding, automation, and continuous improvement. • Mentor team members and provide technical guidance on design and implementation decisions. Must-Have Skills • 8+ years of software engineering experience, preferably in a SaaS environment. • Strong hands-on expertise in TypeScript for backend and frontend development. • Strong experience with Angular and modern frontend development. • Practical experience with AWS, especially: • AWS Lambda • EventBridge • SQS • AWS CDK • Strong understanding of REST APIs, webhooks, asynchronous processing, and event-driven architecture. • Experience implementing API resiliency, retry logic, error handling, and failure recovery. • Good understanding of observability, structured logging, distributed tracing, and monitoring. • Strong software engineering fundamentals including design patterns, testing, code quality, and maintainability. • Excellent communication and collaboration skills. Good-to-Have Skills • Hands-on experience with Go/Golang backend development. • Experience integrating with CRM platforms such as Salesforce, Microsoft Dynamics, HubSpot, or similar. • Experience with OpenTelemetry and Datadog. • Knowledge of GDPR, SOC 2, encryption, data privacy, and tenant isolation. • Experience developing, publishing, or consuming SDK packages. • Experience with Infrastructure as Code and cloud-native architectures. • Experience working with CI/CD pipelines and DevOps practices. Leadership & Collaboration • Lead technical discussions and contribute to architecture and design decisions. • Review code and ensure adherence to engineering standards. • Support sprint planning, estimation, backlog refinement, and delivery tracking. • Identify technical risks, dependencies, and scalability concerns early. • Act as a bridge between engineering, DevOps, product, and business teams. • Promote best practices around security, performance, testing, observability, and maintainability.
