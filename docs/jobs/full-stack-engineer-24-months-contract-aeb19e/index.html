Full-Stack Engineer (24 Months Contract)

User Experience Researchers Pte.Ltd Singapore опубликовано 1 ноября 2026

Senior Контракт / B2BПолная занятость
KubernetesDockerTerraformAWSCI/CDKotlinTypeScript
Role Overview We are looking for Full Stack Engineers to modernise a Singapore public sector digital service. The team will migrate a legacy tech stack to a modern, cloud-native, containerised platform on AWS. Engineers will build and configure products end to end, from frontend to backend, infrastructure, security integration, and production support. Key Responsibilities All levels ● Develop and configure products, migrating legacy applications to a modern cloud-native, containerised tech stack. ● Build responsive, accessible web frontends using ReactJS, TypeScript, and Next.js. ● Develop backend services and APIs in Golang and/or Kotlin, including long-running business processes using a workflow engine (e.g. Temporal). ● Set up and maintain secure AWS infrastructure using Infrastructure as Code (e.g. Terraform). ● Implement security controls and monitoring, including authentication and identity integration with Singpass, Corppass, OIDC, and SAML. ● Build and maintain CI/CD pipelines in GitLab, and deploy workloads to Kubernetes (EKS). Instrument applications for observability using tools such as Dynatrace or Datadog. ● Support production deployments, troubleshoot issues, and take part in incident resolution. ● Write clean, tested, well-documented code and take part in code reviews. Additional responsibilities for Senior Consultant ● Define the technical architecture and target state for the modernised platform. ● Lead delivery across multiple workstreams, coordinating with product owners, DevSecOps, and agency stakeholders. ● Provide strategic technical guidance, set engineering standards, and mentor team members. Plan legacy-to-modern migration approaches, including sequencing, risk management, and cutover. Requirements Experience ● Consultant: 3–5 years of hands-on full stack development experience. ● Senior Consultant: 7+ years of experience, including at least 2–3 years leading technical delivery or defining solution architecture. ● Experience migrating or modernising legacy systems is strongly preferred. ● Experience delivering Singapore Government or public sector projects is an advantage. Technical skills (must have) ● Frontend: ReactJS, TypeScript ● Backend: Golang and/or Kotlin; ● DevOps: CI/CD, Docker, Kubernetes ● Cloud: AWS architecture and services ● Infrastructure as Code: Terraform (or equivalent) ● Observability: hands-on experience with at least one observability tool Technical skills (good to have) ● Experience with Next.js ● Experience in setting up AWS cloud infrastructure (e.g. S3, EKS / ECS, EC2, Lambda, RDS, Load Balancers, API Gateway) ● Experience with a workflow engine (e.g. Temporal) ● Experience with a rules engine (e.g. Gorules, Open Policy Agent) ● Familiarity with observability tools such as Dynatrace, Datadog ● Implemented authentication using OIDC, SAML ● Implemented authorisation using RBAC, ABAC ● Government identity and security tooling: Singpass, Corppass, ADFS, WOG AD, CAM (GovTech Central Accounts Management), Trend Micro FAM ● Infrastructure and container security practices ● OutSystems, Oracle Policy Automation (OPA) / Oracle Intelligent Advisor (OIA), Sitefinity, Oracle Soft skills ● Strong problem-solving and debugging skills in production environments. ● Clear communication with technical and non-technical stakeholders. ● Senior Consultant: proven leadership, stakeholder management, and ability to drive decisions.
