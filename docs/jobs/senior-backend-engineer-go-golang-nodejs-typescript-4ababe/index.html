We are looking for a Senior Backend Engineer to develop, maintain and enhance backend services supporting a real-time gaming platform. Key Responsibilities • Design, develop and maintain backend services and RESTful APIs used by frontend, partner and gaming applications. • Develop and support Node.js and Express.js services and contribute to Go-based game-server components where required. • Maintain player authentication, account, wallet, balance, deposit/withdrawal and transaction-related functionality. • Support real-time communication using WebSocket and/or Socket.IO, including connection handling, heartbeats and reconnection behaviour. • Work with MongoDB, MySQL and Redis for application data, transaction processing, caching and session/token storage. • Support game-session reporting, jackpot, monitoring, synchronisation and other game-related backend services. • Integrate backend applications with third-party partner systems and local/on-premises services. • Implement secure API access using appropriate authentication, authorisation and request-signing mechanisms. • Improve application performance, reliability, logging, health checks and diagnostics. • Troubleshoot production issues across application, database and network-integration layers. • Develop and maintain Docker-based services and contribute to CI/CD and deployment practices. • Participate in code reviews, technical discussions and continuous improvement of automated testing and software quality. Your Skills and Experience Required Skills • 5+ years of commercial backend-development experience. • Strong commercial experience with Node.js and JavaScript and/or TypeScript. • Strong experience designing and developing RESTful APIs using Express.js or a similar backend framework. • Experience with relational and/or NoSQL databases, including data modelling, indexing and query optimisation. • Good understanding of asynchronous programming and service-to-service integration. • Experience using Git and modern source-control workflows. • Experience using Docker for local development, build or deployment. • Strong debugging, analytical and problem-solving skills.
