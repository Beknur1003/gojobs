Job Summary We are seeking a dynamic Sr. Staff Software Engineer to lead the design and delivery of our Cloud Native Firewall Service for Azure. You will leverage Python, Django, FastAPI, Golang, and React to evolve the core management, orchestration, and automation architecture of our cloud-native security offerings. As a technical leader, you will ensure our microservices and complex cloud networking workflows are resilient, scalable, and seamlessly integrated with Azure’s infrastructure. Key Responsibilities • Lead end-to-end architectural design and deployment of scalable, high-availability software for the Cloud Native Firewall Service. • Orchestrate serverless microservices via Azure Functions and Container Apps, ensuring alignment with enterprise security architectures. • Implement system design best practices for scalable, robust, and multi-region asynchronous and event-driven architectures. • Deploy monitoring solutions using Azure Monitor and Log Analytics to track service health and security telemetry. • Design robust backend services to automate the lifecycle of firewall instances across global Azure regions. • Build high-performance API layers bridging core IT data with cloud security telemetry and management tools. • Guide the engineering team in adopting modern software development best practices to accelerate code delivery. • Mentor junior engineers to foster a culture of excellence and accountability in cloud-native domains. Qualifications Required Qualifications • Minimum of 10 years of related experience with a Bachelor's degree in Computer Science, Engineering, or related field. • 10+ years of backend development experience with Python, utilizing Django or FastAPI for microservice architectures.. • Expert-level proficiency in containerization and orchestration using Docker and Kubernetes, specifically Azure Kubernetes Service (AKS). • Proven experience integrating applications with Azure Monitor, Log Analytics, and Application Insights for performance management. Preferred Qualifications • Hands-on experience with the Microsoft Azure platform, including Azure Functions, Networking primitives, and Resource Manager (ARM). • Experience using Terraform, Bicep, or Ansible to automate cloud resource provisioning in a professional environment. • Master's degree in Computer Science or a related technical field.
