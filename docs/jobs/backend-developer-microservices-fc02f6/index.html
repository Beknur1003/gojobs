# Job Description: Backend Developer (Microservices) *Company:* PublicNext (ElectReps Pvt. Ltd.) *Location:* Bengaluru, Karnataka *Experience:* 0–1 Year *Employment Type:* Full-time ## About PublicNext PublicNext is Karnataka’s hyperlocal digital news platform, delivering news and video content across the state through its website and mobile applications. We are looking for a passionate Backend Developer to join our technology team and help build scalable, high-performance backend services using a microservices architecture. ## Role Overview As a Backend Developer, you will design, develop, test, and maintain backend microservices that power PublicNext’s web and mobile applications. This role is ideal for fresh graduates or developers with up to one year of experience who are eager to learn backend engineering, APIs, databases, and scalable system design. ## Key Responsibilities - Develop and maintain backend microservices for PublicNext’s web and mobile applications. - Build and integrate RESTful APIs for news feeds, articles, videos, user activity, notifications, and other platform features. - Write clean, efficient, maintainable, and reusable code. - Work with databases such as PostgreSQL and MongoDB. - Implement API validation, error handling, authentication, and authorization where required. - Debug issues, fix bugs, and improve application performance. - Write unit tests and participate in code reviews. - Collaborate with frontend, mobile app, QA, and DevOps teams. - Work with Git for version control and follow established development practices. - Learn and contribute to deploying and monitoring services in a cloud environment. ## AI-Driven Software Development - Hands-on experience using AI-powered development tools such as GitHub Copilot, Cursor, Claude,kiro,antigravity, opencode , or similar tools. -Ability to leverage AI for code generation, refactoring, debugging, test creation, documentation, and code reviews. -Proficiency in AI-assisted development workflows, including prompt engineering, context management, and iterative code refinement. -Ability to validate AI-generated code for correctness, security, performance, and maintainability. ## Required Skills - Strong programming fundamentals in Go (Golang) or a willingness to learn Go quickly. - Basic understanding of REST APIs, HTTP methods, JSON, and client-server architecture. - Familiarity with SQL and relational databases. - Basic knowledge of data structures, algorithms, and object-oriented or structured programming. - Familiarity with Git and GitHub/GitLab. - Understanding of debugging, error handling, and writing modular code. - Willingness to learn microservices architecture, caching, and distributed systems. ## Good to Have - Academic projects or internship experience in backend development. - Exposure to PostgreSQL, MongoDB, Redis, or message queues. - Basic knowledge of Linux, Docker, and cloud platforms such as AWS. - Experience building APIs or backend services for web or mobile applications. ## Education - B.E./B.Tech in Computer Science, Information Science, IT, or a related discipline. - BCA, MCA, or equivalent qualifications will also be considered. - Freshers with strong programming fundamentals and practical projects are encouraged to apply. ## Who Should Apply? - Fresh graduates interested in backend engineering. - Developers with 0–1 year of experience who enjoy solving technical problems. - Candidates eager to learn Go, microservices, databases, and scalable backend systems. - Candidates who take ownership, learn quickly, and work well in a collaborative team. Skills:- Amazon Web Services (AWS), Linux/Unix, kong, keycloak, RESTful APIs, PostgreSQL and Drupal
