Навыки: Python, PostgreSQL, Docker, REST, Git, Apache Kafka, Redis, MySQL, Grafana, Golang. Квалификация: Senior. Специализации: Бэкенд разработчик. О нас Мы развиваем B2B-платформу для продавцов маркетплейсов — оптовый и розничный маркетплейс цифровых товаров. Платформа объединяет каталог, обработку заказов, балансы, аналитику и интеграции с поставщиками и внешними сервисами. Параллельно планируем развивать направление заказной разработки программного обеспечения для банков и финансовых организаций Беларуси. В фокусе — инвестиционные приложения, личные кабинеты и интеграции с банковскими, информационными и торговыми системами. Ищем Senior Backend Python Developer, который сможет самостоятельно принимать технические решения, развивать backend-сервисы и отвечать за их качество, производительность и надёжность в продакшене. Что нужно делать • Разрабатывать, масштабировать и поддерживать backend-сервисы платформы; вести задачи от уточнения требований до запуска и сопровождения в продакшене. • Проектировать и реализовывать API для фронтенда и внешних интеграций, прежде всего REST API. • Самостоятельно прорабатывать архитектуру своего направления, обсуждать технические решения с командой и менеджментом, объяснять компромиссы и риски. • Оптимизировать производительность и время отклика критических сервисов, находить и устранять узкие места. • Проектировать модели данных, писать эффективные SQL-запросы и безопасные миграции PostgreSQL. • Проводить код-ревью и рефакторинг, развивать модульные и интеграционные тесты, поддерживать техническую документацию. • Интегрировать сторонние сервисы и платёжные системы, обеспечивать корректность обработки операций, повторных запросов и ошибок. • По мере запуска направления заказной разработки участвовать в создании серверных компонентов и интеграций для финансовых проектов. • Обязательно применять ИИ-инструменты в ежедневной разработке: при проработке решений, написании и рефакторинге кода, подготовке тестов и документации; проверять результаты и отвечать за качество итогового решения. Команда и стек технологий Состав команды: • Founder/CEO • Technical Delivery Manager • Backend developers • Frontend developers • Support lead • Support managers Рабочие языки — русский и английский. Взаимодействуем напрямую с менеджментом и коллегами из разработки и поддержки. Используем микросервисную архитектуру: основные бизнес-сервисы построены на Python / FastAPI, синхронное взаимодействие идёт через HTTP/REST, асинхронное — через Apache Kafka. Основной стек: • Python 3.11–3.12 • FastAPI, Pydantic 2; Django — для административных приложений • PostgreSQL, Redis • Apache Kafka, HTTP/REST — взаимодействие микросервисов • SQLAlchemy 2, asyncpg, Alembic • Docker, Docker Compose, Nginx • GitHub Actions (CI/CD) • Celery + Redis — фоновые задачи • S3 API, MinIO — файлы и вложения • ClickHouse — аналитика и хранение логов • Prometheus, Grafana, Alertmanager — мониторинг и оповещения • pytest, pytest-asyncio, Ruff, mypy — тестирование и проверки качества Ожидания от кандидата Hard Skills • Коммерческий опыт backend-разработки на Python и подтверждённый уровень Senior: самостоятельное проектирование, развитие и сопровождение сервисов в продакшене. • Уверенное знание FastAPI и Django / Django REST Framework, понимание устройства веб-приложений и жизненного цикла запроса. • Опыт проектирования и разработки REST API: контракты, валидация, обработка ошибок, авторизация и обратная совместимость. • Глубокое знание SQL и PostgreSQL: проектирование схем, индексы, транзакции, блокировки и оптимизация запросов. • Опыт работы с SQLAlchemy и миграциями Alembic либо аналогичными инструментами; понимание безопасного изменения схемы работающей системы. • Уверенное понимание асинхронного программирования в Python (asyncio), конкурентного выполнения и работы с внешними сервисами. • Умение писать модульные и интеграционные тесты с pytest и проверять критические сценарии обработки данных и ошибок. • Опыт работы с Git и код-ревью, умение разбираться в существующей кодовой базе и улучшать её без потери совместимости. • Практический опыт применения ИИ-инструментов в разработке: умение ставить задачи, передавать контекст, использовать ИИ для работы с кодом, тестами и документацией, критически проверять результат и включать его в рабочий процесс. Регулярное практическое использование ИИ — обязательное требование. Soft Skills • Умение обсуждать и аргументировать технические и архитектурные решения с учётом целей бизнеса. • Опыт работы в команде с итерационным процессом разработки, тесное взаимодействие с фронтенд-разработчиками и менеджментом. • Способность самостоятельно планировать развитие своего направления, оценивать задачи, обозначать зависимости и нести ответственность за результат. • Готовность уточнять требования, заранее сообщать о рисках и предлагать варианты решения. • Готовность разбираться в чужом коде, проводить конструктивное ревью и делиться знаниями с командой.
