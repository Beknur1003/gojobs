WE ARE HIRING – FULLSTACK DEVELOPER VLink Consulting Indonesia is currently looking for an experienced Fullstack Developer to join our growing technology team! We are seeking a skilled developer with strong hands-on experience in full-stack development, backend engineering, and system integration. The ideal candidate should have solid expertise in Golang, REST API, PostgreSQL, Redis, Vue.js, and JavaScript, along with the ability to develop scalable backend services and integrate multiple systems effectively. Job Requirements & Qualifications • Minimum 5 years of professional experience in Fullstack Development, Backend Development, and System Integration. • Strong hands-on experience in Golang for developing, maintaining, and optimizing backend services. • Experienced in designing, developing, and integrating RESTful APIs across internal systems and external services. • Solid understanding of PostgreSQL, including database schema design, query optimization, and complex data processing. • Hands-on experience with Redis for caching mechanisms and distributed state management. • Proficiency in Vue.js and JavaScript for frontend development and backend-to-frontend integration. • Experience working with Tyk API Gateway or other API management platforms. • Familiarity with Microsoft Entra ID (Azure AD) for authentication, authorization, and identity management integration. • Strong understanding of system architecture, API specifications, data mapping, and end-to-end system integration. • Experienced in troubleshooting backend services, API integrations, database performance, and cross-system issues across Development, UAT, and Production environments. • Familiarity with Git/GitLab, Docker, CI/CD pipelines, and deployment workflows. • Experience supporting production releases, deployments, and troubleshooting during release activities. Key Responsibilities • Develop, maintain, and enhance scalable backend services and RESTful APIs using Golang. • Design and optimize PostgreSQL database schemas, queries, and data processing workflows. • Implement Redis caching solutions to improve application performance and manage distributed application state. • Build and maintain integrations between internal platforms and external services through API Gateway solutions. • Support authentication and identity integration using Microsoft Entra ID (Azure AD). • Collaborate on frontend development and integration using Vue.js and JavaScript. • Analyze technical specifications, system flows, business requirements, and data mapping to deliver reliable end-to-end integration solutions. • Perform technical troubleshooting, root cause analysis, and issue resolution across development, UAT, and production environments. • Support CI/CD processes, Docker-based deployments, production releases, and post-deployment stabilization.
