Position Summary: Miovision is building the future of smart transportation, and our Platform Engineering team provides the core infrastructure that connects our entire product ecosystem. We are looking for a Senior Software Developer to lead the technical execution of our unified API gateway; the high-speed express lane that powers everything from our web applications to our AI-driven workflows. In this role, you will act as the traffic controller for our API ecosystem, ensuring data routes securely, seamlessly, and at scale across our architecture. This role is instrumental in turning Miovision’s API surface into a true product: discoverable, versioned, secure, observable, and commercially ready for internal engineering teams, external customers, and integration partners. You will design and build the stateless, governed entry point for Miovision One (our web app), Mateo (our AI assistant), public APIs, CLI/SDKs, and AI agents, establishing the routing patterns and security standards that allow developers to build with confidence. As a Senior Modern Software Engineer, you will sit at the intersection of Context, AI, and Core Engineering - combining deep domain understanding and business value alignment with AI-first workflows and high-rigor distributed systems engineering. Objectives and Responsibilities: • Build the Gateway: Design, build, scale, and maintain our stateless API gateway, serving as the highly performant front door for all Miovision applications and services. • Architect for Scale: Keep architectural boundaries crisp by maintaining domain business logic in owning services, utilizing the platform API layer strictly for routing, access control, and formatting standards. • Commercialize the API: Embed usage tracking, billing hooks, tenant-aware access control, and rock-solid observability into the platform from day one. • Govern and Standardize: Partner with Architecture, Product, Security, and domain teams to enforce strict API governance, including versioning, backward compatibility, API linting, and contract testing. • Enable AI and Automation: Design machine-readable, agent-friendly API contracts that empower our AI chatbot (Mateo), MCP servers, and future AI agents to safely discover and invoke Miovision capabilities. • Drive Consensus: Champion cross-team alignment on complex domain modeling, resource naming, and API structures, transforming tough debates into clean, durable API contracts. • Publish and Document: Create crystal-clear service catalog entries and developer-friendly documentation so consumers can easily discover, understand, and adopt platform capabilities. • Code and Mentor: Roll up your sleeves to write high-quality code (primarily in Kotlin or Go), actively utilize AI-assisted development tools (like AMP), and mentor peers through deep technical design and code reviews. • AI-First Workflows: Embed and promote the use of AI-assisted development tools (e.g., AMP, Claude Code, Copilot) within engineering workflows, while maintaining rigorous code quality. The Ideal Profile: • Experience and Track Record: 7+ years of experience in software engineering, with a strong focus on backend systems, platform engineering, or distributed architectures. • Core
