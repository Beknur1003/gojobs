The Basics As a Senior Software Engineer on the Connect team, you will own how Tanium data reaches the rest of our customers' tools. Connect is the module that moves endpoint data and events out of Tanium and into external systems such as SIEMs (security information and event management tools like Splunk), data warehouses, ticketing systems, cloud storage, and email. Customers run thousands of these exports on schedules, and a failed or slow export means their security team is working with stale data. You'll design and build the services behind Connect, shape its technical direction, and mentor engineers on the team. This role is a strong fit for someone on a path to Staff Engineer. This position follows the Company's hybrid schedule, which currently requires employees to work in the office a minimum of three days per week at our Durham, NC or Emeryville, CA location. Candidates must be US-based. What you'll do • Design and build scalable, reliable backend services in Node.js and Golang that collect, transform, and deliver large volumes of endpoint data to external destinations • Design and evolve the APIs Connect exposes and consumes, with clear contracts, versioning, and backward compatibility • Build and maintain integrations (connectors) to third-party platforms, handling their different authentication methods, rate limits, payload formats, and failure behavior • Own delivery guarantees: retries, backoff, deduplication, and back-pressure (slowing intake when a destination can't keep up), so data is not lost or duplicated • Build event-driven workflows using NATS (an open-source messaging system where services publish and subscribe to events) and Temporal (an open-source engine that runs multi-step jobs durably, so they resume where they left off after a crash) • Lead technical design for new Connect capabilities, driving decisions across teams and writing design docs others can build from • Improve observability (metrics, logs, tracing, alerting) so we find export problems before customers do • Write unit tests for your code and partner with the QA and automation team on integration and end-to-end coverage, building services that are easy to test • Debug production issues, find root causes, and build the fix that prevents the next one • Mentor engineers and help set the team's standards for design, testing, and operations We're looking for someone with Education • Bachelor's degree or equivalent experience • CS degree or related technical field preferred Experience • 8+ years building and running backend services in production, with a track record of leading designs and influencing direction beyond your own team • Strong proficiency in Golang or Node.js, and willingness to work in both • Experience designing APIs (REST, GraphQL, or gRPC) and building event-driven systems (NATS, Kafka, RabbitMQ, or similar) and multi-step workflows • Experience integrating with third-party APIs and SaaS products, including OAuth (a standard for letting one app access another on a user's behalf) • Experience with containers and cloud: Docker, Kubernetes, Terraform, and Azure or AWS • Experience with SQL or NoSQL data stores, plus git and CI/CD pipelines (such as Jenkins or GitHub Actions) • Proficient with AI-assisted development tools (e.g., Claude, GitHub Copilot) • Must be eligible to obtain FedRAMP clearance at a minimum (FedRAMP is the US government's security authorization program for cloud services) Nice to have • Experience
