Kods AI - Sr Fullstack Engineer (AI Native)

Sobre el rol En buscamos un/a Full Stack Senior con mentalidad de producto, apasionado/a por construir software de alta calidad y que utilice herramientas de inteligencia artificial como parte de su flujo diario de desarrollo. Queremos sumar a alguien que pueda moverse con comodidad desde el frontend hasta la infraestructura, diseñando arquitecturas escalables y participando en todas las etapas del desarrollo. Más que alguien que simplemente programe, buscamos a una persona capaz de resolver problemas complejos utilizando las mejores herramientas disponibles. Responsabilidades • Diseñar, desarrollar y mantener aplicaciones web escalables. • Participar en el diseño de arquitectura de software. • Implementar y desplegar servicios cloud-native. • Trabajar junto al equipo de ingeniería y negocio para convertir ideas en funcionalidades. • Integrar modelos de IA, agentes conversacionales y soluciones de IA generativa dentro de los productos. • Optimizar rendimiento, escalabilidad y costos de infraestructura. • Automatizar procesos mediante IA y herramientas modernas de desarrollo. • Participar en code reviews y definir buenas prácticas de ingeniería. Requisitos Excluyentes AI • Uso avanzado y cotidiano de herramientas de desarrollo asistidas por IA. • Experiencia utilizando herramientas como Claude, Codex, Cursor o similares como parte del workflow de programación. • Capacidad para generar, revisar, refactorizar y acelerar el desarrollo mediante IA. Backend • Experiencia sólida con alguno de los siguientes lenguajes: ○ Python ○ TypeScript ○ Go (Golang) • Conocimiento de diseño de APIs REST y/o GraphQL. • Arquitectura basada en microservicios. Bases de datos • Experiencia trabajando con: Bases de datos relacionales (PostgreSQL) • Bases de datos NoSQL (MongoDB) • Conocimiento de: Modelado de datos ,Optimización de consultas , Indexación ,Migraciones Cloud & Infraestructura Experiencia desplegando aplicaciones en plataformas cloud. Idealmente: • AWS • DigitalOcean Conocimiento de: • Docker • Kubernetes • Knative • AWS Lambda • Serverless • Networking básico • Balanceadores de carga • CI/CD Inteligencia Artificial Experiencia o conocimientos en: • AI Generativa • LLMs • Prompt Engineering • AI Agents • Agentes conversacionales • Integración con APIs de modelos de lenguaje (OpenAI, Anthropic, Gemini u otros) • Protocolos modernos como MCP (Model Context Protocol) y herramientas de orquestación de agentes (por ejemplo, LangGraph o similares) son un plus. Valoramos especialmente • Pensamiento de producto. • Capacidad para trabajar de forma autónoma. • Buen criterio técnico para tomar decisiones. • Interés genuino por aprender nuevas tecnologías. • Experiencia construyendo productos SaaS. • Experiencia trabajando en startups. • Mentalidad "ownership". • Comunicación clara y capacidad para colaborar con equipos multidisciplinarios. • Inglés técnico para documentación y comunicación. Interview Process • Silver Screening Interview. • Silver Live coding Interview. • Client Technical Interview (System design + Live coding). • Client Behavioral Interview.
