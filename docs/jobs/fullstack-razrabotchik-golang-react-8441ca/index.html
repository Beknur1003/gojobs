Навыки: Golang, TypeScript, React, gRPC, MySQL, Apache Kafka, Docker, Kubernetes. Квалификация: Senior. Специализации: Бэкенд разработчик. Международная продуктовая IT компания, которая занимается разработкой и поддержкой высоконагруженных проектов для крупных компаний, основная часть которых представляет собой развлекательные онлайн-сервисы, в поисках Senior Fullstack-разработчика (Go + React). Обязанности: • Разрабатывать фичи целиком: сервисы и API на Go, интерфейсы на React. • Проектировать новые сервисы и модули, развивать существующие. • Ставить задачи агентам: контекст, ограничения, результат. • Поддерживать и дорабатывать агентную систему: разбирать неудачные запуски, улучшать постановки, развивать harness. Требования: Backend • 5+ лет коммерческой разработки, из них 2+ года production-кода на Go: идиоматичный код, unit-тесты, code review. • Работали с OLTP-базой: схема, миграции, индексы, кэширование. Frontend • Уверенные React и TypeScript. Понимаете, как React работает внутри, и знаете веб-платформу: DOM, события, сеть, хранение данных, безопасность в браузере. Работа с AI-агентами • Готовы ежедневно работать с AI-агентами. Будет плюсом: • Kafka, NATS, event-sourcing, паттерны надежной доставки: outbox, saga, идемпотентность. • Kubernetes и zero-downtime деплой. • Проектирование сервиса с нуля по короткому описанию задачи. • Практические примеры задач, решенных с помощью coding-агентов, с пониманием того, что получилось и где потребовалось вмешательство. • Опыт автоматизации разработки, создания внутренних инструментов и интеграций с CI/CD. • Опыт координации нескольких агентов, работы с их контекстом и построения проверок качества. • Участие в разработке собственного агентного инструментария или harness. • Опыт tech founder или работы в стартапе. • Контрибьюты в open source. Что компания может предложить Вам: • Офисный формат работы в Сербии (г.Белград), на Кипре (г.Лимассол); Удаленный формат работы вне РФ, также доступна Сербия; • Компания заинтересована в развитии своих сотрудников: готовы привлекать наставников и оплачивать курсы для повышения квалификации; • Отсутствие бюрократии, быстрое согласование необходимых вещей; • Оплачиваемые отпускные; • Частичная компенсация английского; • 4 day-off в год за счет компании; • Компания поддерживает сотрудника в важные периоды жизни; • Годовой бонус по результатам работы; • Реферальная программа за успешную рекомендацию.
