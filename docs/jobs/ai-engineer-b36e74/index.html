AI Engineer

PythonJavaC++AI/LLM
Job Responsibilities: 1. Designing and maintaining high-performance Retrieval-Augmented Generation platforms, focusing on optimizing data ingestion, embedding, and real-time retrieval pipelines. 2. Designing AI-driven content such as intelligent NPCs, AIGC-based level generation, and AI bots to enhance player immersion. 3. Managing complex game data, including cleaning, chunking, and indexing to ensure high-quality retrieval for the knowledge base. 4. Building and deploying Agent and MultiAgent frameworks to solve logic problems and create dynamic, strategizing game characters. 5. Implementing Prompt Engineering and Vibe Coding techniques to rapidly iterate on AI tools and improve production efficiency. Requirements: 1. Bachelor’s degree or higher in Computer Science, Artificial Intelligence, Mathematics, or a related field. 2. Excellent coding skills with a deep understanding of data structures and algorithms. Mastery of Python (required) or proficiency in C++, C, Golang, or Java. 3. Deep understanding of RAG architectures, including experience with Vector Databases (e.g., Pinecone, Milvus, ChromaDB) and semantic search techniques. 4. Proven experience in building AI systems using frameworks like LangChain, AutoGen, or LlamaIndex to handle complex, multi-step tasks. 5. Familiarity with game-specific data formats and the ability to build robust ETL pipelines for unstructured data processing. 6. Proficient in Prompt Engineering and comfortable with Vibe Coding (natural language-driven development) to accelerate the prototyping cycle. 7. Knowledge of RAG evaluation frameworks (e.g., RAGAS) and system monitoring tools to mitigate hallucinations and ensure reliability. 8. Strong passion for the "AI + Game" industry, with the hands-on ability to solve ambiguous technical challenges in a fast-paced environment.
