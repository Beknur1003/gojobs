Backend Engineer 後端工程師 / 軟體工程師(部分遠端)

Go — основной язык Гибрид Полная занятость
PostgreSQLMySQLRedisgRPCKubernetesDockerPythonJavaNode.js
【工作內容】 在資深工程師指導下參與高效能與高併發系統的開發與維運。團隊提供完整的 onboarding 流程與 mentor 制度，協助你從 Junior 成長為獨當一面的後端工程師。 1. 在資深工程師指導下，使用 Golang 開發後端服務模組與 API。 2. 參與 code review，學習團隊的工程實踐與架構設計。 3. 協助修復 bug、處理線上問題，累積 production 系統的實戰經驗。 4. 撰寫技術文件、API 規格，與 QA、前端團隊協作。 5. 學習並逐步熟悉 GKE、PostgreSQL、Redis、gRPC 等技術。 【具備條件】 1. 資訊相關科系畢業，或具備 1 年以上後端開發經驗。 2. 熟悉至少一種後端程式語言（Go、Java、Python、Node.js 擇一），有 Golang 經驗尤佳。 3. 了解基本的資料庫操作與 SQL 語法。 4. 熟悉 Git 版本控制基本操作。 5. 了解 HTTP、RESTful API 基本概念。 6. 具備良好的學習意願與主動溝通能力。 【加分條件】 1. 有 Golang 實作專案經驗（學校專題、Side Project、Open Source 皆可） 2. 接觸過 Docker、Kubernetes 等容器技術。 3. 了解 gRPC、message queue 概念。 4. 有使用過 PostgreSQL、MySQL、Redis 等資料庫。 5. 在 GitHub 上有公開的個人作品。
