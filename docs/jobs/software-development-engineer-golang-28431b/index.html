Responsibilities: • Design, develop, test, and maintain backend services. • Write clean, efficient, and production-ready code. • Participate in code reviews and automated testing practices. • Collaborate with cross-functional teams for smooth system integration. • Debug and resolve production issues with guidance when required. • Work in an agile environment with increasing ownership over time. Technical Skills: • Strong backend engineering experience in any modern programming language. • Experience with MySQL and backend databases. • Understanding of APIs and backend system design. • Exposure to AWS and Docker is a plus. • Experience with Golang is a bonus. • Understanding of trading systems is preferred. Soft Skills: • Good problem-solving and analytical skills. • Effective communication and teamwork. • Ability to work in a fast-paced environment. • Strong learning orientation and ownership mindset.
