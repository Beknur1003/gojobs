Role & Responsibilities : Technical Execution & Ownership : - Distributed Excellence : Design and implement robust, event-driven microservices using Java or Golang. Implement sophisticated caching (Redis) to minimize database contention. - Concurrency & Performance : Profile and optimize the "hot path" of transactions. You will be responsible for sub-second API latencies and ensuring the system scales horizontally under load. Leadership & Standards : - Code Stewardship : Lead by example with "Clean Code," TDD (Test Driven Development), and SOLID principles. Own the peer-review process for your pod. - System Design : Write and defend Technical Design Documents (TDDs) for new product features, ensuring they are scalable, secure, and maintainable. - Mentorship : Act as a force-multiplier by mentoring SDE-1 and SDE-2 engineers, helping them master the nuances of distributed systems. Domain-Specific Challenges (Fintech 2026) : - Real-time Verification : Collaborate with Risk teams to integrate AI-driven fraud checks into the checkout flow without adding latency. - Compliance : Ensure all code adheres to data localization (RBI) and security (PCI-DSS) standards by default. Required Pedigree : - Track Record : 5- 9 years of experience in backend development at a high-scale B2C or B2B tech company (Fintech, E-commerce, or SaaS). - Education : B.Tech/M.Tech in Computer Science from a Tier-1 institute (IITs, NITs, BITS). - Skills : Expert-level mastery of Data Structures, Algorithms, and System Design. Deep understanding of AWS (EKS, RDS, S3).
