Senior Golang Backend Engineer

Go — основной язык Удалёнка Senior

Job Description: A día de hoy el servicio de main controller sólo es capaz de crear repositorios en Bitbucket. Con el planteamiento del banco de migrar a GitHub todos sus repositorios necesitamos a una persona senior con conocimientos en Golang para evolucionar main controller para que pueda crear repositorios en GitHub. La persona será responsable de analizar el caso de uso, hacer el evolutivo y gestionar todas las tareas necesarias para ir desplegando por los entornos hasta llegar a producción. El sistema se despliega en un gestor de contenedores (meigas de HashiCorp) por lo que si el perfi tiene conocimientos de dicha plataforma mejor, pero no es completamente necesario porque se le podría formar dentro del equipo. Conocimiento: - Golang - Docker - Ansible - Meigas (Nomad, Consul, Vault): Opcionales Full remote
