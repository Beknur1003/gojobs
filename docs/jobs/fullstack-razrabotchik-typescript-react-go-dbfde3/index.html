Cloud X — ИТ-компания, предоставляющая услуги облачных вычислений на базе собственной инфраструктуры: облачной платформы CX Platform и гипермасштабируемых центров обработки данных CX Data Centers с нулевым углеродным следом. Компания предлагает более 40 сервисов, предоставляемых по моделям IaaS, PaaS и SaaS, среди которых: базовая инфраструктура, ИИ, машинное обучение, интеграционные сервисы, Интернет вещей, большие данные, сетевые функции и кибербезопасность. Облако Cloud X внесено в реестр отечественного программного обеспечения Министерства цифрового развития, связи и массовых коммуникаций Российской Федерации. Инвестором компании выступает Эн+. Приглашаем Fullstack-разработчика для реализации пользовательской части продукта CX Kubernetes. Чем предстоит заниматься: • разработка интерфейсов облачной консоли кубера; • интеграция консоли K8s в облако Cloud X; • доработка консоли K8s в части нового функционала + развитие визардов консоли; • участие в сертификации продукта на требования ФСТЭК (необходимые для прохождения сертификации доработки). Задачи: • разработка компонентов для построения гибких и масштабируемых интерфейсов; • проектирование клиентской архитектуры приложений; • работа над библиотекой компонентов; • проведение код-ревью, техническая экспертиза. Для нас важно: • В/о, предпочтительно техническое; • 6 - 10 лет опыта разработки компонентов для построения гибких и масштабируемых интерфейсов; • 3+ года разработки на TypeScript; • отличное знание React; (последние 5 лет опыт работы с ним); • отличное знание JavaScript, • опыт разработки RestAPI на Golang (предпочтительнее) или nodejs/Java/C#; • работа со стейт менеджером MobX (в приоритете) и/или Redux / Redux Toolkit, React.Context; • опыт работы с git, Docker, Kubernetes, понимание виртуализации; • понимание принципов работы REST API, микросервисной архитектуры; • опыт проектирования клиентской архитектуры приложений; • опыт работы над библиотекой компонентов; • уверенные навыки верстки (CSS3, HTML5), • опыт работы с cборщиками модулей: webpack, Rollup; • опыт работы с scss/less; • приветствуется опыт работы с визуализацией данных(dataviz); • приветствуется знание работы c микрофронтендами; • приветствуется знание чистой архитектуры, Solid-подхода к проектированию. Мы предлагаем • Реализация проектов федерального масштаба (Облако и сеть облачных дата-центров, которым нет аналогов в России) в составе крупного международного промышленного холдинга; • Оформление по ТК РФ, белая зарплата, уровень вознаграждения обсуждается с успешным кандидатом; • Современный офис в 10-15 мин пешком от м. Улица 1905 года, на территории бизнес-кластера "Трехгорная мануфактура"; • Гибридный график работы (2 дня офис/3 дня можно из дома); • Гибкое начало дня - с 8.00 до 10.30; • Льготы для аккредитованных ИТ-компаний; • ДМС после испытательного срока, в том числе для родственников; • Скидки от компаний-партнеров (BestBenefits, Ингосстрах); • Компенсация спорта и заботы о здоровье (ФИТМОСТ); • Корпоративный университет, библиотека Alpina Digital; • Корпоративное питание; • Мобильная связь; • Курсы английского языка; • Программа развития персонала по итогам Performance review; • Материальная помощь в важных жизненных событиях; • Отсутствие бюрократии, быстрое принятие решений.
