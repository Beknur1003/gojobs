This is a remote position. About the Company The client is a fast-growing technology company that develops innovative software solutions for the home improvement industry. Its platforms help contractors streamline their sales processes, generate accurate project estimates, and offer flexible financing options to homeowners. The company's technology helps contractors simplify complex sales processes, connect homeowners with financing options through a single application, and turn more in-home consultations into signed and funded projects. With more than $14 billion in project estimates powered through its platforms, the company is trusted by some of the most recognized names in the home improvement industry. As the company continues to grow and expand its technology, it is seeking a highly experienced Senior Full Stack Engineer to help build, scale, and improve its financing platform. About the Role The Senior Full Stack Engineer will play a key role in building and scaling the company's home improvement financing platform. This is a hands-on senior engineering role that requires strong backend development experience, particularly with .NET (C#), along with solid frontend capabilities using TypeScript and Angular or React. The successful candidate will own features end to end, working across backend services, frontend applications, database architecture, third-party integrations, and cloud infrastructure. Beyond writing production-quality code, this person will contribute to technical decisions, improve development practices, participate in code reviews, and mentor other engineers on the team. The ideal candidate is someone who combines strong technical expertise with independent problem-solving skills, takes ownership of their work, and is comfortable leveraging AI coding agents as part of their daily development workflow. Key Responsibilities Backend Development • Build, maintain, and evolve backend services and APIs using .NET (C#) and ASP.NET Core. • Design and implement scalable, reliable, and maintainable backend architectures. • Develop and maintain RESTful APIs and integrations with third-party services. • Build asynchronous and event-driven systems, including message queues, background jobs, retries, and idempotent processing. • Design and maintain reliable webhook integrations, including signature validation, retry handling, duplicate prevention, and background processing. • Write clean, efficient, and well-documented code while maintaining high standards for performance and security. Frontend Development • Design, build, and maintain modern web applications using TypeScript with Angular or React. • Develop responsive, user-friendly interfaces that support the platform's business requirements. • Collaborate with product and design teams to translate requirements into functional software. • Ensure frontend applications are maintainable, scalable, and properly integrated with backend services. Database & System Architecture • Design and maintain PostgreSQL database schemas, migrations, and queries. • Optimize database performance and troubleshoot complex data-related issues. • Contribute to technical architecture decisions, considering scalability, security, performance, and long-term maintainability. • Work across different services and technologies as needed, including Python, Go, Ruby, and Elixir. • Identify opportunities to improve system reliability and overall application performance. Cloud Infrastructure & Deployment • Deploy, maintain, and operate services across Azure and AWS environments. • Collaborate with the engineering team on CI/CD pipelines and deployment processes. • Work with containers and cloud-based infrastructure as needed. • Monitor application performance and help identify and resolve production issues. • Contribute to improving the reliability, scalability, and efficiency of cloud-based systems. AI-Assisted Development & Automation • Use AI coding agents such as Claude Code and GitHub Copilot as part of the daily development workflow. • Leverage AI tools to plan, write, test, debug, and review code more efficiently. • Apply independent technical judgment to validate AI-generated code and ensure its quality, security, and reliability. • Help improve how the engineering team integrates AI-assisted development into its processes. • Build and maintain automated QA processes, including end-to-end test suites using Playwright. • Ensure automated tests run consistently within CI pipelines. Technical Leadership & Collaboration • Lead technical design discussions and contribute to important engineering decisions. • Conduct code reviews and maintain high standards for code quality. • Mentor other engineers and share technical knowledge across the team. • Collaborate with product, design, and support teams to understand business needs and deliver effective technical solutions. • Take ownership of assigned features and ensure they are delivered from development through production. Requirements • 5+ years of professional software engineering experience, including full stack development. • Strong backend development experience with .NET (C#), ASP.NET Core, and Web APIs. This is the primary technical requirement for the role. • Strong TypeScript skills and production experience with Angular or React. Angular experience is preferred. • Hands-on experience with PostgreSQL, including database schema design, query optimization, and migrations. • Experience working with AI coding agents such as Claude Code or GitHub Copilot to plan, develop, test, and review code. • Ability to independently evaluate, validate, and take ownership of AI-generated code. • Experience designing and developing RESTful APIs and integrating third-party services. • Experience building asynchronous and event-driven systems, including message queues, background jobs, retries, and idempotent processing. • Experience developing and maintaining webhooks, including signature validation, retry management, duplicate handling, and reliable event delivery. • Familiarity with Git, CI/CD pipelines, and automated testing practices. • Experience with end-to-end QA automation using tools such as Playwright. • Strong problem-solving and analytical skills. • Excellent written and verbal communication skills. • Ability to work independently while collaborating effectively with a distributed engineering team. • Previous experience mentoring engineers or providing technical guidance to peers. Technical Skills Experience with the following technologies and tools is highly valued: Backend: • .NET / C# • ASP.NET Core • Web APIs • RESTful APIs Frontend: • TypeScript • Angular (preferred) • React Database: • PostgreSQL • Redis • Azure Cosmos DB Cloud & Infrastructure: • Microsoft Azure • AWS • Docker • CI/CD Testing & Development Tools: • Playwright • Git • GitHub • Claude Code • GitHub Copilot • JetBrains IDEs Additional Technologies: • Python • Go (Golang) • Ruby • Elixir Nice to Have The following qualifications are considered a plus but are not required: • Experience with one or more of the following programming languages: Python, Go, Ruby, or Elixir. • Experience with Redis for caching, queues, or pub/sub. • Familiarity with Azure Cosmos DB. • Previous experience working with Azure or AWS cloud environments. • Familiarity with containers and infrastructure as code. • Experience with cloud cost optimization and performance tuning. • Previous experience building SaaS products. • Experience developing software solutions for small businesses, construction, or home services industries. • Experience working with financial technology platforms or third-party financial integrations. Benefits • Salary: $3,800 – $4,000 per month, plus an annual performance-based bonus. • Paid Time Off: Paid holidays and paid time off. • Work Environment: Fully remote position with a supportive and collaborative engineering team. (From LATAM) • Professional Growth: Opportunity to work with modern technologies, contribute to technical decisions, and help shape the future of a growing technology platform.
