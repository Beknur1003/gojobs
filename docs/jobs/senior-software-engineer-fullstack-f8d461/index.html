Get to Know the Team The Grab Support Experience team, part of Grab Support Tech Family, builds the systems that power Grab's support journey for consumers, drivers, and merchants. We are transforming support through automation and AI-powered solutions that help users find more relevant information, resolve issues through self-service, and receive faster, more accurate assistance when they need help. Get to Know the Role As a Senior Software Engineer, Fullstack, you will develop full-stack systems for Grab Support Tech Family. You will work on desktop and in-app applications, services, APIs, and automation workflows that power Help Centre and related support platforms. You will report to Software Engineering Manager II and work onsite at CMC Creative Space, HCMC, Vietnam. The Critical Tasks You Will Perform • Develop full-stack features using React, TypeScript, Golang, and Grab's internal platform tooling. • Lead technical design and implementation for support journeys across Help Centre, support workflows, backend APIs, and internal platforms. • Collaborate with product managers, designers, data scientists, QA/SET, and other engineering teams to define requirements and create high-quality solutions. • Oversee production readiness, including monitoring, alerting, dashboards, operational runbooks, and release quality. • Participate in on-call support, incident handling, OPI/OSI follow-ups, root cause analysis, and prevention work. • Improve testing practices across unit, integration, UAT, and end-to-end layers, and contribute to GSTF quality metrics. • Review code and technical designs, mentor other engineers, and raise the engineering quality bar across the team. What Essential Skills You Will Need • 4+ years of professional software engineering experience, with full-stack development experience. • Hands-on experience with React and TypeScript for building production frontend applications, and Golang for backend services, APIs, and microservices. • Experience with distributed systems, service design, API design, data modelling, and reliability trade-offs. • Experience leading technical design and delivering projects independently from requirements to production rollout. • Good familiarity with AI-assisted software development and modern AI engineering practices, including use of coding agents and LLM APIs in daily development workflows. • Experience building maintainable, testable code with unit, integration, and end-to-end testing practices. • Debugging skills across frontend, backend, logs, metrics, and production systems. • Experience with a non-relational / noSQL database such as Elasticsearch, MongoDB, or DynamoDB • Experience in version control tools (Git, Bitbucket, etc.) • Strong ownership and stakeholder management skills. • Communication • Ability to mentor engineers, give clear code review feedback, and improve team engineering practices.
