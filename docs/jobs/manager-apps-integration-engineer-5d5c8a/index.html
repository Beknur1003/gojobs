事業概要 チャネルトークは「企業と顧客のコミュニケーション課題を解決する」ことをミッションに、オールインワンのAIエージェントを提供しています。CRMデータとAIを活用し、顧客からの問い合わせ対応を効率化・自動化。日本・韓国・アメリカで展開し、240,000万社以上に利用される、アジア最速水準で成長するB2B SaaSです。 なぜ募集するのか チャネルトークのAIエージェントが問い合わせ対応を "完結" させるには、顧客の業務システムとリアルタイムにつながる必要があります。注文照会・在庫確認・取消/交換/返品といった実務は、ECカート・OMS/WMS・モールと連携して初めて自動化できるからです。 日本市場では、楽天・Yahooショッピング・MakeShop・Amazon・Qoo10 をはじめ、日本のコマース環境に必要な連携アプリを次々と開発しています。この連携アプリのポートフォリオを一気に拡大するため、チャネルトーク上でアプリを設計・開発・運用するエンジニアを募集します。 「AIエージェントの手足を増やす」——ビジネスインパクトに直結する開発ポジションです。 業務内容 チャネルトークの App Store / Commerce Protocol 上で、外部サービス連携アプリをオーナーシップを持って開発します。 • ECカート・OMS/WMS・モール等、外部サービスとの連携アプリの設計・開発・運用 • OAuth / Webhook / 外部API を用いた認証・データ同期・イベント連携の実装 • App Studio / App Factory（社内のアプリ開発・量産基盤）を活用した高速なアプリ開発とQA自動化 • 連携先の仕様変更・APIバージョン移行への継続的対応 • Product / AI（ALF）/ CS / パートナー各チームとのクロスファンクショナルな連携 このポジションの魅力 • AIエージェントの能力拡張の最前線——作った連携が、そのままAIの自動対応範囲になる • 日本市場の立ち上げフェーズで、どのアプリを作るかから関われる大きな裁量 • アプリを"量産"する仕組み（App Studio / App Factory）そのものの進化にも貢献可能 • 23万社の実トラフィックが流れる環境で、コマース×AIのドメイン知識が深く身につく • 韓国本社のコアエンジニアリングチームと直接協働するグローバルな開発環境 必要な経験/スキル • TypeScript と Go の両方の実務経験 • EC / コマース / OMS / WMS / モール領域のドメイン知識、または連携開発経験 • SaaSのプラットフォーム／SDK／拡張機能（App/Plugin）開発経験 • 日本の主要ECプラットフォーム連携の知見 • クラウドネイティブ環境（AWS / Kubernetes）での運用経験 • AIエージェント／LLM連携（Function Calling 等）への関心・実装経験 • チーム・マネジメント経験（メンバー育成・パフォーマンス管理を含む／目安5年以上） • 日本語：ビジネスレベル以上（顧客・パートナー折衝あり） 望ましい経験/スキル • Enterprise SaaSの導入・実装支援経験 • SQL / Python / API利用経験 • CRM / CX / AI領域への理解 • AIツール（ChatGPT / Claude等）の業務活用経験 • Product Feedback / Product Improvementへの関与経験 • 英語または韓国語：韓国本社チームとの協働のため 技術スタック • 言語：TypeScript / Go • アプリ基盤：App Store、App Studio、App Factory、Commerce Protocol（Extension）、Open API、Custom Function • インフラ：AWS、Kubernetes、Docker、Pub/Sub・SQS、BigQuery • 連携方式：REST API、Webhook、OAuth 2.0、polling extension
