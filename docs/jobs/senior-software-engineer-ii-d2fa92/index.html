Position: Senior Software Engineer II (SSE 2) – Backend Platform & Data System Position Overview We are seeking a Senior Software Engineer II (SSE 2) to join our Core Platform team. In this role, you will design, architect, and optimize the high-throughput real-time data pipelines, advanced polyglot storage layers, and core backend orchestration microservices that power our enterprise AI/ML Platform. This role is heavily focused on advanced backend software engineering and highly concurrent distributed systems. You will build the foundational software layer that enables our platform to interact dynamically with massive streaming datasets. Using a mix of Golang and Python, you will orchestrate real-time data streams through Kafka and Apache Spark, and design highly resilient distributed data layers utilizing Apache Cassandra alongside PostgreSQL. As a senior leader, you will champion modern development workflows, utilizing AI coding assistants to optimize engineering velocity across the team. You will scale these capabilities across Amazon EKS (Kubernetes) and AWS cloud infrastructure. Key Responsibilities • Backend Architecture: Design, build, and optimize high-concurrency production-grade architectures and runtime engines using Golang and Python. • Advanced Engineering Workflows: Lead by example in utilizing advanced AI coding interfaces to accelerate code generation, framework migrations, system debugging, and documentation standards. • Polyglot Storage & System Design: • Architect and optimize highly available Apache Cassandra data models, managing partition keys and CQL queries to ingest massive streaming execution logs. • Design robust relational schemas, query tuning, and index optimizations in PostgreSQL to handle transactional states and analytical metadata. • Streaming & Event Orchestration: Architect resilient data streaming architectures utilizing Apache Kafka for event sourcing, alongside Apache Spark for high-velocity real-time and batch data processing pipelines. • Technical Leadership & Quality Control: Drive architectural reviews, establish engineering standards for platform reliability, enforce CI/CD, and mentor junior-to-mid-level engineers on scaling distributed data layers. Required Technical Skills & Experience • AI Tooling (Must Have): Direct, deep hands-on experience integrating AI-powered development environments and LLM assistants (e.g., Cursor, Claude, GitHub Copilot) into your workflow to significantly accelerate systems engineering and debugging tasks. • Programming Languages: Advanced proficiency in Golang (Go) for writing highly concurrent, memory-efficient systems, and strong production experience in Python. • Data Stream Technologies: Production experience implementing and managing enterprise-scale Apache Kafka topologies and distributed processing frameworks like Apache Spark. • Database Management (NoSQL & Relational): Deep understanding of distributed storage trade-offs (CAP theorem) with advanced hands-on experience in Apache Cassandra and PostgreSQL. • Containerization & Orchestration: Production-level experience with Docker and multi-cluster orchestration via Kubernetes / AWS EKS. Qualifications • Professional Experience: 6 to 8+ years of non-internship professional backend software engineering experience. • Data & Systems Background: 3+ years of experience specifically focused on distributed systems, real-time data streaming pipelines, polyglot storage design, or platform engineering for data-intensive applications. • Education: Bachelor’s degree in Computer Science, Distributed Systems, Software Engineering, or a highly technical related domain.
