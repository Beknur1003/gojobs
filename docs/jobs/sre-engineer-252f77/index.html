Требования: — Опыт работы в роли SRE или DevOps Engineer от 4-5 лет. — Экспертное владение Kubernetes (управление кластерами, написание Helm чартов / Operator SDK). — Глубокие знания Linux internals, сетевых протоколов и безопасности. — Опыт работы с облачными провайдерами (AWS — основной, GCP/Azure). — Уверенное владение Python или Go для написания инструментов автоматизации. — Практический опыт работы с инструментами IaC (Terraform). — Английский язык: Upper-Intermediate (свободная коммуникация в международной команде). Будет плюсом: — Опыт эксплуатации блокчейн-инфраструктуры (Ethereum, L2s, Solana). — Понимание специфики работы ZK-Rollups или систем с интенсивными вычислениями (GPU/FPGA acceleration). — Опыт работы с инструментами распределенной трассировки (Jaeger / Tempo).
