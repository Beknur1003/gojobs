Job Description : We are looking for a hands-on Senior Technical Architect who can drive architecture while actively coding, debugging, designing APIs/data models, working on AWS infrastructure, and mentoring engineering teams. The ideal candidate should have strong expertise in Golang, AWS, microservices, data engineering, and cloud-native architecture. Key Responsibilities : - Design and develop scalable, secure, and high-performance cloud-native applications and microservices. - Stay hands-on with Golang, API development, data modeling, debugging, and technical problem-solving. - Design REST/GraphQL APIs, event-driven architectures, and distributed systems. - Architect AWS solutions using ECS/Fargate, RDS, S3, API Gateway, SQS/SNS, and AWS Glue. - Design data pipelines using AWS Glue and PySpark, with PostgreSQL and MongoDB. - Implement event-driven architecture using messaging platforms such as Solace. - Drive infrastructure automation using Terraform, CI/CD, and DevOps practices. - Provide architecture-level guidance for React.js/Next.js applications. - Evaluate and integrate AI/LLM technologies, preferably AWS Bedrock, into enterprise solutions. - Lead technical decisions, conduct design/code reviews, troubleshoot complex issues, and mentor engineers. Tech Stack : - Golang, AWS (ECS/Fargate, RDS, S3, API Gateway, SQS/SNS, Glue), Microservices, REST APIs, GraphQL, PostgreSQL, MongoDB, PySpark, Solace, Terraform, CI/CD. Must-Have Skills : - 10+ years of software engineering/architecture experience with strong hands-on development. - Expertise in Golang, AWS, Microservices, Distributed Systems, and Data Pipelines.
