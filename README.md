# Go Jobs

Бесплатная лента вакансий для Go-разработчиков: Telegram-каналы, доски
удалённой работы, «Who is hiring» с Hacker News и карьерные страницы компаний в
одном месте. Дубли склеены, контакты рекрутеров открыты, регистрации нет.

Это аналог [Hirify](https://hirify.me), но без платной части и без сервера:
раз в день скрипт собирает вакансии и пересобирает статический сайт, который
бесплатно раздаёт GitHub Pages.

## Чем отличается от Hirify

| | Hirify | Go Jobs |
| --- | --- | --- |
| Источники | ~960 Telegram-каналов + карьерные сайты | 12 каналов + 6 досок + 29 компаний, список в `sources.yaml` |
| Telegram | официальный API (нужен аккаунт) | публичное веб-превью `t.me/s/…`, аккаунт не нужен |
| Разметка | каскад LLM (~$1000/мес) | правила: регулярки и словари, $0 |
| Дубли | векторы + LLM | общие контакты, компания + название, шинглы текста |
| Контакты | скрыты, открываются по лимиту | открыты всем |
| Обновление | каждые 2 часа | раз в день |
| Хостинг | Laravel + Nuxt + Typesense на сервере | статические файлы, фильтры в браузере |

## Быстрый старт

Нужен Go 1.25+.

```bash
make run     # собрать вакансии и сайт (первый раз ~2 минуты)
make serve   # открыть http://localhost:8090/gojobs/
```

`make run` обновляет `data/jobs.json` (вся история) и пересобирает `docs/`
(готовый сайт). Повторный запуск дочитывает только новое.

## Как это работает

```
sources.yaml ─► сбор (47 источников параллельно, с паузами к одному хосту)
                 │
                 ▼
         вакансия? про Go?     ← отсекает резюме, рекламу курсов, дайджесты
                 │
                 ▼
         разметка правилами    ← заголовок, компания, зарплата, формат, грейд,
                 │                английский, стек, контакты
                 ▼
         склейка дублей        ← один пост в пяти каналах = одна карточка
                 │
                 ▼
   data/jobs.json  ─►  docs/  (лента + страница на вакансию + RSS + sitemap)
```

Что стоит знать о правилах:

- **Подвалы каналов вычищаются.** Канал повторяет под каждым постом
  «подпишись на @…» и ссылки на соседние каналы. Такие строки и ручки
  выучиваются по частоте (окнами по 60 постов: подвалы меняются со временем)
  и не попадают в контакты. Email никогда не считается шумом.
- **Зарплата** понимает «от 250 до 350 тыс. ₽», «$4000–6000», «€60k–80k в год»,
  «1,5–2 млн тенге», USDT. Пересчёт в доллары в месяц идёт по фиксированному
  курсу (`internal/service/extract/salary.go`) и нужен только для фильтра.
- **Закрытые вакансии.** Если вакансия пропала с доски или сайта компании, она
  уходит из ленты. Посты в Telegram не «закрываются»: они уходят из ленты через
  `feed_days` дней.

## Источники

Все бесплатные и без ключей. Добавить источник — одна строка в `sources.yaml`:

```yaml
telegram:
  channels:
    - { name: rabota_golang, go_only: true }  # весь канал про Go
    - { name: geekjobs }                      # смешанный: пост должен упоминать Go
greenhouse: [cloudflare, grafanalabs]          # boards.greenhouse.io/<slug>
lever: [neon]                                  # jobs.lever.co/<slug>
ashby: [ramp, supabase]                        # jobs.ashbyhq.com/<slug>
```

Remote OK, Remotive, Himalayas, Jobicy и We Work Remotely разрешают
использовать свои ленты при условии ссылки на оригинал — она есть на каждой
карточке и странице. Remotive запрещает передавать их вакансии в Google Jobs,
поэтому разметки JobPosting для Google на сайте нет.

`api.hh.ru` закрыт для анонимных запросов (403), поэтому hh.ru здесь только
через каналы, которые его репостят.

Статус каждого источника за последний сбор виден на странице «О проекте».

## Публикация на GitHub Pages

Один раз:

```bash
gh auth login                                      # под тем аккаунтом, где будет сайт
gh repo create gojobs --public --source . --push
gh api -X POST repos/{owner}/gojobs/pages -f "source[branch]=main" -f "source[path]=/docs"
```

Сайт появится по адресу `https://<аккаунт>.github.io/gojobs/`. Если аккаунт не
`Beknur1003`, поправь `site.base_url` и `site.repo` в `sources.yaml` и запусти
`make build`. Для своего домена: `base_url: https://example.com`, `base_path: ""`.

## Каждый день

```bash
make daily           # собрать, закоммитить data/ и docs/, запушить
make install-daily   # запускать это каждый день в 09:00 через launchd
```

Если ноутбук спал в 09:00, launchd запустит задачу при пробуждении. Лог —
`logs/daily.log`.

macOS не даёт фоновым задачам читать `~/Desktop`, `~/Documents` и
`~/Downloads`, поэтому `make install-daily` откажется работать, пока репозиторий
лежит там. Перенеси его, например, в `~/gojobs`.

Сбору не нужен ИИ, поэтому его можно перенести в бесплатный cron GitHub Actions
и не зависеть от ноутбука.

## Разработка

```bash
make check                                   # gofmt, vet, golangci-lint, тесты с -race
go run ./cmd/gojobs run -only telegram:      # собрать только часть источников
go run ./cmd/gojobs run -cpuprofile cpu.prof # профиль, если сбор стал медленным
```

Слои: `cmd/gojobs` собирает всё вместе, `internal/handler/site` рендерит сайт,
`internal/service/{pipeline,extract,dedupe}` — логика, `internal/repository`
— источники, HTTP-клиент и хранилище, `internal/models` — доменные типы.
