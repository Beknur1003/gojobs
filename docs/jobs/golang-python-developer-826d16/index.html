Software Engineer – Golang, Python & Automation Experience: 2–4 years About the Role We are looking for a Software Engineer to develop backend services, automation frameworks, and device integration solutions for telecom and networking applications. The role involves working with Golang and Python to build APIs, manage automated workflows, integrate devices and external systems, and improve application reliability. We are looking for someone who writes maintainable code, investigates problems systematically, and can translate functional requirements into reusable software components. Key Responsibilities • • Develop and maintain backend services and REST APIs using Golang. • Build Python-based automation modules for device interaction, workflow execution, data processing, and result validation. • Develop capabilities for scheduling, concurrent execution, resource management, execution monitoring, and reporting. • Integrate backend services with web applications, databases, remote systems, and external APIs. • Automate device and equipment control through interfaces such as SSH, REST APIs, command-line tools, ADB, or serial communication. • Implement reliable communication between services, including timeout handling, retries, cancellation, and recovery from failures. • Troubleshoot issues across application services, automation scripts, databases, devices, and network interfaces. • Enhance existing codebases, resolve defects, and improve performance and maintainability. • Write unit and integration tests, participate in code reviews, and maintain technical documentation. • Support application deployment and debugging in Linux and containerized environments. Required Skills • • Golang development: Hands-on experience with structs, interfaces, packages, error handling, and backend service development. • Concurrency fundamentals: Understanding of goroutines, channels, synchronization, and safe handling of concurrent operations. • Python programming: Experience developing modular automation code, including exception handling, logging, subprocess execution, and data parsing. • API development: Experience designing and consuming REST APIs, including request validation, authentication, response handling, and troubleshooting. • Automation mindset: Ability to convert manual procedures into reusable, configurable, and reliable workflows. • Databases: Working knowledge of SQL, database integration, and basic schema design. • Linux and networking: Comfortable with Linux commands, shell scripting, processes, services, TCP/IP, HTTP/HTTPS, and network troubleshooting. • Software engineering fundamentals: Good understanding of data structures, modular design, Git, testing, and debugging. • Ability to understand an existing codebase and take ownership of assigned features from implementation through validation. Candidates should have practical exposure to both Golang and Python, with strong proficiency in at least one and the ability to contribute in the other. Preferred Skills • • Experience with telecom or network automation, including LTE/5G, RAN, UE/modem control, voice, SMS, or data testing. • Experience integrating mobile devices or modems using ADB, AT commands, or serial interfaces. • Familiarity with distributed services, asynchronous communication, message queues, or event-driven workflows. • Experience with Docker, Docker Compose, and CI/CD pipelines. • Familiarity with Angular and TypeScript for understanding UI-to-backend integration and contributing to UI changes. • Experience with packet analysis, log processing, or performance testing using tools such as Wireshark, tshark, and iPerf. • Exposure to test automation frameworks and automated reporting. Additional Advantage Experience with Wi-Fi connectivity and performance testing, access point/client automation, wireless packet analysis, or Wi-Fi 6/6E/7 is an advantage, but not mandatory. Desired Approach We value engineers who understand the problem before implementing a solution, build reusable components, handle failure scenarios thoughtfully, and remain comfortable learning unfamiliar technologies and devices.
