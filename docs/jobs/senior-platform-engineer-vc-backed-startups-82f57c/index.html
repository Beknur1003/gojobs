performance optimization • Automate cloud operations, disaster recovery, and security policies Common Qualifications While each startup has its own hiring criteria, many senior platform engineering roles in our network look for: • 5+ years of experience in platform engineering, DevOps, SRE, or cloud infrastructure • Strong proficiency with cloud platforms (AWS, GCP, Azure) and container orchestration (Kubernetes, Docker) • Experience with infrastructure-as-code (Terraform, Pulumi, CloudFormation) and configuration management (Ansible, Chef, Puppet) • Proficiency in CI/CD tooling (Jenkins, ArgoCD, GitHub Actions, CircleCI, Spinnaker) • Knowledge of distributed systems architecture, networking, and service mesh technologies (Envoy, Istio, Linkerd) • Expertise in observability
