Пожалуйста указывайте в сопроводительном письме Вашу локацию в РФ и ожидания по з.пл. в рублях! На данном проекте можно работать только с территории РФ! Мы ищем DevOps-инженера (от 7 лет опыта) для работы над поддержкой и развитием инфраструктуры крупного Big Data-решения. Проект предполагает работу с высоконагруженными распределёнными системами. Чем предстоит заниматься: • Документировать и наполнять базы знаний (Jira / Confluence); • Решать типовые задачи и обрабатывать инциденты совместно с архитекторами и экспертами; • Осуществлять подготовку deployment-приложений для установки их в кластер; • Автоматизировать рутинные процессы; • Поддерживать пользователей и помогать им в выполнении шаблонных задач; • Разрабатывать автоматизацию и средства мониторинга на Python и Golang. Требования (обязательные): • Опыт работы DevOps от 7 лет; • Установка и администрирование ОС Linux / Ubuntu / Talos; • Обновление прошивок сетевых карт, настройка бондинга; • Создание и поддержка кластеров: • Kubernetes (K8s); • Kafka; • Greenplum; • Cassandra; • Hadoop; • Apache Ozone; • Понимание принципов работы DevOps и процессов CI/CD; • Опыт работы с системой управления конфигурацией Ansible; • Опыт работы с оркестраторами; • Автоматизация на Python и bash; • Навыки работы с Docker; • Умение работать с git; • Опыт написания веб-сервисов (API) на Python; • Написание скриптов по автоматизации на Python; • Опыт работы с реляционными БД на уровне администратора. Условия работы: • Полная занятость с графиком 5/2; • Удалённый формат работы; • Работа в аккредитованной ИТ-компании; • Работа с современным стеком технологий и крупными игроками рынка; • Официальное трудоустройство по ТК РФ.
