We are looking for a skilled Backend Developer with 3-4 years of experience to join our dynamic team. If you are passionate about building scalable, high-performance backend systems and working in a collaborative environment, we would love to hear from you! Responsibilities: • Design, develop, and maintain RESTful APIs and microservices using Node.js . • Write clean, efficient, and well-documented code. • Implement and maintain NoSQL databases, particularly DynamoDB. • Ensure the performance, scalability, and security of backend systems. • Work on data-driven continuous improvement to enhance system efficiency. • Collaborate with front-end engineers to integrate user-facing elements with server-side logic. • Write unit and integration tests to ensure high code quality. • Participate in code reviews and contribute to process improvements. • Stay up-to-date with the latest technologies and trends in backend development. Requirements: • 3-4 years of experience in backend development. • Strong understanding of Node.js and experience building RESTful APIs. • Experience with NoSQL databases, particularly DynamoDB. • Good understanding of microservices architecture and design patterns. • Familiarity with unit testing frameworks and best practices. • Excellent problem-solving and debugging skills. • Ability to work independently and as part of a team. • Strong communication and collaboration skills. Good-to-Have Skills: • Experience with Java, Golang, or Python. • Knowledge of containerization technologies like Kubernetes. • Experience with cloud platforms like AWS or Google Cloud. • Familiarity with DevOps practices.
