Senior Backend Engineer (Golang & Python) Frisco, Texas (Hybrid) | Engineering About the Company Our client is a global cybersecurity company whose consumer and cloud security products protect millions of users worldwide. Role Summary Our client is seeking a Senior Backend Engineer to help design, build, and scale the backend services that power their security products and cloud platforms. In this role, you will develop high-performance microservices, APIs, and distributed systems using Golang and Python, working closely with product, platform, and security engineering teams. The ideal candidate is passionate about building reliable, scalable systems, has strong cloud-native development experience, and enjoys solving complex technical challenges in a fast-paced environment. Location This is a hybrid position based in Frisco, TX. You will be on-site as needed and work from your home office otherwise. Candidates must be within commutable distance of Frisco, TX. Relocation assistance is not offered. What You’ll Do • Design, develop, and maintain backend services and APIs using Golang and Python • Build scalable, resilient, and highly available microservices architectures • Develop and optimize RESTful and event-driven services supporting millions of customer interactions • Collaborate with product managers, architects, and cross-functional engineering teams to deliver new platform capabilities • Design solutions that leverage cloud-native technologies and modern infrastructure practices • Participate in code reviews, architecture discussions, and technical design reviews • Improve system observability through monitoring, logging, alerting, and performance analysis • Implement automated testing and CI/CD pipelines to ensure high-quality software delivery • Troubleshoot production issues and drive root-cause analysis for critical incidents • Contribute to engineering best practices, operational excellence, and continuous improvement Required Qualifications • Bachelor’s degree in Computer Science, Software Engineering, or a related field, or equivalent practical experience • 8+ years of professional software engineering experience • Strong experience developing backend systems in Golang • Strong experience developing applications and services in Python • Experience building and supporting distributed systems and microservices architectures • Strong understanding of API design, REST services, and asynchronous messaging patterns • Experience with Docker and Kubernetes • Experience with a public cloud platform (AWS, Azure, or GCP) • Strong understanding of Git, CI/CD pipelines, and modern development practices • Experience with relational and/or NoSQL databases • Excellent problem-solving and debugging skills Preferred Qualifications • Experience building large-scale SaaS or cloud security products • Experience with message brokers such as Kafka, RabbitMQ, or AWS SQS/SNS • Experience with Infrastructure as Code tools such as Terraform • Knowledge of observability tools such as Splunk, Datadog, Prometheus, or Grafana • Experience with security-focused applications, cybersecurity products, or endpoint protection platforms • Experience designing high-throughput, low-latency services • Familiarity with AI/ML-powered platforms, LLM integrations, or data processing pipelines Technical Environment Golang, Python, AWS / Azure, Docker, Kubernetes, Terraform, Kafka, REST APIs, GitHub / GitLab, CI/CD, PostgreSQL, MySQL, Redis, MongoDB, observability and monitoring tools What Success Looks Like Successful candidates will bring strong backend engineering fundamentals, ownership of production systems, the ability to work well in a collaborative environment, and a passion for building secure, scalable software that delivers exceptional customer experiences. We thank all applicants for their interest. Only candidates selected for an interview will be contacted.
