Наши клиенты — продуктовые команды из разных бизнес-юнитов компании. Сейчас мы активно развиваем свою платформу для создания автономных AI агентов-разработчиков, а также внедряем общие AI-решения для автономизации различных этапов цикла разработки. Ищем талантливого разработчика, которому интересны Agentic AI-системы, чтобы усилить нашу команду. Примеры задач: • Улучшение облачной системы Sandbox'ов, предоставляющих безопасное изолированное окружение для работы автономных AI-агентов • Разработка, улучшение и внедрение различных мультиагентных пайплайнов для автономизации SDLC • Создание системы бенчмарков для оценивания эффективности автономных AI-агентов для разработки • Улучшение качества работы автономных AI-агентов для разработки У нас интересно: • Наша команда участвует в ключевых проектах компании • Внутренние пользователи всегда рядом, сами приносят обратную связь и открыты к общению • Разнообразные задачи и отсутствие рутины • Широкие зоны ответственности и простор для творчества • Нет лишней бюрократии Задачи • Разработка платформы для создания автономных AI-агентов разработчиков • Разработка и внедрение мультиагентных пайплайнов для автономизации SDLC • Улучшение качества работы автономных AI-агентов разработчиков Требования • Опыт коммерческой разработки production ready AI-систем • Опыт или интерес к созданию инструментов для разработчиков: анализаторы кода, компиляторы, IDE-плагины, SWE AI-агенты и так далее • Уверенные навыки по работе с AI-агентами в разработке и их применению в реальных задачах • Понимание внутреннего устройства AI-агентов и базовых принципов agentic AI: prompt и context engineering для современных LLM, MCP, tool calling, etc. • Опыт разработки и поддержки кода на Go (основной язык), Python или переход на них за испытательный срок • Понимание принципов разработки ПО: подходы к тестированию и его виды, модели работы с Git, современные практики в CI/CD и всё остальное, с чем разработчики разных специализаций сталкиваются каждый день
