SDE 2 / 3 (Backend)

OmneNEST Technologies Mumbai опубликовано 18 сентября 2026

Middle

We are seeking high-performing Backend Engineers (SDE 2 and SDE 3) to architect, design, and scale high-throughput backend services powering our real-time systems. In this role, you will be solving complex, large-scale distributed systems problems serving millions of end users. If you thrive in fast-paced environments, love building systems from the ground up to handle massive scale, and possess strong computer science fundamentals, this role is for you. Responsibilities: • Architecture and Design: Architect, build, and maintain low-latency, high-concurrency microservices, data pipelines, and APIs. • Scalability and Performance: Optimize real-time data handling systems, ensuring high availability, fault tolerance, and efficiency in high-scale production environments. • Code Excellence: Write clean, modular, maintainable, and highly optimized code adhering to SOLID principles and core data structures and algorithms. • System Operations: Solve complex engineering bottlenecks across distributed caching, message queues, and persistent storage layers. • Technical Leadership (SDE 3): Mentor junior engineers, drive architectural discussions, conduct code reviews, and own critical modules end-to-end. Requirements: • SDE 2 3 to 5 years of software development experience. • SDE 3 4 to 7 years of software development experience. • Domain Focus: Strong experience building high-scale internet systems in B2C, e-commerce, fintech, or ride-sharing companies with real-time user-handling requirements. Core Technical Expertise: • Proficiency in Golang (goroutines, channels, memory layout, and concurrency models). • Note: Candidates with exceptional backgrounds in Java or C++ who demonstrate the ability to quickly adapt to Golang will also be considered. • Deep expertise in Low-Level Design (LLD), High-Level Design (HLD), and core Data Structures and Algorithms. • Distributed Systems: Hands-on experience with microservices architectures, event-driven messaging systems (e. g., Kafka, RabbitMQ), distributed caching (e. g., Redis, Aerospike), and relational/NoSQL databases. • Problem Solving: Analytical, structured mindset with a proven track record of solving non-trivial engineering problems.
