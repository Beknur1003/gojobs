Echelon Services is seeking a Senior Full-Stack Application Developer to design, build, and sustain secure, cloud-native applications in Azure Government. This role is responsible for end-to-end application delivery, spanning user interface development, backend services, APIs, microservices, and containerized cloud deployments. The ideal candidate understands how federal security and compliance requirements directly influence application architecture, code design, deployment pipelines, and operational practices, and is able to deliver solutions through a DevSecOps pipeline without introducing security or technical debt. The developer will work directly with government clients, stakeholders, and occasionally end users to define requirements, translate business and HR-focused needs into technical solutions, and implement high-quality, maintainable code. Responsibilities include developing and modifying application logic using .NET Core and Angular/TypeScript, building and integrating RESTful APIs and microservices (including Golang-based services), and deploying applications using containerized architectures on Azure Government platforms. This role requires active participation in DevOps and DevSecOps practices, including CI/CD pipeline development, automated testing, security scanning, configuration management, and infrastructure-aware application design. The developer is expected to design applications with security, compliance, scalability, and performance in mind from the outset, including awareness of STIG requirements, logging, auditing, identity management, and data protection controls that are critical in federal HR environments.
