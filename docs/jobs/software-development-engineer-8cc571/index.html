We are looking for passionate and driven Software Development Engineers (SDE 1 / SDE 2) to join our engineering team. The ideal candidate should have strong fundamentals in software development, problem-solving, database management, and building scalable applications. We are open to both Backend and Full Stack developers who enjoy solving real-world engineering challenges and building reliable, high-performance products. Key Responsibilities Design, develop, and maintain scalable, reliable, and high-performance applications. Build and maintain backend services, REST APIs, and microservices. Write clean, maintainable, reusable, and efficient code. Work with relational databases, optimize queries, and ensure data consistency. Identify performance bottlenecks and improve application scalability. Collaborate with product managers, designers, QA, and other engineering teams. Participate in code reviews, technical discussions, and architectural decisions. Debug production issues and take ownership of resolving them. Work with cloud infrastructure and deployment pipelines. Follow engineering best practices around testing, documentation, and code quality. Technical Skills • Backend Engineering Strong Proficiency In At Least One Backend Programming Language Node.js (preferred) PHP Go (Golang) Experience building REST APIs and backend services. Good understanding of asynchronous programming, concurrency, and event-driven architectures. Experience with MySQL or PostgreSQL. Understanding of database indexing, query optimization, transactions, and schema design. Knowledge of caching mechanisms such as Redis is a plus. Understanding of distributed systems and microservices architecture is an advantage. • Frontend Engineering (For Full Stack Candidates) Experience with React.js and Next.js. Strong understanding of JavaScript, HTML, and CSS. Experience building reusable components and responsive user interfaces. Understanding of state management, API integration, and frontend performance optimization. Knowledge of frontend rendering strategies such as SSR, CSR, and SSG is a plus. • Cloud & Infrastructure Hands-on experience with Google Cloud Platform (GCP). Familiarity with cloud services, deployment, and application hosting. Understanding of CI/CD pipelines and deployment workflows. Familiarity with Linux, Git, and basic server administration. Familiarity with CI/CD pipelines, GitHub Actions, and automated deployment workflows. What We're Looking For 2–4 years of hands-on software development experience. Strong problem-solving and analytical skills. Good understanding of Data Structures and Algorithms. Solid knowledge of OOPs, DBMS, and core software engineering concepts. Ability to write clean, efficient, and maintainable code. Ownership mindset and willingness to take responsibility for deliverables. Ability to work independently as well as collaboratively. Good to Have Experience working on high-traffic consumer-facing applications. Understanding of system design and application scalability. Experience With Redis, RabbitMQ, Elasticsearch, Or Other Distributed Technologies. Experience with monitoring, logging, and production debugging. Exposure to AI-assisted development tools and workflows.
