基础设施平台开发工程师（Infra Platform）

Tiger Brokers Beijing опубликовано 21 октября 2026

MySQLRedisKubernetesPython
关于团队 我们是公司的基础设施团队，负责建设支撑全公司研发、运维的内部平台。公司业务覆盖多个国家和地区，技术环境复杂，稳定性和合规要求高。你将参与核心基础系统的建设，你的工作会直接影响研发效率和系统稳定性。 岗位职责 1. 负责公司内部基础设施平台的架构设计、核心模块开发与长期演进，保证平台的可靠性和可扩展性。 2. 抽象公司的技术资源、组织结构与系统关系，设计统一、可扩展的数据模型，支撑上层运维、发布、监控、成本等系统。 3. 对接多种基础设施环境与第三方平台，实现资源信息的自动采集、同步与一致性校验。 4. 提供稳定、规范的 API 与集成能力，推动平台在各团队落地。 5. 与 SRE、研发、安全、财务等团队协作，把实际需求转化为平台化方案。 1. 本科及以上学历，计算机相关专业，3-5 年后端或平台类系统开发经验。 2. 熟练掌握 Golang 或 Python，两者都熟悉优先，具备良好的工程化意识。 3. 有内部平台、运维平台或基础设施管理类系统的设计和开发经验，具备较强的数据建模和系统抽象能力。 4. 熟悉 MySQL、Redis、消息队列等常用存储和中间件，熟悉主流云平台的核心服务和 API。 5. 沟通顺畅，有主人翁意识，能独立推进跨团队项目。 加分项 1. 有从 0 到 1 主导内部基础平台建设，或对已有平台做重构的经验。 2. 熟悉 Kubernetes 生态，有 Operator、控制器或云原生相关开发经验。 3. 有同时管理多云与自建机房环境的经验。 4. 有金融、券商或其他强合规行业的从业经验。 5. 英文读写流畅，能在多地区团队中协作。 我们提供 具有竞争力的薪酬与福利；面向全球市场的业务和复杂的技术挑战；技术氛围开放的团队，你对平台方向有较大的话语权。
