Principal Software Engineer Web Application Firewall (WAF) | Golang and (c OR c++) About the Role: We are looking for an experienced Principal Software Engineer to lead the architecture, design, development, and optimization of a high-performance Web Application Firewall (WAF) platform. This is a hands-on technical leadership role where you'll drive engineering excellence, mentor teams, and collaborate across product, security, and engineering functions to build scalable cybersecurity solutions. Key Responsibilities: - Lead the architecture, design, development, and optimization of a large-scale Web Application Firewall (WAF) platform. - Conduct technical design discussions and code reviews, ensuring high standards for security, scalability, performance, and maintainability. - Identify and resolve performance bottlenecks across networking, application, and infrastructure layers. Required Skills & Experience: - 13+ years of software engineering experience building large-scale, distributed, high-performance systems. - Expert-level proficiency in Go (Golang) with strong knowledge of concurrency, memory management, and performance optimization. - Deep understanding of HTTP/HTTPS, TCP/IP, DNS, TLS/SSL, and networking fundamentals. - Hands-on experience with NGINX, Envoy, reverse proxies, Web Application Firewalls (WAF), or security middleware. - Strong experience with Kubernetes, containerized applications, and cloud-native architectures. - Experience with Application Delivery Controllers (ADC), load balancers, and distributed system design patterns. - Solid understanding of application security concepts, including OWASP Top 10, secure development practices, and web security threats. - Strong problem-solving and debugging skills in production-scale environments. - Proven experience in technical leadership, architecture ownership, code reviews, and mentoring engineering teams.
