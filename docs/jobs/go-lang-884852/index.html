【職務概述】 1. 我們正在尋找具備高併發分散式架構經驗的資深後端軟體工程師（Senior Backend Engineer），加入我們的遊戲核心研發團隊。 2. 具備優秀的工程架構思維與主動當責的交付態度，使用 Golang 負責 Game Server、Transaction Server、B2B API 整合及各子系統間服務架構等後端研發工作。 【個人特質】 1. 具備團隊合作精神 2. 樂於學習與成長 3. 熱衷於後端效能優化與伺服器品質 4. 勇於探索新技術 【工作內容】 1. 核心即時遊戲伺服器/串流伺服器架構設計與研發。 2. 設計與研發高容錯的有限狀態機（FSM）、低延遲雙向通訊協定，精準同步前後端狀態、全場玩家廣播。 3. 設計與研發高併發、巨量交易系統，確保玩家即時掌握遊戲狀態與資料最終一致性。 4. 設計與研發對接外部 B2B API，具備重試、熔斷、限流與防竄改簽章機制的 API Gateway。 5. 設計與研發高併發資料架構（OLTP 與 OLAP）與即時分析管線，善用 Redis、建立日誌與大量寫入管線，設計高效能的分區與排序鍵，支援億級交易量的秒級多維度統計、風控報表與 CRM 查詢。 6. 負責系統效能剖析、容災機制研發、指標監控與自動告警，確保系統具備高度可觀測性。 7. 主動推動程式碼審查、單元測試與壓力測試，落實模組化與高內聚、低耦合的工程規範。 【必備條件】 1. 4 年以上後端研發經驗，深耕 Golang 實務開發；具備線上高併發（High Concurrency）、分散式系統的生產環境實際導入與上線經驗。 2. 深諳 Go 語言底層機制，包括 Goroutine 排程模型（GMP）、Channel 最佳實踐、Memory Allocation、GC 行為與併發安全（Race Condition 偵測與排查）。 3. 深度掌握 Redis，具備實務撰寫 Lua 腳本保障原子性操作、避免快取雪崩/擊穿/穿透的架構經驗。 4. 熟練使用主流 Message Queue（Kafka、RabbitMQ 或 NATS）處理非同步解耦、尖峰流量削減與事件驅動架構。 5. 熟悉關聯式資料庫（PostgreSQL / MySQL）之交易隔離等級與鎖定機制，且具備 ClickHouse 實戰經驗，能針對大規模時序/日誌資料進行架構設計與查詢效能調校。 6. 深入理解分散式交易處理思維，熟練處理冪等性設計（Idempotent Design）、防重放攻擊與帳務核對邏輯。 7. 精通 TCP、WebSocket、HTTP/2、gRPC 協定之底層原理與網路 I/O 模型。 8. 具備高度當責精神（Ownership）、邏輯清晰，並能冷靜且系統化地排查線上疑難雜症（Troubleshooting）。 9. 具備跨領域溝通能力、良好的同理心與協調技巧。 【加分條件】 1. 具備 iGaming 產業經驗，尤其是高併發遊戲開發經驗。 2. 具備 Seamless / Transfer Wallet 整合經驗，熟悉系統串接規範。 3. 具備 Docker、Kubernetes（K8s）、CI/CD 自動化管線與微服務架構治理經驗。 【技術堆疊一覽（Tech Stack）】 1.
