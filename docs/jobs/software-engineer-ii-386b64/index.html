About NCR VOYIX NCR Voyix Corporation (NYSE: VYX) is a global platform-powered leader in unified commerce for shopping and dining. Combining a flexible, intelligent platform with end-to-end payments capabilities and services developed through its deep industry experience, NCR Voyix empowers retailers and restaurants to accelerate new possibilities for their operations, experiences and business outcomes. NCR Voyix is headquartered in Atlanta, Georgia, and serves customers in more than 35 countries worldwide. Job Summary We are seeking a motivated and detail-oriented Software Engineer II to contribute to the development and maintenance of modern retail and POS applications. The ideal candidate will have hands-on experience with Go backend development and/or React frontend development, a solid understanding of APIs and databases, and the ability to deliver complete features with guidance from senior engineers. This role requires strong collaboration, ownership of assigned deliverables, and the ability to troubleshoot issues across application and service layers within a microservices-based environment. Job Responsibilities • Develop and maintain application features using Go and/or React, following established architectural patterns and coding standards. • Implement complete feature functionality across backend and frontend layers, including service, repository, handler, component, and hook-based implementations. • Create and maintain unit and integration tests to ensure application reliability and feature correctness. • Debug and resolve issues within assigned application areas, including test failures, application defects, and integration problems. • Develop and consume APIs by following established request/response contracts, error-handling standards, and authentication mechanisms. • Perform basic SQL queries and data validation to verify business logic and application functionality. • Work effectively within Docker-based local development environments, identifying and resolving common setup and configuration issues. • Collaborate with engineers, quality teams, and product stakeholders to deliver feature enhancements and bug fixes. • Participate in code reviews, incorporate feedback, and maintain high-quality coding practices. • Follow established agile development processes, task management workflows, and release procedures. • Assist in troubleshooting issues across service interactions and application layers in distributed systems. • Contribute to improving development quality through automated testing, code quality practices, and engineering best practices Required Qualifications • Bachelor's degree in computer science, Software Engineering, Information Technology, or a related field. • 4+ years of software development experience in enterprise or commercial applications. • Strong proficiency in either Go (Golang) or React, with working knowledge of the other technology. • Experience implementing complete features following common architectural patterns such as handler/service/repository or component/hook-based designs. • Experience writing and maintaining unit tests and integration tests. • Understanding of API fundamentals, including REST principles, request/response contracts, HTTP status codes, error handling, and authentication/token-based workflows. • Basic proficiency with SQL and database validation techniques. • Experience working in Docker-based development environments and troubleshooting common configuration issues. • Ability to debug application issues and identify root causes within assigned ownership areas. • Strong communication skills and ability to collaborate effectively within cross-functional teams. • Experience participating in code reviews and following established coding standards and development workflows. Preferred Qualifications • Exposure to Playwright and API automation concepts. • Experience troubleshooting and debugging interactions between BFF layers and downstream services within a microservices architecture. • Familiarity with observability tools and practices, including structured logging, distributed tracing, correlation IDs, monitoring, and metrics analysis. • Understanding of CI/CD concepts and modern software delivery practices. • Exposure to retail, commerce, POS, or transaction-based application development environments This job description outlines the primary duties and responsibilities of the role and is not intended to be exhaustive.
