Location: Bangalore, India (Mahadevapura) Experience: 7 to 15 years Work Mode: Work from Office Position Type: Permanent Job Description: Software Engineer / Senior Engineer (Golang & Python) Location: Bangalore, Karnataka (Onsite / Hybrid as per company policy) Total Experience: 7 to 15 Years Relevant Experience: Minimum 7+ years of hands-on experience with Golang, Microservices, Networking, and Cloud Native technologies. Key Responsibilities • Core Development: Design, build, and maintain efficient, scalable, and reliable backend services using Golang. • Microservices Architecture: Architect and implement high-performance, loosely coupled microservices. • Cloud-Native Solutions: Develop and deploy applications in cloud-native environments (using Docker, Kubernetes, etc.). • Networking Integration: Work with networking protocols, API gateways, service meshes, and backend data paths. • Code Quality & Maintenance: Write clean, readable, well-tested code (unit, integration) and participate in active code reviews. • Collaboration: Partner with cross-functional teams to define architecture, troubleshoot complex issues, and optimize application performance.
