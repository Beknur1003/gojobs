Senior Engineer - Embedded System Software Abu Dhabi, UAE﻿ We are looking for a Senior Engineer - Embedded System Software to join a highly skilled engineering team developing next-generation secure satellite communications technology for mission- critical government and defence applications. This is a hands-on engineering role focused on low-level software development for a next-generation satellite modem platform. You'll play a key role in developing embedded Linux drivers, firmware components and system software, working closely with hardware, platform and systems engineers to deliver robust, production-ready embedded solutions. What You'll Do • Develop and maintain embedded Linux drivers and firmware components for a next-generation satellite modem platform • Design, implement and maintain low-level system software, including boot management and platform utilities • Develop Golang based system tools to replace legacy scripting and improve platform reliability • Integrate software with ARM-based hardware platforms, including NXP Layerscape and Qualcomm processors • Develop and maintain Board Support Packages (BSPs), device drivers and hardware abstraction layers • Write unit tests and functional tests for firmware and low-level software components • Support board bring-up, hardware integration, debugging and system validation • Maintain build systems, cross-compilation toolchains and CI/CD pipelines • Produce technical documentation and collaborate closely with hardware, systems and software engineering teams throughout the product lifecycle What We're Looking For • Bachelor's degree in Computer Science, Electrical Engineering or a related discipline • 7+ years' experience developing embedded software, firmware or low-level Linux systems • Strong experience with Embedded Linux and ARM-based platforms • Proven experience developing Linux device drivers, Board Support Packages (BSPs) and system software • Strong programming skills in C/C++, with experience using Go (Golang) for systems development considered highly desirable • Experience with bootloaders, Linux boot processes and system bring-up • Experience with hardware interfaces such as SPI, I²C, UART and USB • Familiarity with cross-compilation environments, Make, CMake or Bazel build systems • Experience debugging low-level software and integrating embedded software with hardware platforms • Excellent analytical, problem-solving and communication skills • Experience within telecommunications, networking, wireless communications, satellite or defence environments would be advantageous Apply directly or get in touch for a confidential discussion. ﻿PLEASE NOTE THIS ROLE REQUIRES RELOCATION TO ABU DHABI﻿
