Нам нужен человек, который не просто «смотрит логи», а умеет разобраться, как работает сервис, проследить прохождение запроса между системами и понять, где и почему что-то пошло не так. • Разворачивать и настраивать сервисы в Linux-среде • Сопровождать сервисы и контролировать их корректную работу • Анализировать логи приложений и находить причины ошибок • Разбираться в интеграциях между системами и API • Работать с XML и JSON, понимать структуру запросов и ответов • Тестировать и диагностировать API через Postman • Работать с PostgreSQL: писать SQL-запросы, искать и анализировать данные • Писать и дорабатывать небольшие скрипты и утилиты на PHP для автоматизации и решения технических задач • Работать с Linux: файловая система, процессы, права доступа, сеть, сервисы, конфигурации и логи • Участвовать в разборе инцидентов и технических проблем • Взаимодействовать с разработчиками и смежными командами • Вести техническую переписку: четко описывать проблему, предоставлять необходимые данные и фиксировать результаты решения • Поддерживать техническую документацию в актуальном состоянии Требования Нам подойдет специалист, который: • уверенно работает с Linux и понимает его архитектуру • умеет читать и анализировать логи • понимает HTTP/HTTPS и принципы работы REST API • уверенно работает с Postman • умеет читать и анализировать XML и JSON • знает PostgreSQL и умеет самостоятельно составлять SQL-запросы • имеет опыт работы с PHP и golang. может написать скрипт для решения прикладной задачи • понимает базовые принципы сетевого взаимодействия между сервисами • способен самостоятельно локализовать проблему и определить, на стороне какого компонента она возникает • умеет понятно формулировать технические вопросы и грамотно вести деловую переписку • не боится разбираться в незнакомых системах и чужом коде Будет плюсом опыт работы с Docker, Git, CI/CD, Nginx, Bash, системами мониторинга и централизованного сбора логов
