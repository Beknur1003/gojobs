DevOps Engineer

TransferChain Switzerland опубликовано 14 сентября 2026

KubernetesDockerAWSAzureMicroservicesLinuxCI/CDPythonJavaBlockchain
TransferChain is seeking a DevOps Engineer who wants to use modern tools to develop the core tooling we use to test, monitor, secure, and stabilize our growing blockchain based cloud network. We will handle large amounts of data exchange each day. As a result, rigorous security practices, thorough testing, and rock-solid infrastructure are essential. TransferChain enables users to store, process and distribute their data without compromising their privacy and security. Additional information about our company will be shared upon the first meeting. We’re hiring engineers to work on a bunch of exciting projects, responsibilities include: • Build and maintain CI/CD pipelines, focusing on automation, monitoring and configuration management. • Reduce friction for development teams with automation of manual procedures • Work closely with development team to build, maintain and improve the systems and processes used to test releases for security, scale and performance issues • Advancing our testing environment that can simulate network performance with thousands of machines across variable network conditions • Developing sophisticated diagnostic systems that continuously monitor network performance and provide visibility into network health • Designing robust, self-healing systems that ensure the health and stability of a fledgling cloud network under intense network loads or highly adversarial environments • Cooperation with the Development team in building and deployment of TransferChain software releases. • Monitoring and maintenance of TransferChain Network services and IT infrastructure. • Work closely with the senior system engineers to influence decision making and implementation efforts Experience Requirements • Minimum 3 years of experience in systems administration. • Experience with containerization technologies, such as Docker and Kubernetes • Working knowledge of version control systems like Git, GitHub, Bitbucket. • Proficiency in one or more of the following programming languages: Golang, Python and Java is a plus • Knowledge and experience of the technologies that enable the software to build automation and deployment • Good understanding of concepts like CI/CD, configuration management, cloud platforms, version control, automation, monitoring, analytics, containerization, and microservices architecture • High comfort in working with Linux environment and typical sysadmin tools, • Advanced scripting skills (bash, python) with the ability to use various compound data structures • You crave the opportunity to work alongside the best engineers in this space • You enjoy being a part of a feedback culture with shared code ownership and really wants to make a difference worldwide • Exceptional knowledge of Linux, including security aspects, networking and virtualization (3 years minimum) Nice to have • License Degree in Engineering or Computer Science is a plus. • Being passionate about Blockchain technology is a plus • Ability to work in a team, and experience in a startup environment is a plus • Experience with cloud providers, such as AWS, Azure, Hetzner etc is a plus.
