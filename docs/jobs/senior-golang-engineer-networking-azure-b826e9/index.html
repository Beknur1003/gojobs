Senior Golang Engineer (Networking & Azure)

Kim jesteśmy? Jesteśmy ITSG Global, firmą software’ową, która od 2007 roku tworzy i rozwija rozwiązania technologiczne dla międzynarodowych klientów. Realizujemy projekty m.in. w obszarze systemów backendowych, platform IoT, rozwiązań chmurowych oraz AI. Obecnie poszukujemy Senior Software Engineera, który dołączy do zespołu rozwijającego nowoczesną platformę umożliwiającą bezpieczny, zdalny dostęp do maszyn przemysłowych na całym świecie. Szukamy osoby z mocnym doświadczeniem w programowaniu oraz networkingu, która dobrze rozumie komunikację sieciową, potrafi projektować bezpieczne połączenia pomiędzy systemami i chce pracować przy rozwoju rozwiązania opartego na Go. Nie musisz być ekspertem w Go od pierwszego dnia. Jeśli masz solidne doświadczenie developerskie w C++, Rust, Pythonie lub Javie, bardzo dobrze znasz networking i potrafisz efektywnie wykorzystywać narzędzia AI w codziennej pracy, również chętnie Cię poznamy. O projekcie: Wspólnie z naszym niemieckim partnerem technologicznym rozwijamy nową generację platformy Remote Service, umożliwiającej bezpieczną komunikację i zdalny dostęp do maszyn przemysłowych zlokalizowanych na całym świecie. Projekt obejmuje całkowite przepisanie istniejącego rozwiązania i budowę nowej platformy w podejściu greenfield, z wykorzystaniem nowoczesnych technologii backendowych oraz sieciowych. Kluczowym elementem systemu jest architektura Zero Trust Network Access (ZTNA) oparta na OpenZiti. Pozwala ona na bezpieczne łączenie urządzeń brzegowych (edge devices) z usługami backendowymi bez konieczności udostępniania publicznych endpointów. Twoim głównym zadaniem będzie rozwijanie aplikacji w Go, odpowiedzialnej za komunikację sieciową pomiędzy środowiskiem lokalnym a urządzeniami edge. Aplikacja będzie również realizować wewnętrzną logikę biznesową i integrować się z innymi usługami za pomocą REST API oraz Azure Event Grid. Dołączysz do niewielkiego zespołu, który odpowiada za rozwój platformy – od agentów działających na urządzeniach, przez mikroserwisy backendowe, po frontend, infrastrukturę chmurową i testy end-to-end. To projekt, w którym będziesz mieć realny wpływ na projektowanie i rozwój rozwiązania, a także możliwość mierzenia się z ciekawymi wyzwaniami na styku software developmentu, networkingu i bezpieczeństwa. Zakres zadań w projekcie: • Projektowanie i rozwój aplikacji w języku Go, odpowiedzialnej za bezpieczną komunikację pomiędzy środowiskiem lokalnym a urządzeniami edge. • Implementacja rozwiązań sieciowych i mechanizmów zdalnego dostępu z wykorzystaniem architektury Zero Trust. • Rozwijanie logiki biznesowej aplikacji oraz integracji za pomocą REST API i Azure Event Grid. • Projektowanie i optymalizacja komunikacji pomiędzy urządzeniami, usługami backendowymi i środowiskiem chmurowym. • Współpraca z zespołem przy projektowaniu architektury systemu, przepływów danych oraz modeli danych. • Diagnozowanie problemów technicznych, optymalizacja wydajności i niezawodności aplikacji. • Tworzenie testów jednostkowych i integracyjnych oraz udział w code review. • Efektywne wykorzystywanie narzędzi AI-assisted coding w codziennym procesie programowania. • Współpraca z dedykowanym zespołem infrastrukturalnym w obszarach cloud i DevOps. Oczekiwane kompetencje: • Minimum 4 lata doświadczenie komercyjne w rozwoju oprogramowania, preferowane w Go (Golang), ale rozważymy również kandydatów z mocnym doświadczeniem w C++, Rust, Pythonie lub Javie. • Bardzo dobra znajomość networkingu, w szczególności zagadnień związanych z komunikacją sieciową, protokołami i bezpiecznym dostępem zdalnym. • Doświadczenie w projektowaniu lub implementacji rozwiązań komunikacji sieciowej. • Znajomość zagadnień cloud/edge networking oraz zasad komunikacji pomiędzy środowiskami lokalnymi, urządzeniami edge i usługami chmurowymi. • Rozumienie podstaw architektury Zero Trust i bezpiecznej komunikacji sieciowej. • Umiejętność projektowania i rozwijania aplikacji z wykorzystaniem REST API. • Praktyczne doświadczenie w efektywnym korzystaniu z narzędzi AI wspierających programowanie, np. Claude Code. • Bardzo dobre umiejętności analityczne, samodzielność w rozwiązywaniu złożonych problemów technicznych i proaktywne podejście do pracy. • Umiejętność współpracy w niewielkim zespole developerskim oraz otwartość na dzielenie się wiedzą. Mile widziane: • Praktyczne doświadczenie z Go (Golang), szczególnie przy rozwoju aplikacji sieciowych, backendu lub agentów. • Znajomość OpenZiti lub podobnych technologii, takich jak OpenVPN, Tailscale czy WireGuard. • Doświadczenie z PKI, autoryzacją urządzeń i architekturą Zero Trust. • Znajomość Microsoft Azure, Azure Kubernetes Service (AKS) lub Terraform. • Doświadczenie z Azure Event Grid, Azure Event Hubs, MQTT lub innymi rozwiązaniami komunikacji asynchronicznej. • Praktyczna znajomość monitoringu, logowania i distributed tracing. • Znajomość TypeScript, PostgreSQL lub Angular. • Doświadczenie w projektach Industrial IoT, systemach edge computing lub rozwiązaniach do zdalnej komunikacji z urządzeniami. Warunki współpracy projektowej: • stawka: 150-200 zł netto+vat/h • Możliwość pracy 100% zdalnie, hybrydowo lub z biura w Warszawie. • Udział w projekcie greenfield, obejmującym budowę nowej generacji platformy wykorzystywanej w środowiskach przemysłowych. • Realny wpływ na rozwój rozwiązań technicznych oraz architekturę platformy. • Bezpośrednią współpracę z niewielkim zespołem developerskim i międzynarodowym partnerem technologicznym. • Możliwość pracy nad rozwiązaniem łączącym backend development, networking, security i cloud-native technologies. • Dodatkowo: możliwość korzystania z lekcji języka angielskiego, karty MultiSport, prywatnej opieki medycznej, wydarzeń integracyjnych i budżetu szkoleniowego.
