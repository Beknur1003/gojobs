Job Summary We are seeking a Cloud Software Engineer to design, develop, and maintain scalable, secure, and highly available cloud-native services. This role focuses on building backend applications, APIs, microservices, and event-driven systems that support critical business capabilities and integrate with internal and external platforms, including cloud-connected devices and IoT ecosystems. As an Engineer, you will work within a collaborative engineering team to deliver reliable, production-quality software using modern cloud technologies and engineering practices. You will contribute to technical design, implement new features, maintain existing services, and participate in the full software development lifecycle, including testing, deployment, monitoring, and production support. The ideal candidate has strong backend software engineering fundamentals, experience with AWS cloud services, and the ability to independently deliver well-designed solutions while collaborating effectively across engineering teams. Experience with IoT platforms or connected devices is beneficial but not required. integrations between internal services, external APIs, and third-party cloud platforms. • Develop scalable, event-driven applications using asynchronous messaging, queues, and distributed processing patterns. • Develop and maintain backend services that support connected devices, including device provisioning, state management, telemetry processing, and cloud-to-device communication. • Collaborate with architects, product owners, and engineering teams to define technical requirements, API contracts, data models, and service integration points. • Translate functional and technical requirements into maintainable, well-tested software solutions. • Design and implement solutions that emphasize scalability, reliability, performance, security, and operational efficiency. • Develop automated unit and integration tests and contribute to CI/CD pipelines that support reliable and frequent deployments. • Implement and maintain observability capabilities, including application metrics, structured logging, distributed tracing, dashboards, and alerting. • Troubleshoot complex issues across distributed systems, identify root causes, and implement sustainable solutions. • Maintain and modernize existing services, including framework upgrades, dependency management, technical debt reduction, and performance optimization. • Apply secure software development practices, including authentication, authorization, encryption, secrets management, and vulnerability remediation. • Participate in technical design discussions, code reviews, and architectural evaluations to improve software quality and engineering practices. • Collaborate with cross-functional teams to ensure seamless integration between services and platforms. • Create and maintain technical judgment and discretion in matters of significance. • Regular, consistent, and punctual attendance. Required Qualifications • 5+ years of professional software engineering experience developing backend applications, services, or distributed systems. • Strong programming skills in Go (Golang) or another modern backend programming language, with the ability to develop and maintain production-quality Go services. • Experience developing and operating cloud-native applications on AWS. • Experience designing and implementing RESTful APIs, microservices, and service-to-service integrations. • Understanding of distributed systems concepts, including asynchronous processing, fault tolerance, scalability, and resiliency. • Experience with AWS services such as Lambda, SQS, SNS, DynamoDB, API Gateway, or similar cloud technologies. • Experience with NoSQL and/or relational databases, including data modeling and query optimization. • Familiarity with automated testing, version control, CI/CD pipelines, and modern software development practices. • Experience troubleshooting and supporting applications in production environments. • Understanding of application security principles and secure software development practices. • Strong analytical and problem-solving skills, with the ability to independently investigate and resolve technical challenges. • Effective communication and collaboration skills, including the ability to work across engineering teams and contribute to technical discussions. Preferred Qualifications • Professional experience developing backend services using Go (Golang). • Experience with Node.js, particularly maintaining or modernizing existing backend applications. • Hands-on experience with AWS serverless architectures and services such as Lambda, DynamoDB, SNS, SQS, and EventBridge. • Experience designing and implementing event-driven architectures and asynchronous workflows. • Experience integrating with third-party APIs, SaaS platforms, or external cloud services. • Experience with Internet of Things (IoT) platforms, connected devices, or smart home technologies. • Familiarity with IoT device lifecycle management, including device onboarding, provisioning, configuration, state synchronization, and telemetry processing. • Understanding of IoT communication patterns and protocols, such as MQTT, WebSockets, or HTTP-based device integrations. • Experience with Infrastructure as Code (IaC) tools such as Terraform or AWS CloudFormation. • Familiarity with containerization technologies such as Docker and container orchestration platforms. • Experience with monitoring and observability tools such as Grafana, Prometheus, CloudWatch, or Datadog. • Experience with high-volume, highly available distributed systems. • Familiarity with performance optimization, scalability testing, and cloud cost optimization. • Experience working in Agile development environments.
