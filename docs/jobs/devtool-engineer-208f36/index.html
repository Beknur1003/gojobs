Join Barclays as a DevTool Engineer role, where to design, develop and improve software, utilising various engineering methodologies, that provides business, platform, and technology capabilities for our customers and colleagues At Barclays, we don't just anticipate the future - we're creating it. To be successful in this role, you should have below skills: • Hands-on implementation of changes; from creating solution and writing code; to delivering release into production. • Proficient in software engineering with a focus in Java, Golang, Spring & Spring Boot frameworks and with databases such as Oracle, SQL Server, or PostgreSQL. • Experience in utilizing DevOps tools such as Git, and modern application development. • Write and manage configuration in Developer Tooling to control how software tools are installed and configured on end user devices • Create Docker images
