NAMS2 - Software Engineer

Crown Innovations Mountain View, CA, us опубликовано 18 августа 2026

DockerAWSGrafanaMicroservicesLinuxCI/CDPythonJavaReact
Crown is looking for an experienced Software Engineer to work on the NAMS-2 project in Mountain View, CA to: • Develop advanced air mobility applications and micro-services software to meet research objectives and user requirements • Improve the advanced air mobility software based on user feedback from integration tests, real-time simulations, and flight demonstrations. • Manage and track software development tasks through regular team tag-ups and with the Atlassian tool suite (Confluence, JIRA, and Bitbucket). New features and bug fixes are logged as JIRA issues for resolution by the software team. The engineer audits the JIRA issues to ensure that proper levels of details are included for use in documentation such as software release notes and for the testers of the software. • Perform testing, integration, and deployment tasks for collaboration demonstrations involving multiple NASA organizations and aviation partners. Summarize data collection from the demonstration. • Create and update DevSecOps automation to configure, build, deploy, and audit the advanced air mobility software for the collaboration demonstration system. Required: • Bachelor's or Master's degree in Engineering, Data Science, Human Factors Engineering, Computer Science, or a related field. • Minimum 5+ years of relevant experience in JavaScript and Java. • Expertise in software architecture, object-oriented design, and unit testing. • Strong problem-solving skills and ability to work in a fast-paced environment. • Excellent communication skills, both written and verbal. • Experience with version control systems, preferably Git. Preferred: • Relevant experience in GoLang, Grafana, Python, Docker, React, AWS, cloud computing, visualization tools, and Linux. • Experience with Atlassian tools such as Confluence and JIRA. • Knowledge of advanced air mobility concepts and applications. • Familiarity with DevSecOps practices and tools. • Experience with microservices architecture and API development. • Understanding of agile development methodologies. • Experience with real-time simulation systems. • Familiarity with aviation industry standards and regulations. • Knowledge of data analysis and visualization techniques. • Experience with continuous integration and continuous deployment (CI/CD) pipelines. We seek passionate candidates eager to make a real-world impact on millions of Americans. Your work will enhance travel safety and efficiency daily. If making a difference drives you, this is your opportunity. The salary range is $160,000 to $190,000.
