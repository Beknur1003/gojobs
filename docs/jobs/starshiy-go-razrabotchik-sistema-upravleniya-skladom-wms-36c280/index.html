Привет! Это команда системы управления складом (WMS). WMS — это высоконагруженная система, состоящая из нескольких десятков разных микросервисов, отвечающая за качественную, своевременную и удобную доставку товаров от Ozon по всей России и СНГ. То, что мы разрабатываем и тестируем, можно «пощупать» руками, есть возможность посетить склад и посмотреть, как всё реально работает. Основное направление нашей команды — сервисы управления ресурсными лимитами складских процессов и справочники складов. Система является частью ядра складской вертикали. Сервис управления лимитацией ресурсов складских процессов, справочник складов и динамический калькулятор времени сборки заказов на основе реальной производительности и загрузки склада. Наш стек Разработка: Go. Хранение данных: PostgreSQL, ClickHouse, Memcached, Kafka. Логирование/метрики: OpenTracing + Jaeger, Prometheus + Grafana, Graylog. Протоколы: HTTP (HTTP/2), proto, gRPC. Инструменты: GitLab CI/CD, Allure, Docker, Kubernetes, Jira. Вы будете • Разрабатывать сервисы для управления, планирования и автоматизации складских процессов лимитирования. • Участвовать в создании архитектуры новых проектов. • Развивать существующие системы и участвовать в их интеграции. • Участвовать в разработке продукта, влияющего на складскую вертикаль. Нам важно • Опыт промышленной разработки от 3 лет. • Умение работать в команде из разработчиков, аналитиков, тестировщиков, продактов. • Навык находить простые решения для сложных задач. Будет плюсом • Опыт работы с gRPC. • Знание инструментов мониторинга (Prometheus, Grafana). • Понимание принципов работы распределенных систем. • Опыт проектирования хранения баз данных. • Опыт автоматизации логистических процессов.
