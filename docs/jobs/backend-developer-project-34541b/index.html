Backend Developer (Project)

Kimia Farma Jakarta опубликовано 17 ноября 2026

Офис Контракт / B2B
PostgreSQLgRPCDockerMicroservicesPHPNode.js
Level: Senior (± 3–5 tahun). Sekaligus berperan sebagai backup teknis bagi Senior Backend / Lead / Analyst untuk mengurangi risiko ketergantungan pada satu orang. Tanggung Jawab : • Mengimplementasikan service backend untuk modul pendukung (tunjangan, welfare, slip gaji, pinjaman, reimbursement, santunan) dan membantu modul inti sesuai arahan Lead. • Membangun endpoint API, integrasi antar service, validasi data, dan unit test. • Mendukung penyiapan data, query, dan perbaikan bug selama development dan testing. Kualifikasi Wajib (Must-have) : • Minimal 3 tahun pengalaman backend produksi dengan PHP Laravel, Golang, atau Node.js. • Penguasaan PostgreSQL yang kuat: desain skema, query kompleks, relasi, migrasi, transaksi, dan presisi numerik. • Berpengalaman pada arsitektur microservice (REST/gRPC, integrasi antar service) dan mampu mengambil keputusan teknis mandiri. • Ketelitian tinggi pada data numerik & validasi; disiplin menulis unit & integration test. • Mampu menggantikan sebagian tanggung jawab teknis Lead bila diperlukan. • Pengalaman pada sistem payroll, HR, atau keuangan. Diutamakan (Nice-to-have) : • Familiar dengan Docker dan dasar konsep payroll Indonesia (BPJS, PPh 21, THR).
