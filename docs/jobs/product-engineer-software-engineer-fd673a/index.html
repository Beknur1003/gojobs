About the Role This is a full-stack product engineering role at a small, fast-moving fintech company building consumer tools for cash advances, paycheck optimization, and credit building. You'll work closely with product, engineering, and business leaders to ship high-impact features that directly improve users' financial wellbeing. The team is lean, the ownership is real, and the work touches production every day. What You'll Do • Build product features end-to-end, including domain models, business logic, and API integrations. • Drive deployment and iteration through data-driven, incremental releases toward ambitious milestones. • Use SQL and analytics tools to evaluate product and system performance against robust data pipelines. • Debug complex state machines in an event-driven, pub/sub backend to ensure a seamless user experience. • Ship to production daily via a rapid CI/CD process, owning implementations end-to-end and responding to incidents as needed. What We're Looking For • 3+ years building backend features end-to-end for production systems. • Proficiency designing and consuming RESTful APIs with authentication, authorization patterns, and rate limiting. • Experience with event-driven architectures and message queues such as Kafka or Pub/Sub. • Experience with relational databases (PostgreSQL or MySQL), including data modeling and query optimization. • Hands-on experience with CI/CD pipelines, version control, automated testing, and code review processes. • Experience writing SQL and using analytics tools to assess system and product performance. • Experience building consumer-facing products (not exclusively B2B). • Experience debugging complex state machines in event-driven systems. • Strong computer science fundamentals: algorithms, data structures, and system design. • Meaningful early-stage startup experience, rather than exclusively large-company or late-stage backgrounds. • Familiarity with Go (golang) deployed on GCP is a strong plus. Compensation & Benefits Base salary: $120,000 to $200,000 USD annually. Visa sponsorship is available. Location On-site in San Francisco, CA. Candidates must already be based in, or be willing to relocate to, San Francisco or Seattle.
