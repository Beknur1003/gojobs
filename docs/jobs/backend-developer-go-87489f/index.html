Buscamos Backend Developer para importante proyecto financiero Propósito del Cargo Participar en el diseño, desarrollo y evolución de soluciones backend, construyendo microservicios y APIs robustas, escalables y de alto rendimiento, utilizando principalmente Golang y Node.js/TypeScript, bajo buenas prácticas de desarrollo, calidad y operación. Principales Responsabilidades • Apoyar en el diseño técnico de soluciones backend, participando en la definición de componentes, integraciones y contratos de servicio. • Diseñar, desarrollar y mantener microservicios y APIs REST utilizando Golang y Node.js, idealmente con TypeScript y NestJS. • Diseñar y documentar contratos de APIs mediante Swagger/OpenAPI, asegurando estándares de integración y mantenibilidad. • Implementar pruebas unitarias e integración, aplicando prácticas TDD y manteniendo una adecuada cobertura de código. • Integrar soluciones con bases de datos PostgreSQL y MySQL, considerando modelamiento, consultas y optimización básica. • Implementar y utilizar Redis para mecanismos de caché, colas, locks y optimización de procesamiento, según las necesidades de la solución. • Desarrollar integraciones mediante plataformas de mensajería como Kafka o RabbitMQ, cuando el diseño de la solución lo requiera. • Gestionar código fuente mediante Git, aplicando buenas prácticas de branching, Pull Requests y code review. • Participar en el despliegue y operación de servicios en ambientes Docker y Kubernetes. • Diagnosticar problemas técnicos y realizar troubleshooting en ambientes Linux/Unix-like. • Analizar y optimizar latencia, rendimiento y consumo de recursos, contribuyendo a la estabilidad y escalabilidad de las soluciones. • Colaborar con equipos de desarrollo, arquitectura, QA y operaciones durante todo el ciclo de vida de las soluciones. Requisitos Técnicos • Dominio práctico de Golang y Node.js. • Deseable experiencia con TypeScript y NestJS. • Experiencia comprobable en desarrollo de microservicios y APIs REST en ambientes productivos. • Manejo de Swagger/OpenAPI. • Experiencia con Git, Pull Requests y Code Review. • Conocimientos de PostgreSQL y/o MySQL, incluyendo modelamiento y consultas SQL. • Experiencia con Redis. • Conocimientos de Kafka y/o RabbitMQ. • Conocimientos prácticos de Docker y Kubernetes. • Experiencia trabajando en ambientes Linux/Unix-like. • Conocimientos de testing unitario e integración y buenas prácticas de calidad de software. Competencias Clave • Orientación a la calidad y buenas prácticas de desarrollo. • Capacidad de análisis y resolución de problemas. • Trabajo colaborativo y comunicación efectiva con equipos técnicos. • Orientación a rendimiento, escalabilidad y estabilidad operacional. • Capacidad para participar en el diseño y evolución de soluciones tecnológicas.
