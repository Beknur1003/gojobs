雲端架構維運工程師 (Cloud Native / DevOps Advisor)

歐立威科技股份有限公司 Datong District, Taipei City, Taiwan опубликовано 24 сентября 2026

Полная занятость
KubernetesDockerTerraformMicroservicesLinuxCI/CDPythonJavaNode.js
【工作內容】 1. 跨平台開發與自動化：具備 Linux 環境開發經驗，能運用 Python, Golang 或 Java 開發自動化腳本及維運工具。 2. 雲原生架構建置： 規劃與部署現代化基礎架構 (Infrastructure)，涵蓋虛擬化、容器化 (Docker)、高可用性網路及資料庫架構，並落實資安標準。 3. K8S 與 CI/CD 實踐：負責 Kubernetes (K8S) 叢集維運與優化。 設計並整合企業級 CI/CD 流水線，提升開發與部署效率。 4. Vault 密鑰管理專家：負責 HashiCorp Vault產品之部署、設定與系統維運。 協助客戶落實身份驗證管理、敏感數據加密 (Data Encryption) 及動態憑證存取控制。 提供技術故障排除與緊急應對服務，確保客戶資料安全。 5. 高效能架構優化：熟悉 API Gateway、負載平衡 (Load Balancing) 及分散式系統架構，能針對企業環境提供儲存與資安解決方案。 6. 顧問式技術交付：撰寫高品質技術文件（如安裝部署手冊、SOP、架構圖），並能對客戶進行專業技術授權與教育訓練。 7. 專案協作： 配合主管完成專案交付任務，並在售前/售後提供技術支援。 【加分條件】 1. 基礎設施即程式碼 (IaC)：熟練使用 Terraform, Ansible或 Pulumi 實現自動化配置與架構管理。 2. 現代化開發技術：具備 Node.js, Python 或 Golang 前後端整合測試經驗，了解微服務架構 (Microservices)。 3. GitOps 實踐：熟練 Git/GitLab 版本控制，並能建構基於 GitOps 邏輯的自動化部署方案。 4. 專業認證背景： 持有 CKA (Certified Kubernetes Administrator) 認證。 持有 HashiCorp Certified: Vault Associate 認證者尤佳。 5. 資安維運思維：具備雲端或地端基礎設施維運經驗，並對資安合規與威脅防護有深刻理解。 6. 問題解決能力：具備系統性思考能力，能在複雜環境中精確定位問題並提出最佳化方案。
