Senior Backend Developer We are looking for a Senior Backend Engineer with strong experience designing, building, and operating complex distributed systems. You will join a high-performance engineering team that owns its services end-to-end, from concept through production, and plays a key role in shaping our architecture and scaling our platform globally. We expect our engineers to actively leverage modern software development practices, including AI-assisted development, automation, continuous learning, API-first design, and strong production ownership, to deliver high-quality software faster and more effectively. You will work with a modern backend stack, including: • Go (Golang) for backend services • Google Cloud Platform (GCP) for infrastructure • Temporal for durable execution and long-running business workflows • Docker and Kubernetes for orchestration • Event-driven microservices and REST APIs for global scale and resilience • CI/CD pipelines, feature toggles, and frequent, controlled releases Our teams use Domain-Driven Design (DDD), Behavior-Driven Development (BDD), and contract-first development practices to create modular, secure, and maintainable systems. We prefer managed cloud services where they make sense and value pragmatic architecture over unnecessary complexity. How You Will Make an Impact: • Design, build, deploy, and operate backend services that are secure, scalable, reliable, and maintainable. • Build production-grade services using Go and modern cloud-native engineering practices. • Design APIs and service contracts that are easy for internal and external developers to consume. • Collaborate with product managers, analysts, architects, frontend engineers, infrastructure, and security teams to define requirements and deliver high-quality solutions. • Use AI-assisted development tools to accelerate software delivery while maintaining high standards for quality, security, and correctness. • Use AI to understand, navigate, refactor, and modernize large existing codebases. • Write automated tests and participate in BDD/TDD practices that improve release confidence. • Improve development workflows through automation, tooling, and continuous improvement. • Take full ownership of services from design and implementation through testing, deployment, monitoring, incident response, and ongoing support. • Contribute to architecture discussions with a practical understanding of tradeoffs, scalability, cost, operability, and business impact Skills you will have fine-tuned: • Proven ability to build production backend services, ideally with Go. Transferable experience in Java, Rust, C#, or similar backend languages is also valuable when paired with a willingness to work deeply in Go. • Practical experience with microservices, messaging systems, event-driven architecture, and RESTful APIs. • Strong understanding of modern API design principles, including versioning, backward compatibility, idempotency, authentication, authorization, error handling, observability, and developer experience. • Familiarity with distributed systems, cloud-native architectures, event sourcing, durable execution, or workflow orchestration patterns. • Hands-on experience with CI/CD pipelines, Docker, Kubernetes, and automated deployment practices. • Experience with GCP, AWS, or Azure, with a preference for managed cloud services where appropriate. • Strong appreciation for clean architecture, modular design, test automation, and maintainable code. • Daily use of AI-assisted development tools such as Cursor, GitHub Copilot, Claude Code, ChatGPT, Windsurf, or similar. • Ability to use AI effectively for coding, debugging, test generation, documentation, refactoring, architectural exploration, and understanding unfamiliar codebases. • Experience using modern IDEs such as Cursor, VS Code, or JetBrains products, with a focus on productivity-enhancing extensions, integrations, and workflows. • Comfortable using keyboard-driven workflows, automation, scripts, and tooling optimizations to improve development speed and quality.
