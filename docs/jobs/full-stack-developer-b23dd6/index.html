Full Stack Developer — Bridge CX Weeks Group | Remote (International) Build Software That Powers Mission-Critical Data Center Construction Weeks Group is seeking a hands-on Full Stack Developer to help build and enhance Bridge CX, our commissioning and scheduling software platform supporting mission-critical data center construction projects. Bridge CX is already being used on live projects with major U.S. general contractors. Our software supports field engineers working in demanding environments where reliable performance, offline functionality, and practical usability matter. This is an opportunity to work across the entire application stack, take ownership of production features, and contribute directly to a growing software platform serving the data center construction industry. About Weeks Group Weeks Group provides construction management, owner's representation, and consulting services for the mission-critical data center industry. We partner with leading developers and operators to deliver complex, high-performance infrastructure that powers the digital economy. Our teams value accountability, technical expertise, innovation, teamwork, and practical problem-solving. What You'll Do As a Full Stack Developer supporting Bridge CX, you will: • Build and deliver production features across PostgreSQL databases, Go backend services, REST APIs, and React/TypeScript interfaces. • Design and implement database schema changes, API handlers, and frontend functionality. • Develop automated unit, integration, and end-to-end tests alongside your code. • Build reliable application workflows that function under inconsistent internet connectivity. • Implement offline-capable functionality, synchronization states, and graceful error handling. • Troubleshoot production issues using monitoring tools, QA findings, and customer feedback. • Participate in pull request reviews and maintain high engineering standards. • Collaborate with a small, distributed development team using Linear and GitHub. • Use AI-assisted coding tools daily while independently validating generated code. • Take ownership of assigned features from initial development through production deployment. Our Technology Stack Frontend • React 19, TypeScript, Vite • TanStack Query and Form • Tailwind CSS, Zod • Storybook and an internal design system Backend and Database • Go (Golang) • REST APIs and OpenAPI • GORM • PostgreSQL Testing and Quality • Vitest • Playwright • Mock Service Worker • Go integration testing Infrastructure and Delivery • AWS • Terraform • GitHub Enterprise and GitHub Actions • Microsoft Entra ID • Sentry Our broader technology environment also includes native mobile applications, Python scheduling pipelines, Microsoft Fabric, and embedded Power BI. You do not need experience with every technology listed above. Required Qualifications • 3+ years of professional experience developing production web applications across frontend and backend systems. • Strong hands-on experience with React and TypeScript. • Backend development experience using Go or another strongly typed backend language, with the ability and willingness to work in Go immediately. • Strong SQL skills and experience with relational database design. • Experience designing, developing, and consuming REST APIs. • Demonstrated experience writing automated tests as part of regular software delivery. • Daily experience using AI coding tools such as Claude Code, Codex, or Cursor. • Strong written English communication skills for technical documentation, pull requests, and asynchronous collaboration. • Ability to work independently within a distributed development team. • Availability for at least four hours of overlap with the U.S. Eastern workday, including occasional 6:00 a.m. Eastern meetings. Direct Go experience is not required if you bring strong transferable backend engineering experience and are prepared to work in Go from day one. Preferred Qualifications Experience in any of the following is beneficial but not required: • OpenAPI-first development and generated API clients • Playwright or similar end-to-end testing frameworks • AWS, Terraform, or GitHub Actions • Offline-first applications or synchronization-heavy systems • Python data pipelines, Microsoft Fabric, or Power BI • Mobile development with Swift or Kotlin • Construction, engineering, field operations, or mission-critical infrastructure software What Success Looks Like First 30 Days: Establish your development environment and deliver your first production features. First 60 Days: Independently deliver medium-sized features spanning backend APIs and frontend interfaces, supported by automated testing. First 90 Days: Take ownership of a product area, contribute meaningful code reviews, and demonstrate consistent production delivery. Work Arrangement • Location: Fully Remote — International • Engagement: Full-time employment or long-term contract, depending on location • Schedule: Flexible, with at least four hours of overlap with the U.S. Eastern workday • Team: Small, distributed engineering team based in the United States and Romania • Reporting To: Director of IT Our development process emphasizes ownership, asynchronous communication, and practical delivery rather than unnecessary meetings or heavy Agile ceremonies. Why Join Bridge CX? You'll contribute to a production software platform used on real data center construction projects, solve meaningful engineering challenges, and see the direct impact of your work. If you enjoy building complete features, solving challenging technical problems, and taking responsibility for software quality, we'd like to hear from you. Apply to join Weeks Group and help build the future of Bridge CX.
