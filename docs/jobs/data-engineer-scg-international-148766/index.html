Data Engineer - SCG International

Job Descriptions: • Data Warehouse, Pipeline & Integration ดูแลและพัฒนา Data Warehouse, Data Pipeline, Data Integration รวมถึง API Integration ให้มีประสิทธิภาพ และพร้อมใช้งาน • Data Query, Data Processing & Preparation จัดทำ Data Query, Data Extraction และ Data Preparation เพื่อสนับสนุน Reporting, Analytics, AI และโครงการต่างๆ • Automation & Reporting Solution พัฒนา Data Processing, Automation และ Report/Dashboard เพื่อลดงาน Manual, ลด cost ค่าทำบัญชีและรายงานที่เกี่ยวข้อง และประสิทธิภาพการทำงานสำหรับ operation และ management เช่น FX Cash Gap Management Dashboard, Working Capital Report และ Check Margin Report • Prototype & AI-assisted Development พัฒนา Prototype, Internal Took และ Automation Solution ด้วย AI-assisted / Vibe Coding ตาม Project ที่ได้รับมอบหมาย เช่น Automated Payment สำหรับการชำระเงินไปยังธนาคารต่างประเทศ • Data Quality & System Support ดูแล Data Quality, monitoring และ Troubleshooting รวมถึงประสานงานกับ Vendor ในการวิเคราะห์และแก้ไขปัญหาของ SAP BW (SAP Data Warehouse) และระบบข้อมูลที่เกี่ยวข้อง Qualifications: • วุฒิปริญญาตรีด้าน Computer Science, Computer Engineering, Information Technology, Data Science หรือสาขาที่เกี่ยวข้อง (Bachelor's GPAX > 2.70 / Master's GPAX > 3.30) • มีประสบการณ์ด้าน Data Engineering และ/หรือ Data Warehouse, Data Pipeline, ETL/ELT และ Data Warehouse ประมาณ 2-3 ปี • มีประสบการณ์ในการพัฒนาและดูแล Data Warehouse, Data Pipeline, ETL/ELT และ Data integration • มีทักษะด้าน SQL สามารถ Query, Transform และจัดเตรียมข้อมูลได้ • มีทักษะด้าน Python ในระดับดี สามารถพัฒนา Data Processing, Data Integration, API Integration และ Automation Solution ได้ • สามารถใช้ AI-assisted Coding / Vibe Coding เพื่อพัฒนา Prototype, Internal Pool หรือ Automation Solution เช่น Python, Golang, Node.js • หากมีประสบการณ์ด้าน Microsoft Fabric และ Google Clound Platform (GCP) จะได้รับการพิจารณาเป็นพิเศษ • มีทักษะด้านการวิเคราะห์และแก้ไขปัญหา สามารถทำงานร่วมกับทีมและ Vendors รวมถึงเรียนรู้เทคโนโลยีใหม่ได้ดี • สื่อสารภาษาอังกฤษได้ดี (TOEIC score at least 550)
