About InstaSafe InstaSafe is a Zero Trust cybersecurity company trusted by global enterprises to secure users, applications, and infrastructure in hybrid and cloud-native environments. Our ZTNA, IAM, and MFA solutions protect over 500,000 endpoints worldwide, enabling enterprises to adopt cloud securely and confidently. We are seeking a Backend Engineer to design, develop, and optimize the core backend services that power ISA Controller and ZTA Console. These services form the backbone of our Zero Trust platform, handling authentication, authorization, secure session management, and large-scale API integrations. Role Overview The Backend Engineer will design and implement scalable backend services and microservices using Java (Spring Boot) and Go (Golang). You will work across authentication flows, distributed session management, REST/gRPC APIs, and cloud-native orchestration, ensuring the platform is secure, performant, and highly available. This role is ideal for engineers with deep backend expertise and an interest in secure enterprise systems. Duties & Responsibilities • Service Development: Design and implement backend services for authentication, authorization, and Zero Trust access policies using Java Spring Boot and Go. • Microservices Architecture: Build and scale modular, stateless services orchestrated via Docker/Kubernetes. • API Development: Design, document, and optimize REST APIs and gRPC interfaces for secure communication with agents and consoles. • Data Management: Integrate and optimize PostgreSQL, MySQL, MongoDB, and Redis for secure and efficient data storage. • Authentication & Security: Implement OAuth2, JWT, SAML, LDAP integrations to connect with enterprise identity providers. • Performance & Reliability: Benchmark, monitor, and tune backend systems for scalability and low latency. • Collaboration: Work closely with frontend, agent, and gateway teams to deliver cohesive platform features. • CI/CD Integration: Contribute to automated testing, build pipelines, and deployment workflows. • Continuous Learning: Stay current with cloud-native technologies, distributed systems, and secure coding practices. Requirements Qualifications & Skills Education & Experience: • Bachelor’s/Master’s in Computer Science, Engineering, or related field. • 4–8 years’ experience in backend development for enterprise-grade systems. Core Technical Skills (with links for TA reference): • Java & Spring Boot • Go (Golang) • REST APIs & gRPC • PostgreSQL, MySQL, MongoDB, Redis • Docker & Kubernetes • OAuth2, JWT, SAML, LDAP Preferred/Good-to-Have: • Experience with message brokers (Kafka, RabbitMQ). • Familiarity with cloud environments (AWS, Azure, GCP). • Experience in high-performance distributed systems. • Exposure to DevSecOps practices. Benefits Career Value Proposition • Build the core backend brain of a fast-scaling Zero Trust cybersecurity platform. • Work with cutting-edge Java and Go microservices. • Collaborate with top engineers across frontend, networking, and endpoint teams. • Gain career growth in distributed systems and enterprise security platforms.
