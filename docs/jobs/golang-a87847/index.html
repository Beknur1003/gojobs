【新擴編】Golang 後端工程師

我們正在尋找一位熟悉 Golang，且不排斥閱讀 PHP 代碼的後端工程師。 您將成為我們技術轉型的核心成員，與團隊共同將單體式架構逐步拆解並遷移至現代化的 Golang 微服務架構。 【核心任務】 這不是一份單純維護舊系統的工作，而是一個「除舊佈新」的挑戰： 1. Golang 微服務開發： 使用 Go (Gin/Echo) 設計並開發高效能的後端 API，支援前後端分離架構。 2. 系統遷移與重構： 分析現有的 PHP 業務邏輯，將其拆解、優化並遷移至 Golang 環境（需具備閱讀 PHP 代碼的能力）。 3. 架構優化： 參與資料庫設計（MySQL/PostgreSQL）、快取策略（Redis）與併發處理，解決效能瓶頸。 4. 協作與整合： 與前端團隊對接 API，並有機會與內部的 Python AI 團隊合作，整合 AI 服務。 5. 跨語言/跨團隊整合：作為後端核心，你需要與前端團隊對接 API，並與內部的 Python AI 團隊協作，將 AI 模型服務串接至主系統中。 6. 資料庫與效能優化：參與關聯式資料庫（MySQL）與 NoSQL（MongoDB）的架構設計，並透過 Redis 快取策略與 Go 的併發特性提升系統吞吐量。 【必要技能】 1. Golang 實戰經驗：具備 2 年以上 Golang 開發經驗，深刻理解 Goroutines、Channel 等併發模式，並有實際落地專案的經驗。 2. 能夠閱讀 PHP 邏輯：不需撰寫 PHP，但需具備閱讀 PHP (Laravel) 代碼的能力。 你需要能看懂舊有的業務邏輯（變數流向、SQL 查詢），以便將其準確且優化地「翻譯」到 Golang 環境。 3. API 設計思維：熟悉 RESTful API 設計規範，了解 HTTP 協定、Status Code 與錯誤處理機制。 4. 資料庫掌握度：熟悉 MySQL 索引優化、Transaction 處理，並對 MongoDB 有基礎操作或設計經驗。 5. 雲端平台使用經驗：具備 AWS 或 Azure 的操作與開發經驗，了解如何將應用程式部署至雲端環境，並熟悉基本的雲端運算概念（Compute, Storage, Networking）。 6. 團隊協作工具：熟悉 Git 版控操作與 Git Flow 開發流程。
