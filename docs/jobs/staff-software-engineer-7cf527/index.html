Job Summary We’re hiring Platform Backend Engineers to build and operate the core services connecting workflow execution, identity, event routing, secrets management, and audit capabilities across Kaseya’s platform. This is a hands-on backend role focused on Go or Rust, event-driven systems, multi-tenant security, and production reliability. You’ll build foundational services used by engineering teams and AI-enabled workflows, with correctness, auditability, and operational clarity as core design requirements. Roles & Responsibilities • Build and operate core platform services, including API gateways, event routing, identity integrations, secrets management, and audit infrastructure • Design event-driven systems that convert product events, alerts, and partner webhooks into durable workflow execution using Kafka and Temporal • Implement a pluggable key-management layer supporting cloud KMS providers, bring-your-own-key models, envelope encryption, and per-client cryptographic isolation • Build and enforce fine-grained capability grants for individual clients, workflows, operations, and service-to-service requests • Own GitOps-based deployment pipelines for versioned workflow definitions across isolated client environments • Develop onboarding automation for identity provisioning, compliance configuration, and client-specific key-management setup • Build secure connector services for third-party APIs, including scoped access, platform-managed credentials, request validation, and audit logging • Improve platform observability, reliability, failure recovery, security, and operational readiness while supporting production incident response Required Qualifications • Experience building and operating production backend services using Go or Rust • Experience designing event-driven systems using Kafka or similar technologies, including retries, idempotency, replay, and at-least-once delivery • Experience implementing authentication and authorization using OAuth 2.0, OIDC, token lifecycle management, or fine-grained access controls • Experience implementing encryption or key-management solutions using cloud KMS platforms, envelope encryption, or key-hierarchy designs • Experience operating multi-tenant production systems using structured logging, metrics, distributed tracing, and incident-response practices Preferred Qualifications • Experience with Temporal or another durable workflow orchestration platform • Experience integrating identity platforms such as Zitadel, Keycloak, Auth0, Okta, or similar technologies • Experience with ClickHouse or another columnar, append-only, or audit-focused data store • Experience with GitOps, CI/CD, Kubernetes, or infrastructure-as-code deployment practices • Experience integrating MSP, PSA, RMM, security, or Microsoft 365 platform APIs • Experience building software for regulated environments subject to SOC 2, HIPAA, CMMC, or similar requirements • Experience developing multi-cloud platform services across AWS, Azure, or GCP Compensation Range The base salary range for this job is CAD
