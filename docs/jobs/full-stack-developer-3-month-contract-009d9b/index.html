หน้าที่ความรับผิดชอบ • ออกแบบและพัฒนา RESTful API ด้วย NestJS และ/หรือ Golang รวมถึง Authentication/Authorization และการเชื่อมต่อกับระบบภายนอก • พัฒนาหน้าเว็บและ UI Component ด้วย React เชื่อมต่อกับ Backend API และจัดการ State ของแอปพลิเคชัน • ออกแบบ Schema และเขียน Query บน PostgreSQL รวมถึงจัดการข้อมูลบน MongoDB ให้ถูกต้องและมีประสิทธิภาพ • เขียน Unit Test และ Integration Test ทำ Code Review และรักษามาตรฐานคุณภาพโค้ดร่วมกับทีม • ร่วมวิเคราะห์ Requirement วางแผนงาน รายงานความคืบหน้า และประสานงานกับผู้ที่เกี่ยวข้อง • ลงพื้นที่ที่ site ทั้งในกรุงเทพฯ และต่างจังหวัดเมื่อจำเป็น เพื่อติดตั้ง ทดสอบ และแก้ไขปัญหาหน้างาน • จัดทำเอกสารประกอบการพัฒนาตามความเหมาะสม คุณสมบัติผู้สมัคร • มีประสบการณ์ทำงานด้าน Full Stack Development อย่างน้อย 3 ปี • มีประสบการณ์พัฒนาด้วย TypeScript / JavaScript • มีประสบการณ์กับ NestJS, Golang และ React • มีความรู้และประสบการณ์กับฐานข้อมูล PostgreSQL และ MongoDB • มีประสบการณ์เขียน Unit / Integration Testing • มีคอมพิวเตอร์ส่วนตัวสำหรับใช้ทำงาน • สามารถเข้าออฟฟิศ/site ได้ตามที่กำหนด และเดินทางไปต่างจังหวัดได้ • สื่อสารและทำงานร่วมกับทีมได้ดี รูปแบบการทำงาน • เข้าออฟฟิศ/site สัปดาห์ละ 2-3 วัน (ขึ้นอยู่กับทีมที่ร่วมงาน) นอกนั้น WFH • อาจต้องไปปฏิบัติงานที่ site ทั้งในกรุงเทพฯ และต่างจังหวัด
