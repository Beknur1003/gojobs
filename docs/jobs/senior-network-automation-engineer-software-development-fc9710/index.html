Job Summary We are looking for a Senior Network Automation Engineer (Engineer 4) with a strong combination of network engineering, software development, network automation, cloud-native technologies, data/API integration, and applied AI skills. The engineer will work on automation and operational capabilities supporting our DAA access network, including Arista and Juniper switching infrastructure, as well as applications supporting the vCMTS ecosystem, including Docker-based containerized microservices and related network services. This is a senior, hands-on network automation engineering position. The successful candidate should have a good understanding of BGP, IS-IS, routing protocols, Python/Go development, Ansible automation, APIs and network data models, Kubernetes workloads, and production-quality automation solutions. The candidate should also be able to apply AI-assisted engineering and GenAI capabilities to improve development, network operations, troubleshooting, and automation workflows. Job Description *This position is unable to provide work authorization sponsorship or immigration support now or in the future.* The successful candidate should be able to: • Independently own complex technical problems from investigation through production implementation. • Evaluate multiple technical approaches and clearly communicate recommendations, trade-offs, operational impacts, and risks. • Drive approved solutions end-to-end, including design, development, testing, deployment, observability, and production support. • Work across network, software, infrastructure, and platform domains rather than operating within only one technology area. • Troubleshoot complex production issues and perform systematic root-cause analysis. • Design solutions that are scalable, maintainable, observable, resilient, and operationally supportable. • Collaborate effectively with architecture, network engineering, operations, and software development teams. • Provide technical guidance and contribute to engineering and automation standards. Software Development & Network Automation Required Skills • Strong software/network automation engineering experience. • Strong understanding of TCP/IP and networking protocols with hands-on troubleshooting experience. • Strong Python and Golang development skills. • Experience with Ansible-based network automation at scale. • Experience with REST APIs and programmatic network interfaces such as gNMI/OpenConfig or NETCONF/RESTCONF. • Experience with Docker/containerized applications in a microservices architecture. • AWS experience, particularly Lambda, EC2, and AuroraDB. • Strong debugging and root-cause analysis skills. APIs, Network Data & Databases The candidate should be comfortable building automation around both APIs and structured network data. • Strong understanding of REST APIs, API authentication, request/response models, error handling, and API integrations. • Experience with networking interfaces and protocols such as gNMI/OpenConfig, NETCONF/RESTCONF, and vendor APIs. • Experience consuming and developing APIs using Python and/or Golang. • Understanding of database schemas, data models, relationships, and structured network inventory/configuration data. • Ability to work with network inventory/source-of-truth systems such as NOMAD DB or comparable network data platforms. • Experience designing automation that retrieves network inventory and state, transforms the data, executes network changes, and updates operational status. • Ability to troubleshoot data inconsistencies across API, database, automation, and device layers. Containers & Kubernetes • Experience with Docker and containerized applications. • Working knowledge of Kubernetes architecture and operations. • Strong understanding of Kubernetes networking, including Pods, Services, DNS, routing, connectivity, and troubleshooting. • Ability to troubleshoot applications where issues may originate in the application, container, Kubernetes, host, or physical network. Network Engineering Skills • Basic understanding of TCP/IP and Layer 2/Layer 3 networking fundamentals. • Basic understanding of BGP, IS-IS, routing, switching, VLANs, interfaces, and network reachability. • Strong hands-on network troubleshooting experience. • Experience with platforms such as Arista EOS, Juniper Junos, and Cisco IOS/IOS-XR. Preferred Skills • Arista EOS, Juniper Junos, Cisco IOS/IOS-XR. • Kubernetes-based network applications. • Terraform/OpenTofu. • CI/CD pipelines. • Network source-of-truth/inventory platforms. • AI-assisted network operations or network automation. Good to Have • Practical experience using Generative AI/LLMs as part of software engineering or automation workflows. • Experience using AI coding assistants such as GitHub Copilot or equivalent tools to improve engineering productivity. • Understanding of prompt engineering, LLM APIs, structured outputs, and tool/function calling. • Ability to integrate AI capabilities into Python/Go automation workflows. • Interest or experience applying AI to network troubleshooting, telemetry analysis, log analysis, configuration analysis, anomaly detection, and root-cause investigation.
