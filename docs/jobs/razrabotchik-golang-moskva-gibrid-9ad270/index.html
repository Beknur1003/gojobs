Навыки: Golang, Apache Kafka. Квалификация: Middle. Специализации: Бэкенд разработчик. Bell Integrator – крупный системный интегратор страны. Мы являемся аккредитованной ИТ– компанией. На текущий момент с нами работает более 2500 высококлассных аналитиков, руководителей проектов, разработчиков, тестировщиков и специалистов по сопровождению крупных информационных систем. Bell Integrator активно реализует проекты по всей России, среди наших заказчиков – ведущие системообразующие финансовые, телеком и ритейл компании страны. Центральный офис Bell Integrator расположен в Москве, представительства – в Санкт-Петербурге, Нижнем Новгороде, Пензе, Саратове, Уфе, Барнауле, Минске (Беларусь). Проект: Мы - команда разработки продукта Ptc (Push to ci/cd). Мы разрабатываем внутрюннюю платформу для других команд разработки. Продукт уменьшает накладные расходы при выводе новых продуктов и релизе существующих продуктов на настройку инфраструктуры и бюрократическую составляющую. Также мы предоставляем инструменты автоматизации для проведения масштабных работ с инфраструктурой всего блока по общим задачам регуляторов внутри компании. Какие конкретно задачи решаем: - Автоматизация работы с инфраструктурой. Реализуем концепцию Infrastructure as a Code и связываем инфраструктурные настройки с процессом CI/CD. - Автоматизация работы с релизным циклом. Закрываем потребности по регулярным действиям в процессе релиза программных продуктов. - Развиваем инструменты Observability - метрики, логи - Развиваем инструменты сопровождения систем по регулярным установкам и нерелизной деятельности Мы ожидаем: • Опыт разработки на GoLang не менее 3 лет • Jпыт разработки Unit-тестов и интеграционных тестов с помощью test-containers • Опыт использования технологий: Gin, pgx, GraphQL, Git • Опыт работы работы с протоколами: HTTP, Apache Kafka • Опыт разработки приложений с конкуренцией • Опыт работы с SQL на уровне эксперт (составление запросов различной сложности и объединение нескольких таблиц – от 3-х и более, вложенные запросы, и фильтрация по нескольким полям, и умение работать с разным форматом дат, и создание/удаление редактирование таблиц, создание процедур) • Опыт работы с Kubernetes и Jenkins для запуска приложений Условия: • Возможность участия в интересном проекте • Возможность профессионального и карьерного роста в компании; • Опыт работы в команде профессионалов; • Уровень заработной платы обсуждается индивидуально. • Формат работы - офисный/гибридный в Москве
