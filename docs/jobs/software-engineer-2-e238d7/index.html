About the role: Kong’s API Management suite includes the Kong Enterprise Gateway, the Konnect SaaS platform, and a variety of Managed Gateways in public clouds, such as AWS, Azure, and GCP. This suite of products helps customers in different industries (like finance, banking, e-commerce, airlines, etc.) manage their API platforms and operations at scale. Our customers expect secure, reliable, high-scale, low-latency offerings from Kong, whether running on-premise or in the public cloud. A critical need for all our customers is to manage API Operations via Infrastructure-as-Code (IaC) tools. Kong provides an open-source CLI - deck - that is the centrepiece of API Operations. (Source code for deck is at GitHub - Kong/deck: decK: Configuration management and drift detection for Kong. ) Some of the other products that the API Operations toolset includes are: Terraform-provider: Terraform provider for Kong Konnect - Kong’s SaaS product SDK for Go: Go SDK for Kong Konnect SDKs in other languages and tooling to generate SDKs from APIs API specification and tooling for all products of Kong Build a CLI-first experience for Kong Konnect We are looking to expand our Bangalore-based API Operations team by hiring a Software Engineer II to join the team and build out the API Operations toolset. We expect you to work in a hybrid fashion with three days a week in the office. What you'll do: • Design, develop and build the API Operations toolset for Kong, starting with deck. • Keep up with all of Kong’s API runtimes (HTTP gateway, AI gateway, Event gateway, etc.) and enable new features in the API Operations toolset. • Play a pivotal role in shaping the technical direction for the evolution of API Operations. • Make CLI tools work for both humans and automation (inside GitHub Actions, Jenkins, etc.). • Ship API changes to multiple tools at the same time without manual toil • Make and consistently raise the bar for world-class APIs for a company that helps the world build and run APIs • Collaborate closely with product leadership to define and refine strategy, roadmap, and objectives for the API Operations toolset, ensuring alignment between engineering efforts and business goals. • Assist in the hiring process and help grow and mentor the team. What you'll bring: • Bachelor's or Master's degree in Computer Science or a related field. • 3+ years of experience in building high-performance software with Golang. • Hands-on experience with at least one of the major cloud platforms (AWS, Azure, or GCP). • Prior operations experience with Infrastructure-as-Code tools. • Experience building APIs, standardising APIs in large organisations, and creating API workflows. • Strong verbal and written communication skills to effectively collaborate across teams. • Desire to join a fast-paced pre-IPO startup and the ability to move with high velocity to get things done.
