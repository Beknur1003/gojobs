CLOUD APPLICATION ENGINEER What experience should you have: • 4+ years of professional web application development experience. • Strong command of TypeScript and either Go or Python with full-stack development experience. • Knowledge of Google Cloud Platform, specifically Load Balancing and web architecture. • Experience operating Cloud Run applications in production environments. • Proficiency with Git workflows and agile development processes (SDLC). Preferred: Professional Cloud Developer certification or experience in client-facing consulting. What you’ll be doing in this role: • Build and implement web applications using TypeScript (Svelte), Go, and Python (FastAPI). • Design and optimize PostgreSQL database schemas to ensure performance and data integrity. • Manage application deployments on GCP using Cloud Run and Cloud SQL • Develop user-friendly interfaces using modern frameworks like Svelte. • Collaborate with data science teams to integrate AI models into production APIs. What you'll need to accomplish in your first year: • Successfully deploy and maintain high-availability cloud applications for client projects. • Consistently deliver clean, secure, and performant code that meets team standards. • Become a key contributor to the technical integration of AI-driven features into web interfaces.
