Noesis is looking for candidates with the following profile: Main Tasks and Responsibilities: • Develop and maintain backend services using Golang within a cloud-first AWS environment; • Implement technical solutions, including code, infrastructure-as-code, automated tests, and CI/CD pipelines, from development through to production; • Participate in code reviews and collaborate with the squad to ensure code quality, security, scalability, and maintainability; • Contribute to technical documentation and the continuous improvement of systems, architectures, and development practices.
