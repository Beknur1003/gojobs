Salary: RM 15,000 – RM 20,000 per month Golang Backend Developer (VPN / Network Acceleration) Monthly Salary: RM15,000–RM20,000 Experience Required: At least 3 years of Golang backend development experience About the Role We are looking for a Golang Backend Developer who can work independently on backend systems for VPN and network acceleration products. You will be responsible for core business modules, client APIs, subscription payments and server node management, while contributing to distributed architecture design and system performance optimisation. If you have experience with VPN services, network proxies, in-app subscription payments or high-concurrency systems, we welcome your application. Key Responsibilities • Design, develop, maintain and optimise backend systems for VPN and network acceleration products. • Develop core modules covering user management, membership subscriptions, orders and payments, device management, server node management and traffic statistics. • Develop and integrate APIs for iOS and Android applications, improving response times, reliability and security. • Integrate Apple App Store in-app purchases and subscriptions, including transaction verification, auto-renewals, subscription status synchronisation, refund handling and server notifications. • Develop node monitoring, intelligent routing, load balancing and automatic failover functionality. • Contribute to distributed architecture design and optimise databases, caching and service performance to ensure system stability and data consistency under high concurrency. • Troubleshoot production issues, analyse logs and implement fixes. Requirements • At least 3 years of Golang backend development experience, with the ability to independently design and develop business modules. • Strong proficiency in Go, including goroutines, channels, context, concurrency control and network programming. • Familiarity with common frameworks and tools such as Gin, GORM and gRPC, with experience developing RESTful APIs. • Proficiency in MySQL and Redis, with experience in index optimisation, cache design and data processing under high concurrency. • Familiarity with Linux, with the ability to deploy services, analyse logs and troubleshoot production issues. • Experience developing distributed systems, with an understanding of service decomposition, load balancing, message queues, service discovery and high-availability design. • Familiarity with network protocols including HTTP/HTTPS, TCP/IP, UDP and WebSocket. • Understanding of mobile application and backend interactions, including client authentication, API security and device management. • Familiarity with development and deployment tools such as Docker, Nginx and Git. • Strong coding practices, communication skills and a sense of responsibility, with the ability to analyse problems independently and collaborate with iOS and Android developers. Added Advantages • Backend development experience with VPN services, proxy services or network acceleration products. • End-to-end experience integrating Apple App Store in-app purchases and auto-renewable subscriptions, with familiarity with App Store Server API, App Store Server Notifications V2 and StoreKit 2 integration flows. • Familiarity with technologies such as Xray, Sing-box, WireGuard, VLESS, VMess, Hysteria2 and AnyTLS. • Experience developing multi-server node management, route health checks, traffic statistics and failover functionality. • Experience developing or optimising high-concurrency APIs, large-scale user systems or microservices architectures. • Familiarity with Kafka, RabbitMQ, etcd, Consul, Prometheus and Grafana. • Experience deploying and
