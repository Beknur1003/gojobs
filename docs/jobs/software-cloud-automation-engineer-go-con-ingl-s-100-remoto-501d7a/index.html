Software & Cloud Automation Engineer (Go) Responsabilidades principales • Automatización de extremo a extremo: Desarrollar herramientas, operadores, CLIs y flujos automatizados en Go para simplificar el aprovisionamiento, despliegue y operación de servicios. • Gestión de plataformas de contenedores: Desplegar, administrar y operar clústeres de orquestación en producción (Kubernetes o Nomad). • Infraestructura como Código (IaC): Definir, versionar y gestionar la infraestructura en la nube mediante Terraform y automatizar la configuración de sistemas con Ansible. • Operación y Troubleshooting avanzado: Diagnosticar y resolver incidencias complejas a nivel de sistema, contenedores (Docker), rendimiento y networking en entornos distribuidos. • Evolución tecnológica: Colaborar activamente en la mejora continua de la arquitectura cloud, proponiendo estándares y buenas prácticas de desarrollo y operación. Requisitos del perfil • Pasión por la automatización: Mentalidad orientada a automatizar cualquier tarea repetitiva mediante código y herramientas modernas. • Experiencia sólida en Go (Golang): Capacidad demostrada para desarrollar código limpio, concurrente y orientado a producción (herramientas CLI, microservicios, integraciones con APIs o operadores). • Conocimientos de Nube Pública: Experiencia trabajando con proveedores cloud (valoramos especialmente AWS, aunque si vienes de GCP, Azure u otra nube pública y dominas los conceptos fundamentales, nos encantará conocerte). • Stack técnico imprescindible: • • Orquestación de contenedores: Kubernetes o Nomad. • Infraestructura como Código y gestión de configuración: Terraform y Ansible. • Contenerización: Docker. • Sólida base en Networking (redes, DNS, balanceo de carga, seguridad perimetral) y capacidad de troubleshooting profundo en entornos Linux/Cloud. • Formación e idiomas: • • Titulación universitaria superior en Ingeniería Informática, Telecomunicaciones o afines (preferible). • Nivel de inglés avanzado (C1) para trabajar en entornos técnicos internacionales. Ofrecemos: - Oportunidad de trabajar en proyectos innovadores con tecnologías de vanguardia. - Integración a un equipo colaborativo y dinámico. - Proyecto estable. - Modalidad de trabajo: Teletrabajo. 100% remoto (puede haber reuniones puntuales en oficina)
