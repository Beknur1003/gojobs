Senior Software Engineer (Storage)

XCELLINK PTE. LTD. Singapore опубликовано 28 июля 2026

Удалёнка Senior
gRPCPythonRustJavaC++
We are looking for a Senior Software Engineer (Storage) to join a global engineering team focused on building and operating high-performance distributed storage systems and backend services. This is an individual contributor role working closely with technical leads on large-scale infrastructure projects. Key Responsibilities • Design, develop, maintain, and support scalable backend services interacting with storage systems. • Troubleshoot production issues, perform debugging, and provide operational support. • Participate in system design, code reviews, and architecture discussions. • Support service reliability, scalability, and performance improvements. • Participate in on-call support rotations as required. Requirements • Minimum 3 to 5 years of software development experience. • Strong hands-on experience in Rust backend development. • Working knowledge of Golang, Java, and Python. • Familiarity with C/C++. • Strong foundation in Data Structures & Algorithms and distributed system design. • Experience designing scalable, highly available backend systems. Technical Skills Candidates should have hands-on experience in: Concurrent Programming • Asynchronous programming • Multi-threading and concurrency models RPC Technologies • gRPC and/or Apache Thrift Cloud-Native Technologies • Service discovery (Consul, ZooKeeper) • Service mesh (Envoy, Istio) • IPv6 networking Distributed Storage Systems • Data consistency models • Replication and fault tolerance • Sharding, routing, and resharding • Scalability and distributed system design Candidates must have experience building, designing, or operating distributed storage systems or storage components. Experience merely using distributed databases as an application backend is not sufficient. Working Arrangement • Fully remote role. • Collaborate with global teams across the US and Asia. • Flexibility to support occasional meetings outside standard Singapore business hours.
