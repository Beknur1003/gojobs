CTO | GoLang-інженер | Стартап у сфері AI Security Тип: Повна/часткова зайнятість, співзасновник / CTO (на основі акцій з можливістю отримання зарплати згодом) Місце роботи: Дистанційно (Україна) Термін: Постійна посада, початок роботи негайно Бюджет: 15–25 % акцій + зарплата після залучення фінансування Про проєкт: Будуємо execution firewall для AI-агентів — критичний рівень безпеки між AI-агентами та інфраструктурою компанії. Проблема: тисячі AI-агентів розгортаються в enterprise без контролю. Один скомпрометований агент = повний доступ до production. Твої обов’язки (CTO): - Архітектура ядра: Policy engine, credential broker, MCP proxy, capability-based enforcement - Code review: Go-код AI-агента містить boilerplate-код - Інтеграція: об’єднуй модулі в робочий шлюз - Adversarial testing: розробляй 5–10 сценаріїв атак, перевіряй, чи система їх не пропускає - Моделювання загроз: визначаєш межі довіри, формат можливостей, схему аудиту - DevOps/розгортання: Docker-пакети, налаштування локального тестування - Наставництво: координуй роботу з Go-розробниками, спеціалістами з моделювання загроз, front-end-розробниками Вимоги (must-have): - 1+ років досвіду роботи з Go у сфері мереж та безпеки (або: 2+ років + глибокий досвід у вбудованих системах та системних технологіях) - Розуміння основ аутентифікації та криптографії (JWT, Ed25519, механізми політики, модель можливостей — не потрібно бути криптографом, але знати основи) - Архітектурне мислення (не просто писати код, а проектувати системи, розуміти моделі загроз, межі довіри) Бажано: - Досвід роботи з MCP або розуміння фреймворків агентів (OpenAI, Anthropic тощо) - Досвід роботи з API-проксі/шлюзами (nginx, Envoy — або їхні еквіваленти на Go) - Kubernetes / Docker у production - Сертифікати з безпеки (не обов’язково, але буде плюсом) - Досвід у виявленні шахрайства або поведінковій аналітиці - Контрибутор у проектах з відкритим кодом Що пропонуємо: ✓ Посада CTO ✓ Частка в капіталі: 15–25% (залежно від вкладу, обговорюємо) ✓ Цикл MVP → фінансування: створюємо MVP за 2–3 тижні, потім залучаємо фінансування (seed $500K+), потім — зарплата + премії ✓ Реальна проблема: це не side project, не «ще один SaaS» — реальна проблема для підприємств, гарячий ринок ✓ Повна автономія у технічних рішеннях (на початку) ✓ Доступ до AI code-generation (у ядрі) для прискорення, ти зосереджуєшся на архітектурі Процес: 1. 30 хв Zoom: Обговорюємо ідею, твій досвід, очікування 2. Пропозиція: Ми пропонуємо частку в капіталі + дорожню карту Це швидко. Ми не чекаємо 10 раундів співбесід Почни з нас, якщо: - Тебе цікавить безпека, а не лише інженерія - Ти розумієш різницю між виявленням LLM та забезпеченням безпеки - Ти готовий працювати в режимі стартапу (швидко, з невизначеністю, але на власних умовах як співзасновник) - Ти знаєш, що таке архітектура zero-trust - Ти можеш пояснити, чому «compromised agent ≠ capability execution» — це важливо P.S.
