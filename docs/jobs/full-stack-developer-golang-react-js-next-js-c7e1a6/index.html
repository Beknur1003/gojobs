Full Stack Developer (Golang, React.js & Next.js)

Intikom Berlian Mustika Kebayoran Lama, Jakarta опубликовано 6 ноября 2026

Go — основной язык Офис Контракт / B2B
PostgreSQLDockerLinuxCI/CDPythonTypeScriptReact
Deskripsi Pekerjaan Kami mencari kandidat yang memiliki pemahaman kuat dalam pengembangan backend dan frontend, khususnya menggunakan Golang serta framework JavaScript modern, untuk membangun aplikasi web yang scalable, reliable, dan memiliki performa tinggi. Jobdesk : • Mengembangkan, memelihara, dan meningkatkan aplikasi berbasis web sesuai kebutuhan bisnis dan operasional. • Merancang, membangun, serta mengintegrasikan layanan backend dan RESTful API. • Mengembangkan antarmuka frontend yang responsif, user-friendly, dan memiliki performa optimal. • Mengelola struktur database, melakukan optimasi query, serta memastikan integrasi data berjalan dengan baik. • Melakukan debugging, troubleshooting, dan optimasi performa aplikasi. • Menangani proses deployment dan pemeliharaan aplikasi menggunakan version control serta containerization tools. • Berkolaborasi dengan tim lintas fungsi untuk memahami kebutuhan bisnis dan memberikan solusi teknis yang efektif. • Memastikan aplikasi yang sudah berjalan tetap stabil, reliable, dan berfungsi dengan baik. KUALIFIKASI • Pendidikan minimal S1 jurusan Teknik Informatika, Ilmu Komputer, Sistem Informasi, Rekayasa Perangkat Lunak, atau bidang terkait. • Memiliki pengalaman minimal 1–2 tahun sebagai Full Stack Developer atau posisi serupa. • Menguasai Golang (Go) untuk pengembangan backend. • Memiliki pemahaman yang kuat mengenai React.js, Next.js, dan TypeScript untuk pengembangan frontend. • Memiliki pengalaman menggunakan PostgreSQL serta mengembangkan RESTful API. • Memahami HTML, CSS, JavaScript, dan pengembangan web responsif. • Berpengalaman menggunakan Git/GitLab, Docker, serta memiliki pemahaman dasar mengenai lingkungan server Linux. • Memiliki kemampuan analisis, debugging, dan problem solving yang baik. • Memiliki kemampuan komunikasi yang baik serta mampu bekerja sama dengan tim teknis maupun nonteknis. Kualifikasi yang diutamakan : • Familiar dengan Python scripting. • Memahami konsep dan implementasi CI/CD pipeline. • Memiliki pengalaman menggunakan application monitoring tools.
