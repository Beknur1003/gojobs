Senior DevOps Engineer | Federal Government | EL1 Equivalent • 12-month contract with one 12-month extension option and an estimated start date of 21 December 2026. • Hybrid across ACT with at least three days per week in the office. Up to 37.5 hours per week. • Australian citizenship required, along with the ability to obtain a Negative Vetting Level 1 (NV1) security clearance. Position Overview Lead complex cloud and data infrastructure work in a hands-on senior engineering role. You'll work closely with a local full-stack development team and business stakeholders to improve how applications are built, deployed and supported. You'll have the autonomy to solve complex technical problems, shape delivery priorities and advise senior leaders on decisions that affect core government operations. Key Duties • Design, build, deploy and support cloud and data infrastructure. • Prioritise the engineering work queue and manage delivery of key initiatives. • Apply integration best practices and maintain clear technical documentation. • Provide technical leadership within agile project teams and resolve complex delivery issues. • Work with business stakeholders to define requirements, agree on priorities and deliver project outcomes. • Manage internal and external stakeholder relationships and represent the organisation in discussions and negotiations. Skills and Experience Required Essential • Extensive hands-on experience designing, implementing and managing scalable infrastructure and services in AWS and/or Azure. • Strong experience implementing DevOps practices and building continuous delivery pipelines using tools such as GitLab, Artifactory and Jira. • Expertise using infrastructure as code tools such as Terraform to automate infrastructure provisioning and management. • Ability to configure and maintain enterprise platforms, particularly Control-M, Power BI, Talend and Snowflake. • Ability to write and maintain moderately complex code in Python, JavaScript and Go (Golang). • In-depth experience with containerisation, cluster deployment and orchestration using technologies such as Docker and Kubernetes. Desirable • Experience administering infrastructure across both AWS and Azure. • Familiarity with HashiCorp Vault for protecting sensitive data and managing cloud secrets. • Experience designing and managing CI/CD automation that uses AI agents with limited permissions for tasks such as automated remediation, documentation or testing.
