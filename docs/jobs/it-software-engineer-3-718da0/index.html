The IT, Software Engineer 3 is responsible for: • Microservices Development: Design and implement high-performance backend services using Golang and Ruby. • Backend Orchestration & APIs: Develop and operate Spinup’s collection of RESTful micro-service APIs that orchestrate resource provisioning across providers, implementing the layered orchestration pattern (e.g., Server API delegating to provider APIs such as EC2-API and VMware-API), asynchronous long-running task handling with status tracking, secure inter-service authentication, and a tag-based, rebuildable indexing model backed by ElasticSearch, all deployed as containerized services (ECS Fargate). • Cloud Integration: Develop and maintain integrations directly against the AWS API and other cloud provider interfaces. • Infrastructure as Code (IaC): Architect and manage cloud resources across AWS, Azure, and GCP using Terraform. • CI/CD Orchestration: Build and optimize automated deployment pipelines using Jenkins and GitHub Actions to ensure seamless delivery. • Security & Compliance: Implement and enforce Cloud IAM policies and network security configurations (VPCs, Security Groups, Firewalls) to meet NIST and HIPAA requirements. • Project Lifecycle Ownership: Lead the end-to-end execution of backend projects, from initial scoping and architectural design to deployment and post launch optimization. • Stakeholder Collaboration: Translate complex technical requirements for Product, Security, and Compliance teams, ensuring engineering goals align with business objectives. • Platform UI Development: Build and extend the Spinup self-service and managed web interfaces using the Laravel (PHP) MVC framework with Vue.js and Bootstrap, developing the controllers, Vuex stores, routes, and components that let users provision and manage cloud resources from pre-defined offerings. • Full-Stack Service Integration: Onboard new services into the UI end-to-end—implementing Laravel actions, controllers, web/API routes, and background jobs (e.g., Resource Delete, Resource Update) that call the backend microservice APIs, then designing the corresponding Vue create and view experiences with reusable, minimalist components. • Operations: Participate in an on-call rotation and managing cloud resource requests through ServiceNow to ensure high availability and enterprise-grade service delivery.
