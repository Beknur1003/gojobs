About Us AI coding is the largest use case of enterprise AI adoption today, as is evident from the success of Anthropic on Claude Code, Cursor’s $60B exit to SpaceX, and Cognition’s $48B valuation. The bottleneck now has moved from code generation to security and safety - AI agents write code faster than any team can review it, and over 65% of the lines of code produced by them are insecure. Vulnerabilities are piling up 16x faster than companies can fix them, and adversaries are able to exploit these new vulnerabilities within hours. AURI by Endor Labs closes that gap. It runs inside the harness where coding agents work, through hooks, skills and MCP, so the controls sit outside the model and every agent action is visible. Underneath is our patented code context graph, which maps code, open source, containers and infrastructure. It shows which vulnerabilities can actually be reached and exploited, then delivers fixes that won’t break the application. Security teams get evidence instead of noise, and developers get fixes instead of tickets. The companies building AI trust us to secure it - our customers include OpenAI, SpaceX, DoorDash, Dropbox, Atlassian, MongoDB, Snowflake, Robinhood and Peloton to name a few. Endor Labs is the third company from Founder & CEO Varun Badhwar, who built Prisma Cloud, the platform that helped define cloud security, from $0 to $300M ARR at Palo Alto Networks. We’ve raised $163M from Lightspeed, Coatue, DFJ Growth, Salesforce Ventures and Dell Technologies Capital. Software runs everything around our lives today - banking, hospitals, airports and power grids. AI now writes more of it every day, and our mission is to make sure the world can trust that software. Come build that future with us.
