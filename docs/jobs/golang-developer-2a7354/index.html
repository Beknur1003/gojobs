Golang Developer

We are looking for a Senior Golang Developer with 5+ years of core backend engineering experience to join our core architecture team. The ideal candidate possesses exceptional Data Structures & Algorithms (DSA) problem-solving skills, deep expertise in Low-Level Design (LLD), and extensive hands-on experience building scalable, high-throughput backend services using Go. Responsibilities: • Architecture and Development: Design, build, and maintain production-grade microservices and distributed backend systems using Go. • Low-Level Design (LLD): Write clean, extensible, modular, and maintainable code adhering to SOLID principles, OOP concepts (where applicable in Go design patterns), design patterns (e. g., Factory, Strategy, Builder, Decorator), and Clean Architecture principles. • Performance Optimisation: Apply advanced Data Structures and Algorithms (DSA) to write high-efficiency, memory-optimised algorithms. Diagnose performance bottlenecks, race conditions, and memory leaks using profiling tools like pprof. • Concurrency Management: Leverage Go's native concurrency primitives (goroutines, channels, select, sync. Mutex, sync. WaitGroup) to build efficient concurrent systems while preventing deadlocks and race conditions. • API and System Integration: Design robust RESTful and gRPC microservices APIs, integrating with message brokers (Kafka, RabbitMQ, NATS) and caching layers (Redis). • Data Management: Optimise complex database queries, schema designs, and indexing strategies across SQL (PostgreSQL, MySQL) and NoSQL (MongoDB) databases. • Quality and Code Reviews: Lead technical code reviews focusing on idiomatic Go practices, maintainability, and security. Enforce unit, integration, and benchmark testing using testing, Testify, or GoMock. Requirements: • Data Structures and Algorithms: Strong command of core data structures (Arrays, Linked Lists, Trees, Graphs, Hash Tables, Heaps) and algorithm design strategies (Dynamic Programming, Greedy Algorithms, Graph Traversals, Sliding Window). Ability to evaluate time and space complexity ($O(n)$ analysis). • Low-Level Design (LLD): Proven ability to model real-world business domains (e. g., Rate Limiters, Payment Gateways, In-Memory Caches, Task Schedulers, Notification Engines) using proper abstraction, interfaces, domain-driven design (DDD), and modular package structure. Core Golang Expertise: • 5+ years of professional backend software development with at least 3+ years of dedicated experience writing production-level Go. • Deep understanding of Go internals: Memory allocation (Heap vs. Stack, escape analysis), Garbage Collection tuning, and runtime execution model. • Hands-on experience with Go web frameworks (e. g., Gin, Echo, Fibre) and dependency management (go modules). Systems and Storage: • Proficiency with relational databases (PostgreSQL/MySQL) and writing optimised queries, transactions, and indexing. • Hands-on experience with caching solutions (Redis) and distributed queue/event systems (Kafka, RabbitMQ, or NATS). • Experience with API protocols: REST, gRPC, and Protocol Buffers. Bonus Skills • Exposure to High-Level Design (HLD) and distributed systems concepts (load balancing, circuit breakers, data partitioning, consensus protocols). • Experience containerising services with Docker, deployment on Kubernetes, and CI/CD automation. • Experience with observability tooling (OpenTelemetry, Prometheus, Grafana, Zap, Viper).
