Location : Bangalore (Hybrid) Build the Infrastructure That Secures the Cloud We're looking for a Senior Software Development Engineer to build highly scalable, cloud-native systems that help protect modern applications and infrastructure. You'll work on challenging problems across distributed systems, cloud platforms, microservices, security, and large-scale data processing, using Go as a core technology. This is an opportunity to have significant ownership and build systems that operate across multiple major cloud environments. What You'll Do : - Design and build high-performance, distributed backend services and data pipelines using Go. - Develop scalable microservices, APIs, and cloud-native applications. - Build integrations across AWS, Azure, GCP, IBM Cloud, and Oracle Cloud. - Solve complex challenges around scalability, reliability, performance, and cloud security. - Work closely with Product, Engineering, and Security teams to turn requirements into robust technical solutions. - Design and work with databases such as PostgreSQL and Graph databases. - Drive engineering quality through automated testing, TDD, code reviews, and Agile practices. - Contribute to cloud infrastructure using Terraform, CloudFormation, and Serverless technologies. What We're Looking For : - 5+ years of strong software development experience. - Excellent hands-on expertise in Go/Golang. - Strong background in distributed systems, microservices, backend platforms, or large-scale data processing. - Experience with at least one major cloud platform - AWS, Azure, GCP, IBM, or Oracle. - Hands-on experience with PostgreSQL or Graph databases. - Strong understanding of API design, scalability, reliability, and cloud-native architectures. - Exposure to Infrastructure as Code such as Terraform or CloudFormation. - Strong problem-solving and analytical skills with an ownership mindset. - Experience working with globally distributed engineering teams. Why This Role : You'll be working at the intersection of Cloud + Security + Distributed Systems - solving real engineering problems at scale and building technology designed for the next generation of cloud native applications. If you enjoy Go, distributed systems, cloud infrastructure, and solving complex engineering challenges, this is an opportunity to build systems that matter.
