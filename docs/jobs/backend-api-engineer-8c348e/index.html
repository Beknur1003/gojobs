Backend API Engineer (Golang) We're partnering with an innovative, growing technology company developing advanced software solutions for complex, data-intensive environments. Their platform helps organizations better understand, analyze, and manage critical infrastructure through sophisticated data processing and real-time intelligence. They're looking for a Backend API Engineer to join their engineering team, taking ownership of designing, building, and optimizing high-performance APIs that power their core platform. Key Responsibilities • Design, develop, and maintain scalable, high-performance RESTful APIs using Golang (Go). • Build and optimize API endpoints for reliability, security, and performance. • Work with PostgreSQL and MySQL databases, including schema design, query optimization, and performance troubleshooting. • Understand and navigate complex, interconnected software architectures to trace data flows and resolve technical issues. • Collaborate closely with frontend engineers, systems architects, and product teams to deliver new functionality. • Apply networking fundamentals to ensure APIs perform reliably across different infrastructure environments. • Troubleshoot production issues spanning application, database, and network layers. • Participate in code reviews, contribute to engineering best practices, and support continuous improvement. Required Qualifications • Professional experience developing backend software and APIs using Golang. • Strong understanding of RESTful API design, development, and best practices. • Hands-on experience with relational databases, particularly PostgreSQL and/or MySQL. • Proficiency in SQL, database performance optimization, and efficient query design. • Solid software engineering fundamentals, including concurrency, data structures, and error handling. • Experience working with complex software architectures and interconnected services. • Understanding of API security principles, including authentication, authorization, and rate limiting. • Strong problem-solving skills and the ability to work independently within a remote engineering team. Desirable Experience • Experience developing software for cybersecurity, networking, infrastructure, or data-intensive platforms. • Familiarity with network protocols such as TCP/IP, UDP, HTTP/S, DNS, and DHCP. • Experience with packet processing or low-level network programming. • Knowledge of Golang concurrency patterns and performance optimization. • Experience with OpenAPI or similar API documentation frameworks. • Additional programming experience with C, C++, or Rust. • Experience working in smaller engineering teams or fast-paced technology environments. Why Consider This Opportunity? • Fully Remote: Work remotely from anywhere within the United States. • Technical Ownership: Play a meaningful role in developing and scaling a sophisticated software platform. • Interesting Engineering Challenges: Work on high-performance APIs, complex systems, networking, and data processing. • Collaborative Environment: Work closely with experienced engineers across backend, frontend, systems, and product development. • Career Growth: Join a growing organization where your technical contributions can directly influence product development and engineering direction. Interested? If you're a Golang engineer who enjoys building robust backend systems, solving challenging technical problems, and working on innovative technology, we'd love to hear from you.
