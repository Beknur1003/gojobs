We are seeking a Senior Software Engineer to join our Audit Logging & Security Visibility team. This team builds the systems that record and surface security-relevant activity across DigitalOcean's cloud platform, so customers and internal teams can detect threats, investigate incidents, and prove compliance. In this role, you will own key parts of our audit logging systems — not just building features, but deciding how they should work, scale, and run in production. You'll work on high-throughput pipeline problems, help clear technical debt across the team, and raise the bar for the engineers around you. If you like combining deep technical work with growing influence across teams, this role is for you. What you'll do • Own Key Systems: Build and run reliable, high-throughput pipelines in Go that collect, clean up, and enrich audit events. • Build SIEM Integrations: Connect our logs to tools like Splunk, Datadog, Chronicle, and Microsoft Sentinel. • Improve the Audit Log Platform: Work on making our audit records tamper-proof, with clear retention rules and real-time access. • Support Security Visibility: Add features to the dashboard that brings together signals from IAM, network security, and threat detection. • Clean Up Tech Debt: Take the lead on fixing gaps in our logging and event standards, not just working through a backlog. • Design for Scale: Build data models that hold up under heavy load and fail gracefully when something breaks. • Handle Incidents: Help resolve production issues and write clear postmortems. • Work Across Teams: Partner with IAM, Threat Detection, and Platform teams so every part of the product sends clean, useful log data. • Mentor Others: Help junior engineers grow through code reviews and design feedback. • Apply Security Know-How: Use your understanding of audit requirements (like SOC 2 and ISO 27001) to keep our systems secure and compliant. What You'll Add to DigitalOcean • Education: Bachelor's or Master's degree in Computer Science, Engineering, or a related field. • Experience: 5–8 years in software engineering, with some experience in logging, security telemetry, or data pipelines — cloud experience is a plus. • Language Proficiency: Strong in Go; comfortable building services with gRPC. Python or JavaScript/Node.js is a bonus. • Streaming Systems: Hands-on experience with Kafka, Flink, or similar tools, and an understanding of how to avoid data loss or duplication. • Security Observability: Some experience building dashboards, control planes, or SIEM integrations. • Compliance & Distributed Systems: Basic understanding of SOC 2 or ISO 27001 audit needs; solid grasp of distributed systems basics like consistency and failure handling. • Cloud Native: Comfortable with Kubernetes, Terraform, SQL, and analytics databases. • Communication: Able to explain technical trade-offs clearly to both engineers and non-engineers.
