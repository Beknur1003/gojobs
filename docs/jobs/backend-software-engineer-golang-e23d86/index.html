We are seeking a Backend Software Engineer (Golang) to develop, maintain and support cloud-native backend applications within an enterprise environment. You will work with Golang microservices, Kubernetes and cloud platforms such as Amazon Web Services (AWS), Microsoft Azure or Google Cloud Platform (GCP), focusing on application reliability, deployment, monitoring and production troubleshooting. The role involves collaborating with cross-functional teams to maintain application performance, resolve technical issues and deliver continuous improvements within an Agile environment. Responsibilities • Design, develop and maintain backend applications and microservices using Golang • Deploy, manage and troubleshoot containerized applications running on Kubernetes • Develop and maintain microservices integrations with cloud platforms such as AWS, Azure or GCP • Monitor application health, performance and reliability using Datadog or equivalent observability tools • Investigate production incidents, perform root-cause analysis and implement corrective solutions • Troubleshoot application deployment, configuration and runtime issues within Kubernetes environments • Collaborate with development, infrastructure and operations teams to improve application stability and performance • Participate in Agile Scrum activities, including sprint planning, daily stand-ups, reviews and retrospectives Requirements • Strong hands-on experience developing backend applications and microservices using Golang • Solid practical experience deploying, managing and troubleshooting applications on Kubernetes • Experience developing and integrating backend microservices with at least one major cloud platform, such as AWS, Azure or GCP • Working knowledge of cloud-native architecture, containerization and distributed applications • Hands-on experience with Datadog or equivalent application monitoring and observability tools • Proven ability to investigate production issues, troubleshoot application failures and perform root-cause analysis • Experience working with CI/CD pipelines and automated deployment processes • Strong problem-solving, communication and collaboration skills, with experience working within Agile Scrum development teams Nice to have • Experience with web frontend technologies such as React, Vue.js, HTML and CSS •
