We’re hiring: Security Software Engineer 📍 Dhaka, Bangladesh | Full-time At PIPELINE, we build cybersecurity solutions that help organizations understand security risks and take action. We’re looking for an engineer who enjoys building software, exploring security problems and turning ideas into useful features. You will work with our development team and security experts to improve and develop new security capabilities. What you’ll do • Design, build and test security features, integrations and backend services. • Develop capabilities for asset discovery, exposure assessment and validation of security findings. • Build pipelines for threat intelligence ingestion, enrichment and deduplication. • Connect cloud services and security platforms through APIs. • Prototype new ideas and develop successful prototypes into maintainable production features. • Improve finding accuracy, explain supporting evidence and reduce false positives. • Document your work and collaborate with developers from design through release. What we’re looking for • Strong software development skills in Python or Go. • Experience building APIs, working with databases and writing automated tests. • Practical understanding of HTTP, DNS, TLS, Linux and cloud security. • Experience using Git and collaborating through code reviews. • Evidence of a security tool, integration or product feature you personally built. • Clear communication in English and the ability to take ownership of delivery. We welcome candidates with backgrounds in backend development, security engineering or security research who can demonstrate strong coding ability. Useful additional experience • Microsoft Graph, Entra ID or Microsoft 365 security. • AWS security and configuration assessment. • Threat intelligence platforms, MISP, STIX/TAXII or DNS security. • Vulnerability assessment and security automation. • Processing security findings and designing actionable recommendations. About PIPELINE PIPELINE is a cybersecurity company headquartered in Tokyo, with an R&D team in Dhaka. Our solutions help organizations continuously understand security exposure, verify evidence and manage improvements. This role offers the opportunity to contribute directly to business decisions and see your work become capabilities used by customers. To apply Please apply through LinkedIn with your CV and a brief description of a security tool, integration or feature you personally built. Include a GitHub link or non-confidential work sample if available, along with your expected monthly salary in BDT and notice period.
