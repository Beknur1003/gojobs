About Nebius: Nebius is leading a new era in cloud infrastructure for the global AI economy. We are building a full-stack AI cloud platform that supports developers and enterprises from data and model training through to production deployment, without the cost and complexity of building large in-house AI/ML infrastructure. Built by engineers, for engineers. From large-scale GPU orchestration to inference optimization, we own the hard problems across compute, storage, networking and applied AI. Listed on Nasdaq (NBIS) and headquartered in Amsterdam, we have a global footprint with R&D hubs across Europe, the UK, North America and Israel. Our team of 1,500+ includes hundreds of engineers with deep expertise across hardware, software and AI R&D. About the role We are looking for a Senior Infrastructure Security Engineer with a strong focus on Cloud Security Posture Management to improve the security of our foundational cloud services and production infrastructure. You will independently solve complex security problems requiring deep technical and domain knowledge. You will develop security capabilities within your product area, establish clear paths toward company-wide adoption, and partner with engineering teams to make security an integral part of system design. This is a hands-on engineering role combining CSPM, cloud security architecture, threat modeling, software development, identity and access management, and cloud-native infrastructure security. Responsibilities Cloud Security Posture Management • Own and evolve Cloud Security Posture Management capabilities across multiple cloud providers, with a particular focus on Wiz. • Use Wiz to detect, investigate, and prioritize cloud misconfigurations, excessive permissions, exposed resources, vulnerabilities, and control gaps. • Develop risk-based policies, custom rules, and severity models that reflect our architecture and threat landscape. • Define metrics for CSPM coverage, adoption, remediation performance, and measurable risk reduction. • Identify recurring and systemic causes of cloud misconfigurations and address them through secure defaults, preventive controls, policy as code, and reusable infrastructure patterns. • Partner with engineering teams to prioritize and remediate findings based on risk, exposure, business context, and potential attack paths. Security architecture and threat modeling • Conduct in-depth threat modeling and security reviews for foundational services such as Identity and Access Management, Key Management Systems, and other security-sensitive platform components. • Assess complex features and architectures to identify threats, attack paths, trust-boundary weaknesses, and appropriate security controls. • Independently investigate and solve complex security problems requiring deeper domain expertise. • Translate security risks and trade-offs into practical solutions that strengthen system design without unnecessarily constraining engineering teams. Security tools and integrations • Evaluate and compare potential solutions against technical, security, operational, and scalability requirements. • Integrate security tools end to end across common engineering and production scenarios. • Design and build scalable security solutions using Go, taking them from initial implementation to broader organizational adoption. Cloud security architecture • Define scalable security controls that account for differences between cloud providers while maintaining consistent security outcomes. • Partner with platform and infrastructure teams to embed security controls into cloud architectures and delivery processes. • Support the development of preventive and detective controls across multi-cloud environments. Linux, kubernetes and container security • Review the security of Kubernetes workloads, clusters, and platform components. • Partner with platform teams to securely deploy, operate, and maintain services in Kubernetes environments. • Help engineering teams to detect weaknesses and design and apply effective host-hardening, workload-isolation, and least-privilege practices. Security partnership and collaboration • Influence team roadmaps to ensure important security initiatives receive appropriate priority. • Empower teams through clear security guidelines, practical playbooks, reusable patterns, and security-awareness activities. • Promote secure-by-design practices and help teams take ownership of the security of their services. • Communicate complex security concepts clearly to security specialists, software engineers, and other stakeholders. What you’ll bring Cloud Security • Strong hands-on experience with Cloud Security Posture Management • Experience configuring CSPM policies, investigating findings, prioritizing risk, integrating remediation workflows, and reporting on security posture. • Experience using CSPM to analyze cloud context, exposure, permissions, vulnerabilities, and potential attack paths. Threat modeling and security reviews • Experience conducting threat modeling and security architecture reviews for distributed systems, foundational services, and cloud infrastructure. Software Engineering • Hands-on software engineering experience with Go. K8s/Linux security • Practical experience deploying and maintaining services in Kubernetes. • Working knowledge of Kubernetes architecture, workload abstractions, and security controls. • Experience securing Linux systems and containerized workloads. Security Partnership and collaboration • Strong collaboration skills and the ability to influence technical decisions and engineering roadmaps without direct authority. What success looks like • CSPM provides broad, reliable visibility across the organization’s cloud environments. • Cloud security issues have clear ownership and are remediated according to their risk. • Recurring misconfigurations are reduced through secure defaults, preventive controls, and reusable infrastructure patterns. • Engineering teams make better security decisions using the guidance, patterns, and tools you provide. • Solutions developed within one product area have a clear path toward wider organizational adoption.
