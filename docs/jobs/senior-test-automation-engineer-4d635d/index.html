Senior Test Automation Engineer

Hydden Remote опубликовано 31 июля 2026

Go — основной язык Удалёнка Senior Полная занятость
AWSAzureTypeScript
We are hiring a Test Automation Engineer to own the quality signal that protects our product as we ship. You will build and run the automation that catches defects early, keep staging trustworthy, and turn quality into measurable outcomes. This is a hands-on ownership role: you own the framework, suites, standards, and feedback loop, and you keep staging stable so that automation results can be trusted to gate production deployment. You will work across Go services and TypeScript UIs, in Azure and AWS, with a bias toward clear metrics and enforceable standards. Responsibilities: • Owns the content, stability, and efficacy of the automation suites. • Owns the test automation framework and enforces standards. • Owns the stability and maintenance of the staging environment. • Enforce test and coverage standards. • Implement and track quality metrics: defect MTTR, escaped defects, test execution time, etc. • Own cleanup and hygiene of the staging environment. Own automation framework and suites: • Own the test automation framework and enforce coding, structure, and review standards across the team. • Own the content, stability, and efficacy of automation suites and tests that are reliable, maintainable, and worth running. • Own automation development, orchestration, and results feedback so failures are visible, actionable, and routed to the right owners. Staging environment: • Own stability and maintenance of the staging environment used for automated and pre-release validation. • Own cleanup and hygiene of staging: stale data, orphaned resources, drift, and anything that makes results noisy or untrustworthy. Quality standards and metrics: • Enforce test and coverage standards as part of the delivery path. • Implement and track quality metrics, including defect MTTR, escaped defects, test execution time, and related signals that show whether quality is improving Requirements: • Experienced with test automation development, orchestration, and results feedback management. • Familiar with golang services and TypeScript user interfaces. • Experience operating in both Azure and AWS cloud environments. Stack and Environment: • Backend: Golang services. • Frontend: TypeScript user interfaces. • Cloud: Experience operating in both Azure and AWS.
