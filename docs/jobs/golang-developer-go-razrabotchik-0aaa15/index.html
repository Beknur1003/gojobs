О проекте Premiator - e-commerce платформа на Go: каталог с полнотекстовым поиском, корзина и заказы со state machine, внутренняя бонусная система с идемпотентными денежными транзакциями, push- и email-уведомления. Это не очередной CRUD — в проекте есть по-настоящему нетривиальные задачи: многоэтапный расчёт цены доставки с фолбэками, ledger-система с блокировками счетов, интеграции с несколькими внешними API. Мы нацелены на кандидатов уровня middle+ Чем предстоит заниматься: • Поддержка и развитие бэкенда: новые фичи, рефакторинг, разбор технического долга; • Работа с денежно-чувствительной логикой: бонусная система, идемпотентность, транзакции; • Интеграции с внешними сервисами: Яндекс.Доставка, push-уведомления (Expo/APNs), email (SMTP/DKIM), файловое хранилище (S3-совместимое); • Устранение и предотвращение уязвимостей безопасности (аутентификация, работа с секретами); • Написание и поддержка тестов: unit-тесты на моках, интеграционные тесты storage-слоя; • Участие в архитектурных решениях по мере роста системы. Наши ожидания: • Коммерческий опыт разработки на Go от 2-3 лет; • Опыт с веб-фреймворком уровня Gin/Echo/Fiber и ORM уровня GORM; • Уверенное владение MySQL/PostgreSQL: проектирование схем, транзакции, блокировки, миграции, оптимизация запросов; • Понимание слоистой архитектуры приложений (handler → service → storage) и готовность работать по принятым в проекте паттернам; • Осознанная работа с конкурентностью в Go: горутины, мьютексы, гонки данных; • Опыт работы с Docker / Docker Compose; • Умение самостоятельно разбираться в незнакомом коде и брать на себя ответственность за задачи без пошагового контроля. Будет плюсом: • Опыт с денежными/биллинговыми системами, идемпотентностью, ledger-паттернами; • Опыт с полнотекстовым поиском (Manticore, Elasticsearch, Sphinx); • Опыт интеграции с логистическими API и/или 1С; • Опыт security-аудита или практическое понимание типовых уязвимостей веб-приложений; • Опыт использования конечных автоматов (state machine) в бизнес-логике; • Знание Prometheus/Grafana для мониторинга; • Опыт код-ревью и менторства.
