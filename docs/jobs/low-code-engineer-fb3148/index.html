Low Code Engineer

The Low Code Engineer will be responsible for the maintenance, enhancement and stabilisation of an existing digital service, while supporting its transition towards a modern technology architecture. The engineer will perform hands-on technical work across the application lifecycle, including application development, production support, troubleshooting, deployment, technical documentation and migration activities. The application environment includes OutSystems, Oracle Policy Automation (OPA), Sitefinity CMS, Oracle Database and AWS infrastructure, together with associated operating-system, security and identity components. Application Development and Maintenance • Design, develop, test enhancements and defect fixes for applications developed using OutSystems. • Develop and maintain backend business logic, workflows, integrations and rules using OutSystems and, where applicable, Oracle Policy Automation. • Develop and maintain frontend functionality using OutSystems and Sitefinity CMS. • Develop and maintain Oracle Database components, including schemas, SQL queries, stored procedures and data-integrity controls. Production Support • Investigate and resolve application defects, production incidents, integration failures and performance issues. • Support application deployments, release activities, rollback and post-deployment verification. • Perform root-cause analysis and implement permanent corrective actions for recurring technical issues. Infrastructure, Security and Integration • Support application components hosted on AWS services including S3, Lambda, EC2, ELB, CodeDeploy and KMS. • Support application environments running on Amazon Linux 2023 and Windows Server 2016/2019. • Develop and support security and identity integrations involving enterprise directory services, SAML, access management platforms, endpoint security tools and API Gateway. Migration and Modernisation • Assess dependencies between the existing application and target architecture. • Support migration planning, including dependency identification, workstream sequencing, technical risk assessment, testing and cutover activities. • Support progressive transition from the existing technology stack towards the target modern architecture while maintaining continuity of the production service. Documentation • Produce and maintain technical documentation including solution designs, architecture diagrams, interface specifications, deployment procedures, operational runbooks and migration plans. Requirements • At least 3 years of hands-on application development experience using OutSystems • Completed at least one large-scale enterprise or public sector project involving an OutSystems-based production system with a total project or contract value of at least S$5 million. • Experience supporting at least one production application after go-live, including incident investigation, defect resolution or application enhancement. • Hands-on experience working with Oracle Database in an application-development or production support environment. • Experience working in an enterprise technology environment involving application development and one or more supporting technology areas, such as database, infrastructure, integration, security or identity components. Technical Skills: Must Have • Low Code Application Development • OutSystems • Database • Oracle Database Good to Have Experience in the following: • Oracle Policy Automation (OPA) / Oracle Intelligent Advisor (OIA) • Sitefinity CMS • AWS services, including S3, Lambda, EC2, ELB, CodeDeploy and KMS • Amazon Linux 2023 and Windows Server 2016/2019 • Enterprise directory services, SAML, access management platforms, endpoint security tools and API Gateway • CI/CD tooling such as GitLab or CodePipeline • Infrastructure and container security practices • Observability and monitoring tools (e.g. Dynatrace, Datadog, CloudWatch) • Familiarity with modern cloud-native stacks (ReactJS, Golang, Kubernetes) as a complement to legacy expertise Soft Skills • Strong problem-solving and debugging skills in production environments. • Clear communication with both technical and non-technical stakeholders. • Ability to work independently and take ownership of complex, ambiguous legacy systems.
