(Senior) Cloud Engineer (DevOps)

SHOPLINE Taipei, Taiwan опубликовано 11 ноября 2026

Senior
KubernetesTerraformAWSLinuxPython
【What you’ll be doing】 As a SHOPLINE Cloud Engineer, your primary responsibility is to enhance the availability, performance and reliability of all infrastructures supporting SHOPLINE products. You will be tasked with: - Automation: Have a strong focus on implementing workflow automation and optimizing developer experience. - Troubleshooting: Root cause analysis, capable of handling request errors by diving into upstream and downstream dependencies. - Deployment and config management. - Optimizations: performance tuning, enhancing architecture resiliency, refining automation mechanisms. - Define security policies for cloud infrastructures: AWS, Kubernetes and any resources access policy. - Oncall: critical incident mitigations, e.g. system malfunction recovery, DDoS attack. - Operating Kubernetes clusters: including routine upgrades and maintaining Kubernetes components availability. - Networking: design, implement and troubleshoot scalable network architectures. - Cost Awareness: implementing solutions with a focus on balancing cost efficiency and system reliability. 【Who we are looking for】 - Understanding of large-scale distributed systems in practice, covering multi-tier architectures, application security, monitoring, and storage systems. - Proficiency in Linux and willingness to dive into Linux kernels. - Expertise in at least one proxy service such as Nginx, CloudFront, Cloudflare, or similar products. - Expertise in Infrastructure as Code (IaC), e.g. Terraform. - Expertise in networking and cloud networking solutions - Strong scripting skills (Shell or Python preferred). 【It'd be plus if you have】 - Worked with a fast-paced startup. - Expertise in constructing and managing e-commerce infrastructure. - Familiarity with at least one programming language (e.g. Python and Golang).
