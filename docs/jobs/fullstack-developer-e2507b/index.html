Fullstack Developer

KafkaTerraformAWSGCPAzureTypeScriptNode.jsReactAI/LLM
In this role, you will play a key part in designing, scaling, and maintaining high-throughput platforms that facilitate critical digital transactions and data flows. Key Responsibilities: • Architect, develop, and deliver resilient full-stack applications with an emphasis on high performance, scalability, and robust system availability. • Own end-to-end technical system design and drive architectural decisions alongside product and cross-functional teams. • Uphold and elevate software engineering rigor through technical direction, code reviews, and mentorship. • Implement automated testing, observability, and infrastructure-as-code to streamline deployments and rapidly troubleshoot production systems. • Explore and integrate modern development methodologies and AI-accelerated workflows to optimise engineering delivery. Requirements: • At least 5 years of hands-on full-stack production software development experience. • Strong technical background in modern web and backend stacks: TypeScript, Node.js, React, and/or Golang. • Proven relational database design and SQL expertise. • Solid exposure to major cloud platforms (AWS, GCP, or Azure) along with Infrastructure as Code (e.g., Terraform). • Strong fundamentals in automated testing frameworks (unit, integration, and E2E) and agile delivery practices. Advantageous: Exposure to distributed systems, event streaming/message queues (e.g., Kafka), high-throughput data processing, or LLM/AI integrations.
