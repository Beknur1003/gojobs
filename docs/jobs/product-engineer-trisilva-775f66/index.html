Role Overview We are seeking a high-agency Fullstack Product Engineer (Golang + ReactJS) who takes full accountability for product outcomes, not ticket output. In this role, you own features from initial ambiguity, through architecture and implementation, to live production behavior and telemetry. Operating with an AI-first engineering workflow, you will use AI coding agents as your daily delivery leverage while acting as the ultimate author of record—holding an uncompromising bar on system fundamentals, Clean Architecture, relational data integrity, and automated safety nets. Working alongside cross-border product and design teams, you will drive technical decisions asynchronously and ship resilient full-stack slices that solve real user problems. Key Responsibilities • Take business initiatives from vague requirements to shipped, measured results; challenge unnecessary features early, instrument key metrics, and refine or rewrite solutions based on real production data. • Architect Go-based microservices and RESTful/gRPC APIs applying SOLID, Clean/Hexagonal Architecture, and 12-factor principles; design normalized, indexed, migration-safe relational schemas (PostgreSQL/MySQL) capable of scaling under load. • Build and ship end-to-end user-facing flows using ReactJS (or modern frameworks like Next.js), ensuring intuitive UI execution, responsive performance, and clean API integration. • Lead delivery using coding agents (Cursor, Claude Code, Copilot) via spec-driven engineering, custom agent skills, and prompt guardrails; rigorously review generated code to reject over-abstraction, silent errors, or hollow tests. • Own automated testing (unit, integration, contract, E2E) shipped within the same PR; ensure every fix has a reproducing test so agent-assisted changes can merge safely at high velocity. • Deploy, containerize, and run Go microservices on open-source Kubernetes and Docker; instrument services with structured logs, metrics, and tracing to triage incidents and deliver permanent postmortem fixes. • Communicate clearly and proactively across time zones; document technical decisions, specs, and PRs thoroughly in English to unblock globally distributed team members without requiring synchronous meetings. Key Requirements • 5+ years building and operating production backend services; hands-on experience designing microservices architectures (service boundaries, sync/async communication, failure isolation) alongside pragmatic judgment on when a monolith is preferred. • Hands-on production Go engineering experience, including active, continuous production use within the last 12 months. • Practical, working capability in ReactJS (Next.js or Vue) to independently build, integrate, and ship complete frontend slices. • Deep command of OOP, SOLID, Clean Architecture, and design patterns; ability to critique architectures, anticipate failure points at scale, and defend decisions in code reviews. • Proven proficiency in relational databases (PostgreSQL/MySQL—indexing, isolation levels, transactions, query optimization, migrations) and robust RESTful API design (versioning, idempotency, pagination, error schemas). • Practical working experience with open-source Kubernetes (deployments, configs/secrets, probes, limits) and Docker; disciplined adherence to 12-factor application standards. • Strong testing discipline across the test pyramid; experience writing meaningful tests with proper test doubles, refusing superficial coverage targets. • Daily production experience leveraging AI agents (Cursor, Claude Code, Copilot) with spec/context engineering, custom instructions, and disciplined pre-PR self-review to catch plausible-but-incorrect code. • Fluent professional written English, comfortable working asynchronously across time zones, and driven by a strong bias for shipping iteratively. Bonus Points (Nice to Have) • In-depth ReactJS / Next.js expertise (SSR, RSC, advanced state management, performance profiling). • Experience with gRPC, HTTP/2 streaming, Server-Sent Events (SSE), or real-time AI-streaming interfaces. • Hands-on ownership of CI/CD pipelines (GitHub Actions, GitLab CI) with automated security and quality gates. • Infrastructure as Code experience using Terraform, Helm, or Pulumi. • Observability and SRE background (OpenTelemetry, Datadog, Prometheus/Grafana, SLOs, incident response). • Familiarity with event-driven systems, message queues (Kafka, RabbitMQ), or media streaming protocols (HLS/M3U8). What We Offer • Work-from-home options and flexible working hours evaluated by what lands in production and how it performs, not hours spent online. • Daily engagement with product, design, and engineering leaders distributed across multiple regions. • Attractive remuneration package, performance incentives, and clear engineering leadership pathways. • Engaging team-building activities, annual company trips, and an engineering culture that prizes substance and technical rigor over bureaucracy.
