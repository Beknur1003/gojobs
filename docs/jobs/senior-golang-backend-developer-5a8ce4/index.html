Job Description : We are looking for a skilled Backend Developer with strong expertise in Go (Golang), networking, distributed systems, and cloud-native technologies. The ideal candidate should have hands-on experience building high-performance backend services and distributed microservices, along with a strong understanding of network protocols, VPN technologies, Linux networking, security, and real-time monitoring. The role involves designing and developing scalable backend services that interact closely with networking and infrastructure components. Key Responsibilities : - Design, develop, and maintain scalable backend services using Go (Golang). - Build and maintain distributed microservices-based architectures for high-availability systems. - Develop concurrent and performance-sensitive applications using Go's concurrency features. - Design and implement RESTful and gRPC APIs for internal and external services. - Work on network programming and integration with Linux-based networking environments. - Develop and maintain solutions involving OSPF routing, IPsec VPN, VTI, and network interfaces. - Integrate network monitoring and management capabilities using SNMP, SNMP traps, and real-time monitoring systems. - Develop software components for network configuration, monitoring, automation, and orchestration. - Work with Linux networking concepts including routing, interfaces, sockets, TCP/IP, DNS, and network troubleshooting. - Implement secure authentication and authorization mechanisms using OAuth 2.0, JWT, mTLS, and related security technologies. - Design secure APIs and ensure adherence to application and network security best practices. - Analyze and optimize application performance, latency, resource utilization, and system reliability. - Troubleshoot complex issues across application, networking, and infrastructure layers. - Work with Docker, Kubernetes, and cloud-native infrastructure to deploy and operate backend services. - Collaborate with DevOps, network engineering, cybersecurity, and infrastructure teams. - Participate in architecture discussions, code reviews, technical design, testing, and production support. - Develop monitoring, logging, alerting, and observability capabilities for distributed services. Required Technical Skills : 1. Go / Backend Development : - Strong hands-on experience with Go (Golang). - Strong understanding of Go concurrency, goroutines, channels, synchronization, and memory management. - Experience developing scalable and high-performance backend applications. - Strong knowledge of microservices architecture and distributed systems. - Experience developing RESTful APIs and gRPC services. 2. Networking : - Strong understanding of TCP/IP, routing, networking fundamentals, and Linux networking. - Hands-on experience with OSPF routing protocols. - Strong knowledge of IPsec VPN and Virtual Tunnel Interfaces (VTI). - Experience with network programming and network configuration/automation. - Experience with SNMP integration, SNMP traps, monitoring, and alerting. - Understanding of network troubleshooting and real-time network monitoring. 3. Security & APIs : - Experience implementing secure APIs and authentication mechanisms. - Strong understanding of OAuth 2.0, JWT, mTLS, authentication, and authorization. - Good understanding of application and network security principles. - Experience securing microservices and API communication. 4. Cloud & Infrastructure : - Experience with Docker and Kubernetes. - Understanding of cloud-native architecture and distributed infrastructure. - Exposure to AWS, Azure, or GCP is preferred. - Experience with CI/CD, observability, logging, and monitoring tools is an advantage. Preferred Skills : - Go / Golang - Distributed Microservices - Linux Networking - Network Programming - OSPF - IPsec VPN - VTI - SNMP / SNMP Traps - REST APIs - gRPC - OAuth 2.0 / JWT - mTLS - Authentication & Authorization - Docker / Kubernetes - Cloud Native Architecture - Network Security - Real-Time Monitoring
