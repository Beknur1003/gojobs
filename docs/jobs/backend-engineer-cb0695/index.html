Deskripsi Pekerjaan • Mengembangkan bagian belakang (back end) dari aplikasi menggunakan bahasa pemrograman Go (Golang) untuk memastikan kehandalan dan kinerja sistem. • Merancang, mengimplementasikan, dan memelihara solusi back end yang efisien dan skalabel. • Mengintegrasikan aplikasi dengan berbagai jenis database seperti MySQL, PostgreSQL, atau NoSQL databases menggunakan Golang. • Merancang dan mengimplementasikan API (Application Programming Interface) untuk mendukung komunikasi antara bagian-bagian aplikasi. • Menganalisis, mendeteksi, dan memperbaiki masalah teknis dalam pengembangan back end dengan menggunakan keterampilan debugging yang kuat • Berkomunikasi dengan tim Frontend untuk integrasi API • Berkomunikasi dengan Product Owner untuk implementasi kebutuhan bisnis • Berkomunikasi dengan Product Manager untuk update progres pekerjaan” Syarat Pekerjaan • Gelar Sarjana dalam bidang Ilmu Komputer, Sistem Informasi, atau bidang terkait • Pengalaman minimal 1 tahun sebagai Backend Engineer atau posisi serupa dalam pengembangan dan analisis sistem • Mahir dalam bahasa pemrograman Go (Golang) dengan kemampuan untuk mengembangkan solusi back end yang berkualitas. • Memiliki sikap kerja keras yang ditunjukkan melalui dedikasi dalam menyelesaikan tugas dan mencapai tujuan. • Berkomitmen untuk memelihara sikap yang baik dalam berinteraksi dengan tim dan menghadapi tantangan dalam pengembangan perangkat lunak. • Memiliki pemahaman yang baik tentang konsep dasar pengembangan perangkat lunak, termasuk pengelolaan database dan pengembangan API. • Kemampuan komunikasi yang baik dan kemampuan untuk bekerja secara efektif dalam tim.”
