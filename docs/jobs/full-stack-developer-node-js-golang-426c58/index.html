Minimum 1 year of practical experience with Agentic AI / AI-assisted development tools is mandatory. Key Responsibilities: - Design, develop, test, deploy, and support scalable backend applications and REST APIs. - Build business logic, integrations, and backend services using Node.js/TypeScript or Golang. - Contribute to React.js or Flutter development, including API integration and debugging. - Work with SQL databases and optimize queries, schemas, indexing, and transactions. - Participate in system design and troubleshoot issues across application, API, database, and infrastructure layers. - Effectively use AI coding tools while reviewing, validating, and testing AI-generated code. - Collaborate with Engineering, QA, Product, Design, and DevOps/SRE teams.
