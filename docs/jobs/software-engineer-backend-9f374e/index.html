The Role: As Software Engineer, Backend, you will be integral to building, scaling, and maintaining our microservices architecture, driving the performance and reliability of our core platform. The ideal candidate should possess a strong background in backend engineering and system design - particularly in Golang - demonstrate exceptional problem-solving abilities, and exhibit enthusiasm for actively contributing to the achievements of the leading startup within the EdTech sector of Bangladesh. Key Roles & Responsibilities: • Owning assigned microservices end-to-end on a quarterly basis across our fleet of 30+ services (e.g., live class, core, gateway, live exam, machinary, kpi, analytics, anubadok, Shikho AI). • Designing and building scalable, high-throughput microservices in Golang with comprehensive test coverage. • Hands-on RAG (Retrieval-Augmented Generation) engineering: building and maintaining retrieval pipelines, embedding stores, and evaluation datasets for AI-powered services (e.g., anubadok, Shikho AI). • Debugging, troubleshooting, and resolving production issues, while optimizing endpoint performance and overall system health. • Translating product and platform requirements into robust technical architectures and participating in technical design discussions. • Representing the Backend platform in cross-platform API design (REST/GraphQL) and collaboration with Mobile and Product teams. • Maintaining complete technical documentation, service specifications, and system diagrams for owned microservices. • Working in an AI-native engineering environment using agentic IDEs and coding assistants (e.g. Claude Code, Cursor) to deliver daily agent-generated diffs. • Leveraging AI assistance to generate unit tests, test fixtures, database migration scripts, and run efficient production log analysis for root-cause hypothesis generation. • Utilizing AI tools to draft PR descriptions, RFCs, technical documentation, and service runbooks following team playbooks. • Contributing to AI context engineering (prompts, agent skills, context files) and workflow optimization for cost-effective AI utilization. • Participating in code reviews, sharing effective AI prompt workflows, and mentoring junior engineers. • Coordinating with cross-functional teams to ensure strict deadlines and sprint planning guidelines are met. • Working collaboratively within the engineering team to offer support whenever needed to achieve system objectives. Qualifications and Skills: • Minimum 3–4 years of professional experience in backend software development, with a core focus on distributed microservices architectures. • Proven track record of designing, building, and delivering high-volume, low-latency microservices and API endpoints. • Strong proficiency in the specified tech stack: Golang, PostgreSQL, MongoDB, ArangoDB, Redis, REST/GraphQL, Docker, and Weaviate (vector search/RAG). • Hands-on experience or deep familiarity with AI/RAG architectures, including embedding stores, vector databases, retrieval pipelines, and model evaluation datasets. • Experience writing comprehensive test suites (unit/integration), managing test fixtures, and handling database migration strategies. • Demonstrable adaptability to an AI-native workflow, with familiarity using agentic IDEs (Cursor/Claude Code), context engineering, prompt optimization, and daily AI-assisted shipping. • Exceptional problem-solving skills, root-cause debugging capabilities (log analysis), and a metrics-driven approach to service health and latency optimization. • Strong collaborative skills to translate technical specifications into clean designs and represent backend architectures across multi-team discussions.
