Job Description Senior Golang Engineer Location: Bristol, UK Working pattern: Hybrid Rate: £400 per day We're looking for a Senior Golang Engineer to join a specialist engineering team within a large financial services organisation, working on technology that supports the security of high-scale mobile applications. The team is responsible for developing a suite of mobile security components and associated services, helping mobile engineering teams operate securely and confidently in an evolving threat landscape. This is a hands-on Back End engineering role, focused on building secure, scalable and high-performance services using Go, alongside modern cloud, containerisation and DevOps technologies. What you'll be doing • Designing and developing secure, scalable, enterprise-grade applications using Go • Building and maintaining REST APIs and microservices • Working with containerisation technologies including Docker and Kubernetes • Contributing to DevOps practices including infrastructure automation, CI/CD and deployment strategies • Designing Back End services capable of meeting performance • Collaborating closely with other engineers while also taking ownership of individual technical areas • Contributing to coding standards, code management, Agile development and continuous delivery practices • Working on technology with a strong focus on application and mobile security What we're looking for • Extensive commercial experience developing secure, scalable Go applications • Strong experience with REST APIs, microservices and containerised environments • Good understanding of Docker and Kubernetes • Experience with DevOps practices including CI/CD, infrastructure automation and deployment strategies • Experience working with cloud platforms • Strong understanding of software engineering best practices and Agile development • Experience optimising and fine-tuning Back End applications against demanding NFRs • Strong analytical and problem-solving skills • Experience with observability and monitoring tools such as Splunk or Dynatrace • Comfortable working collaboratively within a team while also taking ownership and working independently Desirable experience • Experience developing with Java • Experience with cryptography frameworks in Go
