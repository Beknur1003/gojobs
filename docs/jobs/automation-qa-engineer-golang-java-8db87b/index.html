Overview: FinteqHub is hiring an Automation QA Engineer (Golang / Java) to join our Backoffice team. We’re considering both Mid-Level and Senior professionals who can help improve integration test coverage and reliability across Backoffice services, supporting stable releases and the transition from Java-based testing to Go. About Product: Finteqhub А PCI DSS certified payment gateway for online businesses, providing integration with payment systems via a single software platform. Learn more Purpose of the Role: You will take part in shaping the testing strategy and coverage for Backoffice services, including which checks are maintained alongside Go services, which remain in the Java suite, how tests are executed, and how results are reported. You’ll work within the team’s established processes, test harness, CI pipelines, and reporting systems to develop integration tests in Go within the service repositories. You’ll migrate relevant checks from the Java suite closer to the service code, ensure test results remain visible, and maintain the remaining Java tests throughout the transition. Tech Stack: Go, PostgreSQL, Redis, Kafka, Docker, testcontainers, and GitHub Actions. The existing regression coverage also includes a Java test suite (TestNG, Maven), with reporting in ReportPortal. Key Responsibilities: • Develop and maintain Go integration tests for Backoffice services using real infrastructure dependencies and the team’s existing test harness. • Own the testing backlog for Backoffice services, prioritising coverage, selecting the appropriate testing level, and determining which checks should remain in the Java suite. • Migrate selected test scenarios from Java to Go within the service repositories, preserving relevant checks and removing those that are no longer needed. • Integrate tests into existing CI pipelines and maintain reliable test execution, ensuring clear visibility of results, investigating failures, and fixing or explicitly retiring flaky tests. • Maintain the remaining Java tests until they are migrated or removed. • Collaborate with Backoffice engineers to improve service testability while following existing testing patterns and reporting standards. Required Experience: • Solid hands-on experience with Go, including writing maintainable tests and reusable helpers within existing services, rather than one-off scripts. • Practical experience with integration testing using real dependencies (databases, caches, or message brokers) via Docker or testcontainers. • Ability to determine when unit testing is sufficient, when integration testing is needed, and when end-to-end testing is unnecessary. • Experience testing HTTP APIs, including API clients, contracts, and behavioural assertions. • Experience running automated tests in CI and investigating failures through logs and data, rather than simply rerunning tests. • Experience taking ownership of testing end to end, including coverage, test execution, and failure triage. • Ability to read Java code, maintain existing tests, and migrate relevant checks to Go. • Ability to work effectively within established testing frameworks and processes. • English proficiency at B1 level or higher. • Native-level proficiency in Russian. Nice to Have: • Experience migrating automated test suites between programming languages or frameworks. • Familiarity with TestNG, OpenFeign, ReportPortal, and Kafka clients. • Experience with PostgreSQL, Redis, Kafka, etcd, and testcontainers-go. • Understanding of fintech or payment systems, including payment flows, operation statuses, and idempotency. • Experience using AI tools to generate or migrate tests, with the ability to evaluate the accuracy and reliability of generated checks. • Experience with UI test automation using JavaScript, TypeScript, or Playwright. Our Benefits: • Full-time remote work opportunities and flexible working hours • Private insurance • Additional 1 Day Off per calendar year • Sports program compensation • Comprehensive Mental Health Programme • Free online English lessons with a native speaker • Generous referral program • Training, internal workshops, and participation in international professional conferences and corporate events.
