Backend Engineer (Golang & AI) Tugas dan Tanggung Jawab: * Merancang, mengembangkan, dan memelihara backend services dan REST API menggunakan Golang dengan Fiber. * Merancang dan mengembangkan aplikasi berbasis Microservices Architecture dan SaaS Architecture. * Merancang, mengelola, dan mengintegrasikan aplikasi dengan database seperti MongoDB dan MySQL. * Menulis kode Golang yang reusable, testable, scalable, maintainable, dan efficient. * Membangun dan mengelola business logic serta server-side application. * Merancang, mengembangkan, dan mendokumentasikan API yang efektif dan scalable. * Mengembangkan dan mengintegrasikan AI/LLM capabilities ke dalam aplikasi dan produk perusahaan. * Mengintegrasikan backend dengan berbagai AI/LLM models dan APIs, seperti OpenAI, Claude, Gemini, atau model lainnya. * Mengembangkan fitur berbasis AI Agent, AI Chatbot, RAG, Function Calling/Tool Calling, AI Automation, dan intelligent assistant. * Mengembangkan backend yang memungkinkan AI berinteraksi dengan database, internal API, external API, dan business workflow secara aman dan terkontrol. * Mengembangkan dan mengelola knowledge retrieval dan data processing pipeline untuk kebutuhan AI. * Melakukan testing, debugging, troubleshooting, dan optimasi performa aplikasi. * Melakukan monitoring dan observability menggunakan Kafka, Grafana, logging, metrics, tracing, atau tools sejenis. * Melakukan maintenance dan security update untuk menjaga keamanan, reliability, dan perlindungan data. * Mengembangkan dan menerapkan aplikasi pada Google Cloud Platform (GCP). * Menggunakan Docker dan Kubernetes untuk deployment dan management aplikasi. * Membuat dan mengelola CI/CD pipeline untuk otomatisasi build, testing, dan deployment. * Berkolaborasi dengan Product, Frontend, Mobile, QA, Infrastructure, dan tim terkait dalam pengembangan produk. * Mengikuti perkembangan teknologi Backend, Cloud, AI, LLM, dan Software Architecture serta menerapkannya sesuai kebutuhan produk. Kualifikasi dan Keahlian: * Pendidikan minimal S1 Teknik Informatika, Sistem Informasi, Ilmu Komputer, atau bidang terkait. * Pengalaman minimal 3 tahun sebagai Backend Developer / Backend Engineer. * Wajib menguasai Golang dan memiliki pengalaman menggunakan Fiber Framework. * Memahami dengan baik konsep REST API, HTTP, authentication, authorization, API security, dan backend development. * Memiliki pengalaman dengan MongoDB dan MySQL. * Memahami Microservices Architecture dan SaaS Product Architecture. * Memiliki pengalaman menggunakan Google Cloud Platform (GCP). * Familiar dengan Docker dan Kubernetes, termasuk deployment dan troubleshooting aplikasi. * Memiliki pengalaman dalam membangun dan mengelola CI/CD pipeline. * Familiar dengan Kafka / Message Broker / Event Streaming. * Familiar dengan application monitoring dan observability, seperti Grafana, logging, metrics, dan tracing. AI / LLM: * Memiliki pengalaman atau pemahaman dalam mengembangkan aplikasi yang menggunakan AI/LLM. * Terbiasa melakukan integrasi dengan LLM API, seperti OpenAI, Claude, Gemini, atau provider/model lainnya. * Memahami konsep dasar: - LLM (Large Language Model) - Prompt Engineering - RAG (Retrieval-Augmented Generation) - Embeddings - Vector Database - Function Calling / Tool Calling - AI Agent / Agentic Workflow - Context & Conversation Management * Familiar dengan Vector Database seperti Qdrant, Pinecone, Weaviate, atau teknologi sejenis menjadi nilai tambah. * Memahami integrasi AI dengan database, API, business logic, dan external services. * Memahami konsep AI security, data privacy, hallucination handling, validation, dan access control menjadi nilai tambah. * Pengalaman membangun AI Agent, AI Chatbot, Customer Service AI, AI Automation, atau AI-powered SaaS menjadi nilai tambah. * Familiar dengan LangChain, LlamaIndex, AI SDK, atau LLM orchestration tools menjadi nilai tambah. * Memahami AI model evaluation, token/cost optimization, prompt testing, dan AI usage monitoring menjadi nilai tambah. Additional Skills: * Menguasai atau familiar dengan JavaScript / TypeScript. * Familiar dengan NestJS / Express / Angular menjadi nilai tambah. * Memahami konsep Data Warehouse, Data Lake, Data Hub, Data Mart, dan data processing menjadi nilai tambah. * Memiliki pengalaman atau pemahaman mengenai Machine Learning / AI / Data Engineering menjadi nilai tambah. * Memahami sistem pembayaran Indonesia seperti QRIS, BI-FAST, Switching, E-Wallet, Payment Gateway, dan EDC menjadi nilai tambah. * Memiliki pengalaman mengembangkan SaaS / Multi-Tenant Application menjadi nilai tambah. * Google Cloud certification menjadi nilai tambah. Technology Stack: • Programming Language: * Go / Golang — Primary * JavaScript / TypeScript • Backend: * Fiber * REST API * Microservices • AI / LLM: * OpenAI / Claude / Gemini * LLM API * RAG * Embeddings * Vector Database * AI Agent * Function Calling / Tool Calling * LLM Orchestration • Database: * MongoDB * MySQL * Vector Database Message Broker & Monitoring * Kafka * Grafana * Logging / Monitoring / Observability • Infrastructure: * Google Cloud Platform * Docker * Kubernetes * CI/CD Soft Skills: * Strong analytical and problem-solving skills. * Detail oriented dan memiliki ownership terhadap pekerjaan. * Mampu bekerja secara mandiri maupun dalam tim. * Memiliki kemampuan komunikasi yang baik. * Cepat beradaptasi dengan teknologi baru. * Memiliki curiosity dan ketertarikan tinggi terhadap perkembangan AI dan teknologi software engineering. * Mampu memahami kebutuhan bisnis dan menerjemahkannya menjadi solusi teknis yang scalable.
