We are looking for a hands-on Senior DevOps Engineer with strong expertise in Platform Engineering, DevSecOps, and cloud automation. In this role, you will design, build, deploy, and support scalable cloud solutions across Google Cloud Platform (GCP) environments. You will collaborate with engineering, security, and product teams to deliver secure, reliable, and cost-effective cloud services while reducing operational overhead through automation. The successful candidate will possess strong technical leadership skills, experience managing distributed cloud workloads, and the ability to translate business requirements into scalable technology solutions. • Design, deploy, and support cloud-native solutions across Google Cloud Platform (GCP). • Provide operational ownership for critical cloud services and participate in on-call support rotations. • Develop and maintain infrastructure as code using Terraform. • Build and manage CI/CD pipelines using Tekton Pipeline as Code (PAC). • Develop and deploy automation tools and APIs using Python. • Support application deployments on OpenShift and manage GitOps implementations using ArgoCD. • Manage GCP services including Google Compute Engine (GCE), Cloud Run, Cloud Tasks, Batch, Cloud Scheduler, Pub/Sub, Google Cloud Storage (GCS), and Security Token Service (STS). • Implement and maintain Identity and Access Management (IAM) roles, policies, and security controls. • Ensure High Availability (HA), Disaster Recovery (DR), and operational resilience using Site Reliability Engineering (SRE) principles. • Monitor platform health and performance using observability tools such as Dynatrace. • Lead cloud patching, vulnerability remediation, and security compliance initiatives. • Drive cloud cost optimization and improve developer self-service capabilities. • Contribute to cloud architecture decisions and technology roadmaps. Required Qualifications • Bachelor's degree in Computer Science, Engineering, or a related technical field. • 8+ years of experience in cloud engineering, DevOps, platform engineering, or infrastructure automation. • 3+ years of experience in a senior technical or leadership role. • Strong hands-on experience with Google Cloud Platform (GCP). • Experience administering Google Compute Engine (GCE), Cloud Run, Cloud Tasks, Pub/Sub, Cloud Scheduler, Batch, Google Cloud Storage (GCS), and Identity and Access Management (IAM). • Hands-on expertise in Terraform and Infrastructure as Code (IaC) practices. • Strong scripting and software development experience using Python. • Experience deploying and managing applications on OpenShift. • Experience implementing GitOps practices using ArgoCD. • Understanding of DevSecOps, cloud security, and compliance best practices. • Experience implementing High Availability (HA) and Disaster Recovery (DR) solutions. • Strong troubleshooting, communication, and stakeholder management skills. Preferred Qualifications • Experience with Red Hat Developer Hub. • Knowledge of React-based portal development and customization. • Experience with Golang. • Experience leading cloud modernization initiatives. • Background in enterprise-scale cloud platforms and automation ecosystems. #LI-MF2
