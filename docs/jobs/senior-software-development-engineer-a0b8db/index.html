The opportunity to improve health on a global scale stands before us. Job Description Meet the Team: We are hiring for a Staff Software Engineer to join our team in Bengaluru (Bangalore), India. In this role, you will be a key contributor to the Data Platforms team and the larger Dexcom Software and Data Organization. You will work with Data Platform Engineers to build the infrastructure to support our data pipelines, storage, and API through which reliable, clean, meaningful data is provided to internal and external stakeholders. At Dexcom, you can use your data engineering skills for the greater good. We develop software for medical devices and systems, adhering to the rigorous requirements of regulatory agencies such as ISO and FDA. If you enjoy connecting the dots, using data-driven engineering decisions, and innovating through the server side of our entire platform stack, you’ll enjoy this job. Where You Come In: • You will build cloud-based, event-driven software systems with high availability, scalability, and resilience, as part of a multi-disciplinary team that works within an Agile methodology environment. • You will work with the data scientist team to build machine learning pipelines. • You will contribute to software across the development lifecycle, including software design and architecture, code development, functional and performance testing, and documentation and design verification. • You will identify, champion, and work to implement improvements in internal processes, including automating manual processes, optimizing data delivery, and optimizing software infrastructure for better scalability, maintainability, and cost efficiency. • You will contribute to code reviews and champion best practices for quality control, software testing, and code development/deployment in an agile environment. • You will participate in on-call rotation for production systems when required. • You will protect the confidentiality and security of client data. What Makes You Successful: • You must have strong programming skills in Kotlin, Java, Golang • You have experience with message brokers, queues, and buses like Kafka, Azure Service Bus, ZeroMQ, NoSQL databases etc. • You have experience with relational databases like MySQL and NoSQL databases like Cassandra. • You are familiar with using relevant, modern software test tools and equipment. • You have a proven ability to learn new tools and technology. • You have demonstrated the ability to work in a fast-paced and changing environment with short deadlines, interruptions, and several simultaneous tasks and projects. • You must have a strong frontend development exposure. What you’ll get: • A front row seat to life changing CGM technology. Learn about our brave #dexcomwarriors community. • A full and comprehensive benefits program. • Growth opportunities on a global scale. • Access to career development through in-house learning programs and/or qualified tuition reimbursement. • An exciting and innovative, industry-leading organization committed to our employees, customers, and the communities we serve.
