Meet the Team About the Team The CASB team within Cisco Secure Access develops cloud-delivered security capabilities that help organizations safely adopt cloud applications. A Cloud Access Security Broker (CASB) acts as an intermediary between users and cloud service providers. It provides cloud application visibility, shadow IT discovery, and data loss prevention (DLP) across sanctioned and unsanctioned applications. Our team builds scalable backend services that process complex security data flows and protect sensitive information. ud environments. Your Impact We are looking for a motivated backend software engineer to join our CASB engineering team. You will design, develop, test, deploy, and maintain cloud-native backend services using Golang, Node.js, and Python. You will collaborate with engineers, architects, product managers, security specialists, and operations teams to deliver reliable security capabilities at cloud scale. This role offers opportunities to work with distributed systems, microservices, AWS, data-processing pipelines, observability, and deployment automation. The ideal candidate has strong software-engineering fundamentals, enjoys solving technical problems, and is interested in cloud and cybersecurity technologies. Key Responsibilities • Design, develop, test, and maintain backend services using Golang, Node.js, and Python. • Use Python for backend components, data-processing workflows, automation, and operational tools. • Build scalable microservices for CASB and cloud-security use cases. • Contribute to application visibility, shadow IT discovery, and DLP capabilities. • Develop services that process high-volume security and application data. • Translate product requirements into reliable and maintainable software solutions. • Design and consume RESTful APIs and service-to-service interfaces. • Use AWS and cloud-native technologies to build and operate backend applications. • Monitor service health, availability, performance, and resource utilization. • Troubleshoot complex data flows using logs, metrics, traces, dashboards, and monitoring tools. • Perform root-cause analysis and implement corrective improvements. • Write unit, integration, and functional tests. • Participate in code reviews and follow secure engineering practices. • Build and maintain CI/CD pipelines using Jenkins and related tools. • Improve deployment reliability through automation. • Maintain technical documentation, runbooks, and support procedures. • Collaborate with cross-functional and geographically distributed teams. • Participate in Agile ceremonies, technical discussions, and design reviews. Minimum Qualifications (Provide up to five (5) bullet points • Bachelor’s or master’s degree in computer science, engineering, or a related discipline, or equivalent practical experience. • Proficiency in backend development using Golang, Node.js, and Python. • Ability to develop clean, reliable, testable, and maintainable services. • Understanding of microservices design, communication, deployment, maintenance, and failure handling. • Practical experience with AWS and cloud-native application development. • Familiarity with CI/CD concepts and automated build, test, and deployment workflows. • Strong analytical and problem-solving abilities. • Ability to debug complex data flows using monitoring tools and performance metrics. • Good written and verbal communication skills. Preferred Qualifications (Provide up to five (5) bullet points: these can include soft skills) • Familiarity with AWS compute, storage, database, messaging, monitoring, identity, and serverless services. • Experience with Docker and Kubernetes. • Knowledge of distributed systems, event-driven architectures, message queues, or streaming platforms. • Understanding of infrastructure as code and automated cloud provisioning. • Knowledge of CASB, DLP, shadow IT, SaaS security, or related cloud-security concepts.
