Barclays Services Corp. seeks Golang Senior Developer Tooling Engineer (multiple positions) in Whippany, NJ: • Design and maintain a Go CLI using Cobra and an interactive Bubble Tea TUI. • Deliver install, upgrade, pin, configure, verify, and rollback operations for approved tools on Windows 10/11 workstations and VDI sessions (Citrix Virtual Apps and Desktops, VMware Horizon, Azure Virtual Desktop). • Design and maintain Go backend services — HTTP/JSON where low-latency service-to-service calls are required. Exposing tool catalog entities, semantic version graphs, compatibility matrices, and artifact integrity metadata. • Deploy as immutable OCI images on OpenShift with HPAs and readiness/liveness probes. • Develop event-driven AWS Lambda functions in Go, compiled as static binaries for the provided a12023 custom runtime on x86_64 and arm64 (Graviton), using the AWS SDK for Go v2. • Implement handlers triggered by EventBridge, SQS, SNS, S3, and API Gateway. • Design PostgreSQL 18+ schemas supporting platform persistence needs, including data modeling via JSONB with GIN indexing, partial and expression indexes, declarative partitioning, and row-level transaction locking. • Build multi-stage Cl/CD pipelines — GitLab CI YAML and Jenkins declarative pipelines backed by Groovy Shared Libraries—that run go test and coverage, golangci-lint, image scanning. • Promote artifacts across dev, staging, and production via GitOps-style deployments to OpenShift and AWS. • RedHat OpenShift deployment. Author multi-stage Dockerfiles on Red Hat UBI 9 / UBI 9 Micro and distroless bases to produce minimal OCI images. • Deploy to OpenShift using Routes, ImageStreams, BuildConfigs, ConfigMaps, Secrets, NetworkPolicies, and Security Context Constraints, managed through Helm charts overlays with explicit resource requests/limits, HPAs, and PodDisruptionBudgets. • Build pipelines that ingest upstream artifacts (MSI, EXE, MSIX, ZIP, Chocolatey and winget manifests), verify checksums, and normalize packaging metadata against JSON Schema. • Promote the resulting standardized ZIP artifacts through a multi-stage GitLab CI workflow to Sonatype Nexus Repository. • Write Go code using table-driven unit tests, testify assertions and mocks, mockgen-generated interfaces, and Go fuzz tests for parser-and codec-heavy paths; run integration tests against ephemeral PostgreSQL and containerized dependencies via testcontainers-go. • Enforce coverage thresholds in CI and participate in code, architecture, and threat-model reviews. • Emit structured JSON logs from Go services and Lambdas using slog, ship via Filebeat on OpenShift, parse and enrich in Logstash, and govern Elasticsearch indices. • Build Kibana dashboards and alerting for adoption, latency, and error-rote SLIs. • Configure and maintain golangci-lint in CI and pre-commit hooks with a security- and correctness-focused linter set: gosec (SQL injection, hardcoded credentials, weak crypto, insecure file permissions), staticcheck, revive, errcheck, govet, ineffassign, and gocritic. • May telecommute pursuant to company policies [hybrid role].
