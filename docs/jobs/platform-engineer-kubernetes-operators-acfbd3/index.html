A Little About Us EDB provides a data and AI platform that enables organizations to harness the full power of Postgres for transactional, analytical, and AI workloads across any cloud, anywhere. EDB empowers enterprises to control risk, manage costs and scale efficiently for a data and AI led world. Serving more than 1,500 customers globally and as the leading contributor to the vibrant and fast-growing PostgreSQL community, EDB supports major government organizations, financial services, media and information technology companies. EDB’s data-driven solutions enable customers to modernize legacy systems and break data silos while leveraging enterprise-grade open source technologies. EDB delivers the confidence of up to 99.999% high availability with mission critical capabilities built in such as security, compliance controls, and observability. For more information, visit www.enterprisedb.com **Candidate Note: This position is 100% remote for candidates based in US** We're looking for a Staff Engineer that will focus on a Database Platform that supports Postgres estates and fleets. This position owns the packaging and delivery of a number of Kubernetes operators, across the supported cloud Kubernetes environments (EKS, AKS, GKE, OpenShift/RHOS, kind). The work spans Kubernetes packaging, container builds and CI/CD, Postgres-on-Kubernetes infrastructure, and the customer documentation for those capabilities, and it contributes to database release readiness for each release cycle. You will be part of a supportive team with a breadth of experience. What you will be doing: • Solving problems for customers by developing easy-to-use systems and features for EDB’s database platform offering(s). • Leveraging cloud environments to scale our development, testing, and build systems • Improving the performance and usability of existing products, features, and automated systems • Collaborating and mentor engineers on a global distributed team to ensure we are using standard methodologies to build scalable, secure, and operationally sound tools and systems. • Documenting and evangelizing products, features for use by engineers for the development, testing, and packaging of their products • Implementing and maintaining Kubernetes operators • Must be able to independently take a feature from design to implementation, delivering according to release dates and deadlines. Working across different development teams in order to ensure cross dependency. • Developing distributed systems for Kubernetes environments • Technical writing for customer-facing product documentation that is passed to the documentation team, and documentation for internal stakeholders. • Ability to present technical explanations to engineering audiences and internal stakeholders in English. What you will bring: • Hands-on experience authoring Kubernetes Operators. • Expert in Golang (Go). • Deep Kubernetes experience, both managed (e.g. Cloud) and self-managed (e.g. OpenShift, Rancher) • Container build tooling: Docker, multi-stage and CI image builds. • Traditional enterprise networking patterns and best practices. • Ability to manage work in a globally distributed remote environment. What will set you apart: • Familiar with OpenShift, familiar for design systems for OpenShift / RHOS packaging and Red Hat certification. • Appliance or cloud-marketplace delivery, including air-gapped and private-registry install scenarios. • IAM, Object Storage, Cloud Storage • Observability for Postgres workloads. • CI/CD with GitHub Actions; infrastructure-as-code and config management; linting (hadolint, pre-commit). • Using CloudNativePG or comparable Postgres operators, with solid Postgres operational knowledge. • High-availability and distributed systems.
