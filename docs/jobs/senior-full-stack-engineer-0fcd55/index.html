About the Role As a Senior Full Stack Engineer at Kaleido, you will design, build, and scale modern web applications and services that power enterprise blockchain and digital asset solutions. You'll work across frontend interfaces, backend services, APIs, and cloud-native technologies to deliver intuitive, reliable, and scalable products. This role combines strong software engineering fundamentals with a focus on user experience, working closely with product, design, and engineering teams to turn complex technical capabilities into accessible, production-ready applications. Responsibilities • Design, develop, and maintain scalable full stack applications using modern technologies including React, TypeScript, Node.js, and GraphQL. • Build intuitive, responsive user interfaces that simplify complex blockchain, tokenization, custody, and digital asset workflows. • Develop and integrate backend services, APIs, and data models that support enterprise applications and platform functionality. • Work closely with product managers, designers, and fellow engineers to translate business requirements into high-quality technical solutions. • Take ownership of features throughout the software development lifecycle, from architecture and design through implementation, testing, and production deployment. • Improve application performance, reliability, security, and scalability across frontend and backend systems. • Contribute to engineering best practices through code reviews, automated testing, CI/CD workflows, and technical documentation. • Evaluate and leverage modern AI-assisted development tools and workflows to improve engineering productivity and software quality. • Mentor fellow engineers, contribute to architectural decisions, and help continuously improve the developer and customer experience. Qualifications • 5+ years of professional software engineering experience building and maintaining production applications. • Computer Science degree or equivalent practical experience. • Strong proficiency in JavaScript and TypeScript, with hands-on experience building modern web applications using React. • Experience developing backend services and APIs using Node.js and modern API technologies such as GraphQL or REST. • Strong understanding of frontend architecture, component-based development, state management, and responsive user interface design. • Experience designing, building, and integrating scalable applications in cloud-based or SaaS environments. • Experience with automated testing, version control, CI/CD pipelines, and modern software development practices. • Strong problem-solving skills and the ability to independently own technical solutions from design through delivery. • Ability to work effectively in a collaborative, fast-moving environment with evolving priorities. • Strong communication skills and a focus on delivering high-quality, user-centered products. Preferred Skills • Experience building enterprise SaaS platforms, developer tools, or complex technical applications. • Familiarity with blockchain technologies, digital assets, tokenization, wallets, or custody platforms. • Experience working with cloud platforms such as AWS, Azure, or GCP and containerized environments using Docker or Kubernetes. • Experience with Go (Golang), Python, or other backend programming languages. • Knowledge of distributed systems, event-driven architectures, and real-time application development. • Familiarity with observability, performance monitoring, and troubleshooting production applications. • Experience developing applications that interact with blockchain networks, smart contracts, or decentralized systems. • Experience using AI-assisted development tools such as Claude, ChatGPT, Cursor, orCopilot to improve development workflows. • Experience mentoring engineers and contributing to technical architecture and design decisions. Diversity and Inclusion Kaleido is committed to fostering an inclusive workplace that celebrates diversity in all its forms.We value and respect individuals from varied backgrounds, cultures, and experiences and strive to create an environment where everyone feels welcome and supported. Kaleido is an equal-opportunity employer. We encourage qualified individuals of all backgrounds to apply.
