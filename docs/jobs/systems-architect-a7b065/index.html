Senior Systems Architect / Independent Technical Evaluator Location: Charleston, SC OR San Diego, CA Security Clearance: Secret minimum Job Type: Full-Time Target Salary Range*: $180,000 - $210,000 *This represents the potential salary range for this position depending on education level, years of experience and/or certifications in addition to other position specific requirements which may impact salary Position Overview: The Amatriot Group is seeking a Senior Systems Architect / Independent Technical Evaluator to support the assessment and implementation of a new mission-critical computer, network, and software environment for the U.S. Navy in Charleston or San Diego. This is a senior/expert-level technical position intended for an engineer with unusually broad, hands-on expertise across computer hardware, Linux administration, network engineering, infrastructure automation, software development, and configuration management. The selected candidate will serve as an independent technical assessor and evaluator of a new custom Navy system being implemented to replace an existing legacy environment. Rather than focusing exclusively on one technical discipline, this individual must be capable of evaluating the system holistically—from physical server hardware and bare-metal provisioning through operating systems, network architecture, infrastructure-as-code, software, and configuration management. The ideal candidate is a highly experienced systems technologist who can move comfortably between the hardware, infrastructure, network, and software layers of a complex classified system and independently determine whether the solution is technically sound, properly configured, secure, supportable, and aligned with Navy requirements. Key Responsibilities: • Serve as an independent technical assessor and evaluator for the implementation of a new custom Navy computer/network/software system. • Evaluate system architecture, engineering decisions, configurations, integrations, and implementation approaches across the complete technology stack. • Assess physical server and computer hardware, including component selection, configuration, system functionality, and hardware/software interactions. • Evaluate and support bare-metal provisioning of physical computing infrastructure. • Assess Linux-based environments, with particular emphasis on Red Hat Enterprise Linux (RHEL) and advanced Linux system administration. • Evaluate infrastructure automation and Infrastructure-as-Code (IaC) implementations using technologies such as Terraform. • Review configuration-management and system-automation approaches, including environments utilizing Puppet or comparable technologies. • Review and evaluate software components and automation developed using Go (Golang), including implementations leveraging the Go standard library. • Assess network architectures and configurations supporting complex Navy computing environments. • Evaluate software-defined networking (SDN) and networking implementations operating within secured and classified environments. • Assess system interfaces, dependencies, network connectivity, and interactions between hardware, operating systems, infrastructure services, and application components. • Evaluate configuration-management practices, system baselines, version control, change management, and configuration consistency. • Identify technical deficiencies, architectural risks, integration issues, and potential points of failure and provide technically defensible recommendations to government and engineering stakeholders. • Perform hands-on technical investigation and validation within a secure laboratory environment. • Review technical documentation, system configurations, architecture diagrams, implementation plans, and engineering artifacts. • Communicate complex technical findings to Navy program leadership, engineers, developers, administrators, and other stakeholders. • Support the transition from the existing legacy system to the replacement environment while providing an independent technical perspective on system readiness. Qualifications: • Senior/expert-level experience designing, engineering, administering, or evaluating complex enterprise or mission-critical computing environments. • Deep understanding of computer hardware architecture, including the ability to understand how physical computing components interact and support the complete operation of a system. • Significant hands-on experience with bare-metal provisioning and physical server infrastructure. • Expert-level knowledge of Linux system administration, preferably including Red Hat Enterprise Linux. • Deep understanding of system administration and infrastructure operations in complex production environments. • Experience with Terraform and Infrastructure-as-Code concepts and practices. • Experience with Puppet or comparable configuration-management/automation technologies. • Software-development experience using Go (Golang), including familiarity with the Go standard library. • Strong understanding of network engineering, including routing, switching, network services, segmentation, and troubleshooting. • Experience with software-defined networking (SDN) technologies and architectures. • Experience working with computing and network environments supporting classified U.S. Government or DoD systems. • Strong understanding of configuration management, system baselines, change control, and configuration documentation. • Ability to independently analyze unfamiliar systems, identify technical weaknesses or risks, and develop defensible technical conclusions. • Ability to work effectively across hardware, operating-system, networking, automation, and software-development disciplines rather than specializing exclusively in one area. • Experience working within secure facilities, laboratories, or other controlled DoD technical environments.
