【職務亮點】 AI 驅動開發： 我們極度重視開發效率，鼓勵並要求使用 Cursor、GitHub Copilot 或 Claude Code 等 AI 工具進行代碼解析、重構與開發。 技術挑戰： 參與核心交通派遣系統從 Node.js (Express) + MongoDB 遷移至高性能 Go + PostgreSQL 的架構重組。 多樣化產品： 涵蓋企業端、用戶端、金流分潤系統及多功能旅遊平台。 【工作內容】 系統重構與遷移： 解析舊有 Node.js (Express) 邏輯，並以 Go 語言重新架構實作於新系統。 資料架構優化： 將 MongoDB 的非關聯式資料，精準遷移並正規化至 PostgreSQL。 AI 輔助開發： 運用 AI 工具快速理解「髒亂代碼（Legacy Code）」，並轉化為具備高可讀性、高效能的新系統程式碼。 功能開發與串接： 負責交通派遣即時調度、多功能旅遊平台模組、以及複雜的金流分潤與分配功能。 監控與除錯： 建立新舊系統並行期間的監控（Watch）機制，確保業務邏輯在搬移過程中完全一致且無誤。 【技術要求】 前端： 精通 React，具備複雜企業級後台與直覺用戶端介面的開發經驗。 後端： 必須精通 Go (Golang)（新系統核心）。 必須具備 Node.js (Express) 代碼閱讀與解析能力（遷移舊系統必備）。 資料庫： 熟悉 PostgreSQL 設計與優化，懂 MongoDB 操作。 AI 工具： 熟練使用 Cursor、GitHub Copilot、Claude Code 或其他 AI 工具，具有 Vibe Coding 經驗，且能展示如何利用 AI 提升重構與開發效率。 加分項： 具備金流 API串接經驗、或交通派遣/物流系統開發經驗者優先。 【我們在找這樣的你】 你不排斥「髒代碼」，反而擅長利用 AI 工具快速釐清邏輯並將其標準化。 你對技術有潔癖，能把混亂的舊邏輯重構成優雅、高效的 Go 程式碼。 你具備解決複雜問題的邏輯，能處理高併發的派遣調度與精確的金流分配。
