BÚSQUEDA LABORAL: DEVELOPER BACK END (SEMI SENIOR) 🚀 ¡En AGTEC seguimos expandiendo nuestro equipo de ingeniería! ¿Te apasiona el desarrollo backend, el diseño de arquitecturas basadas en eventos y la construcción de servicios de alto rendimiento? En AGTEC estamos en búsqueda de un/a Developer Back End (Semi Senior) para sumarse a nuestros equipos técnicos y aportar en el diseño, desarrollo y escalabilidad de APIs y microservicios robustos. 📍 Modalidad y Ubicación • Cargo: Developer Back End (Semi Senior) • Ubicación: Santiago, Chile. • Modalidad: Híbrida (días presenciales a coordinar con tu líder). 🎯 Tus principales desafíos serán: • Diseñar y desarrollar APIs y servicios backend escalables utilizando Node.js con TypeScript / JavaScript. • Desarrollar microservicios eficientes en Golang. • Trabajar con Next.js en esquemas de Server-Side Rendering (SSR), API routes e integraciones server-side. • Implementar procesamiento de eventos y mensajería distribuida con Apache Kafka. • Realizar modelado, optimización de consultas y gestión de bases de datos relacionales (PostgreSQL y MySQL). • Contenerizar aplicaciones con Docker y colaborar en el mantenimiento de pipelines de integración y despliegue continuo (CI/CD). • Implementar prácticas sólidas de seguridad backend: autenticación, autorización, validación estricta de inputs y gestión segura de secretos. • Monitorear y asegurar la observabilidad de los servicios mediante análisis de logs, métricas, trazas y resolución de incidencias en producción (troubleshooting). • Garantizar la calidad técnica mediante pruebas unitarias e integración, code reviews y documentación técnica clara. • Incorporar herramientas de IA / Copilot en el día a día para acelerar el desarrollo, refactorización y generación asistida de pruebas y documentación. 🔍 ¿Qué buscamos en ti? • Experiencia comprobable como Backend Developer en nivel Semi Senior. • Dominio en el desarrollo de APIs con Node.js (TypeScript/JavaScript). • Conocimiento y experiencia desarrollando microservicios con Golang. • Conocimientos en Next.js (SSR y API routes). • Experiencia integrando sistemas distribuidos y flujos orientados a eventos con Kafka. • Buen manejo de bases de datos SQL (PostgreSQL y/o MySQL). • Manejo de contenedores con Docker y nociones prácticas en pipelines CI/CD. • Foco en seguridad informática, observabilidad y cultura de testing (unitario e integración). • Apertura y proactividad para integrar herramientas de IA en los flujos de desarrollo. 📩 ¿Te interesa sumarte al equipo?
