【About This Role】 We are continuously building and operating an e-commerce integration platform built around AWS Serverless, alongside the e-commerce applications it connects to. The platform runs across multiple markets and channels — Magento, Shopify — and integrates with ERP (SAP) and regional markets. It covers core business processes such as orders, shipping, inventory, pricing, coupons, and returns, using an event-driven architecture to pass data reliably between systems. Your primary focus is building serverless integration functions in GoLang on AWS Lambda — the backbone that moves data reliably across orders, inventory, pricing, shipping, and returns, and connects our systems to ERP, warehouse, and regional markets. You might also work on the e-commerce and web platforms themselves, which are PHP-based, so solid PHP skills are important too. We are looking for a versatile backend engineer who is strong in Go and equally comfortable in PHP. 【Key Responsibilities】 • Develop and maintain AWS Lambda functions in GoLang to implement integration logic for orders, inventory, pricing, shipping, and returns. • Design and adjust the event-driven architecture, including how API Gateway, SQS queues, and scheduled jobs (EventBridge / Schedule Job) connect and flow together. • Build, customize, and maintain our PHP-based e-commerce and web platforms. • Integrate APIs across multiple commerce channels, SAP / SAP PI for ERP, and warehouse systems, handling two-way data synchronization. • Work with a range of data formats and exchange channels: XML / JSON, SFTP on S3, and SQL. • Investigate and resolve data anomalies, sync failures, and other integration issues, and set up monitoring and alerting. • Write clear technical documentation and process guides, and collaborate with the e-commerce operations, marketing, and other engineering teams. • Support on the sustained and daily operation and find the root cause on abnormaled orders 【Required Qualifications (Must Have)】 • 5+ years of professional software development experience. • GoLang skills (2+ years in production) — able to develop, refactor, and optimize back-end and serverless services independently. • AWS Serverless experience (2+ years): Lambda, API Gateway, and SQS, with a good understanding of event-driven architecture design principles. • PHP development experience (2+ years) — our e-commerce and web platforms are PHP-based, so you are comfortable building and maintaining them. • Familiar with RESTful API design and integration with third-party systems. • Comfortable parsing and transforming XML / JSON data formats. • Experience with relational databases (such as MySQL), and an understanding of data consistency and transaction processing. 【Preferred Qualifications (Nice to Have)】 • E-commerce industry experience is a strong plus, especially familiarity with core processes such as orders, payments, logistics, and inventory. • Experience with PHP platforms such as Magento, Laravel, or WordPress. • Experience with SAP / ERP system integration. • Familiarity with other AWS services (S3, EC2, CloudWatch, EventBridge, IAM, etc.). • Experience developing or operating cross-border / multi-market systems. • Understanding of B2B data exchange formats such as EDI and SFTP.
