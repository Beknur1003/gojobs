Valoramos la autonomía, la comunicación clara y la excelencia técnica, colaborando estrechamente con equipos y socios internacionales para construir tecnología que genera impacto. 🌍 Más información: Buscamos un/a Senior Java Engineer para sumarse a un equipo de alto nivel técnico, con foco en el desarrollo, evolución y operación de soluciones backend dentro de un entorno fintech complejo y exigente. Esta posición requiere una persona con experiencia real en arquitecturas distribuidas, buena base técnica, criterio para trabajar sobre sistemas en producción y apertura para incorporar IA en su trabajo cotidiano. Lo que puedes esperar de este rol (Responsabilidades) Es un rol de alta exigencia técnica, con fuerte foco en la autonomía y la capacidad de ejecución. Serás responsable de diseñar, desarrollar y operar soluciones backend en Java sobre arquitecturas de microservicios, integrando mensajería, comunicación asíncrona, buenas prácticas de resiliencia, AWS, NoSQL e IA en un entorno fintech de alta complejidad. Requisitos +5 años de experiencia trabajando con Java Experiencia en deploy, monitoreo y operación de aplicaciones en entornos productivos Experiencia sólida con microservicios, idempotencia, circuit breaker, retries y CQRS Experiencia con mensajería y comunicación asíncrona entre aplicaciones, idealmente con Kafka y manejo de partition key Experiencia trabajando con tecnologías NoSQL Conocimiento y experiencia con AWS Experiencia en procesos de negocio fintech Experiencia y apertura para incorporar el uso de IA en sus tareas cotidianas Formación universitaria completa en Ingeniería en Sistemas, Ingeniería Informática, Ciencias de la Computación o carreras equivalentes Nivel de inglés conversacional fluido Residencia en Argentina o Uruguay Deseable Conocimiento de Golang Capacidad para leer e interpretar resultados de explain Beneficios Modalidad remota Participación en un proyecto estratégico regional de alto impacto.
