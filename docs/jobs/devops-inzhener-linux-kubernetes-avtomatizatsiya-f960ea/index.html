Пожалуйста указывайте в сопроводительном письме Вашу локацию в РФ и ожидания по з.пл. в рублях! Мы ищем самостоятельного инженера, который возьмёт на себя инфраструктуру и автоматизацию: сделает выпуск изменений предсказуемым, а повторяющиеся операции - понятными скриптами и инструментами вместо ручной работы. Чем предстоит заниматься: • Поддерживать инфраструктуру на Linux (Ubuntu, Talos): установка и настройка, обновления, работа с сетевыми картами - прошивки, bonding • Готовить приложения к развёртыванию в кластере: собирать deployment-конфигурации и следить, чтобы окружения были воспроизводимыми • Поддерживать CI/CD-процессы и управление конфигурацией через Ansible • Автоматизировать рутину на Python и bash, писать небольшие внутренние сервисы и API на Python • Разрабатывать средства автоматизации и мониторинга на Python и Go • Разбирать инциденты вместе с архитекторами и экспертами, решать типовые задачи • Поддерживать пользователей и помогать им с шаблонными операциями • Вести документацию и наполнять базу знаний в Jira и Confluence Требования: • Опыт работы в DevOps и инфраструктуре • Уверенное администрирование Linux (Ubuntu) • Понимание принципов DevOps и процессов CI/CD • Управление конфигурацией через Ansible • Опыт работы с оркестраторами (Kubernetes) • Docker и git в ежедневной работе • Python и bash для автоматизации; опыт разработки веб-сервисов и API на Python • Реляционные БД на уровне администратора • Работа с сетевым стеком: обновление прошивок сетевых карт, настройка bonding • Аккуратность в документации: умение описывать решения так, чтобы ими пользовались коллеги • Будет плюсом разработка автоматизации и средств мониторинга на Golang Условия: • Полная занятость с графиком 5/2 • Удалённый формат работы • Работа в аккредитованной ИТ-компании • Работа с современным стеком технологий и крупными игроками рынка • Официальное трудоустройство по ТК РФ или ИП РФ
