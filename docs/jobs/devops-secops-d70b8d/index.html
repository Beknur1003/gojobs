DevOps/SecOps

Knowit Sweden Stockholm, Stockholms län, Sverige опубликовано 28 сентября 2026

KubernetesDockerTerraformAWSGCPAzureCI/CDPythonTypeScriptAI/LLM
Vill du kombinera DevOps, cloud och cybersecurity? Som DevOps/SecOps-konsult bygger du automatiserade och säkra leveransmiljöer för kunder i olika tekniska miljöer. Vad kommer du att arbeta med? I rollen designar, administrerar och optimerar du moderna utvecklings- och driftmiljöer. Säkerhet integreras genom hela utvecklings- och leveransprocessen, från kod och beroenden till driftsatt infrastruktur. En viktig del av vardagen är att utveckla CI/CD-pipelines med automatiserade säkerhetskontroller, sårbarhetsskanning och secrets management. Du arbetar också med Infrastructure as Code, konfigurationshantering och automation för att skapa reproducerbara, skalbara och säkra miljöer. Containerteknik och orkestreringsplattformar är centrala i uppdragen. Här bidrar du med drift, säker konfiguration och härdning av container- och Kubernetesmiljöer. Monitorering, loggning och observability hjälper dig att identifiera avvikelser, sårbarheter och potentiella säkerhetshot. Uppdragen varierar mellan olika tekniska miljöer och branscher. Det ger dig utrymme att fortsätta utvecklas inom DevOps, cloud security och cybersecurity samtidigt som du skapar lösningar som fungerar i kundernas vardag. För att lyckas i rollen ser vi att du har: • Erfarenhet av mjukvaruutveckling, scripting och automation, exempelvis med Python, samt god förståelse för DevSecOps-principer. • Erfarenhet av att administrera, utveckla och optimera CI/CD-pipelines samt implementera säkerhetskontroller som SAST, DAST, dependency scanning, container scanning eller secrets scanning. • Kunskap om Git repository management, Git workflows, branchingstrategier och säker hantering av repositories, kod, beroenden och artefakter. • Erfarenhet av Infrastructure as Code med exempelvis Terraform samt konfigurationshantering och automation med Ansible, Puppet, Chef eller liknande verktyg. • Erfarenhet av Docker och Kubernetes, inklusive hardening, RBAC, secrets management och sårbarhetshantering, samt kunskap om IAM, least privilege och role-based access control. • Kunskap om monitorering, loggning och observability, vulnerability management och patchning samt grundläggande förståelse för cloud security och nätverkssäkerhet, exempelvis brandväggar, segmentering, TLS, certifikat och säker kommunikation mellan tjänster. Du kommunicerar obehindrat på svenska och engelska, både muntligt och skriftligt. Meriterande • Erfarenhet av Azure, AWS eller Google Cloud med fokus på säkerhet samt säkerhetsverktyg för SAST, DAST, Software Composition Analysis, container scanning eller secrets scanning. • Erfarenhet av SIEM, centraliserad logghantering, Security Operations, incidenthantering, incident response eller security monitoring. • Kunskap om policy as code och automatiserad kontroll av att infrastruktur och deployment följer definierade säkerhetskrav. • Fördjupad erfarenhet av Kubernetes security, exempelvis network policies, RBAC, admission policies eller runtime security, samt secrets management med HashiCorp Vault eller motsvarande. • Erfarenhet av Golang eller CI/CD-automationsflöden som omfattar egen hårdvara, exempelvis egenutvecklade testriggar. • Erfarenhet av säkerhetsstandarder eller ramverk som ISO 27001, NIST, CIS Benchmarks eller OWASP. Vad får du hos oss? Du blir en del av ett kompetent team där samarbete och kunskapsdelning är en naturlig del av arbetet. Kombinationen av varierande kunduppdrag och tekniskt utmanande projekt ger dig möjlighet att bredda och fördjupa din kompetens inom automation, cloud, DevOps och cybersecurity. Här möts teknik, säkerhet och kreativitet i en lärande miljö där du kan bidra med din erfarenhet och fortsätta utvecklas tillsammans med kollegor och kunder. Ansökan Låter rollen intressant? Välkommen att skicka in din ansökan. Vi ser fram emot att höra mer om dig och din erfarenhet. Om Knowit Jobba hos oss på Knowit Connectivity, där vi arbetar med tekniskt avancerade system inom embedded och uppkopplade lösningar. Hos oss får du arbeta med komplexa produkter tillsammans med erfarna ingenjörer i uppdrag som ligger i teknisk framkant. Med expertis inom systemutveckling, AI, cybersäkerhet, molntjänster, digitala kundupplevelser och managementkonsulting utvecklar vi lösningar som bidrar till ett mer hållbart och mänskligt samhälle. Vi är cirka 3 700 medarbetare och arbetar genom våra affärsområden Solutions, Experience, Connectivity, Insight och Products – främst i Norden, men även i Polen, Serbien och Tyskland.
