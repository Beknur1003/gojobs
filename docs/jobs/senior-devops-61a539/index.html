В компанию - поставщика программного обеспечения для игорного бизнеса, сотрудничающую с ведущими мировыми провайдерами мы ищем Senior DevOps инженера для развития и поддержки инфраструктуры. Важно - локация Вне рф Обязанности: • Доступность и производительность: администрирование серверов и виртуальных машин на Debian, настройка балансировщиков нагрузки, реализация DDoS-защиты, работа с платформой виртуализации Proxmox VE. • Сети и инфраструктура: настройка сетей, управление DNS, оптимизация маршрутизации и балансировки, обеспечение высокой доступности (High Availability). • Автоматизация и IaC: разработка и поддержка инфраструктуры с использованием Ansible, AWX, Terraform. • Мониторинг и инциденты: настройка систем мониторинга и алертинга (Zabbix, Grafana, Victoria Metrics, Opsgenie), анализ логов, troubleshooting системных проблем. • Контейнеризация и оркестрация: работа с Docker и Kubernetes, разработка Helm-чартов, управление кластерами, интеграция с CI/CD. • Работа с данными: настройка и оптимизация HA-решений для Redis, Kafka, RabbitMQ, PostgreSQL, MongoDB, ClickHouse. • Автоматизация процессов: разработка скриптов на Python или Golang. • DevOps-культура: взаимодействие с командами разработки и QA, продвижение лучших практик DevOps. • Непрерывное улучшение: поддержка и развитие CI/CD-пайплайнов, поиск точек оптимизации и автоматизации. Требования: • Опыт 5+ лет в аналогичной роли (DevOps / SRE / Infrastructure Engineer). • Bare Metal: глубокое знание серверного железа, опыт работы с физическими серверами. • Linux: отличные навыки troubleshooting на продакшн-серверах Debian / Ubuntu. • Виртуализация: практический опыт с QEMU/KVM, libvirtd, Proxmox VE. • Сети: уверенное понимание TCP/IP, DNS, L2/L3, routing, IPTables, VPN. • Nginx: опыт конфигурации и управления. • Контейнеры: Docker, Kubernetes (продакшн), разработка Helm-чартов. • IaC: Ansible, Terraform. • CI/CD: GitLab CI, ArgoCD, Flux. • Базы данных: PostgreSQL, Elasticsearch, Redis, MongoDB, ClickHouse. • Очереди: Kafka, RabbitMQ. • Мониторинг: Zabbix, Prometheus, Victoria Metrics, Grafana, ELK Stack. • Языки: Python или Golang (для скриптов автоматизации). Условия: • Оформление: по ИП B2B вне РФ. • Формат работы: удалённо • График: гибкое начало рабочего дня, 5/2. • Отпуск: 20 дней оплачиваемого отпуска + 5 family days + компенсация больничных. • Развитие: доступ к внутренней базе знаний, митапы, обучение новым технологиям, поддержка профессионального роста. • Команда: распределённая команда 400+ человек, регулярные внутренние и внешние мероприятия, воркшопы, тимбилдинги, корпоративные поездки.
