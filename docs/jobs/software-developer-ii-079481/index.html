Job Summary We are seeking a motivated Software Developer II to design, develop, and support modern enterprise applications and services. This position is ideal for a developer with approximately 2–3 years of professional development experience who has strong working knowledge of .NET/C#, along with experience using Go (Golang). The developer will work as part of an engineering team responsible for building scalable, highly available applications supporting large-scale enterprise business operations. A significant portion of the role will focus on microservice development, APIs, distributed systems, cloud-based solutions, data integration, and asynchronous processing. The successful candidate should be comfortable working throughout the software development lifecycle and contributing to the architecture, development, testing, deployment, monitoring, and ongoing improvement of production applications. Duties and responsibilities • Design, develop, test, deploy, and maintain enterprise applications and services using C#/.NET, Go (Golang). • Develop scalable microservices and distributed application components. • Design and maintain RESTful APIs and service-to-service integrations. • Participate in the development of large-scale enterprise software platforms that support high transaction volumes and business-critical operations. • Build cloud-native services capable of horizontal scaling, fault tolerance, and resilient operation. • Develop asynchronous processing solutions using messaging, queues, event-driven architectures, or similar technologies. • Create integrations between internal systems, third-party services, databases, APIs, and cloud platforms. • Design and optimize application interactions with relational and non-relational data stores. • Write clean, maintainable, secure, and well-tested code. • Participate in application architecture and technical design discussions. • Troubleshoot performance, reliability, integration, and production issues. • Develop automated unit, integration, and regression tests. • Participate in code reviews and help maintain engineering standards. • Work with Product Owners, Project Managers, QA, Data Engineering, Infrastructure, and other development teams. • Participate in Agile/Scrum development activities including sprint planning, refinement, demonstrations, and retrospectives. • Contribute to CI/CD pipelines and automated deployment processes. • Monitor application health, performance, logging, and telemetry. • Maintain technical documentation for applications, APIs, integrations, and system architecture. • Assist with modernization of legacy applications into modern service-oriented and microservice architectures. • Research and evaluate new technologies where they can improve scalability, maintainability, performance, or developer productivity. Essential Functions • Ability to think critically, research, and apply findings to day-to-day assigned work • Ability to clearly communicate verbally and in writing • Ability to use computer software to access various IT and data related systems • Ability to understand and document technical ideas and convey them to a non-technical audience • Ability to identify, analyze, and correct defects, inconsistencies in software program functions, outputs, and content • Ability to write and understand .NET supported coding languages • Ability to grasp foundational programming and database concepts Qualifications • 2–3+ years of professional software development experience. • Professional working experience with C# and .NET / ASP.NET Core. • Working knowledge or professional experience with Go (Golang). • Experience designing or developing REST APIs and backend services. • Experience developing applications using microservice or service-oriented architecture. • Experience contributing to large-scale or enterprise software solutions. • Strong understanding of object-oriented programming and modern software design principles. • Understanding of distributed application concepts including: • Service-to-service communication • API design • Asynchronous processing • Messaging and queues • Retry and resiliency patterns • Logging and application monitoring • Experience working with relational databases such as SQL Server, PostgreSQL, or similar platforms. • Experience writing SQL queries and working with database-backed applications. • Familiarity with Git-based source control and modern branching strategies. • Experience with automated testing and debugging. • Understanding of CI/CD and modern application deployment practices. • Strong analytical and problem-solving skills. • Ability to work effectively both independently and as part of a collaborative development team. Preferred Qualifications Experience in one or more of the following areas is strongly preferred: • Microsoft Azure or another major cloud platform • Azure Functions or serverless development • Azure App Services • Azure Service Bus or other enterprise messaging platforms • Azure SQL • Azure Storage / Blob Storage • Application Insights or other application monitoring platforms • Docker and containerized application development • Kubernetes or container orchestration • Event-driven architectures • Message-based processing • Background workers and high-volume processing services • API gateways • OAuth 2.0 / OpenID Connect • Microsoft Entra ID / enterprise SSO • Distributed caching • Redis • PostgreSQL • GitHub Actions or Azure DevOps Pipelines Enterprise Development Experience Candidates should have experience participating in the development of applications where considerations extend beyond basic application functionality. Examples include systems involving: • Multiple interacting microservices • High transaction volumes • Large datasets • Enterprise databases • Business-critical workflows • Distributed application processing • Integration with multiple internal and external systems • Asynchronous or event-driven processing • Application resiliency and fault handling • Observability and centralized logging • Authentication and authorization • Data security • Automated deployments • Production monitoring and support Experience does not need to include ownership of an entire enterprise platform; however, candidates should understand how their application components operate as part of a larger enterprise architecture.
