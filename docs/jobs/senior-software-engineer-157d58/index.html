About the Role: As a Senior Software Engineer, you will develop high-performance Go runtime, CLI engines and declarative state managers. You will architect the software that thousands of engineering teams use every day to interact with Kong's runtime — including deck (Kong’s state management & drift detection engine), the Kong Terraform Provider, official Go SDKs and automated spec-driven API tooling. What You Will Build & Own: You will balance Software Development with APIOps Architecture: 1. Declarative Engine • State & Drift Management Engines: Design and optimize algorithms in Go for state diffing, validation, and real-time drift detection across large-scale multi-tenant API topologies. • Go SDK & Core Libraries: Architect and maintain enterprise-grade, high-performance Go SDKs used by Kong’s internal microservices and external clients to interface with the Konnect SaaS platform. • API Design & Standardization: Define clean, extensible REST API contracts across Kong’s platform runtimes. • Code Generation & Tooling Pipelines: Architect spec-driven tooling (OpenAPI/AsyncAPI) to dynamically generate SDKs, client libraries, and IaC definitions without manual developer toil. 2. APIOps & IaC Ecosystem • Core CLI Engineering: Build modern, fast, and intuitive CLI-first developer experiences designed for both human developer workflows and high-concurrency CI/CD automation pipelines (GitHub Actions, GitLab CI, Jenkins). • Terraform & Provider Ecosystem: Build and extend high-reliability Terraform Providers to enable seamless IaC operations. • Support for Next-Gen Runtimes: Bring new runtime capabilities into the declarative management ecosystem as native API primitives. What You’ll Bring: • 5+ years of software engineering experience designing and delivering production-grade backend systems and developer tools using Golang. • API Design Mastery: Proven experience crafting intuitive, developer-friendly API schemas (REST, gRPC, OpenAPI), with a strong focus on backwards compatibility, versioning and developer experience (DX). • Hands-on IaC / Platform Understanding: Production exposure to Terraform provider development, Kubernetes operators or stateful CI/CD automation pipelines. • Engineering Rigor: Strong commitment to clean code, comprehensive automated testing (unit, integration, end-to-end), benchmarking and robust software architecture. • Communication & Technical Leadership: Ability to articulate complex technical decisions, mentor junior engineers and collaborate across global backend and platform teams.
