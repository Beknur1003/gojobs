Role: Software Engineer — Go (Golang) Location: Melbourne About the Role We are looking for a Software Engineer with strong Go (Golang) skills to design and build reliable, distributed backend services. You'll work extensively with Temporal for orchestrating long-running, fault-tolerant workflows, and deploy services on Google Cloud Run as part of our cloud-native, serverless architecture. This role is a great fit for someone who enjoys solving problems around distributed systems, workflow orchestration, and scalable service design. What You'll Do - Design, build, and maintain backend services and APIs in Go. - Model business processes as Temporal workflows and activities, including handling retries, timeouts, signals, queries, and versioning of long-running workflows. - Deploy, operate, and scale containerized services on Google Cloud Run, including configuring concurrency, autoscaling, and revision rollouts. - Build robust CI/CD pipelines for building, testing, and deploying Go services to Cloud Run. - Write clean, well-tested, idiomatic Go code with strong unit and integration test coverage. - Instrument services with structured logging, metrics, and tracing (e.g., OpenTelemetry, Cloud Monitoring/Logging) to ensure observability of workflows and services. - Collaborate with product and platform teams to translate business requirements into resilient, event-driven or workflow-driven architectures. - Participate in code reviews, design discussions, and incident response/on-call for production services. - Continuously improve reliability, performance, and cost-efficiency of services running on GCP. Must-Have Qualifications - 3+ years professional experience writing production Go code. - Hands-on experience with Temporal (or similar workflow orchestration engines like Cadence, Airflow, Step Functions) — understanding of workflows, activities, task queues, and determinism constraints. - Practical experience deploying and operating services on Google Cloud Run (or similar serverless container platforms like AWS Fargate/App Runner, Azure Container Apps). - Solid understanding of REST/gRPC API design and inter-service communication patterns. - Experience with containerization (Docker) and CI/CD tooling. - Familiarity with cloud infrastructure concepts: IAM, networking basics, secrets management, autoscaling. - Strong debugging and troubleshooting skills across distributed systems. - Good understanding of testing practices (unit, integration, contract testing) in Go. Nice-to-Have - Experience with Infrastructure-as-Code (Terraform) for provisioning GCP resources. - Familiarity with event-driven architectures (Pub/Sub, Kafka). - Experience with other GCP services (Cloud SQL, BigQuery, Cloud Storage, Cloud Tasks). - Exposure to security/compliance requirements in regulated environments (e.g., financial services). - Experience with observability stacks (Prometheus, Grafana, OpenTelemetry). - Familiarity with SDLC practices in a microservices/monorepo environment.
