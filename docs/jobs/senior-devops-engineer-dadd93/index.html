Job Description Summary: As a Senior DevOps Engineer 2, you will drive efforts to ensure the reliability, performance, and scalability of AWS cloud infrastructure and services. You will work extensively with Kubernetes (EKS), Helm charts, Kafka, and cloud-native solutions, while also ensuring stability for legacy Java applications running on EC2. You will focus on automation, cost optimization, and applying site reliability engineering (SRE) principles. What you'll do • Architect and manage secure, scalable cloud infrastructure with a strong focus on automation and efficiency. • Lead Infrastructure as Code (IaC) development using Terraform, Helm, and Ansible. • Develop and maintain CI/CD pipelines for Kubernetes applications and traditional EC2 workloads. • Implement and enhance observability solutions using DataDog, ensuring real-time monitoring and proactive issue resolution. • Drive Kubernetes-based containerization and orchestration initiatives. • Work with Kafka to design and optimize event-driven architectures. • Work with developers to build platform features that enable self-service and increase velocity • Mentor junior engineers and contribute to a culture of continuous learning. What you'll bring • Bachelor’s degree in Computer Science, Information Technology, or equivalent experience. • 5+ years of experience in Cloud Engineering, DevOps, or Site Reliability Engineering. • Strong hands-on experience with AWS, Kubernetes (EKS), Helm, and Kafka. • Proficiency in Infrastructure as Code (Terraform, Ansible) and scripting (Python, Bash). Experience with one other high-level language such as Java or Golang preferred. • Familiarity with healthcare-specific technologies such as FHIR and HL7 and their common implementation patterns (such as HL7 VPN networking requirements) • Deep understanding of cloud networking, security, and scalability best practices. • Experience with troubleshooting and optimizing large-scale cloud infrastructures.
