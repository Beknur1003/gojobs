About the Role We are looking for a Golang Developer with 6+ years of experience to join our engineering team. You will build high-performance, scalable, and maintainable backend systems, and you will own the data layer behind them: designing schemas, modeling data for enterprise workloads, and making sure our databases stay fast, consistent, and reliable as we grow. Go is the primary focus. Familiarity with Django and ReactJS is a strong plus. What you’ll do • Design, develop, and maintain scalable backend services and APIs using Go. • Design and evolve relational database schemas, mostly in PostgreSQL. Translate business requirements into well-structured data models with sound normalization, constraints, and relationships. • Make data ownership decisions across microservices, including service boundaries, shared and per-service databases, and how data stays consistent across services. • Write and tune complex SQL queries. Design indexing strategies and use query plans (EXPLAIN ANALYZE) to find and fix performance bottlenecks. • Plan and run safe, versioned schema migrations, including zero-downtime changes on production systems. • Design caching strategies (e.g., Redis) that work alongside the database without compromising data correctness. • Collaborate with cross-functional teams to define, design, and ship new features, including how the data layer supports them. • Write clean, efficient, and testable code, including tests for data-access and transactional logic. • Optimize applications and databases for performance, reliability, and scalability. • Debug and resolve technical issues across development, testing, and production, including data integrity and query performance problems. • Participate in code reviews, including reviews of schema changes and migrations, and contribute to engineering and data-modeling best practices. • (Optional) Contribute to frontend development using ReactJS when required. What we look for • Proven experience as a backend developer with strong proficiency in Golang. • Strong experience in database design and data modeling for enterprise applications: normalization, denormalization trade-offs, constraints, and referential integrity. • Deep, hands-on PostgreSQL experience, including indexing (B-tree, GIN, partial, composite), query optimization, transactions and isolation levels, locking behavior, and features such as JSONB, CTEs, and window functions. • Experience working with databases from Go, such as database/sql, pgx, sqlc, or GORM, along with connection pooling and transaction management. • Experience with schema migration tools (e.g., golang-migrate, goose, Atlas). • Hands-on experience building enterprise backend systems. • Good understanding of concurrency, multithreading, and microservices architecture, including data consistency patterns such as distributed transactions, the saga pattern, and the outbox pattern. • Experience with RESTful APIs, gRPC, or GraphQL. • Working knowledge of NoSQL databases and caching systems (e.g., Redis), and the judgment to choose the right storage for each use case. • Hands-on experience with Docker, Kubernetes, or other container orchestration tools. • Solid understanding of CI/CD pipelines and modern DevOps practices, including running database migrations as part of deployments. • Familiarity with unit testing and integration testing in Golang, including testing against real databases (e.g., Testcontainers). • Exposure to cloud platforms (AWS, GCP, or Azure) and managed database services (e.g., RDS, Cloud SQL, Azure Database for PostgreSQL). • Strong problem-solving skills and the ability to work independently or in a team. Nice to Have (Optional) • Experience scaling PostgreSQL through table partitioning, read replicas, replication, sharding, or PgBouncer. • Understanding of database security and compliance practices, such as role-based access, encryption, auditing, and handling sensitive data. • Experience with backup, recovery, and high-availability strategies for production databases. • Experience with event-driven systems and messaging queues (Kafka, RabbitMQ, etc.), including change data capture (e.g., Debezium). • Exposure to data warehousing or analytics databases (e.g., BigQuery, Redshift, ClickHouse). • Experience with ReactJS for building interactive user interfaces. • Knowledge of frontend build tools and state management libraries (e.g., Redux). • Experience with Django, including the Django ORM and its migration system.
