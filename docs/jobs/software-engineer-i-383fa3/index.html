Job Summary : Reputation is seeking a Go Backend Engineer with PERN Stack experience to maintain and contribute to a large ecosystem of production microservices and web services running on GCP. In this role, you will keep services healthy, resolve issues, and deliver new features across a well-established distributed platform. While Go is the primary language, the platform also includes a PERN stack (PostgreSQL, Express, React, Node.js), and you will be expected to work comfortably across both. We are looking for engineers who can build simple, fast, and scalable software in a fast-paced environment. Responsibilities: • Maintain and enhance existing Go microservices across a distributed, event-driven platform. • Contribute to Node.js/Express and GraphQL API services as needed. • Support and maintain React (Class Components) frontend applications when required. • Contribute to new feature development based on product and business requirements. • Manage and update Helm charts for deployments across Stage, Production, and EU environments. • Maintain and improve GitHub Actions CI/CD pipelines. • Troubleshoot and resolve production incidents across services. • Write and maintain unit, integration, and end-to-end tests (using Testify and testcontainers-go). • Participate in code reviews and uphold code quality standards. • Collaborate with DevOps and platform teams on infrastructure-related changes. • Additional duties as assigned. Qualifications: • Bachelor's degree in Computer Science, Engineering, or related field (or equivalent practical experience). • 2+ years of hands-on Go (Golang) development experience in a production environment, with exposure to Node.js/Express and React. • Strong understanding of microservices architecture, distributed systems patterns, and experience working in a large microservices ecosystem (50+ services). • Proficiency with Kubernetes and Helm — writing and managing Helm charts for multi-environment deployments. • Hands-on experience with GitHub Actions for CI/CD workflows including build, test, and deploy pipelines. • Experience with GCP services, particularly Pub/Sub for event-driven messaging, and RabbitMQ (AMQP) for message queue management. • Solid experience with PostgreSQL (including ORM usage via GORM/pgx) and Redis. • Familiarity with Elasticsearch (indexing, querying, and percolation patterns). • Experience with Docker and containerized application development. • Familiarity with structured logging, health checks, Prometheus metrics instrumentation, and observability tools (OpenTelemetry). • Experience with Node.js, Express.js, and GraphQL (schema design, resolvers, API integration). • Familiarity with React (specifically Class Components) for maintaining existing frontend applications. • Exposure to AWS Redshift or data warehouse integrations, multi-region cloud deployments (US + EU on GCP), and Terraform for infrastructure-as-code. • Strong problem-solving skills, excellent written and verbal communication, and ability to work independently in a distributed team.
