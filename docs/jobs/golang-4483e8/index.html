資深後端工程師(Golang)

杰定管理顧問有限公司 North District, Taichung City, Taiwan опубликовано 22 октября 2026

Go — основной язык Senior Полная занятость
PostgreSQLMongoDBRedisKafkagRPCKubernetesDockerLinuxCI/CD
工作內容： 1.使用 Golang 開發高效能後端服務，負責核心系統功能設計、開發與維護。 2.建置高併發、高可用性的後端架構，優化系統延遲、吞吐量與穩定性。 3.規劃與實作微服務架構，設計並維護 RESTful API / gRPC 介面。 4.負責資料庫結構設計與效能調校，包含索引設計、分庫分表及 SQL Query Optimization。 5.建構事件驅動架構，運用 Kafka 進行非同步訊息處理與系統解耦。 6.開發即時通訊服務，支援 WebSocket 連線管理、訊息推播與即時互動需求。 7.建立與維護 CI/CD 流程，提升部署效率、版本控管與交付穩定性。 工作技術需求： 1.具備 3 年以上後端開發經驗 2.具備 3 年以上 Golang 實務開發。 3.熟悉高併發、分散式系統設計，具高流量平台或遊戲平台開發經驗尤佳。 4. 熟悉微服務架構，具 RESTful API / gRPC 設計與實作經驗。 5.熟悉 PostgreSQL、MongoDB、Redis 等資料儲存與快取技術，並能進行效能優化。 6.熟悉 Kafka、WebSocket 等事件驅動與即時通訊技術。 7.具 Docker、Kubernetes 等容器化與部署經驗。 8.熟悉 Linux 環境與 TCP/IP、HTTP 等網路基礎概念。 9.具備系統監控、效能調校、壓力測試及問題排查經驗。
