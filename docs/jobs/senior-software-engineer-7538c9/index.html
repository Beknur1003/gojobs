Title and Summary Senior Software Engineer Overview Next Edge represents the next phase of Mastercard's Core Payments technology transformation and plays a key role in advancing our cloud-first strategy. This organization is focused on modernizing payment platforms, creating scalable engineering solutions, and delivering the tools and services that enable teams to build, test, and deploy software more efficiently. As a Senior Software Engineer, you will contribute to the design and development of internal platforms, backend services, and engineering tools that improve developer productivity and accelerate delivery across Mastercard's payment ecosystem. Working closely with engineers, product managers, designers, and technical leads, you will help build reliable, scalable solutions while driving continuous improvements in software quality, performance, and maintainability. This role is ideal for an engineer who enjoys solving complex technical challenges, building modern distributed systems, and working with evolving technologies that support innovation at enterprise scale. Role -Design, develop, and support internal platforms, microservices, and engineering tools that improve productivity and accelerate software delivery. -Partner with technical leads and team members to scope, design, and implement complex features from concept through production deployment. -Build high-quality, maintainable code and automated tests that contribute to reliable and efficient software delivery. -Develop backend services and supporting tools using technologies such as Golang, Java, and gRPC. -Contribute to software architecture and design decisions that improve scalability, resiliency, maintainability, and operational readiness. -Collaborate with Product Managers and Customer Experience Designers to understand user needs and translate requirements into technical solutions. -Review code, share feedback, and promote engineering practices that enhance quality, readability, security, and long-term maintainability. -Analyze system behavior, troubleshoot complex issues, identify root causes, and implement sustainable solutions. -Improve application performance, reliability, and observability across services and platforms. -Contribute to automation initiatives, development workflows, and engineering practices that increase team effectiveness and delivery speed. -Support and guide less experienced engineers through knowledge sharing, technical discussions, and collaborative problem solving. -Stay current with emerging technologies and evaluate opportunities to apply them where they create measurable value. All About You -Strong proficiency in Golang, Java, or comparable object-oriented programming languages. -Ability to design and implement complex features within large-scale applications and distributed systems. -Familiarity with microservices architecture, service-to-service communication patterns, and API development. -Understanding of software design principles and architectural patterns that support scalable, resilient applications. -Capability to write clean, maintainable code while balancing performance, reliability, and long-term sustainability. -Proven success contributing to large engineering initiatives involving multiple teams and stakeholders. -Strong foundation in data structures, algorithms, and problem-solving techniques. -Ability to evaluate and optimize application performance in high-volume, transaction-oriented environments. -Commitment to automated testing, code quality, and continuous improvement throughout the software development lifecycle. -Familiarity with secure coding practices and modern software engineering standards. -Strong troubleshooting skills with the ability to diagnose and resolve issues across complex systems. -Comfortable working within Agile environments and collaborating with -geographically distributed teams. -Customer-focused mindset with an appreciation for how technical decisions influence user outcomes. -Curiosity and willingness to learn new technologies, frameworks, and development approaches. -Effective communication skills with the ability to collaborate across engineering, product, and design teams. -Degree in Computer Science, Engineering, or a related technical discipline, or equivalent practical background. -AI-first mindset with the ability to leverage tools such as GitHub Copilot, Claude Code, ChatGPT, and similar technologies to improve productivity, code quality, and delivery outcomes.
