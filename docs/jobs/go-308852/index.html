Go 雲原生平台工程師

Phison Electronics Corp_群聯電子股份有限公司 Zhunan Township, Miaoli County, Taiwan опубликовано 20 октября 2026

Go — основной язык Полная занятость
gRPCKubernetesDockerOpenTelemetryLinuxCI/CDTypeScriptAI/LLM
【工作內容】 ●使用 Golang 開發 Kubernetes Operator 與高效能後端服務。 ●開發多叢集管理平台，整合反向隧道、API 閘道與統一資源操作介面。 ●基於 Kubernetes、Rook/Ceph 與 Istio 服務網格，建構雲原生基礎設施。 ●設計與實作平台安全機制，包含 OIDC 身份驗證、mTLS 憑證管理、Kubernetes RBAC 與多租戶隔離。 ●開發 LLM 模型服務基礎設施，透過 KServe 與 Gateway API Inference Extension 管理模型的打包、部署與推論生命週期。 ●設計與實作 Kubernetes CRD 及 Controller，管理叢集、工作負載、租戶隔離與模型生命週期。 ●使用 ConnectRPC / gRPC 設計跨叢集 API，搭配 Protobuf 定義服務介面。 ●與前端（SvelteKit）、DevOps 及 QA 團隊合作，確保程式碼品質與安全性。 ●參與技術研究，探索 AI 推論優化、Gateway API 與雲原生新技術。 【資格要求】 ●Go 經驗：3 年以上 Go 開發經驗，熟悉 Goroutine 與 Channel。 ●Kubernetes：熟悉 Kubernetes 架構，具備 Operator / controller-runtime 開發經驗。 ●開源貢獻：參與過 GitHub 開源專案，熟悉 Pull Request 與程式碼審查。 ●Linux 技能：精通 Linux 系統操作、Shell 腳本、系統監控與效能優化。 ●容器化技術：熟悉 Docker，具備撰寫多階段 Dockerfile 與容器部署經驗。 ●API 設計：熟悉 ConnectRPC / gRPC、Protobuf 與 RESTful API 設計。 ●軟實力：優秀的問題解決能力、團隊合作精神與溝通技巧。 【加分項目】 ●熟悉 Kubernetes RBAC、NetworkPolicy 或 Admission Webhook 等安全機制。 ●具備 OIDC / OAuth 2.0 身份驗證或 mTLS 憑證管理實作經驗。 ●具備 AI/ML 模型服務經驗（如 KServe、vLLM 或類似推論框架）。 ●熟悉 Istio 服務網格或 Envoy Gateway。 ●熟悉 Gateway API 與 Kubernetes 網路模型。 ●熟悉 CI/CD 工具（如 GitHub Actions）與 GitOps 流程（如 Flux CD）。 ●具備 Helm Chart 開發與管理經驗。 ●熟悉 OpenTelemetry 分散式追蹤與可觀測性實踐。 ●熟悉前端技術（如 SvelteKit、TypeScript）。
