Edge and IOT Architect

Capgemini Bangalore, IN опубликовано 7 ноября 2026

KafkaKubernetesAWSGCPAzureMicroservicesCI/CDPythonReactAI/LLM
Roles & Responsibilities • Define and own the end-to-end architecture of enterprise IoT solutions covering edge computing, device connectivity, data ingestion, streaming, cloud platforms, data storage, analytics, APIs and user applications. • Contribute to the architecture and development of reusable IoT platforms and solutions spanning Edge to Cloud. • Design scalable, distributed and multi-tenant SaaS platform architectures for IoT products and connected applications. • Develop, test and integrate cloud Platform-as-a-Service services to build applications accessible through web and mobile interfaces. • Design and guide the implementation of cloud-native applications and microservices on AWS, Microsoft Azure or Google Cloud Platform. • Define appropriate edge-processing patterns, device-management approaches, connectivity protocols and offline or intermittent-connectivity strategies. • Architect real-time data-ingestion and event-streaming solutions using platforms such as Apache Kafka, Amazon Kinesis or Apache Pulsar. • Design secure and high-performing RESTful, event-driven and public APIs for integration with devices, enterprise systems, partner platforms and third-party applications. • Work across product, engineering, data, security, DevOps and user-experience teams to integrate platform components through well-defined public and internal APIs. • Define NoSQL and relational database architectures, including data modelling, indexing, partitioning, retention, performance and scalability considerations. • Provide hands-on architectural guidance for applications developed using .NET, Golang or Python and modern user-interface frameworks such as React or Angular. • Establish cloud-infrastructure, observability, reliability, security, deployment and operational architecture standards. • Define modern CI/CD, infrastructure-as-code, automated-testing and release-management practices suitable for SaaS-based product releases. • Evaluate technology alternatives, undertake architecture trade-off assessments and create reference architectures, solution blueprints and implementation roadmaps. • Support technical discovery, solutioning, estimations, proposals, client workshops and architecture governance for strategic IoT and edge-computing opportunities. • Where applicable, design AI-enabled IoT capabilities using retrieval-augmented generation, machine learning and intelligent analytics architectures. Our Ideal Candidate • Extensive experience designing scalable, distributed and cloud-native enterprise solutions or SaaS products. • Strong understanding of end-to-end IoT architectures, including devices, gateways, edge computing, connectivity, telemetry ingestion, device management, cloud platforms and applications. • Hands-on experience architecting and building IoT applications and connected-product platforms. • Strong experience with cloud infrastructure and managed services on at least one major cloud platform: AWS, Microsoft Azure or Google Cloud Platform. • Experience with IoT services such as AWS IoT, Azure IoT, Google Cloud-based IoT patterns or equivalent enterprise IoT platforms. • Strong understanding of edge-computing architectures, local processing, protocol translation, remote management and edge-to-cloud integration. • Experience with device and industrial communication protocols such as MQTT, AMQP, HTTP, OPC UA, Modbus or similar protocols. • Strong knowledge of relational and NoSQL database design, data modelling, indexing, partitioning and performance optimization. • Hands-on experience with at least one event-streaming or real-time data platform such as Apache Kafka, Amazon Kinesis or Apache Pulsar. • Strong professional experience developing applications using one or more of .NET, Golang or Python. • Experience designing and implementing APIs for cloud-native applications, including RESTful and event-driven integration patterns. • Familiarity with building rich web applications using React or Angular and integrating them with cloud-based backend platforms. • Good understanding of microservices, containers, Kubernetes, serverless computing and API-management technologies. • Familiarity with modern CI/CD, DevSecOps, infrastructure-as-code, automated testing and SaaS release-management practices. • Knowledge of cloud and IoT security, including device identity, certificate management, authentication, authorization, encryption and secure communications. • Experience defining high-availability, disaster-recovery, observability, monitoring and operational-support architectures.
