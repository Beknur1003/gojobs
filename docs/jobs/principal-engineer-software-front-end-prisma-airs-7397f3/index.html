Job Summary Location: Santa Clara, CA (Hybrid: 3 days/week on-site at Corporate HQ) Team: AIRS (Artificial Intelligence Runtime Security) About the AIRS Team Palo Alto Networks is pioneering the world’s most comprehensive AI security platform through Prisma AIRS—protecting complex ecosystems of AI models, applications, and agents from development through runtime. We are building a brand-new initiative within the AIRS team focused on advancing state-of-the-art AI/ML infrastructure. We are recruiting visionary frontend leaders to design the user experience that makes these powerful AI security capabilities accessible, actionable, and intuitive for enterprise users. The Role As a Principal/Sr. Staff Frontend Engineer on the AIRS team, you will operate at the intersection of UX, cloud security, and AI safety. You will drive the frontend architecture from the ground up, building highly responsive, scalable, and sophisticated web applications that allow enterprise users to visualize threat classifications, tune ML models, and manage adversarial defenses. You will be a key technical leader, setting the standard for UI engineering excellence as we build this platform. Key Responsibilities • Architectural Leadership: Lead the end-to-end architecture, design, and development of sophisticated user interfaces for the Prisma AIRS platform, working seamlessly across on-premise, public, and private cloud environments. • Technical Strategy: Research, recommend, and implement modern web frameworks, UI architectures, and micro-frontend strategies suited for high-volume, low-latency security platforms. • Cross-Functional Collaboration: Partner closely with product management, UX designers, and ML/backend engineers to translate complex user requirements and AI security concepts into intuitive, high-performance UI workflows. • Engineering Excellence: Establish and drive frontend engineering standards, including modern build processes (npm/yarn, Webpack, monorepos), comprehensive CI/CD toolchains, and Test-Driven Development (TDD). • Security First: Ensure the highest standards of frontend security, proactively mitigating vulnerabilities (XSS, SQL injections) and implementing type-safe code practices. • Mentorship: Actively guide the UI team through rigorous code and architectural reviews, fostering continuous improvement and producing an extraordinary user experience. Qualifications ​Required Qualifications: • Education & Experience: BS/MS in Computer Science, Software Engineering, or a related technical field (or equivalent practical experience) with 8+ years of experience in software engineering, specifically focused UI or Full Stack Development with a proven track record of building scalable enterprise web applications. • Hands-on experience setting up robust frontend toolchains for testing, documentation, and bundling using modern OS tooling libraries (npm/yarn, Webpack, monorepo structures). • Demonstrated history of Test-Driven Development using frameworks like Jest, Mocha, or Jasmine. • Deep understanding of web security best practices, code vulnerabilities, and type-safe code. • Excellent communication skills with a proven ability to lead cross-functional technical initiatives, mentor teams, and thrive in ambiguous, zero-to-one product environments. Additional Experience: • Data Visualization: Experience with building graphical and topology-based views, including using libraries like D3.js or similar visualization tools. • Backend Familiarity: Experience with server-side programming languages such as Node.js, GoLang, or Python. • Advanced Integrations: Ability to quickly learn and understand complex backend APIs, including REST, data streaming, and webhooks. • Architecture: Familiarity with Microservice architectures.
