Description du poste :CDI (statut cadre) ou Freelance à Neuilly-sur-Seine / Démarrage ASAP / Télétravail partiel autorisé5 ans d'expérience en tant qu'Architecte Logiciel Cloud & Systèmes Distribués (Go) H/FVotre mission Vous participez à la conception du Control Plane d'une plateforme Cloud innovante reposant sur une architecture distribuée et des technologies Open Source. En lien avec les équipes techniques, vous définissez les choix d'architecture et garantissez la robustesse, la sécurité et l'évolutivité de la solution. Vos principales responsabilités***Concevoir l'architecture du Control Plane et des microservices.***Définir les API et les interfaces entre les différents composants de la plateforme.***Concevoir les mécanismes d'orchestration et de communication asynchrone.***Participer aux choix des technologies Open Source (API Gateway, Message Broker, IAM Définir les architectures de sécurité (OAuth2, OIDC, RBAC Accompagner les équipes de développement et garantir les bonnes pratiques d'architecture. Environnement technique Go (Golang) - OpenStack - Terraform - Docker - Git - RabbitMQ - Kafka - NATS - Keycloak - OAuth2 - OpenID Connect - Microservices - API REST - CI/CDDescription du profil :Issu(e) d'une formation supérieure en informatique, vous justifiez d'au moins 5 ans d'expérience en architecture logicielle ou développement Backend sur des environnements Cloud. Vous maîtrisez les architectures distribuées, les technologies Open Source et les environnements Cloud modernes. Votre leadership technique, votre autonomie et votre capacité d'analyse sont reconnus.
