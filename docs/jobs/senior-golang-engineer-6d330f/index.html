職位名稱：資深 Golang 開發人員 職位描述： 我們正在尋找一位具有遊戲開發專業背景的資深 Golang 開發人員加入我們創新的團隊。此角色將利用 Golang 構建穩健的後端系統和 API，支持複雜的即時多人遊戲環境。您將與遊戲設計師和其他開發人員密切合作，創建高品質、可擴展且響應迅速的遊戲體驗。 職責： • 使用 Golang 設計和實現可擴展的後端服務，用於即時多人遊戲。 • 與遊戲設計師合作，集成複雜的服務端遊戲機制。 • 優化系統性能，以處理高流量和數據吞吐量，同時保持低延遲。 • 確保遊戲網絡和數據交易的穩定性和安全性。 • 維護和增強代碼庫，以提高可擴展性和效率。 • 主導技術討論和代碼審查，推動創新並保持編碼標準。 • 解決分佈式計算和高性能計算等領域的挑戰性問題。 • 緊跟技術進步，將最先進的解決方案融入到遊戲體驗中。 要求與資格： • 具有 3 年以上的專業軟件開發經驗，並專注於 Golang。 • 在後端系統架構和高性能計算方面有豐富經驗，特別是在遊戲開發背景下。 • 熟悉異步編程、線程和並發處理。 • 對於集成複雜數據結構和算法的系統設計有深入了解。 • 熟練使用版本控制系統（如 Git）。 • 具有 SQL 和 NoSQL 資料庫的經驗。 • 深刻理解微服務架構和容器技術（如 Docker 和 Kubernetes）。 • 熟悉 CI/CD 實踐和自動化測試環境。 • 出色的問題解決能力、分析能力和溝通技巧。 加分技能： • 具有雲服務（AWS、Google Cloud 等）在遊戲應用中的實際操作經驗。 • 在遊戲行業中具備網絡編程和數據安全的強大背景。 • 熟悉監控工具（如 Prometheus、Grafana 和 Elasticsearch）。 • 精通敏捷開發方法和有效的項目管理工具（如 Jira）。 • 能夠用中文進行有效溝通者必須具備；英文能力為加分項。
