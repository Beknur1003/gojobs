• Design system architecture, microservices, API contracts and technical solutions with scalability, security and maintainability in mind. • Develop and maintain backend services and APIs using Golang (Fiber/Gin), Node.js (NestJS/Express) and/or C# (.NET). • Design and optimize schemas, queries, indexes and data access for PostgreSQL, MongoDB, Redis and Elasticsearch/OpenSearch. • Establish code quality through code reviews, automated unit/integration testing, secure coding standards and technical debt management. • Analyze and improve application performance, bottlenecks, scalability and reliability. • Directly manage developers through work planning, task assignment, delivery tracking, coaching, mentoring and performance feedback. • Collaborate with the Tech Lead, QA, project/product stakeholders and clients to clarify requirements, manage risks and deliver agreed outcomes. • Build and maintain CI/CD pipelines using GitHub Actions and/or GitLab CI, including release validation and rollback procedures. • Manage containerization and deployment with Docker, Docker Compose, Kubernetes, Helm and ArgoCD/GitOps. • Operate infrastructure primarily on Microsoft Azure, including Linux systems, configuration, secrets and access controls. • Implement monitoring, logging, alerting and observability; respond to incidents, perform root cause analysis and track corrective actions. • Contribute to high availability, backup/restore, disaster recovery readiness and DevSecOps controls. Qualifications • Bachelor’s Degree from an accredited college or university with preferable coursework in Computer Science, Engineer, Mathematics, or a related field with course work in programming. • At least 2 years of relevant software engineering or backend development experience, with demonstrable senior-level technical judgment and leadership capability. • Hands-on proficiency in at least one of Golang, Node.js or C#/.NET, with ability to work across the broader stack. • Working knowledge of API design, distributed systems, databases, Git workflows, automated testing and the software delivery lifecycle. • Practical experience with Docker and CI/CD; familiarity with Kubernetes, Linux, cloud infrastructure and production troubleshooting. • Ability to lead developers, delegate work, communicate across teams and read English technical documentation. • Experience with Microsoft Azure, Helm, ArgoCD/GitOps and monitoring/observability platforms. • Knowledge of system design, microservices, secure coding, DevSecOps, performance tuning, scalability, high availability and disaster recovery. • Responsible use of AI-assisted development, including validation of correctness, security and maintainability. • Experience delivering software using Agile/Scrum practices and coordinating with multiple stakeholders.
