✨ Na MOUTS, transformamos tecnologia em resultados, com agilidade, eficiência e simplicidade. 📌 Vaga: Senior AI Software Developer 🌏 Modelo: Remoto Buscamos um(a) Desenvolvedor(a) de Software Sênior com foco em IA, para atuar de forma remota em projeto internacional (fuso horário Mountain Time, EUA). RESPONSABILIDADES: * Desenvolver e manter aplicações enterprise cloud-native em Microsoft Azure, usando Go e Python; * Integrar aplicações com SAP ERP/S/4HANA e outros sistemas corporativos; * Incorporar recursos de IA às aplicações, como integração com LLMs, agentes, function calling e RAG; * Desenhar integrações síncronas (APIs REST) e assíncronas/orientadas a eventos; * Modelar bancos de dados e arquiteturas de cache para garantir performance e escalabilidade; * Usar ferramentas de desenvolvimento assistido por IA em todo o ciclo de desenvolvimento, de geração de código a testes, documentação e code review; * Atuar no troubleshooting de aplicações, integrações, bancos de dados e infraestrutura cloud. HABILIDADES E EXPERIÊNCIAS ESSENCIAIS: * Inglês fluente ou avançado (escrita e conversação), obrigatório; * Experiência sólida no desenvolvimento de aplicações enterprise; * Experiência sólida com Go (Golang) e Python; * Experiência com desenvolvimento e deploy de aplicações cloud-native em Azure; * Experiência com integração SAP (APIs, OData, IDocs, BAPIs, RFCs, middleware ou mensageria); * Vivência com Azure API Management, Service Bus, Event Hubs, Azure Database for PostgreSQL, Entra ID, Key Vault, monitoramento e CI/CD; * Conhecimento sólido em SQL, PostgreSQL e padrões de integração entre aplicação e banco de dados; * Conhecimento em arquitetura de cache distribuído (Redis ou similar), estratégias de invalidação e cache-aside; * Experiência com microsserviços, arquiteturas distribuídas e sistemas orientados a eventos; * Conhecimento em OAuth 2.0, OpenID Connect, resiliência, tolerância a falhas e alta disponibilidade; * Experiência integrando aplicações com LLMs e serviços de IA, considerando segurança, privacidade e governança de dados; * Experiência com ferramentas como GitHub Copilot, Claude Code, OpenAI Codex ou similares; * Experiência em projetos para bens de consumo, manufatura, supply chain ou distribuição. DIFERENCIAIS QUE VALORIZAMOS: * Experiência com SAP BTP, SAP Integration Suite/CPI, SAP MDG ou SAP Variant Configuration; * Integração de SAP com sistemas de manufatura, gestão de pedidos, MES, WMS ou chão de fábrica; * Experiência com Infrastructure as Code, containers e práticas de deploy cloud-native; * Experiência levando aplicações com IA da prova de conceito até a produção.
