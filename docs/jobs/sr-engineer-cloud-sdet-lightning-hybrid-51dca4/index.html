About the Role: Lightning is a suite of services in the CrowdStrike cloud that expose sub-second, near-real-time APIs enabling Falcon Sensors to rapidly obtain threat information. Operating at massive scale, Lightning processes trillions of threat events daily within tight latency constraints — where performance and availability are critical to sensor operation and customer protection. CrowdStrike is seeking a Senior Software Developer in Test (SDET) for a hands-on, coding-intensive role on par with product development. The Sr. SDET will build and own Lightning-specific test tooling and frameworks, while leveraging and contributing to shared organization-wide testing infrastructure. This critical role owns end-to-end validation across both cloud-side services and Falcon Sensor interactions (e.g., validating interactions between cloud services and lightweight endpoint agents) — ensuring the system behaves correctly at every stage, from individual components to full system behavior. Testing concerns span functional, performance, contract, and chaos/resilience engineering. The Sr. SDET will participate in design discussions and code reviews with a focus on quality, serve as the team's SME for code hygiene, and contribute to service operations — all while continuously expanding test coverage and capabilities. Cybersecurity experience is a plus, not a prerequisite. This role is hybrid, requiring 2-3 days per week on-site in one of the posted locations.
