Title: Senior Full Stack Engineer – (Golang + React) Location: Bengaluru, Karnataka / Hyderabad, Telangana (Onsite, WFO) Duration: Contact Experience Required: 5+ Years Role Overview We are looking for a highly skilled Senior Full Stack Engineer with 5+ years of professional software engineering experience and strong hands-on expertise in Golang and React.js. The ideal candidate will have experience building scalable, high-performance backend services and modern web applications. The candidate should have a strong understanding of distributed systems, microservices, API design, frontend architecture, real-time systems, cloud technologies, and engineering best practices. The role requires an engineer who can work across the entire technology stack, take ownership of end-to-end features, solve complex technical problems, and contribute to engineering excellence across teams. Key Responsibilities Full Stack Engineering • Design, develop, and maintain scalable, high-performance applications using Golang and React.js. • Build production-grade backend services, APIs, microservices, and frontend applications. • Develop reusable and maintainable React components and frontend libraries. • Design and implement scalable application architectures across frontend and backend layers. • Build reliable and fault-tolerant distributed systems. • Work on real-time applications and data handling using WebSockets and related technologies. • Ensure applications are responsive, performant, secure, and cross-browser compatible. • Collaborate with product, engineering, and cross-functional teams to deliver end-to-end features. Backend Engineering – Golang • Develop high-performance backend services using Golang. • Design and implement RESTful APIs and microservices. • Work with event-driven and distributed architectures. • Optimize backend performance, scalability, reliability, and maintainability. • Work with SQL and NoSQL databases and ensure efficient data access. • Implement robust error handling, logging, monitoring, and observability. • Write clean, modular, well-tested, and production-ready Go code. Frontend Engineering – React • Build scalable and high-quality web applications using React.js. • Develop reusable components and frontend libraries. • Work with modern JavaScript/TypeScript, HTML5, and CSS3. • Implement responsive and accessible user interfaces. • Optimize frontend performance and application load times. • Work with WebSockets and real-time data where required. • Debug complex frontend issues and ensure high application reliability. • Follow modern frontend architecture and engineering best practices. Engineering Excellence • Contribute to organization-wide engineering initiatives focused on scalability, reliability, developer productivity, and operational excellence. • Define and promote coding standards, design patterns, and architectural best practices. • Participate in architecture discussions, technical design reviews, and code reviews. • Identify opportunities to improve system performance, reliability, and maintainability. • Build reusable solutions and cross-cutting capabilities that can benefit multiple engineering teams. • Mentor junior and mid-level engineers and contribute to a strong engineering culture. Required Skills & Qualifications • 5+ years of professional software engineering experience. • Strong hands-on experience with Golang. • Strong hands-on experience with React.js. • Solid understanding of modern JavaScript/TypeScript, ES6+, HTML5, and CSS3. • Strong experience building scalable backend services and distributed systems. • Strong understanding of microservices architecture and API design. • Experience building production-grade web applications. • Experience with REST APIs and WebSockets. • Strong knowledge of SQL and NoSQL databases. • Experience with cloud platforms such as AWS, GCP, or Azure. • Hands-on experience with Docker and Kubernetes. • Experience with CI/CD pipelines and modern DevOps practices. • Strong understanding of application performance, scalability, observability, and reliability. • Excellent debugging and problem-solving skills. • Strong understanding of software development lifecycle and engineering best practices. • Ability to work independently and collaborate effectively with cross-functional teams. • Strong communication skills and ability to mentor other engineers. Preferred Qualifications • Experience working on large-scale, high-traffic applications. • Experience with event-driven architectures and messaging systems. • Experience with cloud-native application development. • Familiarity with frontend state management and modern React ecosystem. • Experience with real-time systems and WebSocket-based applications. • Experience working with large-scale distributed systems and internal engineering platforms. • Prior experience in product companies or high-growth technology environments is a plus.
