THE PROJECT📝 As a Senior Software Engineer, you will be engaged to deliver key initiatives that strengthen the security and resilience of Form3's cloud-native payments platform. Working within a collaborative engineering environment, you will design, build, and implement capabilities that enhance the security, trust, and resilience of our systems while supporting the delivery of defined project outcomes. This engagement is centred on hands-on software engineering and security-focused platform development. You'll apply your expertise across areas such as API security, cryptographic controls, AI governance, software supply chain security, and automated security tooling to deliver production-ready solutions. Working alongside engineers, platform specialists, and security experts, you'll focus on delivering scalable, maintainable capabilities that can be embedded into the software development lifecycle and provide lasting value beyond the engagement. WE’RE LOOKING FOR 🔍 • Deep understanding of designing and building distributed systems • Enjoys working on complex challenges within critical software where high performance and robustness are essential • Familiarity with cloud and containerisation technologies, test automation tools and CI/CD pipelines • Interest in owning projects end-to-end and supporting them as they go live in production • Appreciation of clean code and software engineering best-practice • Experience with Go, along with a “right tool for the job” mentality • Great communication skills who enjoy sharing knowledge and collaborating with others TECH STACK ⚙️ Here are a few of the tools and methodologies we utilise: • Infrastructure: AWS, GCP, Azure, Kubernetes • Platform: CockroachDB, NATS JetStream, Elasticsearch, Vault, Cilium • Tools: Terraform, Flux, GitHub, Prometheus, Pact.io, Tilt • Code: Go (and a little Java), containerised microservices, CQRS, open source • Ways of working: TDD/BDD, Pair Programming, 100% remote, SecDevOps INTERVIEW PROCESS ✍️ Stage 1: Screening Call with Talent Team Stage 2: Take home test Stage 3: Technical interview We always aim to stick to the above process, however there may be occasions when an additional interview stage is needed for us to be sure we’re hiring the right person!
