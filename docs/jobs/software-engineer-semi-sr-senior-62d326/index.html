¡En Drimo seguimos creciendo y queremos que te sumes a nuestro equipo! 🚀 Buscamos un/a Software Engineer para incorporarse al equipo de uno de nuestros principales clientes, una reconocida aerolínea, donde tendrás la oportunidad de trabajar en proyectos de alto impacto y gran escala. ¿Cuál será tu misión? Diseñar, desarrollar e implementar soluciones tecnológicas robustas y escalables, participando en la construcción de APIs, servicios backend y componentes frontend dentro de arquitecturas cloud sobre Google Cloud Platform. Serás parte de equipos multidisciplinarios, contribuyendo a la evolución de productos digitales mediante buenas prácticas de desarrollo, automatización y mejora continua Principales funciones: • Diseñar y desarrollar APIs de alto rendimiento utilizando lenguajes como Python y/o Golang. • Implementar soluciones sobre Google Cloud Platform, utilizando servicios como Cloud Run, BigQuery e IAM. • Desarrollar y mantener aplicaciones frontend utilizando frameworks modernos como Angular, React o equivalentes. • Participar en la definición y evolución de arquitecturas de software escalables. • Construir e integrar servicios utilizando APIs REST, gRPC y Protocol Buffers (deseable). • Implementar y mantener pipelines de CI/CD utilizando herramientas como GitLab, GitHub u otras plataformas equivalentes. • Gestionar código utilizando buenas prácticas de desarrollo colaborativo y GitFlow. • Participar en equipos ágiles utilizando metodologías como Scrum o Kanban. • Contribuir en iniciativas de automatización, mejora continua y optimización de soluciones tecnológicas. • Trabajar con equipos técnicos y de negocio para diseñar soluciones alineadas a las necesidades del producto. Requisitos: • Experiencia desarrollando soluciones Full Stack. • Experiencia con Python (excluyente). • Experiencia trabajando con Google Cloud Platform (GCP), idealmente con: • Cloud Run (Services y Jobs). • BigQuery. • IAM (Identity and Access Management). • Experiencia desarrollando aplicaciones frontend con Angular, React o frameworks equivalentes. • Experiencia construyendo y consumiendo APIs. • Manejo de Git y flujos de trabajo colaborativo (GitFlow). • Experiencia trabajando con metodologías ágiles y herramientas como Jira/Atlassian. • Conocimientos de bases de datos y consultas SQL. Conocimientos deseables: • Experiencia con Golang. • Experiencia con servicios GCP adicionales como Cloud Load Balancer, Spanner, Bigtable, Dataflow o Apache Beam. • Conocimientos de Java y Bash. • Experiencia con Terraform e Infraestructura como Código (IaC). • Conocimientos de CI/CD. • Conocimientos de DNS. • Experiencia con gRPC y Protocol Buffers. • Conocimientos de Node.js y herramientas del ecosistema frontend. Porque el mejor código nace de un buen equilibrio, en Drimo te ofrecemos: • Día libre por tu cumpleaños. • Cursos y certificaciones para seguir aprendiendo. • 5 días de vacaciones adicionales al año para que recargues energías. • Seguro complementario de salud y dental que te acompaña cuando más lo necesites.
