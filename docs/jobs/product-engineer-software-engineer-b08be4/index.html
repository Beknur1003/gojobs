About the Role This is a full-stack product engineering role at a consumer fintech company building tools that help everyday people manage cash flow, access earned wages early, and build credit. You will work closely with product, engineering, and business leaders to ship high-impact features directly tied to users' financial wellbeing. What You'll Do • Build product features end-to-end, including domain models, business logic, and API integrations. • Drive incremental, data-driven releases toward ambitious product milestones. • Use SQL and analytics tools to evaluate product and system performance regularly. • Test and debug complex state machines in an event-driven, pub/sub backend to ensure a seamless user experience. • Ship to production daily via a rapid CI/CD process, owning implementations end-to-end and responding to production incidents as needed. What We're Looking For • 3 or more years of experience building backend features end-to-end for production systems. • Proficiency designing and consuming RESTful APIs, including authentication/authorization patterns and rate limiting. • Experience with event-driven architectures and message queues such as Kafka or Pub/Sub. • Experience with relational databases (PostgreSQL or MySQL), including data modeling and query optimization. • Experience writing SQL and using analytics tools to assess system and product performance. • Background building consumer-facing products (not exclusively B2B). • Hands-on experience with CI/CD pipelines, version control, automated testing, and code review. • Strong computer science fundamentals: algorithms, data structures, and system design. • Meaningful experience at an early-stage startup or high-growth environment, rather than exclusively large or late-stage companies. • Experience with Go (golang) deployed on GCP is a strong plus. • Excellent cross-functional communication skills, with the ability to translate technical concepts for non-technical stakeholders. Compensation & Benefits Salary range: $120,000 to $200,000 USD annually. Visa sponsorship is available. Location On-site in San Francisco, CA. Candidates based in Seattle or willing to relocate to San Francisco or Seattle will also be considered.
