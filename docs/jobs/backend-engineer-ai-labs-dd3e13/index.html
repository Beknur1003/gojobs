Backend Engineer - AI Labs

IDFC FIRST Bank Mumbai опубликовано 4 ноября 2026

Офис Полная занятость
PythonNode.jsReactAI/LLM
Job Requirements About the Role As a Back End Engineer within the Data & Analytics function, you will be responsible for developing and maintaining scalable, high-performance backend applications. You will work with asynchronous programming languages such as Python, Node.js, and Golang, contributing to architecture decisions, code quality, and productization of AI-driven solutions. This role involves close collaboration with cross-functional teams to ensure seamless integration and optimal performance across systems. Key ResponsibilitiesPrimary Responsibilities • Design, build, and maintain efficient, reusable, and reliable backend code using design patterns and asynchronous programming. • Collaborate with Frontend Engineers, Data Scientists, Data Engineers, ML Engineers, and Software Developers to support model development and productization. • Ensure optimal performance, quality, and responsiveness of backend applications. • Identify and resolve bottlenecks and bugs, optimizing code and database queries. • Stay updated with full-stack technologies and emerging tools, especially React and Python. • Contribute to backend and frontend end-to-end implementation. Secondary Responsibilities • Ensure code consistency and quality by adhering to best practices in Python, Node.js, and Golang development. • Conduct thorough code reviews and collaborate with team members to improve standards and maintain high code quality. Managerial and Leadership Responsibilities • Provide guidance and mentorship to junior developers, supporting their professional growth. • Lead by example in writing maintainable, performant, and sophisticated code. • Inspire innovation within the backend development team by adopting efficient and modern practices. What We Are Looking ForEducation • Graduationin BCA or B.Tech or BSC. Experience • Minimum of 2 years of relevant experience in backend development. Skills and Attributes • Proficiency in backend development using Python, Node.js, Golang, or similar asynchronous programming languages. • Strong understanding of scalable system design and backend architecture. • Familiarity with full-stack development and modern frontend technologies. • Excellent problem-solving and debugging skills. • Strong communication and collaboration abilities.
