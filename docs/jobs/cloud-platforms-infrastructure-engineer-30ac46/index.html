Job Family: SAAS/PAAS/Cloud Application Development (India) Travel Required: Up to 10% Clearance Required: None Guidehouse India Private Limited is seeking a Cloud Infrastructure Engineer. The ideal candidate will have experience with Infrastructure Automation tools such as Terraform, Docker, Kubernetes, Ansible, and CI/CD tools. This role requires someone comfortable writing code who can understand and follow standards and best practices to automate creation of cloud resources in a complex environment. This position will be part of the central Platform Engineering group in the office of the CIO and will require working remotely with users across Business segments, IT, and Guidehouse Technology. The Cloud Infrastructure Engineer will mentor team members. As such, the ideal candidate must have experience clearly explaining solutions to complex problems and a demonstrated ability to lead and impart knowledge effectively to junior team members. What You Will Do: As a Platform Infrastructure Engineer, you will: • Work with Tech leads and product managers to plan and implement complex infrastructure while mentoring junior team members. • Look for enhancements and innovative solutions to improve existing IT Infrastructure, procedures, or processes. • Commit changes into git repositories, open Pull Requests, and review others’ code • Build automations in CI/CD tools like GitHub Actions • Have an understanding of agile methodologies and DevOps practices. • Have experience in creating CI/CD pipelines to deploy into multiple environments, Knowledge of Cloud services like AWS and Azure is preferable. • Administer various flavors of Linux running in the public cloud (Azure & AWS) environments. • Working knowledge of ServiceNow, GitHub, and Jira. What You Will Need: • 3+ years of relevant industry experience. • 2+ years of experience in a DevOps or Cloud Infrastructure Engineering (or similar) role • Bachelors degree or equivalent in Engineering • Strong knowledge of Terraform and other Infrastructure-as-Code tools • Strong knowledge of infrastructure automation tools (e.g., Ansible, GitHub Actions). • Experience working in public cloud (specifically Azure or AWS) • Ability to research, plan, organize, lead, and implement new processes or technologies. • Proficiency in scripting and programming languages (e.g., Golang, Python, Bash). • Proficient building with APIs and cloud functions • Comfort and demonstrated ability to do Agentic Engineering in a secure, robust way What Would Be Nice To Have: • Experience configuring Helm charts, writing Terraform, administrating Azure and/or AWS, working in Docker • Have knowledge of containerization through Docker, Kubernetes, Ansible, etc. • Experience maintaining Big Data or analytics platforms, secrets management toling • Experience working in version control platforms such as GitHub or Azure DevOps • Experience with agile management tools like Jira, GitHub Projects, or Azure DevOps • Ability to clearly articulate pros and cons of various technologies and platforms and architectural options, as well as being able to document use cases, solutions and recommendations. • Cloud certifications (Azure or AWS) preferred • Linux Certifications preferred (e.g. RedHat) What We Offer: Guidehouse offers a comprehensive, total rewards package that includes competitive compensation and a flexible benefits package that reflects our commitment to creating a diverse and supportive workplace.
