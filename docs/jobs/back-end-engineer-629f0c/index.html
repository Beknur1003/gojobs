後端工程師 Back-End Engineer

創順科技有限公司 Neihu District, Taipei City, Taiwan опубликовано 21 октября 2026

Working as a Back-end Engineer at UNNO Technology means building reliable, scalable, and maintainable systems that support our product growth. We value clean architecture, reusable and testable code, and long-term infrastructure thinking. We are looking for a Back-end Engineer who can develop core features, design robust APIs, and contribute to building a stable and scalable web infrastructure. 【 主要職責｜Responsibilities 】 ．依據產品與商業需求，開發後端功能，撰寫可重用、可測試且高效的程式碼。 ．設計、開發並維護 RESTful APIs，支援產品功能與系統整合。 ．優化 SQL 查詢效能，確保資料庫操作效率與系統效能。 ．撰寫單元測試與整合測試，確保功能正確性與系統穩定度。 ．參與系統架構與基礎建設設計，使其同時符合短期產品功能規劃與長期產品發展目標（加分）。 ．Develop new features depending on the business requirements. ．Develop and maintain RESTful APIs. ．Optimize SQL queries. ．Write unit tests and integration tests. ．Design and build infrastructures which meet the short-term product feature plan as well as the long-term product's future goals. (is a plus) 【 必備條件｜Must to have 】 ．熟悉 Python 程式語言，並具備 Django 或 FastAPI 等任一 Python Web Framework 的使用經驗。（公司使用 Django 進行高可用分散式系統開發） ．理解 RESTful API 設計模式，並具備實際 API 開發能力。 ．熟悉關聯式資料庫（如 PostgreSQL、MySQL、Microsoft SQL Server 等）。 ．Familiarity with Python and any of its web frameworks such as Django or FastAPI. ( For your information, we develop highly-available distributed systems by Django framework.) ．Understanding of RESTful API Design patterns and ability to develop. ．Familiarity in using relational databases such as PostgreSQL, MySQL, Microsoft SQL Server ,etc. 【 加分項目｜Nice to have 】 ．具備資訊工程或相關科系之學士或碩士學位。 ．具備 2–3 年以上 Redis 與 Celery 使用經驗。 ．具備 Docker、Kubernetes、CI/CD 與 DevOps 相關知識（公司使用 Helm 與 Drone CI）。 ．具備 Golang 與 gin framework 的開發經驗。 ．具備高併發（High Concurrency）系統處理經驗。 ．Bachelor / Master degree related to computer science. ．2-3+ years experience in using the Redis database and Celery framework. ．Knowledge of Docker, Kubernetes, CI/CD and DevOps concepts. (We use Helm and Drone CI.) ．Experience in Golang with gin framework. ．Experience in handling highly concurrent systems. 【 我們期待合作的夥伴具備｜We’d love to cooperate with candidates who have 】 ．熱愛軟體開發、問題解決與技術挑戰。 ．自我驅動、行動力強，重視成果並持續精進。 ．具備良好的溝通能力與團隊合作精神。 ．Passionate about software development, problem-solving and technical challenges. ．Self-motivated with strong propensity for action, results and continuous improvement. ．Team players with great communication and teamwork skills.
