Senior Test Automation Quality Engineer Job summary The Senior Test Automation Quality Engineer owns automated quality for a data platform and a data analytics platform. The platform keeps many partner integrations, and those integrations feed the dashboards and reports partners use. This role works with Engineering on requirements, designs, schedules, and release risk. The engineer uses AI coding agents in the Cursor and Claude ecosystem to speed up test authoring, review, and failure analysis, and keeps a human in the loop for assertions, coverage, and release decisions. What you will do • Design and maintain automated tests for partner integrations, the pipelines that land their data, and the dashboards and reports built from that data. • Cover the path from source system to published report: ingest, transform, warehouse or lake, then the dashboard and report the partner sees. Include schema, row presence, freshness, and reconciliation across systems. • Turn manual cases and acceptance criteria into stable automation in Java, Python, or Go. Use Playwright, Cypress, or Selenium for dashboard and report UI, and an API framework for integration and data services. • Prove that a new or changed integration does not break existing partner dashboards and reports. Call out which reports, datasets, and partners a failure affects. • Build these checks on AWS (for example S3, Glue, Athena, Lambda, Step Functions, and IAM) and against the warehouse the analytics platform uses. • Use Cursor and Claude agents to draft tests, page objects, and triage notes from requirements and failures. Review every generated assertion before it is merged. • Execute suites in CI, diagnose failures, and separate product defects from test defects and flakes. File defects with evidence: pipeline, query, dashboard, and report. • Write and maintain test plans, cases, procedures, and release reports. Plan test scope against delivery dates when several integrations ship together. • Review integration designs and report requirements for gaps, risk, and testability before build starts. • Define quality gates for release readiness: an integration is not ready while its dashboards or reports are wrong, empty, or stale. • Review historical results, call out regressions in shared datasets that fan out to many reports, and recommend changes to standards and coverage. • Partner with Engineering and Quality Engineering in an agile delivery model. Explain findings so the team knows which partner experience is at risk. What you bring • Proven experience as a senior test automation or quality engineer, including ownership of suites through release. • Experience on a data platform or analytics platform with multiple integrations, where partner dashboards and reports depend on that data. • Proficiency with AI coding agents, specifically the Cursor and Claude ecosystem: skills, rules, prompts, and review of agent-written tests. • Strong programming in at least one of Java, Python, or Go, and the ability to read the others. • Hands-on UI automation with Playwright, Cypress, or Selenium, plus REST API automation. • Solid AWS experience for data pipelines and analytics workloads. Secrets stay in a secret store, never in tests or logs. • Experience testing web and API systems that depend on a database, warehouse, or lake. • Skill in test design, defect isolation, and release reporting, with a high bar for assertion quality. • Clear writing for test plans, bug reports, and quality summaries that name the affected reports and partners. Preferred • Experience with more than one UI tool (Playwright, Cypress, Selenium) or more than one language (Java, Python, Go). • CI ownership (GitLab CI or GitHub Actions), including artifacts, quality gates, and pipeline triage. • Hands-on checks for schema compare, row counts, and freshness, and for warehouses such as Snowflake or Athena. • Experience validating scheduled or exported reports (PDF, email, or scheduled dashboard delivery), not only the on-screen dashboard. • Educational/Vocational/Previous Experience Recommendations: • Working Conditions: • ConnectWise is an Equal Opportunity Employer, dedicated to building a diverse and inclusive workforce and providing a workplace free from discrimination and harassment.
