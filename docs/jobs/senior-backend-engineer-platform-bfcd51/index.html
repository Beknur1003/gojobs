We are looking for a Senior Backend Engineer to design, build, and maintain backend services in a modern, cloud-native architecture. AI-assisted development is a core part of how we work. We expect you to use AI tools to deliver large projects, not only small tasks, while keeping full control over code quality. This role suits someone who is comfortable with ambiguity and enjoys a fast-paced environment where requirements change as you go.
