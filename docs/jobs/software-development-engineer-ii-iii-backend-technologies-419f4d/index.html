Mandatory : - Strong Golang programming skills - Heavy backend engineering experience - REST/gRPC API development - Microservices architecture - Event-driven systems (Kafka/RabbitMQ/NATs preferred) - PostgreSQL and caching (Redis) - Concurrency (goroutines, channels) - Unit testing and code quality - Performance optimization - Debugging production issues Good to Have : - Kubernetes - Docker - Observability (Prometheus/Grafana) - AI platform integration experience What youll be responsible for : - Design, develop, and maintain backend services and REST/gRPC APIs using Golang - Write clean, maintainable, and efficient code following best practices - Participate in code reviews and contribute to technical design discussions What youd have : - Strong experience of 3 - 7 years in Golang, including goroutines, channels, interfaces, and struct design -
