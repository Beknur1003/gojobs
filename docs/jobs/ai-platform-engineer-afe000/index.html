Solid grasp of system design, data modeling, testing, debugging, and code review -6-12 months shipping LLM-based systems to production, with agentic workflows in use by real end users -Daily, hands-on experience with AI coding agents like Claude Code and Codex to write, test, and review production code -Experience building autonomous or multi-step agents with tool use (Claude Agent SDK, Anthropic/OpenAI APIs, or similar) -MCP server experience (OAuth flows, scoped tokens, user-level access control) -Identity and access experience: Okta (or similar IdP), SSO (SAML/OIDC), SCIM provisioning, group-based and device policies -Creating automated system identities (GitHub Apps, service accounts, API keys, secret managers like 1Password) -Designing guardrails: least-privilege, audit logs, CI checks, approval gates, allowlists, and policy-as-code -Creating evals for LLM systems: test sets, rubrics, CI regression, release gates, and live production scoring -Instrumenting production system observability: tracing, metrics, alerting, dashboards (OpenTelemetry, Grafana, Datadog, Langfuse, LangSmith, Braintrust) -Tracking AI spend across vendors: per-key limits, cost centers, budgets, actionable alerts -Strong in at least one of TypeScript, Python, Go; working knowledge of CI/CD (GitHub Actions/etc), cloud infrastructure -Track record of independently identifying and automating manual processes (two or three concrete examples) -Clear, concise written communication (specs, runbooks, RFCs)
