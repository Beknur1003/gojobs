Job Description – Senior Backend Software Engineer Job Overview: We are looking for an experienced Senior Backend Software Engineer to join our engineering team in Finland. The ideal candidate will have strong expertise in backend development using Golang and/or Kotlin, along with hands-on experience in cloud-native technologies, distributed systems, and event-driven architectures. Key Responsibilities: • Design, develop, and maintain scalable and high-performance backend applications. • Build and implement backend services using Golang and/or Kotlin. • Develop and maintain cloud-native solutions, particularly within Google Cloud Platform (GCP). • Design and implement microservices and event-driven architectures. • Work with messaging systems such as Apache Kafka. • Deploy, manage, and optimize applications running on Kubernetes. • Leverage AI-assisted development tools such as GitHub Copilot to improve development productivity and code quality. • Collaborate with cross-functional teams to deliver high-quality software solutions. • Follow Agile/Lean development methodologies and contribute to continuous improvement. • Participate in technical discussions, code reviews, architecture decisions, and knowledge sharing. Must-Have Skills & Experience: • 10+ years of professional experience in backend software development. • Strong hands-on development experience with Golang and/or Kotlin. • Experience developing and deploying solutions in public cloud environments, especially Google Cloud Platform (GCP). • Hands-on experience with Kubernetes. • Strong understanding of event-driven architectures and messaging platforms such as Apache Kafka. • Experience using AI-powered development tools such as GitHub Copilot. • Experience working with Agile/Lean software development principles. • Strong problem-solving, analytical, and communication skills. • Finnish language skills are preferred, as Finnish is the team's primary working language. Good-to-Have Skills: • Knowledge of Vertex AI or other AI/ML technologies. • Experience with Infrastructure as Code (IaC), particularly Terraform. • Experience working with graph databases, especially Neo4j. • Knowledge of networking technologies such as IP/MPLS. • Interest in improving team collaboration, engineering practices, and development processes.
