Nos équipes IT/produit, à Paris et Nantes livrent tous les jours des de nouvelles fonctionnalités produits, en utilisant les technologies : - Architectures distribuées en Microservices développés en Golang (DDD, architecture hexagonale) - Technologie Vue.js / Nuxt pour le Front ; - Bases de données : PostgreSQL, Elasticsearch ; - BigData : BigQuery, Looker Studio ; - Agents conversationnels : Anthropic SDK - Outils IA : Anthropic, Cursor, VScode/ Github Copilot - Infrastructure : Kubernetes, Tilt, Cloudbuild, Terraform et Datadog Vous rejoignez une squad pour : - Prendre part à la conception technique des projets - Développer et livrer quotidiennement des nouvelles features en production - Faire profiter l’organisation de votre expérience et affûter votre expertise - Participer aux différents rituels Scrum/Agile - Veille à la stabilité opérationnelle de nos médias (monitoring) - Prendre part au shift de la delivery logiciel : développement avec Agent IA - 2 jours de télétravail par semaine (pas de ‘full remote’) Pourquoi FIGARO CLASSIFIEDS ? - Autonomie et flexibilité ; nous vous faisons confiance pour réaliser votre travail - Accès aux conférences, devoxx, Devfest, formations en ligne - Travailler dans un environnement technique en évolution constante pour suivre et intégrer les meilleurs standards du secteur : GCP, K8s, Elasticsearch, Terraform, Container - Guildes Go et Front - Autoformation et animées internes sur la tech : IA, Devops Nos sujets et enjeux sont nombreux : Search, SEO, web perf, scalabilité, monitoring, data, analytics, sécurité, Devops, qualité de code : vous pourrez travailler sur les sujets qui vous animent le plus. Nous positionnons l’IA au coeur de nos enjeux, et revisitons tous les métiers de l’entreprise avec son usage. Pour la squad IT cela signifie : - développer de nouvelles fonctionnalités motorisées par l’IA (agent, parcours clients) - augmenter les développeurs avec tous l’outillage nécessaire : nous testons, apprenons et nous améliorons tous les jours sur le sujets - découvrir les nouvelles opportunités (BMAD, spec driven development via des hackathons) • Diplôme : Licence Scientifique, école d’ingénieur, licence et master en informatique - 5 ans minimum d’expérience (hors stage) - Développement en Java, PHP ou Python et volonté de basculer sur le développement en Go. - Une expérience en Golang serait un avantage, mais n’est pas essentielle - Bases de données - Capacité à apprendre de nouvelles technologies - A l’aise pour démarrer un projet de zéro mais aussi pour maintenir et améliorer le code existant - Appétence pour travailler sur des médias internet et marketplaces à fort enjeux concurrentiels : produit au coeur des squads - Un réel attrait pour les nouvelles opportunités offertes par l’IA, tant sur les fonctionnalités produit que sur l’accélération des developpements informatiques.
