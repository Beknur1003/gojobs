We are looking for a Senior Full Stack Engineer / AI Engineer with strong experience building scalable applications using modern microservices and event-driven architectures. In this role, you will design, develop, and maintain robust software solutions, working across frontend and backend technologies while contributing to AI-powered applications, LLM integrations, and intelligent agents. The ideal candidate is a hands-on engineer with strong technical expertise, a solid understanding of software architecture, and a passion for building secure, scalable, and high-performance products. Key Responsibilities • Design, develop, and maintain scalable applications using Next.js (React), Python, and Go (Golang). • Architect and implement decoupled microservices following Clean Architecture and Domain-Driven Design (DDD) principles. • Design and integrate RESTful APIs, GraphQL services, and asynchronous messaging systems. • Contribute to the development and integration of AI agents using Large Language Models (LLMs) and conversational AI frameworks. • Ensure application performance, security, reliability, and scalability. • Conduct code reviews and implement automated unit and integration testing. • Collaborate with cross-functional teams on cloud deployments using Azure and AWS. • Contribute to CI/CD pipeline optimization and software development best practices. Requirements • 3-5 years of experience in full stack software development. • Strong development experience with Next.js (React), Python, and/or Go (Golang). • Solid experience designing, developing, and consuming RESTful APIs and GraphQL services. • Hands-on experience with microservices and event-driven architectures. • Knowledge of SQL databases such as PostgreSQL or SQL Server, and NoSQL technologies such as MongoDB or Redis. • Familiarity with asynchronous messaging technologies such as Kafka, RabbitMQ, or Azure Service Bus. • Experience with containerization and orchestration tools, including Docker and Kubernetes. • Knowledge of CI/CD pipelines, Git, and preferably Azure DevOps. • Understanding of API security, OAuth 2.0, JWT, and secure development practices. • Experience implementing unit and integration tests. • Experience with AI agent frameworks such as LangGraph or AgentCore, or integrating LLMs such as OpenAI or Anthropic. Nice to Have • Strong understanding of SOLID principles, object-oriented programming, and design patterns. • Familiarity with Domain-Driven Design (DDD), Clean Architecture, and Clean Code practices. • Experience with code quality tools such as SonarQube and code coverage analysis. • Experience with automated testing frameworks. • Experience working in Agile environments using Scrum or Kanban. • Familiarity with cloud services such as Azure Web Apps, Azure API Management, and AWS Lambda.
