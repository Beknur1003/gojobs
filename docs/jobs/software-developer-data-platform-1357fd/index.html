As a Software Developer, you will build and enhance the core infrastructure and services powering a global data ecosystem. Operating within Platform Engineering, the Data Platform team provides real-time streaming, cloud-based databases, release management, distributed key-value storage and bespoke technical solutions. These platforms enable developers to access, process and manage information in real-time and at immense scale. Focusing on real-time stream processing, cloud infrastructure management, system integration and release automation, you will develop, enhance and support an expanding, business-critical platform. This involves contributing to the management of a comprehensive suite of services, tools and platforms, utilising technologies such as Golang, Kafka, Flink, GCP, Spanner and BigQuery.
