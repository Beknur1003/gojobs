About the Role: We are looking for a DevOps engineer who is passionate about Cloud, Microservices, Cloud native technologies. Responsibilities: • Build and Maintain cloud infrastructure on AWS. • Maintain systems health and availability. • Understand and resolve technical issues as they arise. • Automate 95% of tasks. • Logs and monitoring of cloud infrastructure environments. • Manage database and workload. Profile Requirements: • Strong knowledge of Linux systems. • Good knowledge of shell scripting. • Good understanding of networking (DNS, Routing, Subnetting). • 4+ years experience in Amazon Web Services. • 2+ years of Kubernetes in production environments. • Infrastructure as a code - Terraform / Helm etc. • CI / CD with Jenkins, Argo or similar tools. • Experience with system administration and infrastructure maintenance. • Designing / Maintaining logging architecture. • Monitoring / Alerting with Prometheus or similar tools. • Experience with automation and/or configuration management tools like Ansible/Salt stack. • Experience with containers. • Knowledge of different SQL / NoSQL databases. • Good to have: Python / Golang Skills.
