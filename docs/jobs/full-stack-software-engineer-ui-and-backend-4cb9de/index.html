Job Title: Full-Stack Software Engineer (UI and Backend) Key Areas of Proficiency: • Frontend: React.js, JavaScript/TypeScript, Material UI (MUI), HTML/CSS, REST API integration, responsive and accessible UI design • Backend: Node.js (Express), Golang, REST API design; Python a plus • Data: MongoDB; exposure to OpenSearch, ClickHouse or other analytics stores • Identity and Security: OAuth 2.0/OIDC, SSO (Auth0, Amazon Cognito), JWT, role-based access control, secure coding practices (OWASP Top 10) • Public Cloud Platforms: AWS (including ECS/Fargate, EKS, Lambda, S3, CloudFront, KMS, Secrets Manager) or equivalent services in GCP/Azure • DevOps and Observability: Docker, Kubernetes, GitHub Actions CI/CD, OpenTelemetry-based logging, metrics and tracing • Artificial Intelligence: building product features on LLM APIs (Anthropic, OpenAI, Amazon Bedrock) and agent frameworks; familiarity with Generative AI concepts Key Responsibilities: Design & Architecture (25%): • Collaborate closely with product management, UX and customer-facing teams to turn product requirements into intuitive, competitive features, end to end. • Work with software, ML and operations teams to design APIs, data models and UI components that address requirements fulfillment, CI/CD integration, scalability, performance, security and cost-efficiency. • Contribute to UI standards and shared components so the console stays consistent as it grows. Core Engineering (75%): • Develop, implement and sustain features across the stack: React UI, backend APIs and services, and the data behind them. • Build console workflows for: • policy configuration • dashboards and reporting • user and role administration • integrations such as SSO, SIEM, Slack and Microsoft Teams • Own the configurations, APIs, authentication and authorization, logging, metrics and other aspects of your feature areas. • Design and maintain unit, API and end-to-end tests (e.g., Mocha, Playwright), and collaborate with QA teams on integration testing. • Partner with the DevOps team on deployment automation, monitoring and other operational tasks. • Work alongside PLM and documentation teams to create product documents and software specifications. • Provide domain-specific technical expertise to engineering and support teams, including troubleshooting customer issues. • Assist in the hiring process by participating in candidate sourcing and interviews. Requirements: • Bachelor's degree in Computer Science, Electrical Engineering or related field • 5+ years of experience in software engineering, including 3+ years building production web applications across frontend and backend • Strong proficiency in React.js and JavaScript/TypeScript, and in at least one backend language (Node.js or Golang) • Experience designing and securing REST APIs, including authentication and authorization (OAuth 2.0/OIDC, JWT) • Experience with MongoDB or another database, including data modeling and query performance • Strong Linux knowledge and the ability to troubleshoot and debug issues in complex, large software systems, from the browser through the API to the database • Proven track record in large-scale software development, rigorous testing, CI/CD and automation practices • Excellent problem-solving and analytical skills • Excellent communication skills and teamwork spirit Nice to Have: • Experience building enterprise B2B SaaS consoles: multi-tenant data, role-based access control, audit logging and data-heavy dashboards • Background in network security, data security or identity products • Experience building product features on LLM APIs or AI agent frameworks • Experience with Kubernetes, Helm or infrastructure as code (Pulumi, Terraform) • Data visualization experience (charting libraries, large data tables)
