About The Role The role is based in the Pune R&D Center at the SAS R&D Pune facility. We are looking for a Software Developer to join the Visual Machine Learning (VML) and Visual Text Analytics (VTA) product development team in the Analytics area. In this role, you will help design, develop, test, maintain, and support enterprise-scale analytical products with a focus on quality, scalability, maintainability, and timely delivery. You will work with modern technologies and engineering practices such as React, Java /Type , Golang, REST APIs, automated testing, CI/CD, Docker, Kubernetes, and cloud-native deployment models. You will collaborate closely with local and global engineering teams, product owners, UX, architects, and test engineers to deliver features that integrate well with the SAS Viya platform and meet customer expectations. Primary Responsibilities • Design, develop, test, and maintain high-quality product features for complex analytical applications, with focus on scalable UI, API, and service interactions. • Collaborate with product owners, UX, architects, test engineers, and local/global development teams to understand requirements and deliver solutions that meet customer and platform needs. • Translate use cases and design inputs into clear technical designs, implementation plans, and maintainable code. • Develop reusable, secure, accessible, and performant UI components and application workflows using modern front-end development practices. • Build and integrate REST APIs and related service interactions needed to support product functionality and end-to-end user workflows. • Write and maintain unit tests, integration tests, and supporting automation to improve product quality and reduce regression risk. • Participate actively in design reviews, code reviews, debugging sessions, and technical discussions to maintain high engineering standards. • Contribute to CI/CD and cloud-based development workflows, including build, deployment, troubleshooting, and environment readiness activities. • Track assigned work, communicate progress, dependencies, risks, and blockers in a timely and transparent manner. • Resolve product defects and customer-impacting issues by analyzing root causes and implementing reliable, maintainable fixes. • Mentor and guide junior team members through code reviews, design discussions, technical practices, and day-to-day engineering support. • Continuously learn and evaluate relevant technologies, frameworks, tools, and implementation approaches that can improve product quality, developer productivity, and delivery outcomes. Requirement • 5 to 8 years of hands-on experience in designing, developing, and supporting multi-tier software applications, with a strong understanding of the full software development lifecycle. • Strong programming skills in at least one modern programming language such as Golang, Java, Python, Java , or Type , with the ability to quickly work across related technologies as needed. • Hands-on experience developing modern web applications using React, Java /Type , Redux, React hooks, and related UI ecosystem practices. • Experience designing and developing scalable UI components, REST APIs, and interactions across multiple software components or services. • Good understanding of clean code principles, object-oriented design, modular design, data structures, and common design patterns. • Experience with unit, integration, and API/UI testing, including writing testable code and using automated test frameworks as part of day-to-day development. • Working knowledge of Git and GitHub based development workflows, including branching, pull requests, code reviews, and collaborative development practices. • Familiarity with Agile software development practices and tools such as Jira and Confluence. • Strong analytical and problem-solving skills, with the ability to debug complex issues across the UI, API, and service layers. • Good written and verbal communication skills, with the ability to explain technical topics clearly to local and global stakeholders. Good to have • Exposure to cloud-native development practices and deployment models in public cloud environments such as Microsoft Azure, Amazon Web Services, or Google Cloud Platform. • Working knowledge of Docker, Kubernetes, containerized applications, cluster concepts, and troubleshooting in distributed environments. • Experience with CI/CD pipelines, build automation, deployment automation, and quality gates used in modern software delivery. • Exposure to microservices, distributed systems, service-to-service communication, observability, logging, and monitoring practices. • Experience working with analytical, machine learning, text analytics, data management, or enterprise-scale software products. • Awareness of accessibility, internationalization, performance, security, and usability considerations for enterprise web applications. • Experience contributing to technical design documents, developer documentation, or knowledge sharing within an engineering team.
