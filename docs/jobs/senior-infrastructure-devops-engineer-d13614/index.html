Who You Are • Seniority: At least 5 years of dedicated experience in DevOps, infrastructure, or SRE roles. • Expert tooling: Expertise with Docker, Kubernetes, and Terraform or Pulumi. • Cloud proficiency: Deep, proven expertise in AWS, GCP, or Azure, with the ability to apply core infrastructure concepts across cloud providers. • AI-native engineer: AI coding agents such as Claude Code, Codex, Cursor, or Copilot are a core part of how you work, not an experiment. You can point to infrastructure or tooling you shipped faster because of them, and you know where they need a human in the loop—or should not be used at all—including IAM policies, billing, state migrations, and changes affecting production. • Development skills: Strong ability to write clean, maintainable automation code in Go, Python, or Node.js. • Security focus: Demonstrable experience implementing and maintaining modern cloud security controls and meeting relevant compliance standards, such as SOC 2, PIPEDA, HIPAA, GDPR, or PCI. • Independent, proactive, and cross-functional: Proven ability to onboard quickly, diagnose problems, and propose and implement solutions with minimal oversight. Experience in a consulting or freelance capacity, with a track record of communicating effectively with technical and non-technical stakeholders. What You’ll Do • Infrastructure as Code: Implement and adapt infrastructure using Terraform, Pulumi, or other major IaC tools. • AI-accelerated delivery: Use agentic tools to write and review IaC, generate runbooks, triage incidents, and automate toil, with guardrails such as plan review, policy-as-code, and scoped credentials for agents. • Containers: Design, build, and optimize secure, multi-stage Dockerfiles. Deep Docker knowledge is critical. • CI/CD: Design, build, and manage robust pipelines that automate testing, building, and deployment across environments. • Core cloud services: Provision and manage foundational services in AWS, GCP, or Azure. Deep expertise in one major provider is required, along with the ability to transfer that knowledge to others. • Container compute: Run production workloads on container platforms such as Cloud Run, ECS, Fargate, EKS, GKE, or AKS. Exercise judgment in choosing the right platform based on cost, scale, and operational overhead. • Networking: Design secure networks using VPCs, subnetting, routing, NAT, peering, VPNs, and load balancers, with a clear sense of when each is needed. Kubernetes networking experience—including ingress controllers, egress gateways, network policies, and service meshes such as Istio or Linkerd—is a strong plus. • Managed services: Work with object storage, managed databases, serverless functions, CDNs, and message queues, using services such as S3, Cloud Storage, RDS, Cloud SQL, Lambda, and Cloud Functions. • LLM application infrastructure: Deploy and operate LLM-backed services on Bedrock, Vertex AI, or direct provider APIs such as Anthropic and OpenAI. Manage secrets and API keys, rate limits, quotas, token-spend controls, and observability for latency and failures. • Agent infrastructure: Host and secure MCP servers and sandboxed execution environments for AI agents. • Security: Protect PII through encryption, secrets management, network firewalls, and web application firewalls such as AWS WAF or GCP Cloud Armor. Address AI-specific risks, including prompt injection and controlling sensitive data sent to third-party model providers. • Automation and scripting: Write high-quality automation and tooling in Go, Python, Node.js, or Bash to solve client-specific operational challenges. • Monitoring and operations: Ensure robust monitoring using native cloud-provider tooling and maintain high system uptime. Nice to Have • Model serving and compute: Experience with self-hosted inference using tools such as vLLM or KServe, GPU/TPU provisioning—including GKE accelerator configuration—and vector databases such as pgvector or Pinecone. Familiarity with enabling extensions through tools such as StackGres is a plus. • LLM observability: Experience with Langfuse, LangSmith, Datadog LLM Observability, or similar tools. • Multi-cloud experience: Hands-on experience across multiple cloud providers and products, such as AWS, GCP, Azure, or Cloudflare. • Certifications: AWS, GCP, or Claude Certified Architect certifications are a plus, but not mandatory. • Advanced monitoring: Experience with Prometheus, Datadog, or similar monitoring and logging stacks. • GitOps: Experience with Argo CD or Flux. • Service mesh: Experience with a service mesh or ingress gateway.
