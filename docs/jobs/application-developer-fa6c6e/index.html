We are looking for an experienced Software Developer with strong hands-on experience in either Java or Golang (Go) and a good understanding of microservices architecture, containerization, and cloud-native technologies. The ideal candidate should have experience developing scalable backend applications and deploying them using Docker, Kubernetes, and modern CI/CD practices. Key Responsibilities • Design, develop, test, and maintain scalable backend applications using Java or Golang. • Develop and maintain RESTful APIs and microservices-based applications. • Build, package, and deploy applications using Docker and Kubernetes. • Work with cloud platforms and container orchestration technologies to support application deployment and scalability. • Collaborate with cross-functional teams to understand requirements and deliver high-quality software solutions. • Implement unit testing, debugging, performance optimization, and code quality practices. • Participate in code reviews, technical discussions, and architectural decisions. • Work with CI/CD pipelines, version control systems, and automated deployment processes. • Troubleshoot application, deployment, and production issues. Required Technical Skills • Programming: Strong hands-on experience in either Java or Golang (Go). • Backend Development: Experience building REST APIs and microservices. • Containerization: Hands-on experience with Docker. • Orchestration: Experience deploying and managing applications using Kubernetes. • Cloud & DevOps: Familiarity with cloud platforms such as AWS, Azure, or GCP, and CI/CD pipelines. • Version Control: Proficiency in Git. • Databases: Experience with SQL or NoSQL databases. • Software Engineering: Knowledge of data structures, algorithms, design patterns, debugging, and unit testing. Good to Have • Experience with Spring Boot and related Java frameworks, or Go frameworks and libraries. • Familiarity with Helm, Terraform, and Kubernetes deployment configurations. • Experience with Jenkins, GitHub Actions, GitLab CI/CD, or Azure DevOps. • Knowledge of messaging systems such as Kafka or RabbitMQ. • Familiarity with Linux, observability, logging, and monitoring tools. • Exposure to cloud-native architecture and distributed systems.
