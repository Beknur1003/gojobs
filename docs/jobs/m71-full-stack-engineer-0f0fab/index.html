M71 - Full Stack Engineer

FPT Asia Pacific Pte Ltd Singapore опубликовано 30 октября 2026

Полная занятость
KubernetesDockerTerraformAWSCI/CDKotlinTypeScript
Role Overview We are seeking experienced Full Stack Engineers to support the modernisation of a large-scale digital platform. The role involves migrating legacy applications to a modern, cloud-native, containerised architecture on AWS. Successful candidates will be responsible for end-to-end application development, covering frontend and backend engineering, cloud infrastructure, security integration, deployment, and production support. Key Responsibilities Full Stack Development • Develop, enhance, and modernise applications using cloud-native technologies. • Build responsive, accessible web applications using ReactJS, TypeScript, and Next.js. • Design and develop scalable backend services and APIs using Golang and/or Kotlin. • Implement business workflows using workflow engines such as Temporal. • Write clean, maintainable, well-tested, and documented code. • Participate in code reviews and follow software engineering best practices. Cloud Infrastructure & DevOps • Design, configure, and maintain AWS cloud infrastructure using Infrastructure as Code (IaC) tools such as Terraform. • Build and maintain CI/CD pipelines using GitLab. • Deploy and manage containerised applications using Docker and Kubernetes (EKS). • Implement application monitoring and observability using tools such as Dynatrace or Datadog. • Support production deployments, troubleshoot technical issues, and participate in incident resolution. Security & Integration • Implement authentication and authorisation mechanisms using OIDC, SAML, RBAC, and ABAC. • Integrate applications with identity management solutions such as Singpass and Corppass. • Apply cloud security, infrastructure security, and container security best practices. Additional Responsibilities – Senior Consultant • Define technical architecture and target-state solutions for platform modernisation. • Lead technical delivery across multiple workstreams. • Collaborate with product owners, DevSecOps teams, and key stakeholders. • Develop migration strategies, including implementation planning, risk management, and production cutover. • Establish engineering standards and provide technical guidance. • Mentor junior engineers and drive technical decision-making. Requirements Experience • Consultant: 3–5 years of hands-on full stack software development experience. • Senior Consultant: Minimum 7 years of relevant experience, including 2–3 years in technical leadership, solution architecture, or delivery management. • Experience in legacy application modernisation or cloud migration is strongly preferred. • Experience delivering large-scale enterprise or public sector projects is an advantage. Technical Requirements – Must Have • Frontend: ReactJS, TypeScript • Backend: Golang and/or Kotlin • Cloud: AWS architecture and services • DevOps: CI/CD, Docker, Kubernetes • Infrastructure as Code: Terraform or equivalent • Observability: Hands-on experience with application monitoring or observability tools Technical Requirements – Good to Have • Experience with Next.js. • Hands-on experience with AWS services such as S3, EKS, ECS, EC2, Lambda, RDS, Load Balancers, and API Gateway. • Experience with workflow engines such as Temporal. • Knowledge of rules engines such as GoRules or Open Policy Agent. • Familiarity with Dynatrace or Datadog. • Experience implementing authentication protocols such as OIDC and SAML. • Knowledge of authorisation frameworks such as RBAC and ABAC. • Familiarity with identity and security solutions such as Singpass, Corppass, ADFS, WOG AD, CAM, and Trend Micro FAM. • Understanding of cloud infrastructure and container security practices. • Exposure to OutSystems, Oracle Policy Automation, Oracle Intelligent Advisor, Sitefinity, or Oracle technologies. Soft Skills • Strong analytical, troubleshooting, and problem-solving abilities. • Excellent communication and interpersonal skills. • Ability to collaborate effectively with technical and non-technical stakeholders. • Strong ownership, accountability, and ability to work in a fast-paced environment. • Senior Consultant: Demonstrated technical leadership, stakeholder management, mentoring, and decision-making capabilities.
