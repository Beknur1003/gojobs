Platform Engineer

Nearshore Portugal опубликовано 17 ноября 2026

PostgreSQLMySQLNATSgRPCKubernetesTerraformAWSPrometheusGrafanaOpenTelemetryMicroservicesLinuxCI/CDJava
Description We are looking for a Platform Engineer to join a central Platform Engineering team that supports multiple product and development teams. You will design and build scalable backend services in Go, work with Java services, and run distributed applications on Kubernetes. The role combines software development with hands-on work on event-driven systems and data processing. Requirements • Several years of professional experience as a Platform Engineer, Backend Engineer, Software Engineer, or in a similar role. • Strong hands-on experience designing and building scalable backend services in Go (Golang). • Solid experience with Java in enterprise or cloud-native environments. • Experience designing and operating distributed systems and microservices. • Strong knowledge of messaging and event-driven architectures using NATS and/or MQTT, with experience in event streaming and data processing. • Hands-on experience deploying, operating, and troubleshooting applications on Kubernetes in production. • Experience with InfluxDB and time-series data management. • Practical experience with graph databases, preferably ArangoDB, including data modelling, query design, and performance optimisation. • Strong knowledge of relational databases such as PostgreSQL or MySQL, including schema design and query optimisation. • Experience designing and implementing REST and/or gRPC APIs. • Solid Linux administration and troubleshooting skills. • Experience with Git workflows, CI/CD pipelines, and automated testing. • Ability to collaborate with and support multiple product and development teams. Responsibilities • Design, develop, and maintain backend services in Go and contribute to Java services. • Build and maintain APIs and event-driven integrations using NATS and/or MQTT. • Design and improve event streaming and data processing workflows. • Deploy, operate, and troubleshoot applications on Kubernetes in production. • Model data and optimise queries across time-series, graph, and relational databases. • Maintain automated tests and contribute to CI/CD workflows for reliable releases. • Work with product and development teams to resolve platform issues and improve shared services. Nice to have • Experience with cloud platforms, preferably AWS. • Knowledge of Infrastructure as Code using Terraform. • Experience with observability tools such as Grafana, Prometheus, and OpenTelemetry. • Experience building internal developer platforms or self-service tools for development teams.
