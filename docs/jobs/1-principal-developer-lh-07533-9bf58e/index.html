Duration: Initial 12 month contract Location: Sydney, Melbourne or Brisbane Work Arrangements: Flexible WFH Citizenship: Australian citizens only Company Overview BLACKROC is partnering with a major federal government agency to recruit a Lead Developer. The team is splitting an existing product in two, which means new API and platform work and the chance to shape how it’s built from the ground up. Role Purpose This is a hands-on lead role for a genuinely strong Go engineer. You’ll lead the design and build of the consumer API platform behind their websites, portals and mobile apps, connecting them to Salesforce and MuleSoft. You’ll set the engineering standards and mentor the backend team, but you’ll also be writing code every day. The team runs like a product team: people own their work, take pride in it and get things done. If you’ve thrived in a startup, scale-up or small product team, you’ll feel at home here. Key Responsibilities • Lead the design and build of new API and platform services as the product is split in two • Write high-quality Go every day and set the bar for the rest of the team • Define architecture, API standards and engineering practices for Golang and GraphQL services • Mentor backend developers through code review, pairing and hands-on example • Work closely with Salesforce, MuleSoft, frontend and platform teams to deliver end-to-end • Use AI-assisted tools to speed up delivery, while keeping strong engineering judgement over what ships • Own the reliability, security and observability of services across AWS, Kubernetes and Cloudflare Required Skills & Experience • Strong, hands-on Golang. This is essential • Solid cloud experience, ideally AWS, with Kubernetes and Amazon EKS in production • GraphQL and API design, including authentication, authorisation and service-to-service patterns • A track record of leading engineers and setting up code review, automated testing and CI/CD • Practical use of AI coding tools to complement your engineering, not replace it. You can build it yourself and you know when the AI is wrong • An ownership mindset: you care about what you ship and see it through, rather than closing tickets and moving on Preferred Skills & Qualifications • Startup, scale-up or small product company experience • Consumer-facing API platforms serving web, portal and mobile channels • Cloudflare, including Zero Trust, Access, Tunnels and edge security • Integrations involving Salesforce, MuleSoft or similar enterprise platforms We care about what you can do, not how many years you’ve been doing it.
