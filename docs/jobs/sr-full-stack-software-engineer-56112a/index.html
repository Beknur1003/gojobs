Required Skills: Python, React, JavaScript, Java, Node.js, Rust, Golang, TypeScript We are looking for highly skilled Full-Stack Software Engineers to contribute to an AI training project involving software development, technical problem-solving, debugging, system architecture, and code evaluation. We are seeking an experienced Senior Full-Stack Software Engineer with strong hands-on expertise across both front-end and back-end development. The role involves creating, solving, reviewing, and validating complex software-engineering tasks across the application stack, as well as translating complete software implementations from one programming language to another. The ideal candidate should have substantial experience building and maintaining production-grade applications, working across multiple programming languages, and understanding end-to-end system architecture. You should be comfortable navigating unfamiliar codebases, debugging complex issues, evaluating technical solutions, and ensuring code quality, performance, security, and maintainability. Requirements Key Responsibilities • Full-Stack Development: Develop, enhance, and debug front-end and back-end components across production applications. • Feature Implementation: Build user-facing features and the supporting services, APIs, database structures, and data models. • End-to-End Troubleshooting: Trace requests and data flows across browsers, front-end applications, APIs, back-end services, databases, and third-party integrations. • Codebase Analysis: Navigate unfamiliar repositories, understand existing application architecture, and identify dependencies and implementation patterns. • Complex Debugging: Diagnose and resolve issues involving application state, API contracts, authentication, data persistence, network communication, and deployment. • Cross-Language Development: Evaluate, modify, translate, and improve software implementations across multiple programming languages while preserving functionality and correctness. • Code Review and Validation: Assess AI-generated and developer-written code for correctness, completeness, efficiency, security, scalability, and maintainability. • Technical Problem-Solving: Design reliable solutions to challenging engineering problems and validate implementations against defined requirements and specifications. Required Qualifications • Significant professional experience developing and maintaining production-grade full-stack applications. • Strong hands-on expertise in both front-end and back-end software engineering. • Professional experience working with multiple programming languages and adapting to different technology stacks. • Solid understanding of browser-based applications, APIs, application state management, databases, and service integrations. • Experience designing, understanding, and contributing to the architecture of complete software systems. • Ability to navigate unfamiliar codebases and quickly understand existing implementations. • Strong debugging, analytical thinking, and problem-solving capabilities. • Experience reviewing code and evaluating solutions for performance, reliability, security, and maintainability. • Ability to work independently, manage complex technical tasks, and deliver high-quality results.
