AI 應用開發實習生 AI Application Developer Intern

類神經網路股份有限公司 Songshan District, Taipei City, Taiwan опубликовано 20 октября 2026

Стажёр Частичная

在 Aiii.AI，這個角色會參與實際的 AI 應用專案，從資料處理、Data Pipeline 到 RAG、Chatbot 等不同面向，將原始資料轉換成產品與 AI 可以真正使用的能力。 你會接觸到的資料來源相當多元，包含關聯式資料庫、NoSQL、GCP BigQuery，以及客戶提供的 Google Sheets、FTP 檔案等外部資料。你會參與資料的整合、清洗與加工，並逐步將這些流程建立成自動化、可追蹤的數據服務。 除了資料工程，你也會實際參與 RAG 與 AI 應用開發，例如資料爬取、資料蒸餾、Embedding、檢索，以及 Chatbot 等應用。依專案與合作需求，也有機會接觸 LLM Fine-tuning，實際參與模型訓練與效能評估。 這不是只做單一功能的實習，而是會從實際產品與專案中，理解「資料如何被處理、如何被 AI 使用，以及最後如何變成產品功能」。 【Your Responsibilities】 ➤ Data Pipeline & Data Integration（主要工作） • 參與多種資料來源的整合，包含關聯式資料庫、NoSQL、GCP BigQuery，以及 Google Sheets、FTP 檔案等外部資料 • 協助進行資料擷取、清洗、轉換與加工，產出可供產品與 AI 使用的數據 • 參與 Data Pipeline 建置，將資料處理流程逐步自動化 • 協助建立具備可追蹤性與可維護性的數據服務 • 支援報表、分析及 AI 應用所需的資料處理工作 ➤ RAG & AI Application Development • 參與 RAG（Retrieval-Augmented Generation）應用開發 • 協助進行資料爬取、清洗、蒸餾、Chunking、Embedding 與向量化 • 實作與調整資料檢索策略，觀察不同 Retrieval 方法對 AI 回覆品質的影響 • 參與 Chatbot 開發，支援一般問答、預約、資料查詢、分析等應用情境 • 探索不同 LLM 與 AI 技術，並將其應用於實際產品需求 ➤ LLM Fine-tuning（專案型工作） • 依實際專案與合作需求，參與小型語言模型 Fine-tuning • 協助進行訓練資料準備、模型訓練與效能評估 • 實際探索小型模型在特定任務上的表現與應用可能性 • 有機會運用與外部單位合作所取得的算力資源，參與模型相關實驗 ➤ CRM Data & AI Application • 參與 LINE、Meta 等多渠道資料的整合 • 協助整理與分析客戶互動資料 • 運用 AI 對資料進行加值，協助建立客戶輪廓與特徵 • 參與將資料與 AI 能力轉換為 CRM 產品功能 【We Are Looking For】 • 熟悉 Python、JavaScript / TypeScript 或 Golang 至少一項 • 具備基本資料庫操作經驗，接觸過關聯式資料庫或 NoSQL • 具備 RESTful API 串接或基本系統整合經驗 • 對資料處理、AI 應用或軟體開發有興趣 • 能閱讀並理解既有程式碼，並撰寫清晰、簡潔且具可維護性的程式 • 具備基本的問題拆解與自主學習能力 • 願意從實際專案中學習，而不是只停留在技術練習或教學範例 ➤ 請檢附作品集 作品形式不限，可接受： -學校專題 -個人 Side Project -Hackathon 作品 -接案或實務專案 請提供以下其中一種： -GitHub Repo（建議包含 README） -已部署網站 -Demo 影片 【Preferred Qualifications】 • 有 Data Pipeline、ETL / ELT 或資料處理相關經驗 • 具備 SQL 使用經驗 • 有 RAG、Embedding、Vector Database 或 Retrieval System 實作經驗 • 有 Chatbot、LLM 或 Generative AI 應用開發經驗 • 有 GCP、Azure、AWS 等雲端平台使用經驗 • 有 ML Model Training 或 LLM Fine-tuning 經驗 • 有 LINE、Meta 等多渠道資料整合經驗 • 有 GitHub、Side Project、課堂專題或其他能展現實作能力的作品 【What You'll Gain】 • 實際參與 Data Pipeline，從資料來源、清洗、加工到服務化的完整流程 • 接觸多種資料來源與資料架構，累積實際資料工程經驗 • 參與 RAG 從資料處理、Embedding、Retrieval 到生成回覆的完整流程 • 實際參與 Chatbot 與 AI Application 開發，將 AI 技術應用於產品 • 接觸 Cloud Native 與雲端資料服務 • 有機會參與 LLM Fine-tuning 與模型訓練相關專案 • 從實際 CRM 與 AI 專案中，理解資料如何轉換成產品價值 • 累積 Data Engineering × AI Application 的實戰經驗
