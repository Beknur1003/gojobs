Join our Team About this opportunity: Ericsson 5G core business is launching an innovative and highly dynamic unit that will change how we bring 5G solutions to the market, thus changing the way 5G core is delivered globally. We aim to build and deliver Cloud Native solutions “as a Service” on Hyper Cloud Providers (HCP). You will have the opportunity to spearhead how the public cloud connects with core telco services and help build more elastic and fit-for-purpose capabilities, while venturing new business models. This will fundamentally change how we bring 5G services to the industry, making it more accessible, more versatile, and create new opportunities for innovation. We will bring the standard methodologies of the SaaS industry in the public cloud to the realization of 5G services. We are looking for individuals who want to lead change in the industry, apply the latest technologies to a domain that society relies on day in and day out. What you will do: • Design, develop and support cloud native applications and microservices as part of an agile team, ensuring our service offerings are robust, scalable and user-friendly. • Work in a full-stack capacity – developing your service code as well as associated automated tests and deployment scripts. • Ensure the security, scalability, and reliability of our applications and services. • Apply containerization and orchestration technologies such as Docker and Kubernetes to deploy and run applications in a cloud environment. • Work with our Cloud Native based continuous integration and continuous deployment (CI/CD) pipelines to automate the software delivery process. • Ensure the reliability, availability, and performance of cloud-based applications by implementing monitoring, logging, and alerting solutions. • Stay up-to-date with emerging trends and technologies in cloud computing and contribute to the company's technical expertise. • Work in a team using Lean, Agile and DevOps methodologies and tooling. The skills you bring: • Bachelor’s or master’s degree in information technology, Computer Science, or a related quantitative field or equivalent experience • Good knowledge in 3GPP Core requirements and how to translate into System level Test • Good understanding of Packet Core Controller and Packet Core Gateway design • Very good knowledge of Core Test Tools (especially Dallas) systematization and implementation • Good programming skills in Golang, Python, Java, and IaC experience (ex: Terraform) • Experience with test automation, system/function level testing, testcase development, designing test strategy etc. • Experience in Test result analysis and TestOps is a plus. • Familiarity with cloud platforms such as AWS, Azure, or Google Cloud Platform. • Hands-on experience with containerization technologies, especially Docker, and container orchestration tools like Kubernetes. • Strong understanding of microservices architecture, RESTful /gRPC APIs, and cloud-based databases. • Experience with CI/CD tools like GitHub and GitHub Workflow. • Thrive working in a collaborative, generative team culture supporting our teammates and our customers. • Creativity and curiosity – a continuous learner with excellent problem-solving skills. • Experience using agentic tools or AI-based coding assistants (e.g., GitHub Copilot, Claude Code, Cursor) to accelerate test development, test automation, and test result analysis Sponsorship Information: Applicants must be legally authorized to work in Canada by their employment start date.
