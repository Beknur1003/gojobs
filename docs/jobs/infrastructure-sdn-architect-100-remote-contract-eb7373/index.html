Key Responsibilities • Lead OVN networking enhancements focused on performance optimization and zero-data-plane-downtime upgrades. • Improve network scalability, error reporting, and troubleshooting capabilities. • Work on OpenStack Neutron networking, including Quality of Service (QoS). • Implement and support VyOS BGP routing and advanced networking capabilities. • Provide advanced networking support using VyOS, including: • Firewall-as-a-Service (FWaaS) • VPN-as-a-Service (VPNaaS) • Network Address Translation (NAT) • Layer 4–Layer 7 Load Balancing • Support NSX-T-style advanced networking functionality. • Work on kernel-level distributed firewall architecture and implementation. • Troubleshoot complex data-plane, routing, connectivity, and network performance issues.
