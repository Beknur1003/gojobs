Job description About the Role We are looking for an experienced Senior Software Engineer to design, develop, and maintain the management plane and orchestration services for large-scale, highly available distributed systems. The role involves building reliable control-plane microservices, automated deployment workflows, and cluster lifecycle management using Go, Python, Ansible, and Kubernetes. You will solve complex engineering challenges around automated provisioning, non-disruptive upgrades, high availability, configuration management, and observability, collaborating closely with cross-functional engineering teams. Key Responsibilities • Design, develop, and maintain control plane microservices, REST APIs, and daemons for distributed cluster orchestration • Build and maintain automated cluster lifecycle workflows (bootstrap, node discovery, scaling, and non-disruptive upgrades) using Ansible and Python • Design and manage containerized services, operators, and deployments on Kubernetes • Implement transactional data persistence and configuration management using relational databases (PostgreSQL) • Develop host-level configuration tools and agents for Linux networking, system services, and storage discovery • Integrate monitoring, logging, and diagnostics frameworks (Prometheus, Grafana, OpenTelemetry) • Participate in architectural discussions, code reviews, and technical design reviews • Collaborate using Agile tools such as Jira, GitHub, and CI/CD pipelines • Leverage AI-based developer tools to improve productivity, code quality, and automation Required Skills & Experience • 6+ years of software engineering experience in distributed systems, cloud infrastructure, or control plane development • Strong programming proficiency in Go and/or Python • Hands-on experience with Ansible for infrastructure automation, configuration management, and orchestration • Solid working knowledge of Kubernetes architecture, container runtimes, controllers, and Helm • Strong understanding of Linux operating systems, systemd, networking fundamentals (TCP/IP, routing, virtual interfaces), and shell scripting • Experience designing and consuming secure, versioned RESTful APIs • Practical experience working with relational databases such as PostgreSQL Nice to Have • Experience with identity and access management (OAuth2, OIDC, Keycloak, RBAC) • Knowledge of storage systems, block/file storage concepts, or storage networking • Experience of Linux performance tuning.
