Software Engineer - Oracle Integration

Mayo Clinic Rochester, MN, United States опубликовано 20 августа 2026

ГибридОфис Полная занятость

This is a hybrid position and must be located within 100 miles of a Mayo Clinic campus for occasional on-site expectations based on business needs. The Administrative Integration Services Unit is seeking a Software Engineer to develop and support Human Capital Management (HCM) integrations for Mayo Clinic’s Oracle Enterprise Resource Planning (ERP) System. This role will focus primarily on Oracle Integration Cloud (OIC) and Fast Formula development supporting Core HR, Benefits, Talent Acquisition, and Payroll. The Software Engineer will design, develop, implement, and support secure, reliable, and scalable integrations between Oracle HCM Cloud and internal applications, external vendors, APIs, databases, and other enterprise platforms. Responsibilities include developing OIC integrations, orchestrations, mappings, transformations, connections, and error-handling processes, as well as Oracle HCM Fast Formulas and related integration components. Works closely with Product Managers, Architects, functional teams, vendors, and business stakeholders to translate requirements into effective technical solutions. Develops and supports integrations using technologies such as REST and SOAP APIs, HCM Extracts, HDL/HSDL, SFTP, JSON, XML, and other Oracle HCM integration capabilities. Participates in the full software development lifecycle, including requirements analysis, design, development, testing, deployment, monitoring, troubleshooting, and production support. Applies integration standards and DevOps practices to create solutions that are secure, reusable, maintainable, and resilient. Supports CI/CD and deployment automation using tools such as Azure DevOps (ADO) and Azure Pipelines. Performs troubleshooting and root cause analysis of integration and application issues using OIC monitoring, logs, payloads, and other diagnostic tools. Ensures appropriate technical documentation is created and maintained and that solutions comply with organizational security, privacy, and data protection requirements. Communicates effectively with technical and business partners across the organization and continues to build knowledge of Oracle HCM, OIC, enterprise integration patterns, organizational processes, and customers. Participation in a 24/7 on-call rotation is required. Bachelor's degree in computer science/engineering or related field; or an associate’s degree in computer science/engineering or related field with an additional 2 years of experience as described below. Have working knowledge and experience of Software Engineering with a minimum of internships and a minimum of 1 yr. of experience, or 2yrs of experience coding applications or services in a high-level language (C, C++, Golang, Java, C# etc.). Demonstrated problem solving and time management skills. Possesses strong technical aptitude for designing and implementing software solutions. Experience with modern application development frameworks. Knowledge of professional software engineering practices & best practices for the full software development life cycle, including coding standards, code reviews, source control management, build processes, testing, and operations. Deep hands-on technical expertise, excellent verbal and written communication skills. Experience with Agile software development techniques. Preferred qualifications for this position include: Ability to use a wide variety of open-source technologies and cloud-based services. Experience with Google and Azure cloud environments Experience in databases, analytics, big data systems or business intelligence products Experience with building high-performance, highly available and scalable distributed systems. Experience developing software for healthcare related industries. Position requires a high level of analytical skill, ability to manage varied workload on projects, proactiveness, and excellent verbal and written communication skills. Willing and capable of adapting to shifting requirements. Experience writing and supporting complex database queries is highly valued. This position will be expected to develop and support integration code using the following technologies: • Oracle Fusion Cloud Platforms - Required • Oracle Integration Cloud (OIC) - Required • Oracle Fusion HCM Fast Formulas – Preferred • Oracle HCM Data Loader (HDL) • Oracle HCM Extracts • Oracle Business Intelligence Publisher (BIP) • Oracle File-Based Data Import (FBDI) • Oracle Web Services (SOAP/REST) • Oracle SQL – PL/SQL Additional nice to have skills: • Oracle Application Integration Professional Certification • Oracle Cloud Certification • Agile Methodologies • ServiceNow • Splunk • Cleo Harmony (MFT) • Google Apigee Authorization to work and remain in the United States, without necessity for Mayo Clinic sponsorships now, or in the future (for example, be a U.S. Citizen, national, or permanent resident, refugee, or asylee). Mayo Clinic does not participate in the F-1 STEM OPT extension program.
