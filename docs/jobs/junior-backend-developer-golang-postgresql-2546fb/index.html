Job Summary We are looking for a Junior Backend Developer with knowledge of Go (Golang) and PostgreSQL to join our engineering team in Kolkata. The ideal candidate should have a strong foundation in programming, database management, REST API development, and problem-solving. As a Junior Backend Developer, you will work closely with experienced engineers to develop, test, debug, and maintain backend services. This role is ideal for freshers and early-career developers who are eager to learn, contribute to real-world projects, and grow their software engineering skills. Key Responsibilities Develop, maintain, and enhance backend services and RESTful APIs using Go (Golang). Write efficient SQL queries and manage data using PostgreSQL.Design and maintain database tables, relationships, indexes, and constraints. Implement business logic, input validation, error handling, and logging. Write clean, readable, reusable, and maintainable code. Debug technical issues and assist in identifying and resolving software bugs. Write unit tests and support integration and API testing. Collaborate with frontend developers and other team members to deliver features. Use Git for version control and participate in code reviews. Follow backend development best practices related to security, performance, reliability, and scalability. Continuously learn new technologies and contribute to improving existing systems. Required Skills & Qualifications Basic knowledge of Go (Golang), including syntax, data types, functions, structs, interfaces, and error handling. Understanding of PostgreSQL and relational database concepts. Ability to write SQL queries involving filtering, JOINs, GROUP BY, and subqueries. Basic understanding of REST APIs, HTTP methods, JSON, and HTTP status codes. Knowledge of programming fundamentals, data structures, and algorithms. Familiarity with Git and version control. Good logical thinking, problem-solving, and debugging skills. Strong willingness to learn, accept feedback, and work collaboratively. Ability to work from our Kolkata office. Good to Have Familiarity with Go modules and the Go standard library. Basic understanding of goroutines, channels, and concurrency. Exposure to Go frameworks or routers such as Gin, Echo, or Chi. Knowledge of database transactions, indexing, and query optimisation. Basic familiarity with Docker, Linux, and testing tools such as Postman. Personal projects, internships, or open-source contributions involving Go or PostgreSQL.
