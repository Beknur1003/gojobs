We’ve built a sustainable, profitable business for over 7 years without chasing vanity metrics. The 0→1 journey is done, and we’re now scaling through the 1→10 phase. As a Google Publishing Partner, we serve 100M+ daily ad impressions and support 5,000+ apps and games worldwide, delivering up to 75% revenue uplift. Trusted by Amazon, Dream11, MPL, Sharechat, Treebo, Mobikwik, and 1000+ publishers across 20+ countries. 📦 The products you’ll own 📊 Pubscale: Monetization, user acquisition, revenue uplift, and business-growth analysis in a single place. 📱 Immersive Ads: Native, non-intrusive ad formats. Smart caching, priority loading, and adaptive refresh deliver better UX and higher monetization without annoying popups. 🎁 Offerwall: A reward-based engagement layer that monetizes non-paying users through personalized, high-conversion tasks, driving eCPMs up to $1000 in Tier 1 geos and up to 3X more revenue in emerging markets. 📈 AdX & GROW: Monetization via Google Ad Manager and premium demand partners, plus an AI-driven UA engine (GROW) with free credits and optimization support. 🎯 What you’ll do • Own product surfaces end to end. Take publisher and internal dashboards (ad unit management, mediation, reporting, monitoring, operational workflows) from a product brief to production. That covers the React screens, the Go APIs, and the data model behind them. • Set the frontend bar. Define how we structure components, manage state and server data, handle loading, empty, and error states, and keep data-heavy pages fast, accessible, and responsive. • Build and evolve our design system. Grow a shared component library (tables, filters, date-range pickers, charts, forms) so teams ship consistent UI faster. • Design the APIs the UI needs. Write and extend Go services, shape response contracts for the client, and make sensible calls on pagination, aggregation, caching, and where computation should live. • Work with the data layer. Model and query PostgreSQL, and MongoDB, and work with analytical stores for reporting. Spot slow queries and N+1 patterns before they reach users. • Make it reliable. Add monitoring, error tracking, and tests where they matter. Debug production issues across the stack and drive fixes to the root cause. • Raise the team’s level. Review code, mentor interns and junior engineers, write clear technical proposals, and explain tradeoffs to product and engineering. 🔎 What we’re looking for • 4–5 years building production web applications, with most of that time in React. • Deep React and TypeScript: hooks, composition, performance profiling, memoization, and when to reach for a state or data-fetching library such as React Query or Redux, and when not to. • Strong HTML and CSS fundamentals: layout, responsive design, accessibility (a11y), and attention to visual detail. • A track record of shipping complex tables, filters, charts, and dashboards over large datasets, with virtualization, pagination, and efficient re-rendering. • Hands-on backend experience in Go (or solid experience in another backend language and a willingness to go deep in Go): REST APIs, concurrency basics, testing. • Comfort with relational databases (PostgreSQL) and MongoDB, including schema design, indexing, and query optimization. • Experience with the delivery basics: Git workflows, CI/CD, code reviews, and production debugging. • Ownership: you scope work, flag risks early, and see features through to adoption. ✨ Bonus points • Built or maintained a design system or component library. • Charting experience (Recharts, ECharts, D3, Highcharts) and data-visualization sense. • ClickHouse or BigQuery for analytics and reporting workloads. • Ad-tech, analytics, or B2B SaaS dashboard experience. • Frontend performance work: bundle splitting, Core Web Vitals, rendering large datasets. • Experience building MCP (Model Context
