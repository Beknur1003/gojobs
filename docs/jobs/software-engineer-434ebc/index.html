The application window is expected to close on: 11/26/2026 MEET THE TEAM Crosswork Infrastructure (CW Infra) is the core platform powering Service Provider (SP) automation software and a variety of applications across Cisco’s ecosystem. Our infrastructure provides critical support for application monitoring and network management, delivering robust services and interfaces such as Kafka, NATS, Kubernetes, databases, clusters, and Docker. By building and maintaining these foundational capabilities, the CW Infra team enables scalable, reliable operations for all applications running on the platform. YOUR IMPACT As a Software Engineer, you will be responsible for designing, developing, and testing applications and features across the full stack. Your work will span service design, frontend and backend development, automated testing, and deployment, ensuring high-quality user experiences and robust, scalable systems. You will: • Design, develop, and maintain front-end components using HTML, CSS/SCSS, JavaScript, and TypeScript frameworks (React or Angular). • Build and support scalable back-end services using Golang, Node.js, Python, or Java. • Administer RHEL/CentOS Linux environments, including RPM packaging and signing, and utilize Python and YAML for build and manifest automation. • Implement Linux security hardening (SELinux, kernel hardening, secure defaults) and manage secrets lifecycles (rotation, TTLs) using HashiCorp Vault . • Manage HashiCorp Vault operations, including namespaces, auth methods, secrets engines, policies, and tokens. • Apply strong knowledge of data structures, algorithms, and software design to deliver maintainable and efficient code. • Participate in the complete development lifecycle, including service design, coding, testing, and automation. • Practice agile development methodologies and commit to test-driven development and high-quality releases. • Collaborate with team members to review code, troubleshoot issues, and optimize solutions. MINIMUM QUALIFICATIONS • Bachelors with 5+ years of related experience, with 3+ years of experience in front-end development with HTML, CSS/SCSS, JavaScript, and TypeScript frameworks (React or Angular). • Experience building and maintaining back-end services using Golang, Node.js, Python, or Java. • Hands-on experience with RHEL/CentOS Linux administration, RPM packaging, and Linux security hardening. • Proficiency in HashiCorp Vault operations, including identity-based auth (OIDC, service identity) and Kubernetes/container deployment. • Experience working with data structures, algorithms, software design, and analytical problem-solving. PREFERRED QUALIFICATIONS • Familiarity with agile methodologies, TDD, and CI/CD or image-build pipelines (e.g., Jenkins). • Strong grasp of web principles, RESTful APIs, websockets, and version control (Git). • Experience with unit and end-to-end testing tools such as JEST, Junit, Playwright, or Selenium. • Experience with UEFI Secure Boot, signed kernel modules, IMA/EVM, FIPS, OpenSSL/SSH crypto libraries, and CVE patch handling. • Familiarity with Cloud platforms (AWS/Azure/GCP), Vault scaling/DR, or alternative secrets tools (Conjur/Delinea).
