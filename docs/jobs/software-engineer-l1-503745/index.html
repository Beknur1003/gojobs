Job Summary Job Title: Software Engineer (L1) Location: Hyderabad Team: Research & Development (R&D) Employment Type: Full-time We are looking for enthusiastic and motivated Software Engineers (L1) to join our R&D team as part of our expanding global engineering organisation. This role is ideal for early-career engineers who are eager to learn, grow, and gain hands-on experience building real-world software systems. As an L1 Software Engineer, you will work on both front-end and back-end components, collaborate with experienced engineers, and contribute to developing scalable, cloud-native solutions on Google Cloud Platform (GCP). You will be supported through mentorship and code reviews while developing your technical skills in an agile, collaborative environment. to improve reliability, security, and performance • Collaborate closely with team members through code reviews, pair programming, and knowledge sharing Requirements Essential • Bachelor's degree in Computer Science, Software Engineering, Electronics, or a related field • Strong interest in software engineering with a passion for learning new technologies and tools • Solid understanding of core an agile or iterative development environment • Willingness to receive feedback and continuously improve technical and professional skills • Ability to work effectively both independently and as part of a team Beneficial • Experience with strongly typed programming languages • Golang, C#, Java, etc • Exposure to Mobile Application Development • React Native, Android, iOS • Familiarity with modern Javascript Frameworks • NodeJS, ReactJS, NextJS, React-Native, etc • Experience with API development • Rest, GraphQL, etc • Awareness of DevOps practices and tooling • Docker, Kubernetes, Terraform,
