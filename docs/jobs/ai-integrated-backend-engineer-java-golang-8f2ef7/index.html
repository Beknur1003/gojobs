Preferred Skills and Experience : - Understanding of AI agent patterns (tool use, function calling, memory, multi-turn conversations, guardrails). - Experience building multi-tenant SaaS platforms or developer platforms. - Familiarity with observability tools (Datadog, logging, tracing). - Experience designing CI/CD pipelines and automated infrastructure workflows. - Comfortable working cross-team with product, security, and other engineering teams.
