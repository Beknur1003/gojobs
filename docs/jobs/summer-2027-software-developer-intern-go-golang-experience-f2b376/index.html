As an intern, you might: • Add new components to the orchestration engine, enabling customers to integrate with additional third-party systems • Add or modify functionality of the API (Application Programming Interface) to integrate the user interface with the back-end • Write tests to confirm functionality and to compare performance with other systems • Experiment with new capabilities in open-source data orchestration engines • Participate in project scoping and tracking using the Agile methodology in a continuous delivery environment Required qualifications • You’re an undergraduate college student enrolled in an accredited program, not graduating before December 2027. • You have experience/coursework in Golang/Go • You’re interested in the future of analytics and embrace technology. • You’re curious, passionate, authentic, and accountable. These are Our SAS Values and influence everything we do.
