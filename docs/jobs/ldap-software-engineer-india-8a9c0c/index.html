About JumpCloud® JumpCloud® is the AI-powered unified IT management platform designed to secure the modern workforce. By consolidating identity, device, and access management, JumpCloud provides intelligent, secure IT that scales from human users to autonomous AI agents. We help organizations around the globe eliminate complexity and turn AI risk into an optimized advantage, ensuring the right people and agents have secure access to the right resources at all times. JumpCloud is Intelligent, Secure IT. About the Role As a Software Engineer II on the Cloud LDAP team, you will build, scale, and operate JumpCloud’s LDAP-as-a-Service: the systems that let customers authenticate and look up users and groups over LDAP against the JumpCloud directory. You will work with a globally distributed engineering team on high-availability LDAP infrastructure—protocol handling, directory sync, replication, and edge serving—primarily on our Go, Python, and/or Node.js backend stacks. This role is LDAP development. You will implement and maintain LDAP protocol behavior, directory data pipelines, and the services in front of our OpenLDAP clusters, and you will use AI-assisted development tools ( Cursor, Gemini, Claude etc) to ship high-quality code faster. What You Will Do: • What You Will Do • LDAP platform development: Design, implement, test, and deploy scalable, secure services that power Cloud LDAP, including protocol proxies, sync workers, and supporting APIs. • Protocol & directory behavior: Own backend work for LDAP operations customers rely on—bind (including MFA-aware bind flows), search, compare, and related directory semantics (DNs, filters, attributes, schemas, ACLs). • Sync, replication, and availability: Contribute to how directory changes flow into LDAP (async create/update/delete), how data is replicated to regional read replicas, and how the service stays available under load and during failover. • Edge & proxy services: Work on the LDAP request path (load balancing, connection limits, TLS/STARTTLS, eventing/observability, password handling, and related edge protections). • AI-driven efficiency: Use AI coding assistants to generate code, write solid automated tests, and speed up debugging—without skipping review or operational rigor. • Cloud infrastructure: Run containerized services with Docker and Kubernetes and operate cloud-native components on AWS (EC2, S3, Lambda, DynamoDB, and related services). • Quality & automation: Add automated tests for new LDAP features and legacy paths, and use CI/CD to keep quality gates in place. • Collaborative engineering: Partner with product and senior engineers across time zones on requirements, feasibility, and thorough code reviews. Participate in on-call for production LDAP alerts. What We’re Looking For: What We’re Looking For • Experience: 3–5 years of professional software development, with a strong emphasis on backend systems, networked services, and APIs. • Core technical stack: Proficiency in Go, C++, Node.js, and/or Python. • LDAP & directory foundations: Solid understanding of LDAP (or a closely related directory protocol). Comfort with bind/search, DNs, filters, schemas, TLS/STARTTLS, and how applications (Linux, NAS, custom clients, Samba, and similar) consume LDAP. OpenLDAP, 389 Directory Server, Active Directory LDAP, or similar experience is a strong plus. • Distributed systems: Practical experience with high-availability services, messaging/queues, replication, or proxy/load-balancer request paths. • Cloud & DevOps basics: Experience deploying on AWS and a working understanding of Kubernetes and/or Infrastructure as Code (e.g. Terraform). • AI tool fluent: Demonstrated use of AI coding assistants to increase velocity, find bugs, and improve code quality. • Education: Bachelor’s degree in Computer Science, Software Engineering, or a related field. Nice to Have • Experience with OpenLDAP overlays, replication (provider/consumer), or LDAP proxy/middleware. • Familiarity with directory sync from an identity source of truth, service meshes, or HAProxy/Consul-style service discovery. • Comfort debugging protocol-level issues with tools such as ldapsearch, packet captures, or server logs.
