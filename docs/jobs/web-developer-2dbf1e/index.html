Web Developer

Role Mission: The Front-End Web Developer will deliver high-quality, responsive web applications while ensuring performance, maintainability, and seamless user experiences across platforms. They will collaborate with design and backend teams to implement scalable front-end solutions and support modern DevOps practices, including containerization with Docker and orchestration using Kubernetes. This role also drives continuous improvement by adopting emerging technologies, strengthening CI/CD workflows, and promoting best practices within the DXP Digital team. Key Responsibilities: • Develop, test, and maintain user-friendly and responsive web applications using Vue.js and related technologies. • Work closely with designers and back-end developers to create seamless, high-quality user experiences. • Implement best practices for performance, accessibility, and maintainability in front-end development. • Collaborate with the team on technical decisions and feature design to ensure alignment with project goals and deadlines. • Write clean, efficient, and well-documented code. • Stay up-to-date with the latest industry trends and technologies, contributing to the continuous improvement of our development processes. • Help set up and maintain deployment pipelines to streamline the development and deployment processes. Required Skills and Qualifications: • At least 3 years of professional experience in front-end development. • Strong expertise in Vue.js, with experience using Vue.js frameworks such as Nuxt.js. • Proficiency in JavaScript (ES6+), HTML5, CSS3, and CSS preprocessors. • Experience with Node.js and server-side JavaScript development. • Strong understanding of web performance optimization, cross-browser compatibility, responsive design, and SEO principles. • Experience in OutSystems is a plus • Familiarity with containerization and orchestration (docker and Kubernetes) • Familiarity with version control systems, such as Git. • Experience with modern build tools like vite and NPM/Yarn. • Experience in setting up and managing deployment pipelines, including CI/CD processes. Preferred Skills: • Experience with RESTful APIs and integrating with back-end services. • Knowledge of UI/UX principles and frameworks. • Basic understanding of backend frameworks such as GoLang or SpringBoot.
