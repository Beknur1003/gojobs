Senior Full-Stack Developer - Cloud & Platform Services (DoD / GovCloud) Location: Arlington, VA (Hybrid) Clearance: Active Clearance or Proven Clearance Capability (U.S. Citizenship required) Role Overview We are seeking an experienced Senior Full-Stack Developer (Individual Contributor) to build, deploy, and scale secure, mission-critical applications across AWS Commercial and GovCloud (IL2-IL5) environments. In this role, you will develop end-to-end features running exclusively in pure Docker and Kubernetes environments, balancing high-throughput backend services with modern, reactive web interfaces. You will operate in a modern, AI-Native "paved road" development environment. Our engineering philosophy emphasizes modular, API-first contracts and container-native workflows that enable tight collaboration between human developers and autonomous AI coding agents. Key Responsibilities • Full-Stack Application Engineering: Design, build, and maintain production-ready applications, combining performant backend microservices with responsive, accessible user interfaces. • Polyglot Service Development: Build robust services adhering strictly to our technology priorities—primary backend development in Go (Golang), modern frontend interfaces in Next.js and Vite/React, with secondary service and automation layers in Python. • Container & Kubernetes Native Execution: Package, deploy, and operate services exclusively within pure Docker containers and Kubernetes clusters (AWS EKS), defining declarative manifests, Helm charts, and health probes. • Secure API & Contract Design: Architect and consume strict REST, gRPC, and OpenAPI interface contracts to ensure clean service boundaries and compatibility with decoupled distributed systems. • DoD Security & Compliance: Integrate Zero-Trust security principles into application code, including mTLS, Keycloak (OIDC/CAC/PKI authentication), token-based authorization (JWT/OAuth2), and secrets management via Vault. • AI-Native Engineering: Leverage AI coding assistants, prompt-driven generation, and autonomous agent workflows to accelerate feature delivery, generate unit tests, and maintain clean architectural patterns. Required Technical Expertise • Core Languages (in prioritized order): Go (Golang), TypeScript/JavaScript (Next.js, Vite/React), and Python. • Frontend Engineering: Deep proficiency in modern React, Next.js (App Router, SSR/SSG), Vite, component state management, and modern styling (Tailwind CSS, Shadcn). • Containers & Orchestration: Pure Docker workflows (multi-stage builds, minimal base images, rootless execution) and Kubernetes (deployments, stateful sets, services, ingress, Helm). • Cloud & DevOps: Hands-on experience developing against AWS (Commercial and GovCloud) and collaborating through modern CI/CD pipelines (GitLab CI). • Security & Auth: Solid understanding of secure coding practices (OWASP Top 10), authentication protocols (OAuth2/OIDC, SAML, PKI/CAC), and Zero-Trust network models. Qualifications • 5-8+ years of professional full-stack software development experience. • Clearance Requirement: U.S. Citizenship required. Must currently hold an active U.S. Security Clearance (Secret / Top Secret) OR possess a proven track record of obtaining and holding a DoD security clearance. • Demonstrated production experience with Golang backends and Next.js / Vite-React frontends. • Deep hands-on experience building, debugging, and maintaining applications running natively in pure Docker and Kubernetes. • Demonstrated engagement with or active use of AI-native development tools and agentic engineering workflows.
