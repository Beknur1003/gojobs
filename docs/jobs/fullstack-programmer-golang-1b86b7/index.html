Deskripsi Pekerjaan Kami mencari Fullstack Software Engineer yang berpengalaman untuk bergabung dalam pengembangan, pemeliharaan, dan optimalisasi aplikasi web berskala produksi. Kandidat yang ideal memiliki pemahaman mendalam tentang arsitektur sistem, mampu merancang antarmuka yang responsif dengan Next.js, serta membangun layanan backend yang tangguh menggunakan PHP (dan idealnya ekosistem modernnya seperti Laravel). Tanggung Jawab Utama - Pengembangan Frontend: Merancang dan mengimplementasikan antarmuka pengguna yang interaktif, cepat, dan responsif menggunakan Next.js (TypeScript/JavaScript). - Pengembangan Backend: Mengembangkan dan memelihara API (RESTful/GraphQL) serta logika bisnis server-side menggunakan PHP. - Manajemen Basis Data: Merancang skema, melakukan migrasi, dan mengoptimalkan kueri pada basis data relasional (PostgreSQL atau MySQL). - Integrasi & Infrastruktur: Mengintegrasikan layanan pihak ketiga dan memastikan aplikasi dapat di-deploy dengan lancar di lingkungan produksi (memanfaatkan Nginx, PM2, atau container/Docker). - Kualitas Kode: Menulis kode yang bersih, modular, dapat diuji (testable), dan terdokumentasi dengan baik. - Pemecahan Masalah: Melakukan debugging, profil kinerja sistem, dan menyelesaikan isu teknis di seluruh tumpukan aplikasi. Kualifikasi Utama (Core Requirements) - Pengalaman profesional sebagai Software Engineer, Fullstack Developer, atau peran serupa (minimal 3+ tahun). - Pemahaman mendalam tentang ekosistem JavaScript/TypeScript modern. - Pengalaman terbukti dalam membangun aplikasi Server-Side Rendering (SSR) atau Static Site Generation (SSG) menggunakan Next.js. - Keahlian tingkat lanjut dalam pemrograman PHP berorientasi objek (OOP). Pengalaman kuat dengan framework PHP modern seperti Laravel sangat diutamakan. - Kemampuan merancang dan mengelola basis data relasional secara efisien (MySQL/PostgreSQL). - Mahir menggunakan version control system (Git) dan memahami alur kerja CI/CD dasar. - Terbiasa dengan alat pengujian API (seperti Bruno, Postman, atau sejenisnya) dan pengelolaan autentikasi (misal: Bearer tokens, JWT, OAuth). Kualifikasi Tambahan (Nice to Have / Plus Points) - Golang: Memiliki pengalaman praktis menulis layanan, API, atau arsitektur microservices menggunakan Go (termasuk framework seperti Fiber atau Gin). - Infrastruktur & DevOps: Familiar dengan Dockerisasi aplikasi, konfigurasi web server (Nginx), dan manajemen proses (PM2). - Pemahaman mengenai arsitektur sistem berskala besar, manajemen state global pada frontend, dan caching (Redis/Memcached). Soft Skills - Kemampuan komunikasi teknis yang baik untuk berkolaborasi dengan tim produk, desain, dan sesama engineer. - Pola pikir analitis dan proaktif dalam mencari solusi terbaik (bukan sekadar solusi yang bekerja). - Kemandirian dalam mengelola tugas kompleks dengan pengawasan minimal.
