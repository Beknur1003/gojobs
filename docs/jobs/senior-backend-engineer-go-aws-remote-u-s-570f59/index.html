Senior Backend Engineer (Go/AWS) – Remote U.S. Join a lean engineering team building production systems around medical-grade wearable physiology data — the APIs, SDKs, cloud infrastructure, auth flows, and data pipelines that help researchers, clinicians, coaches, and enterprise organizations make better decisions about health and performance. This is a hands-on senior backend IC role for a strong Go engineer who can move quickly, reason through distributed systems, and ship reliable software in a compliance-aware environment. You will work within an architecture set by senior technical leaders, own well-scoped backend workstreams end-to-end, and help turn complex biometric data flows into dependable product and platform capabilities. The Opportunity We are early in our commercial journey and building the kind of engineering team where strong individual contributors have direct impact. You will not be joining to manage people, own the entire architecture, or build prototypes that never ship. You will be joining to execute on production-critical backend work across a real health-tech platform spanning firmware, cloud systems, mobile and web applications, developer APIs, and SDK infrastructure. You’ll work closely with senior technical leaders and help unblock meaningful platform priorities: integrating partner algorithms, improving backend data flows, attaching APIs to existing product capabilities, strengthening infrastructure, and shipping features that support enterprise and consumer-facing use cases. Why This Role Is Worth Your Attention • Work on wearable physiological data systems where reliability and quality matter. • Own real backend work across Go services, APIs, AWS infrastructure, data pipelines, auth systems, and developer-facing surfaces. • Join a fully remote, distributed U.S. team with no specific U.S. location requirement. • Collaborate with experienced technical leaders while staying in a hands-on IC path. • Use modern AI-assisted engineering workflows, including tools such as Claude or Cursor depending on your preferences. • Earn a $160,000 base salary, with final compensation dependent on experience, skill level, and assessment performance. What You Will Own Backend APIs & Services • Design, build, and ship Go-based backend services that support consumer-facing and enterprise-facing product surfaces. • Develop and maintain REST and gRPC APIs, async workers, SDK auth flows, and service integrations. • Translate product and platform needs into simple, reliable, testable backend implementations. Platform Infrastructure & DevOps • Work within and improve AWS infrastructure, including services such as ASGs, Aurora, ElastiCache, SQS, S3, and CloudWatch. • Contribute to CI/CD pipelines, zero-downtime deployment patterns, autoscaling systems, and operational reliability. • Help the platform scale as data volume, enterprise usage, and global infrastructure needs grow. Security & Compliance Engineering • Build and harden authentication and authorization systems, including JWTs, OAuth flows, sessions, and API key management. • Implement backend controls such as rate limiting, audit logging, access control, and secure client-facing data access. • Contribute to a compliance-aware engineering environment, including SOC 2 and HIPAA-related practices. Developer Platform & External APIs • Extend and maintain developer-facing APIs, SDK backend systems, enterprise integrations, and API key workflows. • Help attach APIs to existing and emerging platform capabilities so customers and partners can use data effectively. • Support systems that make biometric data accessible, understandable, and reliable for approved client use cases. Data Systems & Observability • Work across relational and NoSQL databases, data export pipelines, ingestion flows, and structured logging. • Debug performance and reliability issues across distributed components. • Improve observability so the team can understand platform health, trace failures, and resolve issues quickly. B2B Platform & Admin Systems • Build backend capabilities for organization lifecycle management, user provisioning, activation, onboarding, and adherence reporting. • Support multi-organization hierarchy management and enterprise administration workflows. • Help finish important platform features that are currently backlogged because senior engineering capacity is focused elsewhere. What Makes You a Strong Fit • You have strong, production-tested Go engineering experience. • You have built and operated backend services, APIs, and data systems in AWS. • You understand distributed systems well enough to debug issues across services, queues, databases, storage, and client-facing APIs. • You are comfortable with relational and NoSQL databases, messaging or event systems, and infrastructure-as-code workflows. • You have solid authentication and authorization fundamentals, including token lifecycle, session management, OAuth, and API key management. • You can own scoped backend work from definition through deployment without needing close management. • You communicate tradeoffs, progress, and blockers clearly. • You are comfortable working in a lean startup environment where priorities can shift and engineers are expected to keep moving. • You can use AI-assisted coding workflows effectively, including managing multiple coding agents or model-assisted tasks where useful. • You are willing to complete a live coding assessment as part of the process. Nice-to-Haves • Experience in health tech, wearables, biometric data, IoT, or device-connected software. • Background with HIPAA, SOC 2, GDPR, or other compliance-aware engineering environments. • Experience with high-throughput data upload, ingestion, transformation, or export systems. • Developer platform experience, including SDKs, external APIs, enterprise integrations, or API management. • Familiarity with AI/ML platform infrastructure, MCP servers, or model-facing backend systems. • Exposure to mobile-connected systems involving iOS, Android, firmware, or device data flows. What Success Looks Like • You come up to speed quickly on an existing codebase and start shipping useful backend work. • You take ownership of scoped API, infrastructure, auth, data pipeline, and reliability improvements from definition through deployment. • You build software that is simple, maintainable, testable, and appropriate for a compliance-aware platform. • You help senior engineers stay focused by independently knocking out important platform work that has clear context and business value. • You earn trust over time through strong engineering judgment, clear communication, and reliable execution.
