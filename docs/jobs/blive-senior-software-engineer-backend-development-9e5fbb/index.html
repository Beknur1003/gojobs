Senior Software Engineer Location: Bengaluru, Karnataka Work Mode : 5 Days Work From Office Reporting To :Tech Lead Experience : 5 - 7 yrs (backend, hands-on) Function : Backend Engineering Core Stack : - Node.js / Golang - Kafka - AWS + AI. Good to have experience in Agentic AI, LLM, building AI pipelines, RAG models. About the Role : BLive is building the operating system for enterprise EV fleets - combining electric mobility, fleet management, logistics technology, charging infrastructure, and SaaS for the next generation of last-mile mobility. As a Senior Software Engineer, you will be a hands-on builder on our core backend - designing services, owning system design decisions, and shipping features that move real vehicles, orders, and money. You will report to the Tech Lead and work across the EZY/3PL, NXT/SaaS, and Common Platform pods, writing production code every week while raising the engineering bar around you. This is a depth role, not a management role - we want strong Node.js or Golang engineering paired with real, hands-on system design judgement at scale. What You'll Own : - Build & Ship Core Services - System Design & Architecture - Data, Messaging & Scale - Reliability & Performance - Engineering Standards & Mentorship - Design and scale the distributed backend behind India's enterprise EV fleet platform. - Design, build, and ship NestJS / Node.js and Golang microservices across fleet, orders, telematics, and SaaS domains. - Own features end to end - schema, API contract, implementation, tests, rollout, and monitoring. - Write clean, well-tested, production-grade code that the next engineer can change safely. - Turn ambiguous problems into concrete designs - service boundaries, data models, API contracts, failure modes. - Make and defend trade-offs on consistency, caching, idempotency, retries, and backward compatibility. - Write short design docs / TDDs and drive them through review before code is written. - Build event-driven flows on Kafka, RabbitMQ, BullMQ, and Redis - topic design, consumer groups, and replay. - Model and optimise data on PostgreSQL and MongoDB: indexing, query tuning, migrations, and growth planning. - Keep high-throughput telematics and transactional pipelines correct, idempotent, and recoverable. - Profile and fix bottlenecks; drive down p95/p99 latency and cost on critical paths. - Instrument services with meaningful logs, metrics, alerts, and traces; own what you ship in production. - Lead root-cause analysis on incidents and convert findings into permanent fixes, not patches. - Run rigorous code reviews and set the bar on testing, error handling, and API design. - Unblock and mentor engineers through complex implementation problems. - Partner with QA on testability, quality gates, and release readiness. What We're Looking For : Required : - 5 - 7 years of hands-on backend engineering on production systems. - Strong in Node.js (NestJS / TypeScript) or Golang - deep, not surface-level, in at least one. - Hands-on system design : service decomposition, data modelling, API design, caching, and failure handling - with systems you've personally designed and shipped. - Built and operated microservices in a distributed environment. - Solid with PostgreSQL or MySQL plus a NoSQL store (MongoDB / Redis) - including query and index optimisation. - Practical experience with message queues / event-driven systems (Kafka, RabbitMQ, BullMQ, or similar). - Comfortable with Docker, CI/CD pipelines, and cloud deployment on AWS. - Strong debugging and performance-tuning skills in production. - Clear communicator - can explain technical trade-offs to engineering and product. Bonus : - Proficiency in both Node.js and Golang, or a strong polyglot track record. - EV, mobility, fleet, logistics, 3PL, or supply-chain technology. - Telematics, IoT, GPS, or real-time event-driven systems. - Building multi-tenant SaaS platforms. - Designing for eventual consistency and idempotency in distributed systems. - Kubernetes, service mesh, gRPC, or Protocol Buffers. - Observability with Prometheus, Grafana, or the ELK stack. - Performance, load, and reliability engineering. - Interest in Agentic AI frameworks and integrating them into backend services.
