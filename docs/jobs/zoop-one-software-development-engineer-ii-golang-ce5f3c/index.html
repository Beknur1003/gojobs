About the Role : We are looking for a Backend Engineer (SDE 2) to build scalable backend systems for EV charging infrastructure and energy management platforms. The role focuses on developing high-performance APIs, event-driven systems, and data pipelines that process EV telemetry, charging sessions, and energy analytics. What You'll Own : - Design and develop scalable backend services and RESTful/WebSocket APIs. - Build microservices using Go. - Design and optimize databases for high-volume telemetry and charging-session data. - Build event-driven systems and data pipelines using Kafka or similar messaging systems. - Work on real-time and batch processing workflows for telemetry, energy metrics, and analytics. - Improve application reliability, performance, monitoring, and observability. - Deploy and operate services using Docker and Kubernetes. - Participate in system design, architecture discussions, code reviews, testing, and technical documentation. - Mentor and support junior engineers when required. Required Qualifications : - 3 - 5+ years of backend development experience building scalable APIs and microservices. - Strong proficiency in Golang. - Strong understanding of PostgreSQL, MongoDB, or other relational/NoSQL databases. - Experience with query optimization, indexing, schema design, partitioning, or replication. - Experience building event-driven or distributed systems using Kafka or similar messaging systems. - Familiarity with GCP or other cloud platforms. - Experience with Docker and Kubernetes. - Experience with monitoring and observability tools such as Grafana, Kibana, or ELK. - Strong understanding of system design, scalability, and performance optimization. - Experience writing clean, maintainable, testable code with unit and integration tests. Nice to Have : - Experience working with EV charging, energy management, mobility, or IoT platforms. - Experience processing high-volume telemetry or time-series data. - Experience with real-time data processing and analytics pipelines. - Experience with WebSockets or other real-time communication protocols. - Experience with CI/CD and production infrastructure. - Experience working with distributed systems at scale. Why Join Us : - Build backend infrastructure powering EV charging and energy platforms. - Work on distributed systems, real-time data, and high-volume telemetry. - Solve challenging problems around scalability, reliability, and performance. - Take meaningful ownership of production systems and technical decisions.
