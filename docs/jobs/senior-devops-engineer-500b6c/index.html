Job Description Title Senior DevOps Engineer Business Unit GURU_TECSERV_30320 Dept Production Infrastructure & Ops Reports to (Use Manager’s title, not name) Nainesh Patel, Senior Director Cloud Engineering Location Hybrid Job Code Direct Reports No FLSA Status Exempt Updated 8/1/2026 About the Role Impact you will make The Senior DevOps Engineer will play a key role in supporting and improving DevOps solutions across a hybrid infrastructure consisting of Linux and Microsoft ecosystems, Azure cloud services, and select data center-hosted products. This role will contribute to the migration and modernization of on-premise workloads to Azure while continuing to support existing delivery tooling where needed, including TeamCity for products that still depend on data center-based release processes. As a forward-thinking, cloud-focused, and hands-on engineer, the individual will help develop and maintain DevOps processes, automation frameworks, Infrastructure-as-Code, and CI/CD pipelines that support the integration and deployment of infrastructure and application artifacts. The DevOps Engineer II will help improve delivery speed, observability, security, and platform reliability through automated templates, scripts, reusable pipeline patterns, and close collaboration with technical team members across different locations. What you will do Follow established designs and contribute to the development of reusable automation frameworks and end-to-end CI/CD pipelines for deploying application and infrastructure resources across cloud and data center-hosted environments. Support build, test, release, and deployment workflows using Azure DevOps, TeamCity, and related DevOps tooling, especially for products that continue to rely on data center-based release processes. Play an active part in delivering product increments by working on user stories, participating in daily scrum calls, and supporting delivery of roadmap commitments. Provide ongoing DevOps support to application development teams, including pipeline troubleshooting, automation improvements, release support, and guidance on deployment practices. Develop, maintain, and update Infrastructure-as-Code using Terraform, Azure ARM/Bicep, PowerShell, YAML, and related automation frameworks. Create and maintain automation to configure and deploy cloud infrastructure resources such as virtual machines, network components, firewalls, gateways, load balancers, storage, and related platform services. Support containerized application delivery using Kubernetes, Helm, manifests, Docker-based platforms, and GitOps-oriented deployment practices such as Argo CD where applicable. Help improve delivery reliability, observability, and security by implementing automated validation, deployment gates, monitoring integration, secrets handling, rollback approaches, and environment configuration standards. Collaborate with globally distributed application, platform, security, and operations teams to reduce manual effort, improve repeatability, and support consistent deployment practices. Leverage AI-assisted development tools such as GitHub Copilot, Cursor, or similar solutions to accelerate the development of automation scripts, operational dashboards, pipeline improvements, and developer self-service capabilities. Provide after-hours, nighttime, and weekend support on a rotational basis for high-severity incidents, major planned maintenance activities, releases, and deployment-related issues involving Azure DevOps, TeamCity, CI/CD pipelines, and automation. What you will bring 5+ years of hands-on DevOps engineering experience supporting mission-critical applications, delivery pipelines, infrastructure automation, and release processes in a medium to large organization. Working knowledge of cloud computing, Azure services, hybrid hosting environments, and modernization or migration of on-premises workloads to Azure. Practical experience with CI/CD tools such as Azure DevOps, TeamCity, Jenkins, GitLab, Bamboo, or similar platforms, including Git-based workflows, YAML pipelines, branching strategies, build automation, and release orchestration. Experience developing or maintaining automation for CI/CD pipelines using Terraform, PowerShell, ARM/Bicep, Ansible, Chef, YAML, or similar technologies to deploy infrastructure and application artifacts. Experience creating or updating YAML manifests, configuration files, deployment templates, and reusable automation components. Experience supporting application deployments to Kubernetes, Docker Swarm, Docker Enterprise, or similar container platforms using manifests, Helm, Argo CD, or automated CI/CD pipelines. Application development exposure with at least one common programming language such as Java, C#, Python, or GoLang. Experience or working familiarity with Azure services such as Virtual Machines, Azure Site Recovery, Azure Functions, Azure Automation, App Service, Scale Sets, Azure DevOps, Azure Policy, Azure Monitor, Azure Backup, Azure Storage, Application Gateway, Azure DNS, Load Balancer, Azure Active Directory, Azure networking, Azure IaaS, Azure Serverless, Azure Security, Azure PaaS Database, PowerShell, and ARM templates. Exposure to AWS cloud platform concepts such as VPC, Elastic Load Balancing, Global Accelerator, Transit Gateway, Security Groups, IAM, Route 53, KMS, PrivateLink, Direct Connect, VPN, CloudFront, and API Gateway. Familiarity with observability and monitoring tools such as Application Insights, Dynatrace, New Relic, Datadog, Azure Monitor, logging, metrics, and alerting. Experience or strong interest in using AI-assisted development tools such as GitHub Copilot, Cursor, or similar platforms to improve engineering productivity, build dashboards, automate repetitive tasks, and create self-service tools for development teams. Experience working in Agile/Scrum environments and collaborating effectively with globally distributed teams. Strong troubleshooting and technical problem-solving skills, including the ability to diagnose build failures, deployment issues, pipeline errors, infrastructure automation failures, and environment configuration problems. Experience with both Windows and Linux platforms as they relate to application deployment, automation, and troubleshooting. DevOps, Azure, Kubernetes, Terraform, or cloud automation certifications are a plus. Preferred (Nice to Have) Certifications such as Microsoft Azure Architect, Microsoft Certified Azure Administrator, Azure DevOps, Kubernetes, Terraform, or related cloud automation credentials. Bachelor’s degree in computer science, engineering, information systems, or equivalent practical experience. Experience with scripting using PowerShell, Linux Shell, Python, GoLang, or similar languages. Experience building internal dashboards, automation portals, runbooks, or developer self-service tools that improve visibility, reduce support friction, and enable application teams to move faster. Experience with GitOps, Argo CD, TeamCity, container security, automated testing integration, developer productivity tooling, or supporting legacy CI/CD workflows during cloud modernization.
