UI Developer – Agentic Security Platform

Location: India, Remote-First Employment: Full-Time Start Date: January 2027 Experience: 4+ years Language: Fluent English required Industry: Cybersecurity / Enterprise SaaS / AI Security About the Opportunity Pragmatike is recruiting on behalf of a global enterprise cybersecurity company building a new generation of products to secure AI agents, LLM-powered applications, and the data they access. The Agentic Security team gives security teams visibility and control over the AI agents operating across their organization. You’ll build the web interface where expert users investigate agent inventories, session timelines, policy violations, and forensic findings, while administrators define and manage security policies. This is a data-intensive frontend role where clarity, responsiveness, and performance matter. We’re looking for a UI Developer with strong frontend fundamentals who can work closely with Go backend engineers and turn complex security data into intuitive, high-performance interfaces. What You’ll Do • Build and maintain the product UI using React and TypeScript for agent inventory, policy management, session investigation, and security dashboards. • Build data-dense interfaces including timelines, graphs, tables, filtering, and search across large datasets. • Optimize frontend performance when rendering and interacting with large volumes of security data. • Collaborate with Go backend engineers on REST and gRPC-web APIs and with design teams on interaction patterns. • Own frontend quality across component architecture, accessibility, testing, and performance. • Contribute to the shared design system and frontend tooling. • Use AI-assisted development workflows to accelerate implementation, testing, debugging, and problem-solving. What We’re Looking For • 4+ years of frontend development experience building complex, data-rich web applications. • Strong TypeScript and React skills, with a solid understanding of state management, rendering performance, and component architecture. • Experience consuming REST and/or gRPC-web APIs and collaborating closely with backend engineering teams. • Experience with data visualization libraries such as D3, visx, Recharts, or equivalent. • Experience building performant tables, timelines, dashboards, or other interfaces handling large datasets. • Strong frontend testing experience across unit, component, and end-to-end testing. • Fluent English with strong written and verbal communication skills. • Comfortable using modern AI coding assistants such as Claude Code, Cursor, GitHub Copilot, Codex, or similar. This is a must-have. • Strong ownership and the ability to work independently in a remote-first, distributed environment. Nice to Have • Experience building security, observability, analytics, or other data-intensive products. • Basic Go or Python skills for small backend changes or tooling. • Experience working with design systems and WCAG accessibility standards. • Previous experience in cybersecurity, security tooling, or trust & safety. • Experience introducing AI-assisted or agentic development workflows across engineering teams. AI-First Engineering AI is a core part of the engineering workflow on this team. During the interview process, you'll be asked about how you use AI in real-world software development, including the tools you use, how you validate their output, and where AI has changed the way you work. We're looking for engineers who use AI as a force multiplier for quality, productivity, and problem-solving, not simply as an autocomplete tool. Why Join • Build a greenfield product at the intersection of cybersecurity and agentic AI. • Turn complex AI security data into interfaces used by expert security teams. • Solve challenging frontend problems around large datasets, visualization, performance, and real-time investigation workflows. • Take ownership of a key product area and influence frontend architecture from an early stage. • Collaborate with a highly technical, distributed team where AI is a core part of the development process.
