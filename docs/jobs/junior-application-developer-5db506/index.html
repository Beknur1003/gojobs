Junior Application Developer

PT. Vascomm Solusi Teknologi Jakarta Timur, DKI Jakarta, Indonesia опубликовано 18 ноября 2026

Офис Junior Полная занятость

Junior Application Developer Saat ini kami membuka kesempatan bagi para profesional software engineering untuk memenuhi kebutuhan strategis klien BUMN kami yang berlokasi di Jakarta Timur. Posisi ini memegang peranan penting dalam merancang, membangun, dan memelihara aplikasi modern berkinerja tinggi guna mendukung operasional sistem berskala nasional. Jika Anda memiliki antusiasme dalam ekosistem pengembangan web modern, penulisan kode yang bersih, serta mampu bekerja secara kolaboratif dalam tim yang dinamis, kami mengundang Anda untuk menjadi bagian dari proyek strategis ini. Informasi Posisi • Posisi: Junior Application Developer • Penempatan Klien: Klien BUMN – Onsite (WFO) di Jakarta Timur • Status Kerja: Full-time (Kontrak 1 tahun, dapat diperpanjang hingga 3 tahun) • Level Posisi: Junior Level Tanggung Jawab Utama Sebagai Junior Application Developer, Anda akan berkontribusi langsung pada pengembangan fitur aplikasi klien BUMN, dengan tanggung jawab utama meliputi: • Melakukan analisis kebutuhan teknis terkait fitur baru yang ingin dikembangkan. • Mendesain arsitektur sistem dasar dan melakukan coding sesuai dengan panduan awal pengembangan. • Melakukan pengujian (testing) dan pemeliharaan (maintenance) sistem secara rutin. • Menyusun dokumentasi teknis terkait spesifikasi dan fungsi coding secara berkala agar dapat memudahkan pekerjaan tim lintas divisi. Target utama posisi ini adalah mengeksekusi pengembangan aplikasi yang berfungsi sesuai kebutuhan bisnis dengan mematuhi standar best practice, menjaga stabilitas sistem, serta menghasilkan dokumentasi teknis yang rapi dan mudah dipahami. Kualifikasi Pendidikan minimal S1 di bidang: • Teknik Informasi / Teknik Informatika • Ilmu Komputer • Sistem Informasi atau bidang terkait yang relevan Pengalaman Minimal 1–2 tahun pengalaman bekerja di bidang yang sama pada posisi: • Junior Application Developer / Software Engineer • Fullstack / Frontend / Backend Developer Kemampuan Teknis Kandidat diharapkan memiliki penguasaan terkait: • Bahasa pemrograman dan framework modern: Node.js, GoLang, React.js, Vue.js, dan Next.js. • Pengelolaan dan perancangan database relasional menggunakan MySQL dan PostgreSQL. • Pemahaman dan penggunaan tools visualisasi data Power BI. • Penggunaan version control system menggunakan GitHub dan GitLab. Soft Skill • Kemampuan analisis dan problem solving yang baik dalam memecahkan kendala kode. • Kemandirian yang baik dalam mengeksekusi task, namun tetap menjadi team player yang solid. • Komunikasi yang proaktif dengan tim lintas fungsi dalam berkolaborasi menggunakan dokumentasi teknis. • Keinginan yang kuat untuk terus belajar (eagerness to learn) dan beradaptasi dengan tech stack yang dinamis. Target Kinerja Dalam posisi ini Anda diharapkan mampu: • Menyelesaikan implementasi fitur tepat waktu sesuai dengan panduan desain arsitektur dan timeline proyek. • Menulis barisan kode yang rapi, terstruktur, dan teruji sehingga meminimalisir bug pada fase produksi. • Memastikan dokumentasi spesifikasi teknis dan fungsi kode selalu diperbarui secara rutin. Nilai Tambah Kandidat dengan pengalaman berikut akan menjadi prioritas: • Pengalaman mengembangkan aplikasi berskala enterprise atau di lingkungan BUMN. • Memiliki portofolio proyek menggunakan kombinasi stack Node.js/GoLang dan Next.js/React. Mengapa Bergabung Dengan Vascomm? • Kesempatan emas untuk berkontribusi langsung dalam proyek transformasi digital di lingkungan BUMN berskala nasional. • Pengalaman bekerja dengan modern tech stack yang komprehensif dan standar production-grade. • Lingkungan kerja yang kolaboratif, suportif, dan memberikan ruang bagi Anda untuk berkembang secara profesional.
