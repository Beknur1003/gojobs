Everywhere." Be part of the team designing the infrastructure for the AI-first world. Why This Role Exists We're looking for a Software Engineering Intern to help us build the systems powering our GPU cloud platform. You'll contribute to real production code across cloud-native infrastructure, platform tooling, and backend services—working alongside a senior engineering team that moves fast and ships impactful work. This is a unique opportunity for someone who's excited to work on AI infrastructure at scale in a high-growth startup. You'll own meaningful work from day one—not just tickets. What You'll Do • Build and maintain cloud-native services and tooling supporting our GPU cloud platform • Work with Kubernetes to help manage, schedule, and optimize GPU workloads across clusters • automation • Write clean, well-documented code with testing and participate in code reviews • Collaborate cross-functionally with infrastructure, product, and research teams to ship real features •
