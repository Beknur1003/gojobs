Мы развиваем e-commerce направление и ищем Senior Golang разработчика в команду, которая занимается разработкой и запуском нового e-commerce контура. Продукт команды: Приложение сборщика (Pickup) — мобильное приложение для ТСД/Android, которым сотрудники склада пользуются для сборки заказов, перемещения товаров и инвентаризации. Чем предстоит заниматься: • Разработка backend-сервисов и адаптеров вокруг Ensi Platform на Go. • Реализация REST/gRPC API. • Разработка событийных интеграций через Kafka. • Создание сервисов кэширования, ускорения доступа к данным и вспомогательных компонентов. • Обеспечение надёжности интеграций: timeouts, retry, idempotency, logging, metrics, tracing. • Написание unit- и integration-тестов. • Участие в code review. В ближайшие месяцы — участие в массовом запуске e-commerce-контура и разработка новых функций для приложения Pickup. В перспективе — работа с техническим долгом и реализация новых бизнес-функций. Что мы ожидаем от кандидата: • Высшее техническое образование; предпочтительно сильный технический вуз. • Коммерческий опыт разработки на Go — от 2-3 лет • Уровень — Middle+ / Senior. • REST/gRPC API — обязательно. • Опыт с брокерами сообщений — Kafka или RabbitMQ; предпочтительна Kafka. • Опыт с Redis или Memcached, Kubernetes, CI/CD pipelines. • Понимание архитектурных паттернов распределённых систем. • Интерес к solution architecture. • Технический английский уровня B2 — для чтения документации • Самостоятельность — способен сам брать задачи с доски и двигать их без постоянного контроля. • Инициативность — предлагать решения и не ждать постоянных указаний • Коммуникативные навыки — готов самостоятельно обращаться к DevOps, тестировщикам, аналитикам и другим коллегам. Инструменты и технологии: Go / Golang, REST, gRPC, Kafka / RabbitMQ, Redis / Memcached, Kubernetes, CI/CD, Jira, VS Code или аналогичная IDE. Что мы предлагаем: • График работы 5/2, возможен гибридный или удалённый формат работы • ДМС после ИС и "Добросервис" - консультативные услуги по здоровью, психологии, правовым отношениям • Официальное трудоустройство согласно ТК РФ с первого дня, полностью "белая" заработная плата • Скидку на все товары Дом Лента - 10% • Сильная и мотивированная команда • Атмосфера стартапа внутри крупной компании: инициативы приветствуются, а специалист может влиять на технические решения. • Возможность участвовать в запуске нового продукта. • Перспектива роста до тимлида новой команды по мере масштабирования проекта. • Интересные проекты, способствующие самореализации, профессиональному и карьерному росту.
