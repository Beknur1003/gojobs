At HexaIO we are looking for a Senior Backend Software Engineer with advanced, hands-on Go and PHP skills to join the development team of one of our enterprise clients. This is an individual contributor role for an experienced engineer who works independently and helps raise the technical level of the backend team. It is an advantage if you are familiar with AI technologies and already use AI-assisted development tools (e.g., GitHub Copilot, Cursor, Claude Code, or similar) productively in your daily work. As a Backend Software Engineer, you will: • Design and build backend services and APIs in Go and PHP, following the client's architecture guidelines. • Prepare technical proposals, alternatives, and risk assessments for architecture decisions on the most complex components. • Contribute to database design and performance optimization within your own development area. • Build on shared components from the Platform Engineering team instead of creating parallel solutions. • Estimate and deliver your stories independently, documented and demo-ready by the end of each sprint. • Review pull requests from other engineers, and merge your own code only after peer approval. • Mentor fellow engineers and help them resolve technical blockers. • Apply secure coding guidelines and GDPR requirements, especially in components that handle personal data. Requirements • At least 5 years of professional experience in backend software development • Advanced, hands-on knowledge of Go (Golang) and PHP • Experience designing and developing microservice architectures and APIs • Database design and optimization experience • Hands-on CI/CD experience and a working knowledge of DevOps practices • Fluent Hungarian and professional working proficiency in English Development knowledge of as many of the following technologies as possible: • REST, JSON • SQL databases, e.g. PostgreSQL or MySQL • Modern PHP frameworks, e.g. Symfony or Laravel • Docker, Kubernetes • Message brokers, e.g. Kafka or RabbitMQ • Git and pull request workflows Nice to Have • AWS, Azure, or GCP development experience • Linux server environments • OWASP Top 10 and secure development practices • Mentoring or onboarding junior developers • Degree in computer science or a related field Salary: Ft1,200,000 – Ft1,700,000 / month Originally posted on Himalayas
