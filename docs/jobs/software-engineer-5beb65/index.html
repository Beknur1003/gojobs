Centaur Software is a leading provider of practice management software throughout Australia for the last 30 years. We strive to provide solutions to dental practices to help them grow their business. We are currently seeking an experienced Software Engineer to join our Sydney office. This is a permanent full-time position. Key Responsibilities • Designing and developing backend services and microservice-based applications using Golang and Python; • Building scalable Business Intelligence (BI) platforms and analytical data infrastructure to support business reporting and operational analytics; • Designing and implementing ETL/ELT data pipelines for collecting, transforming and loading large volumes of structured and semi-structured data; • Developing and maintaining Data Warehouse using ClickHouse; • Creating and maintaining dbt models, transformations and analytical datasets; • Researching, analysing and evaluating software system requirements, technical limitations and business needs; • Designing software architecture and backend infrastructure for scalable cloud-native applications; • Developing APIs, internal services and integration layers between multiple systems and third-party platforms; • Building AI integration and communication services including MCP (Model Context Protocol) servers and middleware components for AI-driven workflows; • Managing CI/CD pipelines and deployment automation processes; • Implementing containerised infrastructure using Docker and Kubernetes; • Performing software testing, debugging, troubleshooting and optimisation activities; • Maintaining software documentation, operational procedures and technical specifications; • Monitoring software performance (AWS Cloud Watch, Prometheus, Grafana), analysing operational metrics and improving system reliability and scalability; • Participating in software security implementation, access control and risk mitigation activities; • Collaborating with internal stakeholders to deliver reporting, analytics and automation solutions; • Supporting continuous improvement initiatives and modern software engineering practices across the organisation; • Evaluating and implementing new technologies, frameworks and development methodologies to improve software delivery and platform capabilities. Qualifications • Bachelor degree or higher qualification in Computer Science, Software Engineering, Data Engineering or related field. Essential Technical Skills Required • Strong experience with Golang and Python software development; • Advanced SQL knowledge and database design skills; • Commercial experience with ClickHouse, complex query optimisation; • Experience designing and building ETL/ELT data pipelines; • Strong understanding of backend architecture and distributed systems; • Experience with dbt, Airflow; • Experience with Docker, Kubernetes; • Knowledge of CI/CD pipelines on GitHub and automated deployment processes; • Experience building scalable cloud-native applications; • Understanding of API development and microservice architecture; • Familiarity with AI communication systems, MCP servers concept and AI integration platforms; • Strong analytical and problem-solving abilities; • Ability to work independently and collaboratively within agile engineering teams; • Strong communication and documentation skills. Employment Experience Required • At least 5 years of commercial experience as a Software Engineer or Data Engineer; • Strong experience in backend systems, data engineering and Business Intelligence platforms; • Commercial experience with cloud infrastructure, CI/CD and scalable software architecture. No Recruitment Agencies, only direct applications will be considered.
