Tentang Easy Coding Easy Coding adalah platform edukasi online yang berfokus membantu pembelajar membangun keterampilan software development secara praktis melalui kelas berbasis proyek dan mudah dipahami. Kami menciptakan pengalaman belajar yang sederhana, terstruktur, dan relevan untuk orang Indonesia yang ingin memulai atau mengembangkan karier di dunia teknologi. Fokus kami adalah pembelajaran berbasis proyek nyata dengan penjelasan yang jelas, step-by-step, dan mudah diikuti oleh pemula. Penting (Harap Dibaca Dulu) Ini BUKAN pekerjaan mengajar part-time atau live teaching. Ini adalah posisi produksi kelas (course production), di mana Anda akan membuat produk pembelajaran berupa video course lengkap dari awal sampai akhir. Tidak ada kelas live, tidak ada jadwal mengajar mingguan. Yang dibuat adalah rekaman video course yang akan dipublikasikan di platform kami. Deskripsi Role Kami sedang mencari Go Backend Instructor untuk membuat kelas lengkap dari level dasar hingga mampu membangun aplikasi backend menggunakan bahasa pemrograman Go (Golang). Tugas utama Anda adalah menyusun materi, merekam video pembelajaran, dan membimbing siswa melalui pembangunan sebuah aplikasi backend menggunakan Go dari nol sebagai project akhir. Kami mencari seseorang yang bukan hanya memiliki kemampuan programming yang kuat, tetapi juga mampu menjelaskan konsep teknis dengan bahasa yang sangat sederhana dan mudah dipahami pemula ("bahasa bayi"). Tanggung Jawab • Membuat dan merekam video course Go Backend Development secara lengkap. • Menyusun struktur kurikulum dari fundamental hingga intermediate. • Menjelaskan konsep programming dan backend development dengan bahasa yang sederhana dan mudah dipahami. • Mengajarkan fundamental Go (Golang), seperti: • Go Fundamentals (Variables, Data Types, Functions, Structs, Interfaces). • Pointer dan Error Handling. • Package dan Module Management. • Goroutines dan Concurrency Fundamentals. • HTTP Server dan Routing. • RESTful API Development. • Middleware. • Authentication & Authorization (JWT). • Database Integration (PostgreSQL / MySQL). • SQL Query dan Database Relationships. • Environment Variables dan Configuration. • Unit Testing dan API Testing. • Project Structure dan Clean Code. • Deployment dan Production Fundamentals. • Membimbing pembuatan project aplikasi backend menggunakan Go dari awal sampai selesai. • Membuat latihan dan mini project di setiap tahap pembelajaran. • Memastikan materi mengikuti best practice Go Backend Development modern. • Berkolaborasi dengan tim Easy Coding untuk penyusunan dan peningkatan kualitas materi. Kualifikasi • Memiliki pengalaman kuat menggunakan Go (Golang) dalam project nyata. • Memahami konsep backend development dan RESTful API. • Menguasai database relational seperti PostgreSQL atau MySQL. • Memahami authentication, authorization, middleware, dan API security. • Familiar dengan Git dan GitHub. • Memahami software engineering best practices, clean code, dan project architecture. • Mampu menjelaskan konsep teknis dengan sangat sederhana untuk pemula. • Nyaman berbicara di depan kamera dan merekam video tutorial. • Memiliki kemampuan komunikasi yang terstruktur dan jelas. • Pengalaman membuat konten edukasi atau mengajar menjadi nilai tambah. Yang Kami Cari Kami tidak hanya mencari developer. Kami mencari seseorang yang bisa: • Membangun aplikasi backend menggunakan Go dari nol sampai selesai. • Memahami konsep dan praktik backend development yang baik. • DAN menjelaskan cara kerjanya dengan cara yang sangat mudah dipahami oleh orang yang benar-benar pemula. Jika Anda hanya bisa coding tetapi kesulitan menjelaskan konsep teknis dengan sederhana, posisi ini mungkin tidak cocok. Informasi Pembayaran Posisi ini bersifat project-based (produksi course). Bukan gaji bulanan tetap, melainkan pembayaran berdasarkan total produksi video course. Kami akan menggunakan sistem penawaran (offer) dari kandidat. Gambaran Scope Course: • Go Fundamentals: ± 3 jam video. • Go Backend Development: ± 12–15 jam video. Total estimasi: ± 15–18 jam video pembelajaran. Cara Melamar Kami hanya akan merespons pelamar yang mengirimkan Surat Lamaran / Cover Letter. Dalam surat lamaran, harap sertakan: • Pengalaman Anda menggunakan Go (Golang) dalam project nyata. • Pengalaman membangun aplikasi backend atau REST API. • Pengalaman mengajar atau membuat konten (jika ada). • Portfolio (GitHub, project, atau video tutorial jika tersedia). • Alasan Anda cocok untuk mengajar. • Berapa rate yang Anda inginkan untuk produksi course. Wajib Menyertakan Keyword Harap sertakan keyword berikut di dalam cover letter Anda: "GOBACKEND" Lamaran tanpa cover letter atau tanpa keyword tersebut tidak akan diproses.
