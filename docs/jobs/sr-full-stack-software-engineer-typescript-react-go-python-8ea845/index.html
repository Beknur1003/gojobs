Senior Full Stack Software Engineer - TypeScript/React & Python/Golang Position Overview We are seeking a Senior Full Stack Software Engineer to design, build, and maintain scalable web applications across the front-end and back-end. This role will lead feature development using TypeScript and React on the client side and Go/Golang and Python on the server side, drive API and data model design, improve system reliability and performance, and mentor other engineers. The ideal candidate is hands-on across the stack, experienced with cloud-native architectures and microservices, and passionate about clean code, testing, and operational excellence. Qualifications • 7+yrs as a Full Stack Developer, delivering end-to-end features and owning services in production. • 3+yrs TypeScript and React for front-end development. • 3+yrs with Go (Golang) and Python for back-end development. • Deep experience with RESTful APIs, GraphQL, and WebSockets, plus strong understanding of authentication/authorization (OAuth, JWT). • SQL and data modeling. • Practical knowledge of containerization and orchestration (Docker, Kubernetes) and deployment to cloud platforms (AWS, GCP, Azure). • Excellent communication skills, experience working in Agile teams, and a commitment to mentoring and code quality. It is a plus if you have: • PostgreSQL • Caching • Distributed Messaging • GitHub Actions • Redis • RabbitMQ • AWS • Linux Key Responsibilities • Design, implement, and maintain front-end applications using TypeScript and React, ensuring responsive and accessible user experiences. • Develop and operate back-end services and APIs using Go (Golang) and Python, including RESTful and GraphQL endpoints and WebSockets where appropriate. • Architect and implement scalable microservices, data models, and integrations with SQL and NoSQL databases (PostgreSQL, MySQL, MSSQL, MongoDB). • Collaborate with product, design, and QA to translate requirements into robust, maintainable solutions and deliver high-quality releases in an Agile environment. • Build, document, and maintain CI/CD pipelines, container images, and orchestration using Docker and Kubernetes; manage deployments on cloud platforms (AWS, GCP, Azure). • Implement authentication and authorization (OAuth, JWT) and enforce security best practices across the stack. • Optimize application performance, implement caching strategies and message queues (RabbitMQ, Kafka) to support throughput and reliability. • Establish monitoring, logging and observability (Prometheus, Grafana, ELK) and respond to incidents; continuously improve system reliability and operability. • Write and maintain unit, integration and end-to-end tests (Jest, Mocha, Cypress, Selenium) and promote test-driven development and code review best practices. • Mentor and guide engineers, participate in architecture and design reviews, and drive adoption of design patterns and maintainable coding standards.
