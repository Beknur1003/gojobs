The Job: Convoso is seeking a Senior Platform Engineer to help architect and build the next generation of our high-volume, real-time communication platform. We are not just looking for someone who knows a single telecom technology—we are looking for a distributed systems engineer who has built large-scale, high-concurrency communications platforms where milliseconds matter. In this role, you will help rebuild and modernize our core platform in Go (Golang), designing high-performance backend microservices that handle massive call volumes, real-time event routing, voice media streaming, and large-scale analytics with carrier-grade reliability. Responsibilities summary: 1. Distributed Backend & Next-Gen Architecture (Go) • Architect, write, and maintain production-grade microservices in Go (Golang) to power Convoso’s next-generation SaaS platform. • Design high-throughput, low-latency distributed systems that seamlessly coordinate call routing, reporting, AI processing, and customer data synchronization across services. • Utilize modern messaging and event-streaming technologies (NATS, JetStream, Kafka) to handle massive event volumes reliably and asynchronously. 2. Real-Time Telephony & Media Pipeline • Build, scale, and optimize real-time voice and communication pipelines using FreeSWITCH, Kamailio, SIPGo, Pion WebRTC, Asterisk, and RTPengine. • Manage high-concurrency Session Initiation Protocol (SIP) traffic, media streaming, and call control logic with ultra-low latency constraints. • Interface directly with carrier infrastructure to ensure high call quality, instant call placement, and fault-tolerant voice routing. 3. High-Performance Data Engineering & Analytics • Work with high-performance, large-scale database architectures tailored for both transactional workloads (PostgreSQL) and massive operational analytics (ClickHouse). • Optimize system queries, data structures, and state management to ensure real-time reporting and dashboard responsiveness under heavy load. 4. Scalability, Performance & Cloud Operations • Identify bottlenecks across real-time pipelines and optimize code, networking, and memory allocation for maximum speed and resource efficiency. • Deploy, operate, and support resilient software across large-scale cloud production environments with high uptime requirements. • Participate in system design reviews, promote software engineering best practices, and collaborate closely with product and infrastructure teams. Who You Are: Technical Stack & Domain Expertise • Primary Language: Professional experience building large-scale, high-concurrency backend software in Go (Golang). • Real-Time Communication Stack: Hands-on experience with real-time communications platforms and protocols, including FreeSWITCH, Kamailio, SIPGo, Pion WebRTC, Asterisk, or RTPengine. • Distributed Event Streaming: Proven track record building event-driven architectures using NATS, JetStream, or Apache Kafka. • Database Mastery: Experience operating both relational databases (PostgreSQL) and analytical column-oriented databases (ClickHouse) at scale. • Networking & Protocols: Working command of SIP, WebRTC media streams, network packet flow, and core telephony concepts. Core Architectural Competencies • Distributed Systems Design: Proven experience architecting systems composed of many interdependent microservices operating at high velocity. • Real-Time Performance Focus: Demonstrated track record building software where ultra-low latency is critical (e.g., immediate call connection, sub-second event processing). • System Scalability: Experience scaling production infrastructure to seamlessly support rapid growth in users, events, and concurrent traffic. • Target Backgrounds: Backgrounds from communication platforms and CPaaS providers (e.g., Twilio, SignalWire, Telnyx, or similar high-scale VoIP/telecom ecosystems) are highly desirable.
