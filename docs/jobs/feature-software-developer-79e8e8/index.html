We're Hiring a Software Developer! High Tech Genesis is looking for a talented Software Developer to help develop new features and modernize applications used by organizations around the globe. You will join a large software development team working alongside some of the industry's brightest engineers on software developed for one of the world's leading networking companies. This role focuses on modernizing legacy web applications using React and AI-assisted development tools, while developing scalable backend services and collaborating with cross-functional teams to deliver high-quality software. At High Tech Genesis, we don't just build cloud applications, we're helping BUILD THE CLOUD. Responsibilities • Develop modern web applications using React, JavaScript, and TypeScript. • Develop, maintain, and optimize backend services using Ruby on Rails. • Participate in application modernization and migration initiatives, transforming legacy applications into modern solutions. • Design and implement RESTful. • Build and maintain concurrent, scalable, and distributed backend systems. • Work with relational and NoSQL databases to efficiently model, store, and query data. • Leverage AI development tools such as Agentic AI, Claude, OpenAI, GitHub Copilot, and Codex to improve development productivity while validating generated code. • Ensure applications are secure, scalable, reliable, and highly performant. • Implement testing, logging, and monitoring strategies for production environments. • Collaborate with cross-functional teams on software design, architecture, code reviews, and best practices. • Contribute to CI/CD pipelines and modern software development workflows. • Minimum Bachelor's degree in Computer Science or a related field. • 2–4 years of professional software development experience. • Experience developing applications with React, JavaScript, and TypeScrit. • Experience developing backend services using either of the following technologies Java, C++, or Go (Golang). • Experience participating in application modernization or migration projects. • Experience using AI-assisted development tools such as Agentic AI, Claude, OpenAI, GitHub Copilot, or Codex. • Experience designing and consuming RESTful APIs (gRPC experience is an asset). • Experience with relational and/or NoSQL databases (e.g., PostgreSQL, MySQL, MongoDB). • Familiarity with microservices architecture and distributed systems. • Experience with Git and CI/CD workflows. • Working knowledge of Docker; Kubernetes experience is considered an asset. • Strong communication and collaboration skills with a proactive, curious mindset. Nice to Have • Experience with Ruby on Rails, Scala, Python, AJAX/jQuery. • Experience working in Agile software development environments.
