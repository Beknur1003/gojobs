As a Backend Engineer on Coder's Enterprise Experience team, you'll build the features that help large organizations run Coder in production with confidence. The team owns what administrators and operators need to run Coder well. That covers how it scales, how it's upgraded, how reliably it performs, how it's observed and reported on, how activity is held accountable, and how it's secured. You'll join a cross-functional team of backend, platform, and QA engineers who own the operator experience end to end. You'll ship features from design through production and partner with product and design to solve real operator problems. What you'll do here • Build features end to end, from a design you write within the team's existing approach through production rollout. • Write database migrations that follow the team's patterns for schema compatibility and safe upgrades. • Build the observability, reporting, and audit features administrators rely on to see what their deployment is doing. • Build features that keep enterprise deployments secure, following the team's security practices. • Help investigate and resolve scalability bottlenecks under production-like load, from database access patterns to concurrency in coderd. • Help resolve backend issues surfaced by Coder operators and administrators. • Document the features you build so a reviewer and the next engineer do not have to decode them. • Participate in code reviews, contribute to RFC-style design discussions, and join the on-call rotation. What we're looking for • 2+ years of professional software engineering experience. • Professional experience writing and shipping Go. • Working understanding of Go's concurrency model, including goroutines, channels, and the sync package. • Comfortable with SQL, schema changes, and writing migrations. • Strong verbal and written communication skills, including surfacing blockers and uncertainty early. • Solid debugging skills and the persistence to work a problem, and to escalate early when stuck. • A self-motivated, analytical engineer who enjoys difficult technical challenges. Bonus tacos if you have • (Tacos? If you need an ice-breaker, ask how we say thanks by giving tacos!) • Experience investigating performance under real-world load, including debugging race conditions. • Experience with observability, audit, or security features in an enterprise product. • Experience with major cloud providers, Kubernetes, and container orchestration. • Experience building or operating distributed systems at a meaningful scale. • Curiosity about the latest developer tooling. Our tech stack • Backend: Go, Postgres, Kubernetes, gRPC • Observability: Prometheus, Grafana • CI/CD: GitHub Actions • General: GitHub, Slack, Discord, Notion About Coder Coder is the leading platform for AI development Infrastructure, enabling enterprises to securely run human and AI-driven development workflows in consistent, governed environments. Coder provides self-hosted, agent-ready workspaces that unify developer productivity and platform governance. With Coder, enterprises can confidently evolve from human-only development to AI-assisted and autonomous workflows, without sacrificing security, compliance, or performance. Learn more at coder.com.
