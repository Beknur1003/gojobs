Join us redefine what’s next for you. AI-Assisted Software Engineering Skills • Effective use of AI coding assistants and productivity tools such as:GitHub Copilot Microsoft Copilot AI-assisted code review tools • Experience applying Generative AI for:Code generation Unit test generation Documentation creation Root cause analysis Operational troubleshooting • Understanding of:LLM concepts and prompt engineering AI-driven software development workflows AI-assisted DevOps and automation practices Engineering Excellence • Software testing methodologies, including unit, integration, system, regression, and automation testing. • Strong debugging, performance analysis, and troubleshooting skills. • Excellent analytical and problem-solving capabilities. • Strong written and verbal communication skills with the ability to explain technical designs, architecture decisions, and trade-offs to engineering and leadership teams. • Ability to work effectively in global, cross-functional, and open-source collaboration environments.
