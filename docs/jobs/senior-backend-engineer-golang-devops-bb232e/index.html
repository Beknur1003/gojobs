La persona seleccionada participará en el desarrollo de soluciones backend en Go, la optimización de pipelines CI/CD y la implementación de automatizaciones que contribuyan a mejorar la seguridad y fiabilidad de las plataformas. Funciones principales: • Desarrollar y mantener aplicaciones backend utilizando Go (Golang). • Identificar, analizar y solucionar vulnerabilidades en aplicaciones e infraestructuras. • Diseñar, mantener y optimizar pipelines de integración y despliegue continuo mediante GitHub Actions. • Automatizar procesos de infraestructura y operaciones utilizando Ansible. • Colaborar con equipos de desarrollo, operaciones y seguridad para asegurar buenas prácticas de ingeniería. • Participar en revisiones de código y en la definición de estándares técnicos. • Mejorar el rendimiento, la estabilidad y la seguridad de los entornos productivos. Requisitos: • Más de 5 años de experiencia en desarrollo de software. • Experiencia sólida desarrollando aplicaciones con Go (Golang). • Conocimientos y experiencia práctica en entornos DevOps. • Experiencia trabajando con GitHub Actions y procesos CI/CD. • Dominio de Ansible (playbooks, roles e inventarios). • Experiencia avanzada con Git, estrategias de branching y gestión de Pull Requests. • Capacidad para trabajar de forma autónoma en entornos complejos. Se valorará positivamente • Certificaciones oficiales del sector: PMP, PRINCE2, CISM, CISSP o ITIL.
