Responsabilidades • Desarrollar y mantener funcionalidades Backend utilizando Go (Golang). • Desarrollar y mantener funcionalidades Frontend utilizando . • Trabajar con bases de datos MySQL y PostgreSQL. • Desarrollar soluciones siguiendo buenas prácticas de desarrollo. • Implementar pruebas unitarias en las funcionalidades desarrolladas. • Colaborar con el equipo de desarrollo durante todo el ciclo de vida del software.
