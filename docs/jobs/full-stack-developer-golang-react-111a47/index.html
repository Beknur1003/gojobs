We are looking for an experienced Full Stack Developer specializing in Golang and React to join our client's development team. Reporting directly to the Solutions Architect, you will be responsible for building scalable web applications, developing high-performance backend services, integrating third-party APIs, and optimizing system performance. The ideal candidate has strong experience in modern frontend and backend technologies, microservices architecture, database optimization, and secure software development. Key Responsibilities 1. Frontend Development (React) • Design, develop, and maintain modular web applications using React. • Build independent micro front-end components for admin portals, partner dashboards, and other web services. • Ensure seamless integration between frontend components and backend services. 2. Backend Development (Golang) • Design, develop, and maintain secure, scalable, and high-performance backend microservices using Golang. • Build and maintain APIs and backend functionalities to support application requirements. • Ensure efficient communication between distributed services. 3. Database & Performance Optimization • Identify and resolve database bottlenecks and high CPU utilization under heavy concurrent workloads. • Perform database indexing, query optimization, and performance tuning. • Improve application scalability, reliability, and response times. 4. API & Third-Party Integrations • Integrate third-party Video Game Provider (VGP) APIs for retrieving live match results, including games such as Clash Royale and EA FC. • Implement automated Know Your Customer (KYC) identity verification integrations. • Integrate and maintain high-priority push notification services. 5. Security, Architecture & DevOps • Follow secure coding practices and clean architecture principles. • Implement security measures for non-custodial wallet interactions and user state management across microservices and micro frontends. • Assist in maintaining CI/CD pipelines for automated deployments. • Manage regional configuration settings through parameter stores. 6. Technical Documentation • Maintain clear and accurate documentation for API endpoints, micro front-end contracts, and backend architectures. • Collaborate with the Solutions Architect and development team on technical implementation and system improvements. Qualifications • Proven experience as a Full Stack Developer or in a similar software engineering role. • Strong hands-on experience with Golang (Go) for backend development. • Strong proficiency in React.js and modern frontend development. • Experience designing and developing REST APIs and microservices. • Knowledge of micro front-end architecture and modular application development. • Strong understanding of database optimization, indexing, and query performance. • Experience integrating third-party APIs and external services. • Familiarity with CI/CD pipelines and automated deployment processes. • Understanding of application security, clean architecture, and secure coding practices. • Strong troubleshooting, analytical, and problem-solving skills. • Good communication and collaboration skills. Preferred Qualifications • Experience with non-custodial wallets or blockchain-related applications. • Experience integrating gaming APIs or real-time match data. • Familiarity with KYC verification systems and push notification services. • Experience with cloud infrastructure and parameter/configuration management. • Experience handling high-concurrency applications and distributed systems.
