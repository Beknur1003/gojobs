About Job Role : We are seeking a hands-on Full Stack Development Mid-Level/Lead/Manager, with 7 - 15 years of software engineering experience to lead and contribute directly to the architecture, development, deployment, and lifecycle support of scalable cloud-connected applications. This is a player-coach role : the successful candidate will lead a team of engineers while remaining technically hands-on across backend services, web applications, databases, APIs, cloud infrastructure, real-time data pipelines, and production troubleshooting. The role will be central to building highly available digital platforms for remote supervision, configuration, health monitoring, control, telemetry, and event-driven alerting across connected field devices and gateways. Solutions must support secure, low-latency interaction between cloud applications and IoT / edge systems used in fire, life-safety, paging, and emergency communication environments, where reliability, traceability, resilience, and security are critical. Qualifications : - 7 - 15 years of software development experience with substantial full stack, backend, cloud, and distributed-systems responsibility. - Prior experience leading a team of 4 - 5 engineers is strongly preferred. - Bachelor's degree in Computer Science, Information Technology, Electronics, or a related engineering discipline; MTech / MCA or equivalent advanced qualification is an advantage. - Demonstrated player-coach capability : able to lead architecture and people while remaining hands-on in coding, design reviews, debugging, and production problem solving. - Strong experience developing scalable, secure, production-grade applications and services, preferably for connected products, industrial systems, IoT, real-time monitoring. - Strong communication, analytical reasoning, ownership, collaboration, and technical decision-making skills. Tech Stack : - Python backend development - Golang for microservices / performance-sensitive services - React.js - RESTful API design and implementation - Microservices architecture - Database schema design and query optimization - AWS (including EC2, S3, RDS) - Docker / containerization - Security : authentication / authorization using OAuth, JWT, RBAC or equivalent patterns - PostgreSQL - CI/CD and DevOps practices - Apache Kafka / real-time pipelines
