Job#: 3057474 Job Description: MTS Software Engineer 3 Location: Irvine, CA (Hybrid) Role Overview An established organization is seeking a software engineer to contribute to the transition of an existing XML-based Key Server to an object-based architecture supporting certificates, cryptographic keys, tokens, and other protected secrets. The selected candidate will collaborate closely with the cybersecurity team to develop secure, versioned APIs, object models, and robust system integrations. This role involves designing reliable software for distributed environments with intermittent connectivity while maintaining security, compatibility, and operational resilience. Key Responsibilities • Design, modify, and implement software applications from functional and system design specifications. • Code, integrate, test, debug, and refine software to produce secure, high-performing products. • Develop object-based data models for certificates, cryptographic keys, tokens, secrets, metadata, versioning, and lifecycle states. • Build secure, versioned REST and gRPC APIs for object creation, retrieval, updates, and synchronization. • Integrate established encryption, key-wrapping, and secret-management mechanisms. • Prepare and review architecture, interface, design, and requirement documentation. • Implement centralized logging, monitoring, audit trails, and end-to-end traceability for access events. • Support the development and maintenance of software applications related to cybersecurity initiatives. Required Qualifications Education: Bachelor's degree or equivalent in Computer Science, Information Systems, Engineering, or a related field. Experience: Five to ten years of software development experience, including GoLang programming in Linux environments and hands-on experience within cloud infrastructures. Technical Skills: Strong proficiency in object-oriented design, data structures, and secure software development practices. Demonstrated experience designing REST APIs, gRPC services, and networked client-server applications. Experience with structured data formats such as JSON and XML, as well as authentication, authorization, and role-based access control systems. Preferred Qualifications • Experience with cryptographic key management, certificate management, PKI, or secret-management systems. • Working knowledge of AES, RSA, TLS/mTLS, key wrapping, initialization vectors, and related cryptographic concepts. • Experience designing software for API and object versioning, schema evolution, and backward compatibility.
