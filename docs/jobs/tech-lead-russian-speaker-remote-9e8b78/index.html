Job Title: Tech Lead Location: Remote, strictly on New York time (EST/EDT) Job Type: Full-time At Whizz, we are transforming mobility for delivery drivers, breaking down vehicle access and ownership barriers. We are looking for a Tech Lead to own our entire codebase and lead a small engineering team. About the Role As a Tech Lead, you own the architecture and code quality of all Whizz systems: the PHP core and billing, the ERP, the client area, the mobile app and the People platform. You review every change before it reaches production, own the database architecture, and make the team faster with AI tools. The role is hands-on and reports directly to the founder. Responsibilities • Own the architecture and technical roadmap of all Whizz systems. • Review every pull request before merge and keep a clear review standard. • Design and maintain the database architecture across MySQL and PostgreSQL. • Own Docker images, deployments and environments. • Drive AI-assisted development across the team: agent instructions, prompts, rules for reviewing AI-generated code. • Turn product requirements into technical tasks and mentor backend, frontend and mobile developers. • Lead incident response and ship root-cause fixes. Our Stack PHP 8.3 / ProcessWire backend and cron workers on MySQL; ERP and client area on Nuxt 3, Vue 3 and Quasar; Flutter mobile app; People platform on Next.js, React and PostgreSQL. Stripe for payments, Docker and CapRover for deployment, Metabase for reporting, Gogs and GitHub for code. Requirements • 6+ years in backend development, 2+ years leading a team. • Expert in PHP 8 and able to work with all of our code: PHP, TypeScript (Vue / Nuxt, React / Next.js) and Flutter. • Strong database architecture skills: data modelling, migrations and query optimization in MySQL and PostgreSQL. • Docker in production. • Daily use of AI development tools (Claude Code, Cursor, Copilot or similar) and experience writing agent instructions for a team. • Code review as a daily discipline: you catch logic, data-safety and security bugs, not only style. • Experience with Stripe or a similar payment provider and REST API integrations. • Native Russian and fluent English. • Work strictly on New York time (EST/EDT). Nice to Have • Hands-on ProcessWire development. • Flutter development and app store releases. • Subscription billing or fintech experience. • CapRover or another Docker PaaS, CI/CD setup. Benefits • Competitive salary and benefits. • Full ownership of the technical stack and direct access to the founder. • Remote work on a New York schedule. • The chance to be part of an innovative company transforming the transportation industry.
