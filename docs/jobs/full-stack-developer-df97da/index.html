Full Stack Developer

PT Fitx Sehat Bersama West Jakarta, Jakarta опубликовано 22 октября 2026

Офис Контракт / B2B

FITX GYM berkomitmen untuk memberikan akses kebugaran 24 jam dengan fasilitas lengkap dan harga yang bersaing, dengan slogan kami 'Extend Your Limit'. FITX GYM juga menawarkan berbagai kelas kebugaran yang populer, seperti Pilates Reformer, dan berbagai kelas di X Studio seperti Muay Thai, Boxing, Yoga, TRX, Zumba, serta Aerobik. Saat ini FITX GYM membuka peluang untuk bergabung sebagai seorang Full-Stack Mobile Developer yang kompeten, mandiri, dan berpengalaman untuk memimpin pembuatan serta pengembangan aplikasi mobile kami dari nol. Karena Anda akan menjadi satu-satunya developer di tahap awal ini, Anda akan memegang kendali penuh atas arsitektur backend, manajemen database, integrasi API, hingga implementasi antarmuka (frontend) di platform Android dan iOS. Tanggung Jawab Utama • Merancang dan membangun arsitektur aplikasi mobile yang aman, cepat, dan mudah dikembangkan (scalable) dari awal. • Mengembangkan aplikasi mobile cross-platform (Android & iOS) menggunakan Flutter atau React Native. • Merancang dan mengelola arsitektur server, database, dan API (RESTful/GraphQL) di sisi backend. • Mengubah aset desain UI/UX menjadi kode responsif dengan performa tinggi. • Melakukan pengujian mandiri (testing/QA) untuk memastikan aplikasi bebas dari bug sebelum dirilis. • Mengelola proses deployment dan perilisan aplikasi ke Google Play Store dan Apple App Store. Kualifikasi • Mobile Frontend: Menguasai framework Flutter (Dart) ATAU React Native (JavaScript/TypeScript) dengan sangat baik. • Backend & API: Pengalaman membangun backend menggunakan Node.js (Express/NestJS), Golang, atau Python, serta mahir dalam pembuatan RESTful API. • Database: Menguasai database relasional seperti PostgreSQL / MySQL maupun non-relasional seperti MongoDB / Redis. • Cloud & DevOps: Pengalaman menggunakan layanan cloud seperti AWS, Google Cloud Platform (GCP), atau Firebase (Firestore, Authentication, Push Notifications). • Version Control: Mahir menggunakan Git (GitHub / GitLab). • Third-Party Integration: Berpengalaman mengintegrasikan API pihak ketiga (misalnya: Payment Gateway, Google Maps API, atau SMS/Email Gateway). • Pengalaman kerja minimal 3 - 5 tahun sebagai Full-Stack Developer atau Mobile Developer. • Wajib memiliki portofolio berupa aplikasi mobile yang sudah sukses dirilis dan aktif di Google Play Store atau Apple App Store (harap sertakan tautan/link di CV Anda). • Memiliki pengalaman membangun produk digital atau aplikasi dari tahap awal (from scratch / zero). • Memiliki kemampuan problem-solving yang kuat dan mampu bekerja secara mandiri dengan pengawasan minimal. • Memiliki pemahaman yang baik tentang keamanan data (data security) dan optimasi performa aplikasi.
