We are looking for a skilled and motivated Full Stack Developer with hands-on experience in frontend development using Angular and backend development using Golang. The ideal candidate should have a strong understanding of building scalable, responsive, and high-performance web applications, preferably in the trading or fintech domain. The candidate will be responsible for developing and maintaining end-to-end applications, integrating frontend interfaces with backend services, and contributing to scalable, real-time trading platforms Key Responsibilities : Frontend Development : • Design, develop, and maintain responsive web applications using Angular 15+ and TypeScript. • Build interactive frontend features for trading platforms, including order placement, portfolio tracking, market data display, and analytics. • Develop reusable UI components using Angular Material. • Integrate RESTful APIs with backend services for seamless application functionality. • Implement real-time market data streaming and updates using WebSocket connections. • Develop interactive trading charts and financial data visualizations using the TradingView charting library. • Implement JWT-based authentication and secure user sessions. • Optimize frontend performance, application loading times, and user experience. • Ensure cross-browser compatibility and responsive design across desktop and mobile browsers. Backend Development : • Design, develop, and maintain robust backend APIs and microservices using Golang (Go), primarily with the GoFiber framework. • Develop scalable backend services supporting trading operations, including order management, execution, portfolio tracking, and analytics. • Work with microservices architecture to build reliable, maintainable, and high-performance applications. • Integrate message brokers such as Kafka and NATS for event-driven architecture and real-time data processing. • Design, develop, and optimize database schemas and queries using PostgreSQL, MongoDB, and Redis. • Work with Python using Django and/or FastAPI for backend services wherever required. • Implement RESTful APIs and ensure efficient communication between frontend and backend systems. • Work with Docker for application containerization and deployment. • Understand and work with Nginx for reverse proxy and load balancing. Required Skills & Qualifications Technical Skills: • 1 5 years of professional experience in full stack software development. • Strong proficiency in Angular 15+, TypeScript, and JavaScript (ES6+). • Strong hands-on experience with Golang (Go) and the GoFiber framework. • Good understanding of frontend technologies, including HTML5, CSS3, and responsive web design. • Experience with Angular Services, Angular Material, and reusable component development. • Hands-on experience with RESTful API development and integration. • Knowledge of WebSocket communication and real-time data streaming. • Experience with JWT-based authentication and authorization. • Understanding of microservices architecture and distributed systems. • Experience with PostgreSQL, MongoDB, and Redis. • Familiarity with Kafka and NATS message brokers. • Working knowledge of Python with Django and/or FastAPI is an added advantage. • Experience with Docker, Nginx, and Git version control (Bitbucket workflow). • Knowledge of application performance optimization and frontend/backend security best practices. • Experience with TradingView charting library will be an added advantage. • Prior experience in the trading or fintech domain is preferred. Educational Qualification • B.Tech in Computer Science, Information Technology, or a related field (or higher).
