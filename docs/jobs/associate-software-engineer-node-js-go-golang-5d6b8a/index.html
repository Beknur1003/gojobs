Concept Solutions, LLC (CS) is seeking an Associate Software Engineer – Node.js / Go (Golang) to support a mission-critical application modernization and sustainment program for a Department of War (DoW) customer. In this role, you will collaborate with experienced software engineers to develop, enhance, and maintain enterprise web applications that support critical federal operations. This is an excellent opportunity for an early-career developer to expand their technical expertise in Node.js, Go, and modern web technologies while contributing to a collaborative Agile development environment. • Troubleshoot and resolve software defects in web applications using React front ends and Node.js and Go backend services under the guidance of senior engineers. • Develop, execute, and maintain automated tests to improve application quality, functionality, and reliability. • Participate in software patching, maintenance cycles, and application releases. • Collaborate with senior engineers and development team members to support ongoing application modernization and sustainment activities. • Transition into the team's on-call support rotation following onboarding and training.
