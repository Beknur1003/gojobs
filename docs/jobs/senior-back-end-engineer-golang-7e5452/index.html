Senior Back End Engineer (Golang)

REW Technology опубликовано 14 октября 2026

Go — основной язык Senior
KafkaAWSAI/LLM
We are looking for a Senior Go Engineer to develop and maintain an enterprise workflow orchestration platform for a major network infrastructure provider. You will work on Go services, APIs and integrations running on AWS, with Temporal for durable workflows and AI agents supporting specification, implementation and testing. This is a hands-on role with responsibility for engineering quality and the opportunity to take on broader technical leadership as the engagement evolves. Technology Environment • Go (Golang) backend services and a modular, distributed architecture. • Temporal and Temporal Cloud for long-running workflows and task execution. • AWS infrastructure and Amazon Aurora, with SQL-based persistence and Go Migrate for schema migrations. • An API-driven platform using JSON contracts, including TM Forum Open APIs. • API integrations and Apache Kafka for asynchronous messaging and status updates. • GitHub, pull-request reviews, automated tests and repository-defined AI skills. • Component and workflow tests, plus integration tests with programmable downstream stubs. Responsibilities • Develop and maintain Go services, APIs and reusable platform components. • Build Temporal workflows and reusable tasks using established components and engineering conventions. • Work with architects to clarify requirements and translate them into specifications and testable acceptance criteria. • Implement API and messaging integrations, including payload validation, asynchronous completion and failure handling. • Write and maintain automated tests covering component behavior, workflow transitions and integration scenarios. • Review AI-generated specifications, code, tests and schema changes for correctness, maintainability and consistency with requirements. • Investigate issues across workflows, integrations, databases and cloud services using logs, metrics and execution history. • Assess the impact of changes to shared components and coordinate releases and database migrations with platform engineers. • Keep specifications and documentation aligned with implementation, share knowledge, review pull requests and mentor other engineers. Required Experience • Strong professional Go experience, including concurrency, error handling and maintainable service design. • Experience developing distributed services, APIs and asynchronous or event-driven applications. • Understanding of workflow state, retries, timeouts, idempotency and failure recovery. • Practical SQL and relational database experience, including schema changes and migrations. • Experience with automated testing, including component and integration tests using mocks or stubs. • Strong debugging and code-review skills, with the ability to navigate a large existing codebase. • Experience working in cloud environments and using Git, pull requests and automated build and test checks. • Sound engineering judgment, clear communication and the ability to resolve unclear requirements with architects and client teams. • Willingness to use AI tools in daily development and take responsibility for validating their output. Engineering Workflow Development starts with a clear requirement and a reviewed specification. Engineers use AI agents and repository-defined skills to implement changes using approved building blocks. Automated tests and a separate AI review support the process; engineers validate the specification, implementation, tests, schema changes and documentation before approval. You should be comfortable directing AI agents, identifying incorrect assumptions, providing precise feedback and debugging generated code. Experience with a particular AI product is helpful but is not required. Preferred Experience • Temporal or another durable workflow platform, including workflows, activities and workers. • AWS, Amazon Aurora and Kafka. • Specification-driven development and AI tools such as Claude Code, OpenCode or GitHub Copilot. • Standards-based APIs such as TM Forum Open APIs; telecom experience is helpful but not required. • Taking ownership of an existing platform, mentoring engineers or leading a technical workstream. Working Hours Regular collaboration with a U.S.-based client team requires overlap with U.S. Eastern Time, including availability until at least 7:00 PM CET/CEST on regular working days. Occasional later meetings may be required for project needs, knowledge transfer, production issues or key client discussions. Why Work With Us? Our Culture • Open communication and a focus on psychological safety • Recognition of achievements and individual contributions • Collaboration across multicultural and distributed teams • Less bureaucracy and greater focus on outcomes • Opportunity to work with modern AI-assisted engineering practices • Direct involvement in technically challenging enterprise platforms Hiring Process • Intro Call • Technical Interview • Manager Interview • Client Technical \ Manager Interview • Pre-offer Stage + Reference Check, if requested • Official Offer
