Ready to join a mission that matters? The future of cybersecurity starts with you. About the Role: This is a Cloud/Backend development position in the Falcon Exposure Management team. The Exposure Management team focuses on continuous assessment of security configurations and vulnerability landscapes across cloud and hybrid environments in near real time. This involves understanding security misconfigurations, compliance frameworks, vulnerability data sources, and how adversaries may exploit these weaknesses to compromise enterprise environments. This person will be required to build solutions for configuration and vulnerability data sources, gather and normalize assessment data, analyze security posture gaps, assess risk criticality, and automate remediation workflows. They will also be responsible for troubleshooting issues with current assessment data and making platform enhancements. What You'll Do: • Engineering efforts from rapid prototypes to developing large-scale application services for configuration assessment and vulnerability management content • Work with security researchers and vulnerability analysts to troubleshoot time-sensitive production issues related to configuration drift and vulnerability detection • Extensive use of Golang or Java, AWS/GCP cloud services, and relational and distributed databases • Ensure security, accuracy, and efficacy of configuration assessment data and vulnerability intelligence • Backend engineering systems and process automation for configuration compliance and vulnerability management workflows • Build vulnerability and configuration tracking capabilities by conducting analysis on asset configurations, vulnerability data, and compliance benchmarks to provide reviewed content to the platform team for product efficacy • Interact and integrate with platform teams and product teams • Constantly re-engineering to improve architecture, risk scoring models, user experience, performance and stability What You'll Need: • Solid work experience in Golang or Java development • Strong database skills with relational databases and distributed databases like Cassandra, Redis & ElasticSearch • Exposure to AWS/GCP cloud services and cloud security assessment tools Experience delivering high quality & tested code • Understanding of cybersecurity fundamentals, vulnerability management, and security configuration assessment • Knowledge of security configuration frameworks (CIS Benchmarks, NIST CSF, SOC 2, etc.) • Ability to communicate effectively at all levels of an organization • Team collaboration skills and ability to work in a global, distributed team • The skills to meet commitments on
