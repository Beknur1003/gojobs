About Heidi Systems Heidi Systems is building the data infrastructure layer for buildings and energy. We help property owners and managers digitize metering, consumption data, reporting and billing in one of Europe's largest and most outdated infrastructure markets. We're hiring a senior engineer to own DevOps and data infrastructure. You'll be responsible for how our systems get built, deployed, monitored and kept running. And you'll make the architecture calls together with the founders. Tasks What you'll own • Our deployment pipeline and production environment, end to end (CI/CD, containers, servers) • Monitoring, alerting and incident response, so problems show up before customers notice them • Data ingestion and processing for meter, gateway and building data, including MQTT/IoT streams • Database operations: Postgres setup, clustering, backups, performance • Backend services in Go and TypeScript • Validating and transforming high-volume device and consumption data • Debugging real-world issues across gateways, MQTT, APIs and databases • Internal tooling that automates our operations • Architecture decisions with the founding team, plus the engineering standards the rest of the team builds on Requirements Who we're looking for You've run production infrastructure before and you know what breaks at 2am. You make decisions on your own, explain the trade-offs, and take responsibility for the outcome. You're a great fit if you: • Have several years of hands-on experience in a DevOps, SRE, platform or backend role with production responsibility • Have built and maintained CI/CD pipelines and containerized deployments yourself • Write strong Go and/or TypeScript • Have run Postgres (or a comparable relational database) in production • Have set up monitoring and logging and handled real incidents • Can design a system from scratch and defend the choices Bonus: MQTT, IoT or time-series data, bare-metal/VPS setups (we run on Hetzner), experience in energy or real estate. Tech stack • Go, TypeScript • Postgres • Docker, GitHub Actions, GHCR • Hetzner, Caddy • MQTT / IoT data streams • YAML, TOML Benefits Why join us • You own the infrastructure of a product that's live with customers • Direct line to the founders, short decision paths • Your setup becomes the standard: you define how we build and run things • Real hardware, real data: meters, gateways, buildings • A big, outdated market that's only starting to digitize Location Living in or relocating to Berlin is required. Start as soon as possible. Full-time. How to apply Send us a short note, your CV and GitHub profile.
