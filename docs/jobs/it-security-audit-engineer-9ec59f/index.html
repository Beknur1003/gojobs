Релокация

Our client is a leading e-wallet service provider. It is seeking like-minded individuals to consider the position IT Security Audit Engineer, based in Dubai. Attractive relocation package will be offered to the right candidate. ﻿Responsibilities: • Comprehend the security offerings provided by prevalent security manufacturers in the market. • Recommend the most cost-effective third-party security solutions tailored to the company's specific needs. • Possess familiarity with public cloud services like AWS and provide guidance to the development team for secure utilization of diverse cloud products. • Conduct code security audits and possess the capability to design audit report systems, including routine evaluation of AWS cloud resource operations and regular dispatching of audit reports. • Demonstrate practical expertise in zero-trust principles and managing host intrusion scenarios. • Possess some exposure to common attack methodologies and strategies for preventive measures. Key Requirements: • Proficiency in common operational and maintenance CI/CD tools. • Experience in security practices concerning Kubernetes (k8s) and container technologies. • Hands-on experience with deploying and mitigating risks associated with Web Application Firewalls (WAFs) in cloud environments. • Familiarity with widely used programming languages such as Java, Python, Golang, among others. ﻿﻿Interested candidates are invited to send in your resume in MS Word Format* stating your past work experience, reasons for each leave, past and expected remuneration.
