Go Developer (Middle) Salary range: $500 – $1500 Location: Ukraine (Remote) Employment type: Full-time Experience: 1+ year A small, high-performing team is looking for a Middle Go Developer to support an experienced Senior Developer. Our project is growing, and the workload is increasing, so we are seeking a reliable specialist ready to dive into backend service development, write clean code, and grow alongside the team. What you will be doing: • Developing and supporting microservices in Go • Designing and optimizing REST APIs / gRPC • Participating in architectural discussions with the Senior Engineer and developing standalone modules • Writing unit and integration tests • Optimizing database performance and participating in Code Reviews Our expectations (Must-have): • 1–2 years of commercial software development experience with Go • Solid understanding of Concurrency (goroutines, channels, context) • Experience with PostgreSQL / MySQL (writing and optimizing SQL queries) • Good grasp of REST API and gRPC / Protocol Buffers • Experience with Docker and Git • Basic knowledge of NoSQL (Redis / Memcached) • Ability to use AI tools for code assistance and AI agents for automating routine tasks to boost personal productivity Nice to have: • Experience with message brokers (RabbitMQ / Kafka / NATS) • Understanding the basics of Kubernetes and CI/CD • Basic Linux skills What we offer: • Fully remote work setup • 8-hour working day (flexible schedule can be discussed after the interview) • Working closely with a strong Senior Go Developer (we expect self-reliance: before asking a question, you try to find the answer on your own first, but if stuck - help is always nearby) • Minimal bureaucracy and fast decision-making processes • Timely payouts We look forward to receiving your CV! Please note: A short technical task and a brief video introduction are required prior to the interview.
