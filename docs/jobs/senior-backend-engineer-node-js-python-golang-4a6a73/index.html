Senior Backend Engineer – Node.js / Python / Golang

Evnek Bengaluru; Bengaluru опубликовано 17 ноября 2026

Офис Senior Полная занятость

Job Summary We are looking for a skilled and hands-on Senior Backend Engineer with 3-5 years of relevant backend development experience to join our Implementation Team in Bengaluru. The ideal candidate should have strong expertise in at least one of Node.js, Python, or Golang, along with hands-on experience in backend development, REST API integrations, microservices architecture, and relational databases. The candidate will be responsible for designing, developing, customizing, integrating, deploying, and maintaining scalable backend services and enterprise applications. The role involves developing and consuming RESTful APIs, implementing authentication and authorization mechanisms, handling data validation and error management, designing database schemas, writing and optimizing SQL queries, and building secure and high-performance backend solutions. The candidate should have practical knowledge of PostgreSQL or similar relational databases, API integration patterns, asynchronous programming, object-oriented programming, and backend application architecture. Familiarity with AWS or other cloud platforms, Git, CI/CD pipelines, automated testing, application deployment, monitoring, and production troubleshooting is expected. The candidate will also collaborate with Frontend, QA, Product, DevOps, and Customer Success teams to ensure successful implementation and deployment. Strong problem-solving skills, independent technical ownership, debugging capabilities, and effective communication with customer stakeholders are essential. Immediate joiners are preferred.
