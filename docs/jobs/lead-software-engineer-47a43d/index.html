We are seeking an experienced Lead Software Engineer to oversee the design, development, and operation of distributed application architectures powering mission-critical APIs and data services in a cloud-hosted environment, preferably AWS. In this role, you'll combine hands-on technical leadership with strategic oversight to build secure, scalable, and resilient backend systems using TypeScript and GoLang. You'll drive API integration patterns across GraphQL (including Apollo Router) and REST architectures, enable secure integrations through API gateways with robust identity and authorization management, and lead data integration workflows that load and synchronize data with enterprise data warehouses such as Snowflake. Key Responsibilities: • Lead service decomposition strategies for GraphQL subgraphs and backend APIs across synchronous (serverless) and asynchronous (containerized) workloads. • Define resiliency patterns (health modeling, DLQs, autoscaling) and observability strategies (distributed tracing, structured logging, dashboards). • Ensure security-by-design principles, including TLS everywhere, OIDC/JWT authentication, least-privilege IAM, and encryption policies. • Oversee compute stacks (serverless functions, container orchestration) and networking (private subnets, secure ingress, VPC endpoints). • Manage IaC deployments using CDK, Terraform, or equivalent tools while enforcing compliance and auditability across environments. • Drive CI/CD best practices for zero-downtime deployments, blue/green rollouts, and automated health checks. • Guide teams in building GraphQL subgraphs with Apollo Server (TypeScript/Node), including resolver design, schema evolution, and validation directives. • Lead development of Golang-based services for high-throughput APIs, webhooks, and background processing with robust concurrency and context management. • Implement structured logging, error handling, and observability across all services. • Design and optimize data models for relational stores (PostgreSQL or equivalent) while enforcing encryption and backup strategies. • Implement ORM-based persistence layers using GORM, PrismaORM, or TypeORM for maintainable and secure data access. • Architect messaging workflows with queues, event buses, and orchestration frameworks for reliable, at-least-once delivery. • Mentor engineers and foster a culture of technical excellence aligned with business objectives. • Collaborate with product, compliance, and security teams to meet regulatory and operational requirements. • Drive delivery of secure, compliant, and scalable services that meet latency/error SLOs and improve developer experience. • US Citizenship or Permanent Residence Status Required. • Expert-level TypeScript and GoLang, with strong understanding of Node.js and Go runtime patterns; hands-on experience with Apollo Server (GraphQL), Express, and RESTful API design. • Experience with GORM (Go), PrismaORM or TypeORM (TypeScript), and relational schema design. • Proficiency in at least one major cloud provider (AWS/GCP/Azure); experience with serverless (Lambda/Functions), container orchestration (ECS/Fargate, Kubernetes), and IaC (CDK/Terraform). • Strong background in TLS, OIDC/JWT, IAM/RBAC, and KMS or equivalent encryption services. • Experience with distributed tracing (X-Ray/OpenTelemetry), structured logging, and metrics/alerting pipelines; familiarity with SQS/EventBridge or equivalents (Pub/Sub, Service Bus), DLQs, and workflow engines. • Experience with automated pipelines using GitHub Actions, Jenkins, or equivalent tools. Preferred Qualifications: • Experience with GraphQL federation and schema governance. • Familiarity with multi-cloud strategies and cost optimization. • Background in high-volume data processing and event-driven architecture.
