Key Responsibilities • Develop AI agents and enterprise automations using the Moveworks platform. • Design and implement integrations between ServiceNow and enterprise AI solutions. • Build and maintain backend components that support AI-driven applications. • Configure ServiceNow workflows and platform capabilities to support automation. • Troubleshoot technical issues and optimize integrations across enterprise systems. • Collaborate with customers and global delivery teams throughout implementation projects. • Contribute to technical innovation and continuous improvement of AI solutions. • Create technical documentation to support implementation and maintenance.
