Junior+ AI Backend Developer | Go от 1,2к$ Удалённо Ищем разработчика, который умеет писать сильный backend руками и уже ускоряет свою работу с помощью AI-агентов. Мы развиваем собственную AI-инфраструктуру для автоматизации процессов в AdTech и Telegram. Система берёт на себя задачи, которые раньше требовали большой команды операторов: обработку данных, взаимодействие с внешними сервисами, мониторинг и автоматизацию внутренних процессов. Задачи: — Разрабатывать backend на Go; — Подключать API, трекеры, аналитику и платёжные сервисы; — Автоматизировать внутренние процессы; — Быстро собирать MVP и проверять гипотезы; — Работать с PostgreSQL / MySQL / Redis; — Использовать Claude Code, Codex, Cursor, Aider и другие coding agents; — Ревьюить и улучшать AI-generated код; — Работать с Docker, Linux, Git и production-средой. 🔹 Важно! — Go — от 1 года коммерческого опыта; — goroutines, channels, concurrency, production-сервисы; — REST API, webhooks, OAuth; — Уверенный SQL; — Git без постоянного поиска базовых команд; — Docker и Linux; — Реальный ежедневный опыт работы с AI coding agents. ❗️ Не подойдёт, если: — Вы начали программировать только благодаря ChatGPT; — У вас нет реального production-опыта; — AI для вас — только браузерный чат; — Базовые темы backend, БД, HTTP и сетей вызывают сложности. 🔹 Что предлагаем: — Полная удалёнка; — ПН–ПТ, 10:00–19:00 МСК; — $1200-1800 + дальнейший рост; — Оплачиваемая стажировка до 2 недель; — Выплаты 1 и 16 числа в USDT BEP-20; — Все AI-инструменты оплачиваем. Ищем человека, который сочетает сильную техническую базу, скорость и умение эффективно работать вместе с AI. ❗️❗️❗️ Без трудоустройства!
