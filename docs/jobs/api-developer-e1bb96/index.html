Junior to Mid-Level API Software Engineer Job Description Join a growing technology team as a Junior to Mid-Level API Software Engineer, where you will design, develop, test, and support APIs that power secure integrations across digital banking platforms, internal applications, and third-party services. You will work on mission-critical solutions, collaborating closely with architects, developers, business stakeholders, and technology partners to deliver secure, scalable, and high-performing integrations. While experience with Apigee and Golang is preferred, candidates with strong API development experience using other modern technologies are encouraged to apply. Responsibilities • Design, develop, test, deploy, and maintain RESTful APIs and microservices that support digital banking and internal systems. • Collaborate with solution architects and development teams to implement API-driven solutions that meet business and technical requirements. • Develop and maintain clear, accurate API documentation using OpenAPI/Swagger standards. • Participate in the full API lifecycle, including design, versioning, monitoring, and ongoing support. • Implement security best practices for APIs, including authentication, authorization, encryption, and related security controls. • Troubleshoot and resolve API performance, reliability, and integration issues in a timely manner. • Contribute to CI/CD pipelines and automated deployment processes to improve delivery speed and quality. • Perform code reviews to ensure code quality, maintainability, and adherence to standards. • Participate in Agile development activities such as sprint planning, daily stand-ups, and retrospectives. • Work closely with business and technical teams to gather, clarify, and refine requirements for API solutions. • Maintain compliance with banking, security, and regulatory standards throughout the development and deployment process. Essential Skills • Bachelor's degree in Computer Science, Information Technology, Software Engineering, or a related field, or equivalent experience. • 25 years of professional software development experience. • Experience designing and developing REST APIs and web services. • Proficiency in one or more programming languages such as Go (Golang preferred), Java, C#, Python, or Node.js/JavaScript. • Experience with Apigee API Management Platform. • Experience developing applications or microservices in Golang. • Experience with cloud platforms such as Azure, AWS, or Google Cloud Platform. • Knowledge of containerization technologies such as Docker and Kubernetes. • Experience with API gateways, service meshes, or integration platforms. • Exposure to CI/CD tools such as Azure DevOps, GitHub Actions, or similar platforms. • Understanding of API concepts, including REST, JSON, OAuth, JWT, and API security best practices. • Experience working with source control systems such as Git. • Familiarity with Agile/Scrum development methodologies. • Strong analytical, troubleshooting, and problem-solving skills. • Excellent communication and collaboration abilities. • Experience within financial services, banking, or other regulated industries. Additional Skills and Qualifications • Hands-on experience with Java and JavaScript in API or web development contexts. • Experience working in Agile environments and contributing to iterative delivery. • Experience in cloud-based integration projects or large-scale digital transformation initiatives. • Ability to work effectively in cross-functional teams that include architects, developers, and business stakeholders. • Comfort working in hybrid work arrangements that blend on-site and remote collaboration. • Experience with mission-critical systems where reliability, performance, and security are paramount. Work Environment This role is based in Honolulu, HI, within a hybrid work environment that combines on-site collaboration with remote flexibility. You will work on a major integration project in a financial services setting, using modern technologies such as Apigee, Golang, RESTful APIs, cloud platforms (Azure, AWS, or Google Cloud Platform), Docker, Kubernetes, and CI/CD tools like Azure DevOps and GitHub Actions. The team operates using Agile methodologies, emphasizing regular communication, iterative delivery, and strong collaboration. The work focuses on mission-critical banking integrations, requiring attention to security, compliance, and reliability, while offering a supportive environment that encourages learning and knowledge sharing.
