РАБОЧИЕ ЗАДАЧИ: • Разработка нового и доработка действующего функционала внутренней CRM-системы Битрикс24: создание пользовательских модулей, внесение изменений в уже разработанные компоненты системы, добавление новых полей, изменение логики работы, разработка и настройка отчетов, дашбордов и аналитических инструментов для анализа данных и поддержки в принятии управленческих решений. • Разработка и настройка бизнес-процессов в Битрикс24: проектирование бизнес-процессов, настройка автоматических действий (например, уведомления, отправка писем, изменение статусов сделок и т.д.), оптимизация существующих процессов. • Настройка интеграций Битрикс24 с внешними сервисами: настройка обмена данными между Битрикс24 и 1С, интеграция с Microsoft Outlook, мессенджерами и т.д.). • Техническая поддержка пользователей, включая решение технических проблем, проведение регулярного обновления системы до актуальных версий, устранение багов.
