В Digital Spirit мы создаём современные и сложные программные решения для лидеров рынка из различных отраслей экономики. Digital Spirit — это команда экспертов в различных областях: Backend (Java, Golang) и Frontend (Angular, Vue.js), системный и бизнес-анализ, тестирование, дизайн, DevOps. Ищем специалиста в качестве усиления состава команды в проект крупного банка. О проекте. Проект представляет собой разработку Desktop-приложения для операционной системы Windows, которое позволит сотрудникам банковских отделений устанавливать и обновлять приложения iOS на устройствах клиентов. Приложение должно интегрироваться с внутренними системами банка и устанавливать приложение с помощью open-source библиотеки libimobiledevice. Связь Go с iOS: Go будет использоваться для создания Desktop-приложения, обеспечивая логику работы и взаимодействие с внутренними API банка. Что касается взаимодействия с iOS устройством, используется вспомогательная библиотека libimobiledevice для операции установки приложения на устройство клиента Обязанности: • Разработка и поддержка Desktop-приложения для Windows написанного на Go с использованием UI-фреймворка Fyne. Реализация функционала по установке приложений iOS на устройства в отделениях банка. • Интеграция приложения с банковскими системами и API. Сотрудничество с командой разработчиков, QA-инженерами, дизайнерами и аналитиками для достижения целей проекта. • Оптимизация производительности и улучшение пользовательского опыта. • Опыт работы с Go не менее 2-х лет. • Понимание принципов разработки Desktop-приложений под Windows. • Опыт работы с UI-фреймворком Fyne или готовность его изучить. Опыт интеграции с RESTful API и веб-сервисами. • Владение системами контроля версий, например, Git. Желательно: • Знание основ работы с операционной системой iOS и её экосистемой для реализации функции установки приложений. • Опыт написания unit и интеграционных тестов. • В команде 5-7 специалистов, включая разработчиков, QA-инженеров и дизайнера. • Гибкий график работы, возможность удаленной работы.
