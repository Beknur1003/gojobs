Senior Go Backend Engineer

опубликовано 12 октября 2026

Go — основной язык Senior
PostgreSQLRedisNATSKubernetesGCPPrometheusGrafanaLinuxRustBlockchainFinTech
We are building a distributed GPU-compute marketplace. Buyers launch GPU workloads and inference deployments. Provider nodes run workloads through a Go control plane and a Linux-based Rust agent. We are hiring a Senior Go Backend Engineer to own correctness-critical backend systems: job lifecycle, placement, billing, provider operations, and API contracts. You will work directly with the CTO on a system where transactional correctness matters. A duplicate request, failed worker, agent restart, or incomplete usage record must not create free compute, double-charge a buyer, or release a GPU while work is still running. What you will own - Go services and APIs for buyers, providers, operators, and agents. - PostgreSQL data models, migrations, transactions, locking, and query performance. - Job lifecycle and placement across GPU provider nodes. - Prepaid billing, reservations, settlement, refunds, reconciliation, and audit records. - Background workers, idempotent retries, and recovery after partial failure. - Secure agent APIs using mTLS and signed short-lived credentials. - Tests that prove correctness under retries, concurrent requests, and failure cases. - Clear API contracts, OpenAPI documentation, metrics, and operational diagnostics. Our stack - Go backend services. - PostgreSQL, Redis, NATS, and JetStream. - Rust agent on Linux GPU hosts. - Kubernetes, Prometheus, Grafana, and GCP. - Next.js frontend. What we need - 5+ years of backend engineering experience. - Strong production Go experience. - Strong PostgreSQL experience, including transactions, indexes, migrations, and query analysis. - Experience building distributed or event-driven systems. - Experience designing idempotent APIs and handling retries or partial failures. - Strong testing discipline, including integration tests. - Experience with Redis, message queues, or NATS. - Ability to reason clearly about correctness, security, and money movement. - Clear written communication and ownership from design through production support. Nice to have - Payments, billing, ledger, marketplace, fintech, or accounting-system experience. - Kubernetes, GCP, and production observability experience. - mTLS, cryptography, signed credentials, or security-sensitive APIs. - Rust, Linux, GPU infrastructure, or distributed-systems operations. This is a hands-on senior role. You will ship production Go code, review critical changes, investigate failures, and improve the system so that it stays correct under real production conditions.
