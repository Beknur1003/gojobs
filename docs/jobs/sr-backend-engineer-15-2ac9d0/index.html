尋求對 Cloud Native 架構與分散式系統具備熱情與實務經驗的後端工程師。 此職位將參與我們以 Kubernetes(K8s) 為基礎所打造的管理平台的核心後端模組設計與開發工作。除了實作 API 與微服務架構，也需協助團隊導入技術標準、最佳實踐，並與前端、產品與 DevOps 團隊密切合作，實現具備高可用性（HA）、可觀測性（Observability）與可維運性（Operability）的現代化平台。 團隊採用敏捷式開發流程，重視跨部門溝通、持續交付與快速迭代。後端工程師將在此環境中發揮技術專業，參與產品設計與落地實作。 【工作內容】 • 設計與實作平台後端模組，包括 API Server、Controller、Scheduler、Resource Manager 等關鍵元件 • 介接 Kubernetes API Server，開發各類自動化管理模組與整合機制（如 CRD、Operator） • 與前端、DevOps、產品團隊密切合作，推進功能交付、效能優化與使用者體驗 • 導入並整合合適的 Open Source 套件（如 etcd、Prometheus 等） • 撰寫並維護單元測試、整合測試，並持續優化 CI/CD 流程 • 撰寫技術設計文件、API 文件與模組開發規範，推動知識共享 • 協助建置並優化高可用性、可觀測性與易維運的系統架構 • 參與 Sprint 規劃、每日站會、任務拆解與回顧等敏捷流程 【必要條件】 • 具備EVPN-VxLAN • 具備 Golang (以 Gin 為主) 實務經驗，如熟悉其他後端語言，如 Python / Rust 等亦歡迎應徵 • 熟悉微服務架構與 API 設計（RESTful / gRPC） • 熟悉 Kubernetes 架構與核心機制（有 CRD、Controller、Operator 開發經驗尤佳） • 熟悉容器技術（Docker）、Git 操作與 CI/CD 自動化工具鏈 • 有基本 Linux 系統操作與故障排查能力 • 具備基本的資料結構、演算法與系統設計能力 • 具備敏捷開發經驗，能適應短週期交付與跨職能團隊協作 【加分條件】 • 有微服務架構開發實務經驗 • 有 DevOps、SRE 經驗，熟悉系統穩定性與可觀測性設計（Prometheus, Grafana, Loki, Jaeger 等） • 有使用 Helm、Kustomize 等工具經驗 • 了解 Cloud Native 技術生態系（如 Istio、Envoy、etcd） • 有虛擬化、儲存或網路技術背景（KVM, QEMU, CSI, CNI 等） • 有大型系統設計經驗（high availability, scalability）
