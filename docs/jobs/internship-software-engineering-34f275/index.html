Internship - Software Engineering

Western Digital Petaling Jaya, Selangor, my опубликовано 22 октября 2026

Стажёр
GrafanaPythonAI/LLMFinTech
We are looking for a data engineering intern to support the development of a new internal database system for our HDD System Integration Testing (SIT) team. This role covers applied work across schema design, data ingestion, API interfaces, template generation logic, and reporting dashboards — with exposure to multiple data types including relational, time-series, and vector/knowledge data. Essential Duties and Responsibilities • Assist in database schema design and documentation for an automation system in Performance Test Group (PTG). • Develop and maintain ETL pipelines for data ingestion and transformation workflows. • Build basic API interfaces for data access and integration with existing test infrastructure. • Implement template parameter mapping and generation logic using Jinja2. • Support reporting and dashboarding development for engineering and operational metrics. • Perform data quality checks and validation across structured and unstructured data sources. • Maintain clear documentation for pipelines, schemas, and workflows. • Participate in code reviews and maintain clean, well-documented code. This position is part of our Early Career program at WD. Our Early Career program is designed to support individuals beginning their professional career by providing the foundational training through a structured onboarding, mentorship, and development curriculum. Qualifications REQUIRED • Currently pursuing a Bachelor's degree in Computer Engineering, Computer Science, Software Engineering, Data Engineering, Data Science, or a related field. • Willing to work on-site at our office in Kuala Lumpur. • Expected internship onboarding/start date: January 2027. SKILLS • Solid foundation in SQL and relational database concepts. • Experience with Python for data handling and transformation (pandas / polars a plus). • Familiarity with REST API concepts — consuming endpoints and mapping data. • Basic understanding of ETL pipeline design and data ingestion workflows. • Exposure to Jinja2 or similar templating engines. • Ability to research and solve technical problems independently. • Comfortable working in a command-line environment, including remote access via SSH. • Version control using Git. NICE TO HAVE • Dashboarding tools (e.g., Grafana, Streamlit, or similar). • Exposure to LLM integration or API usage (e.g. building with OpenAI, Ollama, or similar). • Time-series or vector/knowledge data experience. • Go (Golang) programming language exposure.
