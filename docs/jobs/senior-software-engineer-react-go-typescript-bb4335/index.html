Elegir Capgemini significa elegir una empresa donde tendrás la libertad de diseñar tu carrera profesional como desees, con el respaldo y la inspiración de una comunidad colaborativa de colegas en todo el mundo. Aquí podrás reinventar lo que es posible. Únete a nosotros y ayuda a las organizaciones líderes en el mundo a descubrir el valor de la tecnología y construir un mundo más sostenible e inclusivo. Estamos buscando un/a Senior Software Engineer con experiencia en React / Go / TypeScript, para unirse a un proyecto internacional a largo plazo, contribuyendo al desarrollo y evolución de aplicaciones web modernas construidas con React, Go y TypeScript. Trabajarás como parte de un equipo multidisciplinar de ingeniería, ofreciendo funciones orientadas al usuario con un fuerte enfoque en la calidad, escalabilidad, mantenibilidad, seguridad y rendimiento. Este puesto está pensado para un ingeniero que aporte sólida experiencia en frontend, un fuerte juicio técnico y la responsabilidad de las soluciones desde la implementación hasta el despliegue en producción. Más allá del desarrollo de funcionalidades, contribuirás a decisiones técnicas, mejores prácticas de ingeniería y a la mejora continua del producto y la plataforma. Este es un puesto con enfoque frontend. Es obligatorio tener experiencia profesional probada tanto con React y Go (Golang). ¿Cuál será tu rol? • Diseñar, desarrollar y mantener aplicaciones frontend modernas utilizando React y TypeScript. • Ofrecer funciones robustas, escalables y mantenibles orientadas al usuario. • Traduce los requisitos de negocio y de producto en soluciones técnicas. • Crea interfaces de usuario complejas, flujos de trabajo, formularios e integraciones con servicios de backend. • Implementa mecanismos seguros de autenticación y autorización. • Diseña componentes reutilizables y patrones de arquitectura frontend. • Contribuir a discusiones técnicas de diseño y a decisiones arquitectónicas. • Garantizar la calidad del software mediante pruebas, revisiones de código y mejores prácticas de ingeniería. • Trabaja estrechamente con los equipos de Producto, UX/UI, Backend y QA para ofrecer experiencias de usuario de alta calidad. • Apoyar el despliegue de aplicaciones, la monitorización y las iniciativas de mejora continua. • Promover las mejores prácticas relacionadas con el rendimiento, la seguridad, la accesibilidad y la mantenibilidad. Tu perfil Requisitos Básicos: • 10+ años de experiencia profesional en entornos de desarrollo de software. • 5+ años de experiencia profesional desarrollando aplicaciones web con React. • 2+ años de experiencia profesional desarrollando aplicaciones con Go (Golang). • Amplia experiencia práctica con TypeScript. • Habilidades profesionales de comunicación en inglés. Habilidades técnicas • Sólido conocimiento de los ganchos React, la composición de componentes y los patrones de arquitectura reutilizables. • Experiencia en la creación de aplicaciones frontend complejas con interacciones enriquecidas, formularios, validaciones y flujos de trabajo empresariales. • Experiencia integrando y consumiendo APIs REST. • Sólido conocimiento de patrones de gestión de estados y arquitecturas modernas de frontend. • Experiencia con Redux Toolkit, Zustand, React Context, Recoil, TanStack Query o soluciones similares. • Sólido conocimiento de la seguridad frontend, la autenticación y los conceptos de autorización. • Experiencia diseñando y manteniendo pruebas automatizadas utilizando marcos modernos de pruebas frontend. • Experiencia con Vitest, React Testing Library, Happy DOM, Playwright o herramientas similares. • Experiencia práctica con Docker y Kubernetes. • Fuerte compromiso con la calidad del software, la mantenibilidad y la excelencia en ingeniería.
