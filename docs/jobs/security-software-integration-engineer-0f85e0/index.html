Security Software Integration Engineer

SISAP México, Mexico опубликовано 20 ноября 2026

PythonNode.js
🚀 ¡Estamos buscando un Security Software Integration Engineer! En SISAP buscamos un perfil con mentalidad de builder: alguien que no solo haya trabajado con herramientas de ciberseguridad, sino que tenga experiencia desarrollando las integraciones que permiten que diferentes plataformas de seguridad se comuniquen entre sí. 💻 ¿Qué buscamos? Una persona con experiencia sólida en desarrollo de software e integración de sistemas, capaz de escribir código para conectar plataformas mediante APIs, transformar información y automatizar el intercambio de datos dentro de ecosistemas de ciberseguridad. 🔎 Experiencia clave: • Desarrollo con Python, Golang y/o Node.js. • Consumo e integración de REST APIs. • Manejo y transformación de datos en JSON. • Desarrollo de integraciones entre sistemas y plataformas. • Experiencia con webhooks, Regex y pipelines de datos. • Experiencia trabajando dentro de entornos de ciberseguridad. 🛡️ Será muy valorado: • Experiencia con plataformas SIEM/SOAR como Splunk, Microsoft Sentinel o QRadar. • Integraciones relacionadas con Threat Intelligence. • Manejo de IOCs y estándares como STIX/TAXII. • Desarrollo de conectores, parsers, automatizaciones o integraciones personalizadas para herramientas de seguridad. 🎯 El perfil que buscamos Esta posición está orientada a ingeniería y desarrollo. Buscamos a alguien que pueda contarnos: “Yo escribí el código que permitió que estas dos plataformas se conectaran”, no únicamente “yo configuré el conector”. Si has construido integraciones desde cero, consumido APIs y utilizado tus habilidades de desarrollo para resolver necesidades reales dentro de ciberseguridad, queremos conocerte. 💙 ¿Por qué SISAP? En SISAP tendrás la oportunidad de formar parte de una organización especializada en ciberseguridad, trabajando en proyectos donde la tecnología, el desarrollo y la seguridad convergen para resolver retos reales. Aquí podrás: • Trabajar con diferentes tecnologías y ecosistemas de ciberseguridad. • Participar en proyectos de integración con impacto directo en nuestros clientes. • Resolver retos técnicos que requieren desarrollo, automatización y pensamiento de ingeniería. • Continuar fortaleciendo tu experiencia en un entorno especializado en seguridad. • Formar parte de un equipo regional de profesionales apasionados por la tecnología y la ciberseguridad. 📩 ¡Postúlate y conversemos!
