Senior Full-Stack Developer (Gaming Industry) Position: Senior Full-Stack Developer (Full-Time) Company: Adisoft Gaming Co., Ltd. Location: Bang Khen, Bangkok (On-site) Position Overview As a Senior Full-Stack Developer, you will play a pivotal role in our cross-functional teams, driving both backend and frontend engineering. In this senior capacity, you will architect, build, and optimize scalable server-side applications and modern web interfaces using Go (Golang) and Nuxt.js (Vue.js). You will ensure seamless integration, high performance, and security across our game backend services and web platforms, while mentoring team members and advocating engineering best practices. Key Responsibilities • Architecture & End-to-End Development: • Design, build, and maintain high-performance, scalable backend services and APIs using Go (Golang). • Develop responsive, SEO-friendly, and accessible frontend applications using Nuxt.js / Vue.js and TypeScript. • Database & Performance Optimization: • Design, implement, and optimize scalable NoSQL (e.g., Firebase, MongoDB, Redis) and relational (e.g., PostgreSQL, MySQL) • Implement robust caching strategies, data security measures, and modern authentication/authorization procedures. • System Integration & Collaboration: • Collaborate closely with cross-functional teams (Game Designers, UI/UX Designers, Product Owners, QA) to translate product requirements into technical architecture. • Build reusable libraries, modular components, and core utilities to accelerate future development and maintainability. • DevOps & Quality Assurance: • Ensure system reliability by building automated unit, integration, and E2E tests following Clean Code and SOLID principles. • Work with DevOps to streamline containerization (Docker, Kubernetes) and CI/CD pipelines across cloud platforms (AWS/GCP). • Leadership & Continuous Improvement: • Conduct code reviews, identify performance bottlenecks, and resolve complex technical blockers. • Mentor junior and mid-level developers, stay updated with emerging industry trends, and propose proactive improvements to existing platforms. Qualifications • Experience & Technical Expertise: • Minimum of 5+ years of professional experience as a Full-Stack Developer (with 3+ years specialized in Go and Nuxt.js/Vue.js). • Backend Proficiency: Strong experience with Go (Golang), microservices architecture, gRPC/RESTful APIs, and frameworks such as Gin, Echo, or Fiber. • Frontend Proficiency: Advanced knowledge of Nuxt.js (Nuxt 3), Vue.js, TypeScript, and modern CSS frameworks (e.g., Tailwind CSS). • Database & Infrastructure: • Solid mastery of relational (PostgreSQL, MySQL) and NoSQL (MongoDB, Redis) database design, query tuning, and ORMs. • Hands-on experience with containerization tools (Docker) and familiarity with cloud orchestration (Kubernetes, AWS/GCP). • Engineering Standards: • Deep understanding of API design, microservices patterns, event-driven architectures (e.g., Kafka, RabbitMQ), and security protocols. • Familiarity with cross-browser compatibility, web performance optimization, and responsive mobile-first designs. • Soft Skills & Communication: • Strong analytical and problem-solving mindset with high attention to detail and accountability. • Excellent communication skills in English and Thai (written and spoken) to articulate complex technical ideas clearly.
