Job Overview: The Golang Backend Developer will be responsible for designing, developing, and maintaining scalable backend services ecosystem. This role involves working closely with frontend teams, architects, and infrastructure teams to deliver robust, cloud-native applications. The engineer will focus on building high-performance APIs and microservices using Golang, ensuring system reliability, scalability, and security. Essential Job Functions: - Design, build, and maintain scalable ETL pipelines to ingest data from multiple internal and external sources - Develop and optimize data warehouse/data lake architecture - Build scalable and high-performance RESTful APIs and microservices - Design and optimize data storage solutions using SQL databases - Collaborate with frontend developers to integrate user-facing elements with server-side logic - Follow Agile/Scrum practices including sprint planning, stand-ups, and retrospectives - Analyze complex problems and propose efficient backend solutions - Ensure code quality through best practices, unit testing, and code reviews - Take ownership of features/modules and deliver high-quality outcomes - Work with DevOps teams for CI/CD, deployment, and monitoring Technical Expertise: - 5+ years of experience in backend development with Golang - Strong understanding of microservices architecture and distributed systems - Experience designing and developing REST APIs and event-driven services - Hands-on experience with SQL databases (PostgreSQL, MySQL, etc.) - Familiarity with NoSQL databases (e.g., Cassandra, DynamoDB, Elasticsearch) is a plus - Experience with Docker and Kubernetes for containerized deployments - Experience working with cloud platforms (AWS, Azure, or GCP) - Knowledge of message queues/streaming systems (Kafka, RabbitMQ, etc.) - Familiarity with OAuth 2.0, JWT, and secure API design - Experience with Git or similar version control systems Desired Skills: - Experience in building high-throughput, low-latency systems - Familiarity with monitoring and observability tools such as Datadog, Prometheus, Grafana - Understanding of caching strategies using Redis or Memcached - Exposure to system design and scalability best practices - Experience working in large-scale distributed environments
