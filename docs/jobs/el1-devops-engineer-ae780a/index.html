EL1 DevOps Engineer (Contract) - 12 months + 12 month extension option We're seeking an experienced EL1-level DevOps Engineer to lead highly complex cloud and data infrastructure initiatives and support a modern delivery environment. You'll work closely with business stakeholders and a local full-stack delivery team, providing technical leadership, problem solving and guidance to ensure high-quality outcomes. Key responsibilities • Design, develop, deploy and support cloud & data infrastructure platforms • Prioritise and manage a delivery work queue to meet timeframes and outcomes • Build and improve CI/CD pipelines and DevOps practices to streamline delivery • Ensure solutions follow integration best practice and are clearly documented • Engage stakeholders to define requirements, set priorities and deliver results • Provide leadership within agile delivery teams and contribute to strategic decisions What you'll bring (essential) • Extensive hands-on AWS and/or Azure experience (designing and managing scalable cloud solutions) • Strong DevOps and continuous delivery pipeline experience (e.g., GitLab, Artifactory, Jira) • Strong Infrastructure as Code capability (Terraform) • Ability to maintain/configure enterprise platforms such as Control-M, PowerBI, Talend and Snowflake • Coding capability across Python, JavaScript and Golang (moderately complex code) • Strong containerisation/orchestration experience (Docker, Kubernetes) • Baseline Security Clearance minimum (NV1 Security Clearance is preferred) Nice to have • Deeper multi-cloud administration across AWS and Azure • HashiCorp Vault (secrets management) • Exposure to intelligent CI/CD automation (e.g., AI agents for permission-controlled tasks like auto-remediation, docs, testing) If you're a senior DevOps engineer who enjoys leading complex delivery, partnering with stakeholders, and building robust cloud platforms-apply now.
