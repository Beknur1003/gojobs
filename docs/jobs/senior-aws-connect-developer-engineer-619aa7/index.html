Mile widziane • Amazon Lex, boty głosowe i chatboty, automatyczne podsumowania rozmów, agent assist lub conversational AI. • Salesforce Apex, Lightning Web Components, Flows lub MuleSoft. • Amazon Bedrock, RAG, bazy wiedzy i mechanizmy kontroli bezpieczeństwa rozwiązań AI. • Doświadczenie w projektach bankowych lub finansowych. • Certyfikaty AWS Developer, Amazon Connect lub Salesforce.
