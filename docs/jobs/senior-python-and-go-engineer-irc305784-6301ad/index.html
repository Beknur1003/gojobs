Description We are seeking a Senior Software Engineer to join our Fleet Migration Team. The team develops software tools that automate customer VM movement across data center clusters without service disruption. You will write the automation services and coordination scripts that power our large-scale transition to ARM hardware. Requirements Education & experience: Bachelor of Science in Computer Science, Systems Engineering, or a related field, plus heavy experience in systems automation and backend tool development. Programming Languages: High proficiency in Python and Go, along with Bash scripting. Virtualization & OS: Good understanding of Linux hypervisors, VM storage snapshots, and state transfer mechanisms. API & Systems: Experience building CLI tools, REST APIs, and database-backed workflow engines. Job responsibilities Build and maintain backend services and CLI scripts to automate customer-driven warm/cold VM migrations. Implement state tracking, validation checks, and rollback logic for automated migration jobs. Integrate migration automation with central database state stores and orchestration APIs. Troubleshoot migration failures and performance bottlenecks during operational test runs.
