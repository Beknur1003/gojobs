Your contribution to something big: Join our team and contribute to the development of scalable software solutions based on modern microservice architectures. In this role, you will work across the software development lifecycle, from designing and implementing new features to deploying and optimizing applications in production. You will also have the opportunity to work with emerging AI/ML and Large Language Model (LLM) technologies. • Develop scalable solutions: Develop, maintain and enhance software within a microservice architecture, writing clean, efficient and maintainable code following software engineering best practices. • Ensure software quality: Write and maintain unit tests, participate in code reviews and provide constructive feedback to continuously improve code quality and reliability. • Bring software into production: Deploy applications using Kubernetes and Helm, supported by modern CI/CD practices, and contribute to reliable production environments. • Build and integrate services: Design, develop and test REST APIs and work with relational databases such as PostgreSQL or MySQL. • Explore AI-driven solutions: Contribute to the integration and application of AI/ML, Generative AI and Large Language Models (LLMs) within software solutions. • Optimize performance: Monitor application performance, troubleshoot issues across the application stack and optimize solutions for scalability and reliability. • Collaborate: Work closely with cross-functional teams to design and implement new features and continuously improve our solutions. • Share knowledge: Create and maintain clear technical documentation and contribute to knowledge sharing within the team. What distinguishes you: Education • M.Sc. or Ph.D. in Computer Science, Software Engineering or a related technical field. Experience • Experience in software development and working with modern software architectures. • Hands-on experience with Go (Golang) is valued; alternatively, you bring solid programming experience and the motivation and ability to quickly learn Go. • Experience with C and/or Python is also relevant. Know-how • Experience developing and testing REST APIs, working with PostgreSQL or MySQL, and using Git in collaborative development environments. • Familiarity with Kubernetes, containerization technologies and CI/CD is valued. Knowledge or hands-on experience with AI, Machine Learning, Generative AI, prompt engineering and/or Large Language Models (LLMs) is an advantage. • Familiarity with AI frameworks such as LangChain or similar technologies is also valued. • Knowledge of React, JavaScript/TypeScript, HTML/CSS, AWS, GCP or Azure is considered a plus. Languages • Good written and spoken English skills, enabling you to collaborate effectively in an international environment. Working Style and Methods • You approach technical challenges in an analytical and structured way, with a strong focus on problem-solving, debugging and software quality. You are comfortable working collaboratively with modern development workflows and quickly adapting to new technologies and frameworks. Personality • You are curious, collaborative and eager to learn. You enjoy exploring new technologies, sharing knowledge with colleagues and contributing ideas to continuously improve both the product and the way the team works.
