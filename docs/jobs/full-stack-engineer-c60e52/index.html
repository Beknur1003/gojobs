Retention Science, oracle SCM, zomato, & from institutions like Hindu College, BITS Pilani, and the University of Southern California. • Backed by VCs & founders of India's biggest unicorns, including Ashneer Grover (BharatPe), Kunal Shah (CRED), Peyush Bansal (Lenskart), and Prashant Pitti (easemytrip). Job Description: • Zippee is looking for a hands-on, 10x Full Stack Engineer to join our Gurgaon HQ. • Build and own technology powering quick commerce at scale, across dark stores, inventory, order fulfilment and last-mile delivery. • Build scalable products using Go (Golang), React and AWS, from architecture through production. • Design reliable distributed systems, APIs and backend services built for high-throughput, real-time operations. • Use AI-assisted development tools like Claude Code to accelerate development, testing and automation. • Write clean, production-ready code with strong testing, minimal unnecessary abstraction and attention to edge cases. • Own engineering decisions across the stack, with a high bar for code quality, reliability and system performance. Roles & Responsibilities: • Build and own scalable full-stack products using Go (Golang), GraphQL, React and TypeScript, from technical design through production. • Use Claude Code and agentic workflows to accelerate development, testing and refactoring while maintaining a high bar for code quality and simplicity. • Design reliable microservices, REST/gRPC APIs and asynchronous workflows using queues/message brokers such as SQS, Kafka or RabbitMQ. • Own system design and architecture, including API contracts, concurrency, caching (Redis), database design and performance across SQL/NoSQL stores. • Build responsive, performant web applications with clean state management, strong security and good user experience. • Deploy and operate production workloads on AWS using services such as ECS/EKS, Lambda, RDS, S3 and ElastiCache. • Write strong tests, review AI-generated and human-written code rigorously, and maintain observability through structured logging, tracing and monitoring. • Produce clear technical designs and work closely with Product and Engineering teams to take features from problem statement to production. Qualifications: • 3–5 years of full-stack engineering experience, with strong hands-on expertise in Go (Golang), GraphQL, React and AWS. • Strong backend fundamentals across microservices, distributed systems, high-throughput APIs, queues/message brokers and caching. • Proficiency in modern React and TypeScript, including hooks, state management and component architecture. • Strong HLD/LLD and system design skills, with a good understanding of scalability, data modelling, failure handling and performance. • Hands-on experience with AI-assisted development tools such as Claude Code, with the ability to use AI to ship faster without compromising code quality. • Strong engineering discipline around clean code, testing, automation and production reliability. What you'll get: • Opportunity to be part of a tight-knit rocketship passionate about empowering consumer brands in the quick commerce era. • Annual company retreat. • Steep learning curve, high ownership, and the chance to grow fast as we scale.
