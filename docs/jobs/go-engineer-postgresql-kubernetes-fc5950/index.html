We are looking for a Software Engineer with strong hands-on experience in Go (Golang) and PostgreSQL to help build and scale a cloud-native database platform. This role combines backend software development, database engineering and Kubernetes automation. You will develop services in Go and automate the deployment, operation and scaling of PostgreSQL across distributed cloud environments. What you will do • Design, develop and maintain scalable services using Go, supporting a managed PostgreSQL platform. • Automate PostgreSQL deployment and lifecycle management using Kubernetes and PostgreSQL Operators. • Contribute to distributed architectures covering high availability, replication, sharding, load balancing and multi-region deployments. • Optimise PostgreSQL performance, maintain data integrity and troubleshoot complex database issues. • Improve automation so the platform can grow without a corresponding increase in manual operational work. • Take technical ownership of platform capabilities, improving reliability, resilience and the customer migration experience. • Collaborate with engineers on architecture, development and cloud-native operations. What we are looking for • Strong professional experience in software engineering, cloud development or database engineering. • Strong hands-on programming experience in Go (Golang). This is a core requirement for the role. • Proven experience with PostgreSQL, from a development and/or administration perspective. • Solid practical knowledge of Kubernetes, container orchestration and cloud-native services. • Hands-on experience deploying and managing PostgreSQL using PostgreSQL Operators. • An automation-focused approach and experience building reliable, scalable systems. • Strong problem-solving skills, a collaborative mindset and the ability to take technical ownership. • Business-fluent English. Nice to have • Experience with highly available PostgreSQL architectures, read replicas and advanced replication. • Exposure to multi-region database platforms and large-scale distributed systems. • Experience building managed database services or Database as a Service platforms. • German language skills.
