About the role We are looking for an experienced Mid-Level Full Stack Engineer to join our development team. In this role, you will take ownership of features end-to-end, building modern frontend user interfaces with Next.js / TypeScript and robust backend microservices with Go (Golang). You will collaborate closely with product managers, UI/UX designers, and QA engineers to deliver performant, scalable, and resilient software in an Agile environment. Key responsibilities • Design, build, and deploy production-ready web features spanning both frontend interfaces (Next.js, React, TypeScript, Tailwind CSS) and backend services (Go, REST, gRPC). • Develop clean, high-performance RESTful and gRPC APIs in Go; design efficient database schemas, optimize queries, and implement caching layers (Redis) and message brokers. • Optimize web application performance, including SSR/SSG/ISR with Next.js App Router, client/server state management, bundle size reduction, and Core Web Vitals. • Participate actively in code reviews, providing constructive feedback and ensuring adherence to Clean Architecture, coding standards, and maintainability. • Develop comprehensive unit, integration, and end-to-end tests to ensure high product quality, reliability, and system availability. • Partner effectively with Product Owners, Designers, and QA to refine requirements, estimate effort, and deliver sprint commitments consistently. • Create and maintain thorough technical documentation for system architecture, API endpoints, and onboarding guides. About you • Bachelor's degree in Computer Science, Computer Engineering, Information Technology, or a related technical discipline (or equivalent practical experience). • 2 to 5 years of professional software development experience building web applications and backend systems. • Strong proficiency in modern frontend development using Next.js (App Router, Server Components), React, and TypeScript. • Strong hands-on experience in backend development using Go (Golang) with frameworks (such as Gin, Fiber, or Go standard library). • Solid experience in database design, indexing, and query optimization with relational databases (PostgreSQL, MySQL) and NoSQL stores. • Practical experience implementing caching solutions (Redis) and event-driven patterns. • Experience with containerization (Docker) and local development container workflows. • Solid understanding of Git workflows, branching strategies, and CI/CD pipelines (GitHub Actions, GitLab CI). • Strong analytical and problem-solving abilities with attention to detail. • Proactive communicator with a collaborative team-player mindset in an Agile culture.
