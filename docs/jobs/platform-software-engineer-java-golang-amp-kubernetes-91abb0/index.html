Únete a nuestro equipo como 💻Platform Software Engineer💻 y disfruta de un entorno de trabajo innovador y colaborativo. ¿Cuál será tu misión en el proyecto? Construir y evolucionar la plataforma tecnológica que utilizan los equipos, desarrollando soluciones software y capacidades de infraestructura automatizadas sobre Kubernetes que permitan desplegar, operar y escalar servicios digitales de forma segura, eficiente y global.
