Cloud Architect

Project description As a Senior Cloud Operations Architect, you will be responsible for implementing and maintaining a highly scalable and secure cloud infrastructure. The role involves applying best practices in cloud governance, security, monitoring, and continuous deployment (CI/CD) to ensure smooth and efficient cloud operations. You will collaborate with cross-functional teams to enhance cloud efficiency, reliability, and security while ensuring compliance with industry/security standards. Responsibilities • Experienced, lead-level, cloud solution architect with a demonstrated ability to evaluate, solution, estimate, implement and document cloud centric application architectures and deployment methodologies. Advise application and data migration efforts and directly contribute to the design and implementation of varied application solutions, IaC implementation, and operational capabilities. Our team solutions for and operates across Azure, AWS, and GCP cloud providers, however, this position will be heavily Azure leaning. Team members in this role must understand development and deployment workflows and be capable of providing appropriate and actionable guidance pertinent to re-factoring applications towards more cloud optimal architectures and cloud-oriented best-practices. Individuals in this role must have the ability to lead technical solutioning engagements, mentor team members, and work in collaboration with other teams to drive application architecture design, ensure compliance with Optum cloud standards and generally assist in cloud migration and modernization efforts. SKILLS Must have • 8+ years of experience Must have Skills: * CSP(AWS, Azure and/or GCP) - 5+ years * Lead experience (3+ years) * Networking * Function Apps (serverless architectures) * Container Apps / AKS (containerized architectures) * Databases and data migration capabilities * Data streaming/messaging services * Security and IAM * CSP Certification (AWS/Azure/GCP) — Associate+ level, verifiable * CI/CD automation using GitHub / GitHub Actions * Infrastructure as Code (IaC) with Terraform Nice to have * GoLang
