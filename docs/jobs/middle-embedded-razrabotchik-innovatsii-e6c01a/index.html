Мы в поисках Embedded-разработчика в команду Инноваций. Разрабатывать системное/низкоуровневое программное обеспечение на C/C++ (или Rust) для embedded/системного кода; Работать с микроконтроллерами, прошивками (firmware) и периферией; Разрабатывать решения с базовым пониманием криптографии на устройстве, включая работу с ключами и secure storage; Собирать и адаптировать Android-образы (AOSP/LineageOS), включая работу с Kernel modules; Пересобирать/кастомизировать образы ОС Android на платформенном уровне; Разрабатывать транспортный SDK и нативные библиотеки под Android (JNI/NDK); Разрабатывать бэкенд-сервисы на Golang/Rust/Java/Kotlin, включая REST/gRPC; Использовать Docker для сборки образов и базовый CI/CD. Smartcard/secure element (под bSIM) - опыт работы с JavaCard (аплеты), secure element/SIM/смарткартами, OTA-провижинингом; MacOS-таргет - опыт разработки транспортного SDK bSIM для Android + macOS; Опыт с виртуализацией Android (Anbox, EDM CloudPhone); Телеком-контекст - понимание SIM, eUICC, профилей; Linux - опыт работы на уровне сборки ядра и драйверов; Опыт построения агентских систем - понимание промпт-инжиниринга, tools, skills, агент-лупы. Релевантно R&D-ядру (AIF, PhoneGPT, РИИЛ). Собственную платформу MTS Ocean для получения ИТ-ресурсов, а это значит, что деплой, мониторинг, observability — не будут для тебя проблемой, ты сможешь сосредоточиться на фичах; Профессиональные гильдии инженеров, где мы поддерживаем друг друга и помогаем стать лучше; Внутреннюю площадку TechTalks для обмена опытом, дискуссий, развития навыков самопрезентации; Участие во внешних IT конференциях. Мы выступаем на HighLoad++, DataFest, Mobius, Test Driven Conf, Joker, DevOps, Матемаркетинг и даже проводим собственную конференцию по архитектуре True Tech Arch; Полезные курсы и вебинары в корпоративном университете и электронную библиотеку; ДМС с первого месяца работы, включая стоматологию; Страхование от несчастных случаев с 1 месяца работы. Материальную помощь в сложных жизненных ситуациях; Отпуск 28 календарных дней; Прием врачей общей практики и массаж в офисе; Мобильная связь за счет компании и льготные тарифы для близких; Подписка на онлайн-кинотеатр KION, сервис МТС Музыка, книжный сервис Строки от МТС, безлимитные мессенджеры и соцсети.
