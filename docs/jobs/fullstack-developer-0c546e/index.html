Fullstack Developer

Основные обязанности: 1. Архитектура и техническое лидерство: Проектирование и развитие микросервисной архитектуры системы на базе Go, обеспечивая высокую отказоустойчивость и масштабируемость. Разработка стратегий оркестрации бизнес-процессов в Camunda Engine: проектирование BPMN-схем, настройка DMN-таблиц для бизнес-правил и управление жизненным циклом задач (Tasklist). Определение стандартов разработки: валидация DTO, покрытие кода unit-тестами, правила работы с ошибками и логирования. Проведение код-ревью, менторство разработчиков (Go и React), оценка технических рисков и выбор оптимальных решений. 2. Разработка Backend (Core & Integration): Разработка высокопроизводительных API на Go для взаимодействия с фронтендом и внешними системами. Реализация интеграционных слоев: Асинхронная обработка событий через Kafka (Core логика, триггеры процессов). Взаимодействие с legacy-системами и партнерами через шлюзы или напрямую (REST/SOAP). Интеграция с Keycloak для управления авторизацией и правами доступа (RBAC). Оптимизация работы с данными: Проектирование схем и запросов в PostgreSQL. Настройка кэширования горячих данных в Redis. Реализация пайплайнов для записи метрик процессов в ClickHouse для последующей аналитики. Настройка полнотекстового поиска и агрегации логов в Elasticsearch. 3. Разработка Frontend (React): Архитектура и разработка SPA на React + JS для интерфейсов пользователей (Tasklist), администраторов процессов и дашбордов аналитики. Интеграция фронтенда с бэкенд-API (Swagger/OpenAPI), реализация сложной клиентской логики и состояния приложения. Адаптация и расширение функционала Camunda Modeler (или создание собственных веб-инструментов для моделирования схем), если это требуется бизнесом. 4. DevOps и качество кода: Участие в настройке CI/CD пайплайнов для автоматического тестирования и деплоя сервисов. Обеспечение безопасности приложения (валидация входных данных, защита от уязвимостей, работа с токенами доступа). Мониторинг производительности системы, профилирование Go-приложений и оптимизация узких мест (БД, очередь, сеть). Поддержка актуальной технической документации (Swagger, архитектурные решения). 5. Взаимодействие с командой и бизнесом: Трансляция бизнес-требований в технические спецификации и задачи. Взаимодействие с аналитиками для корректного описания процессов в BPMN/DMN. Планирование технического долга и roadmap развития платформы. Основные требования: Опыт: 2+ года на позиции Senior. Backend: Отличное знание Go (Golang). Понимание конкурентности, работы с памятью, оптимизации. Будет большим плюсом опыт работы с Camunda (или другими BPM-движками: Activiti, Flowable). Уверенное владение SQL (PostgreSQL) и NoSQL решениями (Redis, Elastic, ClickHouse). Опыт работы с брокерами сообщений (Kafka). Понимание принципов микросервисной архитектуры и паттернов интеграции (REST, SOAP, gRPC). Frontend: Глубокое знание React и экосистемы JavaScript/TypeScript. Опыт создания сложных интерфейсов для корпоративных систем (дашборды, таблицы, визуализация процессов). DevOps & Tools: Опыт настройки CI/CD, написания Unit/Integration тестов. Работа с Docker, Kubernetes (будет плюсом). Знание Swagger/OpenAPI для документирования API. Безопасность: Опыт интеграции с OIDC/OAuth2 провайдерами (Keycloak). Языки: Чтение технической документации на английском. Знание C#, JAVA будет преимуществом (для поддержки legacy-модулей или глубокой кастомизации Camunda). Условия: •Заработная плата и бонусы: конкурентоспособная оплата труда благодаря системе грейдирования, премии ко Дню Независимости и годовой бонус. •Социальный пакет: ДМС и страхование жизни, мобильная связь и скидки от партнеров. •Отпуск и отдых: 26 дней отпуска с возможностью взять дополнительные дни при наступлении важных событий. •Бонусы за рекомендации. •Рабочие условия: льготные условия на паркинг, свободный стиль одежды (smart casual). •Обучение и развитие: тренинги, вебинары и доступ к корпоративной библиотеке, четкая система карьерного роста. •Корпоративная культура: открытая и дружеская рабочая атмосфера, спортивные турниры и активная корпоративная жизнь. •Инициативы и проекты: возможность участия в социальных проектах, реализация идей в новых проектах группы «Halyk» с использованием современных digital-инструментов. •Команда: творческая и поддерживающая команда для реализации ваших идей.
