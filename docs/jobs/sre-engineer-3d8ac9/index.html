Role Overview The selected SRE and DevOps professional will be responsible for maintaining highly available production systems, managing cloud infrastructure, improving observability, and supporting reliable deployment and operations practices. The role combines hands-on engineering with incident response, infrastructure automation, performance optimization, and continuous reliability improvement. The ideal candidate should have experience working in production-critical environments where system availability, quick incident resolution, effective monitoring, and preventive engineering are essential. Key Responsibilities1. Site Reliability and Production Operations • Monitor production systems and maintain service availability, performance, and operational stability. • Participate in production support and scheduled on-call rotations, including the resolution of critical incidents. • Investigate system failures, perform root cause analysis, document post-incident findings, and implement preventive measures. • Identify recurring operational issues and reduce manual intervention through automation. • Improve service reliability using measurable indicators, service objectives, availability targets, and error-budget practices. • Contribute to capacity planning, disaster recovery, high availability, redundancy, and failover strategies. • Cloud Infrastructure and Platform Engineering • Manage and optimize cloud infrastructure across Microsoft Azure, Amazon Web Services (AWS), and/or Google Cloud Platform (GCP). • Work with cloud compute, storage, networking, access management, monitoring, and cloud-native services. • Support containerized applications and manage Kubernetes-based infrastructure, including AKS, EKS, GKE, or equivalent platforms. • Troubleshoot cluster health, application workloads, resource utilization, scaling, networking, and deployment-related issues. • Work with Helm and other relevant deployment tools to maintain consistent application releases. • Infrastructure Automation and DevOps • Develop and maintain Infrastructure as Code (IaC) using Terraform. • Support automated infrastructure provisioning, configuration management, and repeatable deployment processes. • Work with Git-based development workflows, including GitHub, GitLab, Azure Repos, or equivalent platforms. • Contribute to CI/CD pipelines and improve deployment reliability through automation. • Develop scripts using Python and/or Bash to simplify operational activities and eliminate repetitive tasks. • Monitoring, Observability and Performance • Build and maintain monitoring, logging, metrics, tracing, and alerting solutions for production environments. • Work with observability platforms such as OpenTelemetry, Datadog, Prometheus, Grafana, Azure Monitor, Golden Signals(including Latency, errors, traffic, saturation), AWS CloudWatch, and GCP Cloud Monitoring. • Apply the four Golden Signals—latency, traffic, errors, and saturation—to monitor service health and identify performance issues. • Improve distributed tracing and establish meaningful alerts that reflect actual system health and user impact. • Investigate performance bottlenecks across infrastructure, applications, networks, and distributed systems. • Linux, Networking and Security • Troubleshoot Linux-based systems and production infrastructure issues. • Apply networking fundamentals, including DNS, TCP/IP, load balancing, SSL/TLS, and connectivity troubleshooting. • Follow cloud security best practices for identity and access management, network segmentation, and secrets management. • Support vulnerability remediation, security improvements, and compliance-related activities in collaboration with relevant teams. Technical Environment The role involves cloud infrastructure, Kubernetes, Terraform, scripting, production support, monitoring, and modern reliability engineering practices. Experience with one major cloud platform is important, while exposure to multiple cloud environments can be beneficial. Additional exposure to Go (Golang), OpenSearch, ELK Stack, AI/ML production platforms, Azure AI services, AI Foundry, RAG-based workloads, and enterprise observability frameworks would be advantageous.
