Junior GoLang Engineer (Full-Stack) Location: Glasgow or Edinburgh, Scotland - Hybrid Level: Graduate – Junior / Early Career An exciting opportunity has arisen for a Junior GoLang Software Engineer to join an innovative technology company operating within the space sector, developing advanced computing components and software technology for next-generation satellites. As a GoLang Software Engineer, you will join an international Software Development Team building unique Edge Computing technology that will run directly on satellite hardware. The technology allows satellites to process and analyse data directly in orbit. The platform is powered by advanced processing chips, the same technology used in NASA's Mars Rover missions. This is a fantastic opportunity for a graduate or early-career programmer with strong programming fundamentals, mathematical ability and a passion for solving complex problems to work on technology that will ultimately operate in space. Previous experience within the space sector is not required. The team is interested in strong programmers and technically minded individuals from a range of engineering and technology backgrounds who are keen to apply their skills to an exciting new industry. The Role As a Software Engineer, you will work alongside the wider Software Development Team, contributing to the design and development of software that runs on specialised Edge Computing hardware. The team currently uses Go (Golang) as its primary programming language, chosen for its ability to deliver powerful, efficient and high-performance software. This is a particularly exciting time to join the team. The technology is new, and much of the software architecture and development environment is still being established. Rather than joining a team working with an existing, rigid technology stack, you'll have the opportunity to explore new technologies, influence technical decisions and help design and build the software architecture from the ground up. You'll work across the full software stack, gaining exposure to everything from backend systems, data processing and APIs through to application development and integration with specialised hardware. In this role, your focus will be on building software that interacts with specialised hardware, processes datasets and enables computing capabilities directly onboard satellites. The ideal candidate is someone who genuinely enjoys programming, understanding how systems work and solving challenging technical problems. You should be excited by the prospect of learning new technologies, taking ownership of your development and helping create something that hasn't been done before. Key Responsibilities • Design, develop and maintain software applications and components using Go (Golang). • Contribute to the development of full-stack software solutions for Edge Computing hardware. • Work across different layers of the software stack, including backend systems, data processing, APIs and application-level functionality. • Develop software that enables satellite hardware to process and manage datasets directly in space. • Work alongside Cloud Engineers to integrate software components with cloud infrastructure and wider systems. • Contribute to software architecture, development, testing and integration. • Help explore and evaluate new technologies, tools and approaches. • Troubleshoot complex technical challenges and optimise software performance. • Collaborate with hardware and software engineers across international development teams. What We're Looking For • A First-Class or 2:1 undergraduate degree in Computer Science, Mathematics, Applied Mathematics, Physics, Electronics Engineering, Electrical Engineering, Computer Engineering, Robotics, Mechatronics or another numerically or technically demanding discipline. • Strong programming fundamentals and a genuine passion for software engineering. • Experience with Go (Golang) is desirable but not essential. Strong programmers with experience in other languages will also be considered. • Good understanding of programming concepts, algorithms, data structures and software design principles. • Strong mathematical, analytical and problem-solving abilities. • An interest in understanding how software interacts with hardware, processes data and operates at a systems level. • An eagerness to develop across the full software stack rather than specialising in just one area. • A proactive attitude, curiosity and willingness to learn new technologies. Particularly interested in candidates who: • Are recent graduates or have around 1–2 years of programming or software engineering experience. • Have developed personal, university or open-source projects demonstrating strong programming ability. • Enjoy tackling complex programming problems and understanding how things work under the hood. • Have experience with languages such as Go, C, C++, Python, Rust or Java - willing to learn and specialise in GoLang. • Have an interest in systems programming, embedded software, distributed systems, data processing or Edge Computing. • Demonstrate strong logical reasoning and the ability to learn new programming languages and technologies quickly. • Are interested in developing software beyond conventional web applications and frameworks. Additional Requirements • Must have the existing legal right to live and work in the UK. Visa sponsorship is not available for this position. • Must be willing and able to travel internationally to other company office locations when required. • Must be eligible to obtain any necessary security clearance and successfully complete relevant background checks, where required. Why Join? • Work on innovative software technology designed for use in satellites. • Develop software for advanced processing chips also deployed in NASA's Mars Rover missions. • Gain hands-on experience with Go, full-stack development, Edge Computing and hardware integration. • Work alongside Cloud Engineers and hardware specialists to build technology from the ground up. • Help shape the software architecture and technology stack from the ground up, with the opportunity to influence engineering decisions and work with technologies that are still being developed. • Collaborate with experienced international engineering teams across multiple office locations. • Develop a broad technical skill set in a highly specialised and growing area of technology. This is an exceptional opportunity for a graduate or early-career programmer who wants to go beyond conventional software development and help build the next generation of computing technology for space. If you are interested, please apply today. angela.olmo@newspacetechnical.com
