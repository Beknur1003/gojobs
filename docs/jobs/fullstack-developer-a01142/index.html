Frontend Development • Menguasai HTML5, CSS3, dan JavaScript (ES6+). • Memahami TypeScript untuk pengembangan aplikasi yang terstruktur dan type-safe. • Menguasai minimal dua frontend framework/library modern: React.js, Next.js, Vue.js, Angular. • Mampu mengembangkan antarmuka aplikasi yang responsive, reusable, dan user-friendly. • Memahami component-based architecture. • Mampu mengintegrasikan frontend dengan Backend API. • Memahami asynchronous programming, Promise, dan async/await. • Memahami form validation, error handling, dan state management. • Memahami prinsip dasar UI/UX dan mampu menerjemahkan desain menjadi antarmuka yang fungsional. • Memahami browser developer tools untuk debugging dan performance analysis. Backend Development • Menguasai minimal dua bahasa pemrograman backend: JavaScript / TypeScript (Node.js), PHP, GoLang, Java. • Berpengalaman menggunakan backend framework: Express.js / NestJS, Laravel, Spring Boot • Mampu mengembangkan RESTful API. • Memahami implementasi business logic dan server-side validation. • Memahami authentication dan authorization, termasuk JWT, session-based authentication, dan Role-Based Access Control (RBAC). • Memahami konsep MVC, layered architecture, atau modular architecture. • Mampu mengimplementasikan logging, exception handling, dan standardized API response. • Memahami prinsip secure coding. • Mampu melakukan debugging dan troubleshooting pada backend application. Database Management • Menguasai SQL relational database: PostgreSQL, MySQL / MariaDB. • Mampu merancang database schema dan relasi antartabel. • Memahami database normalization dan data integrity. • Menguasai SQL query, JOIN, GROUP BY, subquery, dan aggregate functions. • Memahami database indexing dan query optimization. • Memahami database transaction dan konsep ACID. • Mampu menggunakan ORM sesuai framework yang digunakan. • Memahami database migration dan schema versioning. Version Control, Deployment & DevOps • Menguasai Git untuk version control. • Memahami branching strategy, pull request, merge, dan conflict resolution. • Memahami collaborative development workflow. • Memahami konfigurasi development, staging, dan production environment. • Memahami environment variables dan application configuration. • Memahami dasar Docker dan containerization. • Mampu melakukan troubleshooting melalui application logs. AI-Assisted Software Development • Memiliki pengalaman menggunakan AI-powered coding assistants seperti: GitHub Copilot, Cursor, ChatGPT, Claude Code, Atau AI coding tools sejenis. • Mampu menggunakan AI untuk membantu pengembangan aplikasi frontend maupun backend. • Mampu memanfaatkan AI dalam aktivitas: Code generation, API development, Database query generation, Code refactoring, Debugging dan troubleshooting, Code optimization, Unit test dan integration test generation, Technical documentation. • Memahami teknik prompt engineering untuk memberikan instruksi pengembangan yang jelas, spesifik, dan terstruktur. • Memahami context engineering, termasuk penyediaan project context, business rules, technical constraints, dan coding conventions. • Mampu memecah requirement kompleks menjadi development tasks yang dapat dikerjakan secara efektif dengan bantuan AI. • Mampu melakukan review, validasi, dan perbaikan terhadap AI-generated code. • Mampu mengidentifikasi kesalahan logika, security vulnerabilities, dan performance issues pada AI-generated code. • Mampu memastikan AI-generated code sesuai dengan application architecture, coding standards, dan business requirements. • Memahami risiko AI hallucination dan keterbatasan AI coding assistants. • Memahami keamanan informasi dalam penggunaan AI tools, termasuk perlindungan source code, credentials, API keys, dan data sensitif perusahaan. • Memiliki fundamental programming dan problem-solving skills yang kuat sehingga tidak bergantung sepenuhnya pada AI-generated code. Job Description: • Mengembangkan, memelihara, dan meningkatkan aplikasi web pada sisi frontend dan backend berdasarkan business requirements dan technical specifications. • Menganalisis kebutuhan teknis dan menerjemahkan functional requirements serta implementasi aplikasi. • Mengembangkan antarmuka aplikasi yang responsive, reusable, dan user-friendly. • Mengembangkan backend services dan business logic sesuai kebutuhan sistem. • Merancang dan mengembangkan RESTful API untuk mendukung komunikasi antarkomponen aplikasi. • Merancang dan mengoptimalkan database schema, SQL queries, dan data processing. • Mengimplementasikan authentication, authorization, validation, dan application security. • Melakukan integrasi aplikasi dengan sistem internal maupun third-party services.
