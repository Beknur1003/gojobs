Software Engineer Architect - AI Agents Platform

Hiring Eye Bangalore опубликовано 11 сентября 2026

KubernetesPythonReactAI/LLM
Job Description: We are looking for a hands-on Software Engineer Architect to own the architecture and scalability of an AI Agents platform. The role involves designing reliable, secure, and high-performance distributed systems while actively contributing to complex technical challenges. Key Responsibilities: - Own end-to-end architecture across services, APIs, data, async workflows, and AI/LLM agent pipelines. - Design scalable and reliable systems with strong observability, fault tolerance, retries, and graceful degradation. - Architect secure, multi-tenant platforms with PHI, HIPAA, and SOC 2 considerations. - Make and document key technology and architecture decisions. - Stay hands-on with coding, prototyping, and technical problem-solving. - Work with Kubernetes/GKE and cloud infrastructure on scalability, deployment, and performance. - Mentor engineers and establish best practices for architecture, testing, and production releases. Required Skills: - 10+ years of software engineering experience with strong distributed systems and architecture expertise. - Hands-on experience with Python or Go and backend/service development. - Strong knowledge of REST APIs, event-driven architecture, task queues, and databases. - Experience with cloud platforms and Kubernetes. - Experience building or integrating AI/LLM-based systems and agent orchestration. - Strong understanding of reliability, security, data isolation, encryption, and observability. - Excellent communication, problem-solving, and technical leadership skills. Education : - UG: B.Tech / B.E. in Any Specialization Key Skills : - Skills highlighted with are preferred keyskills: Python, Golang, AI/LLM, Restfull API, Data Modeling, React, Cloud Native, Kubernetes.
