【公司介紹】 一家知名零售通路集團，擁有實體門市與線上平台，正持續推動線上線下整合的全通路數位轉型。資訊與商業應用團隊負責各類資訊系統的管理與維運，專注於全通路服務的技術開發、數據分析、雲端技術與 AI 應用，目標是實現數據驅動決策、流程自動化，以及跨通路的無縫串接。 【工作內容】 • 帶領 8 人的後端團隊，負責人才培育、績效考核與敏捷流程優化 • 主導後端架構演進與 Legacy 系統現代化策略，在技術債與業務需求之間取得平衡 • 維護高併發交易系統，規劃 GCP 資源配置與災難復原機制 • 與產品、數據與營運團隊協作，將商業需求轉化為可落地的技術方案 【職缺亮點】 • 全通路零售場景，交易量與流量都有實戰挑戰 • 現代化技術棧，包含 Golang、Kubernetes、Monorepo 與 CI/CD 自動化 • 有機會參與架構與技術治理的決策，不只是維運 • 年終分紅，分享公司獲利，並有集團通路的員工購物優惠 • 完整教育訓練與學習補助，晉升管道明確，並有海外發展機會 Requirements 【需求條件】 • 精通 Golang（Clean Architecture）現代框架 • 具 GCP、Kubernetes、Monorepo 與 CI/CD 自動化實戰經驗 • 8 年以上開發經驗，其中至少 3 年團隊管理經驗 • 具備跨部門溝通協調能力，能撰寫清晰的技術策略文件 【加分條件】 • 具 Domain-Driven Design（DDD）實戰經驗 • 具 Event-Driven Architecture（EDA）架構經驗（如 Kafka） • 具大型零售或電商平台開發經驗
