We are creating innovative mobile infrastructure solutions, making them accessible for operators and enterprises that want to deploy future-proof, cloud-native networks. We're hiring a talented Software Engineer (m/f/d) to join our team in developing next-gen features for our IMS (IP Multimedia Subsystem) solution.
