Project Duration: 2 Months Responsibilities • Design, develop, and maintain scalable backend services using Golang and Node.js (NestJS) for Back-end, and React.js and Next.js for Front-end. • Troubleshoot and resolve complex backend issues, including performance bottlenecks, debugging, and production incidents. • Optimize system architecture, microservices, database performance, and API reliability. • Develop and maintain RESTful APIs and ensure seamless integration across multiple services. • Implement and review hotfixes, patches, and backend enhancements following engineering best practices. • Conduct unit testing and integration testing to ensure code quality before deployment. • Collaborate with DevOps during deployment and production releases. • Optimize AI pipeline performance, including data ingestion, embedding, retrieval, and Knowledge Base indexing. • Work closely with QA, Project Managers, and other engineering teams throughout the software development lifecycle. • Document technical solutions, system improvements, and engineering best practices.
