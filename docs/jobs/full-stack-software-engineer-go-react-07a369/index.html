Full-Stack Software Engineer (Go + React) Job Summary We are seeking an experienced Full-Stack Software Engineer to help develop, maintain, and expand Samurai Seller, our internal software platform. This role is ideal for an engineer with strong software development fundamentals and professional experience building production applications with Golang. You'll work across both the backend and frontend, designing scalable solutions, writing clean and maintainable code, and independently delivering features from requirements through deployment. We're looking for someone who has already written and maintained production Go code, understands Go's common patterns and tradeoffs, and can contribute with minimal ramp-up. Beyond language proficiency, you should demonstrate strong problem-solving skills, sound software design principles, debugging ability, and the ability to build reliable, scalable applications. Job Type: Full-Time (40 hours/week) – Remote Schedule: 9:00 AM – 6:00 PM EST Responsibilities Software Development • Design, develop, test, and maintain features for Samurai Seller. • Build scalable backend services using Go (Golang) in a production environment. • Develop responsive and maintainable frontend applications using React. • Write clean, efficient, well-tested, and maintainable code. • Debug production issues and implement reliable, long-term fixes. • Participate in code reviews and help maintain high engineering standards. • Improve existing services by considering performance, scalability, maintainability, and reliability. Problem Solving • Analyze business requirements and translate them into technical solutions. • Break down complex problems into clear, maintainable implementations. • Design and implement appropriate algorithms and data structures. • Troubleshoot production issues independently and identify root causes. • Make thoughtful engineering decisions while considering performance and maintainability tradeoffs. Collaboration • Work closely with product owners and other developers. • Communicate technical designs, implementation plans, and engineering tradeoffs. • Contribute ideas that improve system architecture, code quality, and development processes. Required Qualifications • 3+ years of professional software engineering or software development experience. • At least 1 year of professional experience developing and maintaining production applications using Go (Golang). • Strong understanding of Go language idioms, concurrency, error handling, and common design patterns. • Strong experience with React and modern JavaScript/TypeScript. • Solid understanding of REST APIs. • Experience working with relational databases such as PostgreSQL or MySQL. • Experience using Git in a collaborative development environment. • Strong understanding of software engineering best practices, including code quality, testing, and maintainability. • Ability to work independently and contribute with minimal onboarding. Required Technical Skills Candidates should be comfortable with: • Writing clean, maintainable, and efficient production-quality code. • Building and maintaining backend services in Go. • Implementing common algorithms and data structures. • Debugging production systems and resolving complex issues. • Reasoning about algorithm correctness, edge cases, and performance. • Breaking down complex requirements into logical implementation steps. • Reading and understanding existing codebases. • Researching unfamiliar technologies independently and applying documentation effectively. • Understanding software architecture, scalability, and maintainability principles. Preferred Qualifications Experience with: • Docker • Linux environments • CI/CD pipelines • Unit and integration testing • Microservices architecture • E-commerce or inventory management systems • AWS or other cloud platforms Requirements • Your resume and Linkedin Profile • Submit any relevant portfolio, GitHub profile, or examples of previous software development projects (preferred). Please send all requirements in one email to leslie@zulay.net. Important Once we receive your complete submission, we will review your application. If you successfully pass this stage, we will contact you to schedule a technical interview. We appreciate the time and effort you're investing in your application and look forward to learning more about your technical expertise and development experience.
