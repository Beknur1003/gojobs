Position Summary: KBR is seeking a Full Stack Software Engineer with a strong interest in storage architecture, distributed storage systems, and cloud-native data platforms to support the development and sustainment of the GEMSTONE platform. This position will help design, deploy, and manage storage solutions supporting modeling and simulation applications, digital engineering environments, warfighter AI/ML workloads, user data, and platform services across both cloud and on-premises deployments. The successful candidate will work closely with platform engineers and DevSecOps teams to implement scalable, secure, and resilient storage services within (or alongside) Kubernetes-based environments and help shape GEMSTONE's long-term storage architecture for classified and unclassified deployments. Key Responsibilities: • Design and implement software solutions supporting platform storage and data persistence services. • Develop backend services that manage datasets, digital artifacts, metadata, user content, and workflow outputs. • Support design and operation of distributed storage solutions for Kubernetes-based environments and on-premises environments • Assist with design and implementation of hybrid (cloud-native and on-premises) storage architectures within Kubernetes environments. • Build and maintain web applications that allow users to discover, manage, publish, and access data assets. • Support development of APIs for data access, artifact publication, metadata management, and storage lifecycle operations. • Support persistent storage capabilities for interactive developer and engineering environments. • Develop automation supporting backup, replication, migration, archiving, and recovery workflows. • Collaborate with platform engineers to integrate storage services with identity, authorization, auditing, and monitoring solutions. • Participate in architecture reviews, Agile development activities, code reviews, and testing efforts. • Support deployment and validation through CI/CD pipelines. • Contribute to technical documentation and operational procedures.
