Fullstack Developer

PT Cycent Inovasi Kaizen Central Jakarta, Jakarta опубликовано 23 сентября 2026

Офис Контракт / B2B
PostgreSQLMySQLMicroservicesJava
Saat ini kami sedang membuka kesempatan bagi kandidat untuk bergabung bersama kami yang akan ditempatkan di perusahaan klien kami. Tanggung Jawab • Mendesain, mengembangkan, menguji, dan memelihara aplikasi menggunakan berbagai teknologi seperti Java, Golang, Angular, dan ReactJS. • Bekerja sama dengan tim UI/UX Designer untuk menerjemahkan desain menjadi tampilan aplikasi yang berkualitas tinggi. • Mengembangkan logika client-side dan server-side untuk memastikan performa serta responsivitas aplikasi. • Mengintegrasikan aplikasi web dengan database, server, dan API. • Melakukan debugging dan memperbaiki bug untuk meningkatkan performa aplikasi. • Mengikuti perkembangan teknologi terbaru dan mengusulkan penerapannya pada proyek yang relevan. • Melakukan pengujian QA, menyelesaikan masalah, dan memastikan kualitas perangkat lunak. • Berkolaborasi dengan anggota tim dan stakeholder lainnya. • Memastikan aplikasi mematuhi standar keamanan dan integritas data. Kualifikasi • Minimal S1 di bidang Ilmu Komputer, Teknologi Informasi, Teknik Informatika, atau bidang terkait. • Memiliki pengalaman minimal 3–5 tahun sebagai Fullstack Developer • Memiliki pengalaman kuat dalam pengembangan aplikasi menggunakan Java/Golang. • Java atau Golang menjadi skill utama yang dibutuhkan, dengan pengalaman hands-on dalam pengembangan aplikasi production. • Memahami konsep Object-Oriented Programming (OOP), Design Pattern, Clean Code, dan Software Development Lifecycle. • Berpengalaman dalam pengembangan RESTful API dan Web Services menggunakan Java/Golang. • Memiliki pemahaman yang baik mengenai SQL dan database seperti MySQL, PostgreSQL, atau Oracle. • Memiliki pengalaman dengan framework/library backend seperti Spring Boot (Java) atau framework/library yang relevan pada Golang menjadi nilai tambah. • Memiliki pengalaman menggunakan Angular dan/atau ReactJS untuk pengembangan frontend. • Memahami integrasi antara frontend, backend, database, dan external API. • Memahami konsep microservices, authentication/authorization, API security, dan application performance menjadi nilai tambah. • Memiliki kemampuan troubleshooting, analytical thinking, dan problem solving yang baik. • Mampu bekerja secara kolaboratif dengan tim dan memiliki kemampuan komunikasi yang baik. • Teliti, detail-oriented, dan mampu bekerja dengan target serta timeline yang ditentukan.
