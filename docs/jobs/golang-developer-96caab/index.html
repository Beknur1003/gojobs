Job Description : We are looking to hire a GoLang Developer. Role Expectations : - Design, develop, and maintain high-performance backend services and REST APIs using Go. - Build scalable, concurrent and low-latency applications. - Develop concurrent processing using goroutines, channels and worker pools. - Work with PostgreSQL/MySQL, MongoDB and Redis. - Implement caching, connection pooling, asynchronous processing and performance optimisation. - Integrate services with external APIs and distributed systems. - Write clean, testable and production-ready Go code. - Troubleshoot production issues and perform application performance tuning. - Work with Docker, Kubernetes and CI/CD pipelines. - Collaborate with architects, developers and DevOps teams. Required Skills : - Strong hands-on experience with Golang. - Good understanding of goroutines, channels, concurrency and memory management. - Experience developing REST/gRPC APIs and microservices. - Strong understanding of distributed systems and networking fundamentals. - Experience with PostgreSQL/MySQL and Redis/MongoDB. - Good understanding of Kafka or other messaging systems. - Familiarity with Docker, Kubernetes and Git. - Strong problem-solving and debugging skills. Good to Have : - Experience in financial/trading systems or high-throughput applications. - Experience building real-time/low-latency systems. - Knowledge of TCP/WebSocket and network programming. - Exposure to Prometheus, Grafana and ELK.
