技術研發中心 - SRE 技術副理

浪LIVE_旭瑞文化傳媒股份有限公司 Shilin District, Taipei City, Taiwan опубликовано 20 октября 2026

Гибрид Полная занятость
MySQLMongoDBRedisElasticsearchKubernetesDockerTerraformAWSGCPAzurePrometheusGrafanaOpenTelemetryLinuxCI/CDPython
【職務說明】 你是否同時具備策略思維與實作能力，並樂於在高壓、高流量的環境裡保持系統穩定？在浪LIVE，我們每天面對大量使用者、瞬間湧入的直播流量以及全球多區的併發需求。SRE 不只是維運服務，而是以工程方法確保整體平台在高強度負載下依然運作順暢，讓創作者與觀眾都能享受最佳的互動體驗。 身為浪LIVE 的 SRE，你將與跨職能技術團隊密切合作，參與平台可靠度的設計、容量規劃、效能優化與自動化治理。你將親手改善系統瓶頸、預防事故、建立可觀測性架構、擴展基礎設施，並以數據提升整體服務的穩定性。 如果你喜歡直面複雜度、熱衷解決高併發產品的挑戰，擁有旺盛的好奇心與跨領域協作能力，這裡將會是你持續成長、發揮影響力、打造世界級直播平台的最佳舞台。 【職務內容】 1. 負責基礎架構和所有產品的整體性能和可靠性，設計並實踐自動化且可靠和高性能系統的工具 2. 公有雲相關架構設計與建議 3. 管理基礎系統架構，了解上游和下游依賴關係 4. 部署和變更管理，金絲雀發布及其他流程 5. CI/CD 等 Pipline 或是 GitOps Flow 等相關整合 6. 彈性策略如負載和故障測試 7. 提高系統和流程的效率：容量規劃、配置管理、性能調整、監控和 Root Cause 分析等 8. 提高可用性、性能、效率和擴展架構 9. 系統意外事件處理 10. 成本費用管理 11. 資訊安全等議題管理 【技能條件】 1. 有 Container 相關技術以及經驗（Docker，Kubernetes，AWS ECS...etc） 2. AWS / GCP / Azure 等公有雲使用經驗（AWS優先） 3. 有高併發 API 挑戰應對經驗 4. 良好的 Shell Script 腳本技能 5. 具備 CDN 概念，能理解 Cache、Edge Rules、Origin、TTL、WAF、Routing 並分析與RD合作制定策略。 6. 熟悉至少一種程式語言 Python, Golang 7. Ansible / Puppet / Chef / Saltstack 等配置管理工具使用經驗 8. 使用過任意開源監控系統（Grafana，Prometheus，ELK，Jaeger...etc） 9. 使用過任何 IaC Solution（CDK，Terraform，Pulumi...etc） 10. 熟悉任一 Linux Distribution（Ubuntu Centos...etc） 【加分條件】 1. 具備對以下 DB 類的相關知識：Redis、MySQL、MongoDB、Elasticsearch 或類似技術 2. 了解 Networking 原理，例如不同的協議（TCP / IP、UDP、ICMP.. 等）、DNS、OSI 層和負載平衡 3. 了解 Unix / Linux 從 Kernel 到 Shell 及更多的知識如 System Call、File System、Protocols 4. 帶領團隊經驗（3人以上團隊為佳） 【面試流程】 第一輪 _ HR 線上面談 (60 分鐘) 讓我來分享有關公司以及職缺的細節，同時也讓我先多多認識你吧！ 第二輪 _ 用人團隊面談 (120 分鐘) • 白板題 • 可以清楚了解公司福利以及制度, 並且實際感受團隊開發流程及文化 • 歡迎提出任何關於工作內容 & 公司制度的相關問題
