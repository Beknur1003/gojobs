This position is listed on behalf of a partner company, who manages all applications and next steps. Our partner is looking for a Senior Software Engineer - Cloud Platform Engineering based in United States. This role offers the opportunity to build robust cloud infrastructure supporting a globally deployed relational database platform. You will work on application layers, business logic, APIs, and automation at the intersection of data management, cloud operations, and database services. The position combines hands-on software engineering with deep cloud orchestration across multiple public cloud environments. You will take ownership of features end to end, from technical design and implementation through deployment and production operations. The team operates with a lean structure and high individual ownership, giving engineers direct influence over architecture and engineering strategy. You will contribute to production-grade systems designed for reliability, scalability, security, and enterprise use. Accountabilities: • Design, implement, and operate application layers, business logic, API workflows, and cloud-native services supporting a globally distributed relational database platform. • Take end-to-end ownership of significant production features, from functional specifications and architectural design through implementation, deployment, debugging, and ongoing improvement. • Build and manage multi-cloud infrastructure across AWS, Azure, and GCP, ensuring reliable and reproducible deployments. • Develop Infrastructure as Code using Terraform to automate and standardize complex cloud environments and deployment workflows. • Design and maintain production-grade containerized applications and orchestration environments using Kubernetes and Docker. • Build and maintain robust CI/CD pipelines that support automated, scalable, and reliable software delivery. • Develop cloud-native applications, controllers, automation tooling, and backend services using Python and Go or another relevant backend language. • Design and implement REST and/or gRPC APIs consumed by external users, applications, or frontend systems. • Apply strong relational database expertise to data-intensive applications, including SQL development, indexing, query optimization, transactions, and schema design. • Implement data models and systems supporting temporal data, event tracking, audit logs, and system-versioned information. • Build secure application architectures incorporating authentication, authorization, RBAC, row-level security, and multi-tenant data isolation. • Develop and integrate AI application capabilities, including vector databases, embedding pipelines, semantic search, RAG systems, and LLM-based workflows. • Apply modern observability practices, including structured logging, distributed tracing with OpenTelemetry, monitoring, and functional alerting. • Contribute to emerging AI agent infrastructure, including agent frameworks, MCP servers, A2A integrations, agent memory systems, and related tooling where applicable. • Help evaluate and introduce technologies that improve scalability, reliability, performance, and developer productivity. • Collaborate closely with a small, high-ownership engineering team while contributing to technical direction and engineering standards. Requirements • 5+ years of professional software development experience, including at least 2 years focused on data-intensive applications, database-adjacent functionality, or enterprise software. • Deep experience with distributed systems and cloud-native architecture, with a track record of building and operating production infrastructure at scale. • Hands-on production experience deploying, debugging, and managing application services across at least two major public cloud platforms, with AWS, Azure, and GCP experience strongly relevant. • Advanced proficiency with Terraform and Infrastructure as Code, including complex cloud orchestration and reproducible deployments. • Strong experience with Kubernetes, Docker, and production-grade containerized environments. • Strong proficiency in Python for AI and cloud application development, together with advanced expertise in at least one backend language such as Go, Java, or C++. • Demonstrated expertise with relational databases, including complex SQL, indexing, query optimization, transactions, schema design, and temporal data models. • Experience designing and implementing REST and/or gRPC APIs for external consumers or frontend systems. • Experience with application security fundamentals, including authentication, authorization, RBAC, row-level security, and multi-tenant data isolation. • Experience building or integrating vector databases, embedding pipelines, semantic search, or retrieval-augmented generation systems. • Prior experience developing LLM-based applications or workflows using AI agent frameworks such as LangChain, LangGraph, CrewAI, AutoGen, or equivalent technologies. • Strong understanding of application monitoring, structured logging, distributed tracing, and alerting practices. • Demonstrated ability to take ownership of complex engineering initiatives and deliver production-ready solutions with limited supervision. • Strong analytical, problem-solving, communication, and collaboration skills, with an ownership-oriented approach to engineering. • A Bachelor’s or Master’s degree in Computer Science or a related technical field is preferred. • Experience contributing to open-source projects in databases, AI/ML applications, or agent tooling is a plus. • Experience developing MCP servers or integrating A2A protocols into production systems is advantageous. • Familiarity with agent memory frameworks such as Mem0, Graphiti, or Letta is beneficial. • Experience with graph databases, multi-hop graph traversal, semantic caching, or in-memory
