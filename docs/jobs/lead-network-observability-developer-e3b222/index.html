Responsibilities • Network observability platform: Design network observability platform and product architecture, based on best practices and scalable design patterns (reliability, availability, resilience, and fault tolerance) • Schema: Develop schemas for source data transformation and standardization to Zeek format. • Custom Analytics: Build custom analytics algorithms that deliver intelligent/predictive/insightful data. • Data ingestion: Design and build modern data ingestion pipelines from NSP monitoring systems. • Collaborate with Teams: Work with other software developers and business analysts to understand user needs and translate them into technical requirements. • Testing and Troubleshooting: Test APIs to ensure responsiveness and efficiency and identify and fix bugs or bottlenecks. • Documentation: Document development processes, standards, and guidelines for future reference and other developers. • Technical Support: Provide technical support for APIs, including troubleshooting and problem resolution. • Coaches and leads teams, as necessary. • Experience in system and software security (SSO, Kerberos, LDAP, Windows AD, etc.), ensuring robust identity and access management. • Application of engineering principles to production management, supporting scalable and efficient operations. • Proven track record in automation, effectively
