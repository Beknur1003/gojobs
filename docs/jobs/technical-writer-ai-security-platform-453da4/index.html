Technical Writer – AI Security Platform

Удалёнка Полная занятость English C1

Location: India, Remote-First Employment: Full-Time Start Date: February 2027 Experience: 4+ years Language: Fluent English required Industry: Cybersecurity / Enterprise SaaS / AI Security About the Opportunity Pragmatike is recruiting on behalf of a global enterprise cybersecurity company building a new generation of products to secure AI agents, LLM-powered applications, and the data they access. As the AI security platform moves toward general availability, customers, partners, and internal teams need documentation that is accurate, technically rigorous, and easy to act on. You’ll own the documentation ecosystem across product guides, API references, deployment and integration documentation, and release materials, working closely with Go engineers, Product Managers, and Support. We’re looking for a Technical Writer who is comfortable reading code and API specifications, can explain complex security and infrastructure concepts clearly, and uses AI tools to work more efficiently without compromising technical accuracy. What You’ll Do • Own end-user, administrator, and API documentation for the AI security platform, from initial structure through ongoing maintenance. • Create deployment and integration guides for gateway, endpoint, cloud discovery, and platform components, including code samples and configuration references. • Write release notes and in-product help, and maintain documentation standards and style guidelines. • Work directly with engineers to generate and maintain API documentation from OpenAPI and protobuf definitions, keeping documentation aligned with product releases. • Review technical examples and documentation for accuracy, consistency, and usability. • Gather feedback from customers and Support to identify documentation gaps and improve clarity. • Use AI tools to draft, review, update, and maintain documentation at scale while ensuring all technical content is properly validated. What We’re Looking For • 4+ years of technical writing experience for developer- or administrator-facing B2B software. • Ability to read Go, Python, OpenAPI, and protobuf well enough to accurately document APIs, configurations, and code examples. • Experience with docs-as-code workflows, including Markdown, Git, static site generators, and CI-based publishing. • Strong understanding of cybersecurity, cloud infrastructure, or related technical concepts, or a demonstrated ability to learn complex technical domains quickly. • Excellent written English with the ability to explain complex concepts clearly to both technical and non-technical audiences. • Practical experience using AI writing and coding assistants, combined with a rigorous process for reviewing and validating their output. • Comfortable collaborating with distributed engineering and product teams across time zones. • Strong ownership and attention to technical detail. Nice to Have • Experience documenting cybersecurity, cloud, infrastructure, or AI/ML products. • Experience with API documentation and publishing tools such as Redocly, Stoplight, Docusaurus, or equivalent. • Basic Python or scripting skills for documentation automation. • Experience working directly with engineering teams in a docs-as-code environment. AI-First Team AI is a core part of how this team works. During the interview process, you'll be asked about how you use AI in your documentation workflow, including the tools you rely on, how you validate their output, and where AI has changed the way you work. We're looking for people who use AI as a force multiplier for research, productivity, problem-solving, and documentation quality, while maintaining a high bar for technical accuracy. Why Join • Help shape the documentation for a new AI security platform as it moves toward general availability. • Work directly with engineers, product teams, security researchers, and customers on emerging AI security challenges. • Own a documentation ecosystem spanning APIs, integrations, deployment, administration, and product education. • Work on technically complex products at the intersection of cybersecurity, cloud infrastructure, and agentic AI. • Join a highly technical, distributed team where AI is a core part of daily work.
