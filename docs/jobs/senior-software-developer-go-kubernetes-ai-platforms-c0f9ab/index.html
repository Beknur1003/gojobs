About the Role We are seeking an experienced Software Developer to join our engineering team as we build scalable, next-generation backend systems and AI-powered platforms. In this role, you will design and implement resilient microservices written in Go, deploy and orchestrate workloads in Kubernetes, and build pipelines that integrate advanced AI models into production software. If you thrive in an Agile environment, build reliable CI/CD pipelines, and are excited about bridging modern cloud-native architectures with AI systems, we want to hear from you. Key Responsibilities • Microservices Development: Design, write, test, and maintain high-performance, clean, and concurrency-focused microservices using Golang. • Cloud-Native Deployment: Containerize applications using Docker and orchestrate microservices across Kubernetes clusters. • AI Platform Integration: Build robust API layers and backend services that integrate with machine learning models and AI platforms (e.g., OpenAI API, LangChain, custom LLMs, or MLOps platforms). • CI/CD & Automation: Design and maintain automated CI/CD pipelines to ensure seamless testing, building, and zero-downtime deployment. • Agile Collaboration: Participate actively in Agile ceremonies (Sprint Planning, Daily Standups, Code Reviews, Retrospectives) and deliver feature backlogs on schedule. • System Design & Security: Implement strict security practices, perform root-cause analysis, and write unit, integration, and end-to-end tests. Required Qualifications • 3+ years of hands-on software development experience with strong proficiency in Go (Golang). • Solid experience designing and managing microservices architectures deployed on Kubernetes (Helm, kubectl, service meshes). • Hands-on experience integrating with AI platforms / ML APIs or supporting AI/ML application infrastructure. • Proven experience building and maintaining CI/CD pipelines (e.g., GitHub Actions, GitLab CI, ArgoCD, Jenkins). • Strong understanding of Agile/Scrum methodologies and collaborative software engineering best practices. • Deep understanding of RESTful APIs, gRPC, relational/non-relational databases, and Git workflows. Desired Skills • Experience with MLOps frameworks or AI orchestration tools. • Familiarity with cloud providers (AWS, GCP, Azure). • Knowledge of message queues (Kafka, RabbitMQ, NATS). About EndLine Systems EndLine Systems is a startup focused on specialized engineering for complex missions across network engineering, systems engineering, software development, and cybersecurity. We are seeking engineers who enjoy tackling multi-disciplinary technical challenges and delivering reliable, field-ready solutions.
