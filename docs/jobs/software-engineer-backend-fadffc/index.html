Software Engineer (Backend)

Aegion AI Bangalore опубликовано 5 октября 2026

Aegion AI is looking for passionate and highly skilled Software Engineers to build scalable, high-performance backend systems and AI-powered applications. We are seeking engineers with strong problem-solving abilities, a product mindset, and hands-on experience in backend development, distributed systems, or AI-driven platforms. Responsibilities: • Design, develop, and maintain scalable backend services and APIs. • Build high-performance, reliable, and secure software solutions. • Develop AI-enabled applications and integrate Large Language Models (LLMs) where applicable. • Work on distributed systems, microservices, and cloud-native architectures. • Collaborate with cross-functional teams, including Product, AI/ML, and Frontend Engineering. • Write clean, maintainable, and well-tested code while following engineering best practices. • Participate in architecture discussions, code reviews, and technical decision-making. The core requirements for the job include the following: Option 1 - Backend Engineer (Python + AI): • Strong experience in Python • Hands-on experience with FastAPI • Experience building or integrating AI/LLM-based applications • Strong understanding of REST APIs, backend architecture, and scalable systems Option 2 - Full Stack Engineer (Python + AI): • Strong experience in Python. • Hands-on experience with FastAPI. • Frontend expertise in React.js, JavaScript, or Node.js . • Experience working on AI/LLM-powered applications. Option 3 - Core Backend Engineer: • Strong programming experience in Java, Python, or Golang. • Hands-on experience designing and building distributed systems. • Strong understanding of system design, scalability, concurrency, and backend architecture. Option 4 - Backend Engineer (OOP + AI): • Strong programming expertise in Java, Python, or Go. • Experience building or integrating AI/Generative AI/LLM solutions. • Strong backend engineering fundamentals and scalable API development.
