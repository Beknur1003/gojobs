The Role A Senior Backend Engineer to design, build, and operate a production backend platform written in Go. This role is responsible for backend APIs, queue-driven services, document-processing workflows, data integrations, and the engineering standards that keep the system reliable, testable, and maintainable. The engineer in this role should be able to move from technical design to implementation to production support while communicating clearly with product, engineering, and operations stakeholders. Work You’ll Do • Design, implement, and maintain backend services and APIs in Go for a distributed, event-driven platform. • Write clear technical design specs, implementation plans, and engineering documentation before and during delivery. • Own backend architecture decisions across service boundaries, data flow, reliability, performance, and operational readiness. • Build and maintain integrations with core infrastructure such as PostgreSQL, AWS services, object storage, queues, and authentication/authorization systems. • Improve test coverage, debugging practices, observability, and release quality across the backend codebase. • Review code rigorously, provide actionable feedback, and help set a high technical bar for simplicity, correctness, and maintainability. • Communicate effectively with the team on scope, risks, tradeoffs, execution status, and production issues. • Use modern LLM coding harnesses such as Claude Code, Codex, and similar tools effectively to accelerate engineering velocity while preserving code quality, review discipline, and sound technical judgment. • Other duties as assigned Requirements • 8 or more years of professional backend engineering experience, including significant production experience in Go/Golang. • Deep expertise in designing and shipping backend APIs, asynchronous workers, and distributed systems. • Strong experience with relational databases, API contracts, integration patterns, and production debugging. • Demonstrated ability to write design documents, break work into implementation plans, and lead delivery of backend features end to end. • Strong understanding of testing strategy, code review, CI/CD, and operational excellence in production systems. • Clear written and verbal communication skills, with the ability to collaborate well across engineering and non-engineering partners. • Proven ability to use AI-assisted engineering tools productively and responsibly, especially LLM-based coding environments and agentic coding workflows. Preferred Qualifications • Experience with AWS services such as S3, SQS, Cognito, and related cloud-native backend patterns. • Experience with OpenAPI, generated clients or servers, background job pipelines, and document-processing systems. • Experience working in a codebase with strong quality expectations around reliability, observability, security, and test coverage.
