Senior Software Engineer - K0s Team

mirantis Helsinki, Uusimaa, fi опубликовано 6 июля 2026

Удалёнка Senior
KubernetesAWSLinuxCI/CD
We’re seeking a Software Engineer with a passion for shaping the future of k0sproject. As a CNCF Sandbox project, k0s is an open source, all-inclusive Kubernetes distribution, which is configured with all of the features needed to build a Kubernetes cluster and packaged as a single binary for ease of use. We’re tackling an interesting problem: How do we package and operate Kubernetes itself in the simplest possible way but still allowing enough flexibility for varying use cases. Within Mirantis, you’ll join a remote team of fellow maintainers for k0s and related project as well as the larger OSS ecosystem maintainers. We’re looking for someone within European timezones. As part of Mirantis, you’ll also help shape our Kubernetes and container ecosystem products that rely on various upstream projects as well as collaborate on other upstream projects. Responsibilities: • Develop and maintain upstream k0s related projects under the CNCF umbrella • Design and implement • Integrating new features from the cloud native technologies landscape that compliment the Mirantis Kubernetes products • Following the latest developments in the container technology ecosystem and identifying matters that could impact the product roadmap • Act as a cloud native software and technologies subject matter expert and evangelist within the company and broader community • Strong Kubernetes experience, the deeper the better • Experience in Linux, VMs, networking, containers and the general tech stack that makes cloud-native tick • Ability to write clean and maintainable (Golang) code • Strong engineering background with meaningful track record on Github • You value pragmatism and result-oriented team and project work • Good communication skills in English The tech stack you’ll be working with includes things like: • Kubernetes • Golang • Linux • VMs (Lima, qemu, kvm, etc.) • GitHub Actions • k0s (k0sproject.io/) What does Mirantis offer you? • Work with an established Silicon Valley leader in the cloud infrastructure industry. • Work with exceptionally passionate, talented and engaging colleagues, helping Fortune 500 and Global 2000 customers implement next-generation cloud technologies. • Be a part of cutting-edge, open-source innovation. • Thrive in the high-energy environment of a young company where openness, collaboration, risk-taking, and continuous growth are valued. • Professional development and training. • Attend conferences and working groups. • Customized workstation (macOS, Windows). • A competitive compensation package with strong benefits plan and stock options. • Salary range: $70000-$80000 gross yearly It is understood that Mirantis, Inc. may use automated decision-making technology (ADMT) for specific employment-related decisions.
