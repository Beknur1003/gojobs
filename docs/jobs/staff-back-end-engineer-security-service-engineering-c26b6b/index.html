정신을 갖추고 새로운 혁신과 이니셔티브를 추진할 수 있는 기회가 주어집니다. 주저없이 일에 뛰어들어 성과를 이루고자 하는 과감성이, 바로 쿠팡이 일하는 방식의 본질입니다. 쿠팡에서는 여러분 자신, 동료, 팀 그리고 회사 전체가 매일 성장하는 모습을 목격할 것입니다. 쿠팡의 모든 직원은 커머스의 미래를 만들겠다는 쿠팡의 미션에 진심입니다. 우리는 고객의 문제를 해결해 나가고, 전통적인 관념과 통념에 맞서며 실현가능한 한계를 뛰어넘고 있습니다. 고가용성(Always-on) 과 최첨단의 앞선 기술(High-tech), 초연결사회(Hyper-connected world) 에서의 놀라운 업무 경험을 원하신다면, 지금 바로 쿠팡에 합류하세요. 직무 소개 쿠팡은 빠르게 성장하는 글로벌 기술 환경에서 보안 수준을 지속적으로 강화하기 위해 대규모 Security Platform 및 Security Capability를 설계하고 구축할 Staff Security Software Engineer를 찾고 있습니다. 이 포지션은 단순한 보안 운영 역할이 아닌, 대규모 분산 시스템과 보안 플랫폼을 직접 설계·개발하는 Hands-on Individual Contributor(IC) 역할입니다. 보안, 플랫폼, 인프라, 소프트웨어 엔지니어링 조직과 협업하며 회사 전반의 보안 역량을 향상시키는 솔루션을 구축하게 됩니다. 또한 새로운 기술과 AI 기반 보안 기술을 활용하여 보안 문제를 해결하고, 조직 전반의 기술 방향성에 영향을 미치는 역할을 수행하게 됩니다. 업무 내용 • 전사적으로 영향력 있는
