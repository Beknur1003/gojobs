Je krijgt de kans om jezelf continu te blijven ontwikkelen in een dynamische omgeving. Met je Manager stel je een persoonlijk ontwikkelplan op en samen bepalen jullie welke opleidingen, training(en) en opdrachten passen bij jouw ontwikkelingswensen.
