Responsibilities • Cloud database onboarding: Partner with application teams to assess requirements and onboard workloads to curate Azure database services. • Database migration: Plan and execute migrations of Oracle and Microsoft SQL Server databases from on-premises environments to Azure, while minimizing risk and service disruption. • Platform modernization: Identify suitable opportunities to modernize Oracle or Microsoft SQL Server workloads toward PostgreSQL. • Reliability engineering: Define and improve database availability, performance, backup, recovery, resilience, capacity, and operational readiness. • Build reusable database capabilities and automated workflows using Golang, Infrastructure as Code, and platform engineering tools. • Establish monitoring, alerting, logging, and operational practices that support dependable database services at scale. • Work closely with application, cloud platform, security, compliance, and vendor teams to deliver sustainable solutions. Skills Requirement • Bachelors degree in Computer Science/Engineering/Information Technology • 5-7 years of experience with Oracle and/or Microsoft SQL Server in enterprise environments, including at least 2 years in a Database Reliability Engineering role. • Proven experience migrating databases from on-premises platforms to Azure database services, including Azure SQL, Oracle on Azure, and/or Azure Database for PostgreSQL. • Strong understanding of Azure architecture, cloud operations, platform reliability, and production support principles. • Experience designing and implementing automated, self-service database capabilities using Golang, Infrastructure as Code, or comparable platform tooling. • Strong ownership orientation, with practical experience applying automation, reliability, and continuous improvement principles. • Excellent communication skills and the ability to work effectively across application, platform, governance, and vendor teams. • Pragmatic, solution-oriented, and comfortable operating in complex enterprise environments with compliance and regulatory constraints. Good to Have • Hands-on experience migrating Oracle or Microsoft SQL Server databases to PostgreSQL. • Azure certifications related to database administration, Azure architecture, or Site Reliability Engineering. • Experience with database assessment and migration tooling, including schema conversion and compatibility analysis. • Experience working in agile delivery models such as SAFe across multiple teams and initiatives.
