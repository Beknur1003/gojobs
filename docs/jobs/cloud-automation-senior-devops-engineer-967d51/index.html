This position is listed on behalf of a partner company, who manages all applications and next steps. Our partner is looking for a Cloud Automation Senior DevOps Engineer based in India. This is a senior-level opportunity focused on building and operating scalable, secure, and highly automated cloud platforms. You will design, deploy, and support cloud-native solutions across Google Cloud Platform (GCP), working at enterprise scale. The role combines platform engineering, DevSecOps, infrastructure automation, software development, and Site Reliability Engineering practices. You will partner closely with engineering, security, and product teams to improve reliability, security, developer productivity, and cost efficiency. A major focus will be on infrastructure as code, CI/CD, GitOps, cloud automation, observability, and operational resilience. You will also contribute to architecture decisions and modernization initiatives while providing technical leadership across complex cloud environments. This role is ideal for an experienced cloud engineer who enjoys solving challenging problems and turning business requirements into robust technology solutions. Accountabilities: • Design, deploy, operate, and continuously improve cloud-native solutions across Google Cloud Platform. • Take operational ownership of critical cloud services and participate in on-call rotations to maintain reliable production operations. • Develop, maintain, and standardize infrastructure as code using Terraform and established IaC practices. • Build and manage CI/CD workflows using Tekton Pipeline as Code (PAC). • Develop automation tools, services, and APIs using Python to reduce manual effort and operational overhead. • Deploy and manage applications on OpenShift and implement GitOps-based delivery using ArgoCD. • Administer and optimize key GCP services, including Google Compute Engine, Cloud Run, Cloud Tasks, Pub/Sub, Cloud Scheduler, Batch, Cloud Storage, and Security Token Service. • Design and maintain IAM roles, policies, permissions, and other cloud security controls. • Implement High Availability, Disaster Recovery, and operational resilience strategies based on SRE principles. • Monitor platform health, reliability, and performance using observability solutions such as Dynatrace. • Lead cloud patching, vulnerability remediation, security improvements, and compliance initiatives. • Identify and implement opportunities for cloud cost optimization and improved developer self-service. • Contribute to cloud architecture decisions, technology roadmaps, modernization programs, and long-term platform strategy. • Provide technical leadership and collaborate with stakeholders to translate business requirements into scalable and sustainable cloud solutions. Requirements: • Bachelor's degree in Computer Science, Engineering, or a related technical discipline, or equivalent practical experience. • 8+ years of professional experience in cloud engineering, DevOps, platform engineering, infrastructure automation, or a closely related field. • 3+ years of experience working in a senior technical, technical leadership, or engineering leadership capacity. • Strong hands-on expertise with Google Cloud Platform and enterprise-scale cloud environments. • Practical experience administering GCP services such as Compute Engine, Cloud Run, Cloud Tasks, Pub/Sub, Cloud Scheduler, Batch, Cloud Storage, and IAM. • Advanced experience with Terraform and Infrastructure as Code methodologies. • Strong Python scripting and software development capabilities, particularly for automation and platform tooling. • Experience deploying and operating applications on OpenShift. • Hands-on experience implementing GitOps practices with ArgoCD. • Strong understanding of DevSecOps, cloud security, identity and access management, and compliance best practices. • Experience designing and implementing High Availability and Disaster Recovery solutions. • Strong troubleshooting, problem-solving, communication, and stakeholder management skills. • Ability to provide technical direction, influence engineering teams, and make sound architectural decisions. • Experience working in complex enterprise environments with distributed workloads and large-scale cloud platforms. • Preferred experience with Red Hat Developer Hub and React-based portal development or customization. • Knowledge of Golang is an advantage. • Experience leading cloud modernization initiatives and building enterprise-scale automation ecosystems is highly desirable. Benefits: • Fully remote working opportunity based in India. • Opportunity to work with enterprise-scale cloud infrastructure and modern platform engineering technologies. • Hands-on exposure to GCP, Terraform, OpenShift, ArgoCD, Tekton, Python, Dynatrace, and cloud-native services. • Opportunity to influence cloud architecture, modernization initiatives, security strategy, and technology roadmaps. • Senior-level technical ownership and leadership across critical cloud platforms. • Work focused on automation, developer self-service, operational resilience, and continuous improvement. • Cross-functional collaboration with engineering, security, product, and other technology teams. • Opportunity to develop expertise across DevOps, DevSecOps, SRE, GitOps, cloud security, and infrastructure automation. • Flexible remote environment with a focus on delivering reliable, scalable, and cost-effective cloud services.
