Senior Kubernetes Platform Engineer

Tcs Ct Usa Austin, Texas, United States опубликовано 9 ноября 2026

Офис Senior Контракт / B2B
KubernetesAWSGCPCI/CDPython
We are looking for an experienced Cross-Plane Kubernetes Engineer with strong expertise in Kubernetes platform engineering, infrastructure operations, cloud technologies, and software development. The ideal candidate will be responsible for building, supporting, managing, and troubleshooting Kubernetes platforms across cloud environments while developing automation and tooling using Python and Go (Golang). The role requires a strong understanding of compute infrastructure, distributed systems, DevOps practices, CI/CD pipelines, and the software layers that support large-scale cloud-native applications. Key Responsibilities • Kubernetes Platform Engineering: Design, build, deploy, manage, and support Kubernetes clusters, including control plane and worker nodes, cluster lifecycle management, upgrades, scaling, and performance optimization. • Cross-Plane Operations: Troubleshoot and resolve issues across Kubernetes control plane, data plane, compute infrastructure, networking, storage, and application layers. • Software Development: Develop automation tools, utilities, and infrastructure management solutions using Python and Go (Golang). • Public Cloud Infrastructure: Work with third-party cloud providers, preferably AWS and Google Cloud Platform (GCP), to deploy and manage scalable, reliable cloud infrastructure. • DevOps and CI/CD: Implement and maintain CI/CD pipelines, automated deployments, infrastructure-as-code workflows, configuration management, and release automation. • Infrastructure Troubleshooting: Diagnose complex issues involving compute resources, CPU and memory utilization, resource scheduling, networking, storage, operating systems, and application dependencies. • Compute and Capacity Management: Understand workload requirements, resource allocation, capacity planning, performance tuning, and infrastructure optimization. • Observability and Reliability: Implement and improve monitoring, logging, alerting, and troubleshooting practices to ensure platform availability and reliability. • Operational Excellence: Automate repetitive operational tasks, improve platform scalability, reduce manual intervention, and contribute to incident management and root-cause analysis. • Cross-Functional Collaboration: Work closely with development, infrastructure, networking, security, and operations teams to resolve complex technical issues and improve platform capabilities. Skills: Digital : DevOps Continuous Integration and Continuous Delivery (CI/CD) Experience - 8+
