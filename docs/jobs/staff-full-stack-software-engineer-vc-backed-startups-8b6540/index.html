Who Should Join? We’re looking for engineers who are: ✔ Passionate about building and scaling web applications across the full stack ✔ Excited about collaborating across frontend, backend, and infrastructure teams ✔ Experienced in developing APIs, microservices, and cloud-based architectures Typical Roles & Responsibilities • Design, develop, and maintain full stack applications, from front-end interfaces to scalable backend systems • Build APIs, microservices, and cloud-based services that power innovative products • Write clean, maintainable, and efficient code across the stack • Work closely with product, design, and engineering teams to align technical strategy with business goals • Optimize applications for scalability, performance, and security • Establish best practices for code quality, testing, and CI/CD Common Qualifications While each startup has its own hiring criteria, many staff full stack engineering roles in our network look for: • 5+ years of experience in full stack development, with a strong track record of shipping products • Proficiency with front-end frameworks (React, Angular, Vue.js, Svelte) • Expertise in backend frameworks (Node.js, Django, Flask, Ruby on Rails, FastAPI) • Strong experience with cloud platforms (AWS, GCP, Azure) and containerization (Docker, Kubernetes) • Proficiency in relational and NoSQL databases (PostgreSQL, MySQL, MongoDB, DynamoDB) • Familiarity with CI/CD pipelines and infrastructure-as-code tools • Strong coding skills in JavaScript, TypeScript, Python, Ruby, Go, or Java 💡 Technologies You Might Work With: • Languages & Frameworks: JavaScript, TypeScript, Python, Ruby, Golang, Java, React, Angular, Vue.js, Svelte, Node.js, Django, Flask, Ruby on Rails, FastAPI • Databases: PostgreSQL, MySQL, MongoDB, DynamoDB, Redis • Cloud & DevOps: AWS (Lambda, EC2, S3, RDS), GCP (App Engine, Firestore), Azure, Docker, Kubernetes, Terraform, Jenkins, GitHub Actions • Other Tools: GraphQL, REST APIs, WebSockets, Elasticsearch What Happens Next?
