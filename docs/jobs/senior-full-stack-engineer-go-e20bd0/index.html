A proprietary trading and research firm is hiring experienced full-stack engineers to build the user interfaces and services behind mission-critical financial applications, including visual analytics platforms and data-driven tools used by traders, researchers, and analysts. You will work on TypeScript front-ends and the Go services that serve them as the team evolves its applications into a modular, plugin-based platform that other engineers build on. Expect to build reusable UI modules, component libraries, and SDKs as much as end-user features, and to own your work from structured product requirements through to production. No trading or finance background is required; the team cares about engineering craft and will teach you the domain. What You'll Do • Collaborate with traders, researchers, and product managers to translate complex workflows into elegant UI solutions • Design and implement high-performance, responsive front-end applications using a current-generation TypeScript framework such as Svelte, React, or Vue • Design, build, and operate Go back-end services with security and performance built into their design, owning service boundaries and data contracts end-to-end • Build reusable UI modules, component libraries, and SDKs for a modular, plugin-based platform, and integrate front-ends through typed SDKs and MCP-based interfaces • Build real-time UIs that ingest and render high-frequency market and on-chain data from multiple streaming sources, using canvas-based charting (for example uPlot or TradingView Lightweight Charts) and D3.js for bespoke views • Drive architecture and performance decisions for modular, extensible systems, maintain automated tests and code review, and mentor other engineers on best practices Core Essentials • 7+ years hands-on full-stack development, with production ownership on both back-end and front-end • Strong, current TypeScript, HTML, and CSS with one or more modern front-end frameworks (Svelte, React, or Vue), and adaptability to work in a team's chosen framework • Strong, current Go experience, able to design, build, and operate production Go services independently • Proven experience handling large datasets and real-time updates from back-end sources such as WebSockets or Server-Sent Events, plus building reusable, well-structured UI components and shared abstractions • Strong grasp of performance optimization and rendering strategies in data-heavy applications, including the JavaScript runtime • Solid testing discipline, with unit and integration tests as a normal part of delivery • Excellent cross-functional communication, plus familiarity with a major cloud platform (AWS, GCP, or Azure) and version control Bonus Skills • Background or strong interest in trading systems or financial platforms, including prior hedge fund or proprietary trading work • Experience with real-time, streaming, or on-chain / crypto market data • Experience with MCP (Model Context Protocol) or other AI-native / agent integration • Experience building developer platforms, SDKs, or shared component libraries, and with CI/CD, Docker, and observability tools such as Datadog, Grafana, or ELK Originally posted on Himalayas
