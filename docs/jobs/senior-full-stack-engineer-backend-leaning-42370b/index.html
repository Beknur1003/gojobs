Technologies we use Expected • Python • TypeScript Optional • Coupa • SAP Ariba • Oracle • NetSuite • Kafka • Go • Java • Kotlin • C# • Rust About the project We're hiring a senior engineer to help build the products our customers run their sourcing on - events, supplier bids, awards, and the integrations that connect Fairmarkit to the ERPs and procurement suites they already use. The work is full-stack and leans back end. Most of your time goes into domain models, APIs, event-driven services and data that has to be right. Front-end engineers and dedicated designers work on the UI with you, so you need to be comfortable shipping a screen to production, but not necessarily an expert. You won't be pinned to one feature. As priorities change you'll go where the work matters most, which might be sourcing workflows one quarter and an ERP integration the next. If you like learning a new domain quickly and leaving it better than you found it, you'll do well here. We're not just "using AI". We build our own internal tooling, agentic systems and custom harnesses that improve how we collaborate, how we ship, and what we deliver to customers. If anything, AI raises the bar. The corners we used to cut to ship on time are work we can now hand to AI in parallel. We care about engineering excellence in the traditional sense: discipline, rigor, well-designed systems, and code we're glad to maintain a year from now. AI writes more of the syntax than it used to. Your judgment shows up everywhere else, from framing the problem and designing the system to reviewing what gets built, testing it and running it in production.
