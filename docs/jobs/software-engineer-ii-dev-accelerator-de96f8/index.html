About the Team Abnormal AI is looking for a Software Engineer II to join the Dev Accelerator Team. The Dev Accelerator team builds and operates our internal developer platform: the tools, libraries, and infrastructure that let 100+ engineers design, build, test, and ship products quickly and safely. Some of the pieces we’ve been working on recently • Autonomous PR generators for rolling out migrations and linter rule enforcement • Testing frameworks for enabling clear end to end test support with data generation and coverage tooling • Optimizing CI execution speeds • Developer CLI tooling: a “Prompt-to-Product” style CLI that scaffolds services end to end, environment and credentials tooling, and a broad set of internal developer scripts • Large scale code migrations to improve the shape of the codebase for AI efficacy Our goal is to make the easy path the right path for product teams and AI agents building on the platform. What You’ll Do As a Software Engineer II, Dev Accelerator, you will: • Develop and evolve the internal developer platforms that supports development across Abnormal • Own high-leverage projects across CLI tooling, CI/CD, shared libraries, and test infrastructure. • Work across Python, Go, Bazel, Kubernetes, AWS, and CI systems to make our Golden Path fast, reliable, and intuitive. • Shape abstractions and workflows that are AI-native, consumable by both humans and AI agents. This is an individual-contributor role with ownership of multi-quarter initiatives. Success requires close collaboration with product engineering, Infrastructure, SRE, Security, and other partner teams. Must Haves • 3+ years of experience as a software engineer or in a similar role • Proficiency leveraging AI tools to accelerate engineering outcomes through discovery, design, implementation, and rollout of software systems. • Experience or strong interest in using LLMs to improve developer workflows (e.g., failure summarization, smart code generation, AI-native CLIs). Nice to Have • Familiarity with our stack: Python, Golang, Bazel, AWS, Kubernetes, Github Actions • Built or maintained CLI tools, scaffolding systems, or internal frameworks used by other engineers. • Experience with test data management, integration/E2E test infrastructure, or bad-test detection. • Hands on experience in • CLI development • YAML/Jinja2-style templating. • Modern type hints and typing discipline (e.g., typing, dataclasses / attrs, Pydantic-style patterns). • Testing with standard frameworks like pytest/Ginkgo or similar. • Shared library and service development (gRPC/HTTP). • Authoring reusable workflows • #LI-NT1 A note on AI in our process: Abnormal AI uses AI-assisted tools to help our recruiting team prepare for candidate interviews.
