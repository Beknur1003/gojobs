Golang Developer

HARJAI COMPUTERS PRIVATE LIMITED Mumbai City; Navi Mumbai, Maharashtra опубликовано 12 ноября 2026

Go — основной язык Полная занятость
Microservices
This role is a great fit for those with a strong background in Golang development and a desire to work on scalable applications. As a Golang Developer, you will engage in designing, implementing, and maintaining high-performance software solutions that align with client requirements. Key responsibilities include: - Develop and sustain robust applications utilizing the Go programming language. - Collaborate with various teams to define, design, and launch new features effectively. - Troubleshoot and debug existing applications to enhance performance. - Write clean, maintainable, and efficient code consistent with software best practices. - Participate in code reviews while contributing to team knowledge sharing. - Stay informed on the latest trends and technologies in Golang development. Proficiency in Golang is essential, along with a solid understanding of software development principles. Experience with version control systems like Git, familiarity with RESTful APIs, and an understanding of microservices architecture are also required. Collaborative skills are critical for success in this role.
