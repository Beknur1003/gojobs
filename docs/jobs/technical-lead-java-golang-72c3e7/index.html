About the Role: IDFC FIRST Bank is looking for a hands-on Technical Lead with strong expertise in Java and/or Go to build and scale digital banking platforms. This is a predominantly Individual Contributor (70% hands-on) role focused on coding, system design, microservices, distributed systems, and cloud-native architectures, while providing technical leadership and mentoring across engineering teams. Total Experience: 7-11 years Architecture and Engineering: - Design and develop scalable, secure, highly available backend systems using Java (Spring Boot) and/or Golang. - Architect and build microservices, REST APIs, event-driven systems, and distributed applications. - Drive technical design, system architecture, scalability, resiliency, and performance optimization initiatives. - Lead modernization efforts for enterprise applications and digital banking platforms. - Ensure production readiness through robust observability, monitoring, fault tolerance, and security controls. Hands-on Development (70%): - Write clean, scalable, production-grade code. - Perform code reviews, architecture reviews, and technical deep dives. - Troubleshoot complex production issues and drive root-cause analysis. - Drive engineering excellence through test automation, CI/CD, DevOps, and secure coding practices. - Leverage AI-assisted development tools to improve productivity and code quality. Technical Leadership (30%): - Mentor engineers and establish engineering best practices. - Collaborate with product managers, architects, SREs, DevOps, and business stakeholders. - Manage technical dependencies across multiple platforms and engineering pods. - Drive Agile delivery, technical governance, and engineering standards. Requirements: - 7+ years of backend engineering experience. - Currently hands-on with coding and architecture. - Proven experience leading technical initiatives without moving away from development. - Strong problem-solving skills with the ability to influence architecture and engineering decisions. - Passionate about building scalable, resilient, and secure platforms. Mandatory Technical Skills: - Java, Spring Boot, Spring Cloud, and/or Go. - Microservices Architecture and REST API Development. - Distributed Systems and Event-Driven Architecture. - Kafka / Messaging Platforms. - SQL and NoSQL Databases (PostgreSQL, MySQL, Oracle, MongoDB). - Cloud Platforms (AWS/Azure/GCP). - Docker, Kubernetes, Containerization. - CI/CD Pipelines, Git, DevOps Automation. - System Design, Scalability, and Performance Engineering. - API Security, OAuth, JWT, Authentication, and Authorization. - Monitoring and Observability (Grafana, Prometheus, ELK, Splunk). - Design Patterns, Automated Testing, and Engineering Best Practices.
