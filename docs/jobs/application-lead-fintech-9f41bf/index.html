Application Lead - Fintech

Our client is a growing financial services business that is building its technology function in Singapore. They’re hiring an Applications Lead to shape how the platform is architected and built. This is a hands-on leadership role: you’ll set the technical direction and still write code every day. What you’ll be doing • Set the architecture, tech stack and integration standards for the organisation’s applications • Write code yourself across backend and frontend, and build RESTful APIs and event-driven integrations • Embed security into the development lifecycle: CI/CD controls, SAST/SCA scanning, secret scanning and dependency management • Set clear standards for code reviews, testing and documentation, and approve pull requests • Guide database design, containerisation and cloud-native deployment • Use AI coding tools such as Claude and GitHub Copilot to speed up delivery, and set guardrails so the team uses them responsibly • Lead and mentor a small engineering team, and run sprints, backlog priorities and capacity planning • Manage external development vendors and service providers • Support the organisation’s ISO 27001 work from the application side What we’re looking for • 10+ years in fullstack software engineering, including at least 3 years as a tech lead or architect • Experience building enterprise production systems with microservices, event-driven architecture and API gateways • Backend: Golang, Java/Spring Boot or Python • Frontend: React and TypeScript • Messaging and event streaming: Kafka or similar • Databases: MySQL or PostgreSQL, including schema design and query performance tuning • Docker, CI/CD pipeline governance, and cloud experience on AWS, Azure or GCP • Testing: functional and non-functional (e.g. JUnit, Jest, Selenium, SonarQube, Gatling) • Experience in financial services, fintech or another regulated industry is strongly preferred • Exposure to ISO 27001 and mobile development (iOS/Android) is a plus • AWS Solutions Architect or TOGAF certification is a bonus
