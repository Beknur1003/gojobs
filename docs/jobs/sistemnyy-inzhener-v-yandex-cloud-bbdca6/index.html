Системный инженер в Yandex Cloud

Yandex опубликовано 25 сентября 2026

Команда Yandex Cloud расширяет количество доступных сервисов и совершенствует свои продукты. Мы ищем системного инженера, который поможет решать технические проблемы пользователей инфраструктурного облака. Откликайтесь, если способны разбираться в нестандартных ситуациях и предлагать решения.Консультировать клиентов Yandex Cloud по вопросам, возникающим в ходе пользования сервисами облака Вам предстоит заниматься развёртыванием тестовых стендов для диагностики managed-решений Yandex Cloud и искать оптимальные способы реализации сценариев клиентов, воспроизводить сложные технические кейсы пользователей, решать их, а при необходимости инициировать решение на уровне сервисов. Важная задача — своевременно распознавать технические инциденты на инфраструктуре и совместно с командами сервисов участвовать в их решении, сотрудничать с senior-инженерами направления в ходе решения обращений.
