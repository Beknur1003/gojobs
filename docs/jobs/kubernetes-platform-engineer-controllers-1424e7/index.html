Kubernetes Platform Engineer (Controllers) Sony Interactive Entertainment At PlayStation, we're leading the revolution in cloud gaming as we push the boundaries of what's possible! Would you like to use your skills, time, and passion for meaningful projects that are building the future? We're looking for a Platform Engineer who enjoys building Kubernetes-native systems and automation that operate reliably at global scale. If you're passionate about software engineering, Kubernetes, and solving challenging distributed systems problems, we'd love to hear from you. Come help us deliver a unique gaming experience to millions of players around the world. Responsibilities • Design and develop Kubernetes controllers and operators that automate the lifecycle of platform services. • Contribute to the development of our global workload placement system, enabling intelligent scheduling across Kubernetes clusters running in both public cloud and on-premises data centers. • Develop Kubernetes APIs and Custom Resource Definitions (CRDs) that provide clean, maintainable interfaces for platform capabilities. • Build and maintain reconciliation logic that safely manages distributed system state. • Develop controllers and operators that automate provisioning, configuration, upgrades, and lifecycle management of Kubernetes-based platform components deployed across hybrid cloud environments. • Work closely with platform and service teams to build automation that simplifies operating large-scale distributed systems. • Improve the reliability, scalability, observability, and maintainability of the platform through thoughtful engineering and continuous improvement. • Investigate production issues and participate in root cause analysis to improve platform reliability. Requirements • Solid understanding of Kubernetes architecture, lifecycle and core concepts, including workloads running across cloud and on-premises environments. • Experience developing software in Go or another modern programming language, with an interest in Go development. • Experience building software for Linux-based environments. • Experience with Kubernetes development, including controllers, operators, or Kubernetes APIs. • 3+ years of professional software engineering experience. • Strong problem-solving skills and a desire to learn new technologies. Skills & Knowledge • Understanding of Kubernetes reconciliation patterns and declarative system design; especially understanding the principals of Communicating Sequential Processes (CSP). • Experience using Kubernetes in production environments. • Familiarity with controller-runtime, Kubebuilder, Custom Resource Definitions (CRDs), Common Expression Language (CEL) rules, or Kubernetes API extension mechanisms. • Experience building or operating distributed systems spanning public cloud and on-premises infrastructure. • Familiarity with Infrastructure as Code (IaC) and GitOps workflows. • Experience working with bare metal infrastructure, hybrid cloud environments, or multi-cluster Kubernetes deployments is highly desirable. • Experience with Cluster API (CAPI), SIG Multicluster, Karmada, or other Kubernetes ecosystem projects is a plus. Additional Attributes • Strong communication and collaboration skills. • Comfortable working as part of a distributed engineering team across multiple time zones. • Takes ownership of assigned work and follows through to completion. • Curious, pragmatic, and eager to learn from teammates while sharing knowledge with others. • Enjoys solving the unique engineering challenges of operating software across globally distributed cloud and on-premises infrastructure. • Passionate about building reliable systems and improving the user experience. • Contributions to open source projects, particularly within the Kubernetes or CNCF ecosystem, are a plus.
