Marco is hiring for an experienced Golang Software Developer who will be responsible to build and evolve Marco’s data collection agent for IT and print devices: the customer-installed agent and its supporting cloud services, written primarily in Go. ESSENTIAL FUNCTIONS: • Apply in-depth technical knowledge to develop applications across one or more technology areas (web applications, APIs, web services, and application database integration), including cloud and data platforms with supported organization tools such as Go (Golang), Google Cloud Platform. Plan, design, develop, test, debug, and deploy highly available applications. • Build and evolve the customer-installed agent and its supporting cloud services, primarily in Go. • Develop system services that run across Windows, Linux, and macOS. • Collect and normalize data from computers, networks, and print devices. • Design reliable communication and data flows between customer environments and the cloud. • Debug and improve software that crosses operating systems, networks, databases, and distributed services. • Write tests that exercise concurrency, failures, retries, and other real-world conditions. • Build the observability needed to understand released software and improve it using operational evidence. • Write design proposals, technical investigations, and documentation that help the team evaluate decisions. • Help operate containerized services in Azure and Kubernetes. • For consequential work, define the problem, desired outcome, and important constraints before committing to an implementation, and involve other engineers early when a decision affects their work or limits future choices. • Use AI for research, prototypes, implementation, and review while remaining accountable for the resulting system; scale review to the consequence of a change and establish patterns that guide both people and AI. QUALIFICATIONS: • Bachelor’s degree and six years of relevant experience, or equivalent combination of education and experience. • Familiarity with the Marco stack: Go, gRPC, Protocol Buffers, HTTP, WebSockets, PostgreSQL, SQLite, Redis, Azure Blob Storage, Docker, Kubernetes, Terraform, Helm, Argo CD, and GitHub Actions. Experience with every part of the stack is not required. REQUIRED SKILLS: • Experience shipping and supporting production software written in Go. • Preference for simple, idiomatic Go that uses the standard library where possible and adds dependencies or layers of abstraction only when they are clearly needed. • Experience with concurrent, networked, and distributed systems where failures are expected, including concurrency, retries, and failure handling. • Ability to investigate unfamiliar systems, gather evidence, and explain what is happening before proposing a solution. • Comfort learning operating-system, networking, and customer-domain details as the work requires them, including system services on Windows, Linux, and macOS and the behavior of network and print devices. • Observability tooling (OpenTelemetry, Datadog) to a depth sufficient to understand released software and improve it using operational evidence. • Test design that exercises concurrency, failures, retries, and other real-world conditions. • Effective use of AI for research, prototypes, implementation, and review, with personal accountability for the correctness and quality of the result. • Product judgment and architectural thinking: defining the problem, desired outcome, and constraints before implementation, and using prototypes to expose uncertainty. • Clear written and spoken communication of complex technical work, including design proposals, technical investigations, and documentation that help a team make sound decisions. Pay Range: $93,318 - $149,309 annually The pay range listed for this position is based on candidate's skill level, experience, relevant licenses, and educational background. For detailed information about our benefits, please visit our careers page at www.marconet.com/careers. Location: This is a remote-eligible position, however, Marco Technologies requires employees to reside within one of the following states: DE, FL, IA, IL, IN, KY, MD, MI, MN, MO, ME, NE, ND, NJ, PA, RI, SD, TX, WI Application Deadline: Applications are continuously accepted until the position has been filled.
