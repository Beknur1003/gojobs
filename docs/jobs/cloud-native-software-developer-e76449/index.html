Role Overview : We are looking for a skilled Cloud Engineer / Cloud-Native Software Developer with strong expertise in Google Cloud Platform (GCP), cloud platform engineering, API development, automation, security, and cloud-native application development. The candidate will design and implement scalable GCP platforms, reusable infrastructure modules, integration patterns, and operational data hubs while enabling Data Engineers, Analytics Engineers, and Data Scientists. Key Responsibilities : - Design and implement GCP landing zones, cloud architecture patterns, reusable infrastructure modules, and secure cloud-native solutions. - Develop and maintain Terraform-based infrastructure, including reusable modules and infrastructure automation using Atlantis. - Build, manage, and support CI/CD pipelines for infrastructure and application deployments. - Develop cloud-native applications and services using Go, APIs, Cloud Run, Pub/Sub, Cloud SQL, and GKE. - Design and implement REST APIs and integration patterns for cloud-native applications and data platforms. - Build and support operational data hubs leveraging Cloud Run, Pub/Sub, Cloud SQL, Composer/Airflow, Vertex AI, and AgentSpace. - Implement and manage IAM, service accounts, security controls, networking, auditing, monitoring, logging, and alerting across GCP environments. - Develop automated solutions for infrastructure provisioning, configuration management, deployment, monitoring, and operational support. - Manage and support the GitHub Enterprise environment, including repositories, access, integrations, workflows, and enterprise-level CI/CD capabilities. - Work closely with Data Engineers, Analytics Engineers, and Data Scientists to provide scalable and reusable cloud platforms. - Ensure cloud solutions are secure, highly available, scalable, automated, and cost-efficient. - Troubleshoot production issues, perform root-cause analysis, and implement preventive solutions. - Establish and maintain cloud platform engineering standards, reusable patterns, documentation, and best practices. - Support multi-team GCP environments and ensure consistent implementation of security and governance standards. Mandatory Technical Skills : - Google Cloud Platform (GCP) - Terraform - Atlantis - Go / Golang - REST API / API Development - Cloud Run - Pub/Sub - GKE / Kubernetes - Cloud SQL - IAM - GCP Networking - CI/CD - GitHub Enterprise - Cloud Monitoring / Logging / Alerting - Cloud Composer / Airflow Good to Have : - Vertex AI - AgentSpace - Cloud Functions - Dataflow / Apache Beam - BigQuery - Docker - Kubernetes - GitHub Actions - Python - Infrastructure as Code best practices - Cloud security and governance - FinOps / GCP cost optimization Required Competencies : - Strong cloud platform engineering experience. - Strong understanding of cloud-native architecture and microservices. - Hands-on experience in API development and integrations. - Strong automation and Infrastructure-as-Code mindset. - Good understanding of GCP security, IAM, networking, and governance. - Experience supporting enterprise-scale, multi-team GCP environments. - Strong troubleshooting and production-support skills. - Ability to create reusable, scalable, secure, and cost-efficient cloud solutions. - Strong collaboration skills with Data Engineering, Analytics, Data Science, and Application teams. Ideal Candidate Profile : - The ideal candidate should be a GCP Cloud/Platform Engineer or Cloud-Native Software Developer rather than a purely Data Engineer. - The candidate should have strong hands-on experience in GCP + Go + APIs + Terraform/Atlantis + Kubernetes/GKE + Cloud Run + Pub/Sub + Cloud SQL, along with CI/CD, IAM, networking, monitoring, and enterprise cloud platform management.
