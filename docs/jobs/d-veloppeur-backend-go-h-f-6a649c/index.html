Développeur Backend Go – H/F

Гибрид

Au sein de Skills & Affinity (Groupe Scalian), nous recherchons un Développeur Backend Go pour contribuer au développement d'une plateforme Cloud privée de nouvelle génération basée sur des technologies Open Source. Missions principales : • Développement Backend : Développer les services Backend en Go, concevoir et faire évoluer les API de la plateforme Cloud, et implémenter les mécanismes de communication asynchrone. • Gestion et métriques : Mettre en œuvre les contrôles d'accès, la gestion des quotas, les règles métier et les composants de collecte des métriques d'utilisation. • Qualité : Garantir la qualité, les performances et la maintenabilité du code tout en participant aux revues de code. • Profil cible : Formation supérieure en informatique avec au moins 5 ans d'expérience en développement Backend. • Compétences clés (Must-have) : Go (Golang), API REST, Terraform, RabbitMQ, Apache Kafka, NATS, Docker, Git, CI/CD, Keycloak, OAuth2, OpenStack, microservices. • Soft skills : Rigueur, autonomie et goût pour les environnements techniques exigeants. Informations complémentaires • Localisation : Île-de-France / Neuilly sur Seine • Modalités de travail : CDI, télétravail jusqu'à 2 jours par semaine. #LI-AB8
