With a culture that values innovation, growth, and continuous learning, IBM Software places you at the heart of IBM's product and technology landscape. Here, you'l have the tools and opportunities to advance your career while creating software that changes the world. A career in IBM Z is built on shaping critical technology that underpins the global economy. Over 70 percent of global transactional workloads and leading financial, healthcare, and public sector organizations rely on IBM Z and LinuxONE for unmatched security, resilience, and operational scale. As a z/OS System Programmer in IBM Z and LinuxONE Security and Automation, you will be the resident mainframe platform authority for a dedicated software development squad building next-generation security and identity observability offerings for IBM Z. In this specialized technical role, you will bring deep hands-on expertise in z/OS internals, security subsystems, and systems administration to enable seamless integration between modern open-source software stacks and core mainframe environments. You will configure, validate, and troubleshoot software components across real z/OS LPARs, ensuring that product collectors, adapters, and agent governance workflows run reliably and securely in production enterprise mainframe settings. Your primary responsibilities will include: - Serve as Core z/OS Platform Authority: Provide deep mainframe systems programming expertise to the software engineering squad, guiding the design, execution, and validation of software interfacing with native z/OS services. - Implement Mainframe Security and Access Controls: Configure and manage RACF and SAF security environments, defining resource classes, access profiles, user IDs, group structures, and digital certificates required for secure software operation. - Architect and Extract SMF Telemetry: Configure System Management Facility (SMF) record collection, log streams, and system exits to enable real-time ingestion and normalization of security, audit, and transaction telemetry. - Configure z/OS UNIX System Services (USS): Manage USS environment setups, file systems (zFS), environment variables, security permissions, and POSIX bindings required by modern microservices, collectors, and runtime agents. - Integrate Subsystems and Middleware: Interface with key mainframe subsystems including zSecure (Admin and Access Monitor), IBM MQ on z/OS, z/OS Connect, and related transactional environments. - Manage Test LPARs and Automation Scripts: Maintain dedicated z/OS development and test LPARs, building automated JCL, Rexx, and shell scripts to automate deployment, testing, and diagnostic data capture. - Validate Performance and System Integrity: Monitor system resource utilization, Workload Manager (WLM) policies, APF authorizations, and parmlib configurations to ensure software adheres to strict mainframe performance, safety, and reliability standards. '- Deep z/OS Systems Programming Experience: 5 or more years of hands-on z/OS system programming, systems administration, or mainframe systems engineering experience. - Mainframe Tools and Utilities: Mastery of core z/OS tools including JCL, TSO/E, ISPF, SDSF, SMP/E, and Rexx or CLIST scripting. - RACF and SAF Administration: In-depth knowledge of RACF database administration, SAF router interfaces, resource profiling, permission models, and digital certificate management. - SMF and System Monitoring: Practical experience configuring and analyzing SMF records, SMF log streams, and audit data streams for system and security monitoring. - z/OS UNIX System Services (USS): Solid practical experience configuring, managing, and troubleshooting z/OS USS environments, hierarchical file systems (zFS), and UNIX processes on z/OS. - Systems Configuration and Maintenance: Experience with parmlib configuration, APF authorized libraries, system exits, and basic Workload Manager (WLM) definitions. '- Mainframe Security Software: Experience working with IBM Security zSecure suite (zSecure Admin, zSecure Audit, or zSecure Access Monitor). - Mainframe Middleware and APIs: Familiarity with IBM MQ on z/OS, z/OS Connect, or CICS and Db2 security interfaces. - Modern Language Runtimes on z/OS: Familiarity with running Golang, Python, Java, or Node.js within z/OS UNIX System Services or Linux on s390x. - Enterprise Secret Management on Z: Exposure to IBM Vault for Z, PKI infrastructure, or cryptographic hardware (Crypto Express / ICSF). - Hybrid Mainframe Integration: Experience bridging z/OS telemetry and security events with external distributed observability or SIEM platforms.
