Salary: Contact Usama at Usama@blackroc.co Backend API Developer Duration: 12 month contract, with a 12 month extension option Location: Brisbane, Melbourne, Sydney Company Overview BLACKROC is partnering with a large federal government agency to recruit a Backend API Developer. This is a genuine opportunity to work on digital services used by hundreds of thousands of Australians, inside a team that has made contemporary AI-assisted development part of how they work — not an afterthought. Role Purpose You'll design, build and support the backend services and consumer APIs that power a large-scale suite of web applications, portals and mobile apps. Working within a multidisciplinary delivery team, you'll deliver secure, scalable services that sit as a consistent integration layer between customer-facing digital channels and the enterprise platforms behind them. You'll be expected to use AI-assisted development tools as a primary delivery mechanism, while owning the quality, security and maintainability of everything that ships. Key Responsibilities • Design, develop, test and maintain secure, scalable backend services and consumer APIs using Golang and GraphQL • Develop and support cloud-native applications deployed to Kubernetes and AWS EKS • Collaborate with frontend developers, Salesforce developers, integration teams and solution architects to deliver end-to-end solutions • Design and implement authentication, authorisation and secure integration patterns across web, portal and mobile channels • Use contemporary AI-assisted development tools to accelerate implementation, testing, troubleshooting and documentation • Contribute to platform reliability, observability, security and operational excellence Required Skills & Experience • Demonstrated experience building secure, scalable backend services and APIs in Golang, in enterprise or large-scale digital environments • Strong knowledge of API design and integration patterns, including GraphQL, authentication and authorisation, API lifecycle management and service-to-service communication • Experience developing and operating cloud-native applications on Kubernetes and AWS, including Amazon EKS • Solid grounding in source control, automated testing and CI/CD pipelines • Demonstrated use of contemporary AI-assisted engineering tools, backed by strong underlying engineering fundamentals • Excellent collaboration and communication skills across technical and non-technical stakeholders • Australian citizenship and the ability to obtain a Baseline security clearance (mandatory) Preferred Skills & Qualifications • Experience with Cloudflare technologies, including Zero Trust, Access, Tunnels and edge security • Experience designing consumer-facing API platforms serving web, portal or mobile ecosystems • Exposure to enterprise integration architectures such as Salesforce or MuleSoft • Experience in government, regulated or highly governed technology environments Please click the 'Apply' button to submit your resume.
