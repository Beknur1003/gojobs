About position: Position Overview As an Engineer focused on Developer Productivity and DevEx, you will take a hands-on software development role in building, maintaining, and supporting our long-term software delivery fabric. With your technical skills and developer empathy, you will help write the code that creates a proactive, secure, and flexible environment where software and dev box provisioning is invisible, governed, and highly intelligent. You will contribute directly to a greenfield software delivery ecosystem similar to Workbrew that serves two distinct, high-impact cohorts: this project’s macOS-based builder community and the Linux-based automated agents operating in the CI/CD pipeline. You will help tackle complex software supply chain challenges, building automated threat screening integrations, package quarantine loops, and robust telemetry data pipelines that ensure total visibility across our technical landscape. You will partner with various teams and stakeholders and collaborate with engineering partners to grow your skills while shaping this project’s developer platform How You Can Make an Impact • Build and Maintain: Develop, test, and maintain key features of a unified, greenfield software delivery platform that provides a reviewed, governed Golden Path for software consumption across the company. • Support Tooling Ergonomics: Prioritize the developer experience by contributing to clean, ergonomic interfaces and CLI tools that serve as an intuitive safety net rather than a source of friction. • Implement Supply Chain Defense: Code automated security guardrails, including version cooldown periods and strict quarantine rules, to detect and block supply chain attacks before code enters production environments. • Maintain Telemetry Data Pipelines: Build and maintain telemetry pipelines to track asset distribution and version drift, streaming data cleanly into our enterprise data stack including Snowflake, Datadog, and Prometheus. • Apply Technical Governance: Write code to help translate the corporate Tech Radar tiers (Adopt, Trial, Assess, Hold) into real-time, automated platform enforcements. • Collaborate Effectively: Work closely within the team and with adjacent engineering partners to align daily engineering tasks with organizational threat-screening and compliance standards. • Learn and Craft: Participate in code reviews, adopt system design best practices, to support high-quality software craftsmanship and platform empathy. About You • Bachelor's degree in Computer Science, Software Engineering, or a related field (or equivalent practical experience). • 2+ years of professional software development experience, with exposure to Platform Engineering, Infrastructure, SRE, or Developer Experience roles. • Strong developer empathy and an interest in designing highly ergonomic internal developer tools, CLI interfaces, or APIs, or shared libraries. • Proficiency in at least one programming language used for infrastructure and tooling, such as Golang or Python. • Foundational understanding of macOS and Linux operating system environments, alongside experience using multi-language package management systems such as Homebrew, pip, and npm. • Exposure to data engineering concepts, including writing queries or handling data schemas for platforms like Snowflake, Datadog, or Prometheus. • Basic understanding of Software Supply Chain Security concepts such as dependency vulnerability management and package patching. • Good communication and team collaboration skills, with a commitment to providing high-quality visibility and tools for engineering teams. Nice to Have • Familiarity with environments that utilize LLM-based assistants or automated agents for system configuration and code generation. • Exposure to containerized environments (e.g., Docker, Kubernetes) and cloud-native environments like AWS or GCP.
