Our client is seeking highly skilled Senior Full-Stack Software Engineers to contribute to an advanced artificial intelligence training project involving software development, technical problem-solving, debugging, system architecture, and code evaluation. This is a fully remote, global opportunity for experienced engineers with strong hands-on expertise across both front-end and back-end technologies. Selected professionals will create, solve, review, and validate complex software engineering tasks designed to improve the coding and problem-solving capabilities of advanced AI systems. The role also involves translating complete software implementations between programming languages, evaluating technical solutions, and ensuring high standards of software quality. Key Responsibilities • Develop, modify, debug, and optimize front-end and back-end application components. • Design and implement user-facing features, supporting services, APIs, and data models. • Analyze and troubleshoot application behavior across browsers, front-end frameworks, backend services, databases, and external integrations. • Work with unfamiliar code repositories to understand existing application architecture and identify technical improvements. • Diagnose complex issues involving application state, API contracts, authentication, data persistence, networking, and deployment. • Create, solve, review, and validate challenging software engineering tasks across the full application stack. • Translate software implementations between different programming languages while preserving functionality and technical accuracy. • Evaluate and improve code written in multiple programming languages. • Review AI-generated code and technical solutions for correctness, completeness, performance, security, and maintainability. • Apply software engineering best practices to ensure reliable, scalable, and maintainable implementations. • Provide clear technical feedback and document findings when evaluating software solutions. • Work independently and contribute to project deliverables within established quality standards. Technologies and Technical Environment Candidates should demonstrate strong practical experience with multiple programming languages and technologies, including relevant combinations of: • Python • React • JavaScript • Java • Node.js • Rust • Go (Golang) • TypeScript The position requires meaningful production experience across both front-end and back-end systems rather than specialization in only one area. Required Qualifications • Strong professional experience developing and maintaining production-level Full-Stack applications. • Significant hands-on experience in both Front-End and Back-End software engineering. • Production experience with multiple programming languages and technologies, including relevant combinations of: • Python • React • JavaScript • Java • Node.js • Rust • Go (Golang) • TypeScript • Strong understanding of modern web application architecture, browser-based applications, APIs, and backend services. • Experience designing, developing, and maintaining user-facing features and their supporting backend systems. • Solid knowledge of application state management, databases, data persistence, and service integrations. • Ability to understand, navigate, and contribute effectively to unfamiliar codebases and existing software architectures. • Strong debugging and troubleshooting skills across the complete application stack. • Experience diagnosing complex technical issues involving authentication, API contracts, networking, and deployment. • Ability to evaluate software implementations for correctness, completeness, performance, security, and maintainability. • Strong analytical thinking, technical problem-solving, and software engineering judgment. • Ability to work independently and deliver high-quality technical assignments in a remote environment. Preferred Qualifications • Experience working with complex, production-grade applications involving multiple technologies and services. • Familiarity with software architecture, system design, and cross-platform integrations. • Experience reviewing, validating, and improving code written by other developers. • Ability to translate software implementations between different programming languages while maintaining functional accuracy. • Experience evaluating automated or AI-generated code. • Strong technical communication skills and the ability to explain complex engineering decisions clearly. • Interest in artificial intelligence, software engineering evaluation, and advanced coding systems. Additional Requirements • Availability to dedicate approximately 15 hours per week to project assignments. • Ability to meet minimum weekly task submission requirements. • Willingness to complete an AI-based interview of approximately 30 minutes. • Availability to complete a technical assessment if requested. • Ability to begin assignments promptly following successful selection and onboarding. Work Arrangement and Contract Details • Location: Global — 100% Remote • Contract Type: Independent Contractor • Weekly Commitment: Approximately 15 hours • Work Schedule: Flexible. Professionals may choose their working hours and days, including weekends, provided they maintain regular project activity. • Advertised Compensation Range: USD $50–$100 per hour • Payment Structure: Output-based, with payment issued for tasks that meet project specifications and receive approval.
