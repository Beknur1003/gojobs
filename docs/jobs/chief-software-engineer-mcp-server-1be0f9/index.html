Responsibilities • Build the AI Gateway platform across MCP, agents, LLM routing, governance, and observability • Translate business and product requirements into crisp problem statements, gateway features including semantic caching for LLM responses, rate limiting, quotas, traffic governance, and guardrails and validation layers for safe LLM/MCP usage • Define and review authentication and authorization models, including multiple OIDC-based flows, identity propagation, and token-based access control for MCP and LLM traffic • Create prototypes and reference implementations to validate architectural choices and guide engineering teams • Collaborate with multiple product teams integrating with the AI Gateway by providing architecture guidance, best practices, and integration patterns • Review designs and code to deliver actionable feedback that improves quality, performance, scalability, and security • Define and review CI/CD best practices using modern GitHub-based pipelines • Architect and review Kubernetes-based deployment models to ensure scalability, resiliency, and production readiness Requirements • Proven track record with 7+ years of software engineering experience, including significant responsibility in a principal engineer role • Demonstrated experience designing and shipping large-scale distributed systems or platform products • High proficiency
