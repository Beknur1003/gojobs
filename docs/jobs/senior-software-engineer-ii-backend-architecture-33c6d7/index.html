Role Overview : We are looking for a Senior Software Engineer II to join our Enterprise Analytics engineering team and contribute to the development of next-generation distributed database technologies. In this role, you will design, build, and optimize core database components that power scalable, cloud-native analytics platforms. You'll work on critical areas such as query processing, execution engines, distributed storage, and database performance while collaborating with cross-functional teams to deliver enterprise-grade analytics solutions. This position is ideal for engineers passionate about distributed systems, database internals, and building high-performance software infrastructure. Key Responsibilities : 1. Core Database Engineering : - Design, develop, and enhance core distributed database components and analytics capabilities. - Build scalable, reliable, and high-performance systems that support modern cloud-native data analytics. - Contribute to database architecture across query processing, execution runtime, storage engines, and optimization layers. 2. Distributed Systems Development : - Develop distributed services focused on scalability, fault tolerance, and performance. - Improve query execution, storage efficiency, concurrency, and system reliability. - Optimize database performance for enterprise-scale workloads. 3. Engineering Excellence : - Write clean, maintainable, and production-quality code following modern software engineering practices. - Participate in architecture discussions, code reviews, testing, and continuous integration. - Take end-to-end ownership of technical deliverables from design through production deployment. 4. Cross-functional Collaboration : - Work closely with Product Management, QA, Performance Engineering, and Customer Success teams. - Collaborate across engineering teams to deliver innovative analytics capabilities. - Contribute to feature planning, technical design, and product roadmap execution. 5. AI-assisted Development : - Leverage AI-assisted development tools to improve engineering productivity and software quality. - Adopt modern engineering workflows and best practices to accelerate development while maintaining high code quality. Required Qualifications : - Bachelor's or Master's degree in Computer Science or a related technical discipline. - 5 to 7 years of software development experience building enterprise systems or database technologies. - Strong understanding of distributed systems and database internals. - Solid knowledge of operating systems, networking, and systems programming. - Experience with multi-threading, concurrent programming, and performance optimization. - Strong proficiency in Java. - Experience with one or more public cloud platforms such as AWS, Azure, or Google Cloud. - Strong problem-solving skills with the ability to design scalable software systems. Preferred Qualifications : - PhD in Computer Science or related field. - Experience with Golang or Python. - Experience building JDBC or ODBC drivers. - Knowledge of data lake technologies such as Apache Iceberg or Apache Hudi. - Experience developing distributed databases, query engines, or analytics platforms. - Familiarity with cloud-native database architectures. Key Skills : - Java, Distributed Systems, Database Internals, Query Processing, Query Optimization, Database Engine Development, Distributed Databases, Cloud Computing (AWS, Azure, GCP), Multi-threading, Concurrent Programming, Systems Programming, Performance Optimization, Data Structures & Algorithms, Operating Systems, Networking, Backend Development, Golang (Preferred), Python (Preferred), JDBC / ODBC, Apache Iceberg, Apache Hudi, Cloud-native Applications, Microservices, Software Design, Object-Oriented Programming (OOP), CI/CD, AI-assisted Development, Software Engineering Best Practices.
