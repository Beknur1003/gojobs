Backend Software Engineer (Python / Go) Employment Type: Full time Employment Contract As a Software Engineer on the Social Integrations (Social API) team, you’ll build the backend services and streaming pipelines that pull creator content, metrics and audience data from Instagram, Facebook, TikTok, YouTube, X, Snapchat, Pinterest, Twitch and third-party data providers. You’ll turn that data into reliable foundations for campaign reporting, community, discovery and earned media value (EMV) across CreatorIQ, at a scale of roughly 1 billion social records per day. Upstream APIs change without notice, throttle traffic and fail in creative ways, so you’ll design for resilience, token health and monitoring from day one. This is a full-time backend role based in our Warsaw office or remote within Poland, reporting to the Engineering Manager. In this role, you’ll get to: • Build and maintain integrations with social platform APIs, including Instagram, TikTok, YouTube and others. • Develop backend services in Python and Go. • Work on streaming data pipelines using Kafka and AWS. • Modernize legacy services and improve performance. • Support production by handling alerts and investigating data issues. • Build AI agents and tools (LLM-based agents, MCP servers) that automate engineering and support work, such as data triage. • Use AI across the whole development lifecycle: design, coding, testing, code review and operations. • Collaborate with Product, Data and other engineering teams. Who you are and what you’ll need for this position: • 3+ years of commercial backend development. • Strong Python 3 skills, including asyncio, type hints, Pydantic, and pytest • Production experience with Go. • Experience integrating third-party REST/GraphQL APIs at scale: OAuth, rate limiting, retries/backoff, idempotency, pagination. • Hands-on AWS experience, in particular Lambda, S3, SQS, Kinesis/Firehose and Secrets Manager, plus Docker and working knowledge of Kubernetes. • Strong SQL: PostgreSQL, and analytical warehouses such as Redshift with large, partitioned tables. • Experience with Kafka or a similar streaming/messaging system. • Good testing habits, plus experience with code review and CI/CD. • Hands-on experience building AI agents: LLM APIs, tool use / function calling, MCP, prompt and context design, evaluating agent output. • Fluency in an AI-assisted SDLC: using coding agents for design, implementation, tests and review, while staying accountable for quality and security. • Comfort debugging production issues end to end from logs and metrics. • Good written and spoken English, enough to work with global product and support teams. Nice to have: • Experience with social platform APIs: Meta Graph and Marketing API, TikTok Business API, YouTube Data/Analytics. • Serverless Framework; Sanic or aiohttp; Helm • Airflow, Databricks, or other data-engineering tooling. • Microsoft SQL Server, or enough PHP to read and migrate legacy code. • Observability: Coralogix, Prometheus/Grafana, CloudWatch. • Data modeling for metrics and analytics; versioned data contracts. • Background in influencer marketing, martech or ad-tech. • Agent frameworks or SDKs (e.g. Claude Agent SDK, LangGraph); RAG and agent evaluation.
