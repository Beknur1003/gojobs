Software Engineer - Full Stack Development

Software Engineer Job Description : Build scalable, end-to-end solutions that connect the world's leading cybersecurity platforms. We are looking for a Full Stack Developer who thrives on building complete solutions that bring data, applications, and workflows together. In this role, you will design and implement integrations between leading cybersecurity platforms, power reliable data-ingestion pipelines, and build automated response systems. You will work across the stack - from backend services and APIs to intuitive user-facing features - helping make complex cybersecurity ecosystems more connected, efficient, and effective. About Metron Security : At Metron Security, we specialize in automation and integration services for leading cybersecurity companies. Our engineering teams build solutions that extend and connect platforms such as Splunk, IBM QRadar, ServiceNow, CrowdStrike, Palo Alto Cortex XSOAR, and many more. We believe in a developer-first culture where creativity, ownership, technical excellence, and continuous learning come first. Why You'll Love Working with Us : - Developer-First Culture : Work in an environment where experimentation, thoughtful engineering, and ownership are encouraged. - Work Across Hundreds of Security Platforms : Gain hands-on experience with a broad and growing ecosystem of cybersecurity applications and technologies. - Real Customer Impact : Collaborate directly with customers and see how your code improves real-world security workflows. - Continuous Learning : Solve new technical challenges, explore unfamiliar platforms, and grow in a fast-moving global environment. What You'll Be Doing : - Design, build, and maintain full-stack applications and cybersecurity integrations. - Develop scalable backend services, REST APIs, data pipelines, and automated workflows. - Create responsive and intuitive user-facing features using modern frontend frameworks. - Integrate third-party APIs, enterprise applications, and security platforms. - Translate business and technical requirements into robust, maintainable solutions. - Troubleshoot issues across frontend, backend, cloud infrastructure, and external systems. - Participate in architecture discussions, code reviews, sprint planning, and design reviews. - Collaborate with customers, product teams, QA engineers, and fellow developers. - Document APIs, designs, technical decisions, and implementation knowledge. - Continuously improve application performance, security, scalability, and developer experience. What We're Looking For : We would love to meet someone who is comfortable moving between backend and frontend development and enjoys thinking about how complete systems fit together. Our stack often includes TypeScript, JavaScript, Golang and Python, but we value engineers who are language-agnostic and choose the right tool for each challenge. Must-Have Skills : - Strong Programming experience using languages (TypeScript, JavaScript, Python, Java, Golang). - Experience building user-facing features with React, Angular, Vue, or another modern frontend framework. - Backend service design, RESTful APIs, microservices, and data-processing workflows. - Good understanding of databases, application state, data models, and API integration patterns. - Strong debugging, analytical, and problem-solving skills across the full stack. - Familiarity with AWS, Microsoft Azure, or Google Cloud Platform. - Experience working in Agile teams, including sprints, user stories, estimation, and design discussions. - Awareness of frontend, backend, API, authentication, and cloud-security best practices. - Ability to learn new frameworks, tools, platforms, and APIs quickly. - Clear written and verbal communication skills. Bonus Points If You : - Have built integrations with enterprise applications or cybersecurity platforms. - Have experience with SIEM, SOAR, EDR, XDR, threat-intelligence, or incident-response platforms. - Know testing frameworks such as Jest, Cypress, Playwright, or PyTest. - Have experience with Docker, Kubernetes, or containerized applications. - Have deployed and supported scalable applications in cloud environments. - Understand event-driven systems, queues, webhooks, or distributed architectures. - Contribute to open-source projects or enjoy sharing technical insights publicly. - Use AI-assisted engineering tools to improve development, testing, debugging, or documentation. Our Ideal Teammate : - Thinks holistically about backend architecture, frontend usability, and the complete user experience. - Is comfortable learning new programming languages, frameworks, platforms, and tools. - Communicates clearly and collaborates openly with teammates and customers. - Takes ownership of work and follows through on commitments. - Takes pride in delivering secure, scalable, and maintainable solutions. - Brings curiosity, adaptability, and a practical problem-solving mindset. Your Next Challenge : Build What Connects Cybersecurity. At Metron Security, we build solutions that help security teams work smarter. If you are excited about solving complex engineering challenges, connecting systems, and developing reliable end-to-end products, we would love to hear from you.
