Take advantage of the opportunity and become a part of the fast-growing fintech FTMO.com. We are looking for a new colleague to help all our developers run their applications. The ideal candidate is a Kubernetes enthusiast, who wants to be a part of a meaningful project with results visible on a global scale. Our Infrastructure tech stack: • Google Cloud Platform • Cloudflare CDN & WAF • Gitlab for source code control and CI/CD • Elastic Cloud for logs and traces • Prometheus / Thanos for metrics collection ; Grafana for visualization • Helm for deploying microservices • Apache Kafka • PagerDuty for on-calls routing Taste of projects we work on: • Building Landing Zone in Google Cloud Platform, allowing developers to own infrastructure for their applications. • Hardening software supply chain delivery with tooling for automatic dependencies update, vulnerability scanning, software attestation • Expand multi-tenant Kubernetes clusters to support multiple regions. • Building Internal Developer Portal, providing service catalog for organization microservices, golden path for new microservices. • Cost optimization of existing cloud resources. What will be your agenda? • Writing Infrastructure as a Code (IaC) using Terraform. • You will deepen your experience with cloud infrastructure from major cloud providers. • You will contribute with good understanding of computer networks and troubleshooting distributed backend web applications. • Using Bash and other programming languages such as Python or Go and more. • Understanding of software development lifecycle. • Deepening your knowledge of Kubernetes, containers and Linux. What do we expect from you? • Hands-on experience with infrastructure as code (IaC) using Terraform. • Knowledge of cloud infrastructure from major cloud providers. • Ability to understand computer networks and troubleshoot issues in distributed backend web applications. • Basic proficiency in Git. • Familiarity with Bash and a programming language of choice, such as Python or Go. • Understanding of the software development lifecycle. • Practical skills with Kubernetes, containers, and Linux at a basic level. • Capability to scale IaC across teams within an engineering department. • Troubleshooting deployment issues with Kubernetes. • Creating Helm charts. • Fluency in both Czech and English - we are an international team and communicate in both languages (English at B2 level or above) Why join the FTMO team? • We are a Czech fintech that, since 2015, has grown from an idea into a global project. 🚀 • 300+ amazing teammates.
