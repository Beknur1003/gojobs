Software Engineer II - Backend Leaning FullStack

Rippling Bangalore, India опубликовано 27 августа 2026

MongoDBKafkaAWSPythonReact
About the team The App Components Team is a forward-thinking, platform-focused product engineering team dedicated to crafting the cohesive, high-performing building blocks that define Rippling’s "Enterprise Studio" experience. About the Role As a Software Engineer II (Backend / Full Stack) on this team you will be responsible to build and scale the systems that power these components. While your primary focus will be on the backend, this is a truly full-stack role. You will help design the distributed systems that power our platform and also contribute to React and React Native code to deliver polished end-to-end product experiences. You will be responsible for building scalable backend services, APIs, and data models, while partnering closely with product and design to ensure the underlying complexity is translated into seamless, high-performance user experiences. What you will do • Design and implement scalable backend services using Python and Golang to support complex enterprise data modeling and product use cases. • Contribute to systems that operate at scale, with exposure to distributed systems challenges and technologies such as Kafka, Flink, and AWS. • While your strength lies in backend engineering, you will also contribute to the frontend codebase. You will write high-quality React and React Native code to ship end-to-end features and help deliver intuitive, performant UI components. • Take ownership of meaningful product initiatives from early problem definition through implementation. You will help shape technical designs for new "App Studio" capabilities and deliver robust solutions. • Write clean, maintainable, well-tested code, participate in thoughtful code reviews, and contribute to strong engineering standards across backend and frontend systems. • Work closely with Product, Design, and other engineers to break down complex user problems and build components that are technically strong and practically useful for teams building on top of them. What you will need • 3+ years of professional software engineering experience, with strong experience building production systems • Proficiency in building scalable backend services. Experience with Python, Django, Golang, MongoDB, and AWS is highly preferred. • Comfortable in writing and shipping production code in React and React Native. You should understand component lifecycles, state management, and mobile constraints well enough to build and iterate on UI for the systems you own. • Ability to design scalable, reliable systems and reason through trade-offs such as consistency, performance, and fault tolerance. • Experience building reusable systems, frameworks, or developer-facing components is a plus. You should be excited by building flexible foundations that can support multiple product use cases over time. • A track record of independently driving projects, navigating ambiguity, and delivering high-quality outcomes. • Strong communication skills and the ability to work effectively with both technical and non-technical stakeholders.
