Software Engineer (Full Stack) Role Overview We are looking for a Software Engineer (Full Stack) to develop and maintain Web Applications and Backend systems that support business operations. The role will work closely with BA, UX/UI, QA, Mobile, Infrastructure, and other related teams throughout the full software development lifecycle, from requirement analysis and solution design to development, testing, deployment, and post-production support. Responsibilities • Develop and maintain Web Applications across both Frontend and Backend. • Develop Frontend applications using technologies such as Vue.js (Nuxt), React.js (Next.js), Angular, or related technologies. • Develop Backend APIs and Microservices using Node.js (NestJS), C#, PHP, or Golang (Gin). • Design and develop REST APIs and system-to-system integrations. • Design and work with relational databases such as Oracle, SQL Server, and PostgreSQL. • Analyze and optimize SQL queries, indexes, and database transactions to improve performance. • Develop integrations with internal systems, third-party services, and external APIs. • Develop real-time integrations using technologies such as WebSocket, Webhook, or event-based integration. • Analyze and resolve bugs and defects identified during QA, UAT, or Production, while continuously improving application performance, scalability, and reliability. • Conduct Code Reviews and ensure software development follows established Coding and Development Standards. • Manage build, deployment, and application environment configurations. • Work with CI/CD pipelines and tools such as GitLab, Jenkins, and Docker. • Monitor applications, manage logging, and analyze system issues to identify and resolve root causes. • Collaborate closely with BA, UX/UI, QA, Mobile, Infrastructure, and other relevant teams. Required Qualifications • At least 3 years of experience in Web Application Development or Full Stack Development. • Hands-on experience in Frontend development using at least one technology such as Vue.js / Nuxt, React.js / Next.js, or Angular. • Strong understanding of Responsive Design, Component-Based Architecture, and Frontend Application Architecture. • Experience in Backend development using at least one technology such as Node.js / NestJS, C# / .NET, PHP, or Golang / Gin, with the ability to design and develop REST APIs. • Understanding of Authentication and Authorization, such as JWT, OAuth 2.0, or OpenID Connect. • Experience working with Relational Databases such as Oracle, SQL Server, or PostgreSQL, with a good understanding of Database Design, SQL Queries, Transactions, and Indexing. • Proficient in Git and familiar with the Software Development Lifecycle (SDLC). • Strong debugging and application troubleshooting skills. • Understanding of Application Performance, Error Handling, Logging, and Security. • Ability to collaborate effectively with BA, UX/UI, QA, Mobile, Infrastructure, and other cross-functional teams. • Strong analytical and problem-solving skills, with the ability to learn and adapt to new technologies. Preferred Qualifications • Experience designing or developing systems using Microservices Architecture. • Experience with Microsoft Azure, such as Azure App Service, Azure API Management, or other related Azure services. • Experience with Hardware Integration, such as Card Readers, Fingerprint Scanners, POS devices, or other hardware. • Experience with Unit Testing, Integration Testing, or Automated Testing. • Knowledge of Monitoring and Observability, including Application Logs, Metrics, and Distributed Tracing.
