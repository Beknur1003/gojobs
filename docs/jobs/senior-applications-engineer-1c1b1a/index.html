Credence has an immediate opening for a Senior Applications Engineer who will be primarily responsible for supporting the Defense Logistics Agency, Defense Automated Addressing Systems (DAAS), AI/ML program. The Senior Applications Engineer analyzes and studies complex system requirements and leads the design and implementation of software tools and subsystems that support software reuse and domain analyses. This is a hands-on role that pairs deep applications engineering with front-end UI/UX development: you will be handed real enterprise applications with real user friction, and part of your mandate is to diagnose why users aren’t engaging and rebuild experiences — interfaces, dashboards, and data visualizations surfacing AI/ML outputs — that they actually want to use. You will manage software development and support efforts using formal specifications, data flow diagrams, and other accepted design techniques and Computer-Aided Software Engineering (CASE) tools, while providing reliable cost and schedule estimates to program leadership. To succeed in this role, you should combine deep hands-on engineering expertise with modern front-end skills, the ability to guide development teams, improve existing systems, and enforce disciplined configuration management practices in support of DAAS AI/ML modernization efforts.
