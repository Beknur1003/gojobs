This is a remote role anywhere in the USA. Meet the Team Our software engineering team develops software using Cisco’s Design Thinking Principles, with simplification and Security at its core. We use secure coding practices, protect user privacy, and follow software development best practices. We are looking for an experienced engineer who enjoys solving complex security problems through automation, scalable software, and strong engineering practices! We partner closely with Design, Product Management, and other teams to create solutions for our customers. Together, we bring new insights to product innovation and continuously improve how we build software for our customers! Your Impact In this role, you will design and develop high-quality software and help bring features from technical design through delivery. You will create technical design documentation for the team and contribute to user documentation for end users. You will troubleshoot and resolve software issues during development and in production. You will collaborate across teams, share technical knowledge with other engineers, and help improve the quality, scalability, security, and reliability of our software. Responsibilities • Improve the software development lifecycle and advance best practices in agile engineering. • Lead the design and delivery of high-quality security features that improve our products and services. • Design and develop production software and services using technologies such as Golang and Python, including APIs and services built with frameworks such as Flask or FastAPI. • Build and operate scalable cloud-native applications and infrastructure using technologies such as Kubernetes, Helm, AWS, and Terraform. • Work with data technologies such as PostgreSQL, MySQL, and Redis to support reliable, scalable production systems. • Contribute to web-based applications and user experiences using technologies such as React and NextJS, where applicable. • Support automated build, test, and deployment workflows using GitLab CI, GitHub Workflows, or similar CI/CD technologies. • Identify opportunities for products to work together and create greater value for customers. • Consider market needs, product adoption, and competition when making design decisions and tracking related metrics. • Review and test code to identify problems and improve scalability, speed, and reliability. • Develop technical design documentation for the team and contribute to user documentation for end users. • Resolve errors, monitor production systems, identify risks, and escalate issues when needed. You may also support on-call escalations. • Collaborate with cross-functional teams to capture requirements, estimate timelines, track milestones, and deliver projects that meet user requirements. • Share knowledge across teams through presentations, documentation, blogs, newsletters, and other forums. Minimum Qualifications • Bachelor’s degree with 5+ years of related experience, Master’s degree with 3+ years of related experience, or PhD with 1+ year of related experience. • Experience developing production software, including writing clean, functional code and unit tests. • Experience troubleshooting and resolving software issues in development and production environments. • Experience with code reviews, testing, and software engineering practices focused on scalability, reliability, and quality. • Experience creating technical designs and leading software features from design through delivery. Preferred Qualifications • Background leading software projects or features through implementation, testing, and delivery, and preferably experience building security products or developer-facing security tooling. • Knowledge of production monitoring, incident response, postmortems, and root cause analysis. • Familiarity with secure software development practices, threat modeling, vulnerability analysis, and vulnerability management tools and processes. • Ability to use AI/ML or generative AI to solve security problems, such as automated threat detection, alert triage, security investigation, anomaly detection, or security workflow automation. • Familiarity with LLMs, AI agents, embeddings, or other machine-learning capabilities and their integration with production systems. • Experience with Golang or Python and familiarity with frameworks such as Flask or FastAPI. • Familiarity with cloud-native infrastructure and deployment technologies such as Kubernetes, Helm, AWS, and Terraform. • Experience with PostgreSQL, MySQL, Redis, or similar databases and data stores. • Familiarity with React, NextJS, or similar modern web technologies, and GitLab CI, GitHub Workflows, or similar CI/CD tooling. • Proven collaboration with Product Management, Design, Security, and engineering teams, with the ability to mentor engineers, share technical knowledge, and contribute to software engineering roadmaps and capabilities across products.
