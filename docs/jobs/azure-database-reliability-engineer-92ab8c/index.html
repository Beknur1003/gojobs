Azure Database Reliability Engineer

ARYAN SOLUTIONS PTE. LTD. Singapore опубликовано 17 ноября 2026

Go — основной язык
PostgreSQLAzure
Hiring for Billion Dollar client: We are automating and strengthening our cloud database capabilities to enable application teams to migrate from on‑premises databases to secure, scalable Azure database services. As part of our cloud platform evolution, we provide curated Azure DB offerings, automation, and self‑service capabilities that allow product teams to modernise their data layer while reducing dependency on central DBA operations. Join us as a Database Reliability Engineer (DBRE) and play a key role in helping application teams onboard to Azure database services, migrate existing Oracle and Microsoft SQL workloads to Azure, and establish reliable, automated, and observable database operations at scale. Where feasible, modernise them towards PostgreSQL. YOUR PROFILE • Database engineer with strong hands‑on experience (minimum 5 years) working with Oracle and/or Microsoft SQL Server in enterprise environments, including at least 1-2 years’ experience in a Database Reliability Engineering (DBRE) role. • Proven experience migrating databases from on‑premises platforms to Azure database services (Azure SQL, Oracle on Azure, PostgreSQL), with strong understanding of Azure architecture, cloud operations, and platform reliability principles. • Experience designing and implementing automated, self‑service database capabilities using Golang, Infrastructure as Code or platform tooling, with a strong DevOps/SRE mindset and “you build it, you run it” mindset. • Excellent communication and stakeholder management skills; comfortable working across application, platform, and vendor teams. • Prior experience in software engineering or cloud platform enablement teams. • Pragmatic, solution‑oriented, and comfortable operating in complex enterprise environments with compliance and regulatory constraints. Nice to have: • Experience migrating from Oracle or MS SQL to PostgreSQL. • Azure certifications related to Azure Database, Azure Architecture, or Site Reliability Engineering. • Experience with database tooling for assessment and migration (e.g. schema conversion, compatibility analysis). • Experience working in agile setups (SAFe or similar) across multiple teams and initiatives.
