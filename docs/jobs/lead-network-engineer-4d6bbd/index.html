About the role: As a Lead Cloud Network Engineer, you’ll take ownership of securing and scaling our AWS + EKS infrastructure using Terraform-first principles. Every line of code you secure, every pipeline you automate, and every connection you architect directly contributes to a banking platform that millions can trust. If you’re ready to bring cloud-native engineering excellence to the heart of digital finance, this is your opportunity. What you will do: In this role, you’ll be a key driver of cloud-native connectivity. You won’t just maintain infrastructure; you’ll design resilient, compliant, and innovative cloud networks that power a next-generation financial platform, at the same time automate, and secure it end-to-end. • Architect and operate secure networking across AWS (VPCs, Transit Gateways, PrivateLink, Direct Connect, and load balancing). • Build resilient EKS cluster networking with CNI plugins, service meshes, and ingress/egress controls. • Build and maintain reusable Terraform modules for networking, IAM, and Kubernetes add-ons. • Champion scalable Infrastructure-as-Code practices for consistent, compliant deployments. • Design and manage secure connectivity with financial vendors, data centers, and partner ecosystems. • Deliver always-on, high-trust integrations via VPNs, Direct Connect, and private circuits. • Enforce strong cloud network security policies, IAM best practices, and encryption standards. • Guarantee secure communication protocols across AWS and Kubernetes environments. • Lead resolution of complex networking issues (routing, DNS, TLS, IAM, bottlenecks). • Run post-incident reviews to strengthen resilience and prevent recurrence. • Eliminate manual overhead by automating provisioning and management with Terraform, Python/Bash/Golang. • Scale reliability through automation-driven operations. • Deploy and optimize monitoring/alerting with CloudWatch, Prometheus, GuardDuty, and SIEM integrations. • Build proactive visibility into performance and security posture. • Partner with engineering leadership to shape our cloud networking and security roadmap. • Influence long-term architecture decisions for compliance, scalability, and resilience. • Be part of a structured on-call rotation that safeguards critical digital banking systems. What you will need: You’ll thrive if you love cloud-native engineering, solving hard problems, and driving measurable impact. • 6+ years with AWS networking & security (VPC Design, Transit Gateway, Direct Connect, API Gateway, Security Groups, IAM). • Proven experience with Kubernetes (EKS/GKE), K8S Networking, ingress controllers, service meshes, and Kubernetes security controls. • Deep hands-on experience with Terraform in multi-tenant, multi cloud environments setups. • Track record with VPNs, IPSec, Direct Connect, MPLS and hybrid integrations. • Routing, switching, DNS, TLS/PKI, VPNs, load balancing. • Skilled in Python or Bash scripting. • Expertise in investigating cloud security incidents, traffic analysis, and remediation. • Familiar with logging, monitoring, and SIEM for proactive detection. • Hands-on exposure to service meshes like Istio. • Experience working in regulated environments (finance, banking, and fintech). • Certifications (preferred): AWS Certified Advanced Networking/AWS Certified Security/Certified Kubernetes Administrator (CKA) or CKS • Knowledge of modern CI/CD pipelines using GitHub, ArgoCD, HELM and Kubernetes etc Life at slice: Life so good, you’d think we’re kidding: • Competitive salaries.
