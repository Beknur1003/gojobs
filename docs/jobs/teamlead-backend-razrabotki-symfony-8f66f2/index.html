Наш интернет-магазин является одним из лидеров в своём сегменте (1.5 млн. клиентов, 5K RPM, 25K SKU), мы постоянно растем и развиваемся, поэтому в нашу внутреннюю команду разработки требуется опытный "играющий тренер". Обязанности: • Реализация функционала, написание кода проекта; • Лидирование команды backend-разработки (3-4 человека); • Проведение релизов и хотфиксов; • Обеспечение технического качества; • Автоматизация цикла разработки; • Работа с архитектурой проектов; • Написание, хранение, актуализация документации; • Консультирование, работа с менеджерами проектов и командой подрядчика. Требования: • Опыт разработки на PHP7 (Symfony) от 6 лет; • Опыт работы с MySQL\Postgresql, Composer, Docker, Git; • Хорошее понимание объектно-ориентированного программирования с использованием современного MVC-фреймворка; • Опыт работы с высоконагруженными b2c проектами; • Опыт управления группой бэкенд-разработки. • Умение и желание покрывать код тестами (PHPUnit); • Опыт работы с микросервисной инфраструктурой; • Опыт создания REST API для SPA и для внешних интеграций; • Опыт работы с Docker, понимание подходов к проектированию приложений без сохранения состояния; • Способность обучаться новым языкам и технологиям; • Опыт Golang будет преимуществом; • Опыт работы с Kubernetes, с брокерами сообщений (RabbitMQ, Kafka и др.); Условия: • Работа в стабильной компании с более чем тридцатилетней историей; • Официальное оформление, полностью белая ЗП; • Формат работы - удалённый; • ДМС с первого дня работы; • Скидки на корпоративный фитнесс; • Скидки на продукцию компании; • Насыщенная корпоративная жизнь: тимбилдинги, активные спортивные мероприятия (Гонка героев, велопробеги, марафоны, футбольная команда и т.д.);
