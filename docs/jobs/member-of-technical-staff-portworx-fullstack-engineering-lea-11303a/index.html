THE ROLE We are looking for a highly skilled Senior Frontend Engineer to join the Portworx UI team, responsible for building intuitive, scalable user experiences for our Kubernetes-based platform. You will build production-quality web applications using React, collaborate closely with UX, Product, backend teams, and engineering leadership, and help shape frontend architecture and engineering practices. This role requires strong ownership, sound technical judgment, and the ability to solve complex problems independently while helping other engineers grow. Preferred (Good to Have) • Working knowledge of Angular, TypeScript-based component architecture, and RxJS. • Experience maintaining or integrating applications built with both React and Angular. • Exposure to Kubernetes, containerized environments, cloud-native applications, or frontend deployment and observability. • Familiarity with alternative testing frameworks, frontend test infrastructure, or Go and backend API development.
