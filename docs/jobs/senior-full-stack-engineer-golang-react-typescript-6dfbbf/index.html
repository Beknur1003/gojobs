Your Responsibilities Product & Feature Delivery • Translate business and operational requirements into scalable, testable and supportable product capabilities. • Deliver solutions across frontend, backend and data layers. Frontend Development • Build responsive, accessible and high-performance user interfaces using React and TypeScript. • Implement component-based architecture, state management, error handling and performance optimization. Backend & API Development • Design and develop secure, resilient and observable services and APIs. • Implement authorization, validation, idempotency, failure handling and API versioning practices. Data & Integration • Design data models and integrations supporting relational and event-driven systems. Production Support & Ownership • Participate in design reviews, code reviews, testing and release readiness activities. • Investigate incidents, perform root-cause analysis and implement permanent corrective actions. Technical Leadership • Break down complex initiatives into manageable deliverables. • Improve engineering practices and mentor team members through reviews and practical guidance. Architecture & System Design • Strong understanding of: Scalability, Reliability, Service boundaries, Consistency models, Caching, Concurrency, Failure modes, Engineering trade-offs.
