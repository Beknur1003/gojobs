About the Core Platform Services Team Target’s Infrastructure strategy is built around one idea: make the right thing the easy thing. The Target Application Platform (TAP) is where that happens. Builders tell TAP what they need, and the platform, more and more with help from AI agents, gets it done safely. In an agentic world, many more people create software. Builders at Target include engineers, product managers, UX designers, data scientists, and analysts. Core Platform Services builds the common services that connect Target’s platforms, so builders get a delightful experience that feels like one connected platform. We work closely with our Product Manager to find where builders lose the most time and decide what to build next. Our first major capability is Action Center, along with the tools that help builders act on it: • Action Center. A shared service and API that platform teams use to publish the work they need from builders, such as instrumenting with OpenTelemetry or upgrading a runtime. It tracks that work across the more than 5,000 applications on TAP and gives each one a single prioritized list, in place of requests scattered across tickets, chat, and email. • Remediation guides. A shared framework that lets a platform team write the fix for a common problem once and make it available to every application. • Agentic remediation. AI agents that follow a guide, make the code change, and open a pull request for the builder to review, either in the background on TAP or inside the builder’s own coding agent. A person approves every change. Action Center is a starting point. Over time, the team will build the features and integrations that remove friction across the full builder experience, from starting a new project to running it in production. We track adoption, time to complete, and manual work removed, and use that data to decide what comes next. We serve two groups: the builders who create software on TAP, and the platform teams who support them. We earn adoption by building services people want to use, and we measure success in builder time returned. The platform has already given back more than 500,000 hours, and this team’s work is a big part of growing that number. We operate business-critical services in 24x7 production environments. Technologies commonly used across the team include Golang, Kubernetes, Kafka, React, the Model Context Protocol (MCP), and agentic AI patterns.
