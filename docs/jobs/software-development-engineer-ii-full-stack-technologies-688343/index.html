Job Title : SDE 2 - Full-Stack (Golang + Angular) Location : Noida (Onsite / Work from Office) Experience : 3 - 6 Years Employment Type : Full-Time, Permanent About the Role : We are looking for a high-ownership SDE 2 (Full-Stack Engineer) to build and own features end-to-end - from backend services in Go to frontend interfaces in Angular. You will work in a cross-functional product squad alongside product, design, and other engineers, building a platform that powers critical healthcare workflows daily. In this role, you will take features from technical design through deployment and monitoring, write scalable production-grade code, and help raise engineering practices across the team. Key Responsibilities : - End-to-End Ownership : Write backend services in Go and frontend interfaces in Angular, owning features from technical design, implementation, and deployment to production monitoring. - Engineering Standards : Write clean, testable, and well-documented code while maintaining high engineering standards. - System & API Design : Participate in API design, data modeling, and service architecture decisions for new features and platform capabilities. - Collaborative Quality : Review code thoughtfully, catch bugs, share knowledge, and mentor junior engineers through pairing sessions and design discussions. - Product & Engineering Collaboration : Work closely with product and design teams to translate requirements into robust technical solutions. Propose architectural alternatives and trade-offs when necessary. - DevOps & Practices : Contribute to automated testing, CI/CD, observability, and developer tooling to improve overall squad productivity. - Production Support : Debug and resolve production issues quickly, conduct root-cause analysis, and deploy permanent fixes. Requirements & Qualifications : - Experience : 3 - 6 years of professional software engineering experience building and maintaining production systems. - Education : B.Tech / B.E. in Computer Science or an equivalent field (minimum 60% aggregate). Primary Tech Stack : - Backend : Strong proficiency in Golang (experience with Java or other strictly typed languages like Python, PHP, or Node.js is also valued). - Frontend : Hands-on experience building web applications with Angular (or comparable modern frameworks like React/Vue). - Database & Cloud : Solid understanding of relational databases (MySQL schema design, query optimization, indexing strategies) and cloud infrastructure (AWS preferred). - Development Workflows : Strong system design fundamentals, unit/integration testing discipline, and experience with Git and CI/CD pipelines. - Background : Prior experience in a fast-paced Product Startup environment is preferred. Immediate joiners preferred. Good to Have : - Experience in Healthcare or other complex, regulated domains where reliability matters. - Familiarity with containerization technologies (Docker, Kubernetes). - Experience with observability, logging, metrics, and tracing tools. - Familiarity with modern AI coding tools (Claude, Copilot, Cursor) to accelerate development workflows. Perks & Benefits : - Competitive compensation structure including performance bonuses. - Notice period buy-out option available (evaluated on a case-to-case basis). - Mandatory PF and comprehensive Health Insurance benefits.
