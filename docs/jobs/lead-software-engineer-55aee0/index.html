Job Summary : At Crisis24, the Lead Software Engineer designs, builds, and operates backend services powering our global mass notification platform. This role combines hands-on development with technical leadership and production ownership, focusing on delivering reliable, scalable, and high-performance distributed systems on AWS. You will collaborate with engineering, QA, product, and support teams to deliver high-impact features while driving best practices in system design, development, and operations. Responsibilities : - Design and develop scalable backend services for mass notification and mobile platforms. - Build and operate cloud-native microservices on AWS using containerized architectures. - Own service reliability, observability, and performance, including monitoring and optimization. - Define and evolve REST APIs and service contracts using OpenAPI specifications. - Troubleshoot and resolve complex production issues with strong root cause analysis. - Drive testing strategy across unit, integration, and performance testing. - Collaborate with product, QA, and support teams to deliver high-quality features. - Mentor engineers through code reviews, design discussions, and knowledge sharing. - Contribute to CI/CD pipelines and improve development workflows through automation. - Enforce secure coding practices and system design standards. - Participate in on-call rotations and incident response. - Continuously improve systems through modern engineering practices, including AI-assisted development workflows. Qualifications : - Bachelors degree in computer science, Information Technology, or related field. - 7+ years of experience developing applications using .NET Core and REST APIs. - Java / Spring and Golang (beneficial for broader mass notification ecosystem). - Hands-on experience with queuing mechanisms such as Kafka and AWS SQS. - Solid experience with both SQL and NoSQL databases (PostgreSQL, MS SQL, Cassandra, or equivalent). - Strong understanding of coding standards, design patterns, and unit testing practices. - Proven experience building REST APIs in containerized, distributed systems. - OpenAPI/Swagger specification and lifecycle documentation. - Hands-on experience with AWS cloud services and containerization using Docker. - Practical experience with Kubernetes for container orchestration. - Experience implementing AI-assisted development workflows (Copilot, agentic development patterns). - Experience with test automation using Mocha or similar frameworks. - DataDog or similar tools for observability, alerting, and troubleshooting. - Demonstrated ability to implement and maintain CI/CD pipelines and DevOps best practices. - Strong knowledge of software architecture principles including microservices, SOLID, and DDD. - Knowledge of secure coding practices and application of security principles. - Familiarity with Agile/Scrum development methodologies. - Excellent problem-solving, analytical, and communication skills.
