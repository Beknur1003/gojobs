Cybersecurity Automation & Threat Operations Engineer

Westbury Partners Singapore опубликовано 14 августа 2026

Офис
LinuxPython
Drive cybersecurity innovation through automation, threat assessment, vulnerability management, and data analysis, strengthening resilient infrastructure while collaborating globally across network, cloud, endpoint, identity, and application security. What You'll Do: Build and automate resilient security processes, assess threats across networks, servers, and endpoints, investigate anomalous activity, reduce attack surfaces, and transform security data into actionable insights. Your responsibilities will include: • Automating security processes using Python, Go, or similar languages. • Conducting threat and vulnerability assessments across infrastructure and endpoints. • Supporting attack surface reduction and proactive security improvement initiatives. • Investigating suspicious or anomalous activity and producing clear management reports. • Analysing datasets using SQL, Python, Pandas, and related tools. • Troubleshooting Linux systems and network connectivity. • Applying knowledge of DNS, SSL/TLS, IP networking, identity management, and authentication. • Working independently while collaborating with stakeholders across a global security environment. • Continuously improving security controls, processes, and operational resilience. Why Join Us: Join a highly collaborative global security environment where research, innovation, and technology intersect. You’ll gain broad exposure across the security stack while developing into a highly capable T-shaped security professional. About You: You are passionate about security operations, automation, and continuous improvement. You bring strong technical curiosity, programming capability, Linux and networking knowledge, and a practical risk-based approach to security. You’re comfortable working independently, communicating with diverse stakeholders, and learning across multiple security disciplines.
