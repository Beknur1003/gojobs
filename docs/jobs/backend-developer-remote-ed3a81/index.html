About The Role: We are looking for a Backend Developer to join our Business Layer & Portal team. In this role, you will be a key contributor to our core business platform, managing critical integrations and services. This is a polyglot, AWS-heavy environment where your code will orchestrate workflows between Wildix cloud infrastructure and major business systems (SAP, Salesforce, Stripe, etc.). If you love serverless architectures, solving complex business logic, and working with both PHP and Go, you’ll fit right in. Are you up for the challenge? What You Will: • Develop and support core application services: Build, test, and debug backend features. • Integrate with enterprise platforms: Build and maintain secure integrations with Salesforce, SAP B1 Service Layer, payment processors (Stripe), and tax/VAT engines (SureTax). • Work on Serverless AWS infrastructure: Develop and deploy serverless event-driven applications on AWS using AWS Lambda, API Gateway, SQS, Route53, and AppConfig. • Optimize Performance & Security: Enhance API latency, build robust caching strategies with Redis/ElastiCache, and protect system integrity through secure token-based and scope-based authorization. • Collaborate cross-functionally: Work closely with Customer Care, SAP, CRM, SRE, Sales, Marketing, CLASSOUND, and Accounting teams to build requested features and troubleshoot integration bottlenecks. • Maintain documentation: Write and update API specifications and system design diagrams for seamless team collaboration. What You Will Bring: • 2+ years of professional backend development experience, with solid proficiency in PHP 8.x and/or Go (Golang). • Practical experience building applications on AWS (AWS Lambda, SQS, API Gateway) and utilizing Infrastructure as Code (AWS SAM). • Strong SQL skills (MySQL, MSSQL / SQL Server) and a solid understanding of cache-first patterns (Redis, Memcached). • Proven track record of designing, testing, and debugging third-party API integrations (CRM, payment gateways, ERP systems, external web services). • Experience in writing clean, testable code with robust unit/integration testing (PHPUnit, Go testing). • Upper-Intermediate English skills (B2+) for daily collaboration in our international team. Bonus Points If: • Experience with Bref (PHP on AWS Lambda) and modern PHP API design (PHP-DI, FastRoute, Harmony/Laminas middleware). • Direct experience with SAP B1 Service Layer, Salesforce REST API, or automated tax calculation services.
