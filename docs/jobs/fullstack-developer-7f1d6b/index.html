Sobre la posición Buscamos un/a Senior Frontend Engineer con experiencia sólida en React y desarrollo de aplicaciones web escalables. La posición tendrá un enfoque de 60% frontend y 40% backend, participando en el diseño de interfaces, definición de soluciones técnicas y desarrollo de funcionalidades end-to-end, con colaboración estrecha con equipos de producto e infraestructura. Responsabilidades principales - Diseñar y desarrollar interfaces web modernas, escalables y de alto rendimiento utilizando React y/o Next.js. - Traducir diseños de Figma e historias de usuario en soluciones funcionales, intuitivas y mantenibles. - Definir y optimizar la arquitectura frontend, componentes reutilizables y estrategias de renderización. - Colaborar con producto para resolver bloqueos técnicos y proponer mejoras en la experiencia de usuario. - Integrar APIs y servicios backend, participando en el desarrollo con Java o Golang. - Colaborar en arquitecturas de microservicios, servicios de AWS y procesos de despliegue. - Participar en revisiones de código, testing y mejora continua de las aplicaciones. Requisitos indispensables - 6 a 8 años de experiencia en desarrollo de software, con sólida trayectoria en frontend. - Experiencia práctica con React y/o Next.js. - Dominio de JavaScript y desarrollo de aplicaciones web. - Conocimientos de backend con Java o Golang. - Experiencia trabajando con APIs y arquitecturas de microservicios. - Conocimientos de AWS Lambda, API Gateway, testing y pipelines de CI/CD. - Capacidad para tomar decisiones técnicas y colaborar con equipos de producto e infraestructura. Tecnologías y experiencia deseables - Experiencia adicional con Angular o .NET. - Conocimientos de infraestructura y optimización de aplicaciones de alto tráfico. - Experiencia en backoffice, herramientas internas y gestión de permisos. - Experiencia interpretando diseños en Figma y participando en decisiones de experiencia de usuario.
