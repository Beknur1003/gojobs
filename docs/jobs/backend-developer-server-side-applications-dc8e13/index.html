Back End Developer - Django / Node.js / Golang We are hiring a Back End Developer with 23 years of hands-on experience in developing reliable, secure and scalable server-side applications. The candidate should have production experience in at least one backend technology stack: Python with Django, Node.js with Express, or Go/Golang. The role involves developing RESTful APIs, working with relational or NoSQL databases, improving application performance, writing automated tests, supporting application deployment and troubleshooting production issues. Candidates must be comfortable working independently and collaborating with product, frontend, design and other engineering teams. Key responsibilities : - Design, develop and maintain server-side applications and RESTful APIs. - Build backend components using Django, Node.js/Express or Go. - Design and maintain SQL or NoSQL database structures. - Ensure data integrity, security and reliable application performance. - Optimise database queries and backend application performance. - Write clean, reusable and maintainable code. - Develop automated unit or integration tests. - Deploy and maintain applications on cloud or edge platforms. - Monitor production applications and troubleshoot defects or performance issues. - Use Git for version control and team collaboration. - Participate in technical discussions, code reviews and Agile development activities. Required skills : - 2 - 3 years of relevant backend development experience. - Strong hands-on experience in at least one of the following: 1. Python and Django 2. Node.js and Express 3. Go/Golang - Experience developing and integrating RESTful APIs. - Working knowledge of server-side application architecture. - Experience with relational databases such as PostgreSQL or MySQL and/or NoSQL databases such as MongoDB. - Understanding of database design and query optimization. - Experience using Git. - Understanding of automated backend testing. - Strong problem-solving and debugging skills. - Ability to work independently and collaborate with cross-functional teams. Preferred skills : - Microservices or service-oriented architecture. - Docker or Kubernetes. - AWS, Google Cloud Platform or Microsoft Azure. - Production deployment and application monitoring. - Web-application security practices. - Agile software development experience. Location : - Bengaluru - Candidates should be comfortable working from Bengaluru according to the organisations final work-mode policy.
