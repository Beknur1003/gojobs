Job Description About the Company Mango Voice is a leading provider of cloud-based communication solutions, helping businesses of all sizes connect with their customers through innovative VoIP, SMS, and collaboration tools. We are rapidly expanding our partner ecosystem and are looking for a driven individual to help build the technical evolution of our platform. About the Role Mango Voice is searching for an experienced and collaborative Senior Backend Engineer to design, write software for, and maintain cloud applications for viewing, configuring, and using the Mango Voice Business VoIP software system. This role will involve working on a small team of 3-5 engineers to build and improve features, handle on-call duties and support escalations, and software and infrastructure maintenance. A potential focus for this role is integrating and developing AI-driven features and agentic systems, particularly those related to our Customer Experience or Integrations domains. Responsibilities Technical Design & Development • Design and implement scalable, secure, and reliable APIs and routing logic using Golang as the primary . • Write, test, and deploy production-ready code that enhances our platform, potentially focusing on data integrations (CRM/PMS/EHR) and AI-driven workflows. • Contribute to the architectural vision for the unified Conversational AI and Communications Platform, ensuring high performance in a high-volume environment. Delivery & Operational Excellence • Collaborate with Product Management and the engineering team to refine user stories and execute projects using the Shape Up framework. • Drive the full software development lifecycle for assigned features, from technical design through deployment and maintenance. • Monitor, troubleshoot, and resolve issues related to platform reliability, API performance, response latency, participating in on-call rotations. • Maintain and improve cloud infrastructure (AWS) using automation tools. Team Collaboration • Partner with other engineers, UX/Design, and Product teams to ensure the technical implementation aligns with the intended user experience and product vision. • Mentor and provide technical guidance to more junior engineers. Qualifications • Experience: 5+ years of software engineering experience, with a focus on backend development. • Technical Domain: Extensive experience with Golang (Go) for high-volume, production-ready systems. • Cloud Platform: Strong hands-on experience designing and building solutions on AWS (e.g., EC2, S3, RDS, Lambda, CloudWatch). • Architecture: Solid understanding of microservices principles, API design (REST/gRPC), and solving scalability challenges. • Datastores: Experience designing efficient database schemas (relational SQL + NoSQL datastores). • Collaboration: Proficient in collaborative code management via Git and Github; excellent communication and teamwork abilities in a remote environment. • Leadership + Ethics: you create systems that empower not only yourself, but those around you. Skills • Additional : Experience with Python. • AI/ML Depth: Experience designing and building autonomous or semi-autonomous software agents and AI-driven workflows. Familiarity with Large Models (LLMs), prompt engineering, or agentic development frameworks (e.g., LangChain, LlamaIndex). • Industry Experience: Experience in VoIP technologies (SIP, RTP, WebRTC) or messaging (SMS/MMS/RCS). • Automation: Experience with automating processes like CI/CD, server management, and migrations using tools like Terraform, Ansible, and Bash. • Healthcare Experience: Prior experience building software for the Healthcare space, with a deep understanding of HIPAA compliance and security requirements. Benefits • 4-day work week • remote-first (globally distributed) • PTO • healthcare plans available that are 100% covered by employer • parental leave
