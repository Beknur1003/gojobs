Job description About the role You’ll join Hitachi Vantara’s Platform Integrity Engineering team, which builds the cloud-based applications behind our product security platform, including vulnerability management and customer-facing security advisory portals. You’ll design and deliver features across the full stack: Golang backend services, React user interfaces, relational data models, and AWS deployments. The team works with AI-assisted development tools every day, and we expect engineers to use them to move fast while owning the quality of everything they ship. Responsibilities • Design, develop, test, and maintain full stack applications using Golang and React JS. • Build scalable REST APIs, backend services, and microservices. • Develop modern, responsive web user interfaces in React. • Design and implement relational database schemas and data models. • Develop and deploy cloud-based applications on AWS. • Take part in application architecture and technical design discussions. • Use AI prompting and AI-assisted development tools to improve engineering productivity. • Review and validate AI-generated code for correctness, security, performance, and maintainability. • Troubleshoot application, API, database, and cloud infrastructure issues. • Write unit tests and take part in code reviews. • Work with product management, QA, and other engineering teams throughout the software development lifecycle. • Follow established software engineering, security, and coding best practices. Required experience • 5+ years of professional software development experience. • 3+ years of hands-on Golang development, including goroutines and concurrency, channels, interfaces, error handling, package and module design, and REST API development. • 3+ years of hands-on React JS development, including components, hooks, state management, REST API integration, and modern JavaScript/TypeScript. • Hands-on experience building and deploying applications on AWS with services such as EC2, Lambda, S3, API Gateway, RDS, IAM, and CloudWatch. • Strong relational database design and development skills with PostgreSQL, MySQL, or equivalent. This includes schema design, data modeling, keys and relationships, normalization, SQL, indexing and query optimization, and transactions. • Practical experience using generative AI tools for code generation, code review, troubleshooting, test generation, documentation, and design exploration. • Hands-on experience with AI coding assistants or agentic development tools to build prototypes, generate components, refactor code, fix defects, and generate automated tests. You should be able to independently review, debug, secure, and maintain AI-generated code. • 2+ years of experience technically leading a small team of junior and intermediate software developers. This includes assigning and prioritizing work, mentoring, reviewing code, and helping team members grow their skills, while remaining a hands-on contributor. • A current AWS certification, such as AWS Certified Developer – Associate or AWS Certified Solutions Architect – Associate (Professional-level certifications are a plus). Nice to have • Experience building REST APIs with Express JS and Node.js. • Experience writing applications, automation, APIs, or AI-related utilities in Python. • Experience with LLM APIs, agentic development frameworks, or integrating generative AI capabilities into applications.
