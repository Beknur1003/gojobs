Preferred Industry Experience • NBFC (Non-Banking Financial Company) • FinTech • Banking and Financial Services • Digital Lending Platforms • Payment Gateway / Financial Technology Solutions Preferred Domain Knowledge • Banking API and third-party financial API integration. • Payment processing and financial transaction management. • Loan Management System (LMS). • Loan Origination System (LOS). • KYC / eKYC integration.
