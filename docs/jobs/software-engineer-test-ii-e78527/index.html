About the Role We are seeking a Software Development Engineer in Test (SDET) - II specializing in Data Connectors & High-Scale Ingestion. In this role, you will be the technical authority responsible for designing testing frameworks and benchmarking tools that validate multi-source data integration pipelines processing petabyte-scale throughput across AWS, Azure, and Kubernetes. What You'll Do • Design and execute scalable performance, backpressure, and stress-testing harnesses for ingestion connectors (REST, gRPC, CDC, Kafka, RabbitMQ) • Build automation suites across AWS (S3, SQS, Kinesis, EKS) and Azure (Event Hubs, Blob, AKS) to test real-world connector data flows under degraded network conditions and extreme concurrency • Implement automated fault-injection pipelines (simulating schema drift, network partitions, rate limits, and authentication failures) to guarantee zero-data-loss execution • Utilize Kubernetes to dynamically orchestrate transient, high-concurrency test clusters and mock target endpoints at scale What You'll Bring • 5+ years of software engineering/SDET experience in C++, Java, Go, or Python • Deep experience in testing streaming architectures (Kafka, Event Hubs), queueing systems, and API protocols (gRPC, WebSockets, REST) • Hands-on proficiency with AWS, Azure, and Kubernetes (Helm, custom controllers, or K8s operators) • Proven track record building custom distributed load-generation tools (e.g., Locust, k6, custom Go/Java engines) Location - Bangalore #LI-VG1 Veeam Software is an equal opportunity employer and does not tolerate discrimination in any form on the basis of race, color, religion, gender, age, national origin, citizenship, disability, veteran status or any other classification protected by federal, state or local law.
