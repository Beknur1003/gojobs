職務概要 我們正在尋找一位對伺服器基礎設施軟體、AI infrastructure 與企業私有化 AI 落地有熱情、重視團隊合作，並樂於分享與共同解決問題的軟體工程師，負責開發 Rack 管理與監控解決方案，為下一世代 AI Infrastructure 機櫃提供維運、監控、管理與自動化能力。 這個職務將參與 Rack-level management software 的設計與開發，涵蓋設備狀態監控、資料收集、告警管理、系統整合與維運管理等功能。同時也參與把AI Agent以及LLM落地在企業私有環境裡的相關工作，與各大AI Infra系統集成商進行整合驗證。 如果您希望投入伺服器產業，並對基礎設施、Rack 管理、監控系統與 AI 落地解決方案感興趣，這會是一個能發揮軟體專長、參與新世代技術發展，並深入理解伺服器產業鏈的好機會。誠摯歡迎您的加入。 主要工作內容 1. 針對客戶及市場需求進行分析，提出並開發具有可靠、實用、彈性以及便於擴容的解決方案。 2. Rack關鍵組件及Server等相關的管理監控解決方案的軟體研發以及AI Infra落地等整合驗證工作。 3. 跨部門(如EE、QA、AE、SE、Thermal等)協同合作，完成專案工作。 4. 大量利用AI輔助工具及敏捷的自動化開發流程 Agile + CI/CD。 5. 技術相關文件的撰寫，如設計文件、SOP、User Guide等。 6. 針對問題尋找對應的第三方工具，進行整合及優化的開發工作。 7. 參與團隊內外部在新技術研究探討的workshop及presentation。 必要條件 1. Familiar with x86 hardware architecture, BMC features and Redfish standard. 2. Familiar with AI-infra - vLLM/SGlang, LLM selection, create AI Agent/Skill/Tool and MCP 3. Familiar with Linux OS mechanism and related manipulation. 4. Familiar with C/C++, Golang, shell script and RESTful API. 5. Familiar with OSI 7-layer, TCP/IP and network protocols. 6. Familiar with SSDLC, CI/CD and Git-flow software development process 加分條件 1. With concepts of Rack management solution and domain knowledge 2. With concepts of physical and virtual switch/router/bridge network devices. 3. With concepts of hardware resource virtualization and container (Docker). 4. With concepts of VM/k8s cluster orchestration and Micro-Service architecture. 5. With concepts of object oriented programming
