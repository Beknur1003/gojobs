Job Purpose: The Senior Software Engineer role delivers scalable, secure, and maintainable software by solving complex problems and applying modern architectural patterns. It drives Agile, DevOps, and CI/CD practices while leveraging skills in Angular, Java, Spring Boot, Python, Golang, Docker, Kubernetes, and cloud platforms. Acting as a bridge across engineering, QA, and operations, it enforces secure coding, embeds observability, and fosters collaboration to ensure high‑quality, seamless product deliveries. As per company policy, this role requires presence in the office 4 days per week. Technical Expertise: • Strong proficiency in modern front-end and back-end technologies such as Angular (v10+), Java, and Spring Boot. • Solid knowledge of HTML, CSS, JavaScript, TypeScript, and modern UI frameworks/libraries. • Hands-on experience with automated unit and integration testing frameworks (e.g., Jasmine, Jest, Karma, JUnit, PyTest, Go testing, Testify etc.). • Experience with web components, micro front end architecture, responsive UI development. • Strong expertise in API design, gRPC, RESTful services, and development of scalable web-based applications. • Practical experience in Python or Golang development, microservices-based application design, domain-driven design (DDD), and distributed systems principles. • Experience with PostgreSQL (or similar SQL databases) and Redis • Proficiency in containerization and orchestration technologies including Docker and Kubernetes. • Proven experience designing and maintaining CI/CD pipelines and automated build and release processes. • Working knowledge of modern data architecture. • Experience with Agile methodologies, and JIRA. • Deep understanding of test-driven development, and collaborative practices such as pair programming and code reviews. • Familiarity with concept like iFrame , server side vs client-side rendering etc. • Familiarity with version control systems such as Git-based version control, or equivalent tools • Advanced working knowledge of Linux environments, networking fundamentals, scripting, debugging, and performance troubleshooting. • Knowledge on observability, monitoring, logging, and reliability engineering practices. • Understanding of secure coding standards, application security practices, and software quality assurance principles. Nice to Have: • Experience with Grafana • Knowledge of UML and software design modelling techniques. • Working knowledge of event-driven system, real-time/stream processing, data platforms and ML/AI platforms and services • Exposure to UX/UI design principles • Exposure to public cloud platforms and service models (IaaS, PaaS, SaaS) such as AWS, Azure, or GCP. • Familiarity with AI-powered development tools for coding, design, testing, and documentation.
