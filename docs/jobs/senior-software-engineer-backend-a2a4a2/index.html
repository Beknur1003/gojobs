Get to Know the Role We're looking for a Senior Software Engineer, Backend to join our growing engineering team in Ho Chi Minh City, Vietnam. You'll take ownership of designing and developing scalable backend systems that power our core products. You'll work collaboratively with cross-functional teams to solve complex technical challenges, mentor junior engineers, and drive architectural innovations. If you're passionate about building robust, efficient systems and thrive in an inclusive environment, we'd love to hear from you. The Critical Tasks You Will Perform • Design, develop, and maintain high-quality, scalable backend applications using modern technologies and best practices • Build and optimize RESTful APIs and microservices that support multiple client applications • Collaborate with product managers, frontend engineers, and other stakeholders to translate requirements into technical solutions • Write clean, efficient, and well-documented code while adhering to SOLID principles and clean architecture patterns • Conduct code reviews to ensure code quality, share knowledge, and foster a culture of continuous improvement • Troubleshoot, debug, and resolve complex technical issues with analytical rigor • Participate in system design discussions and contribute to architectural decisions that shape our technical direction • Implement and maintain automated testing practices, including unit and integration tests, to ensure reliability • Optimize database queries and system performance to handle growing scale and user demands • Participate in on-call rotations to ensure service reliability and respond to production incidents • Mentor junior team members and contribute to their professional growth and development What Essential Skills You Will Need • A Bachelor's degree in Computer Science, Software Engineering, or an advanced degree. Good Computer Science fundamentals in algorithms and data structures. • 5+ years of professional experience in backend software development. • Proficiency in Golang, with an understanding of its syntax, semantics, standard libraries, concurrency features, and experience optimizing applications. • Experience with RDBMS technologies like MySQL and PostgreSQL, including expertise in database performance, query tuning, and reliability. • Familiarity with cloud platforms such as AWS or GCP, with knowledge in designing scalable, internet-scale microservices. • Expertise in Infrastructure as Code (IaC) tools like Terraform and AWS CloudFormation, along with experience automating infrastructure. • Skills in development practices such as TDD, Continuous Integration, and Continuous Delivery, using tools like GIT, Jenkins, and unit testing frameworks. • Experience applying AI-assisted software development tools such as GitHub Copilot, Claude Code, Cursor, or similar tools to improve engineering productivity across coding, debugging, testing, refactoring, and code review. • Experience leveraging AI tools to improve production engineering workflows, including incident investigation, root cause analysis, troubleshooting, and system design.
