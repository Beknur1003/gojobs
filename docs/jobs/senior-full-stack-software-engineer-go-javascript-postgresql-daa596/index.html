Department Overview The International Services Solutions Enablement Team (ISSET) at Motorola Solutions creates software applications that delight our customers by enabling improved system integration and facilitating the analysis, reporting, and management of mission-critical Land Mobile Radio (LMR) and PCR communications networks. When seconds count, our software enables mission-critical organizations—such as Public Safety entities—to manage and optimize their processes and network information, contributing to operational excellence and efficiency in their 24/7 network operations centers. Job Description Drive the architectural modernization and scalable full-stack execution of mission-critical, AI-assisted predictive software products by transforming legacy on-premise systems into modern, cloud-based solutions. Operating with high autonomy and a strong hands-on focus (80% active coding in Go and modern frontend stacks, 20% system design), the Senior Software Engineer ensures the delivery of clean, production-ready code on the first pass, securing system performance, database reliability, and seamless cloud productization. Responsibilities • Deliver clean, production-ready code on the first pass, maintaining high engineering standards across mission-critical software in a largely asynchronous, 6-month project-cycle environment. • Design, build, and maintain end-to-end software solutions with an 80% Backend / 20% Frontend development balance. • Support the architectural transformation from on-premise systems to cloud-based infrastructure, participating in data modeling, database indexing, and performance tuning. • Design, implement, and document secure, high-performance REST APIs. • Develop scalable backend services and modules primarily in Go (Golang), as well as assist in migrating legacy Java services to Go. • Implement responsive, user-friendly frontend interfaces using modern web technologies, supporting an upcoming migration to React. • Design, optimize, and manage relational database schemas using PostgreSQL. • Package, configure, and deploy containerized services using Docker onto pre-configured Linux and cloud environments managed by DevOps. • Apply engineering best practices throughout the full development lifecycle, including version control with Git (Bitbucket / GitHub), unit testing, build automation, and dependency management. • Collaborate in an Agile environment using Jira to track sprint deliverables and project milestones. Basic Requirements Must-Have Qualifications (Required) • Location & Travel: Based in Argentina (Buenos Aires preferred) with availability to travel ~3 times per year for team workshops. • Education: Bachelor's degree in Computer Engineering, Software Engineering, Systems Engineering, Electrical Engineering, or a related technical field. • Experience: 6+ years of progressive experience in software development roles (ideally within software product/development companies), with strong hands-on systems design skills and autonomy. • Backend & Distributed Systems: Proven hands-on experience designing and developing scalable backend applications and distributed systems. • Go Programming: Solid, proven experience developing software with Go (Golang) at system scale, utilizing concurrency patterns. • Frontend Technologies: Solid knowledge and practical experience with core frontend technologies (HTML, JavaScript, CSS) and modern frontend frameworks. • Databases: Proven experience in data modeling, indexing, and query optimization with relational database engines (specifically PostgreSQL). • APIs: Proven experience in the design and development of REST APIs. • Linux & Containers: Strong command of Linux and experience using Docker to build and deploy container images in pre-configured cloud environments (AWS, Azure, or Google Cloud). • Development Lifecycle & Testing: Experience with core development lifecycle tools (Git, unit testing frameworks, build/dependency management tools) and deep mastery of software fundamentals to audit, test, and explain code implementations. • Language: Intermediate conversational English (Functional B2 level), sufficient to communicate asynchronously and comfortably defend technical solutions. Nice-to-Have Qualifications (Preferred / Strong Plus) • React: Hands-on production experience with React to support the upcoming frontend migration. • Java: Previous production experience with Java (particularly helpful for migrating legacy services to Go). • AI Development Tools: Experience leveraging agentic and AI-assisted development tools (such as Claude Code, Devin, or GitHub Copilot) to accelerate workflows while maintaining strict code quality and architectural control. • US Visa (Optional): Holding a valid US Visa is a strong plus (not a requirement) for attending occasional in-person team workshops in the US. • Container Orchestration & Messaging: Exposure to container orchestration platforms, NATS, and Ansible. #LI-PL1 Travel Requirements None Relocation Provided None Position Type Experienced Referral Payment Plan No EEO Statement Motorola Solutions is an Equal Opportunity Employer.
