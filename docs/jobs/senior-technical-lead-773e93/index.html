Job Summary Build and release the services that support the new remediation UI, bridging front-end capabilities and underlying remediation applications. The role spans application engineering, APIs, automation and cloud delivery and may overlap with platform engineering depending on the final solution design. Key Responsibilities • Design and build APIs, microservices and integration workflows supporting the remediation UI. • Develop across front-end and back-end components using appropriate languages including Golang, Java, React and Python. • Own code/configuration management, CI/CD automation and release readiness. • Containerise workloads with Docker and contribute to infrastructure-as-code using Terraform. • Implement secure IAM configuration and application-to-platform integration patterns. • Work with SQL and NoSQL data stores and troubleshoot end-to-end application issues. • Collaborate with UI, AWS Platform and testing teams to deliver functional and non-functional requirements. Skill Requirements What you will bring • Strong enterprise full-stack software engineering experience. • Programming capability across several of Golang, Java, React and Python. • REST API/microservice design and modern application integration. • CI/CD, code/configuration management and automated testing. • Docker and Terraform or equivalent IaC. • AWS or GCP cloud application experience; AWS strongly relevant to this delivery. • IAM configuration and secure engineering practices. • SQL and NoSQL database experience. Highly regarded • Kubernetes experience. • Apache ecosystem exposure: Spark/Structured Streaming/Beam, YARN and Kafka. • Data engineering experience. • High-availability production systems and release support.
