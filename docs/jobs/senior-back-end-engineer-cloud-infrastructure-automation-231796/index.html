What You Will Do • Design, build, and maintain high-performance, highly available, and scalable backend services to support 10X scale. • Architect resilient distributed systems and APIs capable of handling massive concurrency with sub-millisecond latencies. • Define technical vision and system architecture leveraging cloud infrastructure to achieve 99.999% availability. • Develop self-service platform tools and end-to-end cloud deployment automation using Terraform, Python, or Go. • Optimize CI/CD pipelines, containerized environments (Kubernetes, Docker), and automated testing/monitoring systems. • Identify system performance bottlenecks, optimize cloud infrastructure usage, and enforce security and networking best practices. • Solve complex technical problems across Public Cloud (AWS, GCP, Azure) and Hybrid Cloud environments. • Exert technical influence across multiple engineering teams through mentorship, architectural reviews, and continuous knowledge sharing. Basic Qualifications • Bachelor’s or Master’s degree in Computer Science or a related technical field (or equivalent practical experience). • 5+ years of hands-on experience in backend engineering and building large-scale distributed systems in production. • Strong proficiency in modern backend programming languages such as Go, Python, Java, or C++. • Proven experience in system design and architecture using public cloud services (AWS, GCP, or Azure). • Deep technical expertise in Kubernetes, Docker, Linux internals, and Infrastructure as Code (IaC) tools like Terraform. • Demonstrated track record of delivering backend systems requiring 99.999% uptime and low-latency performance. • Hands-on experience with database management (SQL/NoSQL), automated CI/CD deployment pipelines, and microservices architecture. • Exceptional problem-solving skills, analytical capability, and strong cross-functional collaboration and communication skills.
