Senior Back-End Software Engineer We are looking for someone who is passionate about software and creating the very best consumer application with an exceptional user experience that is built to be performant and scalable. The ideal candidate will be current in their understanding of modern application development, scalable web applications, and has a proven history of developing great products. To be successful in this position, you must be a dynamic back-end engineer who has a proven record of architecting and delivering dynamic and complex applications. The ideal candidate will have experience in JavaScript, SQL, Java, Scala, REST/GraphQL, MongoDB/DynamoDB, Docker, and AWS. You must have an aptitude for learning new programming languages and frameworks. You will build-out a modern web architecture to enable us to more quickly ship new features into production at scale.
