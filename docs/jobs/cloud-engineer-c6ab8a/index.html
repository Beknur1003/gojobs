Cloud Engineer

cwsc Springfield, VA опубликовано 30 апреля 2026

Гибрид
KubernetesAWSMicroservicesLinuxJava
The Cloud Engineer is responsible for implementing high quality technology solutions that meet the business requirements. Supports planning, design, implementation for cloud infrastructure, systems infrastructure and networking infrastructure. Supports the development of network systems as-built documentation and executes hardware/software lifecycle management to include evaluation of products and making recommendations for the acquisition of new products and sun setting of obsolete products. Evaluates change requests that specifically impact the production system. They may also be responsible for supporting financial planning, forecasting, cost optimization and applying common cloud best practices across the AWS cloud platform to help bridge finance and cloud operations to help drive the efficient use of cloud resources. The ideal candidate should be able to demonstrate working knowledge/experience with several of the following concepts or technologies: • Expert understanding of solutioning (i.e., research, analysis and best practices) • Expert understanding of distributed systems and both hybrid and cloud native computing • Proficient in Operating Systems: Linux and Windows • Advanced understanding of AWS cloud computing and proficient in AWS offerings (e.g., CLI, EC2, EBS, S3, VPC, Cloud Watch) • Advanced understanding of virtualization, both using virtual machines and microservices with containers • Advanced understanding of infrastructure management, including resource optimization, load balancing techniques, and database tuning • Red Hat OpenShift Container Platform (e.g., Kubernetes – including cluster, node, and pod management) • System queue monitoring/optimization (e.g., ActiveMQ Artemis) • Microservice performance/latency (e.g., microservice programmed in Golang, Java) • Knowledge to identify changes to optimize system performance • Knowledge to troubleshoot production problems related to system infrastructure and software application • Knowledge to diagnose and resolve complex system problems, including ability to analyze system logs, metrics, and telemetry data to identify bottlenecks and inefficiencies • Experience with central authentication (LDAP/AD) and security • Knowledge of protocols such as GRE, HTTPS, IP, IPSec, SSH, TCP, UDP, TLS, etc., • Familiarity with Agile development, deployment concepts, methodologies and tools • Exceptional communication skills – ability to communicate well with leadership and technical teams Nice to have: Splunk Enterprise Management Dynatrace management Key Tasks & Responsibilities • Execute and manage tasks to support cloud system performance, scalability, and sustainability. • Monitor performance and ensure system availability and reliability • Monitor system resource utilization, trending, and capacity planning • Configure and install various network devices and services (e.g., routers, switches, firewalls, load balancers, VPN, QoS) • Perform network maintenance and system upgrades including service packs, patches, hot fixes and security configurations • Provide Level-2/3 support and troubleshooting to resolve issues • Work within established configuration and change management policies to ensure awareness, approval and success of changes made to the network infrastructure • Select and implement security tools, policies, and procedures in conjunction with the company’s security team • Communicate with vendors and other IT personnel for problem resolution • Provides engineering analysis to assist government in program Systems Development Life Cycle gate reviews. • Provides cost analyses and executes business case analyses to help the customer make decisions on hardware/software, infrastructure and cloud support.
