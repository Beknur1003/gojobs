Job Requirements We are looking for a GoLang Backend Developer to join our Product Development team to produce scalable Software solutions. You’ll be part of a cross-functional team that’s responsible for the full software development life cycle, from conception to deployment. As a GoLang Backend Developer, you should be comfortable building scalable backend systems, APIs, and real-time communication services for IoT and energy management applications. The ideal candidate will have experience in IoT platforms, MQTT messaging, cybersecurity, and working in Agile environments using tools like Jira. Your main responsibilities: In this role, you will: · Design, develop, and maintain high-performance backend services using GoLang. · Build RESTful and MQTT-based messaging systems for real-time data exchange. · Develop backend services for IoT applications (device communication, telemetry, remote control). · Optimize applications for speed and scalability. · Collaborate with cross-functional teams to identify and develop new features. · Implement security best practices and ensure the application is secure. · Write clean, efficient and maintainable code that adheres to industry standards. · Implement cybersecurity measures (authentication, authorization, encryption, secure data handling). · Test software to ensure responsiveness and efficiency. · Troubleshoot and debug issues in the application and provide timely resolution. Desired · Experience with IoT applications and real-time messaging systems. · Familiarity with MQTT protocol. · Hands-on experience with security best practices and cybersecurity measures. · Understanding of CI/CD pipelines and experience with tools like Maven and Gradle. · Exposure to Agile methodologies and tools like Jira. Work Experience Required · 5–9 years of experience in backend development. · Strong understanding of microservices architecture and distributed systems. · Proficiency in GoLang. · Experience with relational and NoSQL databases (PostgreSQL, MongoDB). · Strong problem-solving and debugging skills. · Understanding of cloud platforms (AWS, GCP, or Azure). · Proficient in Git and version control workflows. · Knowledge of complete software development life cycle (coding standards, code reviews, source control, build processes, testing, operations). · Familiarity with Agile methodologies like Scrum and Kanban. · Excellent communication and teamwork skills. · Great attention to detail & an analytical mind. · Experience implementing testing platforms and unit tests. · Appreciation for clean and well documented code. · Proficiency with Git and Agile framework.
