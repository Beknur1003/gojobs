Role: Golang Senior Technical Specialist Location: Chennai, Pune, Bangalore, Hyderabad Mode of interview: Virtual Mode Experience:13-16 years Job Summary Looking for engineers to design, develop, troubleshoot, and operate cloud VPN/Firewall and network security services across VPN/FW DC, data plane, infrastructure, monitoring, automation, and related service components. The engineer will work on distributed networking systems involving security services integration, IP address management, session lifecycle, service chaining, metrics, logging, and operational readiness. Key Responsibilities Develop and maintain components across VPN/FW DCs, Data Plane, Infra, Features. Work on VPN and Firewall services integrations including radius proxy, IPAM, session manager, CRL/OCSP, Secure Client scripts, global FQDN, and named IP pools. Build and improve automation for deployment, validation, reconciliation, and operational workflows. Enhance monitoring and observability using Prometheus/HPA metrics, metric parsers, MT logging, PD alert tuning, and service health signals. Support DCv2 operational readiness, service-chaining, session-terminator, image verification, and context exclusion workflows. Debug production and pre-production issues related to data plane behavior, OOR/BIR flows, Kafka tombstones, database cleanup/writes, and context-management-service reconciliation. Collaborate with cross-functional engineering teams, QA, SRE, and product owners through Jira-driven development and release processes. Required Skills Strong software engineering experience in distributed systems, networking, or cloud infrastructure. Experience with Kubernetes, microservices, REST APIs, Kafka, databases, and observability tooling. Good debugging skills across logs, metrics, packet/network behavior, and service interactions. Familiarity with CI/CD, automation, and operational support for production services. Strong ownership, communication, and ability to work across multiple engineering teams. Skill Requirements Below are the mandatory skills for this role: • Go lang • Python • Terraform • Kubernetes • Ansible • Kafka • Database • AWS Cloud Network – should be strong in VPN and Firewall • CICD Extensive experience in Cloud production setup's deployment and troubleshooting is required Must Have Skills Golang Good to have Skills • Amazon Web Services (AWS) • Kubernetes Other Requirements Experience with Firewall products, Secure Client, RA-VPN, FQDN, IP pools, RADIUS, CRL/OCSP, or service chaining. Experience with Prometheus, HPA metrics, Kafka event handling, and production alert optimization. Background in cloud security, firewall-as-a-service, or multi-tenant VPN platforms.
