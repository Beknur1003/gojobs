About the job This position is needed to help operate, secure, and modernize Twilio's shared Kubernetes platform substrate (OTK, Segment, and ZipWhip EKS fleets) at scale. Join our Cloud Native Container Operations team as an entry-level platform engineer. You will help manage over 1,000 Kubernetes clusters, tackling real-world multi-cloud complexity. This high-impact role offers structured mentorship from senior engineers, hands-on experience with modern automation tools, and a direct path to improving platform reliability. It is the perfect environment to launch your career in infrastructure engineering at a massive scale. Responsibilities In this role, you'll: • Assist in lifecycle management of cloud hosted Kubernetes platforms serving all of Twilio. • Remediate container and kernel-level CVE vulnerabilities to keep the shared substrate secure. • Write automation scripts in Go and Shell to streamline day-to-day cluster operations. • Collaborate with senior engineers to deploy infrastructure changes safely using Terraform and GitOps. • Troubleshoot basic platform issues, applying lessons learned to continuously improve system reliability. Qualifications Twilio values diverse experiences from all kinds of industries, and we encourage everyone who meets the required qualifications to apply. Required: • Bachelor’s degree in Computer Science, Engineering, or equivalent practical training. • Foundational programming skills in Go (Golang) and scripting with Shell. • Basic exposure to cloud environments, specifically AWS. • Familiarity with Infrastructure-as-Code concepts using Terraform and YAML. • Academic or internship exposure to containerization technologies like Docker or Kubernetes. • Practical understanding of version control (Git) and core software development life cycle (SDLC) concepts. Desired: • Familiarity with GitOps workflows and tools like ArgoCD. • Basic understanding of networking, operating systems, and distributed systems. • Experience using AI-assisted development tools (e.g., Claude Code) for coding or debugging. • Strong problem-solving skills and an eagerness to learn complex infrastructure concepts.
