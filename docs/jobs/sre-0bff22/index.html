資安暨維運服務處_雲端可靠性工程師(SRE)

博弘雲端科技股份有限公司 Zhongshan District, Taipei City, Taiwan опубликовано 19 октября 2026

KubernetesTerraformAWSGCPAzurePrometheusGrafanaPythonNode.js
在一般公司當 SRE，你只顧一套產品的架構；在博弘，你會同時面對數十家企業客戶、橫跨 AWS／GCP／Azure 的真實生產環境——金融、遊戲、電商、製造的架構都會經過你手上。這是累積架構廣度最快的位置。 你將擔任維運團隊的二線技術核心：一線TSE工程師處理日常監控與工單，你負責解決他們解不掉的問題，並用自動化讓同樣的問題不再發生。 【工作內容】 1. 客戶雲端架構優化：診斷效能、成本與可靠性問題，提出並實作改善方案 2. 維運自動化開發：把重複性維運工作寫成工具與 pipeline，降低人工作業與人為失誤 3. 監控告警體系優化：設計監控指標、告警規則與通報流程，讓問題在客戶發現前就被發現 4. 深度技術支援：處理一線升級的疑難事件，與原廠協作解決根因 5. 技術文件與報告：撰寫事故報告（含根因分析）、技術與操作文件 【必備條件】 1. 3 年以上系統、網路或雲端維運經驗 2. 熟悉至少一個公有雲（AWS／GCP／Azure） 3. 熟悉 VM 與 Container，有 Kubernetes（EKS／GKE／AKS）建置或維護經驗 4. 熟悉至少一種程式語言（Python、Golang、Node.js 等），能獨立開發自動化工具 【加分條件】 1. 持有公有雲專業級證照（如 AWS SA Professional、DevOps Professional） 2. IaC（Terraform、CloudFormation）或組態管理工具（Ansible 等）實務經驗 3. 監控與 Log 系統（Prometheus、Grafana、CloudWatch、ELK 等）建置經驗 【這個職位的成長空間】 • 多產業、多雲、多架構的實戰廣度，是單一產品公司給不了的 • 原廠培訓資源與證照考試補助，技術投資公司買單 • 你寫的自動化工具會被整個維運團隊使用，影響力直接可見
