Over 70 percent of global transactional workloads and leading financial, healthcare, and public sector organizations rely on IBM Z and LinuxONE for unmatched security, resilience, and operational scale. As the Test Lead in IBM Z and LinuxONE Security and Automation, you will own the comprehensive quality engineering and testing strategy for next-generation security and identity observability software on IBM Z. In this technical leadership role, you will design, automate, and execute robust test frameworks spanning modern microservices on Linux on s390x and native z/OS mainframe environments. You will bring hands-on z/OS test execution skills to validate complex integrations with RACF, Vault on Z, zSecure, and z/OS Connect, establishing clear definition-of-done criteria to ensure enterprise-grade reliability, performance, and security across quarterly product releases. Your primary responsibilities will include: - Own End-to-End Quality Strategy: Define, implement, and govern the holistic test plan, test architecture, and quality assurance strategy across all components of IBM Z security products. - Execute z/OS Integration and System Tests: Lead hands-on functional, integration, and regression testing in native z/OS and z/OS UNIX System Services (USS) environments, validating security bindings, JCL workflows, and system interactions. - Validate Mainframe Security and Telemetry: Design and execute test scenarios verifying RACF and SAF access control enforcement, SMF record generation and extraction, Vault on Z credential rotation, and OpenTelemetry signal normalization. - Build Test Automation Frameworks: Develop, maintain, and scale automated integration and end-to-end test suites using languages such as Python, Java, or Golang integrated into automated CI/CD pipelines. - Drive Non-Functional and Performance Testing: Measure and validate transaction latency impact, memory footprint, throughput, and system stability under high-volume enterprise transaction loads. - Establish Release Quality Gates: Define acceptance criteria, defect severity thresholds, and the definition of done for quarterly releases, collaborating with Product Management, Architects, and Developers to gate release candidates. - Manage Test Data and Environments: Collaborate with z/OS System Programmers to configure realistic test scenarios, synthetic workload generators, and multi-platform test environments across Linux on s390x and z/OS LPARs. '- Quality Engineering and Test Leadership: 5 or more years of experience leading software quality engineering, test automation, and validation for complex enterprise systems or middleware. - Hands-On z/OS Test Execution Skills: Practical experience executing tests and verifying software in z/OS environments, including familiarity with JCL, TSO/E, ISPF, and z/OS UNIX System Services (USS). - Test Automation Development: Proven programming skills in Python, Java, or Golang to design, build, and maintain automated test harnesses, mocks, and API test frameworks. - Mainframe Security Subsystems Exposure: Understanding of RACF, SAF, or mainframe security administration concepts and audit record verification (e.g., SMF records). - API and Integration Testing: Deep experience with RESTful API testing, gRPC validation, event stream verification, and end-to-end data pipeline testing. - DevOps and CI/CD Integration: Experience integrating automated test suites into CI/CD pipelines (e.g., GitHub Actions, Jenkins, or Tekton) with automated reporting and defect tracking. '- Mainframe Integration Tools: Experience testing integrations with zSecure, IBM MQ on z/OS, or z/OS Connect. - Enterprise Secret Management: Experience validating integrations with HashiCorp Vault, IBM Vault for Z, PKI, or TLS certificate workflows. - Observability and Telemetry Testing: Exposure to validating OpenTelemetry collectors, log aggregation engines, or SIEM integration pipelines. - Linux on s390x and Containers: Experience testing containerized applications deployed on Red Hat OpenShift on IBM Z or Linux on s390x. - Performance and Resilience Testing: Practical experience using performance testing tools (e.g., JMeter, Locust, k6) and executing chaos or fault-injection testing.
