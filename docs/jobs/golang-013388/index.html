職務說明 我們正在尋找擅長 Golang 的後端工程師，一起打造穩定、高效、可擴展的後端系統架構。你將參與系統設計、開發、測試與部署，為產品核心服務打下堅實基礎。 你將參與： 1. 後端服務開發與維護 o 使用 Golang 設計與實作核心 API、後端服務與微服務架構 o 撰寫模組化、易於維護的程式碼，並落實 code review 2. 系統效能與可靠性強化 o 設計並執行單元測試、負載測試，強化系統效能與穩定性 o 處理高併發場景與效能瓶頸調校，優化應用資源使用 3. 跨團隊協作與部署整合 o 與前端、運維團隊協同合作，整合 API 並持續交付 o 導入自動化部署流程（CI/CD），提升開發與上線效率 ________________________________________ 任職資格 必要條件： • 熟悉 Golang 語言開發 • 理解 goroutine、channel 並行處理機制 • 熟悉 RESTful API 或 gRPC 開發架構 • 熟悉 SQL / NoSQL 資料庫操作與效能優化（MySQL、PostgreSQL、Redis、MongoDB 等） • 熟悉 Git 版控工具與基本 CI/CD 流程 加分條件： • 有 Docker / Kubernetes 容器化與部署經驗 • 有高併發、大流量系統設計與實戰經驗 • 有 AWS / GCP / Azure 等雲端平台操作經驗 • 熟悉 分散式架構與訊息佇列（Kafka、RabbitMQ） ________________________________________ 我們希望你具備的特質 1. 擁有工程思維：邏輯清晰，能夠拆解問題並提出有效解決方案 2. 具備效能意識：理解系統瓶頸與成本，追求高效能與穩定性 3. 樂於協作：願意與不同角色（PM、前端、DevOps）密切合作 4. 追求最佳實踐：持續學習新技術，並樂於導入合適工具與流程 如果你熱愛 Golang 並想在穩定又高速成長的環境中發揮影響力，我們誠摯邀請你加入！ 【附註】 本職缺歡迎外國人加入,需具備華語文能力測驗（TOCFL）中級以上
