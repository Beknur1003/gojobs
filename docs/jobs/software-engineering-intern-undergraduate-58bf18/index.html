Role Summary: Join Sony Interactive Entertainment and gain hands-on experience supporting the ongoing development of PlayStation’s Global Financial Reporting Systems. You'll work with the enterprise architecture team to build and improve scalable financial systems, with a focus on event-driven architectures, real-time data processing, and simple, intuitive frontends. As an intern, you'll collaborate with engineers to develop technical solutions, improve existing applications, and explore how software engineering supports financial operations. This opportunity offers practical experience with backend development, data management, testing, and cloud technologies while contributing to projects that improve efficiency across the business. What You’ll Be Doing: • Learn to develop and support event-driven microservices in Go that manage high-volume, real-time financial transactions and data flows. • Explore AI Data mining techniques using existing Datasets to support data analysis and processing. • Develop Unit Testing for the existing code base to improve testing coverage and reliability. • Apply common established code to an existing pipeline and support the ingestion of files into database. • Develop monitoring and recons to improve the reliability and visibility of the current data stack. • Participate in design discussions and collaborate with engineers to explore technical solutions and best practices. • Improve documentation and run book processes to support the productization of SRR's offerings. What We’re Looking For: • Currently pursuing a Bachelor's degree in Computer Science, Engineering, or a related field. • Familiarity with Golang, PYTHON, or similar languages, with an interest in building scalable, real-time microservices and REST APIs. • Experience with SQL and data modelling across different databases. Familiarity with additional reporting databases such as Oracle and Snowflake is a plus. • Understanding of software development principles, design best practices, and architecture standards. • Strong communication skills and the ability to collaborate with technical and non-technical teams in a global environment. • Interest in exploring new technologies and continuously developing technical skills. • Familiarity with cloud platforms, including hybrid cloud/on-prem environments in AWS. • Understanding of governance standards within controlled/compliance-based environments, particularly Sarbanes Oxley. • Experience designing, building, or maintaining single-page applications using React or similar frameworks is a plus. Eligibility: • Students with expected graduation between May 2026 and December 2029 from an accredited university. Undergraduate • Able to work during one of the following periods: May 17th - August 6th or June 14th - September 3rd. Relocation assistance is available for eligible candidates. • Must be available for the entire 12-week internship period.
