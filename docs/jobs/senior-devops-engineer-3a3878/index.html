What you bring • 5yrs (T3) Experience with developing, deploying and maintaining solutions using microservice architecture. • A cloud mindset with an affinity for automation (GoLang or Bash or Shell or Python). • Knowledge of continuous integration, continuous testing, and continuous deployment. • Experience working in datacenter, cloud, and network environments. • Troubleshooting and support experience in system monitoring. • Fluency both written and spoken in English Tech you bring • Public Cloud Services: Managed Kubernetes clusters, Managed Database clusters. • Containerisation & Microservices: Docker, Kubernetes, Helm. • Source control & CI/CD tooling: Flux, Git, GitHub Actions. • Observability & Monitoring tools: Splunk, Dynatrace, Grafana, Prometheus, Loki.
