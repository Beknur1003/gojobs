About The Role ﻿﻿Our client is looking for an experienced Senior Backend Developer with strong expertise in NestJS and Golang to design, develop and optimise scalable backend systems. In this role, you will be responsible for building robust APIs, designing efficient PostgreSQL database schemas, and ensuring high system performance, security and reliability. You are encouraged to demonstrate strong problem-solving abilities, a collaborative mindset and in-depth knowledge of backend development best practices, ORM tools and distributed systems to excel in this role. Key Responsibilities • Develop and maintain high-performance backend applications using NestJS (Node.js) and Golang. • Design and implement scalable RESTful APIs, gRPC services, and microservice architectures. • Improve PostgreSQL database performance through effective schema design, indexing, and query optimization. • Build and maintain efficient data access layers using ORMs such as TypeORM, Prisma, and GORM. • Identify, troubleshoot, and resolve complex backend issues, including latency, concurrency, and memory management. • Work closely with frontend, DevOps, and product teams to deliver reliable and scalable solutions. • Maintain high standards of code quality, security, and system reliability through proper logging, monitoring, and automated testing. • Mentor junior developers, share technical knowledge, and contribute to code reviews and engineering best practices. Key Requirements ﻿Education & Professional Experience: • Bachelor's or Master's degree in Computer Science, Software Engineering, or a related discipline, or equivalent practical experience. • Demonstrated experience in designing, developing, and deploying scalable, reliable, and high-performance backend systems. Required Technical Skills & Qualifications: • At least 5 years of professional experience in backend software development. • Strong hands-on expertise in NestJS (Node.js), Golang, and Bun. • Extensive knowledge of PostgreSQL, including database architecture, schema design, transaction management, and query performance optimization. • Practical experience with ORM frameworks such as TypeORM, Prisma, and GORM. • Solid understanding of API security practices, including JWT, OAuth 2.0, rate limiting, and data encryption. • Strong knowledge of microservices architecture and distributed system design. • Experience implementing caching solutions such as Redis and Memcached, along with message brokers like Kafka and RabbitMQ. • Proficiency in containerization and orchestration technologies, including Docker and Kubernetes, as well as cloud platforms such as AWS, GCP, or Azure. • Strong analytical, debugging, and performance optimization skills, with the ability to identify and resolve complex backend challenges. Nice-to-Have Skills: • Familiarity with API testing tools such as Postman and Insomnia. • Experience with gRPC and Protocol Buffers. • Knowledge of CI/CD tools such as GitHub Actions and GitLab CI. • Understanding of event-driven architecture. • Contributions to open-source projects on GitHub or GitLab. Working Location: Subang Jaya, Selangor, Malaysia Remuneration: RM 5,000 - RM 7,000 Consultant In-charge: Jason | jason.wong@hunters-in.com﻿
