Job Title : Senior Backend Developer - Python / Golang Total Experience : 3 - 7 years Location : Mumbai Job Description : We are looking for an experienced Backend Developer with strong expertise in Python and/or Golang to design, develop, and maintain scalable, high-performance backend systems. The ideal candidate should have a solid understanding of microservices architecture, event-driven systems, databases, and message queues. We are looking for someone who is comfortable working with either Python or Golang and is willing to explore and strengthen their expertise in the other technology. Key Responsibilities : - Design, develop, and maintain scalable backend applications using Python or Golang. - Build and manage microservices-based applications and event-driven systems. - Develop and integrate REST APIs and backend services. - Work with PostgreSQL and message queue services for data management and asynchronous processing. - Use Docker for application containerization and deployment. - Troubleshoot, debug, and optimize backend applications for performance and scalability. - Collaborate with product and engineering teams to deliver reliable software solutions. Must-Have Skills : - Strong hands-on experience in Python or Golang. - Good understanding of Microservices Architecture. - Practical experience with Event-Driven Systems. - Strong working knowledge of PostgreSQL. - Experience with RabbitMQ or other Message Queue Services (Kafka, AWS SQS, etc.). - Hands-on experience with Docker. - Willingness and ability to explore and work further with either Python or Golang. Good to Have : - Experience in REST API development. - Understanding of distributed systems and asynchronous processing. - Familiarity with cloud platforms (AWS/GCP/Azure). - Experience with CI/CD pipelines and Kubernetes. - Knowledge of Redis and other caching mechanisms. Educational Qualification : - Bachelor's or Master's degree in Computer Science, Information Technology, or a related field.
