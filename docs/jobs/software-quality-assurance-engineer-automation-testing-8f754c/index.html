Software Quality Assurance Engineer - Automation Testing

Extreme Networks Bangalore опубликовано 28 октября 2026

PythonAI/LLM
About the Role : Extreme Networks, Inc. is setting a new standard for superior customer experience by delivering network-powered innovation and market-leading service and support. The SQA Engineer will be an individual contributor partnering with Engineering, Services, and Field teams to build and validate products for high-end customer deployments. Responsibilities : - Participate in the full product lifecycle from design and development to deployment. - Write test strategies, test plans, and develop automated test frameworks, tools, and scripts. - Cover functional, performance, and scalability aspects of platform and software solution validation. - Build robust, maintainable test automation infrastructure and test suites. Requirements : - B.E./B.Tech in CS/ECE/TCE/EEE or MS in Computer Science/Application/Engineering. - 2-4 years of relevant industry experience in Telecom/Data Networking and Network Security. - 2+ years of hands-on test automation experience using modern frameworks. Tech Stack & Skills : - Networking : L2/L3 features (TCP/IP, VLAN, STP, IPv4/IPv6), Network Security (AAA, IPSec, Firewalls), and Monitoring (SNMP, Netflow). - Automation : Proficiency in Python/Golang, Shell scripting, Selenium, API testing (Postman), and Load testing (JMeter). - Tools : Traffic Generators (Ixia/Spirent), Network debugging (Wireshark), and Virtualization (VMware ESXi, Hyper-V). Added Advantages : - Certifications : ISTQB, Cloud Practitioner, Network+, CWNA, or CCNA. - Experience with AI-assisted test-case generation.
