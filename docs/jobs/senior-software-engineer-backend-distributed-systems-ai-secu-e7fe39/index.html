Elara is a new Omnissa product line that helps enterprises discover, monitor, and govern how AI is used across their devices. We’re hiring a Senior Software Engineer to build the Elara macOS agent. It’s a lightweight, native, always-on component that shows organizations which AI applications are in use, where network traffic is going, and how sensitive data is handled. Why Elara, and Why Now Enterprises are adopting AI faster than they can see it, let alone govern it. Elara exists to close that gap, and you’d be one of the first engineers to shape it. We’re building Elara the way software is going to be built: agentic from day one. We’re also defining what agent-driven engineering means in the context of an enterprise security product. Engineers on Elara work with AI coding agents every day, delegating implementation, test generation, and refactoring. That frees their own time for what agents can’t do, which is system design, security judgment, and careful review of low-level code where mistakes are expensive. We’re writing this playbook as we go, and you’ll help write it.If you want deep macOS systems work in a category that barely existed two years ago, with a small team and real ownership, this is that role. How We Work • Agents are part of the team. AI coding agents are built into how we design, build, test, and debug. Our approved tools include Claude Code, Cursor and GitHub Copilot. • Humans own the judgment. Engineers own architecture, security decisions, and final review, and are accountable for everything that ships. • Guardrails are first-class work. Excellent documentation, strong CI, and test automation are what let us move fast safely. We build on each other’s work. Reusable agent skills, prompts are tooling means you start productive on day one and every improvement benefits the whole team. What You'll Do Backend Engineering & Distributed Systems • Design, develop, and maintain scalable, high-performance backend services and APIs using Go (Golang). • Build cloud-native, distributed microservices supporting enterprise endpoint management, AI security monitoring, and governance workflows. • Design and implement secure, efficient communication between millions of endpoint agents and backend services using gRPC, Protocol Buffers, HTTP/2, and REST APIs. • Optimize concurrency, resource utilization, throughput, and latency across distributed services. • Design secure multi-tenant architectures with strong tenant isolation, authorization, and data protection. • Develop automated unit, integration, performance, and end-to-end tests. • Participate in architecture reviews, code reviews, and technical design discussions. • Contribute to CI/CD automation, infrastructure-as-code, and reliable production deployments. • Collaborate closely with endpoint engineering, security, frontend, and product teams to deliver end-to-end capabilities. Data Engineering, Storage & Real-Time Analytics • Design and optimize transactional data models, queries, indexing strategies, and database interactions using PostgreSQL. • Implement high-performance caching, distributed coordination, and low-latency data access using Redis or Valkey. • Evaluate and integrate analytical data platforms such as ClickHouse, StarRocks, Apache Druid, or similar OLAP technologies to support high-volume, low-latency analytical queries. Performance, Scalability & Reliability • Design services for high availability, fault tolerance, horizontal scalability, and graceful degradation. • Optimize backend systems for high-concurrency workloads, large-scale telemetry ingestion, and low-latency policy operations. • Implement robust retry mechanisms, backpressure, rate limiting, idempotency, and failure recovery across distributed services. • Establish observability through metrics, structured logging, distributed tracing, and actionable alerting. • Conduct performance profiling, load testing, capacity planning, and production troubleshooting. • Collaborate with SRE and platform engineering teams to improve service reliability, operational efficiency, and deployment automation. Required Qualifications • 5+ years of professional software engineering experience, with substantial experience building backend services and distributed systems. • Strong hands-on programming expertise in Go (Golang), including concurrency, goroutines, channels, context management, and performance profiling. • Solid understanding of distributed systems concepts, microservices architecture, asynchronous processing, and fault-tolerant system design. • Strong experience with PostgreSQL, including schema design, query optimization, indexing, transactions, and database performance tuning. • Hands-on experience with Redis or similar in-memory data stores for caching, high-throughput data access, and distributed application patterns. • Experience designing and developing RESTful APIs, gRPC services, and secure client-server communication. • Strong knowledge of data structures, algorithms, networking fundamentals, and concurrent programming. • Experience building scalable, highly available services in containerized environments using Docker and Kubernetes or equivalent orchestration platforms. • Familiarity with event-driven architectures, message queues, or streaming platforms such as Kafka. • Experience with observability, debugging, performance optimization, and production incident troubleshooting. • Understanding of authentication, authorization, encryption, and secure backend development practices. Preferred Qualifications • Experience building large-scale SaaS platforms, endpoint management systems, cybersecurity products, or high-volume telemetry processing services. • Hands-on experience with ClickHouse, StarRocks or similar real-time analytical databases. • Experience designing high-throughput ingestion pipelines, columnar storage architectures, and near-real-time analytics systems. • Knowledge of Apache Kafka, event-stream processing, and distributed messaging patterns. • Experience managing persistent connections with large numbers of distributed clients using gRPC streaming or similar protocols. • Experience with Redis Cluster, PostgreSQL partitioning, replication, connection pooling, and database scalability patterns. • Familiarity with Prometheus, Grafana, OpenTelemetry, Loki, or similar observability technologies. • Experience with Kubernetes, HashiStack (Nomad, Consul, Vault), or other cloud-native infrastructure platforms. • Knowledge of multi-tenant SaaS architectures, tenant-level data isolation, and enterprise security requirements.
