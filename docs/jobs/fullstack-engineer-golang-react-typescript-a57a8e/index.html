Full Stack Engineer – Golang / React / TypeScript Role Overview We are seeking an experienced Mid to Senior Level Golang Engineer to design, develop and maintain scalable, secure and reliable applications. You will be responsible for end-to-end software delivery, working across frontend, backend and data integration layers while collaborating with cross-functional teams to deliver high-quality solutions. Key Responsibilities • Design, develop and maintain full-stack applications, translating business requirements into scalable, reliable and maintainable solutions. • Build responsive, accessible and high-performance frontend applications using React and TypeScript, incorporating reusable components, state management and robust error handling. • Develop secure and resilient backend services and RESTful APIs, ensuring proper authentication, authorization, validation, versioning and error handling. • Design data models and integrations supporting relational databases, asynchronous processing and event-driven architectures. • Participate in system design, code reviews, automated testing, CI/CD deployments, production troubleshooting and root cause analysis. • Apply cloud-native engineering practices, including containerization, configuration management, monitoring and observability. • Implement secure coding practices, ensuring data protection, access controls, secrets management, auditability and compliance requirements. • Collaborate with product owners, infrastructure, cybersecurity, operational technology (OT) teams, vendors and business stakeholders to deliver technical solutions. • Provide technical guidance, mentor engineers and drive improvements in engineering standards and development practices. • Leverage AI-assisted development tools, including GitHub Copilot and agentic coding assistants, to improve development efficiency while maintaining code quality, security and reliability. Requirements • 5–7+ years of software engineering experience, with proven ownership of production-grade full-stack applications. • Strong hands-on experience with Golang, React and TypeScript, including frontend component architecture, hooks, state management, testing and performance optimization. • Solid backend engineering experience developing, deploying and maintaining APIs and services in production environments. • Strong understanding of system design principles, including scalability, concurrency, caching, reliability, consistency and fault tolerance. • Experience with asynchronous processing, messaging systems and event-driven architectures, including retries, message ordering and duplicate handling. • Hands-on experience with Microsoft Azure or equivalent cloud platforms, containerization, CI/CD pipelines, configuration management and observability. • Proficiency in automated testing, including unit, integration, contract and end-to-end testing. • Experience applying secure software development practices and handling sensitive or operational data. • Familiarity with AI-assisted software development lifecycle (SDLC) practices and the ability to review AI-generated code for security, performance, maintainability and reliability. • Strong analytical, problem-solving and communication skills, with the ability to collaborate effectively with technical and non-technical stakeholders.
