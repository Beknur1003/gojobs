Go — основной язык Офис
Role : Golang Developer Job Summary : We are looking for an experienced Golang Developer with strong hands-on expertise in Go programming to join our engineering team in Bangalore. The candidate will be responsible for developing, implementing, and maintaining software applications using GoLang. The role requires strong programming fundamentals, problem-solving abilities, and the capability to contribute to the development of reliable and efficient software solutions. The ideal candidate should have practical experience in GoLang development and be comfortable working in an onsite engineering environment. Key Responsibilities : - Design, develop, and maintain software applications using GoLang. - Write clean, efficient, scalable, and maintainable Go code. - Develop and enhance backend components based on project requirements. - Identify, troubleshoot, and resolve application issues. - Debug code and optimise application performance. - Participate in code reviews and follow established development standards. - Collaborate with engineering and cross-functional teams to understand technical requirements. - Contribute to application development, testing, and maintenance activities. - Ensure code quality, reliability, and adherence to engineering best practices. Required Skills & Qualifications : - 4+ years of professional software development experience. - Strong hands-on experience with GoLang (Golang). - Good understanding of programming fundamentals and software development practices. - Ability to write clean, efficient, and maintainable code. - Strong debugging and problem-solving skills. - Ability to work collaboratively within an engineering team. Work Location & Interview Requirements : - This is an onsite position based in Bangalore. - Immediate joiners are preferred. - Candidates must be willing to attend a face-to-face interview in Bangalore. - Applicants should be interested and available to work from the Bangalore location. Ideal Candidate Profile : A technically strong GoLang Developer with 4+ years of hands-on development experience, good programming fundamentals, and the ability to contribute to software development and engineering initiatives. Candidates who can join immediately and attend an in-person interview in Bangalore will be preferred.
