Job Description We are looking for a Mid-Level Go Backend Engineer to build and maintain microservices and REST APIs for a high-traffic platform. The role requires independent task ownership, solid knowledge of microservices architecture, PostgreSQL, Redis, and code quality practices, along with active participation in code reviews, incident troubleshooting, and the use of agentic coding tools. The position requires full overlap with Italian business hours. Responsibilities • Build and maintain Go microservices and REST APIs for a high-traffic platform. • Own assigned tasks end-to-end, moving work forward independently and raising blockers early. • Use agentic coding tools to implement features and open pull requests for review. • Review teammates’ pull requests and contribute to technical discussions. • Investigate incidents together with the team using metrics, logs and dashboards to identify root causes. • Participate in team ceremonies and product refinements, and share progress and challenges transparently. • Follow and adapt to the team’s established ways of working and engineering standards. Key Requirements • Willingness to work in the Italian time zone with full overlap. • Strong hands-on Go experience as the main backend language. • Solid experience building and maintaining REST APIs, with a clear understanding of REST principles and conventions. • Experience working in a microservices architecture, including how services communicate through REST and through message brokers. • Basic understanding of core microservices patterns such as Circuit Breaker, Bulkhead and Rate Limiting. • Conceptual understanding of scaling under load: when a service needs to scale, and how caching and resilience patterns prevent failures. • Intermediate experience with PostgreSQL or a similar relational database. • Intermediate experience with Redis or a similar in-memory cache, with a solid understanding of how caching works. • Good command of code design patterns and code structure, such as controller, service and repository layering. • Debugging and troubleshooting beyond the IDE, using metrics, logs and observability tools to find root causes during incidents. • Active participation in code reviews through pull requests, both giving and receiving feedback. • Hands-on experience with agentic coding tools as part of the daily development workflow.
