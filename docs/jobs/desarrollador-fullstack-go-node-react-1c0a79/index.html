En Rekluti, el código es el medio, pero la ingeniería de excelencia es el fin. Buscamos estrategas técnicos que sumen su visión al legado de nuestros clientes. Tu misión será liderar la gobernanza de arquitecturas distribuidas en proyectos de escala masiva, donde la resiliencia y el dominio del SDLC son los pilares de cada solución internacional que construimos Este rol requiere una visión 360° del ciclo de vida de desarrollo de software (SDLC), donde tu experiencia técnica será la base para la gobernanza de arquitecturas distribuidas y la resiliencia de sistemas empresariales críticos en entornos internacionales. Requirements Backend (Go & ): • Golang: Desarrollo de microservicios bajo Clean Architecture, patrones de concurrencia (goroutines/channels) y arquitecturas event-driven con Pub/Sub. • Serverless: Implementación de Cloud Functions en Node.js y gestión avanzada de identidad (OAuth 2.0, Firebase Auth). • Data & Performance: Diseño optimizado en AlloyDB (PostgreSQL), consultas SQL complejas y estrategias de caché con Redis. Frontend Architecture (React & TypeScript): • Modern React: Implementación de React Server Components, hooks avanzados y gestión de estado con Zustand o Redux Toolkit. • Microfrontends: Diseño y mantenimiento de arquitecturas federadas con Vite Module Federation o Webpack 5. • Core Skills: TypeScript strict mode, optimización de performance (Vite 5) y virtualización de listas de alto volumen. Ingeniería y Calidad: • Aplicación estricta de principios SOLID, observabilidad (structured logging) y cobertura de pruebas mínima del 80%. • Participación activa en code reviews y diseño de pipelines CI/CD con despliegues independientes. Highlights Proyectos globales con 30 años de respaldo. 100% remoto, acompañamiento 1:1 de HRBP y desafíos técnicos de alta complejidad con clientes internacionales.
