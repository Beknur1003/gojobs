About Backblaze Backblaze provides reliable, high-availability cloud storage trusted by consumers, SMBs, enterprises, and developers in over 150 countries. Backblaze B2 Cloud Storage supports data-intensive workloads including backup, media, analytics, and modern AI pipelines. Our teams focus on building durable, scalable systems with a strong emphasis on developer experience and operational efficiency. Role Overview We are seeking a Software Engineer to build and maintain open source AI integrations, frameworks, and example applications that make Backblaze B2 Cloud Storage a natural part of how AI workflows are constructed and deployed. This is a front-row seat to the AI ecosystem as it evolves, working directly with the latest AI startups, open source frameworks, and developer tools. This role is expected to actively use the latest AI coding agents and tools as part of everyday development work. The primary objective is to build and contribute production-quality open source integrations, new frameworks, and end-to-end example applications that demonstrate how B2 supports AI workflows. A practical understanding of AI workflows, agent-based systems, and data orchestration is required. This role demands continuous learning and hands-on testing of emerging AI frameworks and APIs as they mature, and is best suited for someone genuinely excited to work at the forefront of AI development. What You’ll Be Doing • Implement and maintain open source AI integrations, frameworks and example applications using languages commonly used in the open source ecosystem, including Python, TypeScript, Go, and Rust. • Build and maintain public sample applications, SDK extensions, notebooks, and reference implementations demonstrating AI and cloud storage best practices. • Use AI-assisted development tools, including Claude Code, to accelerate implementation while validating correctness, security, and performance. • Contribute to open source projects through code contributions, issue triage, reviews, and ongoing maintenance. • Ensure all open source assets meet high standards for testing, documentation, reproducibility, and developer usability. • Maintain clean, well-structured GitHub repositories intended for external adoption and community contribution. • Collaborate with Product and QA to ensure integrations reflect real customer AI workflows and Backblaze B2 usage patterns. Tools and Technologies • Languages: Python, TypeScript, Go, JavaScript and other open source languages • Backblaze B2 SDKs and REST APIs • Open source AI frameworks and tooling • AI coding agents, such as Claude Code, Antigravity and Codex • Jupyter and Google Colab notebooks • GitHub, pytest, CI pipelines What We’re Looking For • Software engineer with experience contributing to open source projects in one or more widely used open source languages. • Comfortable owning and maintaining public repositories with external users and contributors. • Practical understanding of AI workflows, including data ingestion, preprocessing, inference, and agent-based systems. • Experience writing production-quality code with strong testing and documentation practices. • Strong written communication skills with a focus on developer experience and adoption. Why Backblaze • Build open source software used by developers worldwide. • Work at the intersection of AI, data, and cloud storage. • Collaborate with experienced engineering, product, and QA teams. • Competitive compensation and benefits. • Remote-first culture supporting work-life balance. Backblaze is an Equal Opportunity Employer committed to building an inclusive and diverse workplace.
