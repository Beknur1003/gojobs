Nous recherchons un Architecte Logiciel Cloud & Systèmes Distribués (Go) pour intervenir sur un projet stratégique de conception d'une plateforme Cloud privée de nouvelle génération. Missions principales : • Conception : Concevoir l'architecture du Control Plane et des microservices, définir les API et les interfaces, et élaborer les mécanismes d'orchestration et de communication asynchrone. • Choix techniques et sécurité : Participer au choix des technologies Open Source (API Gateway, Message Broker, IAM) et définir les architectures de sécurité (OAuth2, OIDC, RBAC). • Accompagnement : Accompagner les équipes de développement et garantir les bonnes pratiques d'architecture. • Profil cible : Formation supérieure en informatique avec au moins 5 ans d'expérience en architecture logicielle ou développement Backend Cloud. • Compétences clés (Must-have) : Go (Golang), OpenStack, Terraform, Docker, Git, RabbitMQ, Kafka, NATS, Keycloak, OAuth2, OpenID Connect, microservices, API REST, CI/CD. • Soft skills : Leadership technique, autonomie et capacité d'analyse. Informations complémentaires • Localisation : Île-de-France / Neuilly sur Seine • Modalités de travail : CDI, télétravail jusqu'à 2 jours par semaine. #LI-AB8
