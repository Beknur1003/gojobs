Department Overview Software Engineering Job Description We are looking for a highly skilled Full Stack Software Engineer to join our dynamic engineering team. In this role, you will be responsible for designing, developing, and maintaining scalable enterprise web applications. The ideal candidate will have strong backend expertise in Java and Spring Boot, paired with robust front-end development skills using Angular. You will collaborate closely with product, design, and QA teams in an Agile environment to deliver high-quality, high-performance software solutions. Key Responsibilities • Full Stack Development: Design, code, test, and deploy responsive web applications using Java, Spring Boot, and Angular. • Backend Engineering: Build and maintain scalable RESTful APIs and microservices using Spring Boot and related Java frameworks. • Frontend Engineering: Develop dynamic, user-friendly, and highly responsive UI components using modern Angular versions, TypeScript, HTML5, and CSS3/SASS. • Database Management: Design database schemas, write optimized SQL queries, and manage data using relational (e.g., PostgreSQL, MySQL) or NoSQL databases (e.g., MongoDB). • Code Quality & Testing: Write clean, maintainable code following SOLID principles. Implement unit and integration tests using JUnit/Mockito for the backend and Jasmine/Karma/Jest for the frontend. • Collaboration: Participate actively in Agile/Scrum ceremonies (sprint planning, daily stand-ups, retrospectives) and work closely with cross-functional teams to define and ship new features. • Optimization: Identify performance bottlenecks, debug complex issues, and optimize applications for speed, security, and scalability. • Peer Review: Participate in code reviews to ensure coding standards, security, and best practices are maintained across the team. Preferred Qualifications (Nice to Have) • Experience deploying applications on Cloud platforms (AWS, Azure, or GCP). • Hands-on experience with containerization and orchestration tools like Docker and Kubernetes. • Familiarity with CI/CD pipelines (Jenkins, GitLab CI, GitHub Actions). • Exposure to integrating AI capabilities (such as OpenAI/LLMs) into enterprise applications. Basic Requirements Required Technical Skills • Backend: 3–6 years of strong hands-on experience with Core Java (Java 8 or higher), OOP concepts, Collections, and Multithreading. Extensive experience with the Spring ecosystem (Spring Boot, Spring MVC, Spring Data JPA, Spring Security). • Frontend: Solid experience building SPAs (Single Page Applications) with Angular (v8 or higher). Proficiency in TypeScript, RxJS, and state management patterns (e.g., NgRx). • Architecture: Deep understanding of microservices architecture and web service integration (REST/JSON). • Version Control & Tools: Strong proficiency with Git (GitHub/GitLab/Bitbucket) and build tools like Maven or Gradle. • Methodology: Proven experience working in Agile/Scrum development environments.
