▍團隊介紹 Golang 團隊主要負責交易撮合及區塊鏈錢包等功能。除業務邏輯開發維護外，我們亦與 SRE 合作導入新技術並優化架構，例如埋入更多 Prometheus Metrics 及導入 OpenTelemetry 以提升系統可觀測性。 身為 Golang 團隊的一員，你將體會到的團隊文化包括： ☑ 重視主動溝通：比起單打獨鬥，我們更重視主動溝通。每日站立會議中，成員會清楚說明負責項目，讓團隊掌握彼此工作範圍，提升系統熟悉度並互相提醒注意事項。 ☑ 定義明確 Delivery：比起設定 Deadline，我們更重視明確的 Delivery。Sprint 開始前會明確定義產出，結束時彼此分享並 Demo 成果，讓工作能有節奏地累積。 ☑ 雙向討論目標：比起 Top-Down 指派任務，我們重視雙向討論。每季定義 OKR，讓組員清楚專案對公司的價值，並能向上提出建議，建立個人與公司目標的關聯。 ☑ 激發想法與火花：比起沉默不語，我們鼓勵表達想法與擁抱不同意見。溝通的準則是先對齊情境與問題，再討論方法與實作。 ☑ 落實系統分析：比起馬上寫程式，我們更重視系統分析。專案開始前皆透過 SA 定義實作內容與修改範圍，避免重構或方向錯誤，並兼顧可擴充性。 ☑ 深度討論與權衡：理解專案有時程壓力，我們不追求實作能立馬完美，但期望在 SA 過程中深度討論，清楚明白當前設計的風險與取捨。 ☑ 擁抱調整與進步：我們是扁平團隊，任何想法皆可提出討論。除專案外亦會討論合作方式（如 Code Review 機制、PR 顆粒度、技術債回收），期待互相激勵與反思進步。 ☑ 建立夥伴關係：除工作交流外，平常也會分享生活、每月聚餐、討論職涯與新技術，建立良好的夥伴關係。 ▍工作內容 身為團隊資深工程師，我們期待你能： ☑ 擔任專案負責人，主動與 PM 釐清需求，主持系統分析會議、切分實作內容，協助成員理解專案並分配任務；擔任主要窗口說明 API 串接方式，並規劃 Release 與壓測計畫。 ☑ 主動發掘系統中待優化之處，於團隊會議提出並主持討論，協助成員理解脈絡、制定優化方案與落地方案。 ☑ 在系統分析中，於業務邏輯與架構層提供精準建議（如 Index 設計、Query 優化、Redis 結構設計以降低記憶體使用率）。 ☑ 幫助團隊在文化、開發流程及最佳實務上持續迭代改進。 ☑ 對團隊與專案具備責任感，面對問題能主動釐清並協助他人尋找解法，對複雜問題抱持追查 Root Cause 的態度。 ☑ 具備清楚且有脈絡的表達與論述能力。 ☑ 溝通富有耐心、堅持立場但不輕易情緒化；能指導其他工程師並主動分享技術知識。 ☑ 提供高品質程式（如清楚命名、好維護的封裝、可測試的程式、易用的介面與高內聚的業務模組）。 ☑ 與跨部門緊密合作（如與 PM 合作專案、與前端合作 API 串接、與 QA 合作自動化測試建置、與 SRE 合作導入新架構與工具）。 ▍技術要求 【必備條件】 • 核心經驗：5 年以上 Backend 開發經驗（含 3 年以上 Golang 實戰經驗），具備區塊鏈或高併發系統背景者佳。 • API 與通訊：精通 RESTful API、WebSocket 及 gRPC / GraphQL 等通訊協定設計與實作。 • 資料庫與快取：精通 RDBMS（具 Performance Tuning 與 Schema 設計經驗）、NoSQL，以及 Redis 資料結構應用與 Memory 優化。 • 分散式與高併發：精通高併發/多執行緒開發、Kafka，以及分散式系統理論與架構（如 Event-driven、Microservices）。 • 系統架構與設計：具備大資料量系統設計經驗，精通 Design Pattern、Clean Architecture，能開發「高內聚、低耦合」之模組。 • 維運與觀測：熟悉 Docker & Kubernetes 操作、基礎 OS 記憶體管理，並具備 Prometheus、OpenTracing 等系統監控工具經驗。 • 綜合能力：具備優秀的邏輯問題排查（Troubleshooting）與跨團隊溝通整合能力。 【加分項目（Nice to have）】 • 具備區塊鏈交易所相關經驗。 • 具備 Solidity 智能合約開發經驗。 • 具備處理訂單金流服務相關經驗。 ▍進入團隊後的成長路徑 ➜ 1–3 個月內： • 熟悉團隊開發流程與 Convention • 建置開發環境 • 透透過新手專案熟悉 Codebase 與開發流程 • 修復一項技術債 • 了解不同專案 Scope 並參與系統分析 ➜ 3 個月後： • 解決更複雜的架構性技術債 • 負責交易所交易核心及 API 優化與維護 • 主導或參與更多專案 • 參與團隊 OKR 制定
