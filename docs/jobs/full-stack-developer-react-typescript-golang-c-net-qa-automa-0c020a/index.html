Build high-quality software. Improve developer workflows. Make an impact. Are you a Full Stack Developer with a passion for React, TypeScript, clean code and software quality? Do you enjoy building reliable applications and improving the way software is tested, released and deployed? Join our development team and help build the next generation of our Release Management Platform & internal developer toolchain. We are looking for a Full Stack Software Engineer with a strong QA Automation mindset who wants to combine feature development with improving software quality. Your role as Full Stack Developer As a Full Stack Developer, you will design and develop modern software solutions used every day by our R&D and Engineering teams. You will work on a business-critical Release Management Platform that centralizes internal software, simplifies deployments and helps teams deliver faster and more reliably. You will be involved in the full development cycle: from architecture and backend development to frontend implementation, automated testing and continuous improvement. You bring: ✅ Experience as a Full Stack Developer / Software Engineer ✅ Strong knowledge of React and TypeScript ✅ Interest or experience with Golang and/or C# .NET ✅ Experience with modern backend development ✅ A strong interest in Quality Assurance and test automation ✅ Understanding of software engineering best practices Experience with the following is a strong plus: • .NET 9 / .NET 10 • Playwright • automated testing frameworks • Azure cloud services • Azure DevOps pipelines • Figma / UI & UX principles You communicate clearly and are fluent in English.
