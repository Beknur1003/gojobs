Software Development Engineer

CapsLock Bangalore опубликовано 5 ноября 2026

Полная занятость
PythonJavaNode.js
We are looking for versatile Software Development Engineers with hands-on experience in Flutter and backend development. The ideal candidate should be comfortable building user-facing mobile applications as well as developing scalable backend services using Golang, Java, Node.js, or Python. You will work in a fast-paced product environment, contributing to the development of consumer-facing applications and backend systems. Responsibilities: • Develop and maintain cross-platform mobile applications using Flutter. • Build, integrate, and consume REST APIs to support mobile application functionality. • Develop backend services using Golang, Java, Node.js, or Python. • Work with databases, data structures, and backend architecture. • Collaborate with product, design, and engineering teams to deliver scalable product features. • Write clean, maintainable, and production-ready code. • Debug application and backend issues and contribute to performance improvements. • Participate in end-to-end product development, from feature implementation to deployment. Requirements: • 1.5-3 years of overall software development experience. • Hands-on experience with Flutter and Dart for mobile application development. • Working knowledge of at least one backend programming language: Golang, Java, Node.js, or Python. • Good understanding of REST APIs, database concepts, and application architecture. • Experience integrating APIs and working with backend services. • Familiarity with SQL/NoSQL databases and version control systems such as Git. • Understanding of application development, debugging, and deployment processes. • Strong problem-solving skills and an interest in building consumer-facing products. • Experience working in a product/startup environment is preferred.
