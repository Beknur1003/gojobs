About the Role: Okta is seeking a hands-on Software Engineer, Globalization with deep software engineering expertise to architect, build, and maintain our global digital engineering and automation infrastructure. This is a specialized, highly autonomous technical role centered on core software engineering principles, robust automation frameworks, and API-driven system integration—focusing hands-on coding strictly on internal automation, CLI tools, and translation management system (TMS) integrations rather than core product feature development. As the sole technical owner on the localization team, you will operate with complete independence without a technical manager or peers for direct technical guidance on execution. You will serve as the primary owner and sole architect of our localization technology stack, fully responsible for driving technical decisions, system architecture, vendor management, and cross-functional i18n consulting. If you excel at independently solving complex software architecture challenges, driving domain-specific metrics like localization velocity, pipeline reliability, and developer tooling efficiency, and implementing developer-centric i18n tooling, this role is for you. What you'll be doing: • Build and Own the Localization Automation Framework: Design, develop, and maintain core automation workflows and system infrastructure using agentic workflows, Python, and REST APIs, seamlessly connecting enterprise TMS platforms with content repositories, CI/CD pipelines, and internal microservices. • Individual Contributor & Hands-On Development: This is an individual contributor, hands-on software development role. You must be comfortable writing, testing, deploying, and maintaining production-grade code (primarily Python) entirely on your own. • Spearhead AI and Technology Integration: Research, evaluate, and implement cutting-edge localization technologies by programmatically integrating LLM APIs and Custom Machine Translation pipelines into proprietary automation frameworks, along with advanced TMS features, to improve the quality, speed, and cost-effectiveness of our workflows. • Provide Technical Oversight and Systems Integrity: Act as the sole software engineering authority for resolving high-impact architectural failures in the localization stack. Independently conduct deep-dive root cause analysis on complex integration issues, API payload/file parsing conflicts, and distributed system bottlenecks to ensure uninterrupted uptime for global content pipelines. • Lead Code-Level i18n Engineering & Cross-Functional Collaboration: Partner closely with localization and product engineering teams to perform deep-dive i18n code reviews (e.g., reviewing React, Go, or Java codebases), construct Abstract Syntax Tree (AST) static analysis scripts, and define structural architectural patterns so that codebases are natively globalized without taking on direct product feature development. • System Architecture & TMS Administration: Act as the core systems engineer for enterprise TMS instances (e.g., Smartling, XTM), handling schema configurations, webhooks, payload parsing, and custom data connectors. • Build Developer Tooling & Shift-Left CI/CD Pipeline Guardrails: Develop CLI tools, custom linters, and pseudo-localization build hooks in CI/CD pipelines to catch string concatenation, hardcoding, and UI truncation issues automatically during build and pull-request phases. What skills you'll bring: • 6-8 years of experience in software or globalization engineering, with a proven track record of architecting localization solutions at scale. • Expert-level proficiency in Python, API development, and software engineering principles to build, test, and maintain robust automation infrastructure and system integrations. • Experience with enterprise CMS or MSM platforms (e.g., Adobe Experience Manager). • Proven, hands-on experience in programmatically integrating LLM APIs and Custom Machine Translation pipelines into proprietary automation frameworks. • Deep technical understanding of the localization landscape, including TMS architecture, content parsing, and a wide variety of file formats (JSON, XML, XLIFF, properties, etc.). • Ability to conduct code-level i18n reviews across React, Go, or Java codebases (using AST-based parsing or linting) and partner effectively with product engineering teams to drive global readiness across core codebases. • A systematic and analytical problem-solving mindset, with a proven ability to operate with complete independence and autonomy without needing technical direction or engineering management. • Excellent organizational skills and the ability to manage and prioritize multiple technical projects simultaneously.
