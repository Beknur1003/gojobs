The weaponization of AI is driving a paradigm shift in the cyber security industry from proactive to preemptive security: clients must now invest more intelligence and effort in understanding their vulnerabilities before their adversaries do (Open AI). The only way to achieve this is to simulate future attack scenarios at scale, and to run them in high fidelity digital replicas of production environments (Gartner/Forrester). SimSpace serves as the AI Proving Grounds to generate hypersynthetic data which pressure tests controls, tools, teams, and agentic capabilities in full kill chain attacks hidden in realistic environmental traffic and patterns of life. Founded in 2015 by experts from U.S. Cyber Command and MIT Lincoln Laboratory, the platform was initially conceived to assist in Offensive Cyber Operations (OCO), to quickly replicate target environments to conduct mission rehearsal of human operators and their tools to deny (disrupt, degrade, destroy) or deceive (manipulate or exfiltrate data) adversaries. The company has since expanded to serve over a dozen allied governments in OCO/DCO as well as critical infrastructure enterprises around the world. The company is actively investing in the Americas, Asia Pacific, Europe and the Middle East through direct sales and channel partners. SimSpace has launched the AI Proving Grounds Consortium, leading the revolution by creating an open platform for the InfoSec ecosystem to train, validate and operationalize their agentic capabilities before committing to production. Job Summary We are hiring three Senior Software Engineers to build user and attack emulation for AI Proving Grounds (AIPG). Your software will help synthetic people carry out work across applications and integrate controlled adversary activity into experiments customers can configure, observe and repeat. You will use AI-native development to deliver features from written requirements through implementation, tests, release and support. Each hire must bring fullstack experience with an emphasis on backend engineering. Work with coding agents routinely, review shared interfaces with the Staff Engineer and validate behavior with domain specialists. All three openings share these responsibilities and qualifications. What will you be doing at SimSpace? • Build configuration interfaces, backend services or execution integrations that contribute to a complete user or attack emulation workflow. • Use coding agents to plan and implement well-scoped changes, generate tests and debug failures. Inspect generated code and verify behavior and access boundaries before release. • Implement interfaces for identities, application state, permissions, supported actions and observed results so activity remains coherent across systems. • Handle asynchronous execution, retries, timeouts and recovery with behavior operators can diagnose. Check actual effects before treating an uncertain action as complete. • Write unit and integration tests and contribute to end-to-end tests that verify intended effects, compatibility and safe cleanup. • Integrate content and capabilities from Scenario Development and partner teams. Investigate defects with the owners of the affected components. • Review code, document behavior and improve development and test automation. Help diagnose and fix the features you release and prepare their operational handover. What are the qualifications to apply? • Experience independently designing, delivering and maintaining production software features through implementation, testing and rollout. • Practical experience using AI coding agents throughout feature delivery, with examples of clear task instructions, useful repository context, automated verification and correction of generated errors. • Production fullstack engineering experience with strong backend implementation skills and the ability to build and diagnose features across web applications, services and execution interfaces. • Experience designing or consuming APIs and reasoning about state, concurrency, permissions, data validation and failure behavior. • Ability to investigate defects across applications and services using logs, tests and reproducible cases. • Experience implementing automated tests and maintaining secure, observable and supportable software. • Ability to clarify requirements, work with domain experts, review code constructively and explain implementation risks and dependencies. Who you are • You take responsibility for the complete feature and seek help early when another layer or team's contribution is needed. • You verify that software produces the intended effect and use operating feedback to improve it. • You investigate unfamiliar environments and use failed AI-assisted changes to improve instructions, tests and reusable automation. Nice to have but not required • Experience with Go, Python, browser integration or a modern frontend framework. • Experience with Windows or Linux, user sessions, endpoint agents or desktop automation. • Familiarity with cybersecurity, adversary emulation, virtualized environments or agent applications. Our Tech Stack Includes The team uses Go and Python, application and service APIs, browser and execution integrations, containers and automated tests. The development workflow centers on AI coding agents, written requirements, automated checks and code review.
