Obecnie poszukujemy Senior Golang Engineera, który dołączy do zespołu rozwijającego nowoczesną platformę do bezpiecznego, zdalnego dostępu do maszyn przemysłowych. To rola dla osoby, która łączy doświadczenie w programowaniu w Go z dobrą znajomością networkingu, infrastruktury chmurowej oraz bezpieczeństwa komunikacji sieciowej. Jeśli interesują Cię systemy rozproszone, architektura Zero Trust i rozwiązania cloud-native, ten projekt może być dla Ciebie ciekawym wyzwaniem. O projekcie: Wspólnie z naszym niemieckim partnerem technologicznym rozwijamy nową generację platformy Remote Service, umożliwiającej bezpieczne połączenia z maszynami przemysłowymi zlokalizowanymi na całym świecie. Projekt zakłada całkowite przepisanie istniejącego rozwiązania i budowę nowej platformy w podejściu greenfield, z wykorzystaniem Go, Microsoft Azure, Azure Kubernetes Service (AKS), Terraform i OpenZiti. Jednym z kluczowych elementów systemu jest architektura Zero Trust Network Access (ZTNA) oparta na OpenZiti, umożliwiająca bezpieczną komunikację pomiędzy urządzeniami brzegowymi (edge devices) a usługami backendowymi, bez konieczności udostępniania publicznych endpointów. Dołączysz do niewielkiego zespołu developerskiego, który odpowiada za cały cykl rozwoju oprogramowania – od agentów działających na urządzeniach, przez mikroserwisy backendowe, po frontend, infrastrukturę chmurową i testy end-to-end. Szukamy osoby, która wzmocni zespół przede wszystkim w obszarze Go Development, Networking, DevOps i Cloud Infrastructure, będzie aktywnie uczestniczyć w projektowaniu rozwiązań oraz mieć realny wpływ na ich architekturę i jakość. Zakres zadań w projekcie: • Projektowanie, rozwój i optymalizacja komponentów backendowych oraz agentów w języku Go. • Projektowanie i implementacja bezpiecznych rozwiązań umożliwiających zdalny dostęp do urządzeń przemysłowych. • Rozwój architektury sieciowej opartej na podejściu Zero Trust, z wykorzystaniem OpenZiti. • Praca z infrastrukturą chmurową Microsoft Azure, Azure Kubernetes Service (AKS) oraz Terraform. • Współpraca z zespołem przy projektowaniu architektury systemu, REST API, przepływów danych i modeli danych. • Diagnozowanie i rozwiązywanie problemów technicznych, optymalizacja wydajności oraz niezawodności systemu. • Rozwijanie rozwiązań wspierających monitoring, logowanie i tracing aplikacji. • Tworzenie testów jednostkowych i integracyjnych, udział w code review oraz dbanie o jakość kodu. • Współpraca z developerami przy rozwoju i doskonaleniu platformy. OpenZiti, OpenVPN lub Tailscale. • Znajomość architektury Zero Trust, mechanizmów PKI, uwierzytelniania i autoryzacji urządzeń. • Praktyczne doświadczenie z Microsoft Azure oraz Azure Kubernetes Service (AKS). • Znajomość Infrastructure as Code, w szczególności Terraform. • Doświadczenie w budowaniu i utrzymywaniu rozwiązań produkcyjnych z wykorzystaniem monitoringu, logowania oraz distributed tracing. • Umiejętność tworzenia czytelnego, wydajnego i łatwego w utrzymaniu kodu. • Doświadczenie w tworzeniu testów jednostkowych i integracyjnych oraz przeprowadzaniu code review. • Samodzielność, proaktywna komunikacja i umiejętność współpracy w niewielkim zespole developerskim. • Otwartość na pracę w środowisku Agile. Mile widziane: • Doświadczenie z komunikacją asynchroniczną i systemami messagingowymi, np. Azure Event Hubs lub MQTT. • Znajomość TypeScript i doświadczenie w rozwoju aplikacji backendowych. • Praktyczna znajomość PostgreSQL lub innych relacyjnych baz danych. • Znajomość Angular i doświadczenie w rozwoju aplikacji frontendowych. • Doświadczenie w projektach związanych z Industrial IoT, urządzeniami edge lub systemami zdalnego dostępu.
