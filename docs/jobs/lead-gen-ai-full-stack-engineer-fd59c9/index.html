Key Responsibilities: 1. Full-Stack Engineering: - Build scalable user-facing applications using React, Next.js, or similar frontend frameworks. - Develop backend services using Node.js, Python, Java, Golang, .NET, or any modern backend framework. - Design and develop RESTful and/or GraphQL APIs. - Implement secure authentication, authorization, and system integrations. - Ensure high performance, scalability, reliability, and code quality across the application stack. 2. GenAI Systems & Agentic Architectures: - Design and implement end-to-end RAG pipelines, including document ingestion, chunking, embeddings, vector indexing, and retrieval optimization. - Integrate and orchestrate LLM APIs such as OpenAI, Anthropic Claude, AWS Bedrock, and similar foundation models. - Build AI Agents and Agentic workflows for reasoning, tool execution, task orchestration, and autonomous decision-making. - Develop reusable prompt frameworks, guardrails, caching, evaluation pipelines, and fallback mechanisms. - Optimize AI systems for latency, accuracy, scalability, safety, and cost. 3. Cloud Engineering & DevOps: - Deploy and manage applications on AWS using services such as Bedrock, Lambda, ECS/EKS, S3, API Gateway, DynamoDB, and RDS. - Build CI/CD pipelines and automate deployments across staging and production environments. - Implement monitoring, logging, tracing, and performance optimization. - Work with vector databases including Pinecone, Weaviate, Chroma, or Milvus. 4. FinTech Product Development: - Develop AI-powered features for financial products with a focus on security, compliance, and auditability. - Process structured and unstructured financial data for intelligent automation. - Ensure AI solutions align with FinTech regulations and business requirements. - Collaborate with product, compliance, engineering, and business teams. Required Skills & Experience: - 58 years of software engineering experience. - Strong proficiency in React.js or Next.js. - Strong backend development experience in Node.js, Python, Java, Golang, .NET, or any modern backend technology. - Experience building and deploying production applications on AWS, including AWS Bedrock. - Hands-on experience with REST APIs, microservices, and distributed systems. - Strong understanding of RAG architectures, embeddings, vector databases, and retrieval optimization. - Experience with LLM APIs and frameworks such as LangChain or LlamaIndex. - Practical experience developing AI Agents and Agentic AI workflows. - Experience with Docker, CI/CD pipelines, and cloud-native architectures. - Prior experience in the FinTech domain (payments, lending, banking, underwriting, treasury, fraud detection, etc.). Nice to Have: - Experience with FastAPI, Spring Boot, Express.js, ASP.NET Core, or Gin. - Experience with Terraform, Kubernetes, or serverless architectures. - Experience with model fine-tuning or domain adaptation techniques. - Knowledge of compliance standards such as PCI-DSS, SOC2, and GDPR. - Experience with event-driven architectures and messaging systems.
