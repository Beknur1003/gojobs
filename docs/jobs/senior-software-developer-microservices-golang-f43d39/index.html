Job title: Senior Software Developer (Microservices - GoLang) Location: Cambridge (Hybrid, 3 days onsite) Job type: Permanent, full-time About the Role: We are seeking a highly motivated and experienced Microservices Developer to join our growing team. You will be responsible for designing, developing, and deploying microservices using GoLang within a cloud-native environment. This role requires a strong understanding of Golang programming language, microservice architecture, containerization, and cloud technologies. You will work closely with other developers and cloud operations teams to ensure the successful delivery of high-quality software. Mandatory Skills: • 8+ years of experience in software development with at least 3+ years of experience in GoLang. • Strong understanding of microservice architecture, principles, and design patterns. • Should have knowledge of developing microservice using Agile Methodology. • Experience in designing, developing, and consuming RESTful APIs (OpenAPI 3.0). • Proficiency in writing unit, integration, functional tests and System test using GoLang testing frameworks. • Experience using Atlassian tools for project management and collaboration. • Solid understanding of Git and JIRA. • Excellent communication, collaboration, and problem-solving skills. • Should have good working knowledge and configuration knowledge of MongoDB. • Strong Debugging skills. • Should have working experience in Design document creation ( LLD,HLD,UML,API Specification etc.,) Desired Skills:. • Experience with containerization technologies like Docker and container orchestration platforms like Kubernetes. • Knowledge of CI/CD pipelines and tools like Jenkins. • Experience of using AI will be added advantage.
