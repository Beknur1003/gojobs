About the Role: As a Software and AI Engineer, IT Systems, you’ll design and develop AI agents and first-party applications that bring intelligence, automation, and great user experience to CoreWeave’s internal ecosystem. You’ll work across the stack ranging from agentics frameworks (using iPaas platforms like Workato) or latest software frameworks from LangChain, LangGrapsh, Cohere, ChatGPT agentflow, OpenAI API, Gemini agent flow, or Glean API to rich, React-based interfaces and mobile experiences to robust backend services written in Node.js and Go. What You’ll Do: • Develop agents using AI capabilities into applications using frameworks such as LangChain, LangGraph, ChatGPT API, and Glean API • Design and build first-party web and mobile applications using React (TypeScript) and modern front-end frameworks • Develop scalable backend services in Node.js and Go for data processing, orchestration, and automation • Build internal AI agents and copilots that assist with tasks in Finance, Billing, and Supply Chain domains, integrating with systems like ERP, HRIS, MRP, DCIM, Data Warehouse among others - either natively or via an iPaaS like Workato or Boomi • Implement APIs and microservices that enable modular and event-driven application architectures • Leverage GenAI tools (Cursor, Claude, Copilot, ChatGPT Codex) to accelerate development, testing, and documentation • Ensure robust observability, maintainability, and security across the application stack • Collaborate with stakeholders in Finance, Accounting, Security, and Engineering to design intelligent, user-centered workflows Who You Are: • Programming Experience: 7+ years of professional programming experience in languages such as TypeScript, Python, Go, C++, C#, or Java, specifically for delivering production-grade cloud services. • Full-Stack Proficiency: Proven expertise in modern backend (e.g., FastAPI, gRPC) and frontend technologies (e.g., React, Next), including the development of scalable backend services in Node.js and Go. • AI/LLM Experience: Solid familiarity with Generative AI frameworks (LangChain, LangGraph, ChatGPT API, or Glean API) and experience shipping production-grade AI/ML/LLM-based applications, or strong desire to build them. • Architecture: Solid experience designing and implementing RESTful APIs, microservices, and event-driven integration architectures. • Cloud & DevOps: Strong understanding of cloud environments (AWS, Azure, or GCP), container orchestration (e.g., Kubernetes), and proficiency with DevOps and CI/CD principles. • Automation Tooling: 7+ years of experience in scripting (Python or Bash) for automation and tooling. Preferred: • Experience developing AI-powered or agentic applications integrated with complex enterprise data (ERP, HRIS, DCIM, Data Warehouse). • Proficiency with machine learning and data engineering platform tools (e.g., Ray, Kafka, Spark). • Experience with iPaaS platforms (Workato, Boomi) for building internal AI agents and copilots. • Exposure to the functional domains of Marketing, Finance, Billing, or Supply Chain where intelligent automation can drive measurable business efficiency.
