You will work with Docker, Kubernetes, Helm, and Argo CD to deliver and maintain applications across multiple classified, air-gapped networks. Responsibilities include maintaining hardened containers, addressing vulnerabilities, and troubleshooting application networking and deployment issues within existing Kubernetes environments. We are looking for a strong software engineer with practical container experience and an interest in taking greater ownership of application delivery and operations. Candidates can develop their experience with our deployment tools, security practices, and classified environments while working with the team. Key Responsibilities • Build, maintain, and improve full stack applications and supporting services. • Maintain Docker images and containerized development workflows. • Deploy and support applications using Helm, Argo CD, and GitOps workflows. • Coordinate releases across multiple classified, air-gapped networks, including environment-specific configuration, artifact availability, and rollback procedures. • Maintain hardened container images and investigate and remediate CVEs affecting application dependencies and containers. • Troubleshoot application, Kubernetes, networking, and ingress issues, coordinating with platform administrators when needed. • Improve deployment automation, application observability, and operational documentation. Qualifications • Strong software engineering experience across front-end and back-end development. • Practical experience building and troubleshooting applications using Docker. • Familiarity with Kubernetes application deployments and a willingness to deepen that experience. • Familiarity with CI/CD pipelines, automated testing, and Git-based workflows. • Comfort working in Linux environments and investigating application and configuration issues. • Interest in learning GitOps, container hardening, vulnerability remediation, and application operations across classified environments. • Strong troubleshooting, communication, and collaboration skills. The ideal candidate would have experience: • Building full stack applications with React, TypeScript, Golang, and PostgreSQL. • Managing application deployments with Argo CD, Helm, and GitOps. • Delivering and supporting applications across multiple classified, air-gapped networks. • Building and maintaining hardened container images and managing CVE remediation. • Troubleshooting Kubernetes workloads, Services, ingress, DNS, TLS, and network policies. • Maintaining GitLab CI/CD pipelines for testing, scanning, building, and packaging applications. • Supporting applications within an established Kubernetes platform and working with platform administrators to resolve infrastructure dependencies.
