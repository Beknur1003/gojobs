En SG Tech buscamos un/a Desarrollador/a Fullstack para incorporarse a un proyecto tecnológico en el que participará en el diseño, desarrollo e integración de soluciones de software. El puesto requiere trabajar tanto con tecnologías Frontend como Backend, dentro de un ecosistema que incluye Golang, Node.js, Vue 3, bases de datos, microservicios y sistemas de mensajería. Funciones principales • Diseñar y desarrollar soluciones técnicas e integraciones. • Participar en desarrollos con Golang, Node.js y Vue 3. • Trabajar con bases de datos relacionales y documentales. • Desarrollar e integrar servicios REST y APIs. • Participar en soluciones basadas en microservicios. • Trabajar con sistemas de mensajería. • Realizar pruebas unitarias y aplicar buenas prácticas de desarrollo. • Utilizar herramientas de control de versiones.
