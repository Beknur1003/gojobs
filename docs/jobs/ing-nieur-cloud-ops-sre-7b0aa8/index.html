Vous interviendrez sur toutes les applications du groupe Drouot - Marketplace d’enchère et Ecommerce complexe et traffic élevé avec search, recommandations, paiement, enchères temps réel, vidéo temps réel - ~150 site web construits et déployés sur un websitebuilder sur mesure - - Vos missions seront les suivantes Garantir le fonctionnement optimal de l’infrastructure • Garantir la fiabilité, performance et scalabilité des systèmes, en ligne avec les SLO/SLA • Prévenir les incidents via le suivi des métriques, l’ajout de benchmarks et de tests automatisés • Développer des dashboards d’observabilité (performance, sécurité, disponibilité) sur Datadog • Gérer les incidents : analyser les root causes, mettre en œuvre les actions correctives Fiabiliser les changements d’infrastructure • Collaborer avec l’équipe technique pour déployer de nouveaux systèmes • Proposer des simplifications / amélioration de l’architecture Environnement Technique Backend : Golang Frontend : SvelteKit, Typescript, Javascript, Flutter/Dart Compute : GCE, GKE (managed kubernetes), VertexAI (GPU workloads) Provider : GCP, AWS Databases : Postgres Search : SOLR, Qdrant Events : Kafka CI/CD : Github Actions Observabilité : Datadog • Diplômé d’une école d’ingénieur • Au moins 4 années d’expériences significatives dans un rôle DevOps / SRE / Infra sur des applications complexes à fort traffic Compétences requises : - Expertise linux et ses environnements - Automatisation via Ansible, Terraform - Scripting bash et une expertise en programmation sur Python ou Go - Caching and Web, Cloudflare, Nginx ou Varnish - Security fundamentals - Francais et Anglais écrit/oral Compétences nice to have - Observabilité avec Datadog - CICD : Github actions - Gestion de cluster Kubernetes via Helm • Call avec le CTO • Entretien tech sur place avec le CTO et DevSecOps • Entretien de fit avec d’autres membres de l équipe tech
