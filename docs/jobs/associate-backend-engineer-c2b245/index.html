Description EDTS is opening opportunities for fresh graduates and early-career professionals to join the Ignition Development Program as an Associate Backend Engineer. This two-year program offers an opportunity to develop technical capabilities, gain real-world experience, and grow professionally as part of a technology team. Selected candidates will be required to work fully on-site at Wisma 46, Central Jakarta.
