Role Summary We are looking for a Senior Developer to design, build, and maintain hub-native forecourt applications. The role requires strong backend engineering in Go, hands-on work with message queues and NoSQL, and practical exposure to AI-enabled features. Candidate will own technical delivery, and mentor junior engineers. Key Responsibilities • Design and develop scalable, high-performance backend services in Go for hub-native forecourt applications • Build event-driven, asynchronous workflows using message queues • Design data models and optimize queries in MongoDB • Integrate AI capabilities (LLM/ML-based features, AI-assisted workflows) into application services • Write clean, testable, well-documented code; participate in design and code reviews • Troubleshoot production issues and drive root-cause analysis • Collaborate with architects, QA, and product teams; mentor junior developers Must-Have Skills Go (Golang): Strong hands-on experience building production-grade services; concurrency, API design, testing • Queues: Experience with message queues/brokers (e.g., Kafka, RabbitMQ, SQS); event-driven patterns, retries, idempotency • NoSQL (MongoDB): Schema design, indexing, aggregation, performance tuning • AI: Practical experience integrating AI/LLM services or ML models into applications Good-to-Have Skills • Terraform (infrastructure as code) • GitHub Actions (CI/CD pipelines) • Temporal.io (durable workflow orchestration) Qualifications • Bachelors degree in Computer Science, Engineering, or equivalent • 7 to 9 years of software development experience, with significant recent experience in Go • Strong understanding of microservices, distributed systems, and RESTful/gRPC APIs • Good communication skills and ability to work in an Agile team Nice to Have • Exposure to IoT, retail, fuel/forecourt, or payments domains • Cloud experience (Azure/AWS/GCP) and containerization (Docker, Kubernetes)
