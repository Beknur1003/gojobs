Nos encontramos en la búsqueda de un Web Developer (Fullstack) para unirse a nuestro equipo. Buscamos un perfil enfocado en la mejora continua, capaz de escribir código mantenible, eficiente y bien documentado, que busque activamente retroalimentación y explore nuevas herramientas o lenguajes. Principales Responsabilidades: • Asistir en el desarrollo y mantenimiento de nuestros sistemas. • Identificar y resolver bugs (errores), garantizando la estabilidad y el rendimiento del sistema. • Colaborar en el diseño e implementación de nuevas funcionalidades. • Preparar documentación integral que abarque arquitectura, bases de datos y guías de usuario. • Sugerir mejoras, mantenerse actualizado sobre las tendencias de la industria y perfeccionar continuamente las habilidades de programación. Requisitos del Perfil: • Experiencia: De 2 a 4 años de experiencia comprobable en desarrollo web. Conocimientos técnicos: • Conocimiento en desarrollo de plataformas web y bases de datos relacionales. • Control de versiones: Manejo de plataformas como Bitbucket o GitHub. • Idiomas: Inglés intermedio o avanzado. • Disponibilidad: Se requiere disponibilidad para viajar. Conocimientos Deseables (Preferidos): • Desarrollo en Golang. Desarrollo en el stack de Next.js / JavaScript / React. Manejo y desarrollo en PostgreSQL. • Desarrollo y consumo de servicios web, como APIs RESTful. ¿Qué ofrecemos? • Sueldo: $20,000 a $25,000 MXN brutos mensuales. • Modalidad de trabajo: Remoto - Híbrido • Tipo de Contrato: Posición permanente. Si cumples con los requisitos y te apasiona el desarrollo tecnológico, ¡postúlate por este medio con tu CV actualizado!
