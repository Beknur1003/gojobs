Senior Software Engineer II (Backend Focused Full Stack) Role Overview We are seeking a Senior Software Engineer II to design, build, and maintain scalable cloud-based applications and services. This role is primarily focused on backend development using Python and Golang AWS, while also contributing to frontend applications built with React and Angular. The ideal candidate will have strong application development experience, a passion for solving complex technical challenges, and proficiency with modern AI-powered engineering tools to deliver high-quality solutions efficiently. Key Responsibilities • Design, develop, and maintain scalable backend services, APIs, and application components using Python. • Build and support cloud-native applications on AWS with a focus on reliability, performance, security, and scalability. • Contribute to frontend development using React and Angular to deliver intuitive, responsive, and accessible user experiences. • Collaborate with Product, UX, QA, and Engineering teams to translate business requirements into high-quality end-to-end solutions. • Participate in architecture discussions, system design reviews, and technical decision-making. • Optimize application performance, observability, maintainability, and operational efficiency. • Troubleshoot production issues, perform root cause analysis, and implement sustainable solutions. • Leverage AI-assisted development tools such as Cursor, Claude, GitHub Copilot, and similar technologies to accelerate delivery, improve code quality, automate repetitive tasks, and enhance engineering productivity. • Champion AI-first engineering practices, incorporating AI into software design, development, testing, documentation, and code review workflows. • Mentor team members through code reviews, technical guidance, and best-practice sharing. Preferred Qualifications • Experience with microservices and event-driven architectures. • Experience modernizing legacy applications and platforms. • Knowledge of observability, monitoring, and reliability engineering practices. • Experience building SaaS applications. • Experience leading technical initiatives and mentoring engineers. • Passion for continuous learning and adoption of emerging technologies, including AI-driven development workflows.
