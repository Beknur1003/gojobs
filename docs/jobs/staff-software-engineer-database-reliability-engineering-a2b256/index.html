Our Enterprise Information Technology (EIT) organization is expanding, and we are seeking a Staff Database Reliability Engineer to drive the modernization of our enterprise data tier. In this role, you will champion the shift from traditional DBA administration to a code-first, automated Database Reliability Engineering discipline across our hybrid cloud footprint. Partnering with application and platform teams, you will architect, automate, and migrate mission-critical relational workloads into Google Cloud Platform (GCP). Our estate is predominantly Microsoft SQL Server, supported by PostgreSQL, Oracle, and MySQL. You will treat the database tier as a scalable internal product—delivering self-service platforms, automated data durability, and resilient high-availability architectures. Mission & Impact • Database as Code & CI/CD: Establish automated, repository-driven pipelines for declarative infrastructure (Terraform) and zero-downtime database schema migrations (e.g., Flyway, Liquibase, DACPAC), eliminating manual DDL execution and configuration drift. • Durability & Continuous Recovery: Automate backup verification and point-in-time recovery (PITR) testing across hybrid environments, continuously validating RPO and RTO targets through programmatic failover drills and disaster recovery automation. • Deep-Tier Observability: Define database-specific SLIs/SLOs that move beyond raw host metrics to capture real user impact—tracking query latency regressions, replication lag, lock contention, transaction log health, and connection pool exhaustion. • Paved-Road Data Platforming: Build self-service provisioning workflows, client/server connection-pooling standards, and intelligent traffic-routing layers (e.g., PgBouncer, ProxySQL, Availability Group listeners) that empower application teams to safely query and scale without manual DBA intervention. • Cloud Modernization & Migration: Lead the technical execution of re-architecting and migrating legacy database workloads into GCP (e.g., Cloud SQL for SQL Server, Cloud SQL for PostgreSQL, AlloyDB), designing minimal-downtime cutover strategies and heterogeneous migration paths. • Performance & Capacity Engineering: Optimize high-throughput OLTP workloads through proactive indexing strategies, execution plan analysis (EXPLAIN / Query Store), TempDB/buffer pool tuning, and long-range storage/IOPS capacity modeling. What you'll need to have: • Minimum 9 years of experience in cloud and hybrid datacenter operations with a focus on Infrastructure as Code (IaC) and Reliability Engineering. • Proficiency with GCP (preferred), AWS, and/or Azure. • Proficient in using GitOps, Terraform and Ansible in a CI/CD (continuous integration and continuous delivery) pipeline. • Experience using PowerShell, Python, or GoLang. • Solid understanding of Linux (POSIX) and Windows System administration as well as networking and firewalls. • Proficiency in Microsoft SQL Server and/or PostgreSQL, including hands-on experience designing resilient high-availability and traffic-routing architectures (e.g., Availability Groups, PgBouncer) and proactive optimization of high-throughput OLTP workloads. • Understanding of security best practices and compliance standards such as CIS, NIST and PCI. • Ability to participate in an on-call rotation every 7-8 weeks. What would be nice for you to have: • Bachelor’s degree in Computer Science Information Technology, Engineering. • Relevant industry certifications.
