Back End Engineer

Fita is a health-tech platform that aims to plug the preventive healthcare gap in Indonesia with localized content that has been curated by certified fitness trainers & nutritionists. We are looking for a Back End Engineer to design and develop high-quality backend services and APIs, with a focus on long-term maintainability, resilience, and high scalability. In Fita, you possess absolute ownership over the systems in your business scope of control. As we have a very dynamic culture, a creative and analytical individual who is not afraid to speak up, take charge, and be bold would be the next rockstar candidate. Our Tech Stack: • Golang and Typescript for Backend • Kubernetes for Backend • GraphQL for API Gateway in NodeJS and Apollo • Google Cloud Platform in Indonesia region with services BigQuery, Pubsub, GKE, Cloud SQL • Flutter for Mobile Apps Job Description : • Engaged in the full agile development lifecycle; designing, developing, testing, deploying, maintaining, monitoring, and improving high quality backend services and APIs • Collaborate with cross-functional team and other engineers specializing in backend services, web frontend, mobile apps, and test automation, as well as product design and ideation • Write unit tests to ensure safety net of regression tests for effective refactoring • Write clean, efficient, high performance and testable code • Transforming requirement into highly scalable and robust system Requirements: • Preferably 3 years of experience in web application development using popular frameworks such as Kubernetes for API and internal services backend platform • Bachelor degree in Computer Science or related fields, or equivalent professional experience in software development • Knowledge and experience in Golang and Typescript for internal services • Strong passion for building secure, high quality, testable, reusable, and clean code • Firm grasp in Algorithm, Data Structure, OOP, Design Pattern • Experience working in an agile environment • Solid understanding of GraphQL and the performance costs associated with queries • Experience in building large-scale web apps/services/API
