Title and Summary Software Engineer I About the Role Join Mastercard’s Transaction Stream team in O’Fallon, Missouri, and help build the applications and services that power critical capabilities across the real-time payment network. This is an opportunity to work on software that operates on a global scale, where speed, reliability, and resilience matter every day. As a Software Engineer I, you will collaborate with engineers and product partners to build, test, and enhance solutions that support the movement of transactions around the world. Role and Responsibilities Develop, test, maintain, and support software applications and services with guidance from experienced engineers Write clean, maintainable, reusable, and secure code following established engineering standards, software design principles, and best practices Participate in software design activities by translating functional and non-functional requirements into scalable, maintainable, and secure software components and services Contribute to the implementation of established software architecture patterns and system designs while gaining experience with scalability, reliability, security, and long-term maintainability considerations Develop and maintain unit, functional, and integration tests to ensure software quality, reliability, and correct system behavior Apply knowledge of data structures, algorithms, and software engineering fundamentals to develop efficient and scalable software solutions Participate in code reviews and incorporate feedback to improve code quality, maintainability, and engineering practices Contribute to APIs, microservices, distributed applications, and event-driven solutions. Apply secure coding practices and security-by-design principles throughout the software development lifecycle Collaborate with Product, QA, Architecture, Security, DevOps, and Operations teams to deliver software solutions that meet business and technical requirements Support cloud-based applications and services while assisting with monitoring, troubleshooting, root cause analysis, and issue resolution Assist in monitoring, analyzing, and optimizing application performance, scalability, and resource utilization to meet business and operational requirements Contribute to CI/CD, automation, observability, reliability, performance, and operational excellence initiatives Help implement operational readiness practices, including logging, monitoring, alerting, and system supportability considerations Continuously learn and adopt modern software engineering technologies, tools, and practices All About You Bachelor's degree in computer science, engineering, information technology, or a related field, or equivalent practical experience in Software Development through a relevant internship, Co-Op, research, or professional business is preferred. Strong understanding of programming fundamentals, data structures, algorithms, and object-oriented design concepts. Knowledge of software design principles and the ability to develop maintainable, scalable, and reusable software solutions. Understanding common architectural concepts and patterns such as layered architectures, microservices, event-driven systems, and distributed applications. Working knowledge of Java, Golang, Kotlin, C#, or similar programming languages. Familiarity with Spring Boot, Spring, Hibernate, or similar frameworks. Exposure to JavaScript, Angular, or similar front-end technologies is a plus. Understanding REST APIs, microservices, relational databases, SQL, and software testing practices. Familiarity with unit testing frameworks and automated testing methodologies. Familiarity with Git, CI/CD pipelines, cloud platforms, DevOps practices, and Agile software development methodologies. Basic understanding of application performance, scalability, monitoring, and observability concepts. Understanding troubleshooting methodologies, root cause analysis, and problem-solving techniques. Basic understanding of secure coding principles, OWASP guidelines, and application security best practices. Strong analytical thinking, problem-solving, communication, collaboration, and continuous learning skills.
