About Base Base is America’s next-generation power company. We’re rebuilding the foundation of modern civilization–electricity–by deploying a vast network of distributed batteries that is transforming today’s fragile, centralized grid into a resilient and abundant system. We are engineers, operators, and creatives solving some of the most complex, interdisciplinary challenges of our time. About the Role System Integration guarantees that our hardware and software always meet the interfaces the rest of Base depends on: deployment, manufacturing, field service, and trading. We ensure new products and firmware iterations never break those interfaces. We are the primary accelerant for how quickly Base can deliver features to the field. The telemetry infrastructure and control plane software we implement enables Base to iterate on new features and hardware quickly. What You'll Do: • Design new databases and golang/python APIs for storing test data and tracking releases on the fleet and in manufacturing. • Design and develop integration tests, CI/CD pipelines, and infrastructure that validate the system as a whole. • Create infrastructure enabling closed-loop agent workflows allowing faster feature development and validation. What You’ll Bring • 5+ years of experience building gRPC and Go APIs • Experience defining databases and storing time series or similar data • Proficiency in Go and Python • A background in cloud software engineering. Test or validation experience isn’t required.
