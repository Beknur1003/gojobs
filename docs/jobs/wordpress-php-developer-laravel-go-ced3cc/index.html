🔥 WordPress / PHP Developer (Laravel + Go) Ищем сильного разработчика в продуктовую команду. Разрабатываем внутреннюю highload-систему в сфере iGaming. Это не работа с лендингами или типовыми сайтами на WordPress — мы строим сложный внутренний продукт с автоматизацией, интеграциями, очередями, бизнес-логикой и постоянным развитием. ❗️Для нас ОБЯЗАТЕЛЬНО: ✅ коммерческий опыт Laravel ✅ коммерческий опыт разработки под WordPress ✅ коммерческий опыт Go Если нет опыта хотя бы с одной из этих технологий — к сожалению, не сможем рассмотреть резюме. Чем предстоит заниматься: • дорабатывать внутренние сервисы и API; • работать с WordPress-интеграциями; • разрабатывать и поддерживать WordPress-плагины; • работать с REST API и XML-RPC; • поддерживать Go-сервисы, работающие через очереди; • запускать регулярные задачи, разбирать логи и дебажить продакшен; • периодически работать с Docker и серверной частью. Наш стек: PHP 8.4 • Laravel 12 • Livewire 3 • Go • MySQL 8 • Redis • RabbitMQ • Vue 3 • Tailwind • Docker • Nginx • Ubuntu Будет плюсом: ➕ опыт работы с большим количеством WordPress-инсталляций; ➕ опыт сложных интеграций; ➕ опыт поддержки highload/production-систем. 📍 Удалённая работа. 💰 Конкурентная заработная плата (обсуждается индивидуально). 📩 Присылайте резюме в личные сообщения @recruiter_sasha
