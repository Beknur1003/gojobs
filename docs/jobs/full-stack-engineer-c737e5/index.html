MIRIAN AI is building the agentic financial operating system for PE-backed mid-market companies. Our AI agents don't just track tasks — they do the actual accounting work: computing accruals, reconciling transactions, generating journal entries, and improving with every close cycle. Humans review and approve. We're looking for a Founding AI Engineer who can design and build production agentic systems from scratch — not wrappers around ChatGPT, not chatbots, not prompt playgrounds. Real multi-step AI pipelines that handle financial data with precision. What you'll own: This is a true full-stack role, balanced across Go and TypeScript. You'll own features from API design and data model to the UI — and the design-driven codegen chain that keeps the contract honest in between. You'll work across three areas: • Backend services & data — Go services behind a design-driven Goa API, PostgreSQL schemas and typed sqlc queries, and event-driven workflows on Kafka. • Frontend product surfaces — Next.js / React interfaces for AR/AP, cash forecasting, reconciliation, and dashboards, consuming the API through generated, end-to-end-typed contracts. • The seams in between — multi-tenant isolation, service-to-service integration with our agentic and workflow services, money correctness, and observability across the stack. Stack: Golang, PostgreSQL, Message Queues, Next.js, React, Typescript, NodeJS, Docker, Terraform You should have: • 4+ years building and shipping production web applications end-to-end, comfortable owning both server and client. • Strong backend skills in a statically typed language — Go preferred (or strong Java / C# / Rust / TypeScript-backend experience and eagerness to go deep in Go) — building REST APIs and services. • Strong frontend skills with React and TypeScript, and a modern framework (Next.js or equivalent). • Solid relational database fundamentals — schema design, migrations, and writing and optimizing SQL (PostgreSQL preferred). • Experience with API contracts and codegen (OpenAPI, Goa, GraphQL, or similar) and keeping types honest across the boundary. • Familiarity with event-driven / async systems (Kafka, queues, or similar) and the failure modes they bring. • A habit of testing across the stack — backend unit and integration plus frontend unit and e2e. • A correctness mindset for sensitive data — you reach for transactions, idempotency, and careful validation by instinct. • Strong collaboration and written communication — thrives in a design-driven, async, written-first culture alongside PM, design, and engineering. Bonus points: Fintech, accounting, or ERP domain knowledge Prior 0→1 startup experience Why MIRIAN: Founding-team ESOPs and impact — shape the product and architecture from day one $5B+ market dominated by legacy tools with zero agentic AI in production Remote-friendly, flexible hours
