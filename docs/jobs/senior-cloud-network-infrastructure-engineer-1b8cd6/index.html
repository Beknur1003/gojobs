Position Summary: We are seeking an experienced Cloud Network Infrastructure Engineer to join our cloud engineering team. The ideal candidate will design, deploy, operationalize, and maintain high-performance Software-Defined Network (SDN) architectures, bridging deep data center networking expertise with modern cloud-native telemetry, microservices, OpenStack environments, and Kubernetes-native application development. You will manage virtual switching platforms, overlay networking, and L2/L3 dynamic routing to ensure seamless connectivity and robust security across our private cloud infrastructure. Roles and Responsibilities: • SDN & Virtual Switching: Architect, maintain, and optimize Open Virtual Switch (OVS) and Open Virtual Network (OVN) dataplanes. Manage OpenFlow pipelines and SDN controllers for automated flow control. • Cloud Infrastructure & Kubernetes: Deploy and operationalize OpenStack networking services (Neutron, Metadata Service) using OpenStack Ansible. Contribute to the development of cloud-native networking products, microservices, and controllers for our Kubernetes product ecosystem. • Overlay & Underlay Networking: Design, optimize, and troubleshoot overlay tunnels (VxLAN, GENEVE) and virtual networks (VLAN 802.1Q) running over high-throughput physical fabrics (L3 CLOS, LACP, MCT/vLAG). • L2/L3 Routing & Switching: Implement and manage dynamic routing protocols (BGP, EVPN, OSPF) for WAN/DC interconnects, ECMP load balancing, and VRRP gateway redundancy. • Network Security: Secure network traffic across untrusted boundaries using IPsec VPNs (IKEv2, ESP). Configure stateful firewalls, connection tracking (Conntrack), and NAT rules using IPTables/Netfilter and NFTables. • Automation, Telemetry & Lifecycle Management: Build, test, and validate network topologies locally using Vagrant and hypervisors (KVM/QEMU) prior to production rollouts. Develop resources to handle platform upgrades, real-time streaming telemetry architectures (gRPC, ProtoBuf, Kafka), and network lifecycle management. Technical Requirements & Skill Stack: • Cloud & Virtualization Platforms: OpenStack (Neutron, Nova, Metadata Service), OpenStack Ansible, KVM/QEMU, DevStack • Software-Defined Networking (SDN): Open vSwitch (OVS), Open Virtual Network (OVN), OpenFlow, SDN Controllers • Overlay & Encapsulation: VxLAN, GENEVE, VLAN (802.1Q) • L2/L3 Protocols & Data Center: BGP, EVPN, OSPF, ECMP, VRRP, IPv4/IPv6, ARP/NDP, Ethernet (802.3), STP/RSTP, L3 CLOS, LACP, MCT/vLAG • Cloud-Native & Telemetry: Kubernetes, Docker, Kubernetes Controllers, Operator SDK, CRDs, gRPC, Protocol Buffers, Kafka, Numaflow • Security & Packet Inspection: IPsec (IKEv2, ESP), IPTables/Netfilter, NFTables, Conntrack • DevOps, Automation & Languages: Golang (Go), Python, C, Vagrant, Ansible, Linux CLI, Bash, CI/CD (Jenkins, Git), OpenAPI / REST APIs Preferred Qualifications: • Bachelor’s degree in Computer Science or a related field with 8–15 years of software development and infrastructure experience across cloud engineering, telecommunications, or large-scale data center environments. • Deep expertise in Linux networking concepts, packet path traversal, and kernel-level networking subsystems. • Proven track record with production OpenStack deployments using OVN/OVS as the default networking backend. • Strong proficiency in Golang, Python, or C with hands-on experience in white-box switch network management applications. • Self-starter with strong problem-solving skills, analytical thinking, and excellent written/verbal communication in dynamic environments. To succeed in this role, you will need to be a team player with a strong sense of ownership for your work and a passion for working in a data-driven organization.
