รายละเอียดงาน หน้าที่และงานที่ต้องรับผิดชอบ •พัฒนา Web Application ทั้งในส่วนของ Front end และ Backend โดยใช้ภาษา Golang •วิเคราะห์และออกออกแบบระบบการทำงาน ให้สอดคล้องและครอบคลุมตามขอบเขตงาน (Scope of Work) ที่ตกลงไว้ •รวบรวมความต้องการ (Requirements) จากผู้ใช้งาน เพื่อจัดทำ Prototype และจัดทำเอกสารยืนยันข้อกำหนดระบบ (System Specification) ร่วมกับลูกค้า เพื่อให้มั่นใจว่าขอบเขตและรายละเอียดของระบบถูกต้องตรงตามความต้องการ •ทำงานร่วมกับทีมพัฒนา (Development Team) เพื่อผลักดันและควบคุมคุณภาพของระบบให้พร้อมสำหรับการทดสอบ UAT •สนับสนุนและดูแลขั้นตอนการทดสอบระบบ (UAT) ไปจนถึงกระบวนการนำระบบขึ้นใช้งานจริง (Production Deployment) •ร่วมเสนอแนวทางการพัฒนาระบบที่สามารถตอบโจทย์ของแต่ละโครงการ •พัฒนางานเพื่อง่ายต่อการปรับปรุงแก้ไขในอนาคตได้อย่างมีประสิทธิภาพ (testable, efficient and easily maintainable code) *ทักษะที่ต้องการ* •มีความเชี่ยวชาญในการเขียนโปรแกรมภาษา Golang เป็นอย่างดี (paradigms, constructs and idioms) •มีความสามารถในการเขียน Full Stack programming •มีความเชี่ยวชาญในการใช้ AI, Claude, Antigravity •มีความรู้ในการใช้งานโดยทั่วไปของ Goroutine และการใช้งาน channel •มีประสบการณ์ในการใช้งาน Go frameworks หรือแก้ไขโค้ด Go frameworks ที่เป็นที่นิยม เช่น echo •มีความรู้ในการใช้งาน Git version control, docker, docker-compose, bash shell คุณสมบัติผู้สมัคร • สำเร็จการศึกษาระดับปริญญาตรี วิทยาศาสตร์คอมพิวเตอร์, วิศวกรรมคอมพิวเตอร์, เทคโนโลยีสารสนเทศ หรือสาขาที่เกี่ยวข้อง • มีความเข้าใจและความชำนาญ Golang, HTML 5, CSS, Bootstrap, JavaScript, jQuery, PostgreSQL, Object-oriented programming , REST Protocol , AI, Claude, Antigravity • มีความเข้าใจและความชำนาญ hire purchase หรือ loan จะพิจารณาเป็นพิเศษ • หากสามารถพัฒนา Mobile Application ด้วย Flutter ได้จะได้รับการพิจารณาเป็นพิเศษ • มีประสบการณ์การทำงานเกี่ยวกับการพัฒนา Web Application และ Micro Service อย่างน้อย 1 ปี • ทัศนะคติดี ตรงต่อเวลา มีความรับผิดชอบสูง ใฝ่เรียนรู้สิ่งใหม่ๆ • สามารถทำงานเป็นทีมได้ • Thai nationality
