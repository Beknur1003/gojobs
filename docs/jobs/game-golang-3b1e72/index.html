【職務說明】 我們正在尋找一位 遊戲數值工程師（Golang），負責遊戲內數值、機率與經濟系統的設計與實作。 此角色需同時理解 數值邏輯與後端工程，能將設計直接寫進系統中，並透過程式進行驗證與監控。 你不是只產出表格，而是 負責數值是否真的「跑得對、跑得穩」的人。 【工作內容】 • 設計並實作遊戲數值系統（倍率、機率、獎勵、消耗） • 規劃並驗算 RTP、勝率、期望值與風控邏輯 • 使用 Golang 撰寫數值運算與機率模組 • 建立數值模擬工具（Simulation）驗證長期表現 • 與遊戲後端整合數值流程（下注、派彩、結算） • 設計數值設定結構（Config / JSON / DB） • 分析營運數據，協助判斷異常輸贏與行為風險 • 配合版本更新進行數值調整與優化 【必備條件】 • 具備遊戲數值企劃或相關實務經驗 • 對機率、統計與期望值具備清楚理解 • 熟悉 Excel / Google Sheet，能建立完整數值模型 • 具備 Golang 開發能力，可獨立撰寫與測試程式 • 能理解遊戲後端流程與資料結構 • 能清楚與工程、企劃、QA 溝通數值邏輯 【加分項】 • 熟悉棋牌、遊戲類數值設計 • 具備 RTP、輪組、權重設計與驗算經驗 • 有 Monte Carlo Simulation 實作經驗 • 熟悉 MySQL / PostgreSQL，可分析歷史數據 • 有風控、反作弊或異常行為分析經驗
