The Role The Senior Software Engineer on the Attack & User Emulation team builds the core endpoint capabilities and distributed orchestration services that power realistic offensive security and simulated user personas across cyber ranges. By operating below standard application abstractions, this role ensures simulated users interact with OS facilities (sessions, processes, UI, and networking) to generate high-fidelity system and security telemetry for training and evaluation. In this role, you will work primarily on our Go-based endpoint agent while contributing across Kotlin backend services, messaging, and orchestration. You will solve distinctive technical challenges around operating-system behavior, privilege boundaries, and dynamic desktop/web automation across thousands of virtual environments. What the Team Owns • High-fidelity attack and user emulation capabilities for cyber range environments. • Cross-platform endpoint agents (Windows/Linux) and backend orchestration services. • System reliability, security, and telemetry fidelity across active virtual systems. • Operational interfaces for AI-driven personas and higher-level range automation. What You'll Do • Design, build, and operate production software in Go, python, and Kotlin for attack and user emulation frameworks. • Develop deep operating-system integrations on Windows and Linux using native OS APIs, session management, process execution, and system facilities. • Improve system reliability, security, testability, and observability across message-driven architectures operating at scale. • Solve high-fidelity emulation problems, including desktop/web automation, privilege boundaries, input simulation, and realistic user timing. • Collaborate with backend, security, and AI engineering teams to define reusable primitives and APIs. • Conduct code and design reviews, mentor team members, and elevate the team's platform-level engineering craft. What Success Looks Like • By 30 days: Build familiarity with the Go endpoint agent, contribute to active feature development, and debug cross-platform OS behaviors. • By 60 days: Lead the design and delivery of a new endpoint emulation capability or native system integration. • By 90 days: Drive architectural improvements across distributed messaging and agent subsystems while mentoring junior/mid-level engineers. Required Qualifications • 6+ years of hands-on software engineering experience delivering and operating production software. • Deep practical experience with Windows or Linux systems development, working below application-level abstractions (e.g., native APIs, process/session management, eBPF, IPC, or security contexts). • Strong proficiency in Go, or demonstrated expertise in another systems language with the ability to become productive in Go quickly. • Experience with JVM languages (Kotlin/Java) and message-driven, asynchronous architectures. • Demonstrated ability to reason about complex OS failure modes, trade-offs between fidelity and complexity, and distributed system stability. Preferred Qualifications • Building production endpoint, monitoring, remote management, or EDR/security agents. • Experience with desktop/browser automation, accessibility APIs, or computer vision. • Familiarity with hypervisors, VDI, endpoint security telemetry, adversary emulation, or tool integration for AI agents.
