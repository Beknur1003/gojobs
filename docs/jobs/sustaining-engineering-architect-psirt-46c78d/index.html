【Sustaining Engineering｜ Architect】PSIRT 資安研究工程師

杜浦數位安全股份有限公司 Songshan District, Taipei City, Taiwan опубликовано 19 мая 2026

Офис Полная занятость

【團隊介紹】 Sustaining Engineering｜持續精進，提供極致體驗 持續優化產品效能、穩定性與使用體驗，讓產品在每一次使用中都更加可靠與完善。 【我們的期望】 我們正在尋找一位具備資安研究能力與問題解決思維的夥伴加入 Sustaining Engineering 團隊。你將參與產品漏洞分析、資安事件應變與漏洞揭露流程，運用逆向工程、漏洞研究與安全分析專業，協助團隊快速掌握漏洞影響、推動修復並降低產品風險。我們期待你不只是處理已知問題，也能主動深入 Root Cause、發掘潛在風險，並與研發及外部資安社群保持良好溝通，共同提升產品的安全韌性。 【工作內容】 ・ 擔任對外窗口，接收並過濾來自 Bug Bounty 平台或外部研究人員的安全通報，驗證其真實性並評估影響範圍。 ・ 運用 IDA Pro、GDB 等工具進行逆向工程與動態測試，重現漏洞攻擊路徑，並從程式碼底層找出根本原因（Root Cause）。 ・ 即時監控全球 CVE 與 0-day 威脅，第一時間研判對產品架構的影響程度，並制定應急緩解措施 (Workaround) 並主導跨部門修復專案。 ・負責編寫技術性安全性公告 (Security Advisories)，確保內容準確且能有效協助客戶應對風險。 ・ 代表公司對接 CVE 編號申請，執行協同漏洞披露 (CVD) 流程，並維護與資安社群的專業溝通 ・追蹤修復成效並進行漏洞回溯分析，協助研發團隊從源頭提升產品安全韌性。 【必要條件】 ・ 3 年以上開發經驗，精通 Golang, Python, C/C++ 其中一項以上。深入理解 Linux Kernel、系統呼叫 (System Calls) 與記憶體管理機制。 ・3 年以上滲透測試或漏洞研究經驗。 ・ 熟練操作 IDA Pro, Ghidra, GDB, Binary Ninja 等逆向與分析工具。 ・ 熟悉 MITRE ATT&CK 框架，能將攻擊手法轉化為產品防禦邏輯。 ・ 具備實務資安事件響應 (IR) 經驗。 ・熟悉 Docker/K8S 容器化架構與微服務安全性實務。 ・ 具備良好的團隊合作及跨部門溝通能力 【加分條件】 ・ 畢業於電機、資工相關系所 ・ 參與過CTF、金盾獎資安相關競賽 ・ 有技術社群參與或開源貢獻經驗，特別是資安社群(HITCON等等) ・ 具備相關資安證照，如 OSCP、CISSP、CISA、ECSA、CEH 等等 Requirements
