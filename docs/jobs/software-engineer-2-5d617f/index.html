Software Engineer 2

Deutsche Telekom Digital Labs Gurgaon опубликовано 11 августа 2026

PostgreSQLMySQLMicroservicesCI/CDJava
We are looking for a Software Engineer II with strong backend development expertise in Java and Golang to build scalable, high-performance applications and distributed systems. In this role, you will design and develop microservices, build robust REST APIs, optimise application performance, and collaborate with cross-functional teams to deliver reliable, secure, and production-ready solutions. If you're passionate about solving complex engineering problems, building systems at scale, and writing clean, maintainable code, we'd love to hear from you. Responsibilities: • Design, develop, test, and deploy scalable backend applications using Java and Golang. • Build and maintain high-performance RESTful APIs and Microservices. • Develop reliable, secure, and scalable distributed systems. • Write clean, efficient, reusable, and production-quality code following engineering best practices. • Participate in system design discussions and contribute to architectural decisions. • Optimise application performance, scalability, and reliability. • Collaborate closely with Product, QA, DevOps, and Engineering teams throughout the development lifecycle. • Troubleshoot production issues, perform root cause analysis, and implement long-term solutions. • Write unit and integration tests to ensure high code quality and maintainability. • Participate in code reviews and promote engineering best practices. • Contribute to CI/CD pipelines and deployment automation. • Mentor junior engineers and actively contribute to technical knowledge sharing. Requirements: • 4-6 years of backend software development experience. • Strong proficiency in Core Java and Golang. • Hands-on experience with Spring Boot and Microservices Architecture. • Experience designing and developing REST APIs. • Strong understanding of Data Structures, Algorithms, Object-Oriented Programming (OOP), and Design Principles. • Experience working with MySQL and/or PostgreSQL. • Familiarity with Git and modern version control practices. • Experience with unit testing, debugging, and performance optimisation. • Strong analytical, problem-solving, and communication skills. • Bachelor's or Master's degree in Computer Science, Information Technology, or a related field.
