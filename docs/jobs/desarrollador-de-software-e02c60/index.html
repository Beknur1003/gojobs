Desarrollador de Software

Fernando Andrés Fernández Flórez Remote, Worldwide опубликовано 1 ноября 2026

Buscamos un desarrollador de software con al menos 5 años de experiencia en Golang y perfil fullstack para unirse a nuestro equipo. Trabajarás en el diseño y construcción de servicios backend y en su integración con frontend, con un rol central en el modelado y la optimización de bases de datos relacionales. Qué harás: - Diseñar, desarrollar y mantener servicios backend en Golang. - Construir y mantener APIs y su integración con aplicaciones frontend. - Modelar, optimizar y mantener bases de datos relacionales con estándares SQL. - Revisar código, participar en decisiones de arquitectura y documentar soluciones. - Colaborar con producto, diseño y el resto del equipo de ingeniería. Qué necesitas (imprescindibles): - 5+ años de experiencia profesional con Golang. - Experiencia fullstack: backend en Go e integración con frontend (React, Vue o similar). - Dominio de bases de datos relacionales y SQL estándar: modelado, consultas complejas, índices y optimización. - Experiencia construyendo y consumiendo APIs REST. - Inglés técnico para leer documentación y comunicarte por escrito. Deseables: - Experiencia con PostgreSQL o MySQL en producción. - Conocimiento de Docker y CI/CD. - Experiencia en entornos cloud (AWS, GCP o Azure). - Testing automatizado en Go. Qué ofrecemos: - Rango salarial: indicar banda real, por ejemplo 8.000.000–11.000.000 COP mensuales. - Modalidad remota, híbrida o presencial en ciudad. - Contrato y beneficios como seguro, presupuesto de formación y días de vacaciones. - Un equipo de personas y un reto concreto: describir el reto real del primer año. Cómo contratamos: - Revisión de postulación (3–5 días). - Entrevista técnica con el equipo (60 minutos). - Prueba técnica breve o revisión de código. - Entrevista final con el hiring manager. - Decisión en plazo. Ubicación: Remoto - Cualquier parte Habilidades requeridas para este trabajo: • Automated testing • Bases de datos relacionales • CI/CD • Cloud platforms • Desarrollo full-stack • Docker • Go • MySQL • PostgreSQL • REST API • SQL
