Senior Software Engineer, Security Engineering We are looking for a Senior Software Engineer that will join the Auth0 Security Engineering organization. In this role, you will join a team of Software Engineers dedicated to building and managing services that secure the platform that Auth0 runs on. You will be instrumental in expanding our platform security controls and architecting custom workflows in a scalable, reliable manner. What You Will Do • Service Development: Build, maintain, and operate platform security services and controls using Python, Node.js, or Golang. • Security Data Pipelines: Design, build, and optimize custom workflows to ingest, process, and distribute security data to downstream systems at scale. • Scalable System Architecture: Architect maintainable, secure, and resilient microservices and platform integrations that protect our infrastructure without adding friction for engineering teams. • Engineering Quality: Write clean, testable, and well-documented code while driving technical designs and participating in code reviews to maintain high engineering standards. What You Bring • Software Development Experience: 5+ years of hands-on experience designing, building, and maintaining production-grade software services. • Core Language Proficiency: Hands-on mastery of Python, Node.js, or Golang. • System Design Expertise: Strong track record of designing scalable, maintainable, and secure software architectures. • Cloud & Containers: Solid experience with cloud-native environments (AWS or Azure) and container technologies (Docker, Kubernetes). • Security Mindset: Practical experience building platform security controls, managing service permissions, and applying secure coding practices. • Education: A Bachelor's degree in Computer Science, Information Security, Systems Engineering, or a related field. Nice to Have • Experience with high-throughput streaming platforms or log processing tools (e.g., Kafka, Kinesis, Pub/Sub, Vector). • Experience with Infrastructure-as-Code (Terraform) and Policy-as-Code tools. • Familiarity with compliance standards (FedRAMP, SOC2) and security frameworks in multi-cloud environments. • Experience or interest in applying AI/ML tools to automate security workflows and analysis. #LI-HYBRID #LI-SH1 P18115_3566087 Below is the annual salary range for candidates located in Canada.
