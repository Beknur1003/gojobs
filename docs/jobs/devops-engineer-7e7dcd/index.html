Location: Vaesteras, Vastmanland County, Sweden Job ID: R0139142 Date Posted: 2026-09-08 Company Name: HITACHI ENERGY SWEDEN AB Profession (Job Category): Engineering & Science Job Schedule: Full time Remote: No Job Description: Hitachi Energy is a global leader in electrification, powering a sustainable future with innovative grid technologies and digital solutions. We’re inspiring the next era of sustainable energy, making electricity more accessible to all and empowering societies to thrive. IVRS (Integration, Verification, Release and Support) is a department within Grid Integration Modular Advanced Control (GI MACH), working with securing the quality of the MACH platform, the brain of the HVDC station. We are responsible for verification of the MACH Platform towards high level requirements and for releasing the platform to our customers. IVRS is developing a robust CI/CD pipeline to revolutionize delivery of the MACH platform in an HVDC project. Join the GI MACH team to help build a next-generation data platform that unifies data from diverse sources, creating a single source of truth for code development, design, and manufacturing. As a DevOps Engineer, you’ll play a pivotal role in automating and scaling the infrastructure that powers this platform, with extra focus on our internal applications and tools. How You’ll Make an Impact • Design, develop, and implement mission-critical tools and applications to support a scalable, high-performance, high-volume production environment with global users. • Build and maintain CI/CD pipelines for C++ and C# development environments, leveraging tools like Azure DevOps, MS Build scripts, Python and build systems. • Automate infrastructure and software processes using tools like Ansible or Terraform. • Manage containerized environments using Docker or Podman including creating and testing Windows and Linux images. • Implement full-stack monitoring and alerting systems using tools like Sensu, Splunk, Logstash or Nagios. • Plan and execute software and infrastructure upgrades based on data-driven capacity planning. • Manage configuration, variants, and version control using Git, TFVC, and release management tools like Jira. • Streamline development experiences for teams by designing scalable CI/CD processes and optimizing workflows with containerization and virtualization. • Collaborate with teams to support business needs and provide domain expertise for internal systems. Your background • Bachelor’s Degree or higher in Engineering, Computer Science, or a related field. • Expert skills in Linux, networking, storage, and virtualization. • Proficiency in scripting languages such as Python. Shell and Golang beneficial. • Strong understanding of CI/CD processes and experience designing pipelines using GitHub or GitLab. • Familiarity with build systems (Makefiles, CMake) or Bazel and release management tools (e.g.: Git). • Ability to manage software and infrastructure upgrades with a focus on scalability and performance. • Experience setting up and supporting development environments for C++ and C#. Embedded system developer background beneficial. • Strong English communication skills, Swedish is advantage.
