Job Responsibilities • Develop and configure products, migrating legacy applications to a modern cloud-native, containerised tech stack • Build responsive, accessible web frontends using ReactJS, TypeScript and Next.js • Develop backend services and APIs in Golang and/or Kotlin, including long-running business processes using a workflow engine (e.g. Temporal) • Set up and maintain secure AWS infrastructure using Infrastructure as Code (e.g. Terraform) • Implement security controls and monitoring, including authentication and identity integration with Singpass, Corppass, OIDC and SAML • Build and maintain CI/CD pipelines in GitLab, and deploy workloads to Kubernetes (EKS) • Instrument applications for observability using tools such as Dynatrace or Datadog • Support production deployments, troubleshoot issues and take part in incident resolution • Write clean, tested, well-documented code and take part in code reviews • Senior Consultant: define the technical architecture and target state for the modernised platform • Senior Consultant: lead delivery across multiple workstreams, coordinating with product owners, DevSecOps and agency stakeholders • Senior Consultant: provide strategic technical guidance, set engineering standards and mentor team members • Senior Consultant: plan legacy-to-modern migration approaches, including sequencing, risk management and cutover Job Requirements • Minimum 3 Years Of hands-on full stack development experience • Frontend: ReactJS, TypeScript • Backend: Golang and/or Kotlin • DevOps: CI/CD, Docker, Kubernetes • Cloud: AWS architecture and services • Infrastructure as Code: Terraform (or equivalent) • Hands-on experience with at least one observability tool, e.g. Dynatrace or Datadog • Experience migrating or modernising legacy systems is strongly preferred • Experience delivering Singapore Government or public sector projects is an advantage • Good to have: Next.js; setting up AWS infrastructure (e.g. S3, EKS/ECS, EC2, Lambda, RDS, Load Balancers, API Gateway); a workflow engine (e.g. Temporal); a rules engine (e.g. GoRules, Open Policy Agent) • Good to have: authentication using OIDC and SAML; authorisation using RBAC and ABAC; infrastructure and container security practices • Good to have: Government identity and security tooling such as Singpass, Corppass, ADFS, WOG AD, CAM (GovTech Central Accounts Management) and Trend Micro FAM • Good to have: OutSystems, Oracle Policy Automation (OPA) / Oracle Intelligent Advisor (OIA), Sitefinity, Oracle • Strong problem-solving and debugging skills in production environments • Clear communication with technical and non-technical stakeholders Interested candidates are invited to apply via the “Apply Now” button.
