Job Description: Senior Golang Backend Engineer - AWS & Kubernetes Locations: Bloomington, Illinois / Dallas, Texas, USA Primary Skills: Go (Golang), Backend Development, Microservices, AWS, REST/gRPC APIs Role Overview We are seeking an experienced Senior Golang Backend Engineer with strong expertise in backend development, microservices architecture, and cloud-native application development. The ideal candidate should have hands-on experience building high-performance backend services using Go (Golang), developing secure REST and gRPC APIs, and deploying containerized applications in Kubernetes-based cloud environments. The role involves working across the complete software development lifecycle, including application development, CI/CD automation, infrastructure as code, observability, performance optimization, and production support. Experience using AI agents to accelerate software development and testing is also required. Must-Have Technical Skills • 5+ years of overall software engineering experience with strong backend development expertise. • Minimum 2+ years of hands-on Go/Golang development experience, preferably building enterprise-grade backend services. • Strong understanding of Go programming concepts, including: • Goroutines and Channels • Concurrency and Interfaces • Error Handling and Context Management • Dependency Management • Performance Optimization • Experience using AI agents to accelerate development and testing activities. • Hands-on experience developing REST APIs and/or gRPC-based microservices. • Strong knowledge of JSON, HTTP/HTTPS, authentication and authorization, OAuth 2.0, JWT, error handling, and API versioning. • Experience building containerized applications using Docker and deploying them through Kubernetes. • Hands-on experience with AWS services, including: • Amazon EKS / ECS • AWS Lambda • API Gateway • Amazon S3 • CloudWatch • IAM • Secrets Manager • Experience building and maintaining CI/CD pipelines using GitHub Actions, GitLab CI, or equivalent tools. • Experience with logging, monitoring, distributed tracing, metrics, alerting, and production observability. Roles & Responsibilities 1. Backend Development & Microservices • Develop and maintain high-performance backend services and microservices using Go (Golang). • Design and develop secure, scalable REST and gRPC APIs for enterprise applications. • Create reusable frameworks, common service components, libraries, and engineering accelerators. • Implement efficient application logic and optimize backend service performance. • Apply Go concurrency patterns using goroutines, channels, and context management. 2. Cloud-Native Development & Deployment • Build and containerize Go applications using Docker. • Deploy and manage services in Kubernetes-based cloud environments. • Work with AWS services, including EKS/ECS, Lambda, API Gateway, S3, CloudWatch, IAM, and Secrets Manager. • Ensure application scalability, reliability, security, and availability. 3. CI/CD & Infrastructure Automation • Build and enhance end-to-end CI/CD pipelines. • Automate build, code-quality checks, testing, security scanning, artifact management, deployment, verification, and rollback processes. • Implement Infrastructure as Code (IaC) for repeatable and automated cloud provisioning. • Work with GitHub Actions, GitLab CI, or equivalent CI/CD tools. 4. Testing & Quality Engineering • Contribute to application development, testing, and test automation based on product-team requirements. • Ensure application reliability through automated testing and code-quality checks. • Support continuous improvement of development and deployment processes. • Leverage AI agents to accelerate development and testing activities. 5. Monitoring & Observability • Implement production-grade logging, metrics, distributed tracing, dashboards, and alerting. • Monitor application health, service performance, and system availability. • Identify performance bottlenecks and implement optimization measures. 6. Production Support & Troubleshooting • Troubleshoot complex production issues and perform Root Cause Analysis (RCA). • Implement permanent corrective and preventive measures. • Participate in production support, incident management, and defect resolution. • Perform performance tuning and continuous service improvement activities. 7. Collaboration & Delivery • Collaborate with Product Teams, DevOps/SRE Engineers, QA Engineers, and business stakeholders. • Participate throughout the complete software development lifecycle. • Contribute to technical discussions, solution design, development standards, and engineering best practices. Required Qualifications • 5+ years of overall software engineering experience. • 2+ years of hands-on Go/Golang development experience. • Strong backend development and microservices architecture experience. • Experience developing REST and/or gRPC APIs. • Hands-on experience with AWS cloud services. • Experience with Docker and Kubernetes. • Knowledge of CI/CD automation and Infrastructure as Code. • Experience with production monitoring, observability, and troubleshooting. • Strong analytical, problem-solving, and communication skills. Preferred Qualifications • Experience in the auto insurance domain. • Knowledge of auto policy administration systems. • Experience building enterprise-grade backend services. • Experience with distributed systems and high-volume transaction processing. • Experience using AI agents for software development and testing.
