Full Stack Engineer - Kubernetes

Sharing Vision Indonesia Central Jakarta, Jakarta опубликовано 27 октября 2026

Tanggung Jawab Pekerjaan • Mengembangkan dan memelihara aplikasi dari sisi Frontend dan Backend. • Membangun dan mengintegrasikan API serta memastikan aplikasi berjalan sesuai kebutuhan. • Melakukan containerization aplikasi menggunakan Docker. • Melakukan deployment dan pengelolaan aplikasi pada lingkungan Kubernetes. • Melakukan troubleshooting terhadap kendala aplikasi, container, dan deployment. • Berkolaborasi dengan tim Developer, DevOps, dan tim terkait untuk memastikan proses deployment berjalan dengan baik. • Menerapkan praktik pengembangan aplikasi yang baik, termasuk version control dan CI/CD. Kualifikasi • Memiliki pengalaman sebagai Full Stack Engineer atau Software Engineer. • Memahami pengembangan aplikasi Frontend dan Backend. • Memiliki pengalaman menggunakan Docker dan memahami konsep containerization. • Memahami konsep Kubernetes, seperti Pod, Deployment, Service, ConfigMap, Secret, dan Ingress. • Memahami REST API, database, dan integrasi antarsistem. • Memahami Git dan proses CI/CD. • Memiliki kemampuan analisis dan troubleshooting yang baik. • Bersedia bekerja secara WFO di area Sudirman, Jakarta. • Mampu bekerja secara mandiri maupun berkolaborasi dalam tim. Teknologi yang Diharapkan • Frontend: React.js, Next.js, atau teknologi sejenis. • Backend: Node.js, Golang, atau teknologi sejenis. • Containerization: Docker. • Orchestration: Kubernetes. • CI/CD & Version Control: Jenkins atau GitHub Actions, Git. • Database & API: SQL, REST API.
