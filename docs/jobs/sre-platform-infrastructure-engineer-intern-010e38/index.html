About the Role: We are looking for a motivated and curious Site Reliability Engineering (SRE) / Platform Infrastructure Engineer Intern to join our team. This is a hands-on opportunity to learn how modern, large-scale systems are built, deployed, and maintained in a fast-paced environment. As a Site Reliability Engineering (SRE) / Platform Infrastructure Engineer Intern at Sezzle, you will work closely with experienced engineers to support infrastructure, improve reliability, and contribute to automation and tooling efforts. This role is ideal for someone eager to learn, experiment, and grow in cloud infrastructure and distributed systems. What You'll Do: • Assist in building, maintaining, and improving infrastructure systems using Kubernetes and AWS. • Monitor system performance, and help troubleshoot production and staging issues. • Contribute to improving observability by working with tools like Prometheus, Grafana, or similar. • Help automate repetitive tasks and improve developer workflows using scripts or tools. • Participate in on-call shadowing and incident reviews to learn how reliability is managed in production systems. • Work with engineers to identify bottlenecks and improve system performance and scalability. • Contribute to documentation and help maintain operational runbooks. • Explore and experiment with AI and automation tools to improve engineering productivity. What We Look For: • Currently pursuing or recently completed a degree in Computer Science, Engineering, or a related technical field. • Basic understanding of cloud platforms (AWS preferred), Linux systems, and networking concepts. • Familiarity with at least one programming language (Golang, Python, or similar). • Understanding of basic database concepts (MySQL, PostgreSQL) is a plus. • Exposure to containers (Docker) and/or Kubernetes is a plus. • Interest in distributed systems, reliability, and infrastructure engineering. • Strong problem-solving skills and willingness to learn. • Good communication skills and ability to work in a team environment. • Demonstrated experience working with Claude or equivalent large language model tools is required; candidates must be comfortable leveraging AI to enhance productivity, research, and communication. Preferred Knowledge and Skills: • Familiarity with version control systems like Git. • Basic understanding of CI/CD concepts. • Exposure to monitoring and logging tools. • Interest in automation and developer tooling, including AI-assisted development tools. About You: • You are curious and eager to learn new technologies and systems. • You take initiative and are excited to solve problems, even if you don’t have all the answers yet. • You are detail-oriented and care about building reliable systems. • You collaborate well with others and are open to feedback. • You are adaptable and comfortable working in a fast-paced environment. Sezzle’s Technology Stack: • Languages: Golang, Typescript, Python • Frontend: Typescript - React and React Native • Backend: Golang • Database: MySQL, Postgres, Elasticsearch • DevOps & Cloud: AWS, Kubernetes • Version Control: Git • CI/CD: Gitlab • Testing: Developer and AI-driven, focus on automated end-to-end, integration, and unit tests • Open Source: Sezzle is focused on using open source, and we build what we can before buying!
