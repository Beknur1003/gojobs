SENIOR DEVOPS ENGINEER

jobs.atos.net опубликовано 10 октября 2026

Senior
KubernetesDockerTerraformPrometheusGrafanaLinuxCI/CDPython
We are looking for a DevOps Engineer to support the development, automation, deployment, and operation of cloud-native applications. The successful candidate will work closely with software engineers, platform teams, and architects to build reliable CI/CD pipelines, manage Kubernetes-based environments, and implement GitOps-driven deployment practices. The role combines infrastructure automation, platform operations, and software engineering practices to ensure secure, scalable, and highly available services. Key Responsibilities CI/CD & Automation • Design, implement, and maintain CI/CD pipelines for application delivery. • Automate build, test, deployment, and release processes. • Improve software delivery efficiency through Infrastructure as Code and automation. • Support developers in integrating applications into the deployment pipeline. Kubernetes & Container Platform • Deploy, operate, and troubleshoot containerized workloads on Kubernetes. • Manage application lifecycle, scaling, upgrades, and fault recovery. • Optimize cluster performance, reliability, and resource utilization. • Collaborate with platform teams on Kubernetes best practices and standards. Docker & Containerization • Build and maintain Docker images. • Support container security, image lifecycle management, and vulnerability remediation. • Standardize container deployment patterns across environments. GitOps & Flux • Implement and maintain GitOps deployment processes using Flux. • Manage environment configurations and application releases through Git repositories. • Ensure consistency between source control and runtime environments. • Support automated rollbacks and deployment validation. Development & Scripting • Develop automation scripts and operational tooling using Python. • Contribute to small platform components and operational utilities using Golang. • Automate repetitive operational tasks and reporting processes. Operations & Reliability • Monitor platform health and application deployments. • Troubleshoot infrastructure, deployment, and runtime issues. • Support incident resolution and root cause analysis. • Contribute to service reliability, resilience, and operational excellence. Collaboration • Work closely with developers, architects, and operations teams. • Participate in Agile ceremonies and technical planning sessions. • Promote DevOps culture and continuous improvement practices. • Document solutions, procedures, and operational standards. Required Skills Must Have • Strong hands-on experience with Kubernetes • Strong experience with Docker • Experience designing and maintaining CI/CD pipelines • Practical knowledge of GitOps principles • Experience with Flux • Good Linux administration and troubleshooting skills • Scripting experience with Python • Understanding of networking, application deployment, and container security • Experience working in Agile/DevOps environments Nice to Have • Basic development skills in Golang • Experience with Helm • Experience with GitLab CI/CD, Jenkins, or similar tools • Knowledge of monitoring and observability solutions (Prometheus, Grafana, Dynatrace) • Experience with Terraform or other Infrastructure as Code solutions • Telecom industry experience
