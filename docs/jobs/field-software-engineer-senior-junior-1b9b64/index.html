Autonomous Control System(ACS)은 이러한 로봇들을 통합적으로 제어하는 핵심 플랫폼입니다. 본 포지션은 ACS가 각 고객사의 환경에 맞게 실제로 동작하도록 만드는 역할입니다. Field Integration Engineer는 고객사의 상위 시스템을 분석하고, ACS와 고객사 시스템을 잇는 Middleware를 설계·개발하며, 실제 운영까지 책임지는 핵심 역할을 수행합니다. 단순한 현장 엔지니어가 아닌, 코드를 작성하고 integration 로직을 설계하며 end-to-end로 시스템을 완성하는 역할입니다. 또한 현장에서 얻은 인사이트를 본사 엔지니어링 팀에 전달하여 제품 개선에도 기여하게 됩니다. 👉 본 포지션은 글로벌 협업 및 고객 대응이 포함되며, 영어로 기본적인 업무 커뮤니케이션이 가능한 분을 필요로 합니다.
