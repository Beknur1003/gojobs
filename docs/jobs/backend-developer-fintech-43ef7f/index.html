Backend Developer (FinTech)

Codenix Москва опубликовано 15 октября 2026

PostgreSQLRedisKafkagRPCKubernetesDockerAWSGCPPythonFinTech
У нас в codenix есть международный финтех проект, под который мы постепенно расширяем команду. Настала очередь backend разработчика. Уровень от Middle до Senior. С нас: сложные задачи, чувство первопроходца, кофе и ламповая атмосфера в команде. Что будем делать: • Развивать платформу обработки больших данных • Использовать сложные алгоритмы • Проводить множество интеграций • Строить системы аналитики и торгового контроля • Вместе разбираться в сложных вещах, исследовать и находить решения • Работать с кучей всего интересного, от анализа данных до децентрализованных технологий Требуемые навыки Бэкенд, Старший (Senior) · Python · Golang · C# · PostgreSQL · Docker · Kubernetes · Websockets · JavaScript Что в этом поможет: • Python, C# (.Net Core), Go - хорошее знание одного из этих языков и опыт разработки backend’а веб приложений на нем. • Опыт работы с различными СУБД (предпочтителен PostgreSQL, Redis). • Опыт работы с Docker, Docker Compose, Kubernetes. • Опыт работы с gRPC, Protobuf, Websocket. • Опыт разработки асинхронных, многопоточных сервисов. • Опыт работы с брокерами сообщений (Apache Pulsar, Kafka). • Уверенное знание Git, желателен опыт работы с Gitlab. • Будем большим плюсом хорошее знание Javascript (включая ES6). • Будет хорошим плюсом опыт работы с облаками (AWS, GCP). • Грамотность в классических алгоритмах и структурах данных. • Высшее образование по техническому направлению. В каких условиях: • Полностью белая заработная плата без конвертов, по результатам собеседования • Приятный офис на Даниловской мануфактуре (м. Тульская) • Согласуем удобный график начала и конца рабочего дня • Глубокое погружение в финансовые технологии • Постоянная прокачка скиллов • Забота о членах команды
