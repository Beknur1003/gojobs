Solvd Inc. is a rapidly growing AI-native consulting and technology services firm delivering enterprise transformation across cloud, data, software engineering, and artificial intelligence. We work with industry-leading organizations to design, build, and operationalize technology solutions that drive measurable business outcomes. Following the acquisition of Tooploox, a premier AI and product development company, Solvd now offers true end-to-end delivery—from strategic advisory and solution design to custom AI development and enterprise-scale implementation. Our capability centers combine deep technical expertise, proven delivery methodologies, and sector-specific knowledge to address complex business challenges quickly and effectively. We are looking for a Senior Go Developer to design and develop high-performance, secure, and reliable software components for enterprise-scale data collection and processing systems. You'll be building software that runs across Windows and macOS, processes high-frequency events, securely buffers and transmits data, and integrates with cloud-based data platforms — with production-grade engineering practices throughout. What you'll do • Design, develop, and maintain high-performance applications and background services in Go, following clean architecture and production-grade engineering practices. • Build multi-threaded and concurrent processing components using goroutines, channels, synchronization primitives, worker pools, and efficient memory-management techniques. • Develop reliable event collection, processing, batching, compression, serialization, and transmission mechanisms for high-volume telemetry and event data. • Implement robust local persistence and encrypted buffering — supporting offline operation, checkpointing, retry queues, recovery, and protection against data loss. • Develop secure integrations with cloud platforms and data services using REST APIs, HTTPS, SDKs, and other integration mechanisms. • Implement enterprise-grade authentication and security mechanisms, including RSA key-pair authentication, JWT/OAuth, TLS, certificate validation, encryption, and secure credential handling. • Design resilient distributed-client behavior — idempotency, duplicate prevention, exponential-backoff retries, acknowledgement handling, failure recovery, rate limiting, and network resilience. • Develop efficient data-processing capabilities across formats such as JSON, Parquet, and Protocol Buffers. • Optimize applications for CPU, memory, disk I/O, network utilization, startup time, and long-running stability using Go profiling and diagnostic tools. • Develop and support cross-platform software for Windows and macOS, including interaction with OS APIs, system services, file systems, networking, and OS-native security facilities. • Build comprehensive unit, integration, performance, stress, resilience, and security tests. • Implement production-grade logging, metrics, health monitoring, diagnostics, and telemetry — ensuring sensitive information is never exposed through operational logs. • Contribute to application packaging, versioning, configuration management, automated deployment, upgrade, rollback, and enterprise software-distribution strategies. • Provide senior-level technical leadership through architecture discussions, design reviews, code reviews, troubleshooting, and mentoring. Required skills & experience • 7+ years of software development experience with strong hands-on expertise in Golang. • Advanced knowledge of Go concurrency — goroutines, channels, mutexes, contexts, synchronization, and worker-pool patterns. • Strong understanding of data structures, algorithms, memory management, and performance optimization. • Experience building long-running services, agents, system utilities, telemetry applications, or distributed client applications. • Strong experience with REST APIs, HTTPS, TLS, JSON, authentication, and secure API integration. • Experience implementing RSA/public-key cryptography, JWT/OAuth, certificate-based authentication, and secure credential management. • Experience with local persistence, caching, queueing, batching, compression, retry, and failure-recovery patterns. • Knowledge of Parquet or similar columnar/binary data formats and high-volume data-processing patterns. • Strong experience with unit testing, integration testing, mocking, profiling, debugging, and performance testing in Go. • Good understanding of CI/CD, Git, code-quality tooling, dependency management, vulnerability scanning, and secure SDLC practices. Preferred qualifications • Experience with Snowflake or comparable cloud data platforms and cloud SDK integration. • Experience with Windows and/or macOS system programming, enterprise endpoint software, or large-scale telemetry systems. • Familiarity with C/C++ or .NET interoperability, Windows APIs, macOS APIs, or OS-level encryption and key stores. • Experience with MSI/MSIX packaging and enterprise device-management platforms.
