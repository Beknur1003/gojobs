A career in IBM Z is built on long-term client relationships and close collaboration worldwide. You will work with leading companies across industries, helping them shape the core of their enterprise environment and AI journeys. As a Software Developer, you will design, develop, test, and deliver next-generation software offerings for IBM Z clients using leading-edge and proven technologies. You will work in an Agile, collaborative environment to understand stakeholder requirements and contribute to the development of innovative software solutions. In this role within IBM Z and LinuxONE Security and Automation, you will develop and deploy on-premises applications that integrate open software technologies and standards with the IBM Z mainframe, connecting front-end, back-end, and middleware components with z/OS and Linux on s390x systems. You will utilize expertise in modern programming languages like Golang, Python, and Java to deliver efficient, resilient, and secure enterprise solutions. Your primary responsibilities will include: - Design and Develop Applications: Develop and deploy enterprise applications and high-throughput microservices using open languages such as Golang, Python, and Java, integrating front-end, back-end, and middleware components with data persistence in NoSQL or RDBMS databases. - Integrate with Core IBM Z Systems: Build adapters, collectors, and services that interface with native z/OS environments and subsystems, including z/OS UNIX System Services (USS), RACF and SAF security controls, SMF telemetry streams, IBM MQ, and z/OS Connect. - Apply DevOps Methodologies: Utilize modern DevOps tools and automated CI/CD pipelines to ensure efficient development, packaging, testing, and deployment across Linux on s390x, Red Hat OpenShift on IBM Z, and hybrid architectures. - Maintain Secure On-Premises Environments: Collaborate with senior engineers, architects, and system programmers to build, test, and maintain robust on-premises and hybrid mainframe environments, focusing on uptime, identity governance, access control, and network security. - Integrate Multiple Technologies: Connect diverse technologies including REST and gRPC services, OpenTelemetry, Vault on Z, messaging queues, and enterprise security frameworks to deliver comprehensive mainframe security and observability solutions. '- Modern Programming Proficiency: Strong hands-on development experience in one or more core languages, including Golang, Python, or Java. - Application and Microservices Development: Experience working with multi-tier software architectures, microservices design patterns, and building RESTful or gRPC APIs. - Data Persistence: Experience working with relational databases (RDBMS) or NoSQL databases, including data modeling and query optimization. - DevOps and Automation: Experience using modern Git workflows, CI/CD automated build pipelines, and automated testing tools. - Linux and Systems Foundations: Practical experience working in Linux operating system environments, shell scripting, and network communication standards. - Aptitude for IBM Z Systems: Demonstrated interest and willingness to learn IBM Z architecture, mainframe operating principles, and mission-critical enterprise systems. '- IBM Z and s390x Exposure: Familiarity with or prior exposure to Linux on s390x, LinuxONE, z/OS, or z/OS UNIX System Services (USS). - Security and Identity Controls: Exposure to enterprise security concepts such as authentication, authorization, access control, PKI, or secret management (e.g., Vault). - Mainframe Security and Telemetry: Familiarity with RACF, SAF, zSecure, or working with SMF audit and event records. - Observability and Event Streaming: Experience with OpenTelemetry, Kafka, Prometheus, or distributed tracing tools. - Container Orchestration: Experience deploying and managing containerized applications on Red Hat OpenShift or Kubernetes.
