Golang Network Engineer

NS Global Corporation Dubai опубликовано 4 июля 2026

Job Description : We are looking for an experienced Golang Network Engineer with strong expertise in backend development and networking technologies. The ideal candidate should have hands-on experience in building scalable applications and working with modern networking and containerization technologies. Key Responsibilities : - Architect and develop high-performance network applications using Golang to enhance the efficiency and throughput of our core infrastructure. - Design and maintain complex network topologies, ensuring seamless integration between software-defined networking components and physical hardware. - Implement and troubleshoot advanced routing protocols such as OSPF to optimize data traffic paths and minimize latency across the global network. - Configure and manage secure communication channels, including IPsec and VPN tunnels, to protect sensitive data transmission across distributed environments. Required Skills : - Strong proficiency in Golang for backend development. - Deep understanding of networking protocols (OSPF, IPsec, VPNs). - Experience with Kubernetes for containerized application deployment. - Knowledge of secure authentication mechanisms (JWT, OAuth2, mTLS). - Familiarity with SNMP traps for real-time network monitoring. - Experience with Linux kernel networking and system-level networking concepts. Preferred : - Candidates currently based in Dubai. - Candidates willing to relocate to Dubai and join within 30 days.
