About the Team We are building an intelligent enterprise-services platform to power ByteDance's global growth and operations. Guided by an AI-First philosophy, the team delivers AI solutions built on industry best practices. As an intern, you will be embedded in the team's product development cycle, working side-by-side with product, design, and cross-regional engineering teams. As a Project Intern, you will contribute to impactful short-term projects and gain hands-on experience in a fast-paced, professional environment. This internship offers the opportunity to develop practical skills, apply your knowledge to real-world challenges, and explore your career interests. Applications are reviewed on a rolling basis, so we encourage you to apply early. Online Assessment Candidates who pass resume screening will be invited to participate in Our Company's technical online assessment. Responsibilities: • Contribute to backend services and the Agent runtime, focusing on code quality, readability, and maintainability; assist in profiling and tuning for performance and stability. • Help integrate internal enterprise systems into Agents via Tools / MCP / CLI / A2A. • Participate in code reviews, and learn and follow the team's coding standards and architectural conventions. • Write clear, AI-friendly technical documentation and contribute to the team knowledge base. • Explore embedding AI capabilities into backend services, and support AI-driven feature development, evaluation, and validation. Minimum Qualifications: • Currently pursuing a Undergraduate in Computer Science, AI, Information Management or a related technical discipline. • Available to start the internship immediately, ideally within one week. • Solid foundation in data structures, algorithms, and computer systems, with strong coding habits. • Proficiency in one or more of Golang / Java / Python. • Hands-on experience with distributed systems and microservice architecture. • Familiarity with or hands-on experience in AI Agent architectural patterns (reasoning, memory management, multi-Agent collaboration, etc.). • Strong communication and collaboration skills; genuine interest in exploring the Agent engineering ecosystem. Preferred Qualifications: • AI Product Builder: as a core contributor to build an AI product / Agent / application aimed at real-world users — able to articulate the product positioning, technology choices, user scale, and iteration process. • Hands-on experience with mainstream Agent frameworks (e.g., LangChain / LangGraph, Claude Agent SDK, etc.), Prompt Engineering, Harness Engineering, Context Management, and Evaluation.
