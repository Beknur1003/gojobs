Senior Fullstack Engineer - Python and Go

Удалёнка Senior Контракт / B2B

Do naszego zespołu poszukujemy doświadczonego Senior Software Developera ze stackiem technologicznym Python i Go, który wesprze rozwój rozproszonej platformy działającej w obszarze bezpieczeństwa sieci. Będziesz uczestniczyć w projektowaniu i implementacji nowych funkcjonalności, integracji oraz mechanizmów egzekwowania polityk bezpieczeństwa w środowiskach klientów. Szukamy osoby, która lubi rozwiązywać złożone problemy techniczne, bierze odpowiedzialność za dostarczane rozwiązania i dba o wysoką jakość kodu. Szukamy Ciebie, jeśli: • Posiadasz minimum 5 lat doświadczenia w tworzeniu oprogramowania, w tym doświadczenie na poziomie Senior. • Bardzo dobrze znasz Python i/lub Go oraz na co dzień tworzysz kod produkcyjny. • Masz doświadczenie w projektowaniu i rozwijaniu systemów backendowych oraz rozwiązań rozproszonych. • Potrafisz tworzyć wysokiej jakości, skalowalne i łatwe w utrzymaniu rozwiązania. • Posiadasz doświadczenie w integracji systemów oraz projektowaniu i rozwijaniu REST API. • Rozumiesz zagadnienia związane z architekturą mikroserwisową lub systemami rozproszonymi. • Potrafisz analizować problemy występujące w środowiskach produkcyjnych oraz skutecznie je rozwiązywać. • Masz doświadczenie w pracy z Git'em, w tym branchami, pull requestami oraz code review. • Znasz praktyki związane z testowaniem oprogramowania, automatyzacją testów oraz zapewnianiem jakości kodu. • Rozumiesz znaczenie monitoringu, logowania i telemetryki w systemach produkcyjnych. • Posiadasz doświadczenie w pracy z procesami CI/CD. • Potrafisz współpracować z zespołami produktowymi, backendowymi oraz infrastrukturalnymi. • Mile widziane jest doświadczenie w obszarze networkingu, bezpieczeństwa sieci, systemów infrastrukturalnych lub appliance'ów on-premise. • Komunikujesz się w języku angielskim na poziomie minimum B2. Praca na tym stanowisku w naszej firmie oznacza: • projektowanie i rozwijanie nowych funkcjonalności w środowisku opartym o technologie Python i Go, • współtworzenie rozwiązań działających w architekturze rozproszonej, • implementację integracji z systemami zewnętrznymi oraz komponentami infrastrukturalnymi, • współpracę przy definiowaniu i rozwijaniu kontraktów API pomiędzy systemami, • udział w analizie wymagań biznesowych i technicznych, • dbanie o jakość dostarczanego oprogramowania poprzez testowanie, code review oraz stosowanie dobrych praktyk inżynierskich, • analizowanie i rozwiązywanie problemów pojawiających się w środowiskach produkcyjnych, • rozwijanie mechanizmów zwiększających stabilność, bezpieczeństwo i niezawodność systemu, • współpracę z zespołami odpowiedzialnymi za platformę, backend oraz infrastrukturę, • udział w dostarczaniu funkcjonalności od etapu projektowania aż po wdrożenie produkcyjne, • optymalizację istniejących rozwiązań pod kątem wydajności, skalowalności oraz utrzymania.
