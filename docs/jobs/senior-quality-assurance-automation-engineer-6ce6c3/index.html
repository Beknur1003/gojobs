Senior Quality Assurance Automation Engineer

LTM is a global technology consulting and digital solutions company that helps organizations accelerate digital transformation through cloud, data, AI, enterprise applications, and modern engineering solutions. Location- Mexico (Remote) Role Details: We are seeking a Senior QA Automation Engineer to help us raise the quality bar of our video delivery, content metadata and rights platforms. You will be an integral part of the Video Streaming and Engineering team, working side by side with software engineers to design, build and maintain the automated API and UI test suites that gate every release of our internal platforms (such as Harvester and Titan). You will own test strategy for your areas, drive quality earlier into the development lifecycle, and keep test results traceable and visible through CI/CD and our test management tooling. This role will also be leading projects and sharing knowledge and has greater autonomy when deciding what approach to take in solving the problems to which they are assigned. Your Day-to-Day: • Design, build and maintain API test automation frameworks in Java (REST Assured, TestNG) for microservices that power video ingestion, delivery, metadata and rights workflows. • Develop and maintain end-to-end UI automation for internal web applications using Selenium WebDriver with Cucumber/Gherkin (BDD) and Playwright with TypeScript. • Validate API contracts and payloads using JSON schema validation, and verify authentication flows (API keys, bearer tokens, SSO) and event streams such as Server-Sent Events (SSE). • Organize regression, smoke and batch suites (TestNG suite XML, Cucumber tags) and run them in parallel in CI with GitHub Actions on every pull request, deployment and on a schedule. • Publish clear, actionable test reports with Allure and Extent Reports, and triage, root-cause and report failures and flaky tests. • Create and maintain test cases, suites and runs in TestRail, link automated tests to their TestRail cases and keep requirement-to-test traceability up to date. • Partner with Golang engineers on testability, test data, environments and shift-left practices such as contract tests, unit-test coverage and test-driven development. • Perform exploratory and manual testing where automation is not yet practical, and file well-documented defects. • Mentor other QA engineers and promote a culture of quality across the team. • Additional duties and responsibilities, as assigned. Key Projects: • Expand and harden API regression coverage for Harvester (video asset ingestion and metadata workflows) and Titan (titles, rights, schedules and licensing). • Grow UI automation coverage for Harvester (media ingest, categories, validation rules, dashboards, caption conversion) and the Titan UI. • Reduce flakiness and execution time of existing suites through parallelization, batching and better test data management. • Standardize frameworks, reporting and TestRail traceability across Video Engineering QA repositories. • Integrate quality gates into CI/CD pipelines and extend automation to new microservices as they are built. • Enhance internal QA documentation, runbooks and onboarding guides. Qualifications: What you bring to the team: You have • 5+ years of experience in software quality assurance, with a strong focus on test automation. • Strong programming skills in Java, including Maven for builds and dependency management. • Hands-on experience building API automation with REST Assured and TestNG (suites, data providers, parallel execution), plus JUnit, Hamcrest and Mockito. • Experience validating REST APIs and JSON payloads using Jackson, JsonPath and JSON schema validation, and describing/consuming APIs with OpenAPI / Swagger. • Experience with UI automation using Selenium WebDriver and BDD with Cucumber / Gherkin. • Experience with Playwright and TypeScript / Node.js for modern web UI test automation. • Experience producing test reports with Allure and Extent Reports. • Experience managing test cases, runs, results and traceability in TestRail (or a comparable test management tool). • Experience running automated suites in CI/CD systems such as GitHub Actions, including scheduled and parameterized regression runs. • Experience with Git/GitHub workflows, shell scripting, and handling authentication (API keys, Okta/bearer tokens, SSO) in automated tests. • Experience using logs, monitoring or APM tools (e.g., New Relic/Datadog) to investigate issues and perform root-cause analysis. • Solid understanding of test design, regression/smoke strategy, defect management and Agile development practices. • Experience with database technologies like MySQL / Postgres for test data setup and validation. • Experience using Jira/Confluence and API exploration tools (e.g., Postman, cURL). • Experience designing and evolving test automation frameworks and architecture, not just writing tests. • Strong written, verbal and interpersonal communication skills. You might also have • Experience testing microservices. • Experience with Cloud/SaaS services such as Amazon AWS / Google Cloud, and container technology such as Docker / Kubernetes. • Knowledge of HLS/DASH streaming media standards. • Experience with performance and load testing tools, and with AI-assisted test development workflows. • BS degree in Computer Science, similar technical field of study or equivalent practical experience Benefits: • Law benefits and permanent contract • Higher medical expenses and life insurance • Food vouchers • Work-from-home allowance • Equipment provided by the company
