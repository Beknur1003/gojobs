[Job Description] We are seeking a talented and motivated AI-Assisted Backend Engineer to join our startup team. The ideal candidate has solid backend development experience and is willing to work primarily with Go/Golang. You will be responsible for designing, developing, and maintaining reliable backend services and tools. You will work closely with frontend, SRE, and security teams to deliver high-quality, scalable, and secure software products. [Responsibilities] 1. Leverage AI coding agents such as Codex, Claude Code, or Cursor for implementation, testing, debugging, and refactoring. 2. Apply agentic development workflows and validate AI-generated code through testing, code review, and engineering best practices. 3. Design, develop, and maintain backend services and tools, primarily using Go/Golang. 4. Design and implement RESTful APIs and integrate backend services with frontend and external systems. 5. Design and optimize SQL queries and work with relational databases such as MySQL and PostgreSQL. 6. Develop and maintain containerized applications using Docker. 7. Ensure backend services meet requirements for reliability, performance, scalability, and security. 8. Collaborate with frontend developers, SRE, and security engineers. 9. Participate in code reviews, technical discussions, testing, and debugging. [Qualifications] • 3+ years of experience in backend software development; 5+ years preferred. • Professional experience with Go/Golang, or strong backend development experience with Rust, Java, C#, or similar languages and willingness to transition to Go. • Solid understanding of backend software development, API design, and software architecture. • Experience designing and implementing RESTful APIs. • Solid experience with SQL and relational databases, especially MySQL and PostgreSQL. • Experience with Docker and containerized applications. • Familiarity with Linux operating systems and basic networking concepts. • Solid understanding of software development best practices, including Git, testing, and code reviews. • Strong problem-solving skills and attention to detail. • Good communication and collaboration skills. • Experience with AI-assisted software development using tools such as Codex, Claude Code, or Cursor, with the ability to validate and review AI-generated code.
