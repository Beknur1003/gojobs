Role Overview : We are seeking an experienced and self-driven Software Development Engineer II (Full-Stack) to build and own end-to-end features for our platform. In this high-ownership role, you will work within a cross-functional squad alongside product, design, and fellow engineers to take features from technical design through deployment and monitoring. You will write clean, production-ready code across the stack - primarily utilizing Go on the backend and Angular on the frontend - in an environment that values engineering craft, reliable delivery, and continuous improvement. Key Responsibilities : - End-to-End Feature Delivery : Write backend services in Go and frontend interfaces in Angular, owning features from initial technical design all the way through production deployment and monitoring. - High-Quality Code & Standards : Write clean, testable, well-documented code that powers critical workflows, maintaining high technical standards. - System Design & Architecture : Participate in designing APIs, data models, and service architectures for new features and platform capabilities. - Code Reviews & Mentorship : Conduct thoughtful code reviews to catch bugs, share knowledge, and mentor junior engineers through pairing sessions and design discussions. - Cross-Functional Collaboration : Partner closely with product and design teams to translate business requirements into efficient technical solutions, actively proposing alternatives when necessary. - Production Reliability & Support : Debug and resolve production issues quickly, identifying root causes to maintain system uptime and stability. - Engineering Practices : Contribute to testing, CI/CD pipelines, observability, and internal tooling to enhance developer velocity across the squad. Tech Stack & Qualifications : - Education : B.Tech / B.E. in Computer Science or equivalent. - Core Backend : Strong proficiency in strictly typed languages with Go (Golang) as the primary preference (experience with Java is also valued). - Core Frontend : Solid experience building user interfaces with Angular (or comparable modern frameworks like React/Vue). - Databases : Strong foundation in relational databases (MySQL) - including schema design, query optimization, and indexing strategies. - System Design & APIs : Strong system design fundamentals across API design, data modeling, and service architecture. - Cloud & DevOps : Hands-on experience with cloud infrastructure (AWS preferred) and familiarity with git, CI/CD, and modern deployment workflows. - Testing & Quality : Strong testing discipline with unit and integration testing built directly into your workflow. Interview Process & Benefits : - Round 1 : Practical Engineering Assignment - Round 2 : Technical Deep-Dive Discussion - Health Insurance coverage provided - Mandatory Provident Fund (PF) benefits included - Notice Period buyout available (evaluated on a case-by-case basis)
