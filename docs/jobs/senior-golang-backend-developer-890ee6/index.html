Senior Golang Backend Developer Location: Remote Workload: Full-time Project: Long-term About the role We’re looking for a Senior Golang Backend Developer to build and scale microservices-based systems and help the engineering team migrate existing backend services from Node.js/NestJS to Go. The role involves designing high-load services, working with distributed systems, improving backend architecture, and implementing modern patterns for asynchronous processing and real-time communication. You’ll work with an existing production codebase, contribute to the migration strategy, and help the team gradually transition services from Node.js to a scalable Go-based architecture. Requirements • 4+ years of backend development experience • 3+ years of hands-on experience with Go / Golang • Strong understanding of Go fundamentals, concurrency, goroutines, channels, interfaces, contexts, and error handling • Strong experience with PostgreSQL, MongoDB, and Redis • Solid understanding of microservices architecture • Experience building high-load and distributed systems • Experience with asynchronous processing, queues, and event-driven architectures • Experience building REST APIs, WebSockets (WS/WSS), and RPC/gRPC services • Ability to design scalable, maintainable, and reliable backend services • Ability to read, understand, refactor, and migrate existing codebases • Strong understanding of performance optimization and observability • High attention to detail Nice to have • Experience with Node.js / NestJS, especially in projects migrating from Node.js to Go • Previous experience migrating production services between technology stacks • Deep knowledge of Go concurrency patterns and performance optimization • Experience with gRPC / Protocol Buffers • Deep knowledge of Redis, including MULTI/EXEC, data structures, Lua scripts, and Pub/Sub • Experience with message brokers and event-driven systems • Experience with Docker, Kubernetes, and cloud environments • Basic understanding of prompt engineering, AI agents, and AI skills Responsibilities • Develop and maintain backend services using Golang • Design and implement high-load, scalable microservices • Help the engineering team migrate existing Node.js/NestJS services to Go • Analyze the existing Node.js architecture and define appropriate Go implementations • Refactor and gradually replace existing Node.js services while maintaining system stability • Design APIs and service-to-service communication using REST, WebSockets, RPC/gRPC, and event-driven patterns • Work with asynchronous architectures, queues, and distributed systems • Optimize backend performance, reliability, and scalability • Improve architecture and engineering practices during the migration • Review code and contribute to technical decisions • Collaborate with developers and other cross-functional team members
