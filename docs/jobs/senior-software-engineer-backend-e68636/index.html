Get to Know the Team The Lending team builds secure and versatile loan products for diverse user segments, owning critical platform components such as Credit Risk, User Profiles, Credit Limits and Offers, Lender Journeys, the Pricing Engine etc. We design and operate large-scale distributed systems that impact millions of users, with a strong focus on financial inclusion and underserved communities. Get to Know the Role As a Senior Backend Developer, you will develop scalable software applications using GoLang. You will be at the forefront of our development efforts, leading architectural plans and coaching junior engineers. You will report to the Engineering Manager, Backend. You will work onsite in our Jakarta Office. The Critical Tasks You Will Perform • Design and construct software applications using GoLang. • Identify main tasks, prioritize them, and deliver them throughout the software development life cycle. • Automate tasks using appropriate tools and scripting. • Collaborate with multiple teams to define needs, design new features and deliver them. • Lead the architecture and coding standards efforts, ensuring clean and efficient code. • Conduct code reviews to ensure adherence to coding standards, best practices, and security guidelines. • Troubleshoot, debug, and upgrade existing software. • Stay up-to-date with latest trends and technologies to improve our products and processes. • Mentor junior software engineers, and guide their development. What Essential Skills You Will Need • 5+ years of related work experience in a similar capacity • Proficiency in GoLang for developing and enhancing software applications. • Architecture mindset: Experience designing scalable and maintainable architectures. • Software Development Life Cycle (SDLC): Experience with SDLC and Agile methodologies to manage tasks. • Automation: Proficiency in using tools and scripting to automate repetitive tasks. • Code Reviews: Experience conducting code reviews to maintain high-quality coding standards. • Experience in Security Practices understanding best practices for coding and security guidelines.
