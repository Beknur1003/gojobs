Role Overview The Senior Software Engineer is a hands-on fullstack engineer responsible for designing, building, and maintaining production applications. Reporting to the Applications Lead, this role delivers secure, well-tested software, contributes to engineering standards, and supports the organisation's ISO27001:2022 compliance programme. Key Responsibilities Fullstack Development • Design and build backend services and frontend components for enterprise production systems; write clean, tested, well-documented code. • Develop RESTful APIs with proper versioning and documentation; integrate message queuing solutions to support event-driven data flows. • Design database schemas and optimise queries; build containerised, cloud-native applications. • Use AI coding tools to accelerate delivery in line with team guardrails, ensuring outputs meet code quality, security, and architectural standards. Engineering Quality and Security • Apply secure SDLC practices including SAST/SCA remediation, dependency hygiene, and secret scanning within CI/CD pipelines. • Participate in code reviews and uphold code review, testing, and documentation standards. • Implement functional and non-functional test coverage (unit, integration, performance). Delivery and Support • Deliver committed sprint work, contribute to backlog refinement and estimation, and mentor junior engineers. • Troubleshoot and resolve production issues; participate in incident response and post-mortems. • On-call availability is required to support 24x7 incident response coverage. Requirements Experience • 8+ years of progressive fullstack software engineering experience building enterprise production systems. • Experience with microservices, event-driven architectures, and secure SDLC practices (SAST,SCA). • Background in regulated industries (financial services or fintech preferred); ISO 27001:2022 exposure advantageous. • Familiarity with MAS Technology Risk Management (TRM) Guidelines is a bonus. • Familiarity with mobile application development (iOS or Android) is advantageous. Technical Skills • Backend: Golang, Java, Spring Boot, Python or equivalent • Frontend: React, TypeScript or equivalent • API design: RESTful design, versioning, and documentation • Messaging and event streaming: Kafka, MQ or equivalent • Database: Schema design and query optimisation (e.g. CockroachDB, MySQL, PostgreSQL, or equivalent) • Containerisation: Docker • CI/CD: Pipeline usage with SAST/SCA gates and secret scanning • Cloud: Cloud-native development (AWS, Azure, or GCP) • Testing: Functional and non-functional testing (e.g. Selenium, SonarQube, Gatling, JUnit, Jest, or equivalent) • AI-assisted development tools (e.g. Claude, GitHub Copilot, or equivalent) Qualifications • Bachelor's degree or higher in Computer Science, Software Engineering, or a related discipline. • Relevant certifications (e.g. AWS Developer/Solutions Architect) are advantageous.
