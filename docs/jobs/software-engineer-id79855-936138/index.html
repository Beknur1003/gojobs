We are looking for a Software Engineer for a 6-month engagement to own infrastructure-as-code and deployment pipelines while building backend services for a large-scale identity and entitlement platform. The mandatory requirements are 6+ years of DevOps experience, hands-on Golang development, Terraform, and upper-intermediate English. RECRUITMENT PROCESS 1. Application — Share a few details about your experience and background. 2. Coding Challenge — If applicable, complete it in the coding language you are most comfortable with. 3. Video Interview — Record a short video introduction in English. 4. Technical Interview or Hiring Manager Interview — Discuss your experience and fit for the role. 5. Offer — If it’s a match, you’ll receive an offer. WHAT YOU’LL GAIN • Remote work — Work from where you feel most productive. • Local presence in India — Work in a structured and compliant environment aligned with Indian regulations. • Competitive compensation in INR — Receive compensation in INR, plus support for learning, education, and wellness. • Exciting projects — Work with modern technologies for global clients and fast-growing companies. MUST HAVES • 6+ years' experience with DevOps tooling and CI/CD pipelines. • Strong hands-on development in Golang and Node.js. • Proven experience with Terraform / infrastructure-as-code. • Solid understanding of microservices architecture. • Demonstrated experience integrating complex, interdependent applications across multiple systems. • Upper-intermediate English level. NICE TO HAVES • API integration experience — REST and an enterprise integration/iPaaS layer (e.g. MuleSoft). • Working knowledge of Azure (AKS, API Management, Key Vault). • Exposure to identity/entitlement or authentication systems. WHAT YOU WILL DO • Repoint existing systems from direct CRM account/contact dependencies onto a new backward-compatible API integration layer. • Design and build integration components connecting entitlement systems to the shielding layer, preserving backward compatibility for downstream consumers. • Execute and support two cutovers per system, including rollback readiness. • Validate entitlement and permission integrity end-to-end across entitlement systems to prevent client over/under-permissioning. • Contribute to program end-to-end QA and support the compressed UAT window for permissioning flows. • Support the entitlements data migration aligned to approximately 8,800 new Segment Accounts. • Manage IaC and deployment pipelines for the entitlement services touched by the migration.
