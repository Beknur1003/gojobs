Release Software Engineer Location: Hyderabad Experience: 6+ Years Job Summary: We are looking for an experienced Release Software Engineer with 6+ years of expertise in release engineering, DevOps, and software deployment automation. The ideal candidate will have strong hands-on experience in managing end-to-end software release cycles, building CI/CD pipelines, and automating deployment processes using Kubernetes, Docker, Jenkins, GoLang, and Python. This role requires close collaboration with development, QA, and operations teams to deliver secure, reliable, and high-quality software releases across multiple environments. Key Responsibilities: - Own and manage the complete software release lifecycle, from planning and build creation to deployment and post-release validation. - Design, implement, and maintain robust CI/CD pipelines to automate application build, testing, packaging, and deployment. - Collaborate with development and DevOps teams to deploy containerized applications using Docker and Kubernetes. - Develop automation tools and scripts using GoLang and Python to improve release efficiency and reduce manual effort. - Manage release planning, version control, branching strategies, and deployment schedules. - Implement deployment strategies that support high availability, zero-downtime releases, and quick rollback capabilities. - Monitor release activities, troubleshoot deployment issues, and resolve build or infrastructure-related problems. - Maintain release documentation, deployment procedures, release notes, and change management records. - Partner with QA, Engineering, Infrastructure, and Operations teams to ensure successful, stable, and timely software releases. - Continuously improve release management processes by adopting DevOps best practices and automation initiatives. Required Skills & Experience: - 6+ years of experience in Release Engineering, DevOps, Build Engineering, or Software Deployment. - Strong hands-on experience in Release Management and software deployment lifecycle. - Expertise in designing and managing CI/CD pipelines using tools such as: 1. Jenkins 2. GitHub Actions 3. GitLab CI 4. Azure DevOps or equivalent CI/CD platforms - Strong experience with Kubernetes for container orchestration and application deployment. - Hands-on experience with Docker containerization technologies. - Proficiency in GoLang and/or Python for automation, scripting, and tooling development. - Experience managing automated deployments across development, testing, staging, and production environments. - Strong understanding of Git, version control systems, and branching strategies (GitFlow, Trunk-Based Development, etc.). - Experience implementing deployment automation, release orchestration, and environment management. - Strong troubleshooting and debugging skills related to application deployments, build failures, and infrastructure issues. Preferred Skills: - Experience with Infrastructure as Code (IaC) tools such as Terraform or Ansible. - Familiarity with cloud platforms such as AWS, Azure, or Google Cloud Platform (GCP). - Experience with monitoring and observability tools such as Prometheus, Grafana, ELK, or Splunk. - Knowledge of Agile, Scrum, and DevOps methodologies. - Experience working in enterprise-scale, highly available production environments. Preferred Qualifications: - Bachelor's degree in Computer Science, Information Technology, Engineering, or a related discipline (or equivalent professional experience). - DevOps, Kubernetes, Docker, or Cloud certifications are an added advantage.
