#job #vacancy Должность: Tech Lead Компания: MDiet mdiet.org/ Город: Астана Занятость: оффлайн Оплата: $3000-$4000 MDiet — healthtech-стартап для рынка США. Наша AI-платформа помогает снижать повторную госпитализацию пациентов. Описание вакансии Языки и фреймворки: Go (основной бэкенд), Python / FastAPI (AI/ML-сервисы) Архитектура: модульный монолит / микросервисы, event-driven (Kafka / RabbitMQ), оркестрация бизнес-процессов и workflow через Temporal AI/ML: LLM, ИИ-агенты, RAG, self-hosted inference (vLLM) Данные: PostgreSQL, pgvector (векторный поиск для RAG), Redis (кэш / очереди), графовая БД (Neo4j / Amazon Neptune) — для графа взаимодействий API и интеграции: REST, API Gateway, FHIR / HL7, gRPC Инфраструктура / DevOps: AWS, Docker, Kubernetes, GitLab (репозитории + CI/CD), Terraform (IaC) Наблюдаемость: Prometheus / Grafana, CloudWatch, OpenTelemetry Безопасность / авторизация: OAuth2 / OIDC, управление секретами, шифрование данных (HIPAA / SOC 2) Кого мы ищем: - Сильный системный дизайн: сервисы, API, интеграции, базы данных, распределённые системы и облачная инфраструктура (AWS будет плюсом). - Опыт разработки на Go и готовность быть hands-on на платформенной части (не только проектирование, но и написание кода). - Понимание AI/LLM на архитектурном уровне — как интегрировать ИИ-агентов, RAG и инференс в продуктовую систему (глубокий ML-опыт не требуется). - Опыт проектирования отказоустойчивых и масштабируемых систем, понимание принципов event-driven архитектуры и workflow orchestration. - Самостоятельность, ownership и комфортная работа в условиях неопределённости стартапа. - Английский язык — чтение технической документации и взаимодействие с партнёрами из США. - Высшее образование в области информационных технологий, системного анализа, прикладной математики или инженерии. Будет плюсом: - Архитектурный опыт построения AI/LLM-систем (агенты, RAG, self-hosted inference, vLLM). - Опыт использования Temporal или аналогичных систем оркестрации workflow. - Понимание распределённых систем (масштабирование, согласованность, отказоустойчивость) и опыт работы с графовыми БД. - Опыт работы в стартапах или в роли founding / lead engineer. - Понимание требований безопасности и compliance (HIPAA, SOC 2 или аналогичных стандартов). Условия: Официальное трудоустройство по ТК РК. Работа из офиса в Астане; после 7–8 месяцев возможен гибридный или удалённый формат. Зарплата: $3000–$4000 + опционы / доля в компании (обсуждается).
