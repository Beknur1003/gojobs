Job Summary : As a Golang Developer, you will be responsible for developing robust backend services, designing scalable microservices architectures, and building high-performance APIs. You will collaborate with product managers, architects, DevOps engineers, and frontend developers to deliver reliable and efficient software solutions. The successful candidate should have hands-on experience with cloud platforms, containerized deployments, CI/CD pipelines, and database technologies. A strong understanding of software engineering best practices, system design, and performance optimization is essential. Key Responsibilities : 1. Backend Development : - Design, develop, test, and maintain scalable backend applications using Golang (Go). - Build and enhance RESTful APIs and microservices to support business requirements. - Write clean, maintainable, and well-documented code following coding standards and best practices. - Participate in application architecture discussions and technical design reviews. 2. Microservices & API Development : - Develop and manage distributed systems using microservices architecture. - Design secure, reliable, and high-performing APIs for internal and external integrations. - Implement service-to-service communication, authentication, and authorization mechanisms. - Ensure API reliability, scalability, and maintainability. 3. Database Management : - Design and optimize database schemas and queries. - Work with relational and NoSQL databases including : 1. MySQL 2. PostgreSQL 3. MongoDB - Ensure data integrity, security, and performance across applications. 4. Cloud & DevOps : - Deploy and manage applications on cloud platforms such as : 1. AWS 2. Azure 3. GCP - Utilize containerization technologies including Docker and Kubernetes. - Collaborate with DevOps teams to automate deployments and infrastructure management. - Contribute to CI/CD pipeline implementation and optimization. 5. Performance & Optimization : - Monitor application performance and identify bottlenecks. - Troubleshoot production issues and implement effective solutions. - Optimize system scalability, response times, and resource utilization. - Conduct performance testing and implement best practices for high availability. 6. Collaboration & Best Practices : - Work closely with cross-functional teams to understand requirements and deliver solutions. - Participate in code reviews, sprint planning, and Agile ceremonies. - Mentor junior developers and contribute to knowledge-sharing initiatives. - Stay updated with emerging technologies and industry best practices. Required Skills & Qualifications : 1. Technical Skills : - 4 to 6 years of professional software development experience. - Strong hands-on experience in Golang (Go) development. - Experience designing and developing REST APIs and Microservices. - Proficiency in database technologies such as MySQL, PostgreSQL, and MongoDB. - Hands-on experience with Docker and Kubernetes. - Strong understanding of Git, version control systems, and branching strategies. - Experience working with CI/CD pipelines and deployment automation tools. - Knowledge of cloud platforms such as AWS, Azure, or Google Cloud Platform (GCP). - Experience with application monitoring, logging, and debugging tools. 2. Core Competencies : - Strong analytical and problem-solving skills. - Understanding of software design patterns and system architecture principles. - Ability to work independently and collaboratively in a fast-paced environment. - Excellent communication and stakeholder management skills. - Commitment to delivering high-quality and scalable software solutions. Preferred Qualifications : - Experience with event-driven architectures and message brokers (Kafka, RabbitMQ, etc.). - Knowledge of distributed systems and scalability patterns. - Exposure to Infrastructure as Code (Terraform, CloudFormation, etc.). - Experience working in Agile/Scrum environments. - Familiarity with security best practices and API security standards.
