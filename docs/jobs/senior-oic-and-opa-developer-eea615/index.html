Available Locations • Bengaluru, India About the Role The Senior OIC and OPA Developer is the definitive technical expert responsible for developing, governing, and standardizing all data movement and orchestration involving the Oracle Fusion ERP Cloud environment. This role designs the most complex and critical integration patterns using Oracle Integration Cloud and Oracle Process Automation ensuring technical solutions adhere to Enterprise Architecture and security standards. Responsibilities • Complex Integration Design: Architect and develop the most challenging, cross-functional, and real-time integration patterns for the Oracle Fusion program using Oracle Integration Cloud. • Architecture & Governance: Act as the technical gatekeeper for all Oracle integration and process automation design, ensuring strict adherence to enterprise standards. Define the long-term technical roadmap for the OIC/OPA platform. • Technical Development: Personally drive the design and development of technical solutions (Interfaces, Conversions, Orchestrations and Workflows) within OIC, utilizing REST, SOAP, ERP, FTP, Other Application-specific Standard and Database adapters. Leverage Oracle AI Data (a.k.a Oracle ATP Database) for data staging and integration. Build BIP reports and ATP objects as needed to meet the requirements. • Security & Performance: Define and validate the technical security protocols for all endpoints and interfaces (e.g., OAuth, API Gateway configuration), ensuring data transmission is compliant and performant. • Technical Mentorship: Serve as the top integration expert, providing technical leadership and direction to developers building integrations. Desirable Skills, Knowledge, and Experience • 10+ years of direct experience architecting, designing, and governing enterprise-level integrations for major ERP/SCM/GTM systems. • Expert-level, hands-on knowledge of Oracle Integration Cloud including strong familiarity with its various adapters, mapping, and orchestration capabilities. • Proven experience working directly with a central Enterprise Architecture organization to define and enforce integration standards. • Deep understanding of SOA, microservices, API management, and security protocols. • Experience in an organization transitioning to Oracle Cloud Ecosystem. • Hands-on experience with other integration tools like GoLang, Boomi, etc. • Experience setting up/using CI/CD tools like FlexDeploy • General awareness of built-in adapter based integrations in various 3rd party softwares. • Exposure to the Data Center Infrastructure industry • Relevant professional product/functional certifications (e.g., OIC/OPA, Database) • Working knowledge of AI Agent Studio for Oracle Fusion Cloud Applications.
