Our client is a Federal Government agency seeking experienced Senior DevOps Engineers to lead the design, development, deployment and support of cloud and data infrastructure. These are hands-on technical roles requiring strong AWS and/or Azure capability, DevOps automation, Infrastructure as Code and containerisation experience. • 12 month contract + 12 month extension option • VIC location, hybrid 3 days in office • Australian citizenship mandatory - must be able to obtain NV1 clearance The role Working as part of a full-stack delivery team, you will take a senior role in designing, implementing and supporting scalable cloud infrastructure and DevOps capabilities. You will combine hands-on engineering with technical leadership, working closely with business and technical stakeholders to define requirements, establish priorities and deliver secure and reliable solutions. Key responsibilities • Design, develop, deploy and support cloud and data infrastructure. • Design and manage scalable cloud solutions across AWS and/or Azure. • Build and enhance DevOps practices, tooling and continuous delivery pipelines. • Develop Infrastructure as Code using Terraform to automate infrastructure provisioning and management. • Work with GitLab, Artifactory, Jira and Git-based development workflows. • Deploy and manage containerised environments using Docker and Kubernetes. • Write and maintain code across languages including Python, JavaScript and Golang. • Work closely with business and technical stakeholders to define requirements, priorities and delivery outcomes. • Lead technical delivery within agile project teams and contribute to engineering best practices. • Ensure solutions are well documented and aligned with integration and delivery standards. About you You will be a senior, hands-on DevOps or Cloud Engineer who is comfortable taking ownership of complex technical work while also providing leadership and guidance across project teams. Ideally, you will bring: • Extensive hands-on AWS and/or Azure infrastructure experience. • Strong experience building and implementing DevOps practices and CI/CD pipelines. • Strong Terraform and Infrastructure as Code capability. • Experience with GitLab, Artifactory, Jira and Git-based development. • Strong Docker and Kubernetes experience, including cluster deployment and orchestration. • Coding capability across Python, JavaScript and/or Golang. • Good understanding of agile development and modern software engineering practices. • Experience administering both AWS and Azure environments would be highly regarded. • Exposure to HashiCorp Vault for secrets management would be advantageous. • Exposure to AI-enabled CI/CD automation or AI agents performing controlled automation tasks would also be advantageous. Please note that only candidates with Australian citizenship can be considered for these roles, and successful candidates must be eligible to obtain an NV1 security clearance.
