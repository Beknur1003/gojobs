Job Description Staff Software Engineer Horario de trabajo: 12 a 21 hs (alineado a horario PST) Requisitos técnicos -Sólido conocimiento de la arquitectura NGPOS, los flujos transaccionales y las integraciones con servicios en la nube y sistemas externos (Pagos, Loyalty/Fidelización, etc.). -Sólida experiencia en programación e ingeniería de software con Golang y C#/.NET, con capacidad para revisar código y orientar técnicamente al equipo. -Capacidad para revisar arquitecturas, diseñar mocks/emuladores y construir y administrar entornos de prueba físicos y virtuales. -Conocimientos de ingeniería de performance y pruebas, incluyendo análisis de métricas, herramientas APM, análisis de memory dumps y thread dumps, tracing y análisis de causa raíz. -Líder efectivo con excelentes habilidades de comunicación, capaz de mentorizar equipos, remover bloqueos y promover el alineamiento entre stakeholders. -Seguridad y criterio para cuestionar objetivos poco realistas utilizando información basada en datos y proponiendo alternativas viables. -Conocimientos de prácticas de DevOps (pipelines de CI/CD y automatización de pruebas de performance, monitoreo y reporting) ¿Qué ofrecemos?
