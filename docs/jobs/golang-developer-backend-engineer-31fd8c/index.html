Loza Studio — українська IT-компанія, яка створює складні цифрові рішення: веб- і мобільні застосунки, державні сервіси, портали, реєстри, B2B-системи та внутрішні корпоративні продукти. Ми шукаємо Golang Developer / Backend Engineer для роботи над backend-сервісами, мікросервісною архітектурою, інтеграціями та високонавантаженими системами. Це роль для розробника, який вміє не просто писати код, а проєктувати з врахуванням наступних ітерацій, брати участь в роботі з інфраструктурою, брати участь у технічних обговореннях і пропонувати рішення. Що потрібно буде робити • Розробляти та масштабувати backend-сервіси на Go / Golang. • Проєктувати, підтримувати та оптимізувати мікросервісну архітектуру. • Розробляти та підтримувати REST API. • Працювати з інтеграціями між сервісами та зовнішніми системами. • Працювати з базами даних, оптимізувати запити та структури даних. • Брати участь у проєктуванні архітектури backend-рішень. • Працювати з великими обсягами даних, чергами, асинхронними процесами та retry-механізмами. • Писати чистий, підтримуваний і тестований код. • Брати участь у code review та технічних обговореннях. • Допомагати команді знаходити оптимальні технічні рішення. • Працювати з контейнеризацією та deployment-процесами. • Підтримувати стабільність, продуктивність і масштабованість backend-систем. • Працювати з логами, метриками, моніторингом і технічною діагностикою. Що очікуємо від кандидата • Комерційний досвід backend-розробки від 4 років. • Практичний досвід розробки на Go / Golang. • Розуміння принципів побудови мікросервісної архітектури. • Досвід проєктування та розробки REST API. • Досвід роботи з базами даних: PostgreSQL / MongoDB / Redis або аналогами. • Розуміння принципів роботи з чергами, асинхронними задачами та background jobs. • Досвід написання unit/integration tests. • Розуміння принципів OOP, SOLID, Design Patterns, TDD, SDD. • Досвід роботи з Git, pull requests та code review. • Вміння працювати в команді з PM, BA, QA, frontend-розробниками та DevOps. • Англійська на рівні читання технічної документації. Технічні навички Backend • Go / Golang. • REST API. • Microservices • PostgreSQL / MongoDB / Redis - оптимізація запитів • Робота з великими обсягами даних • Розуміння потоків даних та їх оптимізації • Асинхронні процеси, черги, retry-механізми • Unit та integration testing • RabbitMQ, Kafka, NATS JetStream або аналогів • Розуміння принципів побудови високонавантажених систем Інфраструктура та DevOps • Docker / Kubernetes • CI/CD • AWS / VMWare - буде перевагою • Terraform / Ansible • Grafana або інші інструменти моніторингу • Робота з логами, метриками та технічною діагностикою. Soft skills • Відповідальність за результат. • Системне та критичне мислення. • Уважність до деталей. • Вміння самостійно приймати технічні рішення. • Готовність брати участь у технічних обговореннях. • Вміння чітко формулювати думки, запити та проблеми. • Командність і здатність допомагати іншим учасникам команди. • Готовність працювати з комплексними задачами та складними продуктами. • Бажання розвиватися професійно та поглиблювати експертизу.
