Fullstack Developer (Golang, NextJs)

The Fullstack Engineer designs, builds, and maintains end-to-end features for client Skyshi enterprise eprocurement platform — part of the eSuite business-application ecosystem — covering the procure- to- pay lifecycle: purchase requisitions, purchase orders, goods receipt, sourcing events, contracts, supplier management, and the configuration layer that lets each company tailor procurement to its own processes. The role delivers reliable, maintainable software across Go backend microservices and a React / Next.js micro-frontend, working inside a live, multi-company production platform. This position joins the eprocurement squad for the next phase of the product. Engineers work as peers, each taking full ownership of features from requirement to production deployment, while collaborating closely with product, QA, and fellow engineers. Key Responsibilities 1. Backend Development & APIs • Design, develop, and maintain Go backend microservices exposing REST and gRPC / Protobuf APIs, following clean / layered architecture. • Model, query, and optimise data in MongoDB (schema design, indexing, aggregation pipelines, pagination), with Redis for caching. • Implement procurement business flows — approvals, state transitions, document versioning, and event history — with correctness, auditability, and multi-company data isolation in mind. • Build asynchronous, event-driven processing with RabbitMQ (e.g. export/import jobs, notifications, scheduled reports), applying retry and idempotency patterns. 2. Frontend Development • Build and extend procurement modules in a TypeScript / React micro-frontend monorepo (Next.js, pnpm, Turborepo) using a shared internal design system. • Implement data-heavy enterprise UI: complex forms and validation, configurable tables and views, advanced filters, attachments, and multi-language support. • Manage server and client state (e.g. TanStack Query, Zustand) against backend APIs; optimise for performance and usability. • Collaborate with product and design to translate requirements and UI/UX into high-quality, accessible implementations. 3. Integration & Platform • Integrate with other eSuite microservices (master data, inventory, finance & accounting, notification, reporting) over gRPC and message queues. • Contribute to ERP integration flows (e.g. SAP) for vendors, purchase orders, and goods receipt — including outbound push, status synchronisation, and error handling. • Contribute to file export/import, document generation, and object-storage based attachment handling. 4. Project Delivery & Collaboration • Own end-to-end delivery of features across backend and frontend: refinement, estimation, implementation, testing, and production release — each item shipped to production within its own delivery cycle. • Work from PRDs and RFCs; write or contribute to technical design documents for your features. • Coordinate with product, QA, and DevOps to meet release timelines; take part in production support and bug fixing when needed. 5. Code Quality, Testing & Knowledge Sharing • Write and maintain unit, integration, and end-to-end tests (e.g. Go testing with testcontainers, Vitest, Playwright). • Participate in merge-request reviews and uphold coding standards, security baselines, and documentation practices. • Actively share knowledge and help keep the team’s technical knowledge base current. Qualifications & Requirements Education & Experience • Bachelor’s degree in Computer Science, Information Technology, or a related field. • Minimum 4 years of experience in fullstack software engineering (backend + web frontend), with a proven track record of shipping production applications. • Demonstrated ability to become productive quickly in a large, live, multi-service codebase with minimal onboarding. Domain Experience (Procurement / ERP) • Required — Hands-on experience building enterprise business applications: ERP, eprocurement, supply chain, finance, or other back-office / B2B SaaS systems. • Familiarity with procure-to-pay concepts — purchase requisition, purchase order, goods receipt, vendor management, contracts, approval workflows, budgets, and tax / currency handling. Technical Skills • Backend — Strong hands-on Go (Golang) for production microservices (e.g. Fiber or similar HTTP frameworks); comfortable reading and extending existing services quickly. • Databases — Solid experience with MongoDB (schema design, indexing, aggregation); Redis for caching. • Frontend — Proficient with TypeScript, React, and Next.js; experience with form, state, and data- fetching libraries (React Hook Form or TanStack Form, Zod, TanStack Query / Table, Zustand) and Tailwind CSS. • API design — Solid understanding of RESTful and gRPC / Protobuf API design and inter-service contracts. • Messaging — Experience with RabbitMQ or similar brokers for asynchronous, event-driven processing. • Version control — Proficient with Git and GitLab-style collaborative workflows (branching, merge- request reviews, CI pipelines). • Fundamentals — Solid grasp of data structures, testing, debugging, and performance optimisation. • AI-assisted development — Proficient using AI coding assistants (e.g. Claude Code, GitHub Copilot, Cursor) to accelerate development, review, debugging, and documentation — while maintaining code quality, security, and sound engineering judgment. Soft Skills • Strong analytical and problem-solving skills; able to turn business requirements into clear technical solutions. • Good communication in Bahasa Indonesia and English, and ability to work cross-functionally. • Ownership mindset, proactive, and able to work independently with minimal supervision. • Comfortable in a fast-paced, delivery-focused project environment with clear async communication. Nice to Have • ERP integration experience, particularly SAP (e.g. IDoc, BAPI, OData, or middleware-based integration). • Experience with micro-frontend architecture and monorepo tooling (pnpm workspaces, Turborepo). • Experience building configurable / metadata-driven features: custom fields and objects, rule engines, workflow or process automation, notification templates. • Reporting and data-export experience (scheduled reports, large export/import jobs). • Observability and cloud-native tooling: OpenTelemetry, Docker, Kubernetes, GitOps (e.g. ArgoCD). • Experience with multi-company / multi-tenant SaaS and role-based permission models.
